Adjust Letter Shifts in Inkscape

Adjusting individual letter positions in Inkscape allows you to fine-tune typography through custom horizontal kerning and vertical baseline shifts. This guide explains how to shift letters precisely using both keyboard shortcuts and the Text tool controls bar, as well as how to reset your text formatting when needed.

Using Keyboard Shortcuts

The fastest way to shift letters horizontally or vertically is with keyboard shortcuts directly on the canvas.

  1. Select the Text tool from the left toolbar or press F8 (or T).
  2. Click inside your text block to place the cursor between or immediately before the letters you want to shift. Alternatively, highlight specific characters to move them together.
  3. Use the following key combinations:
    • Horizontal Shift (Kerning): Hold Alt and press the Left Arrow or Right Arrow key.
    • Vertical Shift (Baseline Offset): Hold Alt and press the Up Arrow or Down Arrow key.
    • Larger Increments: Hold Shift + Alt while pressing any arrow key to shift the letters by a 10x larger step.

Using the Tool Controls Bar

If you need precise numerical values for letter shifts, use the input fields located in the top control bar while the Text tool is active.

  1. Activate the Text tool and highlight the specific letter(s) you want to adjust.
  2. Look at the top control bar for the following input fields:
    • Horizontal shift (Dx): Enter a positive value to shift the character right or a negative value to shift it left.
    • Vertical shift (Dy): Enter a positive value to shift the character downward or a negative value to shift it upward.
  3. Press Enter to apply the shift value.

How to Remove Manual Letter Shifts

If you need to restore the original letter spacing and baseline alignment:

  1. Select the text object with either the Select tool (S) or Text tool (T).
  2. Go to the top menu and select Text > Remove Manual Kerns.
  3. All horizontal and vertical letter shifts will immediately reset to default.
