Limit Colors to SVG Named Colors in Inkscape

This guide explains how to configure Inkscape to restrict your color selection strictly to the standardized SVG Named Colors palette. By switching the active palette and using the Swatches panel exclusively for fills and strokes, you can ensure that every color used in your vector artwork strictly matches the W3C SVG color specification without accidental deviations.

Step 1: Switch the Palette Bar to SVG Named Colors

  1. Look at the bottom of the Inkscape workspace where the color palette bar is located.
  2. Click the small arrow icon on the far right edge of the color bar to open the palette menu.
  3. Scroll through the list and select SVG Named Colors.

The color bar at the bottom will immediately reload to display only the 147 officially recognized SVG/CSS color names (such as aliceblue, crimson, forestgreen, and navy).

Step 2: Open and Dock the Swatches Panel

Using the Swatches panel is the most reliable way to pick and verify colors by their official names rather than guessing hex values.

  1. Open the menu and go to View > Swatches (or press Shift + Ctrl + W).
  2. If the panel does not automatically show the correct palette, click the menu icon in the upper-right corner of the Swatches panel and choose SVG Named Colors.
  3. Resize the panel so that the color names are clearly visible alongside the color tiles.

Step 3: Apply Colors Exclusively from the Palette

To maintain strict compliance, apply colors directly using the Swatches panel or the bottom palette bar:

  • Set Fill: Select your object and left-click the desired color swatch.
  • Set Stroke: Select your object, hold Shift, and left-click the desired color swatch.
  • Fill and Stroke Dialog: Open the dialog (Object > Fill and Stroke or Shift + Ctrl + F). On either the Fill or Stroke paint tab, click the Swatch button (the icon depicting a grid of color tiles). This forces the object's paint definition to link directly to a selected swatch rather than arbitrary RGB, HSL, or CMYK slider values.

Step 4: Avoid Unconstrained Eyedropper Sampling

The Eyedropper tool (D or F7) samples rendered screen pixels, which can vary based on opacity, antialiasing, and display color management. To avoid picking non-compliant RGB values:

  • Do not use the Eyedropper on imported raster images or antialiased object edges.
  • If you must copy colors between objects, select the target object and use the Swatches panel, or select the source object, copy it (Ctrl + C), select the target, and choose Edit > Paste Style (Ctrl + Shift + V) to duplicate the exact SVG color assignment.
