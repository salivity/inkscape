Import SketchUp Vector Details into Inkscape via PDF

This guide explains how to accurately export architectural details as vector graphics from Trimble SketchUp using the 2D PDF export feature and seamlessly import them into Inkscape. By following this workflow, you can preserve precise drawing scales, capture clean vector line work directly from your 3D models, and easily edit paths, colors, and line weights for presentation boards or technical documentation.

Step 1: Prepare the View in SketchUp

To ensure your architectural details export as accurate, undistorted vector drawings, you must configure the camera properly:

  1. Open your model in SketchUp and zoom into the specific detail you want to export.
  2. Go to the top menu and select Camera > Parallel Projection. Do not use Perspective mode, as perspective views cannot be exported as true scaled vectors.
  3. Select a standard view under Camera > Standard Views (such as Top, Front, or Right) to align the camera perpendicular to the detail.
  4. Set the visual style by navigating to Window > Styles. Choose a simple style, such as Hidden Line, to eliminate textures and backgrounds that can generate unnecessary raster data.

Step 2: Export a Vector 2D PDF

SketchUp’s 2D export feature can generate resolution-independent vector lines when saved as a PDF:

  1. Click File > Export > 2D Graphic.
  2. Set the file format dropdown to PDF File (*.pdf).
  3. Click the Options button before saving to configure the export settings.
  4. Under the Drawing Size or Scale section, uncheck "Match View Size" if you require an exact architectural scale (such as 1:1, 1/4" = 1', or 1:20). Set your desired ratio.
  5. Ensure that options generating raster outputs (such as shadows or certain profile extensions) are disabled to produce pure vector paths.
  6. Click OK, choose your destination folder, and click Export.

Step 3: Import the PDF into Inkscape

Once the PDF is generated, bring it into Inkscape using settings that preserve path data:

  1. Launch Inkscape and go to File > Open or File > Import, then select your exported PDF.
  2. In the PDF Import Settings dialog, choose the Internal import engine.
  3. In the precision settings, ensure the resolution for rendering raster objects matches your intended output, though vector paths will remain mathematically defined regardless.
  4. If your drawing contains text labels, check the appropriate font handling settings (either keeping them as text if the fonts are installed, or converting them to paths).
  5. Click OK to place the drawing onto the Inkscape canvas.

Step 4: Clean and Organize Vector Paths

SketchUp wraps exported PDFs inside multiple nested groups and clipping masks that must be cleared for easy editing:

  1. Select the imported drawing and right-click to select Ungroup (or press Ctrl + Shift + G / Cmd + Shift + G). Repeat this several times until the individual lines are selectable.
  2. If the lines are trapped inside a boundary, select the drawing, go to Object > Clip, and select Release Clip. Delete the resulting bounding box rectangle.
  3. Open the Fill and Stroke panel (Ctrl + Shift + F / Cmd + Shift + F).
  4. Select all lines and set uniform line joins, caps, and stroke widths. Because SketchUp exports lines in thin, default weights, you can now apply architectural graphic standards by categorizing heavy cut lines, medium object lines, and light hatch lines into dedicated Inkscape layers.
