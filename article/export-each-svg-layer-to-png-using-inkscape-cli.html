Export Each SVG Layer to PNG Using Inkscape CLI

This guide demonstrates how to automate exporting every layer of an SVG document into individual PNG images using the Inkscape command-line interface (CLI). By parsing layer identifiers from the SVG file and executing Inkscape export commands within a batch script, you can quickly generate isolated graphic assets without manually toggling layer visibility inside the Inkscape graphical interface.

The Base Inkscape Command

In modern versions of Inkscape (v1.0 and newer), exporting a specific object or layer to PNG is handled via the following command:

inkscape input.svg --export-id="LAYER_ID" --export-id-only --export-type="png" --export-filename="output.png"
  • --export-id="LAYER_ID": Specifies the id of the layer or group you want to render.
  • --export-id-only: Ensures that only the specified element is drawn, hiding all other objects and layers.
  • --export-type="png": Sets the export target format to PNG.
  • --export-filename="output.png": Designates the output file path.

Understanding SVG Layer Structure

Inkscape stores layers as standard SVG <g> (group) elements tagged with a special attribute: inkscape:groupmode="layer". Each layer also has an id attribute (used internally by Inkscape) and an inkscape:label attribute (the human-readable layer name displayed in the UI).

Because the Inkscape CLI does not have a single native switch to "export all layers," you need a lightweight wrapper script to extract these layer IDs and invoke the export command iteratively.

Method 1: Cross-Platform Python Script

Using Python is the most robust, cross-platform approach because it natively parses the SVG's XML structure and executes the CLI commands via the subprocess module.

Save the following script as export_layers.py:

import sys
import os
import subprocess
import xml.etree.ElementTree as ET

def export_svg_layers(svg_path, output_dir="output"):
    if not os.path.isfile(svg_path):
        print(f"Error: File '{svg_path}' not found.")
        sys.exit(1)

    os.makedirs(output_dir, exist_ok=True)

    # Namespaces used by Inkscape SVG files
    namespaces = {
        'svg': 'http://www.w3.org/2000/svg',
        'inkscape': 'http://www.inkscape.org/namespaces/inkscape'
    }

    tree = ET.parse(svg_path)
    root = tree.getroot()

    # Find all group tags acting as Inkscape layers
    layers = root.findall(".//svg:g[@inkscape:groupmode='layer']", namespaces)

    if not layers:
        print("No Inkscape layers found in document.")
        return

    print(f"Found {len(layers)} layer(s). Starting export...")

    for layer in layers:
        layer_id = layer.attrib.get("id")
        # Use human-readable label if present; fall back to ID
        label_attr = f"{{{namespaces['inkscape']}}}label"
        layer_name = layer.attrib.get(label_attr, layer_id)

        # Sanitize filename
        safe_name = "".join(c for c in layer_name if c.isalnum() or c in (' ', '_', '-')).strip()
        output_file = os.path.join(output_dir, f"{safe_name}.png")

        cmd = [
            "inkscape",
            svg_path,
            f"--export-id={layer_id}",
            "--export-id-only",
            "--export-type=png",
            f"--export-filename={output_file}"
        ]

        print(f"Exporting '{layer_name}' -> {output_file}")
        subprocess.run(cmd, check=True)

    print("All layers successfully exported.")

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: python export_layers.py <input.svg> [output_directory]")
        sys.exit(1)

    target_svg = sys.argv[1]
    out_dir = sys.argv[2] if len(sys.argv) > 2 else "output"
    export_svg_layers(target_svg, out_dir)

Run the script from your terminal:

python export_layers.py drawing.svg ./exported_pngs

Method 2: Bash Script Using Inkscape Actions

If you are on Linux or macOS and prefer a pure shell script, you can query object IDs directly using Inkscape's built-in query system or standard XML tools like xmlstarlet.

Here is a Bash script utilizing xmlstarlet to parse the layer attributes:

#!/usr/bin/env bash

set -e

SVG_FILE="$1"
OUTPUT_DIR="${2:-./layers_out}"

if [ -z "$SVG_FILE" ] || [ ! -f "$SVG_FILE" ]; then
    echo "Usage: $0 <path-to-svg> [output-dir]"
    exit 1
fi

mkdir -p "$OUTPUT_DIR"

# Extract layer ID and layer label pairs
xmlstarlet sel -N svg="http://www.w3.org/2000/svg" \
               -N inkscape="http://www.inkscape.org/namespaces/inkscape" \
               -t -m "//svg:g[@inkscape:groupmode='layer']" \
               -v "@id" -o ":" -v "@inkscape:label" -n "$SVG_FILE" | while IFS=":" read -r LAYER_ID LAYER_LABEL; do

    # Fallback to ID if label is empty
    FILENAME="${LAYER_LABEL:-$LAYER_ID}"
    OUTPUT_PNG="$OUTPUT_DIR/${FILENAME}.png"

    echo "Exporting: $FILENAME (ID: $LAYER_ID)"

    inkscape "$SVG_FILE" \
        --export-id="$LAYER_ID" \
        --export-id-only \
        --export-type=png \
        --export-filename="$OUTPUT_PNG"
done

echo "Layer export complete."

Make the script executable and run it:

chmod +x export_layers.sh
./export_layers.sh graphic.svg ./output_layers

Customizing Resolution and Dimensions

You can append sizing flags to any of the Inkscape commands within these scripts:

  • Set explicit DPI (default is 96):
    --export-dpi=300
  • Set a fixed export width (height scales proportionally):
    --export-width=1920
  • Set a fixed export height (width scales proportionally):
    --export-height=1080
