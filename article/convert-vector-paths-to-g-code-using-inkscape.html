Convert Vector Paths to G-Code Using Inkscape

Converting vector paths to G-code in Inkscape allows you to transform 2D designs into machine-readable instructions for CNC milling machines. This guide walks you through the entire workflow: preparing vector objects, establishing physical machine coordinates with orientation points, configuring cutting parameters via the tool library, and exporting standard G-code files using Inkscape's built-in Gcodetools extension.

Step 1: Prepare the Vector Design

  1. Open your design in Inkscape or import your existing vector file.
  2. Select all objects in your design using Ctrl + A.
  3. Convert every element to standard vector paths by navigating to Path > Object to Path.
  4. If you have overlapping or grouped shapes, ungroup them (Ctrl + Shift + G) and combine them into a single path if necessary (Path > Combine).
  5. Open File > Document Properties and set your display units to millimeters (mm) or inches (in) to match your CNC controller configuration.

Step 2: Set Orientation Points

Orientation points tell the G-code generator the physical scale, coordinate origin, and cutting depth of your material.

  1. Navigate to Extensions > Gcodetools > Orientation points...
  2. In the dialog, set:
    • Orientation type: 2-points mode.
    • Z surface: 0.0 (the top surface of the workpiece).
    • Z depth: The target cutting depth (e.g., -3.0 for a 3mm cut depth).
    • Units: Match your document units (mm or in).
  3. Click Apply and then close the dialog.
  4. Inkscape will place a coordinate marker on your canvas. By default, the (0,0) point appears at the bottom-left corner of the document. Move your drawing relative to this origin as needed.

Step 3: Configure the Tool Library

  1. Go to Extensions > Gcodetools > Tools library...
  2. Select Cylinder (standard end mill for milling) and click Apply.
  3. A green rectangle containing tool parameters will appear on your canvas.
  4. Select the Text Tool (F8) and manually edit the text inside the green box to match your milling bit and machine capabilities:
    • diameter: Diameter of your end mill.
    • feed: Cutting feed rate (speed along X and Y axes).
    • penetration feed: Plunge rate (speed along the Z axis).
    • depth step: Maximum depth per pass.
    • spindle rpm: Target spindle speed.

Step 4: Generate the G-Code

  1. Select the paths you wish to mill.
  2. Go to Extensions > Gcodetools > Path to G-code...
  3. Switch to the Preferences tab:
    • File: Enter a filename (e.g., output.ngc or design.gcode).
    • Directory: Enter the absolute folder path where the file should be saved (e.g., C:\cnc_files on Windows or /home/user/cnc on Linux/macOS).
    • Z safe height: Specify clearance height above the material during rapid travel (e.g., 5.0).
  4. Switch to the Path to G-code tab:
    • Biarc interpolation tolerance: Set to 0.01 or 0.001 for accurate curve rendering.
  5. Click Apply.

Inkscape processes the paths and generates the .gcode or .ngc file in your designated directory, complete with toolpaths and cutting passes divided according to your defined depth step. Load this output file into your CNC control software (such as Universal Gcode Sender, Candle, or Mach3) to begin machining.
