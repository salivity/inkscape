How to Use Contextual Alternates in Inkscape

Contextual alternates allow handwritten script fonts to mimic real handwriting by dynamically changing letterforms based on surrounding characters. Inkscape includes full support for advanced OpenType features, enabling you to toggle these dynamic substitutions on and off without altering your raw text. This guide covers how to locate the OpenType feature controls in Inkscape and apply contextual alternates to your handwritten script fonts for seamless, natural-looking lettering.

1. Verify Font Support

Before adjusting settings in Inkscape, ensure your chosen script font actually includes contextual alternates. Fonts formatted as OpenType (.otf) or TrueType with OpenType tables (.ttf) typically contain these features. If a font lacks the contextual alternates (calt) OpenType table, enabling the setting in Inkscape will have no visual effect.

2. Select Your Text Object

  1. Open your project in Inkscape.
  2. Select the Text Tool (shortcut: T) or the Select and Transform Tool (shortcut: S).
  3. Click on the text object containing your handwritten script font, or highlight the specific portion of text where you want to apply the alternates.

3. Open the Text and Font Dialog

Inkscape centralizes OpenType typographical controls inside the dedicated Text and Font panel:

  • Go to the top menu and select Text > Text and Font...
  • Alternatively, press the keyboard shortcut Shift + Ctrl + T (or Shift + Cmd + T on macOS).

4. Enable Contextual Alternates

  1. In the Text and Font dialog on the right side of your workspace, click on the Features tab located next to the Font tab.
  2. Browse through the available OpenType feature categories. Look for the section labeled Substitution or Ligatures and Alternates.
  3. Locate Contextual Alternates (represented technically by the OpenType feature tag calt).
  4. Check the box or toggle the dropdown next to Contextual Alternates to activate the feature.
  5. In the same panel, you may also want to ensure Standard Ligatures (liga) is enabled, as many script fonts rely on both ligatures and contextual alternates to link cursive strokes properly.

5. Apply the Changes

After checking the box, the effect will not render automatically on the canvas. Click the Apply button at the bottom-right corner of the Text and Font dialog. Inkscape will immediately update the selected text, replacing default characters with contextual variants that flow smoothly into neighboring letters.

Troubleshooting and Manual Glyphs

If certain letters still do not connect as expected:

  • Ensure the text object is active and properly highlighted when clicking Apply.
  • Open Text > Glyphs... to manually inspect all available alternate glyphs embedded in the font. You can double-click specific alternate characters from the glyph grid to insert them manually into your text string.
