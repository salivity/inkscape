How to Swap Fill and Stroke in Inkscape

This guide covers the default keyboard shortcut to instantly swap the fill and stroke colors of an object in Inkscape. You will learn the exact key combination, how to apply it to your vector selections, and how Inkscape handles transparency and stroke properties during the swap.

The default keyboard shortcut to swap the fill and stroke colors of a selected object in Inkscape is Shift + X.

To use this shortcut:

  1. Select the Select and Transform objects tool (shortcut: S or F1).
  2. Click on the object or group of objects you want to modify.
  3. Press Shift + X on your keyboard.

When executed, the current fill color immediately transfers to the stroke outline, and the stroke color fills the interior of the path.

Key Behaviors to Note

  • No Fill or No Stroke: If an object has a fill color but no stroke, pressing Shift + X removes the fill and applies that color to the stroke. Conversely, an object with only a stroke will lose its outline and gain a solid fill.
  • Stroke Width Preservation: Swapping colors does not alter the stroke width or style (such as dashes or joins). Inkscape only exchanges the paint values (color, gradient, or pattern), leaving geometric stroke settings intact.
  • Multiple Selections: You can select multiple objects simultaneously and press Shift + X to swap the fill and stroke properties across all selected items at once.
