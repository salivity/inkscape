How to Rasterize Filters to PNG in Inkscape

Applying complex SVG filters in Inkscape often leads to noticeable canvas lag and inconsistent rendering across different vector viewers. This guide provides a straightforward method to bake an applied filter directly into an embedded, rasterized PNG on your canvas. By utilizing Inkscape's internal bitmap copy tool, you can preserve the visual appearance of your filtered artwork while significantly improving document performance and compatibility.

Step 1: Set the Desired PNG Resolution

Before generating the rasterized copy, ensure your export resolution matches your project requirements (e.g., 96 DPI for screen or 300 DPI for print):

  1. Go to Edit > Preferences (or press Ctrl + Shift + P).
  2. In the left sidebar, navigate to Imported Images or Bitmaps (depending on your Inkscape version).
  3. Locate the Resolution for Create Bitmap Copy setting.
  4. Set the value to your preferred DPI (such as 300 for high-resolution graphics) and close the Preferences window.

Step 2: Select the Filtered Object

  1. Choose the Select and Transform objects tool (S or F1).
  2. Click on the object, path, or group that contains the applied SVG filter.

Step 3: Create the On-Canvas Bitmap Copy

  1. With the object selected, navigate to Edit in the top menu.
  2. Click Make a Bitmap Copy (or press the keyboard shortcut Alt + B).
  3. Inkscape immediately renders the filtered object into an embedded PNG and places it directly on the canvas, stacked immediately above the original object.

Step 4: Remove or Hide the Original Object

Because the newly created bitmap sits precisely over the original vector object, you must manage the underlying source:

  1. Select the original filtered vector object using the Objects dialog (Ctrl + Shift + O / Layer > Objects...).
  2. Either delete the original object by pressing Delete, or click the eye icon next to it in the Objects panel to hide it if you want to keep the vector source for future edits.

The resulting PNG retains all the visual characteristics of your applied filter without consuming the processing power required to render dynamic SVG filter effects in real time.
