Automatically Vacuum Defs When Saving in Inkscape

This guide explains how to automatically purge unused definitions—historically known as the "Vacuum Defs" command—when saving vector files in Inkscape. While standard Inkscape SVG files do not run this cleanup natively on default saves, you can achieve automatic defs removal by saving your file using the Optimized SVG profile or by utilizing Inkscape's command-line automation.

Understanding Vacuum Defs in Modern Inkscape

In Inkscape version 1.0 and newer, the legacy Vacuum Defs command was renamed to Clean Up Document (found manually under File > Clean Up Document). This function removes unreferenced markers, gradients, patterns, and filters from the <defs> section of your SVG file to minimize file size.

Method 1: Automating Cleanup Using Optimized SVG

The built-in way to automatically strip unused defs whenever you save is to use the Optimized SVG output filter, which passes the file through the Scour optimization engine during the save process.

  1. Open your document in Inkscape.
  2. Go to File > Save As... (or press Ctrl + Shift + S / Cmd + Shift + S).
  3. In the "Save as type" dropdown menu, select Optimized SVG (*.svg).
  4. Choose your file destination and click Save.
  5. An Optimized SVG Output options window will appear. Navigate to the SVG Output tab and verify the following settings:
    • Check Remove unused defs (or Remove unreferenced elements).
    • Check any additional cleanup options you want, such as removing metadata or editor data.
  6. Click OK.

Inkscape saves these settings as your default optimization profile. For subsequent saves using the Optimized SVG format, Inkscape automatically vacuums unused definitions without requiring manual cleanup beforehand.

Method 2: Automatic Cleanup via Command Line Actions

If you are automating file saves or batch exports, you can call Inkscape’s internal cleanup routines automatically through the command-line interface (CLI) using Inkscape actions.

Run the following command in your terminal:

inkscape --actions="clean-up;export-filename:cleaned_output.svg;export-do" input.svg

In this command:

  • clean-up executes the internal Vacuum Defs routine.
  • export-filename:cleaned_output.svg designates the target file name.
  • export-do writes the cleaned file to disk.
