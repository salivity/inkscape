How to Add CSS Classes and IDs in Inkscape

Inkscape allows you to assign CSS classes and unique IDs to vector paths and objects, making your Scalable Vector Graphics (SVG) ready for dynamic web styling and animation. By using either the Object Properties panel or the built-in XML Editor, you can attach clean identifiers to any graphic element and target them with external or embedded CSS stylesheets.

Method 1: Using the Object Properties Panel

The Object Properties panel is the fastest and most user-friendly way to assign classes and IDs to elements.

  1. Select the Object: Click on the path, shape, or group you want to style on the canvas.
  2. Open Object Properties: Right-click the object and choose Object Properties, or press Shift + Ctrl + O (Shift + Cmd + O on macOS).
  3. Set the ID: In the ID field, enter a unique name (e.g., hero-graphic). Click Set to apply the change.
  4. Set the Class: In the Class or Classes field, enter one or more class names separated by spaces (e.g., interactive-btn primary-fill). Click Set.

Method 2: Using the XML Editor

For deeper control over the SVG DOM hierarchy, use the XML Editor to add or modify standard SVG attributes directly.

  1. Select the Object: Click the target element on the canvas.
  2. Open the XML Editor: Go to Edit > XML Editor, or press Shift + Ctrl + X (Shift + Cmd + X on macOS).
  3. Locate the Node: The selected element's node (such as <svg:rect>, <svg:path>, or <svg:g>) will automatically highlight in the tree.
  4. Add or Modify Attributes:
    • To change an ID, select the id attribute in the right pane, update the string, and press Enter or click the checkmark button.
    • To add a class, type class into the top attribute field, enter your class name in the bottom value field, and click Set.

Method 3: Managing Styles with the Selectors and CSS Dialog

Inkscape includes a dedicated panel to manage CSS rules within the SVG document itself.

  1. Open the Dialog: Go to Object > Selectors and CSS... or press Shift + Ctrl + Q.
  2. Create a Rule: Click the + button at the bottom of the panel to add a new CSS selector (for example, .primary-fill or #hero-graphic).
  3. Add Properties: Select your rule and add styling properties like fill: #ff5500;, stroke: #333333;, or opacity: 0.8;.
  4. Link to Elements: Drag and drop elements into selectors, or assign classes to auto-link them to your defined rules.

Exporting for Web Use

Once your IDs and classes are applied, save the file by going to File > Save As... and selecting Optimized SVG or Plain SVG. This removes unnecessary Inkscape-specific metadata while preserving all id and class attributes, allowing web developers to manipulate the graphics seamlessly via CSS and JavaScript.
