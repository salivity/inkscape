Change Connector Routing Style in Inkscape

Inkscape allows you to build dynamic flowcharts and diagrams using the Connector tool, which links objects together with lines that automatically adjust as objects move. You can easily switch the routing style of these connectors between orthogonal (right-angled) lines and polyline (direct, oblique) lines directly from the tool settings. This guide explains how to toggle the connector routing style for both existing connectors and new lines you create.

Changing Routing for Existing Connectors

  1. Activate the Connector Tool: Click the Create diagram connectors icon in the left-hand toolbox or press the shortcut key O.
  2. Select the Connector: Click on the existing connector line on your canvas that you wish to modify. To select multiple connectors, hold Shift while clicking each line.
  3. Choose the Routing Style: Look at the Tool Controls Bar located horizontally above the canvas:
    • Click the Make connectors orthogonal icon (represented by right-angled lines) to force the connector to route only horizontally and vertically.
    • Click the Make connectors polyline icon (represented by a diagonal/slanted line) to allow straight, direct routing between connection points.

The selected connector will immediately update on the canvas to reflect the chosen routing style.

Setting the Default Style for New Connectors

To set the default routing style for future connectors:

  1. Select the Create diagram connectors tool (O).
  2. Click anywhere on an empty area of the canvas so that no objects or connectors are currently selected.
  3. Click either the Orthogonal or Polyline icon in the Tool Controls Bar.

Any new connectors drawn afterward will use the selected routing style by default.
