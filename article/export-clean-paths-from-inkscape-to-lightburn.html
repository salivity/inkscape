Export Clean Paths from Inkscape to LightBurn

Exporting clean, continuous contours from Inkscape to LightBurn is essential for preventing stuttered laser movements, reducing burn times, and eliminating double cuts. This guide provides a direct, step-by-step workflow to convert raw artwork, combine open nodes, remove overlapping segments, and save the file in an optimal vector format that LightBurn can process without geometry errors.

1. Convert Objects and Text to Pure Paths

LightBurn requires vector coordinate paths rather than live software-specific objects, text elements, or strokes.

  1. Select all elements in your design using Ctrl + A.
  2. Go to Path > Object to Path (Shift + Ctrl + C) to convert shapes (rectangles, circles) and text into editable paths.
  3. If your design relies on stroke thickness rather than outlines, select the stroked paths and go to Path > Stroke to Path (Ctrl + Alt + C) to convert outlines into solid, cuttable boundaries.

2. Join Nodes to Form Continuous Paths

Fragmented line segments cause the laser head to constantly lift and reposition. Joining these segments creates a single, uninterrupted burn path.

  1. Switch to the Edit paths by nodes tool (N).
  2. Select the entire design (Ctrl + A) while this tool is active to reveal all individual nodes.
  3. Box-select the nodes that share endpoints or overlap.
  4. Click the Join selected nodes button on the top toolbar (or Join selected endnodes with a new segment if a gap exists).
  5. Ensure closed loops are fully sealed by clicking Close selected paths.

3. Merge and Clean Up Overlapping Vectors

Overlapping lines cause the laser to cut the same area twice, which can burn through material or warp delicate cuts.

  1. If you have overlapping intersecting shapes that should be a single outline, select them and click Path > Union (Ctrl + +).
  2. To remove redundant duplicate lines lying directly on top of each other, select the objects and use Path > Combine (Ctrl + K).
  3. If necessary, simplify excessively dense node clusters by running Path > Simplify (Ctrl + L), though use this sparingly to prevent unintended shape distortion.

4. Ungroup and Flatten Transforms

Nested groups and hidden coordinate transformations within Inkscape can cause geometry to shift or scale incorrectly when imported into LightBurn.

  1. Select everything (Ctrl + A).
  2. Continuously ungroup by pressing Ctrl + Shift + G until the status bar at the bottom indicates that no groups remain.
  3. Ensure objects are placed within the primary page boundaries to avoid coordinate offset errors upon import.

5. Save as Plain SVG

While LightBurn supports various formats, a sanitized SVG is the most reliable choice for retaining scale, bezier curves, and layer metadata.

  1. Go to File > Save As... (or Shift + Ctrl + S).
  2. In the file type dropdown menu, select Plain SVG (*.svg) instead of the default "Inkscape SVG". This strips out Inkscape-specific XML metadata, leaving clean, raw vector data.
  3. Alternatively, export as Optimized SVG with options set to convert CSS attributes to XML attributes and collapse redundant groups.

6. Verification and Final Optimization in LightBurn

Once imported into LightBurn, run a quick check to verify path continuity.

  1. Drag and drop your newly saved Plain SVG directly into the LightBurn workspace.
  2. Select your imported vectors, right-click, and select Auto-Join Selected Shapes (Alt + J) to ensure any microscopic gaps left behind are closed.
  3. Open the Preview window (Alt + P) and drag the time slider to confirm the laser path flows continuously along shapes rather than jumping erratically between disjointed segments.
