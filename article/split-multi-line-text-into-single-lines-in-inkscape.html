Split Multi-Line Text into Single Lines in Inkscape

This guide explains how to quickly break a multi-line text block into separate, individual text objects in Inkscape. Converting multi-line text into standalone single lines makes it easier to manipulate, position, align, and style each line independently within your vector designs.

Method 1: Using the Built-In "Split Text" Extension

Inkscape includes a native extension designed to separate text blocks by lines, words, or individual characters automatically.

  1. Select Your Text: Click on the multi-line text object using the Select and Transform objects tool (S or F1).
  2. Open the Extension: Go to the top menu and navigate to Extensions > Text > Split Text...
  3. Set the Split Parameter:
    • Set the Split by dropdown menu to Lines.
    • (Optional) Uncheck Preserve original text if you want the separated lines to replace your original text block.
  4. Apply: Click Apply and close the dialog box.

Each line will now be an independent text object that can be moved, edited, or transformed on its own.

Method 2: Using Manual Duplication

For small text blocks with only two or three lines, you can manually duplicate and trim the text:

  1. Select the text block and press Ctrl + D to duplicate it for as many lines as exist.
  2. Select the Text Tool (T), double-click the first object, and delete all lines except the first one.
  3. Repeat the process for each duplicated object, keeping only the corresponding line for that specific object.
  4. Use the Align and Distribute panel (Ctrl + Shift + A) to adjust the spacing between the separated lines.
