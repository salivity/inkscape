How to Use the Inkscape Transform Dialog for Translation

The Transform dialog in Inkscape provides a method for moving, scaling, rotating, skewing, and matrix-transforming vector elements using exact mathematical values. This guide explains how to access the Transform tool, configure specific horizontal and vertical translation inputs, manage measurement units, and apply relative or absolute movements to your selected objects for pixel-perfect alignment.

Step 1: Open the Transform Dialog

To open the Transform panel:

  • Navigate to the top menu and select Object > Transform.
  • Alternatively, use the keyboard shortcut Shift + Ctrl + M on Windows/Linux or Shift + Cmd + M on macOS.
  • The Transform panel will dock on the right side of the workspace.

Step 2: Select the Move Tab

Inside the Transform panel, click on the Move tab. This tab is dedicated exclusively to numerical translations along the X (horizontal) and Y (vertical) axes.

Step 3: Choose Measurement Units

Before entering translation values, select your preferred unit of measurement from the drop-down menu next to the input fields. Available options include:

  • px (Pixels)
  • mm (Millimeters)
  • cm (Centimeters)
  • in (Inches)
  • pt (Points)
  • % (Percentage of object dimensions)

Step 4: Enter Coordinate Values

Specify the exact distance you want the object to travel:

  • Horizontal (X): Enter a positive value to move the object to the right, or a negative value (e.g., -50) to move it to the left.
  • Vertical (Y): Enter a positive value to move the object upward, or a negative value to move it downward.

Step 5: Configure Relative Movement

The Relative move checkbox determines how the entered values are applied:

  • Checked (Relative Move): Shifts the object by the specified amount from its current location every time you apply the transformation.
  • Unchecked (Absolute Move): Moves the top-left corner of the object's bounding box to the exact X and Y coordinates specified relative to the document origin.

Step 6: Apply the Translation

  1. Using the Select Tool (S or F1), click on the object or group of objects you want to move.
  2. If multiple distinct objects are selected, decide whether to check Apply to each object separately (which calculates the movement relative to each individual object's origin rather than the selection bounding box).
  3. Click the Apply button at the bottom of the panel.

The selected element will instantly shift to the exact position defined by your numerical parameters. You can click Apply repeatedly to move the object in increments using the same set values.
