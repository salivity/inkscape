How to Inspect Object Attributes in Inkscape XML Editor

Inkscape includes a built-in XML Editor that exposes the underlying Scalable Vector Graphics (SVG) code of your document. This guide provides a straightforward walkthrough on how to open the XML Editor, select objects on your canvas, and inspect or evaluate their raw attributes, styles, and values directly within the interface.

Opening the XML Editor

To access the XML Editor in Inkscape:

  1. Navigate to the top menu bar and click Edit.
  2. Select XML Editor from the dropdown list.
  3. Alternatively, use the keyboard shortcut:
    • Windows/Linux: Ctrl + Shift + X
    • macOS: Cmd + Shift + X

A docked panel or floating window will appear, displaying the hierarchical XML tree of your current SVG file.

Selecting and Locating Objects

The XML Editor and the canvas feature bidirectional selection:

  • From the Canvas: Select any object using the Select Tool (S or F1). The XML Editor will automatically highlight the corresponding node (such as <svg:path>, <svg:rect>, or <svg:g>) in the element tree on the left side of the panel.
  • From the XML Tree: Click on any node in the tree list to highlight and select that specific element directly on the canvas. Expand group tags (<svg:g>) or layers to reveal nested child objects.

Reading Object Attributes

Once a node is selected, the right side of the XML Editor panel displays all the attributes linked to that element:

  • Attribute Column: Lists standard SVG properties assigned to the object, including id, style, d (path data), transform, width, height, and custom XML namespaces.
  • Value Column: Displays the assigned parameter for each attribute.
  • Value Preview Field: Selecting an attribute from the list displays its full string in the text box located at the bottom-right of the panel. This is useful for inspecting long properties, such as CSS style declarations (fill:#ff0000;stroke-width:1px) or path coordinate strings.

Inspecting Common Properties

  • Geometry and Paths: For basic shapes, inspect attributes like x, y, rx, ry, width, and height. For complex paths, select the d attribute to view raw SVG path commands (M, C, Z, etc.).
  • Styles and Appearance: Look at the style attribute to inspect combined CSS declarations for fill, stroke, opacity, and blend modes. If attributes are written as presentation attributes, they may appear individually (e.g., fill="..." rather than inside style="...").
  • Transforms: If an object has been scaled, translated, or rotated non-destructively, check the transform attribute to view the exact matrix or transformation commands applied to that element.
