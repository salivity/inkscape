Strip SODIPODI Namespaces from SVG in Inkscape

When creating SVG graphics in Inkscape, the software automatically embeds editor-specific metadata, including SODIPODI namespaces (xmlns:sodipodi and sodipodi:* attributes), to preserve editing history, guide data, and canvas settings. While useful during design, this proprietary markup increases file size and can clutter clean production code on the web. This guide explains how to completely remove SODIPODI editor namespaces within Inkscape using the Optimized SVG exporter, the Plain SVG format, and the built-in XML editor.

Method 1: Save as Optimized SVG (Recommended)

The most thorough built-in method to strip SODIPODI attributes, alongside other redundant editor data, is Inkscape's Optimized SVG export. This tool uses the Scour optimization engine to clean the file.

  1. Open your graphic in Inkscape.
  2. Navigate to File > Save As... (or press Shift + Ctrl + S).
  3. In the "Save as type" dropdown, select Optimized SVG (*.svg).
  4. Choose your file destination and click Save.
  5. An optimization dialog window will appear. Configure the settings:
    • Under the SVG Output tab, check the box for Remove metadata.
    • Ensure the option to Remove Inkscape and Sodipodi namespaces is enabled.
    • (Optional) Enable options such as Format output with line-breaks and indentation for readability, or keep it compressed for production.
  6. Click OK to generate the sanitized SVG.

Method 2: Save as Plain SVG

If you want a native vector without additional configuration prompts, you can export your graphic directly as a standard vector format.

  1. Open the file in Inkscape.
  2. Go to File > Save As....
  3. Set the file format dropdown to Plain SVG (*.svg).
  4. Click Save.

This converts the Inkscape-native SVG into standard W3C-compliant SVG markup, stripping out the majority of Sodipodi and Inkscape namespaces. Note that while this method removes most editor tags, it may occasionally leave root namespace declarations if custom definitions persist in the document.

Method 3: Manual Removal via the Built-in XML Editor

If you want absolute control over the document structure without running automated exporters, you can remove the namespaces directly inside Inkscape's XML interface.

  1. Open your document in Inkscape.
  2. Open the XML panel by navigating to Edit > XML Editor or pressing Ctrl + Shift + X.
  3. In the tree view on the left, select the root <svg:svg> node.
  4. Inspect the attributes list on the right panel.
  5. Locate the attribute named xmlns:sodipodi and any elements starting with sodipodi:.
  6. Click the attribute name and select the Delete attribute button (trash can icon) in the toolbar above the attribute panel.
  7. Browse the node tree to delete standalone <sodipodi:namedview> elements if they remain.
  8. Save the file.
