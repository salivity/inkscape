Create Banknote Guilloche Patterns in Inkscape

Guilloche patterns are intricate, high-precision mathematical curves traditionally used on banknotes, certificates, and passports to prevent counterfeiting. In Inkscape, you can generate these complex geometric borders using native rendering extensions, path interpolation, and Live Path Effects (LPE). This guide provides a direct, step-by-step workflow to design professional banknote-style guilloche borders and rosettes without third-party plugins.

Method 1: Generating Base Rosettes with the Spirograph Extension

Inkscape features a built-in parametric curve generator ideal for base guilloche designs.

  1. Open the Spirograph Tool: Go to Extensions > Render > Spirograph...
  2. Configure Curve Parameters:
    • Primary Gear Radius (R): Set the main size (e.g., 100).
    • Secondary Gear Radius (r): Set the internal/external rotating gear size (e.g., 43). Using prime numbers relative to the primary radius generates more complex, non-repeating intersections.
    • Pen Distance (d): Adjust the offset distance of the pen relative to the secondary gear (e.g., 60).
  3. Set Quality: Increase the Resolution slider (e.g., 100 or higher) to ensure smooth vector curves without jagged segments.
  4. Apply: Check Live Preview, fine-tune the parameters until a tight rosette forms, and click Apply.

Method 2: Creating Multi-Layered Borders Using Interpolation

To achieve the dense, alternating line density characteristic of currency borders, use path interpolation.

  1. Draw the Outer and Inner Profiles:
    • Use the Pen (Bezier) Tool (B) to draw a smooth, undulating wave path for the outer edge of your border.
    • Duplicate the path (Ctrl + D), scale it down, or modify its nodes to create an inner bounding wave.
  2. Match Node Direction and Count:
    • Select both paths and convert them to basic paths using Path > Object to Path.
    • Ensure both paths have identical node directions (Path > Reverse if lines cross abnormally during interpolation).
  3. Interpolate the Curves:
    • Select both paths.
    • Navigate to Extensions > Generate from Path > Interpolate...
    • Set Interpolation Steps between 20 and 60 depending on the desired line density.
    • Set Interpolation Method to 1 or 2 for smooth linear transitions.
    • Check Live Preview and click Apply.

Method 3: Building Repetitive Linear Security Borders

To turn a single guilloche wave into a continuous border frame:

  1. Create a Seamless Wave Unit: Draw a single sine wave or figure-eight loop.
  2. Duplicate and Distribute: Use the Clones tool (Edit > Clone > Create Tiled Clones) to repeat the unit horizontally across the canvas with precise X-shift spacing.
  3. Unlink and Combine: Select all tiled elements, choose Edit > Clone > Unlink Clone, and merge them into one continuous object via Path > Combine (Ctrl + K).
  4. Bend Along a Frame:
    • Draw a rectangle to act as your banknote border.
    • Copy the interpolated guilloche pattern (Ctrl + C).
    • Select the rectangle and open Path > Path Effects...
    • Add the Pattern Along Path effect.
    • Click Paste Path in the effect panel and set the pattern copies to Repeated, Stretched.

Finishing Touches for Banknote Authenticity

  • Stroke Width: Select the entire pattern and open Object > Fill and Stroke (Ctrl + Shift + F). Set the stroke width to hairline dimensions, typically between 0.1 mm and 0.25 mm.
  • Layering Colors: Duplicate completed rosettes or borders, scale them slightly, rotate them by a few degrees, and apply high-contrast, fine-line ink colors (e.g., deep cyan, intaglio green, or magenta) with slight opacity adjustments to simulate layered security printing.
