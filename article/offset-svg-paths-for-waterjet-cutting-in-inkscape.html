Offset SVG Paths for Waterjet Cutting in Inkscape

This article explains how to apply tool radius compensation (kerf offset) to vector designs in Inkscape before exporting them as SVG files for waterjet cutting. By calculating your waterjet stream's radius and applying numerical offsets using Inkscape's Path Effects, you will learn how to expand exterior contours outward, contract interior holes inward, flatten the modifications into raw vector geometry, and save a clean SVG file that maintains exact dimensional accuracy on the machine bed.

1. Calculate the Required Offset Value

Waterjet cutting removes a slit of material known as the kerf. The width of this cut is determined by the mixing tube diameter and abrasive flow, typically ranging between 0.030 and 0.045 inches (0.76 to 1.14 mm). Tool radius compensation requires an offset equal to half of the total kerf width:

\[\text{Offset Distance} = \frac{\text{Kerf Width}}{2}\]

Measure your machine's test cut with calipers to confirm the exact kerf width before setting this value.

2. Prepare Your Drawing

Before applying offsets, all shapes and text must be converted into standard vector paths:

  1. Select your entire design using Ctrl + A.
  2. Navigate to Path > Object to Path (Shift + Ctrl + C) to convert primitives (rectangles, circles) into editable paths.
  3. Ungroup any grouped items by pressing Shift + Ctrl + G until the status bar shows "No groups."
  4. If your design includes holes inside an outer boundary, separate them by selecting the combined path and choosing Path > Break Apart (Shift + Ctrl + K). This step is essential because external profiles require outward expansion, while internal profiles require inward contraction.

3. Apply Numerical Offsets Using Path Effects

Do not use the standard Path > Outset command, as it relies on arbitrary pixel steps. Instead, use the Path Effects panel for exact engineering dimensions:

  1. Open the panel via Path > Path Effects.
  2. Select the outer perimeter path.
  3. Click the + (Add Path Effect) button and select Offset.
  4. Set the Offset mode to Interpolated or Beveled/Round depending on your part's corner requirements.
  5. In the Offset input field, enter your calculated tool radius as a positive value (e.g., 0.38 mm or 0.015 in). The perimeter will expand outward.
  6. Select any internal holes or cutouts.
  7. In the Path Effects panel, add the Offset effect and enter the tool radius as a negative value (e.g., -0.38 mm or -0.015 in). The cutout will contract inward.

4. Bake the Offsets into Vector Geometry

Path effects in Inkscape are non-destructive modifiers. CNC controllers and waterjet CAM systems often fail to interpret live path effects correctly, so the geometry must be permanently committed:

  1. Select all paths with applied offsets (Ctrl + A).
  2. Go to Path > Object to Path (Shift + Ctrl + C). This freezes the offsets into permanent vector nodes.
  3. Re-combine internal holes with external borders if your CAM software prefers combined geometry: select the outer path and the inner paths, then choose Path > Combine (Ctrl + K).

5. Export as a Clean SVG

Standard Inkscape SVGs contain proprietary XML tags that can confuse CAM post-processors. Save the file in a standardized format:

  1. Go to File > Save As... (Shift + Ctrl + S).
  2. In the file format dropdown, select Plain SVG (*.svg) instead of Inkscape SVG.
  3. Click Save.

The resulting SVG contains exact compensated toolpaths ready for import into your waterjet nesting software without requiring additional machine-side offset adjustments.
