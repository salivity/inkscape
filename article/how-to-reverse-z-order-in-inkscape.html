How to Reverse Z-Order in Inkscape

Reversing the visual stacking order (z-order) of multiple overlapping objects in Inkscape allows you to invert which elements appear in front and behind without having to rearrange each item manually. This guide outlines the fastest method to flip the stacking order of a multi-object selection using Inkscape's built-in Restack tool.

Using the Restack Tool

Inkscape includes a dedicated dialog for reordering objects based on various criteria, including z-order inversion.

  1. Select the Objects: Use the Selector tool (S or F1) to highlight all the objects whose stacking order you want to reverse. You can do this by dragging a selection box around them or by holding Shift while clicking each object.
  2. Open the Restack Dialog: Navigate to the menu bar and select Object > Restack... (In some versions, this is found under Object > Arrange..., then selecting the Restack tab).
  3. Configure the Order: In the Restack panel, locate the restacking options. Look for the layout options and select Z-Order.
  4. Choose Reverse: Set the order toggle to Reverse (or the icon displaying inverted layers).
  5. Apply the Change: Click the Apply button at the bottom of the dialog.

The relative z-order of your selected items will immediately invert, placing the top-most item at the bottom of the selection and the bottom-most item at the top.

Alternative Method: Cut and Paste in Place

If you have a small number of items and prefer not to open dialog menus, you can manually reverse them sequentially:

  1. Select the top-most object you wish to send to the back.
  2. Press Page Down or select Object > Lower to Bottom (End).
  3. Repeat this process moving down the visual hierarchy until the original stacking sequence is inverted.
