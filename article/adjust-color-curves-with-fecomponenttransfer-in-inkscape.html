Adjust Color Curves with feComponentTransfer in Inkscape

Inkscape allows for non-destructive color grading using SVG filter primitives, with feComponentTransfer serving as the vector equivalent of RGB curves found in raster photo editors. By manipulating individual color channels (Red, Green, Blue, and Alpha) using mathematical transfer functions such as table or gamma, you can build custom tonal curves, adjust contrast, and shift hues directly inside Inkscape. This guide outlines how to configure the feComponentTransfer primitive step-by-step using the Filter Editor panel.

Step 1: Open the Filter Editor

  1. Open your project in Inkscape and select the object or group you want to modify.
  2. Go to the top menu and select Filters > Filter Editor... to open the Filter Editor dock.

Step 2: Create a Custom Filter

  1. In the Filter Editor panel, click the New button in the top-left corner.
  2. A new filter entry (e.g., filter1) will appear in the list.
  3. Rename the filter to something descriptive, such as "Color Curves", by clicking on its label.

Step 3: Add the feComponentTransfer Primitive

  1. At the bottom of the Filter Editor, locate the Add Primitive drop-down menu.
  2. Select Component Transfer (which corresponds to the SVG feComponentTransfer element) from the list.
  3. Click the Add Primitive button.
  4. Ensure the primitive's input is set to Source Graphic by connecting the input node to the default graphic stream in the visual connection pane.

Step 4: Configure the Color Curves

Select the added Component Transfer primitive in the list. The lower half of the Filter Editor displays the controls for each individual channel: R (Red), G (Green), B (Blue), and A (Alpha).

To simulate curves, change the Type dropdown for the target channel:

  • Table (Custom Sampled Curves): Select Table to map an input range of 0 to 1 across custom points. In the Table Values field, enter space-separated numbers between 0.0 and 1.0.

    • High Contrast (S-Curve): Enter 0 0.1 0.5 0.9 1 to compress shadows and stretch highlights.
    • Lift Shadows: Enter 0.2 0.4 0.7 1 to raise the black point without clipping highlights.
    • Invert Channel: Enter 1 0 to flip the curve values.

  • Gamma (Power and Midtone Curves): Select Gamma to adjust exposure and midtones dynamically without mapping every coordinate.

    • Amplitude: Controls the overall intensity scale.
    • Exponent: Adjusts the gamma curve. Values below 1.0 brighten midtones; values above 1.0 darken midtones.
    • Offset: Shifts the entire baseline up or down to adjust the black level.

  • Linear (Slope and Intercept): Select Linear to adjust contrast and brightness globally across that channel using the Slope (contrast multiplier) and Intercept (brightness shift).

Step 5: Apply and Fine-Tune the Filter

  1. Keep your target graphic selected on the canvas.
  2. In the Filter Editor list, check the box next to your new filter name to apply it.
  3. Modify the values in the primitive parameters in real time; Inkscape will immediately render the curve changes on the canvas.
  4. Repeat the process for individual channels to balance color casts (e.g., lowering green values or raising red values in the shadows).
