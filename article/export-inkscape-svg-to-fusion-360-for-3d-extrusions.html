Export Inkscape SVG to Fusion 360 for 3D Extrusions

Transforming 2D vector graphics into 3D models is a standard workflow for custom badges, mechanical faceplates, and artistic designs. This guide walks you through preparing and exporting clean vector paths in Inkscape, importing them into Autodesk Fusion 360 as sketch profiles, and extruding those profiles into solid 3D bodies.

Step 1: Prepare Vector Paths in Inkscape

Fusion 360 requires clean, closed geometric paths to generate extrudable profiles. Text and raw shapes must be converted into standard vector nodes before exporting.

  1. Convert Objects to Paths: Select your artwork, navigate to the top menu, and select Path > Object to Path. If working with text, this converts font characters into editable vector outlines.
  2. Ungroup Elements: Press Ctrl + Shift + G (or Cmd + Shift + G on macOS) repeatedly until all grouped elements are separated into individual paths.
  3. Join Overlapping Shapes: If your design features intersecting parts, select them and use Path > Union to merge them into a single continuous profile.
  4. Ensure Closed Loops: Use the Edit paths by nodes tool (press N) to verify that your paths do not have open gaps. Open paths will import as lines rather than closed profiles, preventing solid extrusion.
  5. Set Document Properties: Open File > Document Properties and set the display units to match your intended Fusion 360 workspace units (typically millimeters). Scale your artwork to the exact target dimensions here to minimize scaling adjustments later.

Step 2: Export as Plain SVG

Inkscape saves files by default with proprietary metadata that can occasionally cause import errors or scaling discrepancies in CAD software.

  1. Go to File > Save As.
  2. In the file type dropdown menu, change the format from Inkscape SVG (*.svg) to Plain SVG (*.svg).
  3. Choose your destination directory and click Save.

Step 3: Insert the SVG into Fusion 360

  1. Open your project in Autodesk Fusion 360.
  2. From the top toolbar in the Solid tab, select Insert > Insert SVG.
  3. Choose the target construction plane or flat face where the sketch should sit.
  4. Click the folder icon next to Select SVG File, locate your Plain SVG, and open it.
  5. Use the canvas manipulator handles to position and rotate the artwork. If the scale is off, adjust the Scale Plane XY factor.
  6. Click OK in the Insert SVG dialog, then click Finish Sketch in the toolbar.

Step 4: Create the 3D Extrusion

  1. In the Solid tab, select the Extrude tool (keyboard shortcut E).
  2. Hover over your imported SVG geometry; closed paths will highlight as light blue profiles. Click inside each profile you wish to extrude.
  3. Enter a value in the Distance input field to define the extrusion thickness.
  4. Choose your operation type—typically New Body for standalone parts or Join / Cut if modifying an existing component.
  5. Click OK to generate the final 3D geometry.
