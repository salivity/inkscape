How to Quickly Duplicate and Offset in Inkscape

This guide demonstrates the most efficient ways to simultaneously duplicate and offset objects in Inkscape using keystrokes. You will learn how to use the dynamic spacebar "stamping" technique for fluid, freeform duplication while moving objects, as well as keyboard-only shortcut combinations for precise, measured offsets.

Method 1: The Spacebar Stamping Technique (Fastest)

The fastest way to duplicate and offset an object on the fly combines mouse movement with a single keypress:

  1. Select the object using the Selector tool (shortcut: S or F1).
  2. Click and begin dragging the object to your desired offset position.
  3. Without releasing the left mouse button, press the Spacebar.
  4. A duplicate is instantly created at that exact offset.

You can continue dragging and tapping the Spacebar repeatedly to stamp as many offset duplicates as you need across the canvas before finally releasing the mouse button.

Method 2: Duplicate and Nudge (Keyboard-Only Precision)

If you require precise, uniform offsets without relying on mouse dragging, use Inkscape's duplicate command paired with arrow keys:

  1. Select the object.
  2. Press Ctrl + D to create a duplicate directly on top of the original.
  3. Immediately press the Arrow keys to move the duplicate to your desired offset.

To control the offset distance:

  • Arrow Key alone: Moves the duplicate by the standard nudge distance (2 px by default).
  • Shift + Arrow Key: Multiplies the offset distance by 10 for larger steps.
  • Alt + Arrow Key: Moves the duplicate by 1 screen pixel for fine adjustments.
  • Alt + Shift + Arrow Key: Moves the duplicate by 10 screen pixels.

To adjust the default distance moved by the arrow keys, navigate to Edit > Preferences > Behavior > Steps and modify the value under Arrow keys move by.
