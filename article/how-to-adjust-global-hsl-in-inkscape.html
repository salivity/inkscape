How to Adjust Global HSL in Inkscape

Adjusting the hue, saturation, and lightness (HSL) of multiple vector elements simultaneously in Inkscape is a common task when adjusting color schemes or balancing an illustration. Rather than modifying each object individually, Inkscape provides dedicated color manipulation tools and extensions that allow you to apply relative or absolute HSL shifts across an entire selection. This guide explains how to quickly modify these color values globally using Inkscape’s built-in features.

Method 1: Using the HSL Adjust Extension

The most precise way to modify colors across multiple objects at once is the HSL Adjust extension. This method applies mathematical shifts to the existing fill and stroke colors of all selected paths.

  1. Select the Objects: Use the Selection tool (S or F1) to select all the shapes you want to modify. To select everything on the canvas, press Ctrl + A.
  2. Open the Color Extension: Go to the top menu and navigate to Extensions > Color > HSL Adjust...
  3. Adjust the Values: A dialog box will appear with several sliders:
    • Hue (deg): Rotates the color wheel to change the base color (from -360° to +360°).
    • Saturation (%): Increases or decreases the intensity of the color (from -100% to +100%).
    • Lightness (%): Adjusts the brightness of the colors (from -100% to +100%).
  4. Enable Live Preview: Check the Live preview box at the bottom of the dialog window to see your adjustments in real-time on the canvas.
  5. Apply the Changes: Once you are satisfied with the result, click Apply and then Close.

Method 2: Using the Tweak Tool for Interactive Adjustments

If you prefer an organic, visual approach rather than numeric inputs, the Tweak tool allows you to paint color changes across multiple shapes.

  1. Select the Objects: Select the shapes you want to alter.
  2. Activate the Tweak Tool: Press W or click the Tweak tool icon in the left toolbar.
  3. Set the Mode to Color: In the top tool controls bar, locate the "Colors" section and choose one of the color modes, such as:
    • Paint the tool's color upon selected objects
    • Jitter colors
    • Change hue
  4. Paint Across Objects: Click and drag your cursor over the selected shapes to alter their colors interactively. Adjust the Width and Force settings in the top bar to control the strength and reach of the brush.

Important Considerations

  • Grouped Objects: The HSL Adjust extension works inside groups, but ungrouping complex hierarchies beforehand can sometimes prevent calculation errors.
  • Gradients and Patterns: The HSL Adjust extension primarily modifies solid fills and strokes. If your objects contain complex gradients, individual gradient stops may need to be adjusted manually or converted to solid paths before processing.
