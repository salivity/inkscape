Convert Grayscale Heightmaps to Contours in Inkscape

Converting a grayscale bitmap height field into stepped vector contours in Inkscape allows you to transform digital topographic or height data into physically stackable layers for laser cutting. This guide explains how to import your raster image, use Inkscape’s Trace Bitmap tool to extract discrete brightness steps, clean up the resulting vector paths, and format the lines specifically for laser cutting.

Step 1: Import and Prepare the Bitmap

  1. Open Inkscape and create a new document.
  2. Go to File > Import and select your grayscale height map image. Choose Embed to keep the image data inside the SVG file.
  3. Scale the image to your desired physical footprint by holding Ctrl and dragging a corner handle, or by entering specific dimensions in the toolbar at the top.
  4. If your image contains rough pixelation or digital noise, slightly blur it before tracing using Filters > Blurs > Blur, or pre-process it in an image editor. Smooth gradients produce cleaner vector paths.

Step 2: Extract Stepped Contours Using Trace Bitmap

  1. Select the imported image.
  2. Open the trace panel by navigating to Path > Trace Bitmap (or press Shift + Alt + B).
  3. In the Trace Bitmap panel, switch to the Multicolor tab.
  4. Under the detection mode dropdown, select Brightness steps.
  5. Set the Scans input to the number of physical layers you want to cut (for example, setting this to 10 generates 10 contour levels).
  6. Enable the Stack option. Stacking ensures each contour scan includes all higher elevations, producing solid, stackable plates rather than hollow rings.
  7. Uncheck Smooth to preserve crisp contour boundaries, or leave it checked if you prefer softer, organic curves.
  8. Click Apply. Inkscape will generate a grouped vector object placed directly on top of your bitmap.

Step 3: Ungroup and Organize the Layers

  1. Select the new vector graphic and ungroup it by pressing Ctrl + Shift + G (or go to Object > Ungroup).
  2. Delete the original bitmap image underneath to keep your file clean.
  3. Open the Layers and Objects panel (Object > Layers and Objects) to see the individual paths representing each height level.
  4. Move each layer horizontally to arrange them side-by-side on your canvas, ensuring they fit within the bed dimensions of your laser cutter and the boundaries of your raw material sheets.

Step 4: Clean and Simplify Paths

  1. Select an individual contour path.
  2. If the laser preview shows too many dense nodes, reduce them by selecting Path > Simplify (Ctrl + L).
  3. If there are unwanted micro-islands or specks generated from image noise, select the path, choose Path > Break Apart (Ctrl + Shift + K), deselect the main boundary, and delete the stray shapes. Recombine internal cutouts (such as depressions or lakes) by selecting the outer and inner paths and choosing Path > Combine (Ctrl + K).

Step 5: Format for the Laser Cutter

  1. Select all the generated vector contours.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. In the Fill tab, click the X (No paint) icon to remove all solid fills.
  4. In the Stroke paint tab, select Flat color and choose the color designated for cutting in your laser software (commonly pure red: #FF0000).
  5. In the Stroke style tab, set the stroke width to a hairline value required by most laser cutters, typically 0.001 inches or 0.025 mm.
  6. (Optional) Add registration holes through all layers by drawing a small circle (sized to match a wooden dowel or pin) in the same relative coordinate across all sheets to ensure precise alignment when gluing the cut layers together.
  7. Save your document as an Inkscape SVG or export it as a PDF/DXF according to your laser software requirements.
