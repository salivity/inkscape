Add aria-labelledby to SVG Icons in Inkscape

Attaching custom accessibility attributes like aria-labelledby to Scalable Vector Graphics (SVG) ensures screen readers and assistive devices accurately identify and announce your vector icons. While Inkscape is primarily a visual design tool, its built-in XML Editor allows you to directly manipulate the underlying markup. By creating an accessible <title> element with a unique ID and linking it via aria-labelledby to the root graphic or group, you can produce fully accessible vector icons ready for production web environments.

Step 1: Add a Title Element to the Icon

Screen readers rely on text descriptors to identify non-text content. Inkscape allows you to define this metadata via the document properties:

  1. Open your SVG icon in Inkscape.
  2. Go to File > Document Properties (or press Ctrl + Shift + D).
  3. Select the Metadata tab.
  4. Enter a descriptive, concise name in the Title field (for example, "Search Icon").
  5. Close the dialog. Inkscape will automatically generate a <title> tag inside the SVG code.

Step 2: Open the XML Editor

To inspect the generated tag and add the required ARIA attributes, access the code view:

  1. Go to Edit > XML Editor (or press Ctrl + Shift + X).
  2. The left panel shows the tree structure of your SVG document, starting with the root <svg:svg> node.

Step 3: Assign an ID to the Title

The aria-labelledby attribute works by pointing to the unique ID of the label element:

  1. In the XML tree, locate and click the <svg:title> node (usually found directly under the root <svg:svg> element).
  2. Look at the right panel to see the attributes of the <svg:title> tag.
  3. If an id attribute does not exist, type id into the Attribute name input field at the bottom right.
  4. In the Attribute value field, enter a unique identifier (such as search-icon-title).
  5. Click Set (or press Ctrl + Enter).

Step 4: Attach the aria-labelledby Attribute

Once the title has an ID, link it to the icon:

  1. In the XML tree, select the root <svg:svg> element (or the specific <svg:g> group representing your icon).
  2. In the right panel, enter aria-labelledby in the Attribute name field.
  3. In the Attribute value field, enter the exact ID assigned in Step 3 (e.g., search-icon-title).
  4. Click Set.

Step 5: Add role="img" for Broad Compatibility

Many web browsers and screen readers require a semantic role on SVG elements to treat them as accessible objects:

  1. Keep the root <svg:svg> element selected in the XML Editor.
  2. In the Attribute name field, type role.
  3. In the Attribute value field, type img.
  4. Click Set.

Step 6: Save as Plain SVG

To preserve your custom attributes while stripping out unnecessary editor-specific markup:

  1. Go to File > Save As....
  2. Set the file type dropdown to Plain SVG (*.svg) rather than Inkscape SVG.
  3. Click Save.

The output file will now contain clean, accessible markup featuring the role="img" and aria-labelledby attributes pointing cleanly to the accessible title inside the file.
