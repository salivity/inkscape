Create Extruded Isometric Text in Inkscape

This guide demonstrates how to manually design and extrude isometric 3D typography in Inkscape without relying on automated 3D extensions. By converting text to vector paths, applying precise isometric shear and rotation values, duplicating planes, and connecting geometric vertices with manual shading, you will achieve a clean, vector-based 3D isometric lettering effect.

1. Set Up and Convert Text to Paths

  1. Select the Text Tool (T) and type your desired text using a bold, geometric sans-serif typeface.
  2. Select the text object and convert it into vector outlines by going to Path > Object to Path (Shift + Ctrl + C).
  3. Ungroup the result by pressing Ctrl + Shift + G.
  4. Combine the letters into a single unified path by going to Path > Combine (Ctrl + K).

2. Apply Isometric Projection (SSR Method)

To project the flat 2D path into an isometric plane, use the Transform panel (Object > Transform or Shift + Ctrl + M).

For a Top-Facing Isometric Plane:

  • Scale Tab: Uncheck Scale proportionally, set the units to %, set Width to 100%, and set Height to 86.603%. Click Apply.
  • Skew Tab: Set horizontal skew angle to -30° (or vertical skew to 30° depending on orientation). Click Apply.
  • Rotate Tab: Set the rotation angle to 30° (counter-clockwise) and click Apply.

For a Left-Facing Isometric Plane:

  • Scale Tab: Set Height to 86.603%. Click Apply.
  • Skew Tab: Set vertical skew to 30°. Click Apply.
  • Rotate Tab: Set the rotation to -30°. Click Apply.

3. Duplicate and Position the Extrusion Base

  1. Select your transformed isometric text.
  2. Duplicate the path by pressing Ctrl + D.
  3. Hold Ctrl and drag the duplicated path downward along the vertical axis to define the depth of the extrusion.
  4. Send the bottom duplicate behind the original by pressing Page Down or End.

4. Construct the Extrusion Facets

  1. Enable snapping by clicking the Snap toggle in the top-right corner. Ensure Snap to paths and Snap to cusp nodes are enabled.
  2. Select the Draw Bezier Curves and Straight Lines Tool (B).
  3. Click on a corner node of the front text path, click the corresponding corner node on the back text path, follow the bottom edge to the next node, and close the path at the starting node.
  4. Repeat this process for all visible corners, curves, and edges to generate distinct polygon faces that bridge the front and back planes.

5. Apply Shading and Final Touches

  1. Select a global light source direction (for example, top-left).
  2. Assign the brightest color palette shade to the top-facing surface.
  3. Assign a mid-tone color to the front-facing surfaces.
  4. Assign the darkest shade to the side/underneath faces to create realistic depth.
  5. Select all created faces and the text paths, then remove any outline stroke via the Fill and Stroke panel (Object > Fill and Stroke or Shift + Ctrl + F) by setting Stroke paint to No paint.
