Modify Path Coordinates with Inkscape Python API

This article explains how to programmatically access and modify SVG path coordinates using Inkscape's official Python API, inkex. By reading the geometry of path elements, altering node positions, and writing the updated coordinates back to the document, you can automate complex vector transformations and procedural design workflows directly inside Inkscape extensions or standalone scripts.

Understanding the inkex Path Model

In modern Inkscape (version 1.0 and later), the inkex module represents path data (d attribute) using the inkex.Path and inkex.CubicSuperPath classes.

  • inkex.Path: A collection of individual SVG path commands (e.g., Move, Line, Curve, Arc).
  • inkex.CubicSuperPath: A normalized representation where every segment is represented as a cubic Bézier curve, making algorithmic coordinate manipulation more uniform.

Step 1: Setting Up the Extension Class

An Inkscape extension subclasses inkex.EffectExtension. It processes the selected elements or traverses the entire SVG DOM.

import inkex
from inkex import Path, Move, Line, Curve

class ModifyCoordinatesExtension(inkex.EffectExtension):
    def effect(self):
        # Target either user selection or all path elements
        elements = self.svg.selection.filter(inkex.PathElement) or self.svg.xpath('//svg:path')
        
        for elem in elements:
            self.modify_path_commands(elem)

if __name__ == '__main__':
    ModifyCoordinatesExtension().run()

Step 2: Modifying Direct Path Commands

To modify specific coordinate values directly, parse the element's path data, iterate over its commands, and update their properties.

def modify_path_commands(self, elem):
    # Parse the element's path definition
    path = elem.path.to_absolute()  # Convert relative commands (dx, dy) to absolute

    for command in path:
        # Check command types and adjust coordinates
        if isinstance(command, (Move, Line)):
            command.x += 10.0  # Shift X coordinate by 10 units
            command.y += 5.0   # Shift Y coordinate by 5 units
            
        elif isinstance(command, Curve):
            # Curves contain endpoint (x, y) and control points (x2, y2, x3, y3)
            command.x += 10.0
            command.y += 5.0
            command.x2 += 10.0
            command.y2 += 5.0
            command.x3 += 10.0
            command.y3 += 5.0

    # Assign modified path back to the element
    elem.path = path

Step 3: Modifying Coordinates via CubicSuperPath

For complex geometrical modifications where command types might vary, CubicSuperPath simplifies the path into subpaths of control points: [handle_in, node, handle_out].

def modify_with_superpath(self, elem):
    # Convert path to CubicSuperPath
    superpath = elem.path.to_superpath()

    for subpath in superpath:
        for point in subpath:
            # point[0] = handle in [x, y]
            # point[1] = main node [x, y]
            # point[2] = handle out [x, y]
            
            # Example: Scale all Y coordinates by 1.5
            point[0][1] *= 1.5
            point[1][1] *= 1.5
            point[2][1] *= 1.5

    # Convert the superpath back to an inkex.Path and assign
    elem.path = Path(superpath)

Step 4: Applying Matrix Transformations

If the coordinate modification is linear (translation, rotation, scaling), apply a transformation matrix directly rather than manually editing individual nodes:

from inkex.transforms import Transform

def apply_matrix_transform(self, elem):
    # Create transformation: translate by (20, 30) and rotate 45 degrees
    mat = Transform(translate=(20, 30), rotate=45)
    
    # Apply transformation directly to path geometry
    elem.path = elem.path.transform(mat)

Summary Checklist

  1. Call elem.path.to_absolute() to eliminate relative coordinate calculation errors.
  2. Use command-level iteration (inkex.Path) for simple node shifting.
  3. Use inkex.CubicSuperPath for standardized Bézier curve manipulation.
  4. Reassign the result back to elem.path to automatically update the SVG DOM.
