Packaging Inkscape Extensions for Extension Manager

This guide covers the exact process for packaging, configuring, and publishing an Inkscape extension so users can seamlessly discover and install it using the built-in Extension Manager. You will learn the required file structure, how to configure the extension description file, how to wrap your code into a distributable Python package, and how to publish it to the Inkscape Gallery.

1. Prepare the Core Extension Files

Every Inkscape extension consists of at least two essential files: an implementation script (typically Python) and an INX file (XML) that tells Inkscape how to display the tool in its menu system.

  • Execution Script (my_extension.py): The logic for your tool. It should inherit from inkex.EffectExtension or another relevant base class from the standard inkex library.
  • Definition File (my_extension.inx): Defines the extension metadata, menu location, inputs, and the interpreter target.

Ensure your .inx file includes a unique <id> tag formatted in reverse-domain notation:

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>My Custom Extension</name>
    <id>org.example.inkscape.my_extension</id>
    <effect>
        <effects-menu>
            <submenu name="Render"/>
        </effects-menu>
    </effect>
    <script>
        <command location="inx" interpreter="python">my_extension.py</command>
    </script>
</inkscape-extension>

2. Configure Python Packaging

The Inkscape Extension Manager uses standard Python packaging tools to install and update extensions. You must wrap your code using standard Python build configuration, such as a pyproject.toml file at the root of your project directory.

Create a pyproject.toml file with the following minimum configuration:

[build-system]
requires = ["setuptools>=61.0"]
build-backend = "setuptools.build_meta"

[project]
name = "inkscape-my-extension"
version = "1.0.0"
authors = [
  { name="Your Name", email="you@example.com" },
]
description = "A short description of what your extension does."
readme = "README.md"
requires-python = ">=3.8"
dependencies = [
    "inkex>=1.2",
]

[tool.setuptools.package-data]
"*" = ["*.inx"]

Ensure your .inx files and any non-Python assets (like icons or templates) are explicitly included using package-data so they are not omitted during the build.

3. Build the Wheel Distribution

Inkscape's package manager installs extensions using standard Python wheel (.whl) archives. Build your wheel using Python's standard build module.

Run the following commands in your terminal:

pip install --upgrade build
python -m build

This generates a .whl and a .tar.gz file inside the dist/ directory. The .whl file contains the executable script, definition file, and metadata required by Inkscape.

4. Publish to the Inkscape Gallery

The Inkscape Extension Manager fetches installable tools directly from the official Inkscape community gallery. To make your package available in the manager:

  1. Go to the official Inkscape Website and log in to your account.
  2. Navigate to Community > Gallery.
  3. Select Extensions from the category list and click Upload.
  4. Fill out the extension details:
    • Title: The display name for your extension.
    • Category: Choose the appropriate functional category.
    • Release Version: Match the version string in your pyproject.toml.
  5. Upload the compiled .whl file generated in the previous step to the file attachment field.
  6. Provide a link to your source repository (e.g., GitHub or GitLab) for automated review and issue tracking.
  7. Save and submit your gallery item.

5. Verify the Installation

Once the gallery item is reviewed and published, it is indexed by Inkscape's extension index:

  1. Open Inkscape.
  2. Navigate to Extensions > Manage Extensions... (or launch it from preferences).
  3. Search for your extension by name or ID.
  4. Click Install.
  5. Restart Inkscape and verify that the extension appears under the menu path defined in your .inx file.
