How to Import Specific PDF Pages in Inkscape

Inkscape allows you to import and edit vector content from multi-page PDF documents with precision. While Inkscape handles vector elements natively, opening a PDF requires selecting your target page and configuring import settings to preserve fonts, layers, and layout accurately. This guide explains how to select specific pages during import, how to handle multiple pages within a single project, and how to choose the right rendering settings for your workflow.

Step-by-Step: Importing a Specific PDF Page

  1. Open the File Menu

    • Launch Inkscape.
    • Go to File > Open (to open the PDF as a new document) or File > Import (to insert the page into an existing document).
    • Navigate to your multi-page PDF file, select it, and click Open.

  2. Select the Page Number

    • The PDF Import Settings dialog window will appear.
    • At the top of the dialog, locate the preview area and the Page selection field.
    • Enter the specific page number you wish to import, or use the arrow buttons to navigate through the pages.

  3. Configure Text and Rendering Settings

    • Internal Import vs. Poppler/Cairo:
      • Internal import: Converts text to editable Inkscape text objects and retains vector paths, though complex fonts may shift.
      • Poppler/Cairo: Renders text closer to the original appearance (often converting text to paths), ideal for preserving exact layouts and unsupported fonts.
    • Font Handling: Check "Substitute missing fonts" if you want Inkscape to replace unavailable fonts automatically.

  4. Complete the Import

    • Set your precision settings (clip to Page, Media Box, Crop Box, etc.) as needed.
    • Click OK. The chosen page will load directly onto the canvas.

How to Work with Multiple Pages from the Same PDF

Inkscape supports multi-page documents (version 1.2 and later). To assemble multiple distinct pages from a PDF into one Inkscape file:

  1. Import your first page using File > Open.
  2. Select the Create and Edit Document Pages tool from the left toolbar (or press Shift + X).
  3. Click Create a new page in the top toolbar to add a blank page to your canvas.
  4. Go to File > Import, select the same PDF file, and choose the next page number from the import dialog.
  5. Position the newly imported vector graphics onto the corresponding page on your canvas.
  6. Repeat the process for any additional pages you need to include.
