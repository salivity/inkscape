How to Make Proportional Bubble Maps in Inkscape

This guide explains how to generate proportional symbol bubble maps based on numerical data using Inkscape. By calculating proportional radii derived from your dataset, importing or drawing a base vector map, utilizing Inkscape's precision sizing tools, and arranging layers, you can create visually accurate thematic maps where the area of each circle accurately represents its underlying quantitative value.

1. Prepare Your Data and Calculate Circle Sizes

In proportional symbol mapping, the area of the circle—not the radius—must scale proportionally with the data value (\(Area \propto Value\)). Scaling by radius directly will exaggerate differences and distort perception.

  1. Open your dataset in a spreadsheet program (such as Excel or LibreOffice Calc).
  2. Calculate the square root of each data value using the formula =SQRT(cell).
  3. Determine a scaling factor (\(k\)) that keeps your symbols within a readable size range on your map (for example, multiplying the square root by 2 or 5 depending on map canvas size).
  4. Compute the diameter or radius for each point: \(\text{Size} = k \times \sqrt{\text{Value}}\).

2. Import and Set Up the Vector Base Map

  1. Launch Inkscape and set up your document properties (File > Document Properties) to match your desired canvas dimensions.
  2. Import an SVG vector base map of your target region (File > Import).
  3. Lock the base map layer in the Layers and Objects panel (Layer > Layers and Objects) to prevent accidental modifications while placing symbols.
  4. Create a new layer named "Bubbles" above the base map layer.

3. Draw and Size the Symbol Bubbles

  1. Select the Circles and Ellipses tool (shortcut: E).
  2. Hold Ctrl while dragging on the canvas to draw a perfect circle.
  3. Open the Fill and Stroke panel (Object > Fill and Stroke). Set a fill color, assign an opacity of 50% to 70% to ensure overlapping bubbles remain legible, and add a thin, darker stroke outline for contrast.
  4. Select the circle and open the Transform panel (Object > Transform) under the Scale tab, or use the width (\(W\)) and height (\(H\)) fields in the top toolbar. Ensure the units are set to millimeters (mm) or pixels (px) and the lock icon is enabled to maintain the 1:1 aspect ratio.
  5. Enter the calculated diameter for each corresponding data point. Repeat this process by duplicating the circle (Ctrl + D) and resizing it for each entry in your dataset.

4. Position and Order the Bubbles

  1. Use the Select and Transform Objects tool (shortcut: S) to drag each circle to its appropriate geographic coordinate (such as the centroid of a region or specific city point).
  2. To align precisely with known points, enable Snapping from the top right toolbar to snap object centers to path nodes.
  3. Sort overlapping symbols: larger bubbles must be placed behind smaller bubbles. Select the larger overlapping bubbles and press Page Down or End to lower them beneath the smaller markers.

5. Build the Map Legend

  1. Create three or four reference circles representing low, medium, and high values from your dataset using the exact same scaling formula.
  2. Align the legend circles either vertically stacked by their bottom edges using the Align and Distribute panel (Object > Align and Distribute) or nested concentrically.
  3. Use the Text tool (shortcut: T) to label each reference circle with its corresponding numerical value.
