How to Align and Distribute Nodes in Inkscape

This guide explains how to arrange, align, and evenly distribute individual nodes within a single path using Inkscape's built-in tools. While the Align and Distribute panel is most commonly used for separate objects, it dynamically adapts to handle node-level adjustments when working in node editing mode. Following the steps below will allow you to precisely align nodes horizontally or vertically and distribute the spacing between them evenly.

Step 1: Open the Align and Distribute Panel

Open the tool palette by navigating to Object > Align and Distribute from the top menu, or press the shortcut Shift + Ctrl + A (or Shift + Cmd + A on macOS). Keep this panel open on your screen.

Step 2: Switch to the Node Tool

Select the Node Tool from the left-hand toolbar, or press N on your keyboard (alternatively, press F2). Click directly on the path containing the nodes you wish to adjust so that the path becomes active and its nodes are visible.

Step 3: Select the Target Nodes

Choose the specific nodes within the path you want to arrange:

  • Box Select: Click and drag a marquee box over the nodes you want to modify.
  • Multi-Select: Hold down Shift and click each node individually.

You must select at least two nodes to align them, and at least three nodes to distribute spacing between them.

Step 4: Use Node Alignment and Distribution Controls

Once multiple nodes are selected with the Node tool active, the Align and Distribute panel automatically switches to display node-specific operations under the Nodes section.

Aligning Nodes

  • Align horizontally: Click the Align selected nodes horizontally icon to pull all selected nodes onto a single horizontal line (matching their average Y-coordinate).
  • Align vertically: Click the Align selected nodes vertically icon to line up all selected nodes along a single vertical line (matching their average X-coordinate).

Distributing Nodes

  • Distribute horizontally: Click the Distribute selected nodes horizontally icon to make the horizontal gaps between each node equal.
  • Distribute vertically: Click the Distribute selected nodes vertically icon to make the vertical gaps between each node equal.

Once selected, Inkscape instantly rearranges the nodes along your path while preserving the rest of the vector geometry.
