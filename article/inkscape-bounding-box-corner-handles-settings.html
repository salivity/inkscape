Inkscape Bounding Box Corner Handles Settings

In Inkscape, the display and behavior of bounding box corner handles depend on whether you are transforming full objects or individual path nodes. The primary controls governing these handles are the Show transform handles for selected nodes toggle on the Node Tool Controls bar, the Selector tool bounding box mode (Visual vs. Geometric) located in Preferences, and the general handle size settings under Interface preferences.

1. Node Tool: Transform Handles Toggle

When editing paths with the Node Tool (N or F2), bounding box handles do not appear by default around multiple selected nodes. You can enable or disable them using the control bar:

  1. Select the Node Tool from the left-hand toolbar.
  2. Select two or more nodes on a path.
  3. Locate the Tool Controls Bar across the top of the workspace.
  4. Click the Show transform handles for selected nodes icon (represented by an icon with four corner arrows around a dashed square).

When active, a bounding box with corner scale and rotation handles appears around the selected nodes, allowing you to scale or skew them directly.

2. Selector Tool: Visual vs. Geometric Bounding Box

When using the Select and Transform Objects tool (S or F1), corner handles are visible by default whenever an object is selected. However, the precise placement of these corner handles is controlled by the bounding box calculation method:

  1. Go to Edit > Preferences (or press Ctrl + Shift + P / Cmd + Shift + P).
  2. In the left panel, expand Tools and select Selector.
  3. Under Bounding box to use, choose between:
    • Visual bounding box: Places corner handles along the outside edge of the object, taking stroke width, markers, and blur into account.
    • Geometric bounding box: Places corner handles strictly along the path’s true geometric nodes, ignoring stroke thickness.

3. Handle Scaling and Rotation Modes

For standard object selections, clicking an object once displays double-sided corner arrows for proportional or directional scaling. Clicking the object a second time toggles the corner handles into curved arrows, which control rotation and skewing around a central rotation point.

4. Adjusting Handle Visibility and Size

If corner handles appear too small or difficult to grab:

  1. Open Edit > Preferences.
  2. Select Interface.
  3. Adjust the Handle size slider to increase or decrease the pixel size of canvas handles across all tools.
