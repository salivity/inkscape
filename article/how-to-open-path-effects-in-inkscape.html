How to Open Path Effects in Inkscape

The Path Effects dialog in Inkscape provides access to Live Path Effects (LPE), which allow you to apply non-destructive modifiers and dynamic transformations to your vector artwork. This guide explains the exact steps, keyboard shortcuts, and prerequisite requirements needed to open and use the Path Effects panel in Inkscape quickly.

Method 1: Using the Top Menu

  1. Open your project in Inkscape.
  2. Click on Path in the top menu bar.
  3. Select Path Effects... from the drop-down menu.
  4. The Path Effects panel will dock automatically on the right side of the workspace (or open as a floating window depending on your preferences).

Method 2: Using the Keyboard Shortcut

You can open the panel instantly using the default keyboard shortcut:

  • Windows / Linux: Press Ctrl + & (or Ctrl + Shift + 7 on standard US keyboards).
  • macOS: Press Cmd + & (or Cmd + Shift + 7).

How to Use the Path Effects Panel

Once the panel is visible, follow these steps to apply an effect:

  1. Use the Select Tool (S or F1) to click on the vector path you want to modify.
  2. In the Path Effects panel, click the + (Add Path Effect) button.
  3. Browse the Live Path Effects selector dialog or search for the specific effect you need (such as Corners (Fillet/Chamfer), Power Stroke, or Mirror Symmetry).
  4. Double-click the effect or select it and click Add to apply it to your path.

Troubleshooting: Effect Options are Grayed Out

If the + icon in the Path Effects dialog is grayed out, your selected item is not currently a path. Regular shapes (rectangles, circles, stars) and text must first be converted into paths. Select the object, go to the top menu, and choose Path > Object to Path (or press Shift + Ctrl + C) before applying a path effect.
