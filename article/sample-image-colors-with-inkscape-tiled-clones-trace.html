Sample Image Colors with Inkscape Tiled Clones Trace

This guide explains how to use the Trace tab within Inkscape's Create Tiled Clones tool to sample colors from an underlying image. By mapping a source image to a grid of vector shapes, you can easily generate pixelated graphics, vector mosaics, and halftone color effects.

1. Import and Position Your Image

Place the target image (bitmap or vector) onto your canvas. This image acts as the color source that the clones will sample. Ensure the image is positioned directly beneath where you plan to generate your clones.

2. Create the Source Shape

Draw the single vector shape that will be repeated across the grid, such as a small circle or square. Position this shape over the top-left corner of the underlying image.

3. Unset the Fill Color of the Source Shape

For clones to take on sampled colors, the original object must not have a fixed fill color:

  1. Select the shape you just created.
  2. Open the Fill and Stroke panel (Shift + Ctrl + F).
  3. Under the Fill tab, click the Unset paint icon (the question mark ?). The shape will appear black or transparent, allowing the clone engine to dynamically assign color values to each clone.

4. Open the Tiled Clones Tool

With the source shape selected, navigate to the menu and choose Edit > Clone > Create Tiled Clones... to open the tool panel.

5. Set Grid Dimensions

In the Create Tiled Clones dialog:

  1. Go to the Symmetry tab and keep the default P1: simple translation.
  2. At the bottom of the dialog, set the grid size by defining the number of Rows and Columns needed to cover the area of the background image.

6. Configure the Trace Tab

Switch to the Trace tab inside the dialog and apply the following settings:

  1. Check the box labeled Trace the background under the clones.
  2. Under 1. Specify what to pick, select Color.
  3. Under 2. Apply the value to the clones', check the Color option.
  4. Under 3. Make the picked value determine the clones', you can leave the options unchecked unless you also want to vary size, opacity, or rotation based on brightness.

7. Generate the Clones

Click the Create button at the bottom of the dialog. Inkscape will read the color values of the image directly beneath each grid point and generate a cloned pattern matching the source image's colors. If the layout is misaligned, click Remove, adjust your rows, columns, or shape spacing, and click Create again.
