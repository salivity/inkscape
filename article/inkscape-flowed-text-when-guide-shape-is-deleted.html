Inkscape Flowed Text When Guide Shape Is Deleted

In Inkscape, flowing text into a shape binds the text's formatting and boundaries directly to that object's vector path. When you delete the original guide shape from the canvas, the text object is not deleted, but it loses its formatting container. This causes the text to either disappear visually from the canvas or revert to a broken reference state, even though the text data remains intact inside the document's structure.

The Broken Reference Problem

When you use the Text > Flow into Frame command, Inkscape creates an internal link referencing the unique ID of the guide shape. The text uses this path to determine line breaks, padding, and visible boundaries.

If you select and delete the guide shape with the Delete or Backspace key:

  • The text becomes invisible on the canvas: Because the text relies on the shape's geometry to render its layout, losing the shape leaves the text with zero defined area. As a result, it vanishes from the visual workspace.
  • The text element remains in the file: The actual text string is not erased. If you open the Objects panel (Ctrl + Shift + O) or the XML Editor (Ctrl + Shift + X), you will still see the text element present in the layer hierarchy.
  • SVG rendering errors may occur: In exported SVG files or non-Inkscape viewers, the orphaned text block may either fail to display or render as an unpredictable, unformatted single line of text at coordinate (0,0).

How to Recover or Prevent Hidden Text

If you accidentally delete the guide shape, you can restore or normalize your text using several straightforward methods:

  1. Undo the Deletion: Press Ctrl + Z immediately to restore the guide shape and re-establish the visual flow.
  2. Unflow Before Deleting: To safely remove a frame without losing your text, select the flowed text and choose Text > Unflow (Alt + W). This detaches the text from the shape and converts it into a standard regular text object placed at the top-left of where the frame was. You can then delete the shape without issue.
  3. Select via Objects Panel: If the shape is already gone and you cannot undo, locate the invisible text object in the Objects panel. Select it, create a new shape on the canvas, select both, and choose Text > Flow into Frame to re-link the orphaned text to the new path. Alternatively, run Text > Unflow on the selected invisible object to force it to render as regular text again.
