Designing Gatefold Brochures in Inkscape

Designing a gatefold brochure requires precise measurements to ensure panels fold flat without buckling, a process known as panel compensation. This guide walks through calculating panel widths, configuring multi-page documents in Inkscape, establishing accurate fold guides, and preparing print-ready files.

1. Calculate Panel Compensation

A standard closed gatefold features two outer panels that fold inward to meet in the center, and then the entire sheet folds in half. Because paper has physical thickness, panels that tuck inside must be slightly narrower than the outer panels.

For a standard 8-panel double gatefold (four panels per side):

  • Outer Panels: Standard width (e.g., 8.5 inches / 4 = 2.125" base).
  • Tuck-in Panels: Subtract 1/16 inch to 1/8 inch (1.5 mm to 3 mm) from the folding width.
  • Cover Panels: Add the subtracted amount to the exterior panels so the total sheet width remains standard.

Example using an 8.5" x 14" flat sheet (Double Gatefold):

  • Panel 1 (Left Tuck): 3.4375" (Narrow)
  • Panel 2 (Left Center): 3.5625" (Wide)
  • Panel 3 (Right Center): 3.5625" (Wide)
  • Panel 4 (Right Tuck): 3.4375" (Narrow)
  • Total Width: 14.0"

2. Set Up the Multi-Page Document

Inkscape natively supports multi-page layouts, allowing you to design the outer spread and inner spread within the same file.

  1. Open File > Document Properties (Shift + Ctrl + D).
  2. Set your display units to Inches or Millimeters.
  3. Set the flat unfolded size (e.g., Width: 14 in, Height: 8.5 in).
  4. Select the Create and Edit Pages tool from the toolbar (or press Shift + P).
  5. Click Create a new page in the top tool control bar. Inkscape will generate a second page of identical dimensions directly adjacent to the first.
    • Page 1 represents the Outside Spread.
    • Page 2 represents the Inside Spread.

3. Establish Guides for Panel Folds

Because the interior and exterior spreads mirror each other, your fold lines must be placed accordingly.

Outside Spread (Page 1)

Working from left to right:

  1. Double-click the left ruler to create a vertical guide.
  2. Set the position for the first fold at 3.4375" (Left Tuck panel).
  3. Place the second guide at 7.0" (Center fold: 3.4375" + 3.5625").
  4. Place the third guide at 10.5625" (7.0" + 3.5625").

Inside Spread (Page 2)

The orientation is mirrored when viewing the inside of the sheet:

  1. Place the first fold at 3.4375" (Right Tuck when folded, now on the left).
  2. Place the second guide at 7.0" (Center fold).
  3. Place the third guide at 10.5625".

4. Create Safe Margins and Bleeds

Artwork extending to the edge of the sheet requires a bleed allowance (typically 0.125 inches or 3 mm).

  1. In Document Properties, define a bleed margin of 0.125 in (or 3 mm) on all sides.
  2. On a dedicated locked layer, draw guide rectangles inside each panel to serve as a Safe Zone (at least 0.125 inches inside every fold line and trim edge). This prevents critical text or logos from landing directly on a crease.

5. Layout and Panel Content

Group panel elements logically to avoid layout confusion across the folds:

  • Page 1 (Exterior):
    • Left: Inside Left Flap (folds inward)
    • Middle-Left: Back Cover
    • Middle-Right: Front Cover
    • Right: Inside Right Flap (folds inward)
  • Page 2 (Interior):
    • Panels 1–4 read continuously from left to right as an expansive four-panel spread when the brochure is fully opened.

Use Inkscape's Layers and Objects panel (Shift + Ctrl + L) to separate background artwork, panel guides, and typography for both pages.

6. Export for Professional Printing

  1. Ensure all live text is either converted to paths (Path > Object to Path) or that all used fonts are embedded.
  2. Go to File > Save As... and select Portable Document Format (*.pdf).
  3. In the PDF export dialogue:
    • Select Include bleed margins.
    • Choose PDF version 1.5 or higher.
    • Set resolution to 300 dpi for rasterized effects.
    • Ensure Output page size is set to include all pages in the document.
