How to Build Inkscape with CMake and Ninja

Building and testing development branches of Inkscape allows developers and contributors to test cutting-edge features, debug issues, and verify changes before they are merged. This guide provides a straightforward process for cloning the source code, selecting a target development branch, configuring the build using CMake with the Ninja generator, compiling the application, and running the automated test suite.

1. Install Build Tools and Dependencies

Before compiling Inkscape, install the required toolchain: Git, a modern C++ compiler (GCC or Clang), CMake (version 3.12 or newer), and Ninja.

On Debian/Ubuntu-based systems, install the core tools and dependencies by running:

sudo apt update
sudo apt install git cmake ninja-build build-essential
sudo apt build-dep inkscape

On Fedora:

sudo dnf install git cmake ninja-build gcc-c++
sudo dnf builddep inkscape

On macOS or Windows, install dependencies using Homebrew or MSYS2 respectively, following Inkscape's platform-specific dependency guidelines.

2. Clone the Repository and Select a Branch

Clone the official Inkscape repository along with its submodules:

git clone --recurse-submodules https://gitlab.com/inkscape/inkscape.git
cd inkscape

List available remote branches and checkout the development branch you want to test:

git branch -r
git checkout <branch-name>
git submodule update --init --recursive

3. Configure the Build with CMake and Ninja

Create a dedicated build directory outside the source tree and generate the Ninja build files using CMake. Specifying Debug or RelWithDebInfo is recommended for development and testing:

cmake -B build -S . -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo

To enable faster testing cycles or disable specific optional dependencies, pass additional flags to CMake (e.g., -DBUILD_TESTING=ON to ensure the test suite is configured).

4. Compile the Source Code

Execute the build using Ninja:

ninja -C build

Alternatively, use the universal CMake command:

cmake --build build

Ninja will automatically utilize all available CPU cores to compile Inkscape efficiently.

5. Run Inkscape

Once compilation completes successfully, launch the newly built development binary directly from the build directory:

./build/bin/inkscape

6. Run the Test Suite

Inkscape includes unit and rendering tests to verify code stability. Run the automated tests using Ninja or CTest:

ninja -C build check

Or run tests directly with CTest for detailed output upon failure:

ctest --test-dir build --output-on-failure
