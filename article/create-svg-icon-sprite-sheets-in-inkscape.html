Create SVG Icon Sprite Sheets in Inkscape

Generating an SVG sprite sheet in Inkscape allows you to consolidate dozens of individual UI icons into a single, lightweight vector file for web and application design. This guide covers how to set up a unified grid canvas, prepare and normalize icon paths, organize icons into a structured layout or symbol library, assign predictable element IDs, and export a clean, production-ready SVG sprite sheet.

1. Canvas and Grid Setup

  1. Open Inkscape and create a new document (Ctrl + N).
  2. Open Document Properties (Shift + Ctrl + D).
  3. Under the Page tab, set the Display units to px.
  4. Define your custom canvas size based on the number of icons. For instance, if you have 40 icons sized at 24×24 px, a grid of 8 columns by 5 rows requires a canvas size of 192×120 px.
  5. Go to the Grids tab, click New (Rectangular grid), and set:
    • Grid units: px
    • Spacing X: 24 (or your preferred base icon size)
    • Spacing Y: 24
  6. Enable Snapping on the top/right toolbar and turn on Snap to Grids.

2. Prepare and Normalize the Icons

To ensure consistency across the entire sprite sheet:

  1. Standardize Viewports: Keep all icons bounded within their individual grid cells (e.g., 24×24 px).
  2. Convert Strokes to Paths: Select all stroked objects and choose Path > Stroke to Path (Ctrl + Alt + C). This prevents line weights from scaling inconsistently.
  3. Combine Shapes: Select compound elements of a single icon and choose Path > Union (Ctrl + +) to minimize unnecessary layers and groups.
  4. Remove Fills: If icons are meant to be styled dynamically with CSS currentColor, remove hardcoded fill and stroke colors, or set them to a single uniform color.

3. Arrange Icons on the Grid

  1. Place each icon inside its dedicated grid cell.
  2. Open the Align and Distribute panel (Shift + Ctrl + A).
  3. Use the grid snapping feature or the Rearrange tools to evenly distribute your icons in a neat rows-and-columns layout.
  4. Keep adequate spacing or precise boundary alignment to avoid bleed when rendering sprites via CSS background positions.

4. Assign IDs for CSS or SVG <use> Referencing

If you plan to reference icons using the SVG <use> tag (e.g., <svg><use href="sprite.svg#icon-user"></use></svg>), assign semantic IDs to each icon group:

  1. Select an individual icon.
  2. Group it (Ctrl + G).
  3. Open the Object Properties panel (Shift + Ctrl + O).
  4. Set a unique, human-readable name in the ID field (e.g., icon-home, icon-settings, icon-search).
  5. Click Set.
  6. Repeat this process for each icon on the canvas.

5. Alternative: Converting to SVG Symbols

Inkscape provides a native Symbol definition workflow:

  1. Open Object > Symbols (Shift + Ctrl + Y).
  2. Select an icon group on your canvas.
  3. In the Symbols panel, click Add Symbol from current document.
  4. This adds a <symbol> wrapper with a specific id, making the output inherently structured for modern SVG sprite usage without requiring visual grid alignment.

6. Clean and Export the Sprite Sheet

  1. Go to File > Clean Up Document to purge unused gradients, metadata, and empty definitions.
  2. Click File > Save As... (Shift + Ctrl + S).
  3. In the file type dropdown, select Optimized SVG (*.svg).
  4. In the optimization dialog:
    • Enable Convert styles to XML attributes.
    • Enable Remove unused IDs.
    • Disable Shorten color values if you require explicit color values.
    • Keep Format with indenting checked for readable source code.
  5. Click OK to generate the final SVG sprite file.
