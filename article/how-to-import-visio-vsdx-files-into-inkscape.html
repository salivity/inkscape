How to Import Visio VSDX Files into Inkscape

This guide explains how to open and edit Microsoft Visio (.vsdx) files directly within Inkscape. Thanks to Inkscape's built-in support powered by the libvisio library, you can seamlessly import proprietary Visio vector diagrams, convert them into native Scalable Vector Graphics (SVG), and edit individual paths, text elements, and shapes without requiring Microsoft Office.

Method 1: Direct Import via Inkscape

Inkscape natively supports reading .vsdx and older .vsd files. Follow these steps to open your diagram directly:

  1. Launch Inkscape.
  2. Click on File in the top menu and select Open (to open as a new document) or Import (to add the diagram into your current canvas).
  3. In the file browser dialog, navigate to the folder containing your Visio file.
  4. Set the file format dropdown menu to All Files or Microsoft Visio Diagram (*.vsd, *.vsdx).
  5. Select your .vsdx file and click Open.
  6. If the document contains multiple pages, Inkscape will prompt you to select the specific page you want to import. Choose your desired page and click OK.

Once loaded, the Visio diagram is converted into Inkscape vector objects, ready for editing.

Method 2: Export as SVG from Microsoft Visio

If you have access to Microsoft Visio and want the highest fidelity with minimal font or rendering discrepancies, export the file directly to SVG:

  1. Open the diagram in Microsoft Visio.
  2. Go to File > Save As.
  3. Choose your destination folder.
  4. In the Save as type dropdown menu, select Scalable Vector Graphics (*.svg).
  5. Click Save.
  6. Open the newly created .svg file directly in Inkscape.

Method 3: Convert via PDF (Fallback Method)

If a .vsdx file fails to import correctly due to unsupported proprietary formatting, converting it through a PDF provides an exact visual match:

  1. In Microsoft Visio (or a free online Visio viewer), save or print the diagram as a PDF.
  2. Open Inkscape and navigate to File > Open.
  3. Select the exported PDF file.
  4. In the PDF Import Settings dialog, select Poppler/Cairo import for precise visual rendering or Internal import to keep text editable.
  5. Click OK.

Working with Imported Visio Elements

After importing your .vsdx file into Inkscape, use these tips to edit the diagram effectively:

  • Ungroup Elements: Visio diagrams often import as deeply nested groups. Select the imported graphic and press Ctrl + Shift + G (or Cmd + Shift + G on macOS) repeatedly to separate connectors, text blocks, and shapes.
  • Resolve Missing Fonts: If Visio used proprietary Microsoft fonts (such as Calibri or Segoe UI) that are missing from your operating system, select the text fields and assign installed system fonts using the Text and Font tool (Ctrl + Shift + T).
  • Clean Up Shapes: Visio connectors and dynamic shapes may import as combined paths. Use Path > Break Apart or the Node Tool (N) to modify individual path nodes.
