How to Use Mirror Symmetry in Inkscape

Inkscape’s Mirror Symmetry Live Path Effect (LPE) allows vector artists and designers to create perfectly balanced illustrations in real time by reflecting drawn paths across a customizable axis. This guide provides a direct, step-by-step walkthrough on how to enable, configure, and manipulate the Mirror Symmetry effect to streamline your vector workflow.

Step 1: Draw an Initial Path

  1. Select the Draw Freehand Lines tool (P) or the Draw Bezier Curves and Straight Lines tool (B).
  2. Draw half of the object you want to create (such as half of a face, shield, or butterfly wing) on your canvas.

Step 2: Open the Path Effects Panel

  1. With your path selected, open the top menu.
  2. Navigate to Path > Path Effects to open the Path Effects dialog panel on the right side of your workspace.

Step 3: Apply the Mirror Symmetry Effect

  1. In the Path Effects panel, click the + (Add Path Effect) button.
  2. Locate and select Mirror symmetry from the effect library (you can use the search bar to find it quickly).
  3. Inkscape will immediately mirror your path across a default vertical axis.

Step 4: Adjust the Symmetry Axis and Settings

In the Path Effects settings panel, you can customize how the reflection behaves:

  • Mode: Choose the orientation of the mirror line:
    • Free reflection: Lets you freely move and rotate the mirror axis.
    • X-axis / Y-axis: Locks the axis vertically or horizontally relative to the bounding box.
  • Discard shifted paths: Removes overlapping segments if needed.
  • Fuse paths: Automatically joins endpoints that meet along the symmetry line, creating a single closed shape.

Step 5: Edit the Shape in Real Time

  1. Switch to the Edit paths by nodes tool (N).
  2. Manipulate the nodes and control handles on the original half of your drawing. The mirrored half will instantly update to match.
  3. To adjust the mirror line itself, look for the two guide handles connected by a thin line on the canvas. Drag these handles to change the position or angle of the reflection line.

Step 6: Finalize and Convert the Shape (Optional)

If you want to convert your dynamic symmetry into a standard, permanently editable vector path:

  1. Select the object.
  2. Go to Path > Object to Path (Shift + Ctrl + C).
  3. This applies the effect permanently and converts both halves into a single, unified vector object.
