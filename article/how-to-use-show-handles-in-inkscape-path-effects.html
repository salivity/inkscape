How to Use Show Handles in Inkscape Path Effects

The "Show Handles" feature in Inkscape’s Path Effects dialog allows you to manipulate Live Path Effect (LPE) parameters visually on the canvas instead of manually entering numeric values. This guide explains how to locate this button within the dialog, activate the corresponding handles, and use the Node tool to intuitively adjust your vector shapes directly in your workspace.

1. Open the Path Effects Dialog

Select your vector object and open the Path Effects panel by navigating to Path > Path Effects from the top menu, or by pressing Ctrl + & (or Cmd + & on macOS). Apply any effect that relies on visual guides, such as Bend, Lattice Deform, Power Stroke, or Corners (Fillet/Chamfer).

2. Locate the "Show Handles" Button

Inside the Path Effects panel, locate the specific effect you want to edit. Many parameters—such as control paths, center points, or offset limits—have a small button next to their input fields. This icon typically resembles a node, a node path, or an editing pencil (often labeled as "Edit on-canvas" or "Show Handles"). Click this button to target that specific parameter for on-canvas editing.

3. Switch to the Node Tool

To see and manipulate the handles on your canvas, activate the Node Tool by pressing N or selecting it from the left-hand toolbar. Once active, Inkscape draws dedicated control lines, guide nodes, or interactive handles directly over or adjacent to your selected object.

4. Adjust the Effect on the Canvas

Click and drag the displayed handles:

  • For effects like Bend, you will see an editable path line passing through your shape; dragging its nodes or segments bends the shape accordingly.
  • For Power Stroke, you will see purple diamond-shaped handles that adjust the stroke width at specific points.
  • For Corners, dragging the circular handles dynamically adjusts the radius of individual corners.

5. Troubleshooting Handle Visibility

If the handles do not appear after clicking the button, verify that your object is currently selected and that the Node tool is active. Additionally, check the Node tool's control bar at the top of the screen to ensure that the "Show temporary path effect handles" toggle is enabled.
