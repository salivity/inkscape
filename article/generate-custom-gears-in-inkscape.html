Generate Custom Gears in Inkscape

Inkscape features a built-in tool that allows you to generate precise, mathematically accurate 2D gear wheels directly on your canvas. By using the Gears extension located in the Render menu, you can specify exact tooth counts, pitch, and pressure angles to create individual components or interlocking gear trains. This guide provides a step-by-step walkthrough for locating the tool, configuring the parameters for specific tooth numbers, and ensuring proper meshing between multiple gears.

Accessing the Gears Tool

  1. Open Inkscape and create a new document.
  2. In the top menu bar, navigate to Extensions > Render > Gear > Gear....
  3. A dialog window will appear with several customizable input fields.

Configuring Tooth Count and Parameters

To create a gear with a specific tooth count, adjust the settings in the dialog box:

  • Number of teeth: Enter the exact integer value for the number of teeth you require. This setting directly controls the tooth count.
  • Circular pitch (px): This determines the distance between individual teeth along the pitch circle. Larger numbers produce larger teeth and a larger overall gear diameter.
  • Pressure angle (degrees): This controls the slope of the tooth profile. The standard mechanical values are typically 20° or 14.5°.
  • Diameter of center hole (px): Sets the size of the circular cutout in the middle of the gear for axles or shafts. Set this to 0 if you do not need a center hole.

Previewing and Generating the Gear

  1. Check the Live preview box at the bottom of the dialog window to see real-time changes directly on your canvas.
  2. Adjust the Number of teeth or other parameters until the shape meets your requirements.
  3. Click Apply to generate the vector path on your canvas, then click Close.

Creating Interlocking Gears

If you are designing a gear pair or gear train with different tooth counts, the gears must be able to mesh correctly:

  1. Keep the Circular pitch and Pressure angle identical for every gear in the set.
  2. Change only the Number of teeth to set your desired gear ratio (for example, a 12-tooth driving gear and a 24-tooth driven gear for a 1:2 ratio).
  3. Align the gears on your canvas so their pitch circles touch, then rotate one gear slightly if necessary to interlock the teeth cleanly.
