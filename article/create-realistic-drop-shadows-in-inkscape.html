Create Realistic Drop Shadows in Inkscape

Creating realistic vector drop shadows in Inkscape requires moving beyond default presets and utilizing the built-in Filter Effects engine. This article walks through building a custom SVG filter from scratch using primitives like Gaussian Blur, Offset, Color Matrix, and Composite. By mastering these nodes, you can control shadow diffusion, directional light offset, color tone, and opacity falloff to produce natural, lifelike depth for any vector object.

1. Open the Filter Editor

  1. Select the object you want to apply the shadow to.
  2. Go to the top menu and select Filters > Filter Editor.
  3. In the Filter Editor panel, click New to create an empty filter template and assign it a clear name, such as "Realistic Shadow".
  4. Check the box next to your new filter name to apply it to your selected object.

2. Add and Configure the Filter Primitives

A realistic drop shadow requires chaining specific filter primitives together in the correct sequence. Add the following primitives using the Add Effect drop-down menu:

  • Offset:
    • Connect the input of the Offset node to Source Alpha.
    • Set the Dx (horizontal) and Dy (vertical) values to define the direction and distance of the light source (e.g., Dx: 4, Dy: 8).
  • Gaussian Blur:
    • Connect the input of Gaussian Blur to the output of the Offset node.
    • Adjust the Standard Deviation slider to soften the shadow edges. A value between 3.0 and 6.0 provides a natural, soft falloff.
  • Color Matrix:
    • Connect the input of Color Matrix to the output of the Gaussian Blur node.
    • Change the type to Matrix.
    • Reduce the alpha multiplier (the bottom-right value in the 4x5 matrix) to around 0.4–0.6 to soften the shadow's overall opacity without making the object itself transparent.
  • Composite:
    • Add a Composite primitive.
    • Connect Input 1 (Image 1) to Source Graphic (the original sharp vector shape).
    • Connect Input 2 (Image 2) to the output of the Color Matrix node.
    • Set the Operator to Over. This layers the crisp original object directly on top of the blurred shadow.

3. Create a Dual-Stage Shadow for Maximum Realism

Real-world light produces both a sharp, dark contact shadow near the base of an object and a wider, softer ambient shadow further away.

  1. Add a second Gaussian Blur and Offset branch in the same filter.
  2. Configure the first branch as a Contact Shadow: low blur radius (1.0–2.0), low offset (1–2 px), and higher opacity.
  3. Configure the second branch as an Ambient Shadow: high blur radius (8.0–12.0), larger offset (6–10 px), and lower opacity.
  4. Merge both shadow branches using a Merge primitive before passing them underneath the Source Graphic with the final Composite node.

4. Fine-Tune and Reuse

Because the effect is purely vector-based SVG code, your shadows remain fully non-destructive and scalable. You can adjust lighting parameters at any time via the Filter Editor sliders or apply the saved filter preset to any other vector path, text element, or group across your Inkscape document.
