How to Create Celtic Knots in Inkscape

Creating Celtic knots in Inkscape is straightforward when using the built-in Knot Live Path Effect (LPE). This tutorial explains how to draw overlapping lines, combine them into a single path, apply the Knot effect, and configure the intersections to achieve a seamless, traditional over-and-under woven design.

Step 1: Draw the Base Pattern

  1. Select the Draw Freehand Lines (Pencil) or Draw Bezier Curves (Pen) tool.
  2. Draw the intersecting lines or loops that will form the foundation of your Celtic knot design.
  3. Ensure the strokes cross over one another where you want the woven pattern to appear.
  4. Set a visible stroke width in the Fill and Stroke panel (Ctrl + Shift + F) so you can clearly see the lines.

Step 2: Combine the Paths

The Knot Path Effect requires all intersecting lines to belong to a single path object.

  1. Select all the drawn segments using the Select Tool (S).
  2. Go to the top menu and select Path > Combine (or press Ctrl + K).

Step 3: Add the Knot Live Path Effect

  1. With your combined path selected, open the Path Effects panel by going to Path > Path Effects.
  2. Click the Add Path Effect button (the + icon).
  3. Search for or scroll to Knot and click it to apply it to your path.

Step 4: Adjust the Over-and-Under Weaving

Once the Knot effect is applied, Inkscape automatically cuts gaps at the intersections.

  1. Switch to the Node Tool (N).
  2. Hover over the intersections; you will see small handles or highlighted crossing points.
  3. Click on an intersection to toggle which strand is on top and which is underneath to establish the alternating Celtic knot pattern.
  4. In the Path Effects panel, adjust the Gap length slider to increase or decrease the visual gap size between overlapping strands.

Step 5: Finalize the Design

  1. To customize the appearance, adjust the stroke color, width, and join styles in the Fill and Stroke panel.
  2. If you need to manipulate the knot as filled vector shapes rather than live strokes, select the object and go to Path > Object to Path.
