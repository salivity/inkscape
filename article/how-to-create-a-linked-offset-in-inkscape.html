How to Create a Linked Offset in Inkscape

In Inkscape, creating a dynamic offset path linked to an original shape allows you to generate an outline or inset that automatically adjusts whenever the source object is modified. This guide explains how to use Inkscape's Linked Offset tool to generate responsive contours, borders, and layered vector graphics that remain synchronized with the underlying path.

Step 1: Prepare the Source Object

  1. Select the object you want to offset using the Select Tool (S).
  2. If your object is a basic shape (such as a rectangle or circle) or text, convert it into a vector path by going to Path > Object to Path (Shift + Ctrl + C).

Step 2: Generate the Linked Offset

  1. Keep the base path selected.
  2. Navigate to the top menu and select Path > Linked Offset (Ctrl + Alt + J).
  3. Inkscape will automatically switch to the Node Tool (N) and place a new offset object directly over your original shape.

Step 3: Adjust the Offset Distance

  1. Locate the single, diamond-shaped handle near the top edge of your shape.
  2. Click and drag the handle outward to create an expanded outer offset, or drag it inward to create a contracted inset.
  3. Optional: Turn off Snap controls on the right toolbar if snapping prevents smooth adjustment of the offset distance.

Step 4: Customize the Appearance

  1. Open the Fill and Stroke panel (Object > Fill and Stroke or Shift + Ctrl + F).
  2. Change the fill color, stroke color, or stroke width of the offset object so it visually stands apart from the original shape.
  3. Lower the layer position if needed using Object > Lower to Bottom (End) to place an expanded offset behind the source path.

Step 5: Test the Dynamic Link

  1. Select the original base path with the Node Tool (N).
  2. Move, add, or delete nodes on the original shape.
  3. The linked offset path will automatically reshape and update its boundaries in real time to match the source geometry.
