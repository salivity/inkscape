Convert Arrow Marker to Path in Inkscape

Converting an arrow marker into an editable vector shape in Inkscape allows you to customize the arrowhead's nodes, scale it independently, or apply unique fills and strokes. While markers normally behave as dynamic properties attached to a stroke, Inkscape provides a built-in command to bake these markers into standard vector geometry. This guide provides the direct steps required to separate an arrow marker from its line and convert it into an independent path.

Step 1: Select the Object

Using the Select tool (shortcut: S or F1), click on the path that currently contains the arrow marker you wish to edit.

Step 2: Convert the Stroke to a Path

With the object selected, navigate to the top menu and select:

  • Path > Stroke to Path (Keyboard shortcut: Ctrl + Alt + C on Windows/Linux, or Cmd + Option + C on macOS).

This operation converts the stroke line into a filled outline shape and automatically detaches the arrow marker, converting it into a separate closed vector path grouped with the line.

Step 3: Ungroup the Elements

Because Inkscape automatically groups the converted stroke and the newly created marker shape together, you must ungroup them to edit the arrow independently:

  • Go to Object > Ungroup (Keyboard shortcut: Ctrl + Shift + G or Cmd + Shift + G).

Step 4: Edit the Arrow Marker

Click anywhere on the canvas to deselect, then click directly on the arrow marker. It is now a standalone vector object.

  • Switch to the Edit paths by nodes tool (shortcut: N or F2) to modify the individual anchor points, curves, and corners of the arrow.
  • Use the Fill and Stroke panel (Ctrl + Shift + F) to change its color, opacity, or outline independently from the original line.
