Convert Flowed Text to Regular Text in Inkscape

Flowed text in Inkscape allows paragraphs to wrap automatically inside a predefined bounding box, but it can cause compatibility issues and rendering errors when exported to standard SVG viewers. This article explains how to quickly convert flowed text into standard single-line or regular SVG text, ensuring your vector typography renders consistently across all web browsers and design software.

Method 1: Using the "Convert to Regular Text" Command

The most direct method converts the flowed text box into standard SVG text while preserving manual line breaks.

  1. Select the Flowed Text: Click on the Select and Transform objects tool (keyboard shortcut S or F1), then click on the flowed text object you want to convert.
  2. Access the Text Menu: Navigate to the top menu bar and click on Text.
  3. Convert the Text: Select Convert to Regular Text from the dropdown menu.

The text will instantly convert into standard text. The rigid bounding frame will disappear, and the text will now behave as regular text anchored to baseline coordinates.

Method 2: Using the "Unflow" Command

If your text was flowed inside an arbitrary path or shape, the Unflow command removes the text from the boundary path and places it onto a single horizontal line.

  1. Select the Object: Use the Select tool (S) to choose the flowed text object or shape containing the text.
  2. Unflow the Text: Go to the top menu, select Text, and click Unflow (or press the shortcut Alt + W).

This action extracts the text string and formats it as a single-line regular text element, leaving the original bounding shape empty.

Verifying the Conversion

To confirm that the conversion succeeded:

  • Select the text with the Text Tool (T). Regular text will display a single baseline anchor node rather than a resizing handle on the corner of a bounding box.
  • Check the status bar at the bottom of the Inkscape window. It will identify the selected object as Text (regular) instead of Flowed text.
