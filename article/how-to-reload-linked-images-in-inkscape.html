How to Reload Linked Images in Inkscape

When working with externally linked raster graphics in Inkscape, edits made to source image files in external editors do not automatically update on the canvas due to how Inkscape caches linked assets. This guide outlines the quickest and most effective methods to force Inkscape to refresh and reload updated external raster images without restarting your project or disrupting your workflow.

Method 1: Cut and Paste in Place (Fastest)

The simplest way to force a cache refresh for an individual image is to remove and re-insert it in the exact same coordinates.

  1. Select the linked raster image on the canvas.
  2. Press Ctrl + X (Windows/Linux) or Cmd + X (macOS) to cut the image to your clipboard.
  3. Press Ctrl + Alt + V (Windows/Linux) or Cmd + Option + V (macOS) to Paste in Place.

Inkscape treats the pasted graphic as a fresh object, fetches the updated version directly from the disk, and places it precisely where it was originally positioned.

Method 2: Force Refresh Using the XML Editor

If your image is nested inside complex groups or clipping masks where cutting and pasting might alter the layer hierarchy or z-index, use the built-in XML editor.

  1. Select the linked image.
  2. Open the XML Editor by pressing Ctrl + Shift + X (or navigate to Edit > XML Editor).
  3. In the tree view, ensure the corresponding <svg:image> node is selected.
  4. Locate the xlink:href (or href) attribute in the right-hand panel.
  5. Click on the attribute, add a space to the end of the file path, remove the space, and press Set (or press Enter).

Triggering a change event on the file path attribute commands Inkscape to re-read the file from the disk instantly without altering the image's positioning or stacking order.

Method 3: Revert the Document

If you have updated multiple linked images simultaneously outside of Inkscape and have not made unsaved vector edits in your current session:

  1. Save your current Inkscape document (Ctrl + S or Cmd + S).
  2. Go to File > Revert.

This action reloads the entire SVG file from storage, clearing the temporary memory cache and loading the current version of every linked external asset on your canvas.
