How to Slice a Path in Inkscape with Cut Path

Slicing a closed vector shape into two separate open paths is a fundamental editing technique in Inkscape. By utilizing an intersecting stroke and the Cut Path operation, you can precisely divide an existing shape at specific intersection points. This guide explains the exact steps required to position your cutting line, apply the command, and separate the resulting open paths.

1. Prepare Your Objects

Ensure that the shape you want to cut is recognized as a vector path. If you are using a standard shape primitive (such as a circle, rectangle, or star), select it and go to Path > Object to Path (or press Shift + Ctrl + C).

2. Draw the Cutting Line

Select the Draw Bezier curves and straight lines tool (press B) and draw a line that crosses entirely through the closed path. The line must intersect the perimeter of the shape at the exact two locations where you want the cut to occur.

3. Position the Line on Top

Inkscape requires the cutting element to sit above the target object in the layer stacking order. Select the cutting line and press Home on your keyboard, or navigate to Object > Raise to Top.

4. Select Both Paths

Switch to the Select and transform objects tool (press S). Click on the cutting line, hold Shift, and click on the closed shape so that both elements are selected simultaneously.

5. Apply the Cut Path Command

Navigate to the top menu and select Path > Cut Path (or press the keyboard shortcut Ctrl + Alt + /).

Once executed:

  • The cutting line is consumed and disappears automatically.
  • The original closed shape loses its fill color, as closed fills cannot apply to open paths.
  • The shape is sliced at the intersection points into two independent open path segments.

6. Separate the Resulting Paths

Click on an empty area of the canvas to deselect everything. Then, click on one of the segments with the Selection tool and drag it away from the other segment. If you cannot see the segments clearly, open the Fill and Stroke panel (Shift + Ctrl + F) and increase the stroke width or assign a visible stroke color to each open path.
