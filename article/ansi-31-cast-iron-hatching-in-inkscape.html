ANSI 31 Cast Iron Hatching in Inkscape

This guide covers the process of creating standard ANSI 31 cross-hatching for cast iron sections in Inkscape using both Pattern Fills and Live Path Effects (LPE). ANSI 31 specifies uniformly spaced, single diagonal lines oriented at a 45-degree angle. By following these steps, you will learn how to configure the exact 45-degree angle and adjust line pitch (spacing) to achieve clean, technically accurate engineering section cuts.

Understanding ANSI 31 Specifications

In technical drafting, ANSI 31 is the standard hatch designation for cast iron and general section lining. It consists of continuous, parallel diagonal lines drawn at a 45° angle relative to the primary axis of the drawing. Pitch—the perpendicular distance between adjacent hatch lines—typically ranges from 1.5 mm to 3 mm (1/16" to 1/8"), scaled proportionally to the size of the cross-sectioned area.

Method 1: Using Live Path Effects (Recommended for Precision)

The Live Path Effects (LPE) engine provides the most direct numerical control over hatch pitch and angle.

  1. Convert the Shape to a Path

    • Select the cut section shape.
    • Go to Path > Object to Path (or press Shift + Ctrl + C).
    • Ensure the shape has a transparent fill and a defined stroke, or duplicate it if you need to retain a solid background outline.

  2. Apply the Hatches Path Effect

    • Open the Path Effects panel via Path > Path Effects.
    • Click the + (Add Path Effect) button.
    • Search for and select Hatches (rough) or Hatches.

  3. Set the 45-Degree Angle

    • Select the Edit paths by nodes tool (N).
    • On the canvas, you will see two handles connected by a guideline that controls the hatch direction and origin.
    • Hold Ctrl while dragging the rotation handle to snap the angle precisely in 15-degree increments until you reach 45°.

  4. Adjust the Pitch (Spacing)

    • In the Path Effects settings panel:
      • Set Frequency and Randomness options to ensure strict uniformity.
      • Reduce Random factor and Jitter to 0 to remove hand-drawn irregularities.
      • Adjust the Spacing or Frequency parameter to define the line pitch (e.g., 2.0 mm).
    • Adjust the stroke thickness in the Fill and Stroke panel (Shift + Ctrl + F) under the Stroke style tab (typically 0.25 mm to 0.35 mm for ANSI standards).

Method 2: Using the Pattern Fill Engine

Inkscape includes predefined stripe patterns that can be applied to any enclosed fill and rotated.

  1. Apply a Striped Pattern

    • Select the enclosed boundary representing the cast iron section.
    • Open the Fill and Stroke panel (Shift + Ctrl + F) and choose the Fill tab.
    • Click the Pattern icon.
    • From the pattern drop-down menu, choose Stripes 1:1 or Stripes 1:2.

  2. Orient to 45 Degrees and Adjust Pitch

    • Press N to switch to the Node Tool.
    • Locate the pattern manipulation handles (usually appearing at the top-left origin of the canvas or bounding box):
      • Cross (X) Handle: Moves the pattern origin.
      • Square Handle: Controls scale and pitch (line spacing).
      • Circle Handle: Controls rotation.
    • Click and drag the Circle Handle while holding Ctrl to snap rotation to 45°.
    • Click and drag the Square Handle inward or outward to scale the pitch to your desired dimension. Holding Ctrl preserves proportional scaling.

Best Practices for Section Cuts

  • Scale Consistency: If multiple parts in an assembly consist of cast iron, maintain an identical pitch across all matching sections.
  • Mating Parts: When two cast iron components touch along a joint, set the adjacent hatch angle to 135° (-45°) to clearly distinguish separate parts.
  • Lineweight Hierarchy: Always keep hatch line weights noticeably thinner than the surrounding object boundary lines to preserve drawing readability.
