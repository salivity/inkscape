Configure Single-Key Shortcuts in Inkscape

Configuring single-key shortcuts in Inkscape allows you to rapidly switch between essential vector design tools without relying on multi-key combinations or mouse clicks. This guide explains how to access the keyboard settings, assign custom single keys to your most-used tools—such as the Select, Node, and Bezier Pen tools—and resolve keybinding conflicts to streamline your vector illustration workflow.

Accessing the Keyboard Preferences

To customize your shortcut layout, you must access Inkscape’s internal shortcut editor:

  1. Open Inkscape.
  2. Go to the top menu and select Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left-hand sidebar of the Preferences dialog, expand the Interface category and select Keyboard.

Assigning Single-Key Shortcuts to Vector Tools

Inside the Keyboard settings menu, you can search for and rebind any vector tool:

  1. Locate the Search bar at the top right of the Keyboard settings panel.
  2. Type the name of the tool you want to modify (e.g., "Select", "Node", "Draw Bezier curves").
  3. Expand the relevant category (such as Tools) in the list below.
  4. Click directly on the Shortcut column next to the action name. The text will change to indicate it is listening for user input.
  5. Press the single key you wish to assign (for example, press V for the Select tool, A for the Node tool, or P for the Bezier Pen tool).

Resolving Key Conflicts

If the key you select is already assigned to another command, Inkscape will display a conflict warning:

  • Overwrite: If you want your new tool shortcut to take precedence, confirm the reassignment. The previous command will be stripped of that shortcut.
  • Cancel: If the key is bound to a critical command you still need, cancel the prompt and choose an alternative single key.

Exporting and Saving Custom Keymaps

Once you have configured your shortcuts:

  1. Click the Export button at the bottom of the Keyboard preferences window.
  2. Save your .xml shortcut map to a safe directory.
  3. If you ever reinstall Inkscape or switch workstations, you can load this layout using the Import button.

Note: Single-key shortcuts only trigger tool switches when you are not actively editing text within a text object.
