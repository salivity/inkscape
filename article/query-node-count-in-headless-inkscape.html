Query Node Count in Headless Inkscape

This guide explains how to determine the total node count of an SVG document using Inkscape's headless command-line interface. Because Inkscape does not include a direct, built-in action specifically named query-nodes, obtaining an accurate total count headlessly requires executing Inkscape actions to convert all document objects into paths and piping the result into a command-line parser.

Understanding Inkscape Headless Query Actions

Modern versions of Inkscape (version 1.0 and later) replace legacy --verb options with the --actions argument. Inkscape provides several native query actions:

  • query-all: Lists the ID, X coordinate, Y coordinate, width, and height of elements.
  • query-x, query-y, query-width, query-height: Query specific dimensions of selected elements.
  • query-id: Returns element IDs.

Because none of these native actions return the number of path nodes, you must use Inkscape actions to standardize the geometry first, then parse the resulting path data (d attributes).

Method 1: Inkscape Actions Combined with Python (Recommended)

To capture every node, non-path shapes (rectangles, circles, text, stars) must first be converted to paths. You can chain actions in a single headless command and pipe the plain SVG output directly into Python for node parsing without writing intermediate files to disk.

Run the following command in your terminal:

inkscape input.svg \
  --actions="select-all:all;object-to-path;export-plain-svg;export-filename:-" \
  | python3 -c '
import sys, re
import xml.etree.ElementTree as ET

svg_data = sys.stdin.read()
root = ET.fromstring(svg_data)

total_nodes = 0
# Regular expression matching path command letters indicating a node coordinate
node_pattern = re.compile(r"([MmLlHhVvCcSsQqTtAa])")

for elem in root.iter():
    if elem.tag.endswith("path"):
        d = elem.attrib.get("d", "")
        # Each command letter (except closing Z/z) corresponds to node anchors/points
        commands = node_pattern.findall(d)
        total_nodes += len(commands)

print(f"Total nodes: {total_nodes}")
'

How this command works:

  1. select-all:all: Selects all objects across all layers.
  2. object-to-path: Converts all shapes and text to explicit SVG <path> elements.
  3. export-plain-svg: Strips out Inkscape-specific metadata and editor markup.
  4. export-filename:-: Directs the exported SVG output to standard output (stdout).
  5. The piped Python snippet parses the path definitions (d attributes) to calculate the precise count of node vertices.

Method 2: Shell Pipeline Using Grep and AWK

If you want a lightweight solution without using Python, you can pipe the Inkscape output through standard Unix command-line utilities.

inkscape input.svg \
  --actions="select-all:all;object-to-path;export-plain-svg;export-filename:-" \
  | grep -o -E '\bd="[^"]+"' \
  | grep -o -E '[MmLlHhVvCcSsQqTtAa]' \
  | wc -l

Explanation:

  • The first grep extracts all d="..." path data segments.
  • The second grep isolates each path command letter that generates or moves to a vertex point (M, L, C, S, Q, T, A, H, V, case-insensitive).
  • wc -l outputs the total count of matched node commands.

Legacy Inkscape (Versions Prior to 1.0)

For legacy Inkscape versions using verbs instead of actions, use --verb combined with --vacuum-defs:

inkscape input.svg \
  --verb="EditSelectAll;ObjectToPath;FileSave;FileQuit" \
  --export-plain-svg=output_paths.svg

grep -o -E '[MmLlHhVvCcSsQqTtAa]' output_paths.svg | wc -l

For automated and headless server environments, upgrading to Inkscape 1.2+ and using the --actions stdout pipeline is recommended to avoid GUI dependencies and unnecessary disk I/O.
