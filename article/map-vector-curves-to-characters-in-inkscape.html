Map Vector Curves to Characters in Inkscape

Creating a custom font in Inkscape involves transforming standard vector paths into usable font glyphs linked to specific keystrokes. This guide provides a direct walkthrough on setting up the SVG Font Editor, preparing your vector artwork, and mapping custom vector curves to exact keyboard character codes to build a functional SVG font.

1. Prepare Your Vector Artwork

Before mapping any artwork to a glyph, your vector shapes must be formatted so the font engine can interpret them:

  • Convert to Paths: Select your design and ensure everything is a path by navigating to Path > Object to Path.
  • Combine into a Single Path: If your character consists of multiple shapes, select them all and choose Path > Combine (or Path > Union if they overlap). An SVG glyph can only take geometry from a single path object.
  • Size and Orientation: Place your character design inside a square bounding area (often 1000x1000 px to match standard font units). Note that the SVG Font specification uses an inverted Y-axis relative to standard Inkscape drawing coordinates; you may need to flip your path vertically (Object > Flip Vertically) before assigning it, or adjust the font transformation settings.

2. Open the SVG Font Editor

  1. In the top menu, go to Text > SVG Font Editor.
  2. A dockable panel named SVG Font Editor will appear on the right side of your workspace.

3. Initialize a New Font

  1. In the Font section of the SVG Font Editor, click New.
  2. Double-click the default name to rename your font family.
  3. Switch to the Global Settings tab to configure fundamental font metrics:
    • Units per em: Typically set to 1000.
    • Ascent / Descent: Define vertical metrics (e.g., 800 for Ascent, 200 for Descent).

4. Create and Map a Glyph to a Character Code

  1. Switch to the Glyphs tab within the SVG Font Editor.
  2. Click the Add Glyph button at the bottom of the tab. A new row will appear.
  3. Select the new glyph entry and define the character mapping:
    • Glyph name: Give the glyph an internal identifier (e.g., letter_A or exclamation).
    • Matching string: Enter the exact keyboard character you want to map to this curve (e.g., typing A, a, 1, or a specific symbol). The system directly maps this string to the corresponding character code.
    • Advance: Enter the horizontal advance width (the space the character occupies before the next character starts, usually matching your em box width, such as 1000).

5. Link the Vector Curve to the Glyph

  1. On your canvas, select the prepared single vector path.
  2. In the SVG Font Editor's Glyphs tab, make sure your target glyph row is highlighted.
  3. Click the Get curves from selection button located beneath the glyph list.
  4. The path data will be transferred into the glyph's internal definition.

6. Preview and Test

  1. Scroll down to the Sample Text input box at the bottom of the SVG Font Editor.
  2. Type the character assigned to the Matching string.
  3. The preview box will render your custom vector curve. If the path appears upside down, undo, select your vector on the canvas, flip it vertically (Object > Flip Vertically), and click Get curves from selection once more.
