How to Batch Export Icons in Inkscape

Exporting multiple icons individually in Inkscape can be tedious, but the built-in Batch Export feature allows you to output dozens of assets simultaneously. This guide explains how to organize your design assets, navigate the Export dialog's Batch Export mode, and automatically render multiple icons into your desired file formats and resolutions in just a few clicks.

1. Prepare and Name Your Icons

Before opening the export panel, ensure your icons are properly structured on the canvas:

  • Group Elements: Combine all paths, shapes, and text for each individual icon into a single group by selecting the parts and pressing Ctrl + G (or Cmd + G on macOS).
  • Name Your Groups: Inkscape uses object IDs or labels as the exported filenames. Open the Layers and Objects panel (Ctrl + Shift + L / Cmd + Shift + L), right-click each icon group, select Rename, and enter the desired filename.

2. Open the Export Dialog

Open Inkscape’s export interface using one of the following methods:

  • Go to the top menu and select File > Export...
  • Use the keyboard shortcut Ctrl + Shift + E (Windows/Linux) or Cmd + Shift + E (macOS).

The Export dialog will appear docked on the right side of your workspace.

3. Switch to the Batch Export Tab

Inside the Export panel, you will see several tabs at the top (Single, Batch export).

  1. Click on the Batch export tab.
  2. Select your batch source mode depending on how your project is structured:
    • Selection: Exports all currently selected objects or groups on the canvas as separate files.
    • Layers: Exports every visible layer as an independent file.
    • Pages: Exports individual pages if you are using Inkscape’s multi-page feature.

If you organized your icons into individual groups, select all the icon groups on your canvas and choose the Selection option.

4. Configure Output Formats and Settings

In the lower section of the Batch export panel:

  1. Click Add Export Format if the target file type is not already listed.
  2. Choose your preferred file format (e.g., PNG, SVG, PDF, or JPEG).
  3. Set your export parameters:
    • For PNG/raster formats, specify the DPI (e.g., 96 DPI for standard web resolution, 300 DPI for high resolution, or custom pixel dimensions).
    • For SVG, select the SVG profile suitable for your workflow (such as Plain SVG or Optimized SVG).
  4. Add multiple formats simultaneously if you need icons in both vector (SVG) and raster (PNG) formats.

5. Choose the Destination and Export

  1. Click the folder icon next to the Directory field to choose the folder where your icons will be saved.
  2. Review the preview list in the dialog to confirm the filenames and export formats.
  3. Click the Export button at the bottom of the panel.

Inkscape will process each asset sequentially and save all the icons to your designated folder.
