Design Custom Playing Cards in Inkscape with Batch Export

Designing custom playing cards and board game assets requires precision layout, reusable templates, and an efficient export pipeline. This guide walks you through setting up standard card dimensions with bleeds, structuring reusable vector components, organizing multi-card decks, and utilizing Inkscape’s batch export tools to generate high-resolution, print-ready image files for your tabletop games.

1. Set Up Document Dimensions, Margins, and Bleed

Tabletop components require specific sizing to ensure clean physical production or digital prototyping:

  1. Open Inkscape and press Ctrl+Shift+D to open Document Properties.
  2. Set the Display units to mm or in.
  3. Standard poker cards measure 2.5 × 3.5 inches (63.5 × 88.9 mm). If printing physically, add a standard 1/8-inch (3.175 mm) bleed on all four sides, setting the custom page size to 2.75 × 3.75 inches (69.85 × 95.25 mm).
  4. Create visual guides by dragging from the rulers to mark:
    • Bleed Line: The outer edge of the canvas.
    • Cut Line: 0.125 inches inside the bleed line (the final trimmed card size).
    • Safe Zone: 0.125 inches inside the cut line to ensure vital text and icons are not trimmed off.

2. Organize Component Layers

Structured layers allow you to maintain consistency across entire card sets:

  • Background Layer: Base textures, borders, and color fills that extend past the cut line to the bleed edge.
  • Frame & Structural Layer: Card borders, stat boxes, resource cost frames, and visual layout geometry.
  • Artwork Layer: Central illustrations or iconography.
  • Text & Data Layer: Title, rules text, flavor text, and numeric values.

To keep repetitive elements identical across cards, use Clones (Alt+D or Edit > Clone > Create Clone). Editing the original master asset automatically updates all cloned instances across your project.

3. Create Multi-Card Layouts with the Page Tool

Inkscape supports multi-page documents, making deck management seamless without creating separate files for every card:

  1. Select the Create and Edit Pages tool (Shift+P) from the left toolbar.
  2. Click Duplicate the active page in the top tool control bar to generate matching artboards for each card in your deck.
  3. Keep the template elements fixed on each page while swapping card titles, artwork, and descriptions per page.
  4. Name each page explicitly in the Page tool toolbar (e.g., card_01_warrior, card_02_mage) to automate clean file naming during export.

4. Batch Export Cards and Assets

Once your card designs and board assets are finalized, export them simultaneously:

  1. Open the Export dialog (Ctrl+Shift+E or File > Export).
  2. Select the Batch Export tab at the top of the dialog.
  3. Choose the export target:
    • Pages: Exports each card artboard as an individual file named according to its page label.
    • Layers: Exports individual layers separately (useful for modular UI assets, tokens, and asset overlays).
    • Selection: Exports individual tagged vector objects across the canvas.
  4. Set the Format to PNG for digital tabletop platforms (such as Tabletop Simulator) or TIFF/PDF for professional printing.
  5. Set the resolution to 300 DPI for high-resolution physical printing, or 72–150 DPI for digital prototypes.
  6. Select your destination directory and click Export. Inkscape will render and save all cards and components in a single automated process.
