How to Export Inkscape Vector Paths to LibreCAD

Moving vector line paths from Inkscape to LibreCAD allows designers to combine Inkscape's flexible freehand and vector design tools with LibreCAD's precision CAD environment. This guide provides a clear, step-by-step workflow for converting Inkscape graphics into CAD-ready paths, exporting them via the AutoCAD DXF format, and importing them into LibreCAD with correct architectural units and scale.

Step 1: Prepare Paths in Inkscape

LibreCAD does not recognize standard SVG shapes, dynamic strokes, or text as CAD geometry. You must convert all elements into basic vector line paths before exporting:

  1. Set Document Units: Go to File > Document Properties (Ctrl+Shift+D). Set the display units and document units to your target architectural unit (such as millimeters, centimeters, or inches).
  2. Convert Objects to Paths: Select all elements (Ctrl+A) and choose Path > Object to Path (Shift+Ctrl+C).
  3. Convert Strokes to Paths: If your drawing relies on stroke width rather than centerlines, select the lines and go to Path > Stroke to Path (Ctrl+Alt+C). If you only need the single-line vector skeleton, skip this step and ensure your strokes have no fills.
  4. Ungroup Everything: Select all objects and repeatedly press Object > Ungroup (Ctrl+Shift+G) until the status bar confirms there are no groups left.
  5. Flatten Layers (Optional): Move critical geometry to a single layer if you want to avoid nested layer issues during CAD translation.

Step 2: Export as a DXF File

LibreCAD relies on the Drawing Exchange Format (DXF) to read external CAD files.

  1. Navigate to File > Save As (Shift+Ctrl+S).
  2. Set the file format dropdown to AutoCAD DXF R14 (*.dxf) or Desktop Cutting Plotter (AutoCAD DXF R14) (*.dxf).
  3. In the export settings dialog that appears:
    • Base Unit: Match this exactly to the unit chosen in your Document Properties (e.g., mm or in).
    • Character Encoding: Choose UTF-8 or Latin 1.
    • Layer Option: Enable layer export if you want to preserve Inkscape layer names in LibreCAD.
    • Polyline Export: Check the option to export paths as polylines if prompted, as this yields the cleanest entities in CAD software.
  4. Click OK to save the file.

Step 3: Import and Configure in LibreCAD

  1. Launch LibreCAD.
  2. Go to File > Open and select the .dxf file you exported from Inkscape.
  3. Go to Options > Current Drawing Preferences.
  4. In the Units tab, verify that the Main drawing unit matches the unit you defined during the Inkscape export.
  5. Click OK.

Step 4: Verify Scale and Clean Geometry

  1. Check Dimensions: Use the measurement tool (Info > Distance Point to Point) to measure a known reference line in your drawing. If the dimension does not match real-world measurements, select all entities (Ctrl+A) and use Modify > Scale to resize the plan accordingly.
  2. Handle Curves: Inkscape Bézier curves often export into DXF as segmented polylines. If smooth arcs are required for drafting or laser-cutting specifications, use LibreCAD's Draw > Arc or Draw > Circle tools to replace rough segments with true geometric arcs.
  3. Assign Architectural Layers: Use the LibreCAD Layer List to organize your paths into functional CAD layers (such as WALLS, DOORS, WINDOWS, and ANNOTATIONS), assigning distinct line weights and colors for drafting standards.
