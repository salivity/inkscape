How to Select Overlapping Objects in Inkscape

Selecting specific objects that are hidden beneath other layers or shapes in Inkscape can be challenging. Inkscape includes a built-in shortcut using the Alt key and the left mouse button that allows you to cycle through the Z-order (stacking order) of overlapping objects directly on the canvas. This guide explains how to use this feature, provides useful modifier combinations, and covers quick troubleshooting steps if your operating system blocks the shortcut.

Step-by-Step: Cycling Through Overlapping Objects

  1. Activate the Select Tool: Press S or F1 on your keyboard, or click the Select and Transform objects arrow icon in the left toolbar.
  2. Hover Over the Stack: Move your cursor over the area where the objects overlap.
  3. Hold Alt and Left-Click:
    • Click once to select the top-most object.
    • Click a second time (while continuing to hold Alt) to select the object directly beneath it.
    • Continue clicking to cycle deeper down through the stack. Once you reach the bottom-most object, the next click will cycle back to the top object.
  4. Transform or Edit: Once the desired object shows its selection bounding box, release the Alt key to move, style, or edit it normally.

Useful Selection Modifier Combinations

Inkscape allows you to combine the Alt click technique with other modifier keys for more precise control:

  • Alt + Shift + Click: Cycles through underlying objects while simultaneously adding them to your existing selection.
  • Ctrl + Alt + Click: Cycles through and selects individual overlapping objects that reside inside groups without needing to ungroup them first.
  • Ctrl + Alt + Shift + Click: Adds underlying objects within groups to an existing multi-object selection.

Troubleshooting Alt + Click Conflicts (Linux & macOS)

  • Linux Window Managers: On many Linux distributions (such as Ubuntu with GNOME or environments using XFCE/KDE), Alt + Left-Click is reserved by the operating system to drag windows. To fix this, change your window manager's "Window Action Key" from Alt to the Super (Windows) key in your system settings.
  • macOS: Use the Option key in place of the Alt key (Option + Left-Click).

Alternative Ways to Select Hidden Objects

If you prefer not to use keyboard modifiers on the canvas, you can manage overlapping selections using these built-in tools:

  • Objects / Layers Panel: Open the panel via Layer > Layers and Objects... (Ctrl + Shift + L). Locate your shape in the tree hierarchy and click it to select it directly.
  • Tab Key Navigation: Select an object on the canvas and press Tab to cycle through the next object in the stacking order, or Shift + Tab to cycle in reverse.
