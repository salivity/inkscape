Export Inkscape SVG to FreeCAD PartDesign Sketch

Bringing vector designs from Inkscape into FreeCAD allows you to turn 2D artwork, logos, and profiles into 3D models quickly. This guide provides a direct, step-by-step process to prepare and export SVG paths in Inkscape, import them cleanly into FreeCAD, and convert them into fully functional PartDesign sketches ready for padding and extrusion.

1. Prepare and Clean the Paths in Inkscape

FreeCAD requires well-defined, closed geometry to perform solid extrusions. Open paths or complex grouping will cause the PartDesign Pad operation to fail.

  1. Convert Objects to Paths: Select all elements and navigate to Path > Object to Path (or press Shift + Ctrl + C). Convert any strokes to paths as well via Path > Stroke to Path (Ctrl + Alt + C) if your geometry relies on line thickness.
  2. Combine Intersecting Geometry: If your shape has inner cutouts (like the holes in letters like "O" or "A"), select the outer path and the inner path, then navigate to Path > Combine (Ctrl + K).
  3. Verify Closed Loops: Switch to the Edit paths by nodes tool (N) and verify that all outer boundaries form closed shapes. Overlapping nodes or unjoined endpoints will prevent extrusion.
  4. Set Real-World Units: Go to File > Document Properties (Shift + Ctrl + D). Set the display units and format to millimeters (mm). Match the SVG viewbox dimensions directly to your intended mechanical dimensions.
  5. Export as Plain SVG: Go to File > Save As..., select Plain SVG (*.svg) from the file type dropdown menu, and save the file. Do not use "Inkscape SVG", as the proprietary metadata can introduce scaling errors or unsupported XML tags in FreeCAD.

2. Configure FreeCAD for SVG Import

To ensure FreeCAD interprets the SVG as geometry rather than a flat drawing:

  1. Open FreeCAD and navigate to Edit > Preferences.
  2. Select Import-Export in the left sidebar and open the SVG tab.
  3. Under the SVG Import options, ensure that Import style is set to SVG as geometry (importSVG).
  4. Click Apply and OK.

3. Import and Convert to a PartDesign Sketch

Once imported, the SVG shapes reside in FreeCAD as 2D Draft objects and must be converted into a PartDesign-compatible Sketch.

  1. Create a new document in FreeCAD (Ctrl + N).
  2. Go to File > Import and select your Plain SVG file.
  3. Switch to the Draft Workbench using the workbench selector.
  4. In the Tree view, select all the newly imported 2D path objects.
  5. Click the Draft to Sketch tool (located on the toolbar, represented by a blue drafting shape converting to a white sketch). This creates a new object named Sketch in the tree.
  6. Switch to the PartDesign Workbench.
  7. Create a new body by clicking Create body in the PartDesign tasks panel.
  8. Drag and drop the generated Sketch from the Tree view into the newly created Body.

4. Validate and Extrude (Pad)

Vector conversions often contain duplicate points or tiny open gaps that need a final cleanup before PartDesign can extrude them.

  1. Double-click the Sketch inside your Body to open the Sketcher.
  2. In the top menu, go to Sketch > Validate sketch....
  3. In the Sketcher validation tool, run Find under "Missing coincident constraints" and click Fix to close microscopic gaps. Run Find under "Duplicated constraints" and remove them if present.
  4. Click Close to exit the Sketcher.
  5. With the sketch selected in the Tree view, click the Pad tool in the PartDesign toolbar.
  6. Set your desired extrusion length in the task panel and click OK. Your SVG paths are now a fully parametric 3D solid feature.
