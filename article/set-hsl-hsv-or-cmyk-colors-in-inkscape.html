Set HSL, HSV, or CMYK Colors in Inkscape

Inkscape provides native support for multiple color spaces, allowing designers to precisely define object colors using HSL, HSV, or CMYK values directly. By utilizing the built-in Fill and Stroke dialog, you can switch color models instantly, input exact numerical values, and ensure your vector artwork matches specific digital or print color requirements.

Step 1: Open the Fill and Stroke Panel

  1. Select the object or path you want to modify using the Select tool (S or F1).
  2. Open the Fill and Stroke panel by pressing Ctrl + Shift + F (Windows/Linux) or Cmd + Shift + F (macOS), or by navigating to Object > Fill and Stroke in the top menu.

Step 2: Choose the Target Property

At the top of the Fill and Stroke panel, choose whether you are applying color to the interior of the shape or its outline:

  • Select the Fill tab to change the inner color.
  • Select the Stroke paint tab to change the outline color.
  • Ensure the Flat color icon (the solid square next to the "No paint" X icon) is active.

Step 3: Switch to Your Desired Color Model

Below the paint type options, Inkscape displays several color space tabs: RGB, HSL, HSV, CMYK, Wheel, and CMS. Click on the tab corresponding to the color format you want to use:

  • HSL (Hue, Saturation, Lightness):

    • H (0–360): Represents the color angle on the color wheel.
    • S (0–100): Sets the intensity or purity of the color.
    • L (0–100): Sets the brightness, from black (0) to white (100).
    • A (0–100): Controls the Alpha (opacity) channel.

  • HSV (Hue, Saturation, Value):

    • H (0–360): Defines the color hue.
    • S (0–100): Defines the saturation level.
    • V (0–100): Defines the value/brightness (0 is completely dark; 100 is maximum brightness).
    • A (0–100): Controls the Alpha (opacity) channel.

  • CMYK (Cyan, Magenta, Yellow, Key/Black):

    • C (0–100): Cyan percentage.
    • M (0–100): Magenta percentage.
    • Y (0–100): Yellow percentage.
    • K (0–100): Black percentage.
    • A (0–100): Controls the Alpha (opacity) channel.

Step 4: Enter Direct Values

  1. Double-click the numerical input box next to any slider (H, S, L, V, C, M, Y, or K).
  2. Type the exact numeric value.
  3. Press Enter to apply the value immediately to the selected object.
