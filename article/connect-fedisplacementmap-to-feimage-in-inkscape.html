Connect feDisplacementMap to feImage in Inkscape

Connecting an feDisplacementMap primitive to an feImage graphic in Inkscape allows you to distort vector objects using an external or internal raster or vector graphic as a displacement map. This process is accomplished entirely through Inkscape’s Filter Editor dialog by adding both primitives to a custom filter and routing the output of the feImage node directly into the secondary input of the feDisplacementMap node.

Step 1: Open the Filter Editor

  1. Open your project in Inkscape and select the object you want to distort.
  2. Navigate to the top menu and select Filters > Filter Editor....
  3. In the Filter Editor panel, click New to create a fresh filter, and check the box next to your new filter to assign it to your selected object.

Step 2: Add the Required Filter Primitives

  1. In the Add Primitive drop-down menu at the bottom of the Filter Editor panel, select Image and click Add Primitive. This creates the feImage element.
  2. Return to the drop-down menu, select Displacement Map, and click Add Primitive. This creates the feDisplacementMap element.

Step 3: Configure the feImage Element

  1. Click on the Image primitive in the list.
  2. In the Filter Attribute tab below the list, locate the file path or URL field.
  3. Click the folder icon or paste the URI targeting the image file or internal object ID you want to use as your displacement map (e.g., an external PNG, JPG, or SVG element #id).

Step 4: Wire the Inputs in the Graph

The Filter Editor displays a connection matrix on the right side showing inputs and outputs:

  1. Locate the Displacement Map node in the list. It requires two distinct inputs:
    • in (First Input): The graphic that will be visually distorted.
    • in2 (Second Input): The map graphic providing pixel values used to displace the target.
  2. Click and drag the connection line from the top connection handle of the Displacement Map to Source Graphic (or to whatever preceding primitive generates the visual content you wish to displace).
  3. Click and drag the connection line from the second (lower) connection handle of the Displacement Map directly to the Image primitive node.

Step 5: Adjust Displacement Parameters

  1. Select the Displacement Map primitive from the list.
  2. In the attributes tab below, set the Scale slider to adjust the intensity of the displacement effect.
  3. Select which color channels drive the movement by configuring X Channel and Y Channel (typically set to Red, Green, Blue, or Alpha depending on the nature of your displacement image).
