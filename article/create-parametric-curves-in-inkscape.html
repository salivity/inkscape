Create Parametric Curves in Inkscape

Inkscape includes a built-in mathematical plotting tool known as the Parametric Curves extension, which allows designers and mathematicians to generate complex vector paths using mathematical formulas. This guide explains how to access the extension, input custom mathematical equations for \(x\) and \(y\) as functions of a parameter \(t\), configure domain and sampling settings, and render the resulting paths directly onto the Inkscape canvas.

Accessing the Extension

  1. Open Inkscape.
  2. Go to the top menu bar and select Extensions.
  3. Hover over Render, then navigate to Mathematics (or directly under Render in older versions).
  4. Click on Parametric Curves.

Setting Up the Mathematical Formulas

The Parametric Curves extension uses standard Python mathematical syntax where the position of any point \((x, y)\) on the curve is determined by an independent variable, usually represented as t.

  • X-Function: Enter the mathematical expression for the horizontal position (e.g., cos(t)).
  • Y-Function: Enter the mathematical expression for the vertical position (e.g., sin(t)).

Standard functions and constants include:

  • Trigonometric: sin(t), cos(t), tan(t)
  • Powers and roots: t**2, sqrt(t)
  • Exponential and logarithmic: exp(t), log(t)
  • Constants: pi, e

Configuring Parameters and Domain

Before rendering, adjust the parameters to define the size, resolution, and range of your curve:

  • Start value of t: The lower bound of the domain (e.g., 0).
  • End value of t: The upper bound of the domain (e.g., 2 * pi or 6.28318).
  • Samples / Intervals: The number of calculation points used to generate the curve. Higher values result in smoother curves, while lower values yield geometric or jagged segments.
  • X-axis scale factor / Y-axis scale factor: Multipliers that determine the size (in canvas units) of the plotted curve.
  • Isotropic scaling: Check this option to ensure both the X and Y axes use the same scaling factor, preventing distortion.

Generating the Curve

  1. Enable the Live Preview checkbox at the bottom of the dialog box to inspect the curve in real time on your canvas.
  2. If the curve looks correct, click the Apply button.
  3. Click Close to exit the extension dialog.

The generated curve is a standard SVG vector path that can be colored, scaled, transformed, or manipulated using the Edit paths by nodes tool (N).
