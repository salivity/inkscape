How to Plot Polar Rose Curves in Inkscape

This guide provides a straightforward walkthrough for generating polar rose curves (rhodonea curves) natively in Inkscape. Because polar roses loop and self-intersect, they cannot be defined as simple single-valued Cartesian functions (\(y = f(x)\)); instead, they are plotted using parametric coordinate conversion within Inkscape’s mathematical rendering tools. By converting the polar equation into parametric expressions and applying them across a defined bounding box, you can instantly render precise, scalable vector rose curves.

Understanding the Mathematical Formula

A polar rose is defined by the polar equation:

\[r(\theta) = a \cos(k\theta) \quad \text{or} \quad r(\theta) = a \sin(k\theta)\]

Where:

  • \(a\) controls the radius/amplitude (the length of the petals).
  • \(k\) determines the number of petals. If \(k\) is an odd integer, the curve has \(k\) petals. If \(k\) is an even integer, the curve has \(2k\) petals.

To plot this curve in Inkscape, convert the polar coordinates \((r, \theta)\) to Cartesian coordinates \((x, y)\) using the parameter \(t\) in place of \(\theta\):

  • X-Function: cos(k*t) * cos(t)
  • Y-Function: cos(k*t) * sin(t)

Step 1: Create a Bounding Box

Inkscape’s mathematical rendering extensions use an existing rectangle on your canvas to define the coordinate axes, scale, and origin:

  1. Select the Rectangle tool (R) from the left toolbar.
  2. Draw a square or rectangle on the canvas (for example, 400 × 400 px) where you want the curve to appear.
  3. Keep the rectangle selected.

Step 2: Open the Curve Plotter

  1. Navigate to the top menu and select Extensions > Render > Parametric Curves... (in some versions grouped under Function Plotter).
  2. A configuration window will appear with input fields for parameters and functions.

Step 3: Enter the Plotting Parameters

In the configuration window, configure the following settings:

  • Start value of t: 0
  • End value of t: Set this based on the value of \(k\):
    • If \(k\) is an even integer, the full curve completes over an interval of \(2\pi\). Enter 6.2832 (or check the option to Multiply by \(2\pi\) if available in your version and set the range from 0 to 1).
    • If \(k\) is an odd integer, the curve completes over an interval of \(\pi\). Enter 3.1416.
  • Number of samples: Enter 360 to 720. Higher values yield smoother curves at larger sizes.
  • X-Function: Enter the parametric formula for \(x\): cos(k*t) * cos(t)
    (Replace k with your desired petal multiplier, e.g., cos(4*t) * cos(t) for an 8-petal rose).
  • Y-Function: Enter the parametric formula for \(y\): cos(k*t) * sin(t)
    (Use the same k value as used in the X-Function).
  • X-range: -1 to 1
  • Y-range: -1 to 1

Step 4: Generate and Finalize the Vector Path

  1. Check the Live preview box to verify the shape.
  2. Click Apply to generate the curve path, then click Close.
  3. Select and delete the initial guide rectangle from the canvas.
  4. Open the Fill and Stroke panel (Shift + Ctrl + F) to adjust the stroke color, stroke width, or fill of your new polar rose vector.
