Appliqué Placement and Tack-Down in Ink/Stitch

Designing appliqué in Ink/Stitch requires a precise three-step sequence: a placement stitch to show where the fabric goes, a tack-down stitch to secure the raw fabric in place, and a final covering stitch (typically satin or blanket stitch) to finish the edges. By utilizing duplicate vector paths, assigning distinct thread colors to trigger machine stops, and configuring basic stroke parameters in Inkscape, you can build a reliable and clean appliqué design ready for machine embroidery.

1. Draw the Base Appliqué Shape

  1. Open Inkscape and create the shape you want to use for your appliqué using the Draw Freehand Lines tool, the Bezier Curves tool, or standard geometric shapes.
  2. If using a standard shape (such as a circle or rectangle), convert it to a path by navigating to Path > Object to Path.
  3. In the Fill and Stroke panel (Ctrl + Shift + F), set the Fill to "None" and set a Stroke paint color. Ensure the stroke style width is set to a standard thin line (e.g., 1 mm).

2. Create the Three Essential Layers

Appliqué relies on duplicate paths placed in the exact same location but executed at different stages of the stitch order.

  1. Select your base path.
  2. Duplicate it twice using Ctrl + D. You will now have three identical paths directly on top of each other.
  3. Open the Layers and Objects panel (Ctrl + Shift + L) and rename the three objects from bottom to top:
    • Placement Stitch (Bottom)
    • Tack-Down Stitch (Middle)
    • Finishing Stitch (Top)

3. Configure the Placement Stitch

The placement stitch is a simple running line sewn directly onto the stabilizer to show the user where to position the appliqué fabric.

  1. Select the Placement Stitch path.
  2. Open Fill and Stroke and assign it a distinct color (e.g., Blue).
  3. With the path selected, open Extensions > Ink/Stitch > Params.
  4. Leave the settings configured as a standard running stitch, verify the stitch length (typically 2.0–2.5 mm), and click Apply and Quit.

4. Configure the Tack-Down Stitch

After placing the fabric over the placement line, the tack-down stitch sews the fabric securely to the stabilizer.

  1. Select the Tack-Down Stitch path.
  2. Change the stroke color in Fill and Stroke to a different color than the placement stitch (e.g., Red). Machine embroidery files recognize color changes as instructions to pause the machine, allowing you to place and trim your fabric.
  3. Open Extensions > Ink/Stitch > Params.
  4. Choose your preferred tack-down method:
    • Standard Running Stitch: A simple straight stitch, best used if you plan to trim the fabric edges closely after stitching.
    • Zig-Zag Stitch: Set a small zig-zag width to firmly bind edges that are prone to fraying.
  5. Click Apply and Quit.

5. Configure the Finishing Stitch

The finishing stitch conceals the raw edges of the trimmed appliqué fabric.

  1. Select the Finishing Stitch path.
  2. Change the stroke color to your desired final thread color (e.g., Black).
  3. Depending on the desired finish:
    • Satin Edge: Convert the path into a satin column by adding a second parallel contour or converting the stroke to a wide zig-zag via Extensions > Ink/Stitch > Tools: Satin > Convert Line to Satin.
    • E-Stitch / Blanket Stitch: In Extensions > Ink/Stitch > Params, configure the stroke style to use an E-stitch sequence suitable for a casual or vintage appliqué look.
  4. Set the stitch density appropriately (typically 0.4 mm spacing for dense satin coverage) to prevent any raw fabric edges from showing through. Click Apply and Quit.

6. Add Stop Commands and Verify

To ensure the embroidery machine halts at the proper moments:

  1. Rely on color changes: Ensure all three steps (Placement, Tack-Down, and Finishing) have distinct thread colors assigned. Most embroidery machines automatically stop when encountering a color change.
  2. Optional Stop Command: Select the Placement Stitch path, go to Extensions > Ink/Stitch > Commands > Attach Commands to Selected Objects, check Stop (pause machine), and click Apply. Repeat for the Tack-Down Stitch path.
  3. Verify the sequence by opening Extensions > Ink/Stitch > Visualise and Export > Simulator/Realistic Preview. Confirm that the machine sews the placement line first, pauses, sews the tack-down line second, pauses, and completes the design with the finishing border.
