How to Launch Inkscape Interactive Shell Mode

Inkscape features a built-in interactive command line shell mode that allows you to execute actions, run verbs, and process vector graphics sequentially without reloading the application for every command. This guide explains how to launch this shell mode across different operating systems and provides essential usage instructions for running commands directly within the prompt.

Launching the Shell

To launch the interactive shell, open your terminal or command prompt and call the Inkscape executable with the --shell flag.

Linux and macOS

On Linux and macOS systems where Inkscape is added to your system's PATH, run:

inkscape --shell

If Inkscape is not in your PATH on macOS, run the executable directly from the application bundle:

/Applications/Inkscape.app/Contents/MacOS/inkscape --shell

Windows

On Windows, navigate to your Inkscape installation directory (typically C:\Program Files\Inkscape\bin) or use the full path. Use inkscape.com rather than inkscape.exe to ensure standard input and output function properly in the console:

"C:\Program Files\Inkscape\bin\inkscape.com" --shell

Using the Interactive Shell

Once the command executes successfully, the terminal prompt changes to > or inkscape>, indicating that the interactive session is active.

In this mode, you can chain actions and file operations together. Commands are executed sequentially without the overhead of starting a new process each time:

file-open:drawing.svg; export-filename:drawing.png; export-do

To see a full list of available actions supported within the shell:

action-list

Exiting the Shell

To terminate the interactive shell session and return to your operating system's standard terminal prompt, enter:

quit

Alternatively, you can send an EOF signal using Ctrl + D on Linux/macOS or Ctrl + Z followed by Enter on Windows.
