Export Inkscape Vectors to Vectric Aspire for CNC

Exporting vector designs from Inkscape to Vectric Aspire for multi-axis CNC carving requires preparing vector geometry, exporting to a compatible CAD format, and mapping the flat vectors onto a wrapped rotary setup in Aspire. Following a standardized workflow ensures that paths maintain correct dimensions, join cleanly, and wrap accurately around your workpiece for rotary or multi-axis machining.

1. Prepare Vectors in Inkscape

Multi-axis machining requires closed, precise vectors scaled to the unwrapped dimensions of your stock.

  • Set Units: Open File > Document Properties and set the display units to match your Aspire configuration (typically millimeters or inches).
  • Calculate Rotary Dimensions: If carving on a cylinder, calculate the unwrapped circumference (\(C = \pi \times \text{Diameter}\)). Size your Inkscape canvas width or height to match this circumference, depending on whether your rotary axis runs along X or Y.
  • Convert Objects and Text to Paths: Select all elements and navigate to Path > Object to Path. If your design uses strokes, go to Path > Stroke to Path so paths translate as cuttable geometry rather than stroke outlines.
  • Combine and Clean Geometry: Use Path > Union or node-editing tools to eliminate overlapping geometry, open nodes, and duplicate lines.

2. Export the Vector File

Vectric Aspire natively supports several vector formats generated by Inkscape:

  • Method A: Plain SVG (Recommended) Go to File > Save As..., choose Plain SVG (*.svg), and save. Plain SVG strips Inkscape-specific metadata, resulting in cleaner imports.
  • Method B: DXF (AutoCAD DXF R14) Go to File > Save As... and select AutoCAD DXF R14 (*.dxf). In the export dialog, ensure the base unit matches your document units and that paths are exported as LWPOLYLINEs.

3. Set Up the Multi-Axis Job in Vectric Aspire

Before bringing in the vectors, define the cylindrical dimensions in Aspire:

  1. Click Create a new file.
  2. Under Job Type, select Rotary.
  3. Enter the Job Dimensions: Cylinder length, cylinder diameter, and measurement units.
  4. Select the Z Zero Position (Cylinder Axis or Cylinder Surface) based on your machine's touch-off procedure.
  5. Set the Orientation to match your physical CNC rotary setup (along the X-axis or Y-axis).

4. Import and Align Vectors

  1. Go to File > Import > Import Vectors... and select the SVG or DXF exported from Inkscape.
  2. Center the vectors within the job bounds using the Align Selected Objects tool (F9).
  3. Check vector integrity using the Vector Validator tool under the Edit Objects menu to identify zero-length spans, overlaps, or intersections.
  4. Join any broken paths using the Join Open Vectors tool (J).

5. Generate Multi-Axis Toolpaths

Because Aspire handles rotary unwrapping automatically based on the Job Type settings, standard 2D and 2.5D toolpaths (Profile, Pocket, V-Carve, or Fluting) will wrap around the cylindrical stock.

  1. Select your imported vectors and open the desired toolpath strategy.
  2. Set cut depths, feeds, speeds, and tooling.
  3. Calculate the toolpath and review it in the 3D View to verify the wrapped geometry.
  4. Save the toolpath using a dedicated rotary or multi-axis post-processor configured for your machine's controller (such as Mach3/4 Rotary, GRBL Rotary, or generic G-code Wrap post-processors converting Y or X into A-axis degrees).
