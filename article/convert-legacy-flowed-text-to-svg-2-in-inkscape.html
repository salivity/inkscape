Convert Legacy Flowed Text to SVG 2 in Inkscape

Legacy flowed text created in older versions of Inkscape relies on the non-standard <flowRoot> element, which often fails to render in web browsers and external SVG viewers. Modern Inkscape releases (version 1.0 and later) fully support SVG 2.0 text wrapping standards, using native <text> elements styled with attributes like inline-size or shape-inside. This guide explains how to identify legacy flowed text in your documents and convert it into fully compliant SVG 2.0 text objects without losing your typography formatting.

Why Legacy Flowed Text Fails

Older versions of Inkscape implemented an early draft of the SVG standard for text wrapping using <flowRoot>, <flowRegion>, and <flowPara> tags. Because the W3C ultimately dropped this draft, modern web browsers do not render <flowRoot> elements, leading to blank or invisible text when SVGs are viewed online.

SVG 2.0 resolves this by introducing standard text wrapping directly inside standard <text> elements using CSS properties like inline-size and white-space: pre.

Method 1: Using the Text Menu Conversion

The fastest native way to remove the obsolete <flowRoot> structure from an object is to use Inkscape's built-in text conversion tools.

  1. Select the legacy text object on your canvas using the Select Tool (S or F1). Look at the status bar at the bottom; it will read Flowed text... instead of Text....
  2. Navigate to the top menu and select Text > Convert to regular text.
  3. Inkscape will replace the <flowRoot> hierarchy with a standard <text> container and multiple <tspan> elements, placing line breaks manually.
  4. To turn this standard text into an SVG 2.0 auto-wrapping box, activate the Text Tool (T), click and drag the blue bounding handle at the top-right of the text block to establish an active wrapping width.

Method 2: Manual Migration to an SVG 2.0 Text Frame

If you need dynamic re-wrapping where text flows automatically based on a predefined frame width rather than fixed <tspan> lines, manually migrating to an SVG 2.0 text box is the cleanest approach.

  1. Select the legacy flowed text object and copy the text content (Ctrl+C / Cmd+C).
  2. Activate the Text Tool (T or F8).
  3. Instead of single-clicking the canvas, click and drag across the canvas to define a rectangular text frame. Inkscape 1.0+ automatically initializes this box as an SVG 2.0-compliant text object with an embedded inline-size property.
  4. Paste your copied text into this newly drawn box (Ctrl+V / Cmd+V).
  5. Select the original legacy flowed text object and press Delete.

Method 3: Flowing Text into an Arbitrary Shape

If your legacy text was flowed into an irregular shape (like a polygon or circle):

  1. Select the text and the boundary shape simultaneously using the Select Tool while holding Shift.
  2. Navigate to Text > Flow into Frame (Alt+W).
  3. In Inkscape 1.2 and later, this action writes SVG 2.0 compliant markup (shape-inside) rather than the outdated <flowRoot> element.

Verifying SVG 2.0 Compliance

To confirm that all legacy tags have been eliminated from your file:

  1. Open the XML Editor by going to Edit > XML Editor (Ctrl+Shift+X / Cmd+Shift+X).
  2. Search through the XML tree to verify there are no <svg:flowRoot> nodes remaining.
  3. Your compliant text will appear as an <svg:text> element containing a style attribute that includes white-space: pre; and an inline-size or shape-inside declaration.
  4. Save your file as a standard Plain SVG via File > Save As... to ensure maximum compatibility across all web rendering engines.
