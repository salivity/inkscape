How to Backup Inkscape Palettes, Templates, and Brushes

Backing up your custom settings in Inkscape ensures you never lose personalized workflows, unique color swatches, custom document setups, or reusable brush assets. This guide explains how to locate your Inkscape user profile directory across different operating systems, identify the exact folders containing your custom palettes, templates, and brush-related assets, and safely copy them to an external or cloud storage location for easy restoration.

Step 1: Locate Your Inkscape User Directory

The easiest way to find where Inkscape stores your custom files is directly inside the application:

  1. Open Inkscape.
  2. Go to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left sidebar, click on System.
  4. Look for the User data or User config path.
  5. Click the Open button next to the path to directly open the folder in your file manager.

Alternatively, you can manually navigate to the default paths:

  • Windows: C:\Users\<YourUsername>\AppData\Roaming\inkscape
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape (or ~/.config/inkscape)
  • Linux: ~/.config/inkscape

Step 2: Identify the Specific Asset Folders

Inside your Inkscape user directory, you will find dedicated subfolders for each custom asset type:

  • Palettes (/palettes): Contains your custom .gpl (GIMP Palette) files used for color sets.
  • Templates (/templates): Contains custom .svg files that load when you choose a template or launch a new document.
  • Brushes and Symbols (/symbols, /paint or /markers): Inkscape uses vector shapes and patterns for brushes (such as Pattern along Path assets) and symbol libraries. Custom symbols and vector markers are saved here.
  • Extensions (/extensions): Contains any custom scripts, tools, or brush add-ons you have installed.

Step 3: Copy and Backup the Folders

  1. Close Inkscape completely to prevent file-locking issues.
  2. Select the palettes, templates, symbols, and extensions folders. Alternatively, copy the entire parent inkscape user folder to preserve all user configurations, keyboard shortcuts, and UI settings at once.
  3. Copy these folders to a safe destination, such as an external hard drive, USB flash drive, or a cloud backup service (e.g., Google Drive, Dropbox, OneDrive).
  4. (Optional) Compress the copied folders into a .zip archive labeled with the date and Inkscape version for organized record-keeping.

Step 4: How to Restore Your Backup

To restore your custom items on a new computer or after a fresh installation:

  1. Install and launch Inkscape once so it generates default configuration folders, then close it.
  2. Open the user directory via Preferences > System (or manual path navigation).
  3. Paste your backed-up palettes, templates, symbols, and extensions folders into the user directory, replacing or merging with existing folders.
  4. Restart Inkscape to access your custom tools and presets.
