How to Create Multi-Page Documents in Inkscape

Starting with version 1.2, Inkscape includes a native Page Tool that allows users to create, manage, and export multi-page documents seamlessly within a single file. This guide explains how to use the Page Tool to add new pages, adjust page dimensions, rearrange page layouts, and export the entire project into a standard multi-page PDF.

1. Select the Page Tool

Open your project in Inkscape. In the left-hand toolbox, click the Page Tool icon (located near the bottom of the toolbar) or press the keyboard shortcut Shift + X. This mode activates page-editing controls on the canvas and top toolbar.

2. Add New Pages

Once the Page Tool is active, you can add pages using two methods:

  • Toolbar Button: Click the Create a new page button in the tool controls bar at the top to add a new page adjacent to the existing one.
  • Click and Drag: Click and drag anywhere on the canvas to draw a custom-sized page manually.

3. Adjust Page Size and Orientation

With the Page Tool selected, click on any page to make it active. Use the top control bar to adjust its properties:

  • Presets: Choose standard sizes such as A4, US Letter, or custom dimensions from the dropdown menu.
  • Orientation: Toggle between portrait and landscape modes using the orientation buttons.
  • Margins: Define custom margins directly in the numerical input fields.

4. Move and Rearrange Pages

You can manage the layout of your pages directly on the workspace:

  • Repositioning: Click and drag inside a page border to move it around the canvas.
  • Moving Content with Pages: Ensure the Move overlapping objects toggle in the top bar is enabled if you want artworks on a page to move alongside the page boundary.
  • Deleting Pages: Select a page and press the Delete key or click the trash icon on the control bar.

5. Export to a Multi-Page PDF

To compile your work into a single document:

  1. Go to File > Save As... or File > Export....
  2. Set the file format to Portable Document Format (*.pdf).
  3. In the PDF export options dialog, ensure the setting for exporting all pages is selected.
  4. Click Save to generate the final multi-page PDF document.
