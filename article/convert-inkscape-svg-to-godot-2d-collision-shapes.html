Convert Inkscape SVG to Godot 2D Collision Shapes

This guide explains how to convert vector artwork created in Inkscape into functional 2D collision shapes within Godot Engine. By preparing vector paths properly in Inkscape and using Godot's automatic collision generation tools or custom script parsing, you can rapidly create accurate CollisionPolygon2D nodes for your physics bodies without manually placing points.

Step 1: Prepare the Artwork in Inkscape

To ensure Godot can interpret your shapes correctly, the vector paths must be clean, closed, and standardized:

  1. Select your artwork and convert all objects into paths by selecting Path > Object to Path (Shift + Ctrl + C).
  2. If your shape consists of multiple overlapping elements, combine them into a unified silhouette using Path > Union (Ctrl + +).
  3. Ensure the path is closed. Open paths will cause unpredictable collision boundaries.
  4. Reduce unnecessary points by using Path > Simplify (Ctrl + L). High vertex counts negatively impact physics performance in Godot.
  5. Set the page border tightly around your artwork using File > Document Properties > Resize to content.
  6. Save the file using File > Save As... and choose Plain SVG (*.svg) instead of the default Inkscape SVG to remove proprietary metadata.

Step 2: Import into Godot

  1. Drag and drop the Plain SVG file into your Godot project's FileSystem dock.
  2. Select the SVG in the FileSystem dock and inspect the Import tab.
  3. Keep the default import settings (Texture2D) and click Reimport.

Step 3: Generate the Collision Shape (Native Method)

The fastest way to generate a CollisionPolygon2D from an SVG in Godot is through the Sprite2D editor tool:

  1. Create a scene with a physics node, such as a RigidBody2D, CharacterBody2D, or StaticBody2D.
  2. Add a Sprite2D node as a child of the physics body and assign your imported SVG to its Texture property.
  3. Select the Sprite2D node in the Scene tree.
  4. In the top toolbar of the 2D viewport, click the Sprite2D menu.
  5. Select Create CollisionPolygon2D Sibling.
  6. A dialog box will appear with generation settings:
    • Simplification: Controls how aggressively the path is simplified. Higher values reduce node counts for better performance; lower values maintain tighter geometric accuracy.
    • Shrink (Pixels): Offsets the generated boundary inward or outward.
  7. Click Create CollisionPolygon2D.

Godot will generate a new CollisionPolygon2D sibling node with its polygon property automatically populated with the vertices matching the silhouette of your SVG artwork.

Step 4: Alternative Method Using Direct Vector Data

If you require mathematical precision rather than bitmap-traced vertices, you can parse the raw SVG data via GDScript:

  1. Read the SVG file as text using FileAccess.
  2. Parse the XML tags to locate the <path> elements and their d attributes.
  3. Convert the SVG coordinate commands (M, L, C, Z) into a PackedVector2Array.
  4. Assign this array directly to a CollisionPolygon2D.polygon property via code during runtime or within a @tool script in the editor.
