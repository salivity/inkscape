Inkscape Neon Glow Filter Using feMerge

This guide demonstrates how to build a vibrant neon glow effect in Inkscape using the built-in Filter Editor. By cascading multiple feGaussianBlur primitives with varying blur radii and compositing them over one another using an feMerge node, you can produce a realistic light-bleed effect featuring an intense core, a bright mid-range halo, and a diffuse ambient glow.

Understanding the Glow Architecture

A convincing neon effect relies on light falloff. A single blur looks flat or muddy. By stacking three distinct layers of blur plus the original sharp stroke, you replicate optical light dispersion:

  1. Source Graphic: The white-hot, sharp core of the neon tube.
  2. Inner Glow: A narrow, high-opacity blur for intense brightness near the source.
  3. Mid Glow: A moderate blur creating the primary saturated color emission.
  4. Outer Glow: A wide, soft blur simulating ambient atmospheric light.

The feMerge primitive acts as a compositor, accepting multiple filter outputs as feMergeNode inputs and flattening them in a bottom-to-top rendering order.

Step-by-Step Filter Construction in Inkscape

1. Open the Filter Editor

  1. Select the vector path or text you wish to stylize. For authentic neon, give it a bright stroke (e.g., #00FFFF or #FF0055) and set the stroke width between 2px and 6px.
  2. Navigate to Filters > Filter Editor in the top menu to open the filter management panel.

2. Create the Filter Container

  1. In the Filter Editor panel, click New at the bottom left.
  2. Double-click the default name (e.g., filter1) and rename it to NeonGlow.
  3. Check the box next to NeonGlow while your vector object is selected to apply the blank filter to it.

3. Add the Blur Primitives

Add three Gaussian Blur primitives to create the three glow tiers:

  1. Select Gaussian Blur from the primitive dropdown menu and click Add Primitive.
  2. Repeat this process two more times so you have three Gaussian Blur items listed under Effect.
  3. Connect the input of each Gaussian Blur to the Source Graphic by dragging the input connection triangle of each blur layer to the Source Graphic row.

4. Configure Blur Radii

Select each blur primitive individually and adjust the Standard Deviation slider in the lower pane:

  • Blur 1 (Inner core): Set standard deviation to approximately 1.5 (X and Y).
  • Blur 2 (Mid halo): Set standard deviation to approximately 5.0.
  • Blur 3 (Outer aura): Set standard deviation to approximately 15.0 to 20.0.

5. Assemble the Layers with feMerge

  1. Select Merge from the primitive dropdown and click Add Primitive.
  2. Expand the Merge item if necessary. It requires four inputs to assemble the full effect.
  3. In Inkscape's interface, drag a connection from each individual input connector of the Merge node to your layers in the following sequence:
    • Input 1: Connect to Blur 3 (the widest, softest blur at the bottom).
    • Input 2: Connect to Blur 2 (the mid-range halo).
    • Input 3: Connect to Blur 1 (the tight inner glow).
    • Input 4: Connect to Source Graphic (the crisp original vector on top).

If the Merge primitive does not display enough connection points by default, adding another sub-node inside the merge stack creates an additional input handle.

Underlying SVG Definition

For users inspecting the XML Editor (Shift + Ctrl + X), the resulting filter definition inside the <defs> element translates to the following structure:

<filter id="NeonGlow" x="-50%" y="-50%" width="200%" height="200%">
  <feGaussianBlur in="SourceGraphic" stdDeviation="1.5" result="blur_tight"/>
  <feGaussianBlur in="SourceGraphic" stdDeviation="5.0" result="blur_mid"/>
  <feGaussianBlur in="SourceGraphic" stdDeviation="18.0" result="blur_wide"/>
  <feMerge>
    <feMergeNode in="blur_wide"/>
    <feMergeNode in="blur_mid"/>
    <feMergeNode in="blur_tight"/>
    <feMergeNode in="SourceGraphic"/>
  </feMerge>
</filter>

Tuning and Bounding Box Adjustments

  • Preventing Clipped Edges: Large blurs often exceed Inkscape's default filter region, causing boxy edges. Select the filter in the Filter Editor, open the Filter General Settings tab, and increase the Coordinates dimensions (e.g., set X, Y to -50% and Width, Height to 200%).
  • White-Hot Center Core: To mimic intense gas discharge, make your object's fill or stroke pure white (#FFFFFF). The wide and mid-range blurs will capture the underlying color tone if color matrix primitives are added, or you can use a duplicate colored path directly underneath the white source stroke.
