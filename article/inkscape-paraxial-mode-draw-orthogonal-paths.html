Inkscape Paraxial Mode: Draw Orthogonal Paths

Inkscape’s Bezier Pen tool features a specialized Paraxial mode designed specifically for creating strictly orthogonal paths composed solely of horizontal and vertical line segments. This guide explains how to activate Paraxial mode, control path directions on the canvas, and cleanly finish orthogonal shapes without relying on manual angle constraints.

1. Select the Bezier Tool

Open your Inkscape project and select the Draw Bezier curves and straight lines tool from the left-hand toolbox, or press the keyboard shortcut B (or Shift + F6).

2. Enable Paraxial Mode

Once the Bezier tool is active, look at the Tool Controls bar directly above the main canvas. Locate the Mode section, which contains several icons for path types. Click the icon representing Create a sequence of paraxial line segments (represented by a series of connected 90-degree right-angle lines).

3. Draw Orthogonal Segments

With Paraxial mode enabled, start creating your path on the canvas:

  • Place the start point: Left-click once anywhere on the canvas.
  • Add segments: Move your mouse cursor. The tool automatically snaps the active preview line to strictly horizontal or vertical orientations. Left-click to place intermediate nodes.
  • Toggle direction: By default, the tool alternates between horizontal and vertical segments. If the tool starts moving in the wrong orientation, press the Shift key while moving the mouse to toggle the primary axis direction between vertical and horizontal.

4. Finish the Path

To complete your orthogonal drawing:

  • Press Enter or right-click anywhere on the canvas to leave the path open.
  • Alternatively, hover over the original starting node until it highlights and left-click it to close the path into a complete shape.
