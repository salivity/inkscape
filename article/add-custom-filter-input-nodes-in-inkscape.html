Add Custom Filter Input Nodes in Inkscape

This guide explains how to add and connect custom filter input nodes using the Filter Editor dialog in Inkscape. By routing inputs such as the source graphic, background image, or previous primitive outputs into specific filter effects, you can create advanced, multi-layered SVG filter effects directly on the canvas.

1. Open the Filter Editor Dialog

To access the interface:

  1. Open your document in Inkscape.
  2. Go to the top menu bar and select Filters > Filter Editor.
  3. A docked panel named Filter Editor will appear in your workspace.

2. Create and Assign a Filter

Before adding input nodes, you must have an active filter applied to a target object:

  1. Select an object on your canvas.
  2. In the Filter Editor panel, click the New button at the bottom of the filter list.
  3. Check the box next to the newly created filter to assign it to your selected object.

3. Add Filter Primitives

Filter input nodes belong to individual effect components called "primitives" (such as Gaussian Blur, Composite, Blend, or Offset):

  1. In the drop-down menu at the bottom of the Filter Editor, choose the primitive you want to use (for example, Composite or Blend).
  2. Click Add Primitive. The effect appears in the primitive list in the center column.

4. Locate the Input Connection Nodes

In the Filter Editor, the connection area is located between the standard inputs column (on the left) and the primitive list:

  • Standard Source Nodes (Left Column): These represent global inputs:
    • Source Graphic: The original color and opacity of the selected object.
    • Source Alpha: Only the opacity mask of the selected object.
    • Background Image: The canvas content beneath the object.
    • Background Alpha: The opacity mask of the underlying canvas content.
    • Fill Paint / Stroke Paint: The solid color, gradient, or pattern assigned to the object's fill or stroke.
  • Primitive Input Nodes (Connection Rows): Each primitive in your list has one or more input connection points displayed as small triangular handles extending to the left. Single-input effects like Gaussian Blur have one node, while dual-input effects like Composite have two.

5. Connect and Route Custom Input Nodes

To route an input into a specific primitive:

  1. Click and hold the triangular input handle on the left side of your target primitive.
  2. Drag the connection line toward the desired input source:
    • Connect to a Global Source: Drag the line all the way to one of the standard inputs in the far-left column (e.g., Source Graphic or Background Image).
    • Connect to Another Primitive: Drag the line to the output of an existing primitive higher in the list to chain multiple effects together.
  3. Release the mouse button to secure the connection.

6. Managing Multi-Input Primitives

For primitives like Composite or Blend, which require two distinct inputs (Input 1 and Input 2):

  1. Drag the top triangular handle to your primary visual source (e.g., the output of an Offset or Blur primitive).
  2. Drag the bottom triangular handle to your secondary source (e.g., the original Source Graphic).
  3. Select the primitive to adjust its parameters in the lower settings pane (e.g., switching the Composite operator to Over, In, Out, or Arithmetic).

To disconnect or reroute any node, click and drag the triangular handle away from its current connection and release it onto a different source.
