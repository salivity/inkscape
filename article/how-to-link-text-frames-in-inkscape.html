How to Link Text Frames in Inkscape

Inkscape allows you to handle overflowing text by flowing a single text block across multiple shapes or frames in a specific sequence. This guide outlines how to prepare your text and container shapes, link them together using the "Flow into Frame" command, adjust the flow order, and detach frames when necessary.

1. Create Your Text and Containers

First, create the text and the shapes that will hold it:

  • Use the Text tool (press T) to click on the canvas and type or paste your full body of text. At this stage, it does not matter if the text extends far beyond the canvas.
  • Use the Rectangle tool (press R) or any other shape tool to draw two or more shapes representing the columns or frames where you want your text to appear.

2. Flow Text Into the Linked Frames

Inkscape links frames based on the order in which the shapes are selected:

  1. Select the Selection tool (press S or F1).
  2. Click on your text object.
  3. Hold down the Shift key and click your first container shape.
  4. Continue holding Shift and click the second container shape, followed by any subsequent shapes in the exact order you want the text to flow.
  5. Go to the top menu and select Text > Flow into Frame (or press Alt + W).

The text will immediately enter the first shape. When the first shape is filled, the remaining text will automatically overflow into the next selected shape in the sequence.

3. Adjusting Containers and Text

After the text is linked, the shapes remain fully dynamic:

  • You can resize or move any of the container frames independently using the Selection tool; the text will automatically redistribute across all linked shapes in real time.
  • If you edit the text using the Text tool, the overflow will dynamically advance or retract through the chain of frames.
  • To add an additional frame later, select the flowed text along with the new shape while holding Shift, and run Text > Flow into Frame again.

4. Unlinking Frames

If you want to revert the text back to a standard, unlinked text object:

  1. Select the flowed text object.
  2. Go to the top menu and select Text > Unflow (or press Shift + Alt + W).

The text will revert to a single, continuous line or block, and the shapes will return to empty path objects.
