Cut a Hole in a Shape Using Inkscape Combine

Cutting an interior hole out of a shape in Inkscape allows you to create complex composite paths, such as rings, frames, or letterforms, while keeping them as a single editable vector object. Although the Difference tool is commonly used for subtraction, the Combine command creates a compound path where overlapping paths can interact to form negative space. This guide outlines the exact steps to place an inner shape inside an outer shape and utilize the Combine feature along with proper fill rules to cut out an interior hole.

Step 1: Create and Convert the Shapes

  1. Use the shape tools (such as the Rectangle or Circle tool) to draw your primary outer shape on the canvas.
  2. Draw the smaller shape that will serve as the interior cutout.
  3. If you created these using the parametric shape tools, convert them to standard vector paths by selecting each shape and navigating to Path > Object to Path (or pressing Shift + Ctrl + C).

Step 2: Position the Shapes

  1. Select the inner shape and place it directly over the outer shape where you want the hole to appear.
  2. If precise alignment is required, select both objects, open the Align and Distribute panel (Shift + Ctrl + A), and use the center alignment options to position the inner shape accurately.

Step 3: Combine the Paths

  1. With the Select tool (S), select both the outer shape and the inner shape simultaneously by clicking and dragging over them, or by holding Shift and clicking each one.
  2. Go to the top menu and select Path > Combine (or press Ctrl + K).

Step 4: Adjust the Fill Rule (If the Hole Does Not Appear)

Depending on your default path settings, the combined object may still appear solid instead of showing a cutout. If this occurs, you need to adjust the path's fill rule:

  1. Select the combined path and open the Fill and Stroke dialog (Shift + Ctrl + Y).
  2. In the Fill tab, locate the Fill rule toggle buttons at the top right of the fill controls (represented by two overlapping circle icons).
  3. Switch the fill rule from Non-Zero to Even-Odd. This rule automatically turns any overlapping interior area into a transparent hole.
  4. Alternatively, if you want to keep the Non-Zero fill rule, select only the inner sub-path using the Node tool (N), click a node on the inner path, and go to Path > Reverse. Changing the winding direction of the inner path creates the cutout under the non-zero rule.
