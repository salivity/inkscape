Create Voronoi Mosaic Textures in Inkscape

This guide explains how to generate procedural mosaic and stained-glass textures in Inkscape using the built-in Voronoi Pattern extension. By generating randomized mathematical cells across a shape or canvas, you can quickly produce organic geometric backgrounds, low-poly aesthetics, and tiled patterns without manually drawing individual segments.

Step 1: Create a Base Shape

  1. Open Inkscape and select the Rectangle tool (R) or Circles tool (E).
  2. Draw a shape on the canvas that matches the size of the area where you want the mosaic pattern to appear.
  3. Keep the shape selected.

Step 2: Open the Voronoi Pattern Tool

  1. Navigate to the top menu and select Extensions > Generate from Path > Voronoi Pattern... (or Voronoi Diagram... depending on your Inkscape version).
  2. A dialog window will appear with configurable parameters for generating the procedural cells.

Step 3: Configure the Pattern Settings

  • Number of cells / points: Increase this value for a denser, smaller mosaic tile look, or decrease it for larger, low-poly fragments.
  • Pattern type: Choose between Voronoi (which creates polygonal cells) and Delaunay (which creates triangular meshes). For a classic mosaic, select Voronoi.
  • Cell spacing / Border: Adjust the line thickness setting if you want clear separation between tiles to emulate grout or stained-glass lead lines.
  • Check the Live Preview box to see real-time updates as you adjust values.
  • Click Apply, then Close.

Step 4: Colorize and Style the Mosaic

  1. Select the generated Voronoi object and ungroup it by pressing Ctrl + Shift + G (or Cmd + Shift + G on macOS).
  2. Manual Coloring: Select individual cells with the Select tool (S) and assign different fills using the color palette.
  3. Randomized Shading: Select all cells, go to Extensions > Color > Randomize..., and adjust Hue, Saturation, or Lightness ranges to procedurally color the entire mosaic.
  4. Grout/Borders: Select all cells, open the Fill and Stroke panel (Ctrl + Shift + F), set a solid Stroke paint (such as dark gray or white), and adjust the Stroke width to define the tile boundaries.

Step 5: Mask or Clip to Specific Shapes

If you need the pattern confined inside a specific boundary:

  1. Place your target shape directly above the grouped Voronoi pattern.
  2. Select both the Voronoi group and the target shape.
  3. Go to Object > Clip > Set Clip.
