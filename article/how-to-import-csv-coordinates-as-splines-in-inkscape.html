How to Import CSV Coordinates as Splines in Inkscape

This guide demonstrates how to import a CSV list of X and Y coordinates into Inkscape to generate smooth, continuous spline contours. While Inkscape lacks a native one-click CSV importer, you can quickly achieve this by formatting your coordinate data into SVG path syntax, inserting it via Inkscape's built-in XML Editor, and applying the BSpline path effect to create continuous contours.

Step 1: Format the CSV Data into SVG Path Syntax

Inkscape stores vector shapes as SVG <path> elements using the d attribute. To make Inkscape understand your points, format your coordinate list into an SVG path string.

  1. Open your CSV file in a spreadsheet program (such as Microsoft Excel or Google Sheets) or a text editor. Ensure your X coordinates are in Column A and your Y coordinates are in Column B.
  2. In Column C, generate the SVG path commands using a formula.
    • For the first row (the starting point), use: ="M " & A1 & "," & B1
    • For all subsequent rows, use: ="L " & A2 & "," & B2
    • (Optional) If your contour is a closed loop, append Z to the final coordinate.
  3. Drag the formula down to cover all coordinates.
  4. Copy the entire Column C output and paste it into a plain text editor to concatenate it into a single text string (e.g., M 10,20 L 15,25 L 20,40...).

Step 2: Insert the Path into Inkscape

  1. Open Inkscape and create a new document.
  2. Open the XML Editor by navigating to Edit > XML Editor or pressing Ctrl + Shift + X.
  3. In the XML tree on the left, select the active layer (usually labeled <svg:g id="layer1">).
  4. Click the New element node icon at the top of the XML Editor, enter svg:path as the node name, and click Create.
  5. Select the newly created svg:path node. In the right-hand panel, find the Attribute name field, type d, and paste your concatenated coordinate string into the Attribute value field.
  6. Click Set (or press Ctrl + Enter).
  7. Add a stroke so the path is visible: set the style attribute to stroke:#000000;stroke-width:1;fill:none; and click Set.

Your coordinates will now appear on the canvas as a connected polyline.

Step 3: Convert the Polyline to a Continuous Spline

  1. Select your imported path using the Selector Tool (S).
  2. Open the Path Effects panel by navigating to Path > Path Effects.
  3. Click the Add Path Effect button (+).
  4. Search for and select BSpline (or Spiro Spline for mechanical curves).
  5. The sharp polyline segments will instantly convert into a smooth, continuous spline contour governed by your original coordinate points.
  6. To make the curve permanent, select Path > Object to Path (Ctrl + Shift + C).
