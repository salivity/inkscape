How to Add Custom XML Attributes in Inkscape

Adding custom XML attributes to objects in Inkscape allows you to attach metadata, integrate custom data for web development (such as data-* attributes for JavaScript), and prepare SVGs for interactive applications. This guide provides a straightforward walkthrough on using Inkscape’s built-in XML Editor to insert, modify, and manage custom attributes on any vector element.

Step 1: Open the XML Editor

  1. Launch Inkscape and open your SVG document.
  2. Open the XML Editor dialog by using the keyboard shortcut:
    • Windows/Linux: Ctrl + Shift + X
    • macOS: Cmd + Shift + X
  3. Alternatively, navigate to the top menu and select Edit > XML Editor.

Step 2: Select the Object

  1. Choose the Select and transform objects tool (keyboard shortcut: S or F1).
  2. Click on the object on your canvas that requires the custom attribute.
  3. The XML Editor panel will automatically highlight the corresponding XML element (such as <svg:path>, <svg:rect>, or <svg:g>).

Step 3: Enter the Custom Attribute

  1. In the XML Editor panel, locate the two input fields at the bottom (or side, depending on your layout):
    • Attribute name: Enter the name of your custom attribute (for example, data-id, class, or custom-tag).
    • Attribute value: Enter the corresponding value you want to assign to this attribute.
  2. Click the Set button (or press Enter while in the value field) to apply the attribute to the selected node.

Step 4: Verify and Save

  1. Look at the attribute list for the selected element in the XML Editor to confirm that your new attribute name and value are displayed.
  2. Save your file by going to File > Save or pressing Ctrl + S (Cmd + S on macOS). Choose Plain SVG or Inkscape SVG depending on whether you want to strip Inkscape-specific metadata while keeping standard and custom XML attributes.

Tips for Custom Attributes

  • HTML/Web Compatibility: When adding attributes meant to be targeted by CSS or JavaScript, use standard HTML5 data-* prefixes (e.g., data-tooltip="Information").
  • Editing Values: To update an existing attribute, click on the attribute name in the XML list, modify the value in the text box below, and click Set.
  • Removing Attributes: Select the attribute from the list and click the Delete attribute icon (the red 'X' or minus icon) at the top of the XML Editor panel.
