Import ArcGIS Geological Cross-Sections to Inkscape

This guide outlines the complete workflow for transferring vector geological cross-sections from ArcGIS into Inkscape to prepare publication-ready figures. By properly exporting vector formats from ArcGIS, configuring Inkscape’s import settings, and cleaning up layered geometry, geoscientists can efficiently refine fills, structural contacts, line weights, and typography without loss of spatial resolution or vector precision.

1. Prepare and Export the Cross-Section from ArcGIS

Whether using ArcMap or ArcGIS Pro, the data must be exported as a vector format to preserve editable points, lines, and polygons.

  1. Isolate Vector Elements: Open your cross-section layout. Turn off or remove background raster layers, hillshades, or aerial imagery that may force the export engine to rasterize the entire document.
  2. Standardize Symbology: Set solid fills for your geological formations. Avoid complex, semi-transparent procedural fills within ArcGIS, as these often rasterize upon export. Standard solid colors or basic hatch lines convert most reliably.
  3. Export Settings (ArcGIS Pro):
    • Navigate to Share > Export Layout.
    • Set the File Type to PDF (preferred for vector stability) or SVG.
    • Under the Vector resolution settings, set the DPI to at least 300 (600 DPI is recommended for thin fault lines and intricate contacts).
    • Check Embed fonts to avoid font substitution.
    • Under the Advanced tab, ensure Layers and attributes are preserved and set Georeference information according to preference (usually unnecessary for static publication figures).
    • Ensure Output to Continuous Tone is unchecked to prevent rasterization of vector features.

2. Import the File into Inkscape

  1. Launch Inkscape and go to File > Open (or File > Import if adding to an existing document template).
  2. Select your exported PDF or SVG file.
  3. If importing a PDF, the PDF Import Settings dialog will appear:
    • Select the Internal import engine for better font handling and path fidelity.
    • Check Replace PDF fonts by closest-named installed fonts if you plan to edit typography directly.
    • Set the precision to high to ensure complex stratigraphic contacts retain their coordinate precision.
  4. Click OK.

3. Ungroup and Clean Up Clipping Masks

ArcGIS exports typically nest paths inside multiple nested groups and clipping paths, which must be cleared before editing individual geological units.

  1. Release Clipping Masks: Select the imported illustration, right-click, and choose Set Clip > Release (or Object > Clip > Release). Delete the boundary bounding boxes that ArcGIS automatically creates.
  2. Ungroup Elements: Select the cross-section and press Ctrl + Shift + G (Windows/Linux) or Cmd + Shift + G (macOS) repeatedly until the status bar displays that no groups remain, or until objects are separated into distinct paths.
  3. Remove Unwanted Artifacts: ArcGIS frequently exports tiny, invisible filler polygons or duplicate boundary lines. Use the Edit paths by nodes tool (N) or the Objects panel to identify and delete duplicate boundary strokes along unit contacts.

4. Organize Geological Layers

To streamline figure assembly, organize your cross-section components into logical Inkscape layers:

  1. Open the Layers and Objects dock (Ctrl + Shift + L).
  2. Create distinct layers: Annotations/Labels, Structural Lines (Faults/Folds), Contacts, Geological Units (Fills), and Grid/Exaggeration Frame.
  3. Select your elements on the canvas and move them to their respective layers by right-clicking and selecting Move to Layer.

5. Finalize for Publication

  1. Apply Standard Geologic Patterns: Replace solid color fills with standard FGDC or USGS lithologic patterns using Inkscape's Path > Fill and Stroke > Pattern Fill menu.
  2. Adjust Stroke Weights: Set uniform line weights according to your target journal's specifications (e.g., 0.75 pt for faults, 0.35 pt for depositional contacts, 0.25 pt for grid tics).
  3. Format Text: Update unit labels, structural dip indicators, and scale bars using vector-friendly fonts (such as Arial or Helvetica) sized between 6 pt and 10 pt.
  4. Export: Go to File > Save As to save an editable native .svg master, then use File > Export to generate publication-grade PDF, EPS, or 300+ DPI TIFF figures.
