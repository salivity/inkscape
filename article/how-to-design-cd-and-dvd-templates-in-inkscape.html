How to Design CD and DVD Templates in Inkscape

This guide provides a comprehensive walkthrough for creating accurate, custom templates for standard CD/DVD jewel case covers, tray inserts, and disc labels using Inkscape. By following these steps, you will learn the exact standard dimensions, how to configure precise guides and bleed areas, how to organize your layers for seamless artwork design, and how to save your files as reusable templates for future print projects.

1. Set Up the Inkscape Document

  1. Open Inkscape and create a new document.
  2. Open the Document Properties dialog by pressing Shift + Ctrl + D (or going to File > Document Properties).
  3. Under the Display tab, change the Display units to Millimeters (mm) or Inches (in) for standard physical printing accuracy.
  4. Set the Page size to match the specific component you are designing or choose a standard sheet size (such as A4 or US Letter) if you plan to print multiple elements on a single page.

2. Standard Dimensions Reference

Use the following standard measurements when creating your shapes:

  • CD Jewel Case Front Cover: 120 mm × 120 mm (Single panel) or 242 mm × 120 mm (Two-panel bi-fold including fold line at 121 mm).
  • CD Jewel Case Back Tray Insert: 150 mm × 118 mm total.
    • Left Spine: 6 mm
    • Main Back Area: 138 mm
    • Right Spine: 6 mm
  • CD/DVD Disc Label (Standard):
    • Outer Diameter: 116 mm to 120 mm
    • Inner Hub Hole: 15 mm (small hole) or 40 mm (wide stacked ring)
  • Standard DVD Keep Case Cover: 273 mm × 183 mm (Front: 129.5 mm, Spine: 14 mm, Back: 129.5 mm).

3. Create the Front Cover Template

  1. Select the Rectangle Tool (R) and click on the canvas.
  2. In the top toolbar, enter the width (120 mm) and height (120 mm).
  3. Open the Fill and Stroke panel (Shift + Ctrl + F). Set the Fill to none and give the Stroke a thin black or blue outline (e.g., 0.2 mm).
  4. Add a Bleed Area (standard 3 mm on all sides) to avoid white edges after trimming:
    • Create another rectangle sized 126 mm × 126 mm.
    • Center both rectangles using the Align and Distribute panel (Shift + Ctrl + A).
  5. Add internal Safety Margins (3 mm to 5 mm inside the cut line) by placing guides to ensure text and critical graphics do not get cut off.

4. Create the Back Tray Card Template

  1. Draw a rectangle sized 150 mm × 118 mm.
  2. To create the spine fold lines:
    • Drag a vertical guide from the left ruler to the 6 mm mark.
    • Drag another vertical guide to the 144 mm mark.
  3. Draw text boxes on the 6 mm spine sections, rotate the text 90 degrees or 270 degrees (Object > Rotate 90° CW/CCW), and center the text within each spine zone.

5. Create the Disc Surface Label Template

  1. Select the Circles and Ellipses Tool (E).
  2. Hold Ctrl while clicking and dragging to create a perfect circle.
  3. Set the circle’s dimensions in the top toolbar to 120 mm × 120 mm for the outer edge.
  4. Draw a second circle set to 15 mm × 15 mm (or 40 mm depending on your printable disc hub size).
  5. Select both circles, open the Align and Distribute panel, and click both Center on vertical axis and Center on horizontal axis.
  6. Set the stroke paint of both circles to a visible color and set the fill to none.

6. Structure Layers and Save as a Template

  1. Open the Layers and Objects panel (Shift + Ctrl + L).
  2. Rename the current layer to Template Guides.
  3. Create a new layer above it and name it Artwork.
  4. Lock the Template Guides layer by clicking its padlock icon so you do not accidentally move the layout lines while designing.
  5. Once complete, save the file as a default template by navigating to File > Save Template....
  6. Name the template (e.g., "Standard CD Jewel Case"), enter a description, and check Set as default template if desired.

7. Exporting for Print

  1. Once your artwork is finalized on the Artwork layer, hide or delete the cut and fold guide lines that should not appear on the final print.
  2. Keep the artwork extending all the way out to the 3 mm bleed lines.
  3. Go to File > Save As... and select Portable Document Format (*.pdf).
  4. In the PDF export options dialog, ensure the output resolution is set to 300 DPI or higher for crisp print quality.
