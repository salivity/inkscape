Use Clone Original LPE for Linked Paths in Inkscape

This guide explains how to use the Clone Original Live Path Effect (LPE) in Inkscape to generate dynamic, linked duplicates of vector paths. Unlike standard clones, paths created with the Clone Original LPE inherit the underlying geometry of the source path while allowing you to apply independent fills, strokes, transforms, and secondary path effects. Following the steps below, you will learn how to set up the effect, link your paths, and manage reactive vector designs.

Standard Clones vs. Clone Original LPE

A standard clone in Inkscape (created with Alt + D) mirrors both the geometry and the styling (fill and stroke) of the parent object unless the parent is explicitly styled without fill and stroke. The Clone Original Live Path Effect operates strictly on path data. It allows a secondary path to read the node coordinates of a master path in real-time while maintaining complete freedom over styling, positioning, and additional modifiers.

Step-by-Step: Setting Up Clone Original LPE

1. Prepare the Master Path

  1. Select the tool of your choice (such as the Pen or Bezier tool) and draw your master shape.
  2. If your shape is a geometric primitive (circle, rectangle, star), convert it into a true path by selecting it and going to Path > Object to Path (Shift + Ctrl + C).
  3. Note the ID of this path in the Object Properties panel (Shift + Ctrl + O), or keep it selected to copy it.

2. Create the Secondary (Target) Path

  1. Draw any simple placeholder path on the canvas (such as a single line or small polygon). This object will adopt the master path's geometry.
  2. Select this target path.

3. Apply the Clone Original Effect

  1. Open the Path Effects dialog by going to Path > Path Effects.
  2. With the target path selected, click the + (Add Path Effect) button.
  3. Search for or select Clone original from the list.

4. Link the Target to the Master

There are two ways to establish the reactive link:

  • Method A (Clipboard): Select the master path and copy it (Ctrl + C). Select the target path, navigate to the Clone original options in the Path Effects panel, and click the Link to path on clipboard icon.
  • Method B (Picker): Select the target path. In the Clone original settings, click the Pick path (dropper/crosshair) icon, then click directly on the master path on your canvas.

Once linked, the target path will instantly reshape itself into an exact copy of the master path's geometry.

Customizing Linked Clones

Independent Styling

Because only the node data is linked, you can open the Fill and Stroke panel (Shift + Ctrl + F) on the target path to assign:

  • A different fill color, gradient, or pattern.
  • A different stroke width, color, or dash pattern.
  • Variable opacity and layer blend modes.

Transforming Clones Independently

By default, moving the master moves the geometry. In the Clone Original LPE panel, you can toggle behavior options depending on your version of Inkscape:

  • Allow transforms: Enable this setting to scale, rotate, or translate the clone independently across the canvas without breaking the node link to the original.

Stacking Path Effects

The Clone Original LPE can serve as the base for further procedural alterations:

  1. With the linked clone selected, open the Path Effects panel.
  2. Add a second effect, such as Offset, Power Stroke, or Pattern Along Path.
  3. The clone will update based on both the original path's geometry and the stacked modifiers applied locally.

Modifying the Geometry

To test the reactive link:

  1. Select the original master path.
  2. Switch to the Edit paths by nodes tool (N).
  3. Move, add, or delete nodes, or adjust curve handles.

Any geometric alterations made to the master will instantly render across all linked clones, maintaining your custom fills, strokes, and secondary path effects intact.
