How to Import Scribus CMYK Palette to Inkscape

This guide outlines the process of transferring CMYK color palettes from Scribus into Inkscape. Because Inkscape natively uses the GIMP Palette (.gpl) format rather than the native Scribus XML format, importing colors requires exporting or converting the palette data into a .gpl file and placing it inside Inkscape’s dedicated palette directory.

Step 1: Locate or Export the Scribus Palette

Scribus stores custom and predefined color swatches as .xml files.

  1. Open Scribus and navigate to Edit > Colors and Fills.
  2. Select the CMYK color set you wish to export from the Color Sets tab.
  3. If using custom colors, click Save to export the set as a Scribus .xml file to a known location on your computer.

Step 2: Convert the Palette to GPL Format

Inkscape reads color palettes using the .gpl (GIMP Palette) plain-text format. To make your Scribus palette compatible:

  1. Use an Automated Converter: Use a free web-based palette converter (such as tools that convert Scribus XML to GIMP GPL) or a Python script to convert the .xml file to .gpl.
  2. Manual Creation (for small palettes): Open a text editor and format the file as follows: 
    GIMP Palette
Name: Scribus CMYK Import
Columns: 4
#
R   G   B   Color Name
    Replace R G B with the converted RGB values corresponding to your Scribus CMYK colors, followed by the color name, and save the file with the extension .gpl.

Step 3: Place the Palette in the Inkscape Directory

Move your newly created .gpl file into the Inkscape user configuration folder based on your operating system:

  • Windows: C:\Users\<Username>\AppData\Roaming\inkscape\palettes
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes
  • Linux: ~/.config/inkscape/palettes

(Note: If the palettes folder does not exist inside the Inkscape directory, create it manually.)

Step 4: Activate the Palette in Inkscape

  1. Launch or restart Inkscape.
  2. Open the Swatches dialog by pressing Shift + Ctrl + W or going to View > Swatches.
  3. Click the small arrow menu (hamburger icon) on the right side of the palette bar at the bottom of the window, or inside the Swatches panel.
  4. Locate and select your imported Scribus palette from the list.

Step 5: Configure CMYK Color Management in Inkscape

Inkscape operates natively in RGB space, but it can manage CMYK swatches accurately using ICC color profiles:

  1. Go to File > Document Properties > Color.
  2. Under Available Color Profiles, link the identical CMYK ICC profile used in your Scribus project (such as Coated FOGRA39 or US Web Coated SWOP).
  3. When selecting colors from the imported palette, Inkscape will properly map the display values to match your Scribus print output.
