Generate Involute Spur Gears Using Inkscape Scripts

This article outlines how to generate mathematically accurate involute spur gear tooth profiles in Inkscape using internal parametric tools, native extensions, and custom Python scripts. By translating the core geometric formulas of involute curves into SVG paths, designers can produce mechanically functional gears suitable for laser cutting, 3D printing, and digital fabrication.

Core Mathematical Formulas of the Involute Curve

An involute curve represents the path traced by a point on a taut string unwinding from a cylinder (the base circle). To construct an accurate tooth flank, scripts calculate coordinates relative to the base circle radius (\(r_b\)) and the pressure angle (\(\alpha\), typically 14.5° or 20°).

The standard parametric equations for an involute curve in Cartesian coordinates are:

  • \(x(t) = r_b \cdot (\cos(t) + t \cdot \sin(t))\)
  • \(y(t) = r_b \cdot (\sin(t) - t \cdot \cos(t))\)

Where \(t\) represents the roll angle in radians. Key gear dimensions must be derived prior to plotting:

  • Pitch Diameter (\(D\)): \(D = m \cdot N\) (where \(m\) is the module and \(N\) is the number of teeth)
  • Base Circle Diameter (\(D_b\)): \(D_b = D \cdot \cos(\alpha)\)
  • Addendum Diameter (\(D_a\)): \(D_a = D + 2m\)
  • Dedendum Diameter (\(D_d\)): \(D_d = D - 2.5m\)

Method 1: Using the Parametric Curves Function

Inkscape includes a mathematical plot engine that creates vector paths based on parametric formulas without requiring external development tools.

  1. Navigate to Extensions > Render > Parametric Curves.
  2. Set the Start value of t to 0 and the End value of t to the maximum roll angle required to reach the addendum circle: \[t_{max} = \sqrt{\left(\frac{D_a}{D_b}\right)^2 - 1}\]
  3. Enter the equations into the input fields:
    • X-Function: rb * (cos(t) + t * sin(t))
    • Y-Function: rb * (sin(t) - t * cos(t)) (Replace rb with the evaluated numerical value of the base radius).
  4. Set the sampling density to a minimum of 30 to ensure path smoothness.
  5. Click Apply to generate the vector curve representing a single flank of one gear tooth.

Method 2: Inkscape's Native Python Gear Extension

For a fully automated calculation that directly outputs a closed gear loop, use Inkscape's bundled Python script.

  1. Navigate to Extensions > Render > Gear > Gear...
  2. Define the input parameters:
    • Number of teeth: Specify the tooth count (\(Z\) or \(N\)).
    • Circular pitch: Pitch length along the pitch circle (in pixels).
    • Pressure angle: Select your desired angle (standard is 20°).
  3. Click Apply.

Under the hood, Inkscape runs gear.py, which generates a complete path element (<path d="..." />) composed of circular arcs approximating the involute curve alongside the appropriate dedendum, addendum, and fillet regions.

Method 3: Custom Python Scripting via the Inkscape Extension API

To achieve higher precision than the native approximation, you can write a targeted Python script using the inkex library to generate true involute spline paths.

1. Define the Extension Description (involute_gear.inx)

Place an XML file in your Inkscape user extensions folder (~/.config/inkscape/extensions/ on Linux, %APPDATA%\inkscape\extensions\ on Windows):

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespaces/inkscape">
    <name>Parametric Involute Gear</name>
    <id>org.inkscape.render.parametric_gear</id>
    <param name="teeth" type="int" min="5" max="360" gui-text="Teeth:">20</param>
    <param name="module" type="float" min="0.1" max="100.0" gui-text="Module (mm):">2.0</param>
    <param name="pressure_angle" type="float" min="10.0" max="35.0" gui-text="Pressure Angle (deg):">20.0</param>
    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Render"/>
        </effects-menu>
    </effect>
    <script>
        <command location="inx" interpreter="python">involute_gear.py</command>
    </script>
</inkscape-extension>

2. Implement the Geometry Script (involute_gear.py)

Create the accompanying Python script in the same directory:

import math
import inkex
from inkex import PathElement

class InvoluteGear(inkex.GenerateExtension):
    def add_arguments(self, pars):
        pars.add_argument("--teeth", type=int, default=20)
        pars.add_argument("--module", type=float, default=2.0)
        pars.add_argument("--pressure_angle", type=float, default=20.0)

    def generate(self):
        z = self.options.teeth
        m = self.options.module
        alpha = math.radians(self.options.pressure_angle)

        r_pitch = (z * m) / 2.0
        r_base = r_pitch * math.cos(alpha)
        r_add = r_pitch + m
        r_ded = r_pitch - 1.25 * m

        t_max = math.sqrt(max(0, (r_add / r_base) ** 2 - 1))
        steps = 10

        points = []
        for i in range(z):
            angle_offset = (2 * math.pi / z) * i
            
            # Left involute flank
            left_flank = []
            for s in range(steps + 1):
                t = (s / steps) * t_max
                x = r_base * (math.cos(t) + t * math.sin(t))
                y = r_base * (math.sin(t) - t * math.cos(t))
                
                # Rotate into position
                xr = x * math.cos(angle_offset) - y * math.sin(angle_offset)
                yr = x * math.sin(angle_offset) + y * math.cos(angle_offset)
                left_flank.append((xr, yr))

            points.extend(left_flank)

        # Convert calculated points to an SVG path string
        d_string = "M " + " L ".join(f"{px:.4f},{py:.4f}" for px, py in points) + " Z"

        gear_path = PathElement()
        gear_path.style = {"stroke": "#000000", "stroke-width": "0.5", "fill": "none"}
        gear_path.path = d_string
        return gear_path

if __name__ == "__main__":
    InvoluteGear().run()

Finalizing the Profile in Inkscape

  1. Close Discontinuous Segments: If using manual plotting via the parametric curves extension, mirror the plotted flank across the tooth centerline, bridge the tip with an arc at the addendum radius, and bridge the base with an arc at the dedendum radius.
  2. Radial Array: Group the single tooth path, rotate and duplicate it around the origin at intervals of \(360/N\) degrees, then combine all segments using Path > Union.
  3. Scale Verification: Ensure your document display units are set to millimeters or inches to preserve dimensional accuracy prior to exporting paths for manufacturing.
