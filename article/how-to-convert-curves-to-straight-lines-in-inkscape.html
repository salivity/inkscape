How to Convert Curves to Straight Lines in Inkscape

Transforming smooth, curved paths into sharp, straight-line vectors is a common task in Inkscape, especially when simplifying complex vector artwork, creating low-poly designs, or preparing files for laser cutting and CNC machining. Rather than editing each curve individually, Inkscape provides a built-in function that allows you to instantly flatten every curved segment across an entire path simultaneously. This guide details the exact steps to convert all path curves into straight lines at once using the Node tool.

Step 1: Select the Node Tool

Click the Edit paths by nodes tool from the left toolbar, or press the shortcut key N.

Step 2: Select the Path

Click directly on the path containing the curves you want to convert. The existing nodes will appear along the outline of your shape.

Step 3: Select All Nodes

With the Node tool active, select every node on the path at the same time:

  • Press Ctrl + A (or Cmd + A on macOS) while your cursor is over the canvas.
  • Alternatively, click and drag a selection box around the entire object to encompass all the nodes.

All selected nodes will change color (usually turning yellow or blue, depending on your Inkscape theme), indicating they are ready to be modified.

Step 4: Convert Segments to Straight Lines

Look at the Tool Controls Bar at the top of the screen (directly above the canvas).

Locate the segment editing section and click the Make selected segments lines icon. This icon displays a straight diagonal line connecting two nodes.

Once clicked, Inkscape instantly removes the Bezier curve handles from all selected segments, transforming every curve across the entire path into a straight line.

Quick Keyboard Shortcut Alternative

If you prefer using keyboard shortcuts, select all nodes as outlined above (Ctrl + A), and then press Shift + L. This immediately triggers the "Make selected segments lines" command without needing to click the toolbar button.
