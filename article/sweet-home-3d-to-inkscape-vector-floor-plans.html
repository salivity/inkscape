Sweet Home 3D to Inkscape Vector Floor Plans

Exporting vector floor plans from Sweet Home 3D into Inkscape allows you to transform basic architectural CAD layouts into polished, artistic illustrations for presentations, portfolios, or marketing materials. Sweet Home 3D natively supports the Scalable Vector Graphics (SVG) format, which preserves clean line geometry, precise dimensions, and object boundaries. By importing these vector assets into Inkscape, you gain full control over stroke weights, color palettes, textures, shadows, and layer hierarchies without losing resolution.

Step 1: Export the 2D Plan as SVG in Sweet Home 3D

  1. Open your project in Sweet Home 3D and ensure your 2D plan view displays all the elements you want to include (walls, furniture, rooms, dimensions).
  2. Adjust your 2D view settings if necessary. You can toggle the visibility of room names, areas, or furniture codes through Plan > Modify 2D View.
  3. In the top menu, navigate to Plan and select Export to SVG format....
  4. Choose a destination folder, enter a file name, and click Save. Sweet Home 3D will output the entire 2D drawing as clean, scalable vector paths.

Step 2: Open the SVG in Inkscape

  1. Launch Inkscape.
  2. Go to File > Open, navigate to the exported .svg file, and select Open. Alternatively, if you already have a template or presentation sheet open, select File > Import to insert the floor plan into your active document.
  3. Check the document properties via File > Document Properties (Ctrl+Shift+D) to adjust the canvas orientation, units (e.g., millimeters, inches), and page size to match your presentation requirements.

Step 3: Clean and Organize the Geometry

Sweet Home 3D bundles exported elements into nested groups. Organizing these groups into structured layers makes styling significantly easier.

  1. Select the imported floor plan and press Ctrl+Shift+G (or choose Object > Ungroup) multiple times to break apart the top-level nested groups.
  2. Open the Layers and Objects panel (Layer > Layers and Objects... or Ctrl+Shift+L).
  3. Create distinct layers to organize your drawing logically, such as:
    • Background / Floor Finishes
    • Walls
    • Doors & Windows
    • Furniture
    • Annotations & Text
  4. Select related elements (such as all wall polygons or dimension lines) and move them to their respective layers by right-clicking and selecting Move to Layer....

Step 4: Apply Artistic Rendering Techniques

Once the vector data is isolated by layer, use Inkscape's styling tools to enhance the visual quality of the plan:

  • Wall Fills (Poché): Select all exterior and interior wall shapes. Open the Fill and Stroke panel (Ctrl+Shift+F), apply a solid dark gray or black fill for a traditional architectural look, or use a vibrant brand color. Set the stroke to none or a clean, fine outline.
  • Floor Textures and Colors: Use the room boundary paths to apply floor fills. You can apply soft pastel colors, subtle gradients, or load seamless vector patterns (such as wood planks, concrete, or tile grids) via Fill > Pattern.
  • Furniture Styling: Simplify furniture vectors by giving them consistent stroke widths (e.g., 0.5 mm) and muted fills so they do not compete visually with the structural walls.
  • Depth and Shadows: Create visual hierarchy by adding subtle drop shadows. Select the wall layer or specific furniture groups, then navigate to Filters > Shadows and Glows > Drop Shadow to simulate overhead lighting. Alternatively, draw soft black polygon shapes with reduced opacity (10%–20%) beneath furniture and overhangs to simulate ambient occlusion.
  • Typography: Sweet Home 3D text exports as editable vector text or paths. Replace standard CAD fonts with modern sans-serif or clean serif typography that matches your graphic identity.
