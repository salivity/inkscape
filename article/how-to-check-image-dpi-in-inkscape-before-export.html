How to Check Image DPI in Inkscape Before Export

Ensuring embedded or linked raster images meet the standard 300 DPI (dots per inch) threshold is essential for crisp, professional print results. This guide explains how to calculate and verify the effective resolution of any raster graphic placed on your Inkscape canvas before you export your final document.

Understanding Effective DPI in Inkscape

Inkscape is a vector design program, meaning the canvas itself does not have a fixed pixel grid. When you import a raster image (such as a PNG or JPEG), its resolution depends on two factors: its native pixel dimensions and the physical size it occupies on your canvas.

Setting the export settings to 300 DPI will only export the canvas at 300 DPI; it will not magically increase the resolution of an image that is physically stretched beyond its pixel capacity. Therefore, you must verify the effective DPI of the image manually.

Step 1: Find the Native Pixel Dimensions

To calculate resolution, you first need the image's original pixel count:

  1. Select the raster image on your canvas using the Select and Transform objects tool (S or F1).
  2. Open the XML Editor by pressing Ctrl + Shift + X (or Cmd + Shift + X on macOS).
  3. With the image node (<svg:image>) selected in the XML tree, locate the width and height attributes in the right-hand panel. These values reflect the original pixel dimensions of the source file.
  4. Alternatively, select the image and look at the Status Bar at the bottom of the Inkscape window, which often lists the original pixel dimensions of embedded images.

Step 2: Check the Placed Dimensions in Inches

Next, check how large the image is currently scaled on your canvas:

  1. With the image still selected, look at the Controls Bar directly above the canvas.
  2. Change the measurement unit dropdown from pixels (px) or millimeters (mm) to inches (in).
  3. Note the current width (W) and height (H) values.

Step 3: Calculate the Effective DPI

Use the following formula to find the effective DPI:

\[\text{Effective DPI} = \frac{\text{Native Pixel Dimension}}{\text{Placed Dimension in Inches}}\]

  • Width Check: Divide the native pixel width by the placed width in inches.
  • Height Check: Divide the native pixel height by the placed height in inches.

If the resulting number is 300 or higher, the image satisfies the print resolution requirement. If the number is below 300, the image is scaled too large and will appear pixelated or blurry in print.

Quick Verification Rule

To quickly determine the maximum size an image can be scaled while maintaining 300 DPI, divide its native pixel dimensions by 300:

  • A 1500 × 1200 px image can be scaled to a maximum of 5 × 4 inches (\(1500 / 300 = 5\); \(1200 / 300 = 4\)).
  • A 3000 × 2400 px image can be scaled up to 10 × 8 inches.

If your image exceeds these dimensions on the canvas, shrink it until its width and height in inches are within the calculated limits, or replace it with a higher-resolution asset prior to export.
