How to Bend a Gradient Along a Path in Inkscape

Bending a linear gradient along a curved path in Inkscape requires converting the color transition into an interpolated vector group, as standard SVG linear gradient coordinates can only travel in straight lines. By pairing path interpolation with the Bend Live Path Effect (LPE), you can deform a dynamic color blend smoothly along any custom curve. This guide explains how to generate the blended source geometry and curve it using Inkscape's path effect tools.

Step 1: Create an Interpolated Gradient Strip

Standard gradient fills cannot curve on their own, so you must create a series of blended vector steps to simulate the gradient.

  1. Select the Pen (Bezier) Tool (B) and draw a single straight vertical line.
  2. Duplicate the line with Ctrl + D and hold Ctrl while dragging it horizontally to create the end point of your gradient.
  3. Select the first line and assign your starting color using the Fill and Stroke panel (Ctrl + Shift + F).
  4. Select the second line and assign your ending color.
  5. Select both lines, then navigate to Extensions > Generate from Path > Interpolate.
  6. Set Interpolation Steps between 50 and 100 (higher values create smoother gradients at the cost of processing speed).
  7. Ensure Interpolate style is checked and click Apply, then Close.
  8. Select the resulting interpolation and group all the lines together by pressing Ctrl + G.

Step 2: Apply the Bend Live Path Effect

  1. Select the grouped gradient.
  2. Open the Path Effects dialog by selecting Path > Path Effects.
  3. Click the + (Add Path Effect) icon and select Bend from the list.

Step 3: Curve the Gradient Along a Path

You can shape the curve manually or link it to an existing vector path.

Method A: Deform On-Canvas

  1. In the Path Effects panel under the Bend settings, click the Edit on-canvas icon (represented by a node tool icon next to "Bend path").
  2. A green reference line will appear through the center of your gradient group.
  3. Switch to the Node Tool (N).
  4. Click and drag anywhere along the green line to bend the gradient into an arc, or click its endpoints to adjust the handles for complex curves.

Method B: Map to an Existing Target Curve

  1. Draw the desired curve using the Pen Tool (B).
  2. Select the drawn curve and copy it to the clipboard (Ctrl + C).
  3. Select the grouped gradient with the Bend LPE applied.
  4. In the Path Effects panel, locate the "Bend path" property and click the Paste path icon (represented by a clipboard). The gradient will automatically deform to match the exact shape and curvature of the copied line.

Step 4: Refine the Output

  • Width and Scale: To adjust the thickness of the bent gradient, change the length of the original lines prior to applying the effect, or scale the group before bending.
  • Curve Adjustments: With the Node Tool active, selecting the bent gradient will reveal the active bend spine, allowing real-time reshaping of the curve.
