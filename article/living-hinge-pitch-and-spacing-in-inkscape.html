Living Hinge Pitch and Spacing in Inkscape

This guide explains how to accurately adjust the pitch and lattice spacing of a laser-cut living hinge pattern directly within Inkscape. Controlling the pitch (the horizontal distance between adjacent cut lines) and the lattice spacing (the uncut material bridges along a single cut line) determines the flexibility, strength, and minimum bend radius of your material. Using Inkscape’s vector tools, grid settings, and the Tiled Clones engine, you can generate clean, highly customizable hinge patterns optimized for any laser cutter.

Understanding the Key Variables

  • Pitch: The distance between consecutive cut columns or rows. A tighter pitch increases flexibility but weakens the material. A wider pitch makes the bend stiffer and increases the minimum bend radius.
  • Lattice Spacing (Bridge/Gap): The length of uncut material left between cut segments on the same line. Larger bridges provide structural integrity, while smaller bridges allow greater torsional twist and bending freedom.
  • Kerf Consideration: The laser beam width removes material (typically 0.1mm to 0.2mm). Factor this into your bridge widths so structural connections do not burn away.

Method 1: Manual Layout Using Align and Distribute

This method provides full visual control for custom, non-repeating hinges or simple test swatches.

1. Create the Base Cut Line

  1. Select the Draw Freehand Lines or Draw Bezier Curves tool (B).
  2. Hold Ctrl and draw a perfectly straight vertical line matching your hinge height.
  3. Open the Fill and Stroke panel (Shift + Ctrl + F).
  4. Set the Stroke paint to a flat color and set Stroke style width to your laser’s hairline cut setting (e.g., 0.001 in or 0.05 mm).

2. Set Lattice Spacing (The Bridges)

  1. Draw individual line segments equal to your desired cut length (e.g., 20mm).
  2. Duplicate the segment (Ctrl + D).
  3. Position the segments vertically with a defined space between them (e.g., a 2mm uncut gap for the bridge).
  4. Use the Align and Distribute panel (Shift + Ctrl + A), select all vertical segments in the column, and choose Distribute targets: Distribute vertical distance evenly.
  5. Select all segments in that column and group them (Ctrl + G).

3. Set the Pitch (Horizontal Spacing)

  1. Duplicate your grouped column (Ctrl + D).
  2. Move the duplicated column horizontally to establish a second cut line.
  3. Offset the second column vertically so that its cut segments center on the bridges of the first column. This alternating layout creates the standard living hinge weave.
  4. Select both columns, duplicate them multiple times, and position them across the desired hinge width.
  5. Select all columns, go to Align and Distribute, and click Distribute horizontal distance evenly. Adjust the horizontal spacing value directly to set your exact pitch (typically 2mm to 5mm depending on material thickness).

Method 2: Parametric Generation Using "Create Tiled Clones"

The Create Tiled Clones tool is the most accurate way to automate alternating hinge lattices with fixed pitch and spacing.

1. Build the Alternating Unit

  1. Draw two vertical line segments representing the primary cut and the offset cut:
    • Segment A: A vertical line segment of your chosen length.
    • Segment B: Placed parallel to Segment A at your desired pitch distance (e.g., 3mm to the right), shifted vertically by half the cut length plus half the bridge width.
  2. Group Segment A and Segment B together (Ctrl + G).

2. Apply Tiled Clones for Fixed Pitch

  1. Select the group.
  2. Navigate to Edit > Clone > Create Tiled Clones...
  3. In the dialog, go to the Symmetry tab and select P1: simple translation.
  4. Go to the Shift tab:
    • Under Shift X, set Per column to 100% plus the desired gap percentage, or switch to explicit units using the absolute coordinate options.
    • Ensure Shift Y is set to 0%.
  5. Set the number of Rows to 1 and Columns to the number of cut pairs needed to span your hinge zone.
  6. Click Create.

Best Practices for Material Calibration

  • Plywood (3mm / 1/8"): Start with a 3mm pitch and a 1.5mm to 2mm bridge width. Increasing pitch beyond 5mm often causes cracking along the wood grain.
  • Acrylic (3mm): Requires wider bridges (at least 2.5mm to 3mm) and a slightly looser pitch to prevent stress fractures from laser heat dissipation.
  • Grain Orientation: Always align the cut lines perpendicular to the wood grain. Cutting parallel to the grain results in immediate hinge failure.
