Create Foil Stamping Separation Masks in Inkscape

This guide explains how to prepare print-ready metallic foil stamping separation masks and precise registration marks using Inkscape. Foil stamping requires a separate monochrome vector file—known as a foil mask or separation—that die makers use to etch the metal stamping plate. By structuring your document with dedicated layers, converting artwork to solid black vector paths, and generating standardized alignment targets, you can ensure flawless foil-to-print registration during the physical printing process.

Step 1: Set Up Document Layers

Organizing your design file into distinct layers prevents accidental edits and streamlines export.

  1. Open your design in Inkscape and press Shift + Ctrl + L to open the Layers panel.
  2. Create three separate layers:
    • Base Artwork: Contains your standard CMYK or digital print graphics.
    • Foil Mask: Holds only the elements to be stamped with foil.
    • Registration: Holds the alignment marks that must appear in identical positions on both separations.
  3. Lock the layers you are not currently editing to avoid displacing elements.

Step 2: Isolate the Foil Artwork

Foil dies require 100% solid, high-contrast vector shapes with no transparencies, halftones, or gradients.

  1. Select every element on your artboard intended for foil stamping.
  2. Copy (Ctrl + C) and paste them in place (Ctrl + Alt + V) onto the Foil Mask layer.
  3. Select all paths on the Foil Mask layer, open the Fill and Stroke dialog (Shift + Ctrl + F), and set the Fill to 100% solid black (#000000). Turn off all strokes unless the stroke itself is meant to be foiled.
  4. If your foil design uses strokes, convert them to outlines by selecting them and clicking Path > Stroke to Path (Ctrl + Alt + G).
  5. Convert any live text to outlines by selecting the text and clicking Path > Object to Path (Shift + Ctrl + C).
  6. Select overlapping foil paths and merge them into unified vector shapes using Path > Union (Ctrl + +).

Step 3: Create Registration Marks

Registration marks allow the press operator to align the hot foil stamping die directly over the printed sheet.

  1. Set your document grid or guides to define your trim line and bleed area. Registration marks must sit outside the final trim line (in the slug area) so they are cut off after production.
  2. Select the Registration layer.
  3. Use the Create circles, ellipses, and arcs tool (F5) to draw a small circle (approx. 5 mm or 0.2 inches) with no fill and a 0.5 pt solid black stroke.
  4. Use the Draw freehand lines tool (F6) to draw two intersecting perpendicular lines (a crosshair) running through the center of the circle, extending slightly beyond its perimeter.
  5. Select both the circle and the lines, then open the Align and Distribute panel (Shift + Ctrl + A) to center them horizontally and vertically relative to each other.
  6. Group the mark components together (Ctrl + G).
  7. Duplicate this mark (Ctrl + D) and place one copy in each of the four corners of your document canvas, ensuring they sit outside the trim edge.

Step 4: Verify Alignment and Path Integrity

  1. Toggle the visibility of the Base Artwork and Foil Mask layers back and forth. Ensure that the foil vector shapes precisely match the areas where foil should hit the printed design.
  2. If foil is applied over printed knockout areas, verify whether your printer requires a slight "choke" or "spread" (trapping). If trapping is needed, expand the foil area slightly using Path > Outset (Ctrl + )).
  3. Ensure no stray raster images, hidden objects, or open paths remain on the Foil Mask layer.

Step 5: Export the Separation Files

Commercial print shops require two separate PDF files: one for the base print run and one for the foil die tooling.

  1. Export the Base Print File:
    • Make the Base Artwork and Registration layers visible.
    • Hide the Foil Mask layer.
    • Go to File > Save As..., choose Portable Document Format (*.pdf), and save as Project_Base_Print.pdf. Ensure output settings preserve vector data.
  2. Export the Foil Separation Mask:
    • Hide the Base Artwork layer.
    • Make the Foil Mask and Registration layers visible.
    • Go to File > Save As..., select Portable Document Format (*.pdf), and save as Project_Foil_Mask.pdf.

Both exported files will share the exact same dimensions and registration coordinates, enabling the foil manufacturer to manufacture a perfectly matching stamping die.
