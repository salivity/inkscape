How to Make 45-Degree Subway Maps in Inkscape

This guide explains how to design schematic, vector-based transit maps in Inkscape using standardized 45-degree and 90-degree angles. By configuring angle constraints, setting up an efficient snapping grid, applying path effects for rounded corners, and creating modular station markers, you can produce clean, professional schematic transit diagrams modeled after classic metro navigation systems.

1. Configure Document Properties and Grid

A consistent grid ensures uniform spacing between parallel lines and stations:

  1. Open Inkscape and create a new document.
  2. Go to File > Document Properties (or press Shift + Ctrl + D).
  3. Under the Grids tab, select Rectangular grid and click New.
  4. Set Spacing X and Spacing Y to identical values (such as 10 px or 20 px). A 1:1 ratio guarantees that diagonal movements across grid intersections align precisely to 45 degrees.
  5. In the Snap toolbar (typically on the right edge of the interface), enable snapping, enable Snap to Grids, and turn on Snap to paths and Snap to path intersections.

2. Set Up Angle Constraints for the Bézier Tool

Inkscape allows you to restrict line segments to precise degree increments:

  1. Open Edit > Preferences (or press Shift + Ctrl + P).
  2. Navigate to Interface > Steps.
  3. Locate Rotation snaps every [X] degrees and set it to 15.0 degrees (the default value) or 45.0 degrees. Because 45 is a multiple of 15, holding Ctrl while drawing naturally snaps to 0°, 45°, and 90°.

3. Draw the Transit Lines

  1. Select the Draw Bézier curves and straight lines tool by pressing B.
  2. In the top tool control bar, ensure the mode is set to Create regular Bézier path and shape is set to None.
  3. Click on the canvas to place the starting node.
  4. Hold down the Ctrl key as you move the cursor to lock the segment to 0°, 45°, or 90° angles.
  5. Click on grid intersections to place subsequent nodes, maintaining 45-degree diagonals or orthogonal lines.
  6. Press Enter or right-click to end the path.

4. Style Lines and Standardize Thickness

Transit maps rely on distinct, uniform stroke widths to indicate routes:

  1. Open the Fill and Stroke panel (Shift + Ctrl + F).
  2. Set Fill to none.
  3. Under the Stroke paint tab, choose a flat color for your line.
  4. Under the Stroke style tab:
    • Set a fixed Width (e.g., 8 px or 12 px). Apply this exact width to all main lines.
    • Set Cap to Round cap or Butt cap.
    • Set Join to Round join for soft bends, or keep it as Miter join if using manual corner rounding.

5. Round Line Corners Using Path Effects

Schematic transit maps feature smooth curves between angle transitions:

  1. Select the transit line path.
  2. Go to Path > Path Effects....
  3. Click the + (Add Path Effect) button and select Corners (Fillet/Chamfer).
  4. Set the Method to Fillet and input a fixed radius (e.g., 15 px or 20 px) across your entire transit system.
  5. To apply the curve directly on the canvas, choose the Edit paths by nodes tool (N), click the green control handles near the corners, and drag to curve them uniformly.

6. Create Modular Station Markers

Stations must be aligned to the grid and line vectors:

  • Regular Stations: Select the Circle/Ellipse tool (F5), hold Ctrl + Shift to draw a perfect circle, and make its diameter slightly wider than the line width (e.g., 12 px circle on an 8 px line). Give it a white fill with a black or line-colored stroke.
  • Interchange Stations: Use a rounded rectangle or combine multiple circles into a "capsule" shape using Path > Union.
  • Snapping Markers: Use the Select and transform objects tool (S) to drag stations onto the lines. With Snap to paths or Snap to nodes active, station centers will snap directly to the transit route.

7. Manage Parallel Lines

When running multiple lines along the same corridor:

  1. Duplicate the initial path using Ctrl + D.
  2. Move the duplicated path parallel to the original by using the arrow keys with a fixed nudge distance, or manually drag it along the grid points.
  3. If shifting along 45-degree paths, move the line an equal number of steps on both the X and Y axes to preserve spacing.
