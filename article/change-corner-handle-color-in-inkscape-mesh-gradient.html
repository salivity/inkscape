Change Corner Handle Color in Inkscape Mesh Gradient

Mesh gradients in Inkscape allow designers to create realistic, multi-directional color transitions across vector shapes. This guide explains the exact steps to select a specific corner handle on a gradient mesh and change its individual color using Inkscape’s Mesh tool and color management panels.

Step 1: Select the Mesh Tool

Select the object containing your mesh gradient, then activate the Mesh Tool by clicking its icon in the left toolbar or pressing the keyboard shortcut M.

Step 2: Identify and Select the Corner Handle

Once the Mesh Tool is active, the mesh grid, nodes, and handles will appear over your object:

  1. Locate the specific corner handle (also referred to as a mesh corner node) you wish to recolor. Corner nodes appear as small diamond- or square-shaped handles at the intersections of the grid lines.
  2. Click directly on the corner handle to select it. When selected, the handle will highlight (typically turning red or blue depending on your Inkscape theme).

Step 3: Apply the New Color

With the specific corner handle selected, you can assign a new color using any of the following methods:

  • The Color Palette: Click any color swatch in the palette bar at the bottom of the screen.
  • The Fill and Stroke Dialog: Open the dialog by pressing Ctrl + Shift + F (or Cmd + Shift + F on macOS). Under the Fill tab, adjust the color using the Wheel, RGB, HSL, or CMYK sliders.
  • The Dropper Tool: Press D or select the Dropper tool from the toolbar, then click anywhere on your canvas to sample an existing color directly to the selected corner node.

Step 4: Adjust the Gradient Spread (Optional)

To control how the new color blends into adjacent nodes:

  1. Click and drag the circular tensor handles extending from the corner node.
  2. Lengthening or rotating these handles changes the direction and curvature of the color transition across the mesh patch.
