How to Import AutoCAD DXF and DWG in Inkscape

Importing CAD drawings into Inkscape allows you to edit, style, and prepare technical vector plans for presentations and graphic design workflows. While Inkscape natively supports AutoCAD DXF files, importing proprietary DWG files requires a quick conversion step. This guide outlines the exact procedures for importing both DXF and DWG formats into Inkscape, along with essential settings to maintain accurate scaling and line work.

Importing AutoCAD DXF Files Directly

Inkscape includes a built-in DXF import engine that supports AutoCAD R13 DXF files and newer. Follow these steps to open or import your DXF drawing:

  1. Open Inkscape and navigate to File > Open (to create a new document from the file) or File > Import (to insert the drawing into an existing document).
  2. Set the file format dropdown in the file browser to AutoCAD DXF R14 (*.dxf) or All Files.
  3. Select your DXF file and click Open.
  4. In the DXF import dialog box, configure the following settings:
    • Input Unit: Select the unit of measurement used in the original CAD model (e.g., millimeters, inches, meters). Choosing the wrong unit will distort the scale.
    • Manual Scale: Enter a scaling factor if you want to scale the drawing immediately, or leave it at 1.0 to preserve the original geometry dimensions.
    • Text Encoding: Set to UTF-8 or Latin 1 depending on your drawing's text requirements.
    • Combine Paths: Check this option if you want connected segments merged into single paths automatically.
  5. Click OK to render the vector drawing on the canvas.

Importing AutoCAD DWG Files

Inkscape cannot open native DWG files directly because the DWG format is a proprietary binary specification. To import a DWG file, convert it to a supported vector format first:

Method 1: Export to DXF or PDF from AutoCAD

If you have access to AutoCAD or a compatible CAD program (such as BricsCAD, LibreCAD, or DraftSight):

  1. Open the DWG file in your CAD software.
  2. Use Save As or Export and choose AutoCAD 2013/2018 DXF or PDF.
  3. If saving as PDF, ensure vector output is selected rather than a raster print.
  4. Import the resulting DXF or PDF into Inkscape using File > Open.

Method 2: Use the ODA File Converter

If you do not have CAD software installed:

  1. Download and install the free ODA File Converter provided by the Open Design Alliance.
  2. Set the input folder containing your DWG file and designate an output folder.
  3. Select an output version such as ASCII DXF (2018 or earlier).
  4. Run the conversion, then import the converted DXF file directly into Inkscape.

Post-Import Optimization in Inkscape

CAD exports often import as thousands of disjointed lines or nested groups. Clean up the imported vectors with these steps:

  • Ungroup Elements: Select the drawing and press Ctrl + Shift + G (or Cmd + Shift + G on macOS) multiple times to unpack nested layers and groups.
  • Join Line Segments: Switch to the Node Tool (N), select the disconnected path nodes, and click Join selected endnodes in the top toolbar to turn individual segments into continuous polylines.
  • Set Stroke Widths: Open the Fill and Stroke panel (Ctrl + Shift + F) to assign uniform stroke weights, colors, and line styles across the imported geometry.
