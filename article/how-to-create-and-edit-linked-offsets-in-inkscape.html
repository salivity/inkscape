How to Create and Edit Linked Offsets in Inkscape

In Inkscape, linked offsets allow you to generate dynamic, scalable contours around an object that automatically update whenever the original shape is modified. This guide explains how to create a linked offset from an existing path and how to edit the underlying source geometry to maintain responsive vector illustrations.

Creating a Linked Offset

  1. Select or Convert to Path: Click the object you want to offset using the Select Tool (S). If the object is a basic shape or text, convert it to a path by navigating to Path > Object to Path (or press Shift + Ctrl + C).
  2. Generate the Offset: With the path selected, go to the top menu and choose Path > Linked Offset (or press Ctrl + Alt + J).
  3. Adjust the Distance: Inkscape automatically switches to the Node Tool (N) and places a single control handle at the top of the shape. Click and drag this handle outward to expand the offset or inward to contract it.
  4. Style the Offset: The linked offset acts as an independent object regarding styling. Use the Fill and Stroke panel (Shift + Ctrl + F) to change its color, opacity, or stroke properties without affecting the original shape.

Editing the Source Geometry

Because the offset is dynamically linked, modifying the original shape automatically updates the offset path.

  1. Select the Node Tool: Press N or select the Edit paths by nodes icon from the left toolbar.
  2. Select the Original Path: Click directly on the original source path beneath or inside the offset. If the offset is covering the original shape, lower the offset by pressing Page Down or select the source path via the Layers and Objects panel (Shift + Ctrl + L).
  3. Modify the Nodes: Click and drag existing nodes, adjust node handles, or double-click the path to add new nodes. As you reshape the source object, the linked offset will immediately recalculate and reflect the changes in real-time.

Managing Linked Offsets

  • Multiple Offsets: You can create multiple linked offsets from the exact same source path to create layered sticker borders or nested contour effects.
  • Unlinking: If you want to stop the offset from updating with the source geometry, select the linked offset and go to Path > Object to Path. This converts the dynamic offset into a standard, static vector path.
