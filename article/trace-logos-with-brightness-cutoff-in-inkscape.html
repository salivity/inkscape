Trace Logos with Brightness Cutoff in Inkscape

Tracing high-contrast logos in Inkscape allows you to quickly convert low-resolution raster images (such as PNGs or JPEGs) into clean, infinitely scalable vector paths. This guide provides a straightforward walkthrough on using the Brightness Cutoff feature within the Trace Bitmap dialog, covering the step-by-step process from importing your source image to adjusting threshold values and finalizing your vector output.

1. Import and Select the Image

  1. Open Inkscape and create a new document.
  2. Go to File > Import (or press Ctrl + I) to load your raster logo onto the canvas.
  3. Use the Select and Transform objects tool (S) to click on the imported logo to ensure it is active.

2. Open the Trace Bitmap Dialog

  1. Navigate to the top menu and select Path > Trace Bitmap (or press Shift + Alt + B).
  2. The Trace Bitmap panel will dock on the right side of the workspace or open in a separate window.

3. Configure the Brightness Cutoff Settings

  1. Ensure the Single scan tab is selected inside the dialog.
  2. Choose Brightness cutoff from the detection mode dropdown. This mode calculates the luminance of every pixel, turning pixels darker than the threshold into solid vector shapes and treating lighter pixels as transparent backgrounds.
  3. Enable the Live Preview toggle (or check the preview window) to see real-time updates of the trace.

4. Adjust the Threshold Value

  • Default Value (0.450): The standard starting point for balanced black-and-white images.
  • Increase the Threshold: Raise the value (e.g., to 0.600–0.800) if fine dark details or thin lines are disappearing.
  • Decrease the Threshold: Lower the value (e.g., to 0.200–0.400) if background noise, artifacts, or unwanted lighter areas are being included in the trace.

5. Execute the Trace

  1. Once the preview displays crisp outlines without missing elements, click the Apply button at the bottom of the dialog.
  2. Inkscape will generate a new vector path directly on top of the original bitmap.

6. Separate and Clean Up

  1. Click and drag the new vector graphic away from the original bitmap image.
  2. Select the original raster image and press Delete to remove it from the canvas.
  3. Switch to the Edit paths by nodes tool (N) to inspect the vector nodes, remove stray points, or apply Path > Simplify (Ctrl + L) if the path contains excessive nodes.
