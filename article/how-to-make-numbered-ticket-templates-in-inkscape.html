How to Make Numbered Ticket Templates in Inkscape

Creating variable data printing (VDP) templates for serial-numbered tickets in Inkscape allows you to design professional event tickets and automate sequential numbering for print production. While Inkscape is primarily a vector illustration tool, its open SVG standard makes it exceptionally easy to integrate with variable data workflows. This guide covers how to set up your base ticket geometry, configure text placeholders for serial numbers, and merge dynamic data using Inkscape-compatible tools for final PDF output.

Step 1: Set Up the Ticket Canvas and Bleed

  1. Open Inkscape and create a new document (File > Document Properties).
  2. Set the display units to inches or millimeters depending on your print specification (standard event tickets are typically 2" x 5.5" or 50mm x 140mm).
  3. If printing to the edge, expand the page size to include a 0.125-inch (3mm) bleed on all sides.
  4. Use the rectangle tool to mark your final trim line and a perforating line to separate the main ticket body from the stub. Set guides by dragging them from the rulers to mark these boundaries.

Step 2: Design the Ticket Artwork

  1. Lay out all static graphical elements (logos, event name, date, venue, terms, and backgrounds) on dedicated layers.
  2. Group static graphics and lock the artwork layer to avoid accidental movement while working on text elements.
  3. Keep the areas reserved for serial numbers clear of complex vector gradients or busy backgrounds to maintain legibility.

Step 3: Configure Serial Number Placeholders

Inkscape stores all text elements as clear, plain-text nodes in its underlying SVG XML code.

  1. Select the Text Tool (T) and click once where the serial number should appear on the main ticket body. Avoid drawing a bounded text box; click-to-type ensures standard single-line SVG text.
  2. Enter a recognizable placeholder value such as NUM0001 or %%SERIAL%%.
  3. Format the text with your desired font, size, weight, and color.
  4. In the Text and Font panel, set the text alignment to right-aligned or centered so that expanding digits (e.g., from 99 to 100) expand evenly without spilling over your margins.
  5. If your ticket has a detachable stub, duplicate this text element to the stub area.
  6. Select the text object, open the Object Properties panel (Shift + Ctrl + O), and set a clean, unique ID in the ID field (e.g., ticket_serial and stub_serial). Click Set.

Step 4: Generate Variable Data Using an Extension

Because Inkscape does not include a native database merge UI, you can use the open-source NextGenerator extension or standard SVG string replacement.

Using NextGenerator

  1. Install the NextGenerator extension into your Inkscape user extensions directory.
  2. Create a CSV file containing your serialized numbers under a designated column header (e.g., SERIAL).
  3. Set your ticket placeholder text to match the column header syntax: [SERIAL].
  4. Open the extension via Extensions > NextGenerator.
  5. Browse to select your CSV data file, choose your output format (individual SVGs or a single multipage PDF), and click Apply to batch-generate the numbered tickets.

Using External Scripting (Alternative)

Because SVG files are plain XML, you can write a short Python or Bash script to loop through a range of numbers:

  • Find the placeholder string NUM0001 in the saved .svg file.
  • Replace it sequentially with zero-padded numbers (0001, 0002, etc.).
  • Save each iteration as a separate SVG or render them directly to PDF via Inkscape's command-line interface: inkscape input_0001.svg --export-filename=ticket_0001.pdf

Step 5: Prepare for Printing and Imposition

  1. For high-volume production, assemble the exported single-ticket PDFs onto multi-up press sheets (e.g., 8 or 10 tickets per 8.5" x 11" or A4 page).
  2. Utilize open-source tools such as pdfjam or dedicated imposition software to maintain cut-and-stack sequential ordering. This ensures that when the printed sheets are sliced, the numbers stay in order from top to bottom.
