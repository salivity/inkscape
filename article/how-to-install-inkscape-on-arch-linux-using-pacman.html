How to Install Inkscape on Arch Linux Using Pacman

This guide provides a straightforward walkthrough for installing Inkscape, a powerful open-source vector graphics editor, on Arch Linux using the default Pacman package manager. It covers updating your system repositories, executing the installation command, installing optional dependencies for extended features, and launching the application.

Step 1: Update Your System

Before installing new software, ensure your package database and system packages are up to date. Open your terminal and run:

sudo pacman -Syu

Step 2: Install Inkscape

Inkscape is available directly in the official Arch Linux extra repository. Install it by running the following command:

sudo pacman -S inkscape

When prompted, type Y and press Enter to confirm the download and installation.

Step 3: Install Optional Dependencies (Recommended)

Inkscape relies on optional packages to enable advanced features like PDF import/export, spell checking, and various extension scripts. To install the most common optional dependencies, run:

sudo pacman -S python-numpy python-lxml poppler-glib pstoedit ghostscript
  • python-numpy & python-lxml: Required for running many built-in extensions and filters.
  • poppler-glib: Improves PDF import rendering.
  • ghostscript & pstoedit: Enable PostScript and EPS file handling.

Step 4: Verify the Installation

To verify that Inkscape has been successfully installed, check its version:

inkscape --version

Step 5: Launch Inkscape

You can launch Inkscape in two ways:

  1. From the Terminal: 
    inkscape
  2. From the Desktop Environment: Open your application launcher (such as GNOME Activities, KDE Application Menu, or Rofi/dmenu) and search for Inkscape.

How to Remove Inkscape

If you ever need to remove Inkscape and its unused dependencies, execute:

sudo pacman -Rs inkscape
