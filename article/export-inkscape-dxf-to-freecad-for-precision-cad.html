Export Inkscape DXF to FreeCAD for Precision CAD

Exporting 2D vector silhouettes from Inkscape into FreeCAD allows designers and engineers to transform artistic vector graphics into dimensionally accurate, 3D-printable or machinable CAD models. This guide outlines the complete workflow for preparing path geometries in Inkscape, exporting them cleanly as DXF files with true real-world scaling, importing the vector data into FreeCAD, and converting the resulting 2D wireframes into fully editable sketches for 3D operations like extrusions and pockets.

1. Prepare Vector Geometry in Inkscape

To ensure FreeCAD interprets your Inkscape silhouette correctly, the geometry must consist of clean, closed vector paths rather than strokes, groups, or bitmap traces.

  1. Ungroup All Objects: Select everything (Ctrl + A) and ungroup (Ctrl + Shift + G) repeatedly until no groups remain in the status bar.
  2. Convert Strokes and Objects to Paths:
    • Select your shape and go to Path > Object to Path (Shift + Ctrl + C).
    • If your silhouette uses outline strokes, convert them via Path > Stroke to Path (Ctrl + Alt + C).
  3. Combine Shapes into Closed Loops:
    • Use Path > Union (Ctrl + +) or Path > Combine (Ctrl + K) to merge overlapping elements.
    • Switch to the Edit paths by nodes tool (N) and verify that all silhouette outlines are closed loops with no self-intersecting segments or stray open nodes.
  4. Set Explicit Document Units:
    • Open File > Document Properties (Ctrl + Shift + D).
    • Set Display units to your target engineering unit (e.g., mm or in).
    • Set the Page size to match your design bounds and position the silhouette at X: 0, Y: 0 for consistent CAD origin alignment.

2. Export as DXF from Inkscape

  1. Navigate to File > Save As... or File > Export As....
  2. Select AutoCAD DXF R14 (*.dxf) or Desktop Cutting Plotter (AutoCAD DXF R14) (*.dxf) from the format dropdown.
  3. In the export configuration dialog:
    • Base unit: Select the exact unit used in your document (e.g., mm).
    • Character Encoding: Choose UTF-8 or Latin 1.
    • Layer export options: Check Export all layers or target the specific layer containing your silhouette.
    • Polyline export: Enable polyline conversion if prompted, as polylines import cleanly into CAD environments.
  4. Click OK to save the file.

3. Import the DXF into FreeCAD

  1. Open FreeCAD and create a new document (Ctrl + N).
  2. Verify FreeCAD import settings under Edit > Preferences > Import-Export > DXF:
    • Ensure the Draft module DXF importer is selected.
    • Check Create sketch or Create Draft objects based on your preferred workflow.
    • Confirm the default input scale matches the export unit (e.g., millimeters).
  3. Go to File > Import and select your exported .dxf file.
  4. Choose Draft Import if prompted.

4. Convert DXF Vectors into Solid 3D Geometry

  1. Switch to the Draft Workbench.
  2. Select the imported 2D DXF entities in the tree view.
  3. Click the Draft to Sketch tool to convert the vector geometry directly into a FreeCAD sketch.
  4. Switch to the Part Design Workbench:
    • Create a new Body.
    • Move the generated sketch into the newly created Body.
    • Double-click the sketch to enter edit mode, inspect the silhouette for missing constraints or unclosed vertices, and add dimensional constraints if needed.
    • Exit the sketch and click Pad to extrude the silhouette into a precise 3D solid.
  5. Alternatively, switch to the Part Workbench and use the Extrude tool directly on the imported wires or sketch.
