How to Add Custom Palettes to Inkscape on Linux

Custom color palettes in the GIMP Palette (.gpl) format allow you to quickly access specific color schemes in Inkscape. On Linux, installing these palettes requires placing the .gpl files into the appropriate Inkscape configuration directory depending on whether you installed the application via your distribution's native package manager, Flatpak, or Snap. This guide outlines the exact file paths for each installation type and explains how to activate your new palette inside the program.

Standard Native Installation

If you installed Inkscape via APT, DNF, Pacman, or another native package manager, place your .gpl files in your user configuration directory:

~/.config/inkscape/palettes/

If the palettes folder does not exist inside ~/.config/inkscape/, you can safely create it yourself using your file manager or by running:

mkdir -p ~/.config/inkscape/palettes/

Flatpak Installation

If you run Inkscape as a Flatpak, the application is sandboxed and uses an isolated configuration path. Move your .gpl files here:

~/.var/app/org.inkscape.Inkscape/config/inkscape/palettes/

Snap Installation

If you installed Inkscape via Canonical's Snap Store, place your .gpl files in the Snap user data directory:

~/snap/inkscape/current/.config/inkscape/palettes/

System-Wide Installation (All Users)

To make a palette available to every user on the system, place the file in the shared system directory (root privileges required):

/usr/share/inkscape/palettes/

How to Access the Palette in Inkscape

  1. Close and reopen Inkscape if it is currently running.
  2. Locate the color palette bar along the bottom of the workspace.
  3. Click the small arrow icon located at the far-right corner of the palette bar.
  4. Scroll through the drop-down list to find and select your custom palette by name.
