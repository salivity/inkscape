Export Inkscape Vectors to RawTherapee Masks

RawTherapee does not natively read raw SVG vector code, but you can bridge the gap by designing custom vector paths in Inkscape and translating them into high-precision raster masks for RawTherapee. This guide details how to draw vector shapes in Inkscape, feather and render them to the appropriate dimensions, and apply them in RawTherapee using the Flat-Field tool to create completely custom vignetting effects.

Step 1: Match Aspect Ratio and Dimensions in Inkscape

  1. Open Inkscape and access File > Document Properties.
  2. Under the Format or Custom size settings, change the units to pixels (px).
  3. Set the width and height to match the exact resolution or aspect ratio of your target raw photo (for example, 6000 x 4000 px).

Step 2: Draw and Style the Vignette Path

  1. Select the Draw Bezier curves and straight lines tool (Shift+F6).
  2. Draw your custom vignetting path across the canvas.
  3. Open the Fill and Stroke panel (Ctrl+Shift+F).
  4. Set the canvas background or an underlying rectangle to pure white (#FFFFFF).
  5. Set the fill of your drawn vignette shape to pure black (#000000) with no stroke.
  6. In the Fill and Stroke panel, adjust the Blur slider on the vignette object to feather the transition edges smoothly, or apply a radial/mesh gradient to create an organic falloff.

Step 3: Export the Path as a High-Bit-Depth Mask

  1. Go to File > Export.
  2. In the Export dialog, set the export area to Page to ensure the canvas bounds align with your image frame.
  3. Set the output format to TIFF or high-resolution PNG.
  4. Ensure the output DPI matches the target dimensions and export the file to your working directory.

Step 4: Apply the Mask as a Vignette in RawTherapee

  1. Open RawTherapee and navigate to your target photo in the Editor.
  2. Go to the Raw tab located on the right-hand adjustment panel.
  3. Expand the Preprocessing section and locate Flat-Field.
  4. Check the box to enable Flat-Field.
  5. Set the mode to File, click the folder icon, and select the mask image you exported from Inkscape.
  6. Adjust the Flat-Field blur type and Auto clip control if needed to fine-tune the intensity and smooth out any harsh transitions across your photo.
