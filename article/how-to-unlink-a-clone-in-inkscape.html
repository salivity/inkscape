How to Unlink a Clone in Inkscape

In Inkscape, clones are linked copies that dynamically reflect the style, geometry, and modifications of the original parent object. This guide explains how to unlink a clone to turn it into a standard, independent shape or path, allowing you to freely edit its nodes, colors, and dimensions without affecting—or being affected by—the original artwork.

The Fastest Method: Menu Command

  1. Select the clone you want to detach using the Select Tool (S or F1).
  2. Navigate to the top menu and select Edit.
  3. Hover over Clone in the dropdown list.
  4. Click Unlink Clone.

Once selected, the clone instantly becomes an independent object with its own editable properties.

Using Keyboard Shortcuts

For a faster workflow, you can use the built-in keyboard shortcuts after selecting the cloned object:

  • Windows / Linux: Press Shift + Alt + D
  • macOS: Press Shift + Option + D

Unlinking Multiple Clones Simultaneously

If your canvas contains several clones—such as elements arranged via tiled clones or patterns—you can unlink them in a single batch:

  1. Select all the clones you want to separate using the Select Tool (click and drag a selection box or hold Shift while clicking each object).
  2. Use the shortcut Shift + Alt + D (or go to Edit > Clone > Unlink Clone).
  3. Every selected clone will immediately convert into an individual, stand-alone vector object.

What Happens After Unlinking?

When you unlink a clone, it typically converts into a standard group or regular path, depending on the structure of the original parent object.

  • To edit individual nodes: If the newly unlinked object is a path, switch to the Node Tool (N or F2) to adjust its vertices.
  • If it unlinks as a group: Select the object and press Ctrl + Shift + G (Windows/Linux) or Cmd + Shift + G (macOS) to ungroup the components and edit them separately.
