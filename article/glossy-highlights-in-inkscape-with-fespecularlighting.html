Glossy Highlights in Inkscape with feSpecularLighting

The feSpecularLighting filter primitive generates realistic, glossy highlights by calculating light reflected off an object’s alpha channel treated as a 3D heightmap. In Inkscape, you can construct custom filters using this primitive via the Filter Editor to transform flat vector elements into shiny, dimensional objects. This guide details how to build and configure an SVG filter network using feSpecularLighting, its nested light sources, and blending primitives to create dynamic gloss effects.

Accessing the Filter Editor

To build a custom filter with feSpecularLighting, you must work directly within Inkscape’s SVG filter graph tool:

  1. Select your target object on the canvas.
  2. Navigate to Filters > Filter Editor in the top menu to open the Filter Editor panel.
  3. Click the New button at the bottom of the left column to create an empty filter profile, then check the box next to your new filter to bind it to the selected object.

Creating the Base Heightmap

feSpecularLighting reads pixel opacity variations to determine surface curvature. Sharp vector edges produce harsh, unnatural reflections, so smoothing the alpha channel first creates a rounded surface profile.

  1. In the Add Primitive dropdown menu, select Gaussian Blur (feGaussianBlur) and click Add Primitive.
  2. Connect the input of the Gaussian Blur primitive to Source Alpha.
  3. Adjust the Standard Deviation slider to roughly 2–5 pixels depending on the size of your object. This blur defines the bevel curvature that the light will interact with.

Adding feSpecularLighting and Light Sources

  1. Select Specular Lighting (feSpecularLighting) from the primitive dropdown and click Add Primitive.
  2. Connect its input to the output of the Gaussian Blur node.
  3. In the effect parameters section, locate the Light Source configuration. Specular lighting requires one of three nested light sources:
    • Distant Light (feDistantLight): Simulates sunlight with parallel rays defined by Azimuth (direction) and Elevation (angle above the horizon). This is ideal for uniform highlights.
    • Point Light (fePointLight): Simulates an omnidirectional bulb with explicit X, Y, and Z (depth) coordinates.
    • Spot Light (feSpotLight): Focuses a conical beam defined by source coordinates, target points, and beam attenuation.
  4. For general gloss, choose Distant Light or Point Light, setting the light position above the canvas (a positive Z value).

Fine-Tuning the Surface and Specular Parameters

Adjust the attributes of the feSpecularLighting node to control the texture and intensity of the reflection:

  • Surface Scale: Determines the perceived height of the bump map. Higher values exaggerate the 3D extrusion of the edges, creating a thicker, more rounded bevel.
  • Specular Constant: Controls the overall brightness of the reflection. Default is 1.0; increase this value if the highlight appears too faint.
  • Specular Exponent: Dictates the sharpness or focus of the reflection. A low exponent (e.g., 5 to 10) produces a broad, soft, matte sheen. A high exponent (e.g., 30 to 80) produces a tight, highly polished, glass-like hotspot.
  • Lighting Color: Sets the tint of the highlight. Pure white (#FFFFFF) represents standard glossy plastic or glass, while tinted colors emulate metallic sheens.

Compositing the Highlight over the Source Graphic

By default, feSpecularLighting generates an isolated grayscale-to-white lighting map on an opaque black field. You must combine this highlight back with the original colored shape:

  1. Add a Composite primitive (feComposite) to the filter chain.
  2. In the connection graph, set Input 1 (Source) of the Composite node to the output of feSpecularLighting.
  3. Set Input 2 of the Composite node to Source Alpha.
  4. Set the Composite Operator to In. This masks the specular light strictly to the boundaries of the original vector object.
  5. Add a second Composite primitive to the chain.
  6. Connect Input 1 to the output of the previous Composite node (the masked highlight), and connect Input 2 to Source Graphic (the original colored shape).
  7. Set the Operator of this final Composite node to Arithmetic.
  8. Set the coefficients to: K1 = 0, K2 = 1, K3 = 1, and K4 = 0. This mathematically adds the white specular highlight directly on top of the base graphic's fill color without washing out dark tones or altering surrounding transparent regions.
