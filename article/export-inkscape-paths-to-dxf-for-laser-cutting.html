Export Inkscape Paths to DXF for Laser Cutting

Exporting vector designs from Inkscape to a DXF file requires converting all text, shapes, and strokes into clean, continuous vector paths that laser cutting software can interpret. This guide outlines the essential steps to prepare your artwork, convert elements into raw paths, eliminate duplicate lines, and save the file in the correct DXF format for precision cutting.

Step 1: Prepare and Ungroup Your Artwork

  1. Open your design in Inkscape.
  2. Select everything on your canvas by pressing Ctrl + A (or Cmd + A on Mac).
  3. Ungroup all nested elements by pressing Ctrl + Shift + G (or Cmd + Shift + G) repeatedly until the status bar at the bottom indicates that there are no groups left.

Step 2: Convert Objects and Text to Paths

Laser cutters cannot interpret live text or native Inkscape shapes (such as circles, rectangles, or stars) unless they are converted to paths.

  1. With all elements selected (Ctrl + A), go to the top menu and select Path > Object to Path (Shortcut: Shift + Ctrl + C).
  2. If your design contains text, this step converts each letter into a vector node outline.

Step 3: Convert Strokes to Paths (If Cutting Outlines)

If your design relies on stroke thickness rather than filled vector shapes:

  1. Select the stroked elements.
  2. Go to Path > Stroke to Path (Shortcut: Ctrl + Alt + C). Note: If you only want the laser to follow the centerline of the stroke for scoring or single-line cutting, skip this step and ensure the stroke width is minimal.

Step 4: Clean Up Intersecting Vectors

Overlapping paths can cause the laser to cut the same area twice or ruin internal geometries.

  1. Select overlapping shapes that should be cut as a single piece.
  2. Go to Path > Union (Shortcut: Ctrl + +) to merge them into a single continuous path.
  3. Remove any hidden or duplicate layers that could contain extra cut lines.

Step 5: Save as DXF

  1. Go to File > Save As... (or File > Export depending on your Inkscape version).
  2. In the file type dropdown menu, select AutoCAD DXF R14 (*.dxf) or Desktop Cutting Plotter (AutoCAD DXF R14) (*.dxf).
  3. Choose your destination folder, enter a file name, and click Save.

Step 6: Configure DXF Export Settings

A dialog box will appear with DXF export options:

  • Base Unit: Set this to the unit used by your laser cutting software (typically mm or in). Using the correct unit prevents scaling errors.
  • Character Encoding: Leave as Latin 1 or UTF-8.
  • Layer export selection: Choose whether to export visible layers or all layers.
  • ROBO-Master export: Uncheck this unless specifically required by your machine.
  • Click OK to generate the final DXF file.
