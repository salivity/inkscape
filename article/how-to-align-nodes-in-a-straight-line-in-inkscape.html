How to Align Nodes in a Straight Line in Inkscape

Aligning intermediate nodes along an imaginary straight line between two outer endpoints is a common task in Inkscape that ensures clean paths and precise geometry. While Inkscape includes native one-click tools to align nodes horizontally or vertically, aligning nodes along an angled or diagonal line between two outer nodes requires straightforward geometric techniques. This guide covers the built-in node alignment controls for horizontal and vertical lines, as well as the most efficient methods to align nodes along an arbitrary angled line.

Aligning Horizontal or Vertical Nodes

If the line between your two outer nodes is strictly horizontal or vertical, Inkscape provides a dedicated tool in the Node editor.

  1. Select the Edit paths by nodes tool from the toolbar (shortcut: N).
  2. Click on the path to reveal its nodes.
  3. Hold Shift and select all the nodes you wish to align, ensuring the two outer nodes are included in the selection.
  4. Open the Align and Distribute dialog by pressing Shift + Ctrl + A (or navigate to Object > Align and Distribute).
  5. In the dialog, locate the Node section at the bottom.
  6. Click Align selected nodes horizontally to level them along a horizontal axis, or click Align selected nodes vertically to line them up on a vertical axis.

Aligning Nodes Along an Angled Line Using Snapping

When the imaginary line connecting the two outer nodes is at an arbitrary angle, use Inkscape's path snapping engine to align intermediate nodes quickly and precisely.

  1. Enable snapping by toggling the Enable Snapping switch in the top-right corner of the window (shortcut: %).
  2. In the snapping popover, ensure that both Snap to paths and Snap to nodes (specifically cusp nodes and smooth nodes) are enabled.
  3. Select the Draw Bezier curves and straight lines tool (shortcut: B).
  4. Click the first outer node, then click the second outer node to draw a straight reference segment between them. Press Enter to complete the line.
  5. Switch back to the Node tool (N).
  6. Click and drag each intermediate node toward the reference line. Inkscape will automatically snap each node directly onto the path of the straight line.
  7. Once all nodes are placed, select and delete the temporary reference line.

Aligning Nodes Using Canvas Rotation

If you need mathematically perfect alignment across an angle without dragging individual nodes manually, rotate the canvas so the two outer nodes sit on a flat plane.

  1. Select the Node tool (N) and click the path.
  2. Drag a guide down from the top ruler. Position it over one of your outer nodes.
  3. Rotate the canvas using Ctrl + Middle-click drag (or enter an angle in the status bar at the bottom right) until both outer nodes rest precisely on the horizontal guide line.
  4. Select all the target nodes, including the two outer nodes.
  5. In the Align and Distribute panel (Shift + Ctrl + A), click Align selected nodes horizontally.
  6. Reset the canvas rotation by pressing Ctrl + 1 or double-clicking the rotation field in the bottom-right corner and resetting it to 0.0.

Recreating Nodes on a Straight Segment

If the intermediate nodes do not have unique attributes and you simply need evenly spaced or placed nodes on a straight line:

  1. Select the Node tool (N).
  2. Select only the intermediate nodes between the two endpoints and press Delete. The path segment between the two outer nodes will become a single straight line.
  3. Double-click anywhere on the new straight segment to insert a new node directly along the line, or select both endpoints and click Insert new nodes into selected segments in the top control bar to add evenly distributed nodes.
