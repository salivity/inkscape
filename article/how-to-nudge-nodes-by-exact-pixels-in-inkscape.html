How to Nudge Nodes by Exact Pixels in Inkscape

Moving nodes by precise pixel values in Inkscape is a straightforward process that combines the Node tool with keyboard shortcuts and step configuration settings. By configuring Inkscape's step preferences and using keyboard arrow keys along with modifier keys, you can quickly and accurately nudge individual or multiple vector nodes by exact pixel increments.

Step 1: Configure Exact Pixel Step Distance

To ensure arrow keys nudge nodes by an exact unit rather than an arbitrary default, set your preference step:

  1. Open the Preferences window by pressing Ctrl + Shift + P (or Cmd + Shift + P on macOS), or go to Edit > Preferences.
  2. In the left-hand menu, navigate to Behavior > Steps.
  3. Locate the setting labeled Arrow keys move by.
  4. Set the value to 1.0 and change the unit dropdown to px.
  5. Close the Preferences window.

Step 2: Select the Nodes to Move

  1. Select the Node Tool by pressing N or F2.
  2. Click on the path containing the nodes you want to edit.
  3. Click directly on a node to select it, hold Shift and click to select multiple nodes, or click and drag a bounding box around the desired nodes.

Step 3: Use Keyboard Shortcuts to Nudge Nodes

With the nodes selected, use the following shortcuts to reposition them:

  • Arrow Keys (Up, Down, Left, Right): Moves selected nodes by the exact distance configured in your preferences (e.g., 1 px).
  • Shift + Arrow Keys: Moves selected nodes by 10 times the default step (e.g., 10 px).
  • Alt + Arrow Keys: Nudges nodes by exactly 1 screen pixel, which scales dynamically based on your current zoom level.
  • Shift + Alt + Arrow Keys: Nudges nodes by 10 screen pixels based on your current zoom level.
