How to Configure Cairo for PDF Export in Inkscape

This guide explains how to configure the Cairo rendering engine when exporting PDF documents from Inkscape. You will learn how to access Cairo-driven export settings through the graphical interface, optimize rasterization resolution for unsupported SVG features, manage font embedding, and control Cairo output parameters directly from the command line.

Accessing the Cairo PDF Dialog in the GUI

Inkscape relies on the Cairo 2D graphics library to translate native SVG elements into PDF vector operators. To access these settings in the graphical interface:

  1. Open your document in Inkscape.
  2. Navigate to File > Save As... or File > Save a Copy...
  3. In the file type dropdown, select Portable Document Format (*.pdf).
  4. Choose a destination and click Save.

The PDF Export dialog window will appear. The options presented in this dialog directly configure how the Cairo backend processes the document.

Key Cairo Configuration Settings

Because Cairo cannot map every SVG feature to native PDF constructs, several settings must be configured to balance file size and visual fidelity:

  • PDF Version Compatibility: Select the PDF standard (typically PDF 1.4 or PDF 1.5). Choosing PDF 1.4 or higher allows Cairo to preserve native alpha transparency rather than flattening the design into opaque layers.
  • Convert Text to Paths: Enabling this forces Cairo to trace text characters as vector shapes. This prevents font substitution or missing glyph issues on systems lacking the installed fonts, though it makes the final text unsearchable and unselectable.
  • Embed Fonts: Leaving text as native text directs Cairo to embed subset fonts into the PDF, maintaining searchability and crisp vector rendering.
  • Rasterize Filter Effects: SVG filters (such as Gaussian blurs, drop shadows, and blend modes) are not natively supported by standard PDF vector specifications. When checked, Cairo isolates these elements and converts them into raster bitmaps.
  • Resolution for Rasterization (DPI): Sets the pixel density for rasterized filter effects and fallback objects. For standard office printing, set this to 300 DPI. For professional press work, use 600 DPI, or reduce to 96–150 DPI to decrease file size for digital-only distribution.
  • Bleed / Margin Settings: Define bleed margins around the document if exporting for print production to ensure background artwork extends beyond the trim line.

Configuring Cairo via the Command-Line Interface (CLI)

For automated workflows, you can pass Cairo configuration flags to the Inkscape executable without opening the graphical interface.

Basic Export Command

inkscape input.svg --export-filename=output.pdf --export-type=pdf

Advanced Export with Cairo Settings

To specify the PDF version, rasterization DPI, and font handling:

inkscape input.svg \
  --export-filename=output.pdf \
  --export-type=pdf \
  --export-pdf-version=1.5 \
  --export-dpi=300 \
  --export-text-to-path
  • --export-pdf-version: Sets the PDF specification version (e.g., 1.4 or 1.5).
  • --export-dpi: Adjusts the raster resolution for Cairo fallback rasterization.
  • --export-text-to-path: Bypasses font embedding by converting typography into vector paths.
  • --export-area-page or --export-area-drawing: Defines whether Cairo crops output to the page boundaries or includes the entire bounding box of drawn objects.
