Export All Embedded Images from Inkscape

Inkscape allows users to easily extract embedded raster graphics—such as PNG and JPEG files—and save them directly to your hard drive. Instead of manually taking screenshots or re-exporting slices, you can use Inkscape's built-in extension tools or context menu options to automatically unpack and link embedded images to a dedicated folder.

Method 1: Batch Extract Using the Extensions Menu

This method is the fastest way to extract all embedded raster images from an entire document at once.

  1. Open your SVG file in Inkscape.
  2. Deselect all objects by pressing Esc or clicking an empty area on the canvas (ensures the tool checks the whole document).
  3. Navigate to the top menu and select Extensions > Images > Extract Image...
  4. In the dialog window that appears, configure the extraction settings:
    • Directory: Enter the full file path to the folder where you want to save the extracted images.
    • Extract only selected images: Ensure this box is unchecked if you want to export every embedded image in the document.
    • Link extracted images: Check this if you want Inkscape to replace the embedded data with links to the newly created external image files.
  5. Click Apply.

Inkscape will process the file and write all embedded raster images into your specified directory.

Method 2: Extract Individual Images via Context Menu

If you only need to extract specific images rather than the entire collection, you can extract them individually:

  1. Click on the embedded image using the Select and Transform objects tool (S or F1).
  2. Right-click the image on the canvas.
  3. Select Extract Image... from the context menu.
  4. Choose a destination folder and file name in the file browser.
  5. Click Save.

Key Tips for Successful Extraction

  • File Paths: On Windows, ensure the directory path uses forward slashes / or double backslashes \\ if you type the path manually into the extension field.
  • Preserving Original Files: Make a backup copy of your original SVG before running extraction tools if you check the "Link extracted images" option, as this alters the file's internal structure from self-contained base64 data to relative file paths.
