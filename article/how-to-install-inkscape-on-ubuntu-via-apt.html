How to Install Inkscape on Ubuntu via APT

This guide explains how to install Inkscape, a powerful open-source vector graphics editor, on Ubuntu using the APT package manager. You will learn the commands required to install the software using both the standard Ubuntu default repositories and the official Inkscape Personal Package Archive (PPA) to ensure you have the latest stable release.

Method 1: Install Inkscape from the Default Ubuntu Repository

This is the quickest method, though it may not always provide the very latest release of Inkscape.

Step 1: Update Your Package List

Open your terminal by pressing Ctrl + Alt + T and refresh your local package index:

sudo apt update

Step 2: Install Inkscape

Run the following command to install Inkscape and its required dependencies:

sudo apt install inkscape -y

Step 3: Verify the Installation

Check that the installation was successful and verify the installed version:

inkscape --version

Method 2: Install the Latest Version via Official Inkscape PPA

If you require the newest features and updates not yet available in the default Ubuntu repositories, use the official Inkscape PPA.

Step 1: Add the Official Inkscape PPA

Add the stable PPA repository to your system:

sudo add-apt-repository ppa:inkscape.dev/stable

Press Enter when prompted to confirm.

Step 2: Update the Package Index

Update your system's package list to include the newly added PPA:

sudo apt update

Step 3: Install Inkscape

Install or upgrade to the latest version of Inkscape:

sudo apt install inkscape -y

How to Launch Inkscape

Once installed, you can launch Inkscape in two ways:

  • Via Terminal: Type inkscape and press Enter.
  • Via Application Menu: Search for Inkscape in your Ubuntu Application launcher and click the icon.

How to Uninstall Inkscape via APT

If you need to remove Inkscape from your system, execute:

sudo apt remove inkscape -y
sudo apt autoremove -y

If you used the PPA and wish to remove it as well, run:

sudo add-apt-repository --remove ppa:inkscape.dev/stable
