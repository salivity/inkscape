Export Inkscape Vectors to OpenSCAD for 3D Printing

Exporting 2D vector contours from Inkscape to OpenSCAD is a fast and precise way to transform graphic designs into extruded 3D-printable models. This workflow requires preparing closed vector paths in Inkscape, exporting them as standard SVG or DXF files, and using OpenSCAD’s import() and linear_extrude() functions to convert the flat profiles into solid geometries ready for slicing and 3D printing.

Step 1: Prepare the Vector in Inkscape

OpenSCAD requires 2D geometry to consist of clean, closed contours. Open your design in Inkscape and prepare the geometry:

  1. Convert Objects to Paths: Select all elements in your document and navigate to Path > Object to Path (Shift + Ctrl + C).
  2. Convert Strokes to Paths: If your design relies on stroke thickness rather than filled shapes, go to Path > Stroke to Path (Ctrl + Alt + C).
  3. Combine Shapes: Use Boolean operations like Path > Union (Ctrl + +) or Path > Difference (Ctrl + -) to merge overlapping geometry and remove duplicate interior lines.
  4. Set Units to Millimeters: Go to File > Document Properties (Shift + Ctrl + D) and set the Display units to mm. Align your design with the page origin (bottom-left or top-left corner) to ensure predictable positioning in OpenSCAD.

Step 2: Export the File

OpenSCAD supports both SVG and DXF imports. Standard SVG is recommended for modern versions of OpenSCAD.

  • For SVG (Recommended): Go to File > Save As, choose Plain SVG (*.svg), and save your file in your OpenSCAD project folder.
  • For DXF: Go to File > Save As, select AutoCAD DXF R14 (*.dxf), and check Use LWPOLYLINE type to ensure paths remain continuous. Set base units to millimeters.

Step 3: Import and Extrude in OpenSCAD

Create a new script in OpenSCAD and save it in the same directory as your exported vector file. Use the import() and linear_extrude() modules to give the 2D path thickness:

// Set extrusion height in millimeters
extrusion_height = 5;

// Extrude the vector design
linear_extrude(height = extrusion_height, center = false, convexity = 10) {
    import("design.svg", center = true, dpi = 96);
}

Note: If using a DXF file, replace "design.svg" with "design.dxf" and omit the dpi parameter.

Step 4: Render and Export for 3D Printing

  1. Press F5 to preview the extruded model in OpenSCAD.
  2. Press F6 to fully render the 3D geometry (Computational Geometry / CGAL).
  3. Go to File > Export > Export as STL... (or 3MF).
  4. Load the exported STL file into your slicer software (such as PrusaSlicer, Cura, or Bambu Studio) and slice it for 3D printing.
