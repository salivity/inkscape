Export Cut Lines from Inkscape to Roland CutStudio

This guide explains how to prepare, format, and export vector cut lines in Inkscape so they can be seamlessly imported and cut using Roland CutStudio. By properly converting shapes to vector paths, setting precise stroke weights, and choosing the correct export format, you can ensure your vinyl cutter reads your design outlines accurately without unwanted blade passes or missing lines.

1. Convert Objects and Text to Paths

Roland CutStudio requires vector path data rather than editable text or grouped parametric objects to determine blade trajectories.

  1. Open your design in Inkscape.
  2. Select any text elements and go to Path > Object to Path (Shift+Ctrl+C).
  3. If you are starting from a raster image (PNG or JPEG), select it and choose Path > Trace Bitmap (Shift+Alt+B) to generate a clean vector outline, then delete the original raster image underneath.
  4. Select all objects and ungroup them by pressing Ctrl+Shift+G until no groups remain.

2. Configure Stroke and Fill for Cutting

CutStudio interprets vector strokes as cut paths. Removing fills and defining a thin stroke ensures the software only identifies the intended cut boundaries.

  1. Select your entire artwork with Ctrl+A.
  2. Open the Fill and Stroke panel (Object > Fill and Stroke or Shift+Ctrl+F).
  3. Under the Fill tab, click the X (No paint) icon to remove all fills.
  4. Under the Stroke paint tab, select Flat color and assign a distinct solid color (such as pure black or magenta).
  5. Under the Stroke style tab, set the unit to millimeters or points, and adjust the line width to a hairline thickness, ideally 0.1 mm (or 0.25 pt).

3. Remove Intersecting Lines

If your artwork has overlapping vector elements, the blade will cut through overlapping areas and damage the vinyl.

  1. Select overlapping shapes that should be cut as a single boundary.
  2. Go to Path > Union (Ctrl++) to merge them into one continuous outline.
  3. Use the Edit paths by nodes tool (F2) to delete any stray or unintended internal lines.

4. Export the File for CutStudio

Roland CutStudio reliably imports vector line art via the Encapsulated PostScript (.eps) format.

  1. Go to File > Save As...
  2. In the file format dropdown, select Encapsulated PostScript (*.eps).
  3. Name your file and click Save.
  4. In the EPS export options dialog:
    • Set Output page size to Use exported object's size.
    • Ensure Convert texts to paths is checked.
    • Set Rasterize filter effects to unchecked.
    • Click OK.

(Alternative: You can also select **Desktop Cutting Plotter (AutoCAD DXF R14) (.dxf)** if EPS files do not import at the correct scale on your specific CutStudio version).*

5. Import and Cut in Roland CutStudio

  1. Launch Roland CutStudio.
  2. Go to File > Import.
  3. Locate and select your exported .eps or .dxf file, then click Open.
  4. Verify that your graphics appear with sharp, distinct cutting lines.
  5. Use the Cutting Setup tools to position the design according to your vinyl width, set the origin point, and send the job to your Roland plotter.
