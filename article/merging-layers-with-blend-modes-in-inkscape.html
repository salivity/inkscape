Merging Layers with Blend Modes in Inkscape

When merging layers in Inkscape, blend modes applied at the layer level are not preserved across the merged elements. Because Inkscape treats layers as SVG groups, merging them collapses the container holding the blend mode property, forcing all objects into the destination layer. This article explains how Inkscape processes blend modes during a layer merge, the visual consequences on your artwork, and methods to preserve your intended effects.

How Inkscape Handles Layer Blending

In Inkscape, a layer is essentially an SVG group (<g>) with a custom attribute defining it as a layer. When you apply a blend mode (such as Multiply, Screen, or Overlay) through the Layers panel, Inkscape applies that blend mode to the entire layer group container rather than to the individual paths, shapes, or text inside it.

What Happens During "Merge Down"

When you select an upper layer and choose Merge Down, Inkscape performs the following actions:

  1. Object Relocation: All individual objects inside the upper layer are transferred into the lower (destination) layer's group hierarchy.
  2. Container Deletion: The upper layer's group container is deleted from the SVG code.
  3. Loss of Blend Mode Settings: Because the blend mode was attached to the upper layer container, it is discarded along with that container.
  4. Adoption of the Lower Layer's Properties: The transferred objects immediately inherit the lower layer's blend mode and opacity settings. If the destination layer is set to "Normal" blend mode with 100% opacity, the merged objects will display as normal, completely losing the visual blending interaction they previously had with the elements below them.

How to Preserve Blend Modes When Combining Elements

If you need to combine your artwork without losing specific blend mode interactions, use one of the following alternatives:

  • Apply Blend Modes to Objects Directly: Instead of setting the blend mode on the layer itself, select the objects and adjust their blend modes via the Fill and Stroke panel (Shift + Ctrl + F) or the Object Properties panel. Object-level blend modes remain attached to the individual paths even after layers are merged.
  • Group Before Merging: Group the elements on the top layer (Ctrl + G) and assign the blend mode directly to that group. When the layer is merged down, the group retains its specific blend mode attributes within the destination layer.
  • Create a Bitmap Copy: If the artwork is finished and does not need to remain in vector format, select the interacting layers and choose Edit > Make a Bitmap Copy (Alt + B). This renders the blend mode result directly into a flattened raster image.
