Inkscape Glow: feMorphology and feGaussianBlur

Combining feMorphology and feGaussianBlur in Inkscape allows you to build expansive, luminous halos around objects without losing the sharpness of the original artwork. While a standard blur merely softens the boundaries of a shape, pairing a morphology dilation step before the blur physically extends the object’s footprint outward first. This guide explains how SVG filter primitives work together and provides the direct steps to create this custom glowing effect using Inkscape’s Filter Editor.

Why Combine Dilation and Gaussian Blur?

Applying feGaussianBlur directly to a shape diffuses its alpha channel inward and outward equally, which often causes thin lines or text to lose their definition and appear dim.

The feMorphology primitive with its operator set to dilate thickens the object's alpha mask uniformly by a specified radius. When you route this widened mask into feGaussianBlur, the blur diffuses from an expanded boundary. This ensures the halo radiates well beyond the object's perimeter while retaining an intense, solid core.

Step-by-Step Implementation in Inkscape

To build this filter, select your vector object and open the Filter Editor panel by navigating to Filters > Filter Editor.

  1. Create the Base Filter

    • Click New in the Filter Editor panel to generate an empty filter container.
    • Rename the filter to "Luminous Halo" for easy identification.

  2. Add and Configure feMorphology

    • In the Add Effect drop-down menu, select Morphology and click Add Effect.
    • In the connection matrix, set the input of feMorphology to SourceAlpha.
    • Under the Effect parameters tab, set the Operator to Dilate.
    • Adjust the Radius (X and Y). A radius between 3 and 10 pixels works well depending on the size of the artwork and how far you want the glow to reach.

  3. Add and Configure feGaussianBlur

    • Select Gaussian Blur from the drop-down menu and click Add Effect.
    • Route the input of feGaussianBlur to the output of the feMorphology primitive.
    • In the Effect parameters, adjust the Standard Deviation. A value roughly equal to or slightly higher than your dilation radius will produce a smooth, radiant fade.

  4. Color the Halo with feFlood and feComposite

    • Add a Flood primitive. Choose your desired glow color and opacity in the parameters tab.
    • Add a Composite primitive. Connect the first input to the Flood effect and the second input to the Gaussian Blur effect.
    • Set the composite Operator to in. This clips the flood color exclusively to the blurred, dilated shape.

  5. Merge with the Original Object

    • Add a Merge primitive to the chain.
    • Connect the first merge input node to the output of your Composite primitive (the glow).
    • Connect the second merge input node to SourceGraphic (the original, crisp vector).

Check the box next to your new filter in the Filter Editor list to apply it to your selected shape. You can tweak the morphology radius, blur amount, or flood color in real time to balance the size and softness of the surrounding halo.
