Create Duotone Vectors in Inkscape

This guide provides a straightforward tutorial on creating two-tone (duotone) vector illustrations using Inkscape. You will learn how to convert source images or existing graphics into dynamic, high-contrast vector art by isolating shadow and highlight values, applying vector path operations, and styling your design using a limited two-color palette.

Method 1: Converting a Photo into a Duotone Vector

Converting a raster image into a stylized duotone graphic is the fastest way to achieve this aesthetic.

1. Import and Prepare Your Image

  1. Open Inkscape and go to File > Import to load your source image.
  2. Select the image and go to Filters > Color > Grayscale (or adjust saturation) to better evaluate light and shadow values.

2. Trace the Bitmap

  1. Select the image and open the tracing tool via Path > Trace Bitmap.
  2. Under the Single scan tab, select Brightness cutoff.
  3. Adjust the Threshold slider until the preview captures the distinct contrast you want for your foreground shadows.
  4. Click Apply. Inkscape will generate a black-and-white vector path over your original image.
  5. Delete or move the original bitmap image out of the canvas.

3. Create the Background and Set Duotone Colors

  1. Select the Rectangle tool (R) and draw a box that completely covers your canvas or design boundary.
  2. Send the rectangle to the bottom layer by pressing the Page Down key or clicking Object > Lower to Bottom.
  3. Pick your background color (the light or primary tone) from the color palette at the bottom.
  4. Select the traced vector path on top and pick your contrasting foreground color (the shadow or accent tone).

Method 2: Creating Duotone Art from Existing Vector Shapes

If you are working with an existing multi-colored vector illustration, follow these steps to reduce it to a two-tone design.

1. Separate Artwork into Two Light Values

  1. Ungroup your artwork completely using Ctrl + Shift + G (or Cmd + Shift + G on macOS).
  2. Categorize all elements into either "Highlights" (light tone) or "Shadows" (dark tone).

2. Combine Paths by Value

  1. Select all the shapes designated as shadows and merge them into a single path by navigating to Path > Union (Ctrl + +).
  2. Select all the shapes designated as highlights and combine them using Path > Union.

3. Apply the Two-Color Palette

  1. Select the combined shadow path and apply your darker palette color using the Fill and Stroke panel (Ctrl + Shift + F).
  2. Select the combined highlight path (or background shape) and apply your lighter palette color.

Tips for Refining Duotone Illustrations

  • Use High-Contrast Color Combinations: Popular pairings include navy blue and bright orange, deep purple and neon yellow, or dark cyan and warm white.
  • Add Midtone Accents with Halftones: If you need a perceived third tone without adding an extra color, use the Circle tool to create a dot matrix/halftone pattern using the foreground color over the background.
  • Clean Up Stray Nodes: Use the Node Tool (N) to delete unnecessary artifacts generated during the Trace Bitmap process to keep your final vector file lightweight and sharp.
