Create Sewing Notches and Grainlines in Inkscape

Digital pattern drafting requires precise reference marks to ensure fabric pieces align properly during assembly. This guide provides a straightforward method for designing functional sewing notches—including single, double, and external triangle notches—and standardized grainline alignment markers using Inkscape's vector drawing, snapping, and stroke tools.

Set Up the Workspace and Snapping

Open Inkscape and set your document units to inches or millimeters via File > Document Properties. Enable the snapping toolbar on the right side of the screen. Ensure Snap to paths, Snap to cusp nodes, and Snap to path intersections are toggled on. Snapping ensures that your notches and grainlines attach directly to the cutting lines and seam allowances without accidental offsets.

Design Grainline Alignment Markers

A grainline indicates the fabric's warp direction and typically consists of a long line with arrows at one or both ends.

  1. Select the Draw Bezier curves and straight lines tool (B). Hold Ctrl to constrain the angle and click twice to draw a perfectly straight vertical or horizontal line across the body of your pattern piece.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F) and select the Stroke style tab. Set an appropriate stroke width (e.g., 0.5 mm or 1 pt).
  3. In the Markers section of the Stroke style tab, select an arrowhead from the start and end marker dropdown menus. Standard drafting uses either double-ended arrows or single-ended arrows pointing downward.
  4. Select the Text tool (T), type "GRAINLINE", and place the text parallel to the line.
  5. Select both the line and the text, open the Align and Distribute panel (Ctrl + Shift + A), center them horizontally, and press Ctrl + G to group them together.

Create Slit Notches (Internal Marks)

Slit notches are simple tick marks that cross the seam allowance to show matching points.

  1. Using the Bezier tool, draw a straight line perpendicular to the pattern edge. A standard notch length is typically 0.25 inches (6 mm).
  2. Use the Stroke style panel to set the line weight to match your pattern's inner markings.
  3. For a double notch (commonly used for back armholes and yokes), select the slit line, press Ctrl + D to duplicate it, and use the arrow keys to nudge the copy 0.25 inches (6 mm) to the side.
  4. Select both lines and press Ctrl + G to group them.
  5. Move the notch to the pattern perimeter. Because snapping is active, the notch node will lock directly onto the pattern edge.

Create External Triangle Notches

External triangle notches point outward from the cutting line, which is useful when working with fraying fabrics.

  1. Select the Stars and Polygons tool (*). In the top control bar, set the shape to Polygon and Corners to 3.
  2. Hold Ctrl while dragging on the canvas to draw an equilateral triangle with a flat base.
  3. In the top toolbar, set the triangle's dimensions manually—a standard size is 0.35 inches (9 mm) wide by 0.3 inches (7.5 mm) high.
  4. To create a double triangle notch, duplicate the triangle (Ctrl + D), position it adjacent to the first, select both, and click Path > Union (Ctrl + +) if you want them merged as a single vector.
  5. Position the base of the triangle flush against the pattern cutline using snapping. If you want the notch integrated into the cutting line itself, select both the pattern piece and the triangle notch, then run Path > Union.

Align Notches to Curved Seams

Sewing patterns feature curved seams like armscyes and necklines.

  1. Place your notch on the target node along the curved path.
  2. Click the notch a second time to activate the rotation handles.
  3. Move the center rotation pivot to the point where the notch touches the seamline.
  4. Drag a corner rotation handle until the notch is perpendicular (90 degrees) to the curve's tangent at that exact point.
