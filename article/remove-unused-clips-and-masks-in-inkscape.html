Remove Unused Clips and Masks in Inkscape

When editing complex SVG graphics, Inkscape often retains removed or altered clip paths and masks inside the file's definitions section, which can unnecessarily bloat the file size. This guide explains how to quickly find and remove these unused clip paths and masks using Inkscape’s automated cleanup tools, the XML Editor, and export settings.

Method 1: Use the Clean Up Document Tool

The fastest way to purge all unreferenced resources—including clip paths, masks, gradients, and patterns—is by using the native cleanup command.

  1. Open your SVG file in Inkscape.
  2. In the top menu, go to File > Clean Up Document.
  3. Inkscape will automatically scan the <defs> section of your file and delete any definitions that are no longer actively applied to an object on the canvas.
  4. Save your file (Ctrl + S or Cmd + S).

Method 2: Manually Remove via the XML Editor

If you want granular control over which definitions are deleted, you can manage the SVG tree directly.

  1. Open the XML Editor by navigating to Edit > XML Editor (or press Ctrl + Shift + X / Cmd + Shift + X).
  2. In the tree view on the left, locate and click the arrow to expand the <svg:defs> tag.
  3. Look for elements labeled <svg:clipPath> or <svg:mask>.
  4. Select the specific clip path or mask you wish to remove.
  5. Click the Delete node button (represented by a trash can or red "X" icon) at the top of the XML Editor panel.
  6. Close the XML Editor and save your document.

Method 3: Export as Optimized SVG

You can also strip unused definitions automatically during the export process.

  1. Go to File > Save As...
  2. In the file format dropdown, select Optimized SVG (*.svg) and click Save.
  3. In the optimization dialog that appears, go to the SVG Output tab.
  4. Ensure the option to remove unused elements and definitions is checked.
  5. Click OK to save a streamlined version of your graphic without unused clip paths or masks.
