Inkscape Voronoi Diagram: Adjust Spacing and Borders

This article explains how to modify the border thickness and cell spacing of a Voronoi diagram in Inkscape. Because Inkscape’s native Voronoi Diagram extension generates standard vector paths rather than a procedural pattern, adjustments to border widths and inter-cell gaps are handled directly on the canvas using native path and stroke manipulation tools.

Generating the Voronoi Diagram

  1. Select a group of objects, nodes, or points on your canvas.
  2. Navigate to Extensions > Generate from Path > Voronoi Diagram.
  3. Choose Voronoi diagram as the diagram type and click Apply, then Close.

The resulting diagram will be placed on your canvas as a grouped set of vector paths.

Adjusting Border Thickness

The border thickness of Voronoi cells is controlled through standard stroke settings:

  1. Select the generated Voronoi diagram.
  2. Open the Fill and Stroke panel by pressing Ctrl + Shift + F (or Cmd + Shift + F on macOS).
  3. Switch to the Stroke paint tab and ensure a flat color is applied to make the borders visible.
  4. Go to the Stroke style tab.
  5. In the Width field, enter your desired thickness value and select your preferred unit of measurement (such as pixels or millimeters).
  6. Adjust the Join setting to round or bevel if you want to soften sharp corners where edges intersect.

Adjusting Cell Spacing

The Voronoi extension does not include an internal slider for cell gaps, but you can create uniform spacing between cells using two distinct methods:

Method 1: Using Path Inset (Geometric Gap)

This method creates actual empty space between the cells, which is ideal if you need a transparent background or intend to cut the design with a plotter or laser cutter.

  1. Select the Voronoi diagram and ungroup it by pressing Ctrl + Shift + G (or Cmd + Shift + G).
  2. With all individual cells selected, verify they have a fill color applied.
  3. Go to Path > Inset (or press Ctrl + ().
  4. Repeat the shortcut until the cells have shrunk to your desired spacing.
  5. To change how much the path insets per keystroke, go to Edit > Preferences > Behavior > Steps and adjust the Inset/Outset by value.

Method 2: Using Stroke as Spacing (Visual Gap)

This method is faster for graphic design projects where physical path separation is not strictly required.

  1. Ungroup the diagram using Ctrl + Shift + G.
  2. Select all cells and open the Fill and Stroke panel.
  3. On the Stroke paint tab, set the stroke color to match your canvas or background color.
  4. On the Stroke style tab, increase the stroke Width.

As the stroke expands, it covers the borders between neighboring cells, effectively increasing the visual spacing between their filled centers.
