How to Push and Pull Paths with Inkscape Tweak Tool

Inkscape’s Tweak tool allows you to sculpt vector paths dynamically, treating lines and shapes like digital clay. This guide explains how to activate the Tweak tool, select the correct path-deformation mode, adjust essential brush parameters such as width and force, and fluidly push and pull vector segments without manually adjusting individual nodes.

1. Prepare the Vector Object

Before you can manipulate a shape with the Tweak tool, it must be an editable path:

  1. Select your object with the Select Tool (S).
  2. Go to the top menu and click Path > Object to Path (or press Shift + Ctrl + C) if working with a basic shape, text, or star.
  3. Keep the path selected so the Tweak tool knows which object to modify.

2. Activate the Tweak Tool

  1. Click the Tweak objects by sculpting or painting icon in the left-hand toolbox, or press W on your keyboard.
  2. Ensure your target path remains highlighted with a bounding box or node outline.

3. Select the "Push Path" Mode

Look at the Tool Controls Bar at the top of the canvas. The Tweak tool has several modes for objects, colors, and paths.

  1. Locate the path manipulation section in the toolbar.
  2. Click the Push parts of paths in any direction icon (represented by an arrow pushing against a path segment).

4. Adjust Width and Force Settings

Configure your brush behavior before interacting with the path:

  • Width: Controls the radius of the brush influence. Set a larger width for broad curves and a smaller width for fine details. You can quickly change the brush size by pressing the Left Arrow and Right Arrow keys.
  • Force: Controls how aggressively the path reacts to your cursor movements. A lower value (e.g., 20–40) provides subtle, controlled adjustments, while a higher value dramatically deforms the path quickly. Adjust force using the Up Arrow and Down Arrow keys.
  • Pressure Sensitivity: If you are using a drawing tablet, enable the pressure icon next to the Width or Force fields to control deformation dynamically with pen pressure.

5. Push and Pull the Segments

  1. Place your cursor near or over the edge of the selected path.
  2. Click and drag in the direction you want the path segment to move.
  3. Dragging outward pulls the path to expand the shape; dragging inward pushes the path to create indentations.
  4. Make continuous, gentle brush strokes to gradually sculpt smooth contours.

6. Refine and Clean Up the Path

Sculpting dynamically adds nodes to maintain curvature, which can occasionally create dense or jagged geometry.

  • Smooth the deformation: Switch to the Shrink/Grow or Roughen/Smooth path modes on the Tweak toolbar to polish uneven sections.
  • Simplify the path: If the path becomes cluttered with too many nodes, press Ctrl + L (Path > Simplify) to reduce node count while preserving the overall sculpted form.
