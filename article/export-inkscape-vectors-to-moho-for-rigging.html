Export Inkscape Vectors to Moho for Rigging

Transferring vector art from Inkscape to Moho requires preparing clean geometry, exporting in a compatible format, and adjusting the imported vectors for character rigging. This guide covers how to optimize paths and node counts in Inkscape, export the artwork as a Plain SVG, and properly configure the imported vector layers in Moho so your linework deforms smoothly with bone rigs.

1. Prepare Linework in Inkscape

Moho’s vector engine functions differently from standard illustration software. Moho relies on points, curvature, and connected edges rather than traditional Bézier handles. To ensure clean rigging later, prepare your artwork first:

  • Reduce Node Count: Moho performs best with minimal points. Select your paths and use Path > Simplify (Ctrl + L) to remove unnecessary nodes while preserving the silhouette.
  • Convert or Maintain Strokes: Decide whether you want outline strokes or filled shapes. If you want outlines that adjust thickness uniformly, keep them as basic strokes. If your linework features complex calligraphic widths, convert them via Path > Stroke to Path.
  • Remove Unsupported Features: Moho does not fully translate Inkscape-specific features such as live path effects, complex clipping masks, mesh gradients, or layer blend modes. Flatten effects and convert objects to standard paths using Path > Object to Path.
  • Separate Body Parts: Place distinct body parts (head, torso, upper arm, lower arm, etc.) into separate layers or distinct groups in Inkscape to make layer organization inside Moho easier.

2. Export as Plain SVG

Once the linework is clean, export it in a standard SVG format:

  1. Go to File > Save As....
  2. In the file type dropdown menu, select Plain SVG (*.svg) instead of the default "Inkscape SVG".
  3. Name your file and click Save.

Plain SVG strips proprietary Inkscape metadata, which prevents import errors and coordinate shifting inside Moho.

3. Import the SVG into Moho

  1. Open your project in Moho.
  2. Navigate to File > Import > General Import... or File > Import > SVG... (depending on your Moho version).
  3. Select your saved Plain SVG file.

Moho will generate a new group layer containing individual vector layers corresponding to the paths and groups created in Inkscape.

4. Optimize Linework for Moho Rigging

Before attaching bones, you must refine the vector data inside Moho to allow for seamless deformation:

  • Weld Open Points: Inkscape paths may import with disconnected endpoints. Use Moho's Transform Points tool (T) with Auto-weld enabled to merge overlapping points at joints.
  • Adjust Curvature: Moho translates Bézier curves into point curvature values. Use the Curvature tool (C) to adjust the roundness or sharpness of corners along your linework.
  • Set Stroke Exposure: Check that line widths are properly recognized. Use the Stroke Width tool (W) to normalize or taper lines where limbs bend.
  • Organize Layer Hierarchy: Move your vector layers into a Bone Layer. Ensure each articulating part (such as hands, limbs, and joints) resides on its own vector layer or is properly grouped for point binding, smooth flexi-binding, or use with smart warp meshes.
