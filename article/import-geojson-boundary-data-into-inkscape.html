Import GeoJSON Boundary Data into Inkscape

Inkscape does not natively parse GeoJSON files, meaning spatial data must first be converted into a compatible vector format before it can be edited. This guide explains how to convert GeoJSON boundary data into Scalable Vector Graphics (SVG) using free tools like Mapshaper, QGIS, or command-line utilities, and how to import those paths directly into Inkscape for graphic design and styling.

Method 1: Using Mapshaper (Fastest Web-Based Method)

Mapshaper is a free, browser-based tool designed to edit and convert spatial vector data quickly.

  1. Navigate to mapshaper.org in your web browser.
  2. Drag and drop your .geojson or .json file into the browser window, then click Import.
  3. (Optional) If your boundary file is too complex or large, click the Simplify button in the top-right corner to reduce the node count while retaining geographic shape.
  4. Click Export in the top-right corner.
  5. Select SVG as the export format and click Export.
  6. Open Inkscape, navigate to File > Open, and select your newly downloaded SVG file.

Method 2: Using QGIS (For Custom Projections and Coordinate Systems)

If your GeoJSON requires specific map projections or coordinate reference systems (CRS) before editing, QGIS offers precise control.

  1. Open QGIS and drag the GeoJSON file into the workspace.
  2. Set the project CRS to your desired projection (e.g., EPSG:3857 for Web Mercator or a localized UTM zone) via the CRS status bar in the bottom-right corner.
  3. Go to Project > New Print Layout.
  4. Add a map frame by selecting Add Item > Add Map and dragging a box over the canvas.
  5. Adjust the scale and extent to center your boundaries within the page.
  6. Go to Layout > Export as SVG.
  7. In the export dialog, ensure Export map layers as SVG groups is checked, then save the file.
  8. Open the exported SVG in Inkscape.

Method 3: Using GDAL / ogr2ogr (Command-Line)

If you prefer automation or working directly from the terminal, the GDAL library can convert GeoJSON directly to SVG.

  1. Install GDAL on your system.
  2. Run the following command in your terminal: 
    ogr2ogr -f "SVG" output.svg input.geojson
  3. Open output.svg directly in Inkscape.

Editing Boundary Paths in Inkscape

Once your converted vector file is open in Inkscape:

  1. Ungroup the Paths: Imported vector maps often arrive grouped inside multiple layers. Select the imported object and press Ctrl + Shift + G (or Cmd + Shift + G on macOS) repeatedly until individual boundary polygons or lines can be selected independently.
  2. Inspect Nodes: Switch to the Edit paths by nodes tool (N) to confirm that boundaries are native Bézier paths. You can modify, simplify (Ctrl + L), or delete specific boundary lines.
  3. Apply Styles: Use the Fill and Stroke panel (Ctrl + Shift + F) to define boundary outlines, change line weights, or add color fills to individual geographic regions.
