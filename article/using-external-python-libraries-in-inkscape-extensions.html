Using External Python Libraries in Inkscape Extensions

Inkscape extensions rely on an underlying Python interpreter to execute scripts, but utilizing advanced third-party libraries like NumPy or SciPy requires configuring the extension to see those dependencies. Depending on your operating system and deployment preferences, you can make external libraries accessible by installing them directly into Inkscape's bundled Python environment, modifying sys.path within your extension script, or delegating computation to an external Python environment via subprocess.

Understanding the Inkscape Python Environment

How Inkscape executes Python depends on the operating system:

  • Linux: Inkscape uses the system-level Python interpreter. If an extension requires NumPy or SciPy, it expects them to be installed in the system environment or user site-packages.
  • Windows and macOS: Inkscape typically bundles its own isolated Python distribution. Installing packages to your global system Python will not make them available to Inkscape extensions by default.

Method 1: Install Directly into Inkscape's Bundled Python

On Windows and macOS, you can use the bundled interpreter to run pip and install packages directly into Inkscape’s internal environment.

Windows

  1. Open Command Prompt or PowerShell as Administrator.
  2. Locate Inkscape’s internal Python executable (typically located in C:\Program Files\Inkscape\bin\ or C:\Program Files\Inkscape\bin\python.exe).
  3. Run pip using that specific executable:
"C:\Program Files\Inkscape\bin\python.exe" -m pip install numpy scipy

macOS

  1. Open Terminal.
  2. Target the Python binary inside the Inkscape application bundle:
/Applications/Inkscape.app/Contents/Resources/bin/python3 -m pip install numpy scipy

Once installed, your extension script can import these libraries normally:

import inkex
import numpy as np
from scipy.spatial import Voronoi

Method 2: Dynamically Append an External Environment (sys.path)

If you want to avoid altering Inkscape’s internal files or need to use a dedicated virtual environment (venv or Conda), you can dynamically append the path of that environment's site-packages directory to sys.path inside your extension script before importing the library.

import sys
import os

# Define the path to your external environment's site-packages
# Adjust the path according to your operating system and environment name
venv_path = os.path.expanduser("~/my_project_env/lib/python3.10/site-packages")

if venv_path not in sys.path:
    sys.path.insert(0, venv_path)

# Import external dependencies
import numpy as np
import scipy

import inkex

class CustomExtension(inkex.EffectExtension):
    def effect(self):
        # Your extension logic utilizing NumPy or SciPy
        pass

if __name__ == '__main__':
    CustomExtension().run()

Method 3: Use the System Package Manager (Linux)

On Linux distributions, extensions execute through the system's default Python interpreter. Install the required libraries globally or for your local user using your distribution's package manager or pip.

  • Debian / Ubuntu: 
    sudo apt install python3-numpy python3-scipy
  • Fedora: 
    sudo dnf install python3-numpy python3-scipy
  • Arch Linux: 
    sudo pacman -S python-numpy python-scipy

Method 4: Delegate Processing via subprocess

For complex workflows, you can keep the Inkscape extension lightweight and offload computational tasks to a completely separate Python script running inside a specific environment.

  1. The Inkscape extension extracts coordinates, paths, or SVG data.
  2. It serializes the data (e.g., as JSON) and sends it to a standalone script using subprocess.Popen or subprocess.run.
  3. The standalone script, executed by your chosen Python environment with NumPy/SciPy, computes the output and prints or returns the result.
  4. The extension parses the output and updates the SVG document.
import subprocess
import json
import inkex

class HeavyMathExtension(inkex.EffectExtension):
    def effect(self):
        input_data = [1.0, 2.0, 3.0, 4.0]
        
        # Call an external Python environment
        result = subprocess.run(
            ["/path/to/venv/bin/python", "compute.py"],
            input=json.dumps(input_data),
            text=True,
            capture_output=True,
            check=True
        )
        
        output_data = json.loads(result.stdout)
        # Apply output_data to the SVG elements...

if __name__ == '__main__':
    HeavyMathExtension().run()

This method decouples third-party scientific dependencies entirely from Inkscape's bundled installation.
