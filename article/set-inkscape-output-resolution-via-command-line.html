Set Inkscape Output Resolution via Command Line

Inkscape provides a robust command-line interface that allows you to automate the rasterization of vector files with specific output resolutions. When exporting SVG files to raster formats like PNG, you can precisely control the output dimensions and pixel density using dedicated resolution flags.

1. DPI Parameter (-d, --export-dpi)

The primary parameter to set the output resolution by pixel density is --export-dpi (or the shorthand -d).

By default, Inkscape renders graphics at 96 DPI. Supplying a custom value scales the output bitmap proportionally. For instance, setting the DPI to 300 generates a high-resolution image suitable for print.

Syntax:

inkscape input.svg -o output.png --export-dpi=300

Or using the shorthand:

inkscape input.svg -o output.png -d 300

2. Dimension Parameters (-w, -h, --export-width, --export-height)

If you require a specific pixel dimension rather than calculating DPI, you can specify the target width and height directly using --export-width (-w) and --export-height (-h).

  • --export-width=<VALUE> or -w <VALUE>: Sets the generated image width in pixels.
  • --export-height=<VALUE> or -h <VALUE>: Sets the generated image height in pixels.

If you specify only one dimension, Inkscape automatically calculates the other to preserve the original aspect ratio.

Syntax (Width only):

inkscape input.svg -o output.png -w 1920

Syntax (Both Width and Height):

inkscape input.svg -o output.png --export-width=1920 --export-height=1080

3. Combining Resolution with Area Selection

To ensure the resolution applies only to a specific part of your SVG, combine the resolution flags with the area parameter:

  • --export-area-page (-C): Exports only the defined document page area at the specified resolution.
  • --export-area-drawing (-D): Crops the canvas to the bounding box of all drawn objects before applying the resolution.

Example:

inkscape input.svg -o output.png -C --export-dpi=300
