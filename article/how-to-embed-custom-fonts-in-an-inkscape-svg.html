How to Embed Custom Fonts in an Inkscape SVG

Embedding custom fonts directly into an Inkscape SVG ensures your typography renders accurately across different devices and web browsers without requiring the viewer to install the font locally. This guide details how to embed font files directly into the SVG's internal code using CSS @font-face rules and base64 encoding, as well as the alternative method of converting text to vector paths.

Method 1: Embedding Fonts Using Base64 and the XML Editor

Embedding a font via base64 encoding keeps your text editable while packaging the actual font data inside the SVG file.

Step 1: Convert Your Font to a Base64 Data URI

  1. Obtain the font file in .woff, .woff2, or .ttf format.
  2. Use a reliable online base64 converter or a local command-line tool to encode your font file into a base64 string.
  3. Prepare the CSS @font-face rule using the following structure:
@font-face {
  font-family: 'YourFontName';
  src: url('data:font/woff2;charset=utf-8;base64,PASTE_BASE64_STRING_HERE') format('woff2');
  font-weight: normal;
  font-style: normal;
}

Step 2: Add the Font to Inkscape via the XML Editor

  1. Open your SVG file in Inkscape.
  2. Open the XML Editor by navigating to Edit > XML Editor or pressing Ctrl + Shift + X (Cmd + Shift + X on macOS).
  3. In the XML tree, select the root <svg:svg> element or the <svg:defs> element. If <svg:defs> does not exist, create a new element named svg:defs.
  4. Right-click <svg:defs> and choose New child element.
  5. Name the element svg:style and click Create.
  6. Select the newly created <svg:style> element, click the New text node button, and paste your prepared CSS @font-face code.
  7. Save the SVG file.

Method 2: Converting Text to Paths (Alternative Approach)

If you do not need the text to remain editable and only want to preserve the visual appearance of the font, you can convert the text to vector outlines.

  1. Select the text object in Inkscape.
  2. Go to Path > Object to Path or press Ctrl + Shift + C (Cmd + Shift + C on macOS).
  3. Save your file.

Note: Once converted to paths, the text becomes a shape and cannot be edited as standard text.

Verifying the Embedded Font

To confirm that the font is correctly embedded:

  1. Open the saved SVG file in any modern web browser.
  2. Test the file on a secondary device or virtual machine that does not have the custom font installed to ensure the typeface displays properly.
