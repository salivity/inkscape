Trace River Networks from Satellite Images in Inkscape

Tracing complex river systems from satellite imagery into clean, simplified vector paths is an essential skill for cartographers, graphic designers, and GIS professionals. This guide walks you through the step-by-step process of importing satellite data into Inkscape, tracing waterway centerlines, and utilizing vector simplification tools to produce streamlined, production-ready river networks without visual clutter.

1. Prepare and Import the Satellite Image

  1. Open Inkscape and navigate to File > Document Properties to set your canvas dimensions according to your desired output.
  2. Go to File > Import, select your high-resolution satellite image, and choose Embed to keep the image file self-contained within your SVG.
  3. Open the Layers and Objects panel (Ctrl + Shift + L).
  4. Rename this initial layer to "Satellite Basemap" and click the padlock icon to lock it, preventing accidental shifts while tracing.
  5. Create a new layer above it and name it "River Network."

2. Trace the River Centerlines

Because satellite rivers vary in width and often pass under canopy or bridges, manual tracing using the Bézier tool yields significantly cleaner results than automatic raster tracing.

  1. Select the Draw Freehand Lines tool or the Bézier Curves tool (B) from the left toolbar.
  2. In the top tool controls bar, set the mode to Regular Bézier path and shape to None.
  3. Zoom in to the main river stem (+ key or scroll wheel while holding Ctrl).
  4. Click along the visual center of the river channel, placing nodes at major bends and turns. Avoid over-clicking; sparse node placement creates naturally smoother curves.
  5. Repeat the process for tributaries. To connect a tributary to the main river, enable Snap to paths on the snapping toolbar and begin or end the tributary stroke directly on the main path.

3. Simplify the Vector Paths

Raw manual traces often contain minor hand tremors or redundant nodes that bloat file sizes and look jagged.

  1. Switch to the Select and Transform Objects tool (S) and select your traced river paths.
  2. Run Path > Simplify (Ctrl + L). Inkscape will automatically reduce the node count while retaining the overall geometry.
  3. To fine-tune the aggressiveness of the simplification, go to Edit > Preferences > Behavior > Steps and adjust the Simplification threshold. A smaller value preserves tight meanders, while a larger value abstracts the river into generalized lines.
  4. Switch to the Edit paths by nodes tool (N) to manually inspect, move, or delete any remaining awkward sharp angles.

4. Establish Visual Hierarchy and Stroke Styling

Natural river networks visually taper from headwaters to main channels. Setting proportional stroke widths establishes a clear cartographic hierarchy.

  1. Open the Fill and Stroke panel (Ctrl + Shift + F).
  2. In the Fill tab, ensure fill is set to No paint.
  3. In the Stroke paint tab, select a uniform river color (such as a standard hydrographic blue or dark gray for minimalist maps).
  4. In the Stroke style tab:
    • Set Cap to Round cap and Join to Round join to eliminate harsh segment breaks.
    • Assign thicker stroke widths to major rivers (e.g., 2.0–3.0 px) and progressively thinner strokes to secondary and tertiary tributaries (e.g., 0.75–1.25 px).

5. Clean Up and Export

  1. Open the Layers and Objects panel and toggle the eye icon next to the "Satellite Basemap" layer to hide the background image.
  2. Inspect the standalone vector network for floating, disconnected, or overlapping paths.
  3. Select all river paths and group them (Ctrl + G) or navigate to Path > Combine (Ctrl + K) if you want them unified into a single compound path.
  4. Go to File > Save As... to save your clean vector artwork as an Inkscape SVG or Optimized SVG for digital design and GIS workflows.
