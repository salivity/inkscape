Create Vector Email Headers in Inkscape

This guide covers the process of creating professional, scalable email header graphics using the free, open-source vector editor Inkscape. You will learn how to configure your document dimensions for standard email layouts, build crisp vector elements, organize layers, and export your design for maximum clarity across high-resolution desktop and mobile displays.

Step 1: Set Up the Canvas

  1. Open Inkscape and create a new document.
  2. Open Document Properties by pressing Shift + Ctrl + D (or Cmd + Shift + D on macOS).
  3. Set the Display units and Custom size units to px (pixels).
  4. For standard email templates (which generally display at 600 pixels wide), set your canvas width to 1200 px and height between 300 px and 600 px. Designing at 2x resolution ensures your header looks sharp on Retina and high-density screens.
  5. In the Document Properties panel, uncheck Show page shadow and ensure the background color is either pure white (#FFFFFF) or transparent, depending on your email template design.

Step 2: Structure Your Layers

  1. Open the Layers panel using Shift + Ctrl + L.
  2. Rename the default layer to Background.
  3. Create two additional layers: Graphics and Text & Branding.
  4. Lock the Background layer after placing your base color or gradient to avoid accidental shifts while designing.

Step 3: Create Vector Shapes and Branding Elements

  1. Background Elements: Select the Rectangle tool (R), draw a rectangle matching your canvas dimensions, and use the Fill and Stroke panel (Shift + Ctrl + F) to apply solid brand colors or gradients.
  2. Logos and Icons: Import your existing vector logo (File > Import) or create one using the Pen tool (B) and shape tools.
  3. Alignment: Use the Align and Distribute panel (Shift + Ctrl + A) to center your elements vertically and horizontally. Set the "Relative to" dropdown to Page for accurate positioning within the email container.

Step 4: Add and Convert Typography

  1. Select the Text tool (T) and type your headline, slogan, or callout message.
  2. Choose your desired font family, size, and color from the Text and Font settings.
  3. Once the layout is finalized, select your text objects and go to Path > Object to Path (Shift + Ctrl + C). This converts text to vector paths, ensuring your visual typography renders consistently regardless of font installation when exported.

Step 5: Export for Email Clients

While SVG is ideal for web development, many desktop and web email clients (such as Microsoft Outlook and Gmail) have limited or inconsistent native SVG support. To ensure universal compatibility while maintaining vector clarity:

  1. Open the Export panel by pressing Shift + Ctrl + E.
  2. Under the Export Area tab, select Page.
  3. Set the Image size to your original canvas dimensions (e.g., 1200 x 400 pixels).
  4. Choose PNG as the export format for high-contrast graphics with text, or JPEG if your header contains complex photographic imagery.
  5. Click Export and save the file.

When embedding the exported graphic into your email template's HTML, set the display width to half the exported pixel width (e.g., <img src="header.png" width="600" style="width: 100%; max-width: 600px; height: auto;" />) to achieve a crisp, scalable look on all mobile and desktop devices.
