Read Inkscape Namespace Attributes with inkex

This article explains how to retrieve custom XML attributes stored under the Inkscape namespace using Python and the inkex library. You will learn how inkex handles SVG XML namespaces, how to properly resolve the Inkscape namespace prefix using built-in helpers, and how to safely read attribute values from elements during extension development.

Understanding SVG Namespaces in inkex

In Inkscape SVG files, custom metadata and editor-specific attributes—such as inkscape:label or user-defined attributes—are qualified with a XML namespace. The standard URI for the Inkscape namespace is:

http://www.inkscape.org/namespaces/inkscape

Because inkex is built on top of lxml, elements store namespaced attributes using Clark notation: {URI}attribute_name. For example, inkscape:custom-data is represented internally as {http://www.inkscape.org/namespaces/inkscape}custom-data.

Method 1: Using inkex.addNS()

The recommended way to resolve a namespaced attribute key is the inkex.addNS() function. It takes the local attribute name and the prefix shortcut ('inkscape') and formats them into the appropriate Clark notation.

import inkex

# Resolve the qualified attribute name
attr_key = inkex.addNS('custom-key', 'inkscape')

# Retrieve the attribute from an element
value = element.get(attr_key)

If the attribute does not exist on the element, .get() returns None (or a fallback value if specified as a second argument).

Method 2: Accessing via Clark Notation Directly

If you prefer not to use inkex.addNS(), you can construct the Clark notation string manually:

INKSCAPE_NS = "http://www.inkscape.org/namespaces/inkscape"
attr_key = f"{{{INKSCAPE_NS}}}custom-key"

value = element.get(attr_key)

Complete Extension Example

Below is a complete implementation of an inkex.EffectExtension that iterates over the user's current selection and reads a custom attribute named inkscape:my-attribute:

import inkex

class ReadCustomAttributeExtension(inkex.EffectExtension):
    def effect(self):
        # Resolve the namespaced attribute name
        attr_name = inkex.addNS('my-attribute', 'inkscape')

        for elem in self.svg.selection:
            # Safely fetch the value
            custom_value = elem.get(attr_name)

            if custom_value is not None:
                inkex.utils.debug(f"Element '{elem.get_id()}': {custom_value}")
            else:
                inkex.utils.debug(f"Element '{elem.get_id()}' does not have the attribute.")

if __name__ == '__main__':
    ReadCustomAttributeExtension().run()

Searching for Elements with a Custom Attribute

You can also use XPath with namespace mappings to query only elements that contain your custom Inkscape attribute:

# Search the entire SVG tree for elements with the attribute
elements = self.svg.xpath(
    "//*[@inkscape:my-attribute]",
    namespaces=inkex.NSS
)

for elem in elements:
    val = elem.get(inkex.addNS('my-attribute', 'inkscape'))
    # Process element

The dictionary inkex.NSS contains standard SVG namespace definitions (including svg, inkscape, sodipodi, and xlink), making it directly usable inside xpath() queries.
