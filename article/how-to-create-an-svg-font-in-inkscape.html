How to Create an SVG Font in Inkscape

Inkscape features a built-in SVG Font Editor that allows you to convert vector artwork into functional typographic glyph sets directly within the program. This guide covers the complete workflow for creating an SVG font, from configuring the global font parameters and designing your vector characters to assigning paths as glyphs, setting spacing, and exporting the final font file.

1. Open the SVG Font Editor

Launch Inkscape and open the font editing tool by navigating to the top menu and selecting Text > SVG Font Editor. A docked panel will appear containing three main tabs: Global Settings, Glyphs, and Kerning.

2. Create and Configure a New Font

  1. In the SVG Font Editor panel, click the New button under the Font column.
  2. Select your newly created font (named Font 1 by default) to activate it. Double-click the name to rename it to your preferred font family name.
  3. Switch to the Global Settings tab to define the metrics:
    • Units per em: Set this to a standard scale, typically 1000 or 1024. This defines the resolution of your glyph grid.
    • Ascent: Define the height above the baseline (e.g., 800).
    • Descent: Define the depth below the baseline (e.g., 200).

3. Set Up the Drawing Canvas

To ensure your glyphs match in scale and alignment:

  1. Open File > Document Properties.
  2. Set the display units to pixels and make the canvas dimensions match your chosen "Units per em" value (e.g., 1000 px by 1000 px).
  3. Drag horizontal guidelines from the rulers to mark the ascent, cap-height, x-height, baseline, and descent based on your global settings.

4. Design the Vector Glyph Paths

  1. Draw your character on the canvas using the Draw Freehand Lines tool, Draw Bézier Curves tool, or standard geometric shapes.
  2. Ensure the artwork consists of a single vector path:
    • If you used strokes, convert them to fills by selecting the object and clicking Path > Stroke to Path.
    • If the glyph consists of multiple overlapping shapes, join them via Path > Union.
    • If the glyph has counter-spaces (such as the holes in "O", "B", or "A"), select the outer and inner paths and choose Path > Combine or Path > Difference.

5. Assign Paths to Glyphs

  1. In the SVG Font Editor, click on the Glyphs tab.
  2. Click the Add Glyph button at the bottom of the panel.
  3. Select the newly added row and configure the fields:
    • Glyph name: Enter a descriptive label (e.g., letter-a or A).
    • Matching string: Enter the exact keyboard character that triggers this glyph (e.g., A).
    • Advance: Set the horizontal spacing/width of the character slot (typically matching or slightly wider than your path width).
  4. Select the drawn vector path on your canvas using the Select and Transform objects tool.
  5. In the SVG Font Editor, click Get curves from selection. A small preview of your character will appear next to the glyph entry.
  6. Repeat this process for every character, digit, and punctuation mark you wish to include.

6. Configure Kerning Pairs

  1. Switch to the Kerning tab in the SVG Font Editor.
  2. Click Add Kerning Pair.
  3. Specify the first character in the First Glyph field and the second in the Second Glyph field (for example, A and V).
  4. Adjust the Kerning value to add or subtract space between the two characters to fix visual gaps.

7. Save and Convert the Font

  1. Go to File > Save As... and select Plain SVG or Inkscape SVG to store your font definitions in an .svg file.
  2. Because native SVG font support is deprecated in modern web browsers and desktop operating systems, import your saved .svg file into font generation tools like FontForge, BirdFont, or an online SVG-to-TTF converter to generate usable OpenType (.otf), TrueType (.ttf), or Web Open Font (.woff) formats.
