How to Prepare Vectors for Laser Engraving in Inkscape

Preparing vector files in Inkscape for laser-engraved wood projects requires setting precise document dimensions, converting text to outlines, assigning distinct color-coded vector paths for cutting versus engraving, and cleaning up overlapping geometries. Following a standardized workflow ensures that laser software accurately interprets your designs, prevents duplicate cuts, and produces clean, professional results on wood materials.

1. Set Up the Document Workspace

  1. Open Inkscape and navigate to File > Document Properties (or press Ctrl+Shift+D / Cmd+Shift+D).
  2. Change the Display units to millimeters (mm) or inches (in), matching the measurement system used by your laser software.
  3. Set the Page Size to match either the dimensions of your laser bed or the specific dimensions of your wooden blank.
  4. Set the color profile to sRGB to maintain predictable color mapping in laser control software.

2. Convert Objects and Text to Vector Paths

Laser software cannot interpret live text fonts or parametric shapes (like standard rectangles and circles) without conversion to raw vector paths.

  • Convert Text: Select your text and go to Path > Object to Path (Shift+Ctrl+C).
  • Ungroup Text: Converted text becomes a group of individual letter paths. Go to Object > Ungroup (Ctrl+Shift+G).
  • Weld Script Lettering: If using cursive or overlapping fonts, select all letters and go to Path > Union (Ctrl++) to merge overlapping nodes into a single, continuous outline.

3. Assign Standard Color Coding

Laser cutters use stroke color and fill color to distinguish between cutting, scoring (vector engraving), and raster engraving (surface area engraving).

  • Raster Engraving (Dark Fill):
    • Set Fill to solid black (#000000).
    • Set Stroke paint to No paint.
  • Vector Scoring / Marking (Thin Surface Lines):
    • Set Fill to No paint.
    • Set Stroke paint to solid blue (#0000FF).
    • Set Stroke width to 0.1 mm or 0.001 in (hairline).
  • Vector Cutting (Through-Cuts):
    • Set Fill to No paint.
    • Set Stroke paint to solid red (#FF0000).
    • Set Stroke width to 0.1 mm or 0.001 in (hairline).

(Note: Stroke width does not affect the laser's physical beam kerf, but setting a hairline width ensures the software identifies the line as a vector stroke rather than a filled shape).

4. Clean Up Geometry and Overlaps

Overlapping vector paths will cause the laser to cut the same area twice, charring the wood edges and weakening the material.

  • Remove Duplicate Nodes: Use the Edit paths by nodes tool (F2) to inspect overlapping lines.
  • Combine Overlapping Shapes: Select intersecting vector shapes and use Path > Union to create a unified perimeter, or Path > Difference to subtract interior cutouts.
  • Flatten Filled Artwork: If your engraving artwork contains stacked layers, select all elements and use Path > Flatten or merge elements using Path > Union to avoid redundant raster passes.

5. Export for Laser Software

Different laser systems require specific vector formats:

  • Glowforge, LightBurn, and Web Interfaces: Go to File > Save As... and select Plain SVG (*.svg). Plain SVG strips Inkscape-specific metadata for cleaner imports.
  • Industrial Laser Systems (RDWorks, Ruida, GCC): Go to File > Save As... and choose AutoCAD DXF R14 (*.dxf) or Portable Document Format (*.pdf). Ensure all lines are converted to basic paths before DXF export.
