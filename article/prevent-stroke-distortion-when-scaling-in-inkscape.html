Prevent Stroke Distortion When Scaling in Inkscape

When stretching shapes non-proportionally in Inkscape, stroke widths often stretch unevenly, resulting in borders that are thicker on some sides and thinner on others. This guide explains how to prevent stroke distortion by disabling stroke scaling in the tool controls bar, resizing via parametric shape handles, and updating global transform preferences.

Method 1: Disable Stroke Scaling in the Select Tool Bar

The most common reason strokes distort during resizing is that Inkscape’s transform settings are set to scale stroke widths proportionally with the bounding box. You can disable this directly from the interface:

  1. Click the Select and Transform Objects tool (shortcut: S) in the left toolbar.
  2. Look at the Tool Controls Bar running horizontally across the top of the workspace.
  3. Locate the toggle icon labeled "When scaling objects, scale the stroke width by the same proportion" (represented by four expanding arrows over a corner border).
  4. Click the icon to disable it. When turned off, the icon will appear inactive/unhighlighted.
  5. Stretch or resize your rectangle non-proportionally using the selection handles. The border width will now remain uniform on all sides.

Method 2: Resize Using the Rectangle Tool Handles

If an object is still a native parametric shape rather than a converted path, you can alter its dimensions without triggering the transformation matrix that affects strokes:

  1. Select the Rectangle Tool (shortcut: R).
  2. Click on the rectangle to activate its shape handles.
  3. Click and drag the square handles on the top-left or bottom-right to change the width and height.
  4. Because this alters the geometric properties of the shape rather than applying a scale transform, the stroke width stays completely unaffected.

Method 3: Change the Behavior in Global Preferences

To ensure that stroke widths never scale with transformations across future projects, you can disable the setting globally:

  1. Open the Preferences window by going to Edit > Preferences (or press Ctrl + Shift + P).
  2. In the left panel, expand the Behavior category and select Transforms.
  3. Under the Transformations section, uncheck the box for Scale stroke width.
  4. Close the Preferences window. Inkscape will now keep stroke widths constant whenever objects are scaled.
