How to Import Shapefiles into Inkscape

Importing GIS vector shapefiles into Inkscape allows cartographers to transform raw geographic data into publication-quality maps using advanced vector design tools. Because Inkscape does not natively read the ESRI Shapefile format (.shp), the geometry must first be converted into a compatible vector format—such as Scalable Vector Graphics (SVG) or Portable Document Format (PDF)—using open-source GIS software like QGIS or GDAL before opening and styling the layers in Inkscape.

Method 1: Exporting from QGIS to SVG (Recommended)

Using QGIS provides total control over map projection, scale, and layer organization before editing in Inkscape.

1. Load and Project the Shapefile

  1. Open QGIS and create a new project.
  2. Drag and drop your .shp file into the Map Canvas.
  3. Set your project's Coordinate Reference System (CRS) at the bottom-right of the window to an appropriate projected coordinate system (e.g., UTM or a local conformal projection) rather than an unprojected geographic system (WGS84) to avoid spatial distortion.

2. Set Up the Print Layout

  1. Go to Project > New Print Layout and give it a name.
  2. Set your page size by right-clicking the canvas and choosing Page Properties.
  3. Click Add Item > Add Map and drag a rectangle over the canvas.
  4. In the Item Properties panel, set the exact scale and geographic extent you require.

3. Export to SVG

  1. Click Layout > Export as SVG.
  2. Choose a file destination and click Save.
  3. In the SVG Export Options dialog:
    • Check Export map layers as SVG groups (crucial for maintaining individual GIS layers in Inkscape).
    • Uncheck Render map tiles as raster to keep all features purely vector.
    • Enable Always export as vectors if prompted.
  4. Click Save.

Method 2: Converting via GDAL/OGR (Command Line)

For direct geometry conversion without opening a GIS graphical interface, use the ogr2ogr utility:

  1. Open your terminal or OSGeo4W shell.
  2. Run the following command to reproject and convert the shapefile directly into an SVG:
ogr2ogr -f SVG output.svg input.shp -t_srs EPSG:3857

Replace EPSG:3857 with your desired target projection code.

Opening and Designing in Inkscape

  1. Open Inkscape and select File > Open, then choose your exported SVG file.
  2. Open the Layers and Objects panel (Ctrl + Shift + L or Cmd + Shift + L).
  3. Expand the main group to access distinct geographic layers (e.g., roads, boundaries, water bodies).
  4. Ungroup layers (Ctrl + Shift + G) as needed to isolate paths for individual styling.
  5. Apply custom fills, stroke weights, blend modes, patterns, and typography for cartographic presentation.
  6. Use the Path > Simplify tool carefully if working with dense geometries, ensuring geographic accuracy is not compromised.
