Use Power Stroke in Inkscape for Variable Width

The Power Stroke Live Path Effect (LPE) in Inkscape allows you to create dynamic, hand-drawn vector lines by freely adjusting the thickness of a path at different points. This guide provides a straightforward walkthrough on how to apply the Power Stroke effect, manipulate width control handles, and customize stroke parameters for precise vector illustration.

1. Draw a Base Path

  1. Select the Draw Freehand Lines tool (Pencil / P) or the Draw Bezier Curves tool (Pen / B).
  2. Draw a line or curve on your canvas. Keep it as a simple open path without a fill and with a visible stroke.

2. Apply the Power Stroke Effect

  1. Select your path using the Select Tool (S).
  2. Go to the top menu and select Path > Path Effects to open the Path Effects dock.
  3. Click the + (Add Path Effect) button in the dock.
  4. Search for or select Power Stroke from the list of effects. Once applied, your path’s stroke will be converted into a dynamically shaped vector fill.

3. Adjust Width Using Node Handles

  1. Switch to the Node Tool (N).
  2. You will see your regular path nodes along the centerline, as well as pink or purple diamond-shaped control points along the stroke.
  3. Click and drag any of the diamond handles away from or toward the path to increase or decrease the stroke width at that specific location.

4. Add or Remove Width Control Points

  • Add a handle: Hold Ctrl and click on an existing pink/purple control handle to duplicate it, then drag the new handle to your desired position along the line.
  • Remove a handle: Click on the pink handle you want to delete and press Delete (or Ctrl + Alt + click depending on your Inkscape version).

5. Configure Path Endpoints and Join Types

In the Path Effects panel under the Power Stroke settings, you can fine-tune the appearance of the stroke:

  • Start and End Caps: Choose how the tips of the stroke terminate (e.g., Round, Square, Peak, or Zero width for tapered ends).
  • Join: Adjust the rounding or sharpness of corners along the path.
  • Cubic/Linear Interpolation: Control the smoothness of transitions between different width points.

6. Finalize as a Standard Vector Shape (Optional)

If you need to edit the outline as a regular vector object or export it to software that does not support Inkscape's live path effects:

  1. Select the path with the Select Tool.
  2. Go to Path > Object to Path (Ctrl + Shift + C). This permanently converts the dynamic Power Stroke effect into standard vector nodes and curves.
