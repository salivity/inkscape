Inkscape Font Collections: Version and Guide

Inkscape introduced the revamped Font Collections feature in version 1.3, released in July 2023. This update resolved long-standing typography management challenges by allowing users to organize fonts into custom categories, filter through extensive type libraries, and quickly apply curated font sets to their vector graphics projects. This guide covers the details of the release, how the Font Collections system operates, and how to use it effectively.

The Introduction of Font Collections in Inkscape 1.3

Prior to Inkscape 1.3, navigating the font selector could be cumbersome for designers with hundreds or thousands of system fonts installed. Inkscape 1.3 fundamentally overhauled how the software handles typography by introducing a dedicated Font Collections tool. This feature was designed to reduce search friction and give users complete control over organizing their typographic assets directly within the application.

How the Font Collections Feature Works

The revamped system allows users to create custom-named collections—such as "Serif Projects," "Brand Fonts," or "Display Type"—and assign installed fonts to one or more of these groups.

Key capabilities of the feature include:

  • Collection Creation and Management: Users can open the Font Collections manager to add new lists, delete obsolete ones, and sort fonts with a few clicks.
  • Toolbar Integration: The main Text tool controls and the Text and Font dialog include a drop-down filter, enabling users to isolate only the fonts within a specific collection rather than scrolling through the entire system library.
  • Non-Destructive Organization: Organizing fonts inside Inkscape does not alter system font files or how other operating system applications access them; the collections exist natively within Inkscape’s configuration settings.

Accessing and Using Font Collections

To use the feature in Inkscape 1.3 and later:

  1. Select the Text tool from the toolbox on the left side of the workspace.
  2. In the top tool controls bar, click on the font family dropdown menu.
  3. Click the collection icon (or navigate to Text > Font Collections) to open the management interface.
  4. Click the + icon to create a new collection, enter a name, and drag or assign fonts into that group.
  5. Filter your typography choices during editing by selecting your custom collection from the font selection menu.
