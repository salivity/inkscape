How to Unlink Flowed Text in Inkscape

This guide explains how to break the connection between linked flowed text frames in Inkscape. When working with complex desktop publishing layouts, text can span across multiple chained shapes or frames. Breaking this link allows you to edit, move, or format individual text blocks independently without reflowing content across the entire chain. Below are the direct methods to disconnect linked frames, convert flowed text back to standard text, and isolate individual text blocks.

Method 1: Completely Disconnect Text from Frames (Unflow)

To remove the connection between the text and all associated bounding frames entirely:

  1. Select the flowed text using the Select Tool (S or F1).
  2. Navigate to the top menu and click Text.
  3. Select Unflow (or press Alt + W).

The text will instantly detach from all linked shapes and revert to a single-line normal text object. The original shapes will remain on your canvas as empty path objects.

Method 2: Convert Flowed Text to Standard Text

If you want the text to keep its multi-line shape and layout without remaining bound to external frame objects:

  1. Click on the flowed text with the Select Tool.
  2. Go to Text in the top menu bar.
  3. Click Convert to Text.

This command strips the dynamic flow links to the underlying shapes, transforming the content into standard SVG text with manual line breaks preserved.

Method 3: Separate Text into Independent Flowed Frames

Inkscape does not have a single-click "split chain" button to divide a continuous flow across multiple frames while maintaining the text distribution. To divide linked text into separate, independent flowed frames:

  1. Select the original linked text object and press Ctrl + D to duplicate it.
  2. Move the duplicated text to the side or keep it aligned.
  3. Select the original text, enter text editing mode (T), and delete the portion of the text that spills into the subsequent frame.
  4. Select the duplicated text object, enter text editing mode, and delete the text corresponding to the first frame.
  5. Apply Text > Flow into Frame (Alt + W to unflow first if necessary) independently to each respective shape to create two distinct, unlinked flows.

Removing an Empty Linked Frame from a Chain

If you have multiple shapes linked in sequence and want to disconnect only the final, unused frame:

  1. Select the specific shape/frame you wish to remove from the flow.
  2. Press Delete on your keyboard.
  3. The text will automatically pull back and constrain itself to the remaining shapes in the chain without losing the flow connection between the remaining objects.
