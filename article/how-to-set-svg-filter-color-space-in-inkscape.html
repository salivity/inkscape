How to Set SVG Filter Color Space in Inkscape

This guide explains how to configure the SVG filter color interpolation space to either linearRGB or sRGB within Inkscape. You will learn how to change this setting at both the application level for future filters and at the object level for existing filters, preventing unwanted gamma shifts, darkening, and visual artifacts in your vector artwork.

Understanding Filter Color Spaces in SVG

By default, the SVG specification processes filter effects using the linearRGB color space to achieve physically accurate light calculations. However, this often causes unexpected color darkening or blending artifacts when working with assets designed in standard gamma-corrected sRGB. Inkscape allows you to explicitly control whether filters calculate in sRGB or linearRGB.

Changing the Default Filter Color Space in Preferences

To set the default interpolation mode that Inkscape assigns when creating new filters:

  1. Open Preferences by navigating to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  2. In the left navigation pane, expand the Filters or Rendering category (depending on your Inkscape version).
  3. Locate the setting labeled Filter color space or Color interpolation for filters.
  4. Select either sRGB (recommended for standard web/UI design) or linearRGB (standard SVG spec for realistic blurs/lighting).
  5. Close the Preferences dialog. Your choice will now apply to newly created filters.

Adjusting Color Space on Existing Filters

If a document already contains filters that look washed out or overly dark, update their color space directly through the Filter Editor or the XML Editor.

Method 1: Using the Filter Editor

  1. Go to Filters > Filter Editor... to open the panel.
  2. Select the target filter from the list on the left.
  3. In the primitives list, select a primitive (e.g., Gaussian Blur, Color Matrix).
  4. Look at the lower section of the panel for the Color interpolation or Effect attributes dropdown.
  5. Set the value explicitly to sRGB or linearRGB.

Method 2: Using the XML Editor

For direct and guaranteed control across the entire filter definition:

  1. Open the XML Editor by navigating to Edit > XML Editor (or press Ctrl + Shift + X).
  2. Locate the <svg:defs> node in the tree and expand it.
  3. Select the <svg:filter> element you want to edit.
  4. In the attribute panel on the right:
    • Enter color-interpolation-filters into the Attribute field.
    • Enter either sRGB or linearRGB into the Value field.
  5. Click Set (or press the checkmark button).

Applying color-interpolation-filters="sRGB" directly to the <filter> container automatically cascades the setting to all primitives inside that filter unless an individual primitive explicitly overrides it.
