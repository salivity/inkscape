How to Lock Node Handle Angle in Inkscape

This guide explains how to lock and constrain the angle of node handles while editing Bezier curves in Inkscape. By utilizing built-in keyboard modifier keys and the Node Tool, you can scale the length of a node handle to adjust curve tension while preserving its exact directional angle.

Using the Ctrl Modifier to Lock Handle Angles

  1. Select the Edit paths by nodes tool from the left toolbar or press N (or F2).
  2. Click on the path you want to modify to reveal its nodes.
  3. Click on a specific node to make its Bezier handles visible.
  4. Click and hold the circular tip of the handle you want to adjust.
  5. Press and hold the Ctrl key while dragging the handle.

Holding Ctrl constrains the handle's movement to its existing angle line, as well as fixed angular increments (default is 15 degrees). This allows you to extend or shorten the handle length without accidentally rotating the curve's trajectory.

Adjusting Related Handle Constraints

  • Lock Handle Length (Rotate Only): Hold Alt while dragging a handle. This locks the handle length so you can adjust only the angle without altering curve depth.
  • Rotate Both Handles Together: If a node is set to Smooth (Shift + S) or Symmetrical (Shift + Y), dragging one handle while holding Ctrl preserves the collinear 180-degree lock between both handles.
  • Move Handles Individually: Hold Shift and drag a handle on a smooth node to break the collinear lock and convert it into a cusp (corner) node handle on the fly.

Customizing the Angular Snap Step

To change the default snap increment used when holding Ctrl:

  1. Go to Edit > Preferences (or press Ctrl + Shift + P).
  2. Navigate to Behavior > Steps.
  3. Locate the Rotation snaps every field and enter your preferred degree increment.
