Configure SVG ViewBox Scaling in Inkscape

This guide explains how to configure the SVG viewBox and scaling behavior in Inkscape to create responsive web hero illustrations. By properly managing document dimensions, internal scale values, and aspect ratio attributes, you can ensure that your vector graphics adapt smoothly to various screen sizes without unwanted cropping, distortion, or layout shifts.

1. Set the Canvas Dimensions and Units

To establish a stable coordinate system for your hero illustration:

  1. Open your document in Inkscape and navigate to File > Document Properties (or press Ctrl + Shift + D).
  2. Under the Display section, set the Display units to px (pixels).
  3. Set your target base resolution under Custom size (for example, 1920 for Width and 1080 for Height for a standard 16:9 hero section).

2. Standardize the Internal Scale

Inkscape calculates the viewBox based on the document's scale factor. An incorrect scale factor introduces unexpected coordinate shifts on the web:

  1. In the Document Properties dialog, locate the Scale section.
  2. Ensure the Scale x value is set strictly to 1.00000.
  3. Verify that the Viewbox fields (X, Y, Width, Height) directly match your document's width and height. For a 1920x1080 canvas, the viewBox should read 0 0 1920 1080.

3. Configure preserveAspectRatio via the XML Editor

The SVG viewBox relies on the preserveAspectRatio attribute to determine how graphics scale inside modern responsive web containers. Inkscape does not always expose this setting in the graphical interface, but it can be set directly:

  1. Open the XML Editor via Edit > XML Editor (or press Ctrl + Shift + X).
  2. Select the root <svg:svg> node at the very top of the hierarchy.
  3. In the attribute panel on the right, look for preserveAspectRatio. If it does not exist, type preserveAspectRatio into the attribute name field.
  4. Set the value according to your layout requirements:
    • xMidYMid meet: Scales the illustration uniformly so the entire graphic fits within the viewport without being cut off (ideal for contained hero illustrations).
    • xMidYMid slice: Scales the illustration uniformly while covering the entire container, cropping the edges if the aspect ratio differs (ideal for full-bleed background hero graphics).
  5. Click Set to apply the attribute.

4. Remove Fixed Dimensions for Web Responsiveness

By default, Inkscape writes hardcoded width and height attributes that override responsive CSS rules:

  1. In the XML Editor, select the root <svg:svg> node.
  2. Select the width attribute and click the Delete attribute button.
  3. Select the height attribute and click the Delete attribute button.
  4. Ensure the viewBox attribute remains intact (e.g., viewBox="0 0 1920 1080").

Without fixed width and height, modern browsers use the viewBox to automatically scale the SVG via CSS rules such as width: 100%; height: auto;.

5. Export as Optimized SVG

When saving the asset:

  1. Go to File > Save As...
  2. In the file type dropdown, select Optimized SVG (*.svg).
  3. In the export dialog, ensure that options to remove Inkscape-specific metadata are enabled, but verify that the viewBox is preserved.
