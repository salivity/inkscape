Create a Custom Brand Color Palette in Inkscape

Creating a custom brand color palette in Inkscape ensures visual consistency across your design projects and significantly streamlines your workflow. This guide outlines the exact steps to define your brand colors using hex codes, store them in the document palette, and save the file as a reusable template for future projects.

Step 1: Open the Required Panels

To manage colors efficiently, open the essential color tools:

  1. Navigate to Object > Fill and Stroke (or press Shift + Ctrl + F).
  2. Navigate to View > Swatches (or press Shift + Ctrl + W) to open the color palette panel.

Step 2: Create Swatches from Brand Hex Codes

Inkscape allows you to convert any standard fill color into a persistent document swatch:

  1. Use the Rectangle tool (R) to draw a temporary shape on the canvas.
  2. In the Fill and Stroke panel, select the Fill tab and choose the Flat color mode.
  3. Enter your brand’s hex code in the RGBA or HEX input box at the bottom of the panel.
  4. Click the Swatch button (the small ribbon/tag icon) located next to the color mode buttons in the Fill panel. This action converts the color into a named document swatch and automatically adds it to the document's palette.
  5. Repeat this process for every color in your brand guide (primary, secondary, accents, and neutrals).

Step 3: Switch to the Document Palette View

Once your colors are converted to swatches, set your palette bar to display only this document's colors:

  1. Look at the bottom of the screen where the color palette strip is located, or look at the Swatches panel.
  2. Click the small arrow menu icon (Palette Menu) on the far-right edge of the palette strip.
  3. Select Document (or Auto in newer versions) from the list. The palette bar will now display exclusively the custom swatches you registered.

Step 4: Rename and Organize Your Swatches

For clear organization:

  1. Open the Swatches panel (Shift + Ctrl + W).
  2. Ensure the palette drop-down menu inside the panel is set to Document.
  3. Right-click any color swatch in the list and choose Edit color... to rename it to a functional brand name (e.g., "Brand Primary", "Accent Blue").

Step 5: Save as a Reusable Brand Template

To prevent having to rebuild this palette for every new document:

  1. Delete the temporary shapes you drew on the canvas. The swatches will remain stored in the document's internal metadata.
  2. Go to File > Save Template...
  3. Enter a name (e.g., "Brand Assets Template"), provide author details if needed, and check the box for Set as default template if you want this palette to load every time Inkscape launches.
  4. Click Save. You can now access your branded palette anytime via File > New from Template.
