Using Multiple Chained Actions in Inkscape CLI

This guide explains how to chain multiple commands together using the --actions parameter in the Inkscape command-line interface (CLI). By using semicolon delimiters and colon-separated arguments, you can automate complex vector workflows, modifications, and file exports in a single command without opening the graphical interface.

Basic Syntax

To run multiple actions in sequence, list each action separated by a semicolon (;). Enclose the entire list in quotation marks so your terminal shell does not interpret the semicolon as a command separator:

inkscape --actions="action1; action2; action3" input.svg

Passing Arguments to Actions

When an action requires parameters or values, append a colon (:) followed by the argument.

Syntax structure:

action-name:argument_value

If an action requires multiple parameters, separate them with additional colons:

action-name:arg1:arg2

Step-by-Step Example

Here is a common scenario where an SVG file is loaded, all objects are selected, converted to paths, and exported as a new PDF file:

inkscape --actions="select-all; object-to-path; export-filename:output.pdf; export-do" input.svg

In this sequence:

  1. select-all selects every element in input.svg.
  2. object-to-path converts the selected shapes and text elements into paths.
  3. export-filename:output.pdf sets the target export name and format.
  4. export-do triggers the actual export process.

Processing Without GUI Overhead

When automating operations across multiple files, include the --batch-process flag to prevent the user interface from loading and to automatically close Inkscape once the actions complete:

inkscape --batch-process --actions="select-all:rect; selection-delete; export-filename:cleaned.svg; export-do" input.svg

Finding Available Actions

To view the complete list of actions supported by your installed version of Inkscape, run:

inkscape --action-list

This command outputs every action name along with a brief description of what it does and whether it accepts parameters.
