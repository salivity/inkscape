Draw Accurate Door Swings and Walls in Inkscape

This guide explains how to construct architectural door-swing arcs and clean wall cutouts with precise vector accuracy using Inkscape. By configuring precision snapping, utilizing Boolean path operations, and defining exact geometric arc parameters, you can draft clean, professional floor plan components to scale without relying on dedicated CAD software.

1. Configure Snapping and Document Scale

Accurate architectural drafting requires precise alignment to points, grids, and edges.

  1. Open File > Document Properties (Ctrl + Shift + D).
  2. Set your Display units to millimeters (mm), centimeters (cm), or inches (in).
  3. Open the Snap Controls bar on the right edge of the canvas.
  4. Enable snapping globally, then turn on:
    • Snap to paths
    • Snap to cusp nodes
    • Snap to bounding box corners and midpoints

2. Create the Wall Cutout

Walls are best managed as closed polygon paths or stroked lines. To create an opening for a door:

  1. Draw your wall using the Rectangle tool (R) or Draw Bezier curves tool (B), giving it the required wall thickness.
  2. If using stroked paths for walls, convert them to filled geometry via Path > Stroke to Path (Ctrl + Alt + C).
  3. Draw a cutting rectangle with the Rectangle tool representing the door frame width and depth (must be at least as thick as the wall).
  4. Snap the cutting rectangle to the exact location of the door opening on the wall.
  5. Select both the wall and the cutting rectangle.
  6. Navigate to Path > Difference (Ctrl + -). This punches out the door opening, creating clean vector terminals on both sides of the wall.

3. Draw the Door Leaf

The door leaf represents the physical door panel in an open position.

  1. Select the Rectangle tool (R).
  2. Click and drag to create the door panel. Set its exact width (e.g., 36 inches or 900 mm) and door thickness (e.g., 1.75 inches or 45 mm) using the W and H fields in the top toolbar.
  3. Use the Select tool (S) to drag the door leaf to the opening.
  4. Snap the hinge corner of the door leaf directly to the interior corner of the wall cutout.
  5. To show the door fully open at 90 degrees, click the object a second time to activate rotation handles, hold Ctrl, and rotate the panel against the wall line.

4. Construct the Vector-Accurate Swing Arc

Architectural conventions show the swing of a door as a quarter-circle arc.

  1. Select the Circles and Ellipses tool (E or F5).
  2. Move the cursor over the hinge point until the snap indicator confirms alignment with the hinge node.
  3. Hold Ctrl + Shift and drag outward to draw an ellipse constrained to a 1:1 circle centered on the hinge point.
  4. Drag until the radius snaps directly to the outer edge of the open door leaf.
  5. In the top tool control bar for the Ellipse tool:
    • Switch the shape mode to Arc (the icon showing an open cut stroke, not a slice/pie).
    • Set the Start and End angle fields to define the 90-degree quadrant (e.g., Start: 0.0, End: 90.0, adjusting based on the door’s orientation).
  6. Open the Fill and Stroke panel (Ctrl + Shift + F):
    • Remove the Fill completely.
    • Under Stroke paint, set a solid color.
    • Under Stroke style, reduce the width to a lighter line-weight than the wall geometry (e.g., 0.18 mm or 0.25 mm) and select a dashed line pattern from the Dashes dropdown.

5. Group the Assembly

  1. Select both the door leaf and the swing arc.
  2. Press Ctrl + G to group the components into a single reusable object.
  3. You can now duplicate (Ctrl + D), flip horizontally (H), or flip vertically (V) to place identical doors throughout your floor plan while preserving vector precision.
