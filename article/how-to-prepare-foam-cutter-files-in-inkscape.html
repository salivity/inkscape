How to Prepare Foam Cutter Files in Inkscape

Thermal wire foam cutters require precise, continuous toolpaths to slice clean shapes through expanded or extruded polystyrene without stalling and causing burn marks. This guide walks you through setting up your vector artwork, configuring wire kerf offsets, utilizing Inkscape’s built-in Gcodetools extension, and generating production-ready G-code files tailored for CNC hot-wire foam cutting machines.

1. Set Up Your Inkscape Workspace

  1. Open Inkscape and access File > Document Properties.
  2. Set the Display units and Custom size units to millimeters (mm) or inches (in), matching your CNC controller's standard input.
  3. Set the custom width and height to match the cutting envelope (working area) of your foam cutter.
  4. Close the Document Properties dialog.

2. Prepare and Clean the Vector Geometry

Hot-wire cutters require continuous lines rather than layered shapes.

  1. Select all elements and convert them to paths by navigating to Path > Object to Path.
  2. If your design includes text or grouped elements, ungroup them completely (Object > Ungroup) before converting them to paths.
  3. Combine overlapping shapes using Path > Union or connect separate line segments using the Edit paths by nodes tool (F2) to join adjacent end nodes.
  4. Remove any duplicate overlapping vectors, as a double pass in the same spot will overheat and deform the foam.

3. Account for Wire Kerf

The heated wire melts a channel wider than the physical wire diameter, known as the kerf.

  1. Determine your setup's kerf (typically between 0.5 mm and 1.5 mm depending on wire thickness, temperature, and speed).
  2. For external cuts, offset your path outward by half the kerf distance using Path > Outset or by applying a stroke with a width equal to the kerf and running Path > Stroke to Path.
  3. For internal cutouts, offset your path inward to preserve the finished dimension.

4. Add Lead-In and Lead-Out Paths

Because hot wires cause thermal expansion where they pause or enter the material:

  1. Extend your cut line beyond the foam stock boundary so the wire enters the material while already moving at target speed.
  2. Use the Draw freehand lines or Draw Bezier curves tool to add an entry line from the edge of the block to the profile, and an exit line to allow the wire to leave the stock cleanly.

5. Configure Orientation Points with Gcodetools

Inkscape includes the Gcodetools extension suite to generate CNC code.

  1. Navigate to Extensions > Gcodetools > Orientation points.
  2. Select 2-points mode, define your Z-surface (usually 0.0), and set the Z-depth to match your cut requirement (for 2D wire cutting, this value is often kept at 0.0 or a nominal depth if controlling an auxiliary axis).
  3. Click Apply to place coordinate marker points on your canvas.

6. Configure Tool and Cutting Parameters

  1. Go to Extensions > Gcodetools > Tools library.
  2. Select Cylinder (or Default) and click Apply. A green text box containing tool parameters will appear on your canvas.
  3. Switch to the Text Tool (F8) to edit the parameters directly in the green box:
    • Feed: Set the travel speed appropriate for your wire temperature and foam density (e.g., 200–500 mm/min). Setting the speed too slow causes excessive melt; setting it too fast bends the wire.
    • Penetration feed: Set this to match your horizontal cutting feed rate.
    • Spindle rpm / Diameter: Clear or set these to 0 unless your controller requires specific dummy inputs.

7. Generate the G-Code

  1. Select your cutting path along with any lead-in/lead-out lines.
  2. Open Extensions > Gcodetools > Path to Gcode.
  3. In the Preferences tab:
    • Enter a target file name (e.g., foam_cut.ngc or foam_cut.gcode).
    • Enter the exact directory path where the output file should be saved.
    • Set the Z safe height according to your machine's clearance settings.
  4. Return to the Path to Gcode tab and click Apply.
  5. Inspect the generated path layer directly in Inkscape for direction arrows and verify the output G-code in a CNC visualizer or G-code sender before running the cut.
