How to Make App Store Screenshots in Inkscape

This guide explains how to design professional, vector-based app store preview screenshots using Inkscape's multi-page document tools. You will learn how to configure standardized store dimensions across multiple artboards, design continuous panoramic graphics, organize vector assets, and batch export the finished screens for submission to platforms like the Apple App Store and Google Play.

1. Set Up the Multi-Page Document

Inkscape natively supports multi-page layouts, allowing you to manage an entire set of preview slides within a single file.

  1. Open a new document in Inkscape.
  2. Open the Document Properties window (Ctrl + Shift + D or Cmd + Shift + D).
  3. Set the display units to Pixels (px).
  4. Set the default page size according to the target store specification (e.g., 1290 x 2796 px for Apple 6.7-inch displays or 1080 x 1920 px for standard Android layouts).
  5. Switch to the Create and Edit Pages tool on the left toolbar (or press Shift + P).
  6. Click Create a new page in the top tool control bar to add subsequent screens. Place them side-by-side with a small gap or zero spacing to create a panoramic canvas.

2. Structure Layers and Guides

Proper layer management ensures background elements, mockups, and text remain organized and easy to edit.

  • Background Layer: For background colors, gradients, and continuous decorative vectors that span across multiple screens.
  • Mockups Layer: For imported vector device frames and app UI screenshots.
  • Content Layer: For marketing headlines, subheadings, feature badges, and iconography.

To maintain consistency, drag guides from the rulers to establish safe zones, such as top and bottom margins for text alignment across all pages.

3. Create Continuous Vector Graphics

Multi-page setups allow design elements to flow across adjacent screenshots, encouraging users to swipe through your store listing.

  1. Draw shapes, curves, or gradients that physically cross the boundary line between two pages.
  2. When the pages are exported individually, Inkscape automatically crops the vector elements along the page boundaries without requiring manual clipping paths.
  3. Import your app interface designs and place them into vector device frames. Position frames across page divides if you want an angled, multi-screen display effect.

4. Format Typography and Icons

  1. Select the Text tool (T) and create clear, concise value propositions above or below the device frames.
  2. Use the Align and Distribute panel (Ctrl + Shift + A or Cmd + Shift + A).
  3. Set the "Relative to" option to Page to center text boxes and UI elements perfectly within the active artboard.
  4. Convert crucial typography to paths (Path > Object to Path) before final distribution if you plan to share the editable source file across different machines without embedded fonts.

5. Batch Export the Screenshots

Exporting every artboard individually is automated through the Export panel.

  1. Open the Export dialog (Ctrl + Shift + E or Cmd + Shift + E).
  2. Select the Batch Export tab at the top of the panel.
  3. Choose the Pages option to list all artboards in the document.
  4. Set the export format to PNG (or JPEG depending on store requirements).
  5. Ensure the DPI is set to 96 DPI (Inkscape's native 1:1 pixel resolution) so the output matches the exact pixel dimensions specified in the document properties.
  6. Choose an output directory and file naming pattern, then click Export.
