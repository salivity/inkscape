How to Sort Swatches in an Inkscape Palette

Organizing color swatches in Inkscape streamlines your design workflow and keeps your artwork consistent. While Inkscape automatically tracks colors by usage frequency via the Document Palette, sorting swatches by visual properties such as hue or value requires configuring palette display settings, generating structured palettes from canvas elements, or sorting the underlying palette file. This guide explains how to organize your swatches using these practical methods.

Sorting by Usage Frequency

Inkscape tracks the colors actively used in your project through the dynamic Document Palette.

  1. Locate the Palette bar at the very bottom of the Inkscape window.
  2. Click the small arrow or hamburger menu icon on the far right of the palette bar.
  3. Select Auto or Document Palette from the list.
  4. As you apply new fills and strokes to shapes on your canvas, Inkscape places the most recently used colors into this palette.
  5. To remove unused colors and condense the list, open the Swatches dialog (View > Swatches or press Ctrl + Shift + W), click the menu icon, and choose to remove unused swatches.

Sorting by Hue or Value

Inkscape does not have a single-click native button in the basic palette menu to reorder existing third-party palettes by hue or brightness. However, you can achieve a sorted palette using one of the following approaches:

Method 1: Generate a Sorted Palette from Canvas Objects

If you have a set of colors you want to arrange visually:

  1. Draw a row of squares or circles on the canvas, each colored with one swatch from your selection.
  2. Manually arrange these shapes in order of lightness (value) or color spectrum order (hue).
  3. Select all the colored objects.
  4. Go to Extensions > Color (or use an installed palette export extension) or create a custom swatch set:
    • Open the Swatches panel (Ctrl + Shift + W).
    • Select the objects and convert their colors to persistent swatches by clicking the Add / New swatch icon.
    • Because they were added sequentially from your arranged canvas shapes, the palette retains your custom hue or value order.

Method 2: Sort the GIMP Palette (.gpl) File

Inkscape stores custom palettes as .gpl (GIMP Palette) plain-text files. You can sort these files using an external script or text editor:

  1. Open your Inkscape user directory:
    • Windows: %APPDATA%\inkscape\palettes
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes
    • Linux: ~/.config/inkscape/palettes
  2. Locate the .gpl file for your palette and open it in a text editor (such as VS Code, Notepad++, or TextEdit).
  3. The file lists colors by standard RGB values: 
    GIMP Palette
Name: My Palette
Columns: 4
#
255   0   0   Red
  0 255   0   Green
  0   0 255   Blue
  4. Reorder the lines based on RGB brightness:
    • By Value (Brightness): Calculate relative brightness using \((0.299 \times R + 0.587 \times G + 0.114 \times B)\) and sort lines from lowest to highest.
    • By Hue: Group the lines by primary color families (Reds, Yellows, Greens, Cyans, Blues, Magentas).
  5. Save the file and restart Inkscape. Your palette will now appear in your defined order.

Method 3: Use GIMP's Native Palette Sorter

Because Inkscape natively reads .gpl palettes, you can leverage GIMP to sort the palette automatically:

  1. Place your .gpl file into GIMP's palettes folder.
  2. Open GIMP and open the Palettes dialog (Windows > Dockable Dialogs > Palettes).
  3. Right-click your palette and choose Edit Palette.
  4. In the Palette Editor, right-click and select Sort Palette....
  5. Choose your sorting criterion: Hue, Saturation, or Value, as well as the sort direction (Ascending or Descending).
  6. Save the palette. It will immediately reflect the sorted order when selected in Inkscape.
