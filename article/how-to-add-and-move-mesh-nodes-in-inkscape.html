How to Add and Move Mesh Nodes in Inkscape

Mesh gradients in Inkscape allow you to create complex, photorealistic vector shading by applying multi-directional color transitions across a custom grid. This guide explains how to select, move, and add mesh nodes within an active mesh gradient so you can precisely control geometry and color flow in your designs.

Activating the Mesh Tool

To interact with a mesh gradient, select the object containing the gradient and switch to the Mesh Tool by clicking its icon in the left-hand toolbar or pressing the keyboard shortcut X. Once activated, the mesh grid will appear over your object, displaying intersecting grid lines, corner nodes, and control handles.

Moving Mesh Nodes

  1. Select a Node: Click directly on any node (the diamond- or square-shaped intersection points on the grid). The selected node will change color to indicate it is active. To select multiple nodes, hold Shift and click each node, or click and drag a selection box around them.
  2. Reposition the Node: Click and drag the selected node to your desired location. Moving internal nodes warps the inner color flow, while moving outer boundary nodes reshapes the boundary of the gradient.
  3. Adjust Curve Handles: Each node connects to adjacent nodes with curved lines governed by Bézier handles (small circular handles extending from the nodes). Click and drag these handles to alter the curvature of the grid lines and smooth out color transitions.

Adding New Mesh Nodes

To increase the detail of your gradient, you can add new rows and columns of nodes to an existing mesh:

  1. With the Mesh Tool (X) active, hover over an existing mesh line where you want to add a subdivision.
  2. Double-click the line. Inkscape will insert a new perpendicular mesh line through that point, creating new intersecting nodes across the entire row or column.
  3. Alternatively, you can define the number of rows and columns in the Tool Controls Bar at the top of the screen prior to creating the mesh over a shape.

Modifying Node Colors

After positioning or adding nodes, you can change the color emitted from any specific point. Click a node to select it, then choose a color from the bottom color palette or open the Fill and Stroke panel (Ctrl+Shift+F) to set an exact hex code, RGB value, or opacity level.
