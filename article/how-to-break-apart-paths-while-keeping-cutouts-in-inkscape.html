How to Break Apart Paths While Keeping Cutouts in Inkscape

When working with compound paths in vector design, using the standard Break Apart command turns all cutouts and counter-spaces into solid, overlapping shapes. To separate multiple disjoint shapes into independent objects while keeping interior holes and cutouts intact, Inkscape offers a dedicated feature called Split Path, alongside alternative node and builder tools for older versions.

The Standard Problem: "Break Apart" vs. "Split Path"

Pressing Path > Break Apart (or Ctrl + Shift + K) completely deconstructs a compound path into every individual subpath. This causes negative spaces (such as the center of an "O" or decorative cutouts in a stencil) to become solid black shapes, requiring you to manually re-subtract every hole using Path > Difference.

To avoid this, you need to separate non-overlapping parent structures while automatically retaining parent-child cutout relationships.

Method 1: Use the "Split Path" Command (Inkscape 1.2 and Newer)

Starting with Inkscape 1.2, a native tool was introduced specifically to solve this problem.

  1. Select your compound path using the Select Tool (S).
  2. Navigate to the top menu and select Path > Split Path.
  3. Inkscape will evaluate the geometry:
    • Outer boundaries that do not touch will be split into individual objects.
    • Any subpaths completely enclosed inside an outer boundary will remain combined with that boundary as negative space.

Each disjoint shape is now its own independent object with all original cutouts preserved.

Method 2: Use the Shape Builder Tool (Inkscape 1.3 and Newer)

If you only need to extract specific outer sections or if overlapping boundaries are causing issues:

  1. Select your object with the Select Tool (S).
  2. Activate the Shape Builder Tool (X) from the left toolbar.
  3. In the top tool controls bar, ensure the mode is set to Add (the plus icon).
  4. Click and drag across the solid areas of the shape you wish to keep together, intentionally avoiding the holes.
  5. Click the Finish checkmark in the tool controls bar.
  6. Inkscape generates a clean, standalone path preserving the interior voids.

Method 3: Manual Node Selection (Inkscape 1.1 and Older)

If you are running an older version without the "Split Path" command, you can manually isolate an outer shape and its corresponding holes:

  1. Choose the Node Tool (N) and click on the compound path.
  2. Hold Shift and drag a selection box around all nodes belonging to the outer contour and its interior holes.
  3. Press Ctrl + X to cut those specific nodes/subpaths.
  4. Switch to the Select Tool (S), click anywhere on an empty part of the canvas, and press Ctrl + Alt + V (Paste in Place).
  5. The cut piece is now separated as its own object with the cutouts intact, leaving the rest of the original artwork unchanged.
