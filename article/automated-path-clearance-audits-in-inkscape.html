Automated Path Clearance Audits in Inkscape

Running automated path clearance audits in Inkscape ensures that vector designs meet minimum spacing requirements for digital fabrication processes like laser cutting, CNC routing, and PCB isolation. This guide explains how to leverage Inkscape's internal Python ecosystem and external geometry libraries to programmatically measure the distance between adjacent vector paths, detect spacing violations, and generate automated audit reports.

The Need for Automated Path Clearance

In subtractive manufacturing and high-precision plotting, placing paths too close together can cause material burn-through, tool collisions, or structural collapse. While Inkscape provides a manual Measurement Tool (accessible via keyboard shortcut M), manually inspecting complex vectors with hundreds of paths is prone to error and time-consuming. Scripting the process automates the calculation of the shortest Euclidean distance between any two distinct geometry boundaries.

Setting Up the Environment

Inkscape relies on a built-in Python environment bundled with the inkex library, which provides direct access to SVG Document Object Model (DOM) elements. To perform clearance checks accurately, combine inkex with the shapely library, an industry standard for 2D Cartesian computational geometry.

Install the required geometry module into Inkscape’s Python distribution:

# On Windows (inside Inkscape's installation directory)
python -m pip install shapely

# On macOS/Linux
pip install shapely

Developing the Clearance Audit Script

An automated clearance auditor follows a clear execution pattern: it parses the SVG document, converts path strings into polygon or linestring geometries, performs pairwise distance evaluations, and flags items below a target threshold.

Create a Python script named clearance_audit.py:

import inkex
from inkex.paths import Path
from shapely import wkt
from shapely.geometry import LineString, Polygon
from itertools import combinations

class ClearanceAuditExtension(inkex.EffectExtension):
    def add_arguments(self, pars):
        pars.add_argument("--threshold", type=float, default=1.5, help="Minimum clearance in mm")

    def effect(self):
        # Convert threshold from mm to document units (pixels, 96 dpi standard: 1mm ~ 3.7795px)
        threshold_px = self.svg.unittouu(f"{self.options.threshold}mm")
        paths = self.svg.xpath('//svg:path')
        
        geometries = []
        for p in paths:
            # Parse SVG path data into Shapely geometry
            d_string = p.get('d')
            if not d_string:
                continue
            parsed_path = Path(d_string)
            points = [(cmd.x, cmd.y) for cmd in parsed_path.end_points]
            if len(points) > 1:
                geometries.append((p, LineString(points)))

        violations = []

        # Compare path clearances pairwise
        for (elem_a, geom_a), (elem_b, geom_b) in combinations(geometries, 2):
            distance = geom_a.distance(geom_b)
            if distance < threshold_px:
                dist_mm = self.svg.uutounit(distance, 'mm')
                violations.append((elem_a, elem_b, dist_mm))
                # Visually mark failing elements
                elem_a.style['stroke'] = '#ff0000'
                elem_b.style['stroke'] = '#ff0000'

        if violations:
            inkex.errormsg(f"Found {len(violations)} clearance violations below {self.options.threshold}mm:")
            for elem_a, elem_b, dist in violations:
                inkex.errormsg(f"- Paths {elem_a.get_id()} and {elem_b.get_id()}: {dist:.2f}mm")
        else:
            inkex.utils.debug("All paths satisfy clearance requirements.")

if __name__ == '__main__':
    ClearanceAuditExtension().run()

Creating the Extension Definition (.inx)

To run the script directly within Inkscape’s graphical interface, create a corresponding clearance_audit.inx file in your Inkscape user extensions folder:

  • Linux: ~/.config/inkscape/extensions/
  • Windows: %APPDATA%\inkscape\extensions\
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/
<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>Run Path Clearance Audit</name>
    <id>org.inkscape.audit.clearance</id>
    <param name="threshold" type="float" min="0.01" max="100.0" precision="2" gui-text="Minimum Clearance (mm):">1.5</param>
    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Fab Verification"/>
        </effects-menu>
    </effect>
    <script>
        <command location="inx" interpreter="python">clearance_audit.py</command>
    </script>
</inkscape-extension>

Running Audits via Command-Line Interface (CLI)

For integration into automated quality assurance (QA) or continuous integration pipelines, execute the script without launching the Inkscape GUI:

python clearance_audit.py --threshold=2.0 input_design.svg > audit_log.txt

This headless execution checks the file against the specified tolerance, updates failure stroke styles for visual verification, and prints all flagged clearance distances to standard error or an audit log. Failing paths are isolated by ID, enabling immediate targeted remediation in the source artwork.
