Run Inkscape in Safe Mode Without Extensions

Running Inkscape in a clean or "safe" state is an effective troubleshooting method when third-party extensions, corrupted scripts, or faulty configuration files cause crashes or slow performance. This guide covers how to temporarily disable extensions, isolate your user profile, and start a fresh instance of Inkscape on Windows, macOS, and Linux.

Method 1: Temporarily Disable Custom Extensions

Third-party extensions are loaded from a dedicated user directory. Renaming this directory prevents Inkscape from loading these extensions upon startup without permanently deleting them.

Windows

  1. Close Inkscape completely.
  2. Press Win + R, paste %APPDATA%\inkscape, and press Enter.
  3. Locate the extensions folder and rename it to extensions_disabled.
  4. Launch Inkscape to check if the issue persists.

macOS

  1. Quit Inkscape.
  2. Open Finder, press Cmd + Shift + G, and enter ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/.
  3. Locate the extensions folder and rename it to extensions_disabled.
  4. Restart Inkscape.

Linux

  1. Close Inkscape.
  2. Open a terminal or file manager and navigate to ~/.config/inkscape/.
  3. Rename the extensions directory: 
    mv ~/.config/inkscape/extensions ~/.config/inkscape/extensions_disabled
  4. Start Inkscape.

To restore your extensions later, simply delete the new, empty extensions folder Inkscape creates and rename extensions_disabled back to extensions.

Method 2: Launch with a Clean Profile via Terminal

You can launch Inkscape with an isolated temporary profile from the command line. This acts like a true safe mode by ignoring all existing user preferences, custom shortcuts, and installed extensions.

Linux / macOS

Open your terminal and run:

INKSCAPE_PROFILE_DIR=$(mktemp -d) inkscape

Windows (PowerShell)

Open PowerShell and run:

$env:INKSCAPE_PROFILE_DIR = "$env:TEMP\InkscapeSafeMode"
& "C:\Program Files\Inkscape\bin\inkscape.exe"

Method 3: Reset User Preferences

If extensions are not the root cause, a corrupted preferences file might be responsible.

  1. Open Inkscape and navigate to Edit > Preferences (or Inkscape > Settings on macOS).
  2. Select the System tab from the left sidebar.
  3. Click the Reset Preferences button.
  4. Restart Inkscape for the changes to take effect.
