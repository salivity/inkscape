How to Add CSS Transitions to SVG in Inkscape

Applying CSS transitions directly within an SVG file creates interactive, web-ready vector graphics that animate on states like hover without needing external stylesheets. Inkscape provides a built-in XML Editor that allows you to inject raw <style> elements and custom CSS rules straight into the document structure. This guide explains how to use the Inkscape XML Editor to define transitions and link them to your SVG shapes.

Step 1: Open the XML Editor

  1. Open your graphic in Inkscape.
  2. Open the XML Editor by navigating to Edit > XML Editor or by pressing Ctrl + Shift + X (Cmd + Shift + X on macOS).
  3. The editor tree will appear, showing the internal SVG DOM hierarchy.

Step 2: Add an svg:style Element

  1. In the XML Editor tree, select the root element, typically labeled <svg:svg ...>.
  2. Click the New element node button on the toolbar above the tree.
  3. In the dialog that appears, type svg:style and click Create.
  4. With the newly created <svg:style> element selected, add the type attribute:
    • In the Name field on the right panel, enter type.
    • In the Value field, enter text/css.
    • Click Set.

Step 3: Insert CSS Rules and Transitions

  1. With the <svg:style> node selected, click the New text node button on the toolbar.
  2. In the text area on the right, write your CSS styles including the transitions. For example:
.interactive-shape {
  fill: #3498db;
  transition: fill 0.3s ease, transform 0.3s ease;
  transform-origin: center;
}

.interactive-shape:hover {
  fill: #e74c3c;
  transform: scale(1.1);
  cursor: pointer;
}
  1. Click Set to apply the text node.

Step 4: Assign the Class to an SVG Element

  1. In the XML tree, locate and select the node representing the shape you want to animate (e.g., <svg:path>, <svg:rect>, or <svg:circle>). You can also select the shape on the Inkscape canvas, and the editor will highlight the corresponding node.
  2. In the attribute panel on the right:
    • Enter class into the Name field.
    • Enter the class name matching your CSS (e.g., interactive-shape) into the Value field.
    • Click Set.
  3. If the shape already has inline styles (a style attribute) defining properties like fill, remove or edit that attribute, as inline SVG presentation attributes can override your custom CSS classes.

Step 5: Save and Test

  1. Save the file via File > Save As... and choose Plain SVG to remove Inkscape-specific metadata, or keep it as Inkscape SVG if you plan to edit it further.
  2. Open the saved .svg file directly in any modern web browser.
  3. Hover over the modified element to verify that the CSS transition executes smoothly.
