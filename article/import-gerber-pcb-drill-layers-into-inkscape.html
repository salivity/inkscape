Import Gerber PCB Drill Layers into Inkscape

Importing Gerber photoplotter files and Excellon drill layers into Inkscape requires converting raw manufacturing data into a vector format that Inkscape can parse. Because Inkscape does not natively support Gerber (RS-274X) or drill files directly, the most efficient workflow utilizes an open-source Gerber viewer—such as Gerbv or KiCad’s GerbView—to render the drill hits and copper layers and export them as Scalable Vector Graphics (SVG) or PDF. This guide outlines how to process drill files, export them as vector graphics, and import and style them within Inkscape for technical illustrations and documentation.

Step 1: Open Layers in a Gerber Viewer

To align drill hits precisely with your board artwork, open both the photoplotter layer (such as copper or soldermask) and the drill file together in a Gerber viewer.

  1. Launch Gerbv (part of the gEDA suite) or KiCad GerbView.
  2. Go to File > Open Layer(s) and select your Gerber photoplotter files (.gbr, .ger, or .pho).
  3. Go to File > Open Excellon Drill File(s) and select your drill file (.drl, .xln, or .txt).
  4. Ensure the drill layer aligns correctly with the copper pads. If there is an offset or scaling mismatch, adjust the drill format settings (such as metric/imperial units or zero-suppression options) within the viewer until alignment is exact.

Step 2: Export the Data to SVG or PDF

Once the drill holes and board traces are aligned, export the view into a vector format.

  • In Gerbv: Go to File > Export > SVG... or File > Export > PDF.... Save the file to your desired location. Exporting as SVG preserves native vector paths and layer information directly.
  • In KiCad GerbView: Go to File > Export to SVG.... Choose the directory, select the layers you want to include, and click Export. Alternatively, you can use File > Print and print to a PDF with vector preservation enabled.

Step 3: Import into Inkscape

  1. Open Inkscape.
  2. Go to File > Import (or press Ctrl + I) and locate the exported SVG or PDF file.
  3. If importing a PDF, select Internal import in the prompt, leave the resolution settings at default, and ensure text and paths are maintained as vector objects.
  4. Click OK. The board layers and drill hits will appear on your canvas as vector paths.

Step 4: Organize and Style for Documentation

  1. Ungroup Paths: The imported artwork usually loads as grouped objects. Select the imported graphic and press Ctrl + Shift + G repeatedly until the drill holes and photoplotter traces are separated into distinct elements.
  2. Assign Layers: Open the Layers panel (Ctrl + Shift + L). Create separate layers for the board outline, copper features, and drill holes. Move the corresponding paths onto their respective layers to make editing easier.
  3. Format Drill Hits: Select the drill paths to adjust their appearance. In the Fill and Stroke panel (Ctrl + Shift + F), set appropriate stroke widths or fills. You can render drill holes as white circles with black outlines to indicate cutouts, or color-code different hole diameters for assembly and fabrication documentation.
  4. Scale and Dimension: If adding dimension callouts, lock the layer containing your board and drill paths to prevent accidental movement while placing dimension lines, annotations, and leader text around the drill locations.
