Check for Embedded RGB Images in Inkscape

Preparing an SVG for commercial print requires verifying that all assets comply with the intended color space, as unintentional RGB raster images can cause dull or unpredictable colors when converted to CMYK on press. This guide explains how to quickly locate raster images embedded inside an Inkscape SVG document, inspect their properties using native tools like the Find dialog and XML Editor, and verify their true color mode before sending files to print.

Step 1: Locate All Embedded Images in the SVG

Before inspecting color profiles, you must identify every raster element within the document.

  1. Open your document in Inkscape.
  2. Open the Find/Replace dialog by pressing Ctrl + F (or Cmd + F on macOS).
  3. In the dialog, set the search parameters:
    • Leave the Find field blank.
    • Expand the Object Types section.
    • Check only Images and uncheck all other types (paths, shapes, text, etc.).
  4. Click Find. Inkscape will select all embedded and linked bitmap images across all unlocked layers.

Alternatively, open the Objects panel (Layer > Objects...) to visually scan the tree for <image> nodes.

Step 2: Extract and Inspect Image Color Modes

Inkscape displays all raster images within an RGB canvas profile and does not display an image's native color space directly in the main interface. To verify if an embedded image is RGB:

  1. Select the image in the canvas.
  2. Right-click the image and select Extract Image....
  3. Choose a destination folder and save the extracted image file (usually saved as a PNG or JPEG).
  4. Inspect the extracted file’s metadata using your operating system tools or an image viewer:
    • Windows: Right-click the extracted file, select Properties, open the Details tab, and check the Color representation field (e.g., sRGB).
    • macOS: Select the file, press Cmd + I to open Get Info, and expand the More Info section to inspect the Color profile.
    • Linux / Command Line: Run identify -verbose image.png (using ImageMagick) or exiftool image.png to read the Color Space tag.

If the color space reports sRGB or Adobe RGB, the image is an unintentional RGB asset that must be converted to CMYK using a raster editor like GIMP, Krita, or Photoshop.

Step 3: Inspect Raw Image Data via the XML Editor

To verify whether an image is linked externally or directly embedded as base64-encoded RGB data:

  1. Select the image.
  2. Open the XML Editor by pressing Shift + Ctrl + X.
  3. In the tree view, highlight the selected <svg:image> node.
  4. Review the attributes list on the right:
    • xlink:href or href starting with data:image/png;base64,...: PNG files strictly use RGB or Grayscale; they do not support CMYK. Any embedded PNG is guaranteed to be in an RGB format.
    • xlink:href or href starting with data:image/jpeg;base64,...: JPEG files can be either CMYK or RGB, requiring extraction (Step 2) to confirm the color space.

Step 4: Convert and Replace Non-CMYK Images

If an image is identified as RGB:

  1. Open the extracted image in a dedicated image editor that supports CMYK profiles (such as Photoshop, Photopea, or Krita).
  2. Convert the image's color profile to your target print profile (e.g., GRACoL, SWOP, or FOGRA39).
  3. Save the image as a CMYK TIFF or high-quality CMYK JPEG.
  4. In Inkscape, select the original RGB image and delete it, or right-click it and choose Image Properties to update the file path with the newly converted CMYK file.
