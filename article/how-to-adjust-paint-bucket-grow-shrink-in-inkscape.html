How to Adjust Paint Bucket Grow/Shrink in Inkscape

Adjusting the grow/shrink and threshold settings for the Paint Bucket tool in Inkscape allows you to create seamless vector fills without unwanted gaps or color bleed. This guide provides a straightforward walkthrough on locating the Tool Controls Bar, modifying the Threshold to control color detection sensitivity, and using the Grow/Shrink offset parameter to expand or contract your filled paths.

Step 1: Select the Paint Bucket Tool

Open your project in Inkscape and activate the Fill Bounded Areas (Paint Bucket) tool by clicking its icon in the left toolbar or by pressing the shortcut U (or Shift + F7).

Step 2: Locate the Tool Controls Bar

Once the tool is selected, look at the Tool Controls Bar running horizontally across the top of the canvas. This bar contains all the parameters that dictate how the Paint Bucket operates.

Step 3: Adjust the Threshold

The Threshold setting controls how sensitive the bucket is to color variations when detecting boundaries:

  • Lower Values (e.g., 5–15): The fill strictly stops at slight color changes. Use this for sharp, high-contrast line art.
  • Higher Values (e.g., 30–80): The fill tolerates greater color variations, allowing it to bridge anti-aliased edges or gradients.
  • Change this value by typing a number directly into the Threshold field or using the up/down arrows.

Step 4: Adjust the Grow/Shrink Value

The Grow/shrink by setting adjusts the final dimensions of the generated fill path relative to the detected boundaries:

  • Positive Values (Grow): Expands the filled shape outward. Setting this to 0.5 px to 1.5 px prevents white gaps between your fill and outline strokes caused by anti-aliasing.
  • Negative Values (Shrink): Insets the filled shape inward, making it smaller than the detected area.
  • Zero (0.00): Creates an exact boundary match based strictly on the visible pixels.
  • Change the value in the Grow/shrink by box, and use the adjacent dropdown to change the measurement unit (e.g., px, pt, mm) if necessary.

Step 5: Apply the Fill

Click inside any closed region on your canvas. Inkscape will calculate the area according to your chosen Threshold and automatically apply the offset defined in your Grow/shrink by field. If the fill bleeds outside the boundary or leaves visible gaps, press Ctrl + Z to undo, tweak the values in the top bar, and click again.
