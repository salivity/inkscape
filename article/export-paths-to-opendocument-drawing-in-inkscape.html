Export Paths to OpenDocument Drawing in Inkscape

Exporting vector paths from Inkscape to the OpenDocument Drawing format allows you to seamlessly share and edit your vector illustrations in office suites such as LibreOffice Draw and Apache OpenOffice. This guide outlines the straightforward process of preparing your paths and saving them into the standard OpenDocument Drawing format directly within Inkscape.

Step 1: Prepare Your Paths

Before exporting, ensure all shapes and text elements are converted into pure vector paths so they render consistently across different software.

  1. Select the elements you want to export using the Select Tool (S or F1).
  2. Navigate to the top menu and click Path.
  3. Choose Object to Path (shortcut: Shift + Ctrl + C).
  4. If you have strokes that need to remain fixed in width, select them and click Path > Stroke to Path (Ctrl + Alt + C).

Step 2: Export to OpenDocument Drawing

Inkscape includes native support for exporting directly to the OpenDocument Drawing specification.

  1. Click on File in the top menu bar.
  2. Select Save As... (or Save a Copy... to keep your working SVG intact).
  3. In the file browser dialog, choose your destination folder and name your file.
  4. Click the Save as type dropdown menu.
  5. Locate and select OpenDocument Drawing (*.odg) from the list.
  6. Click Save.

Step 3: Verify the Export

Open the generated file in an OpenDocument-compatible viewer or editor (such as LibreOffice Draw) to confirm that the path geometry, fills, and stroke properties have transferred properly.
