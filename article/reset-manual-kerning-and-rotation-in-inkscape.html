Reset Manual Kerning and Rotation in Inkscape

When working with typography in Inkscape, manual character adjustments such as custom kerning, vertical shifts, and rotations can quickly accumulate and distort a layout. This guide explains how to completely clear those manual adjustments and restore your text to the font's default spacing and alignment using Inkscape's built-in tools.

The Fast Method: Remove Manual Kerns

The quickest way to revert all kerning, shifting, and rotational changes across an entire text element is by using the dedicated text menu command:

  1. Select the Text tool (T or F8) from the left-hand toolbox.
  2. Click inside the text object you want to fix.
  3. Select the characters you wish to reset. To fix the entire text object, press Ctrl + A to select all text within the block.
  4. Go to the top menu and select Text.
  5. Click Remove Manual Kerns.

This command instantly strips out all manual horizontal kerning, vertical shifts, and character rotations, returning the selected glyphs to their native font metrics.

What Adjustments Are Cleared?

Using the "Remove Manual Kerns" feature clears every adjustment applied using the Alt key shortcuts or the text tool controls bar, including:

  • Horizontal kerning: Adjustments made using Alt + Left Arrow or Alt + Right Arrow.
  • Vertical shifts: Adjustments made using Alt + Up Arrow or Alt + Down Arrow.
  • Character rotation: Angles applied using Alt + [ or Alt + ].

Manual Reset via the Tool Controls Bar

If you prefer to reset specific parameters individually rather than removing all adjustments at once:

  1. Activate the Text tool and highlight the modified characters.
  2. Locate the Tool Controls Bar directly above the canvas.
  3. Identify the input fields for:
    • Dx: Horizontal kerning
    • Dy: Vertical shift
    • Rotation: Character angle (in degrees)
  4. Delete the numeric values in these fields or set them to 0, then press Enter.
