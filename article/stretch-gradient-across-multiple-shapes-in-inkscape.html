Stretch Gradient Across Multiple Shapes in Inkscape

Applying a single, continuous gradient across several independent vector objects creates a cohesive, professional aesthetic. This guide explains how to span, stretch, compress, and reposition gradient boundaries across multiple distinct shapes in Inkscape without permanently flattening them into a single path. By utilizing multi-selection techniques or object grouping, you can manipulate a single set of gradient boundary handles to precisely control the color transition across your entire layout.

Method 1: Multi-Selection with the Gradient Tool

This method allows shapes to maintain their individual layers and attributes while sharing the same gradient geometry.

  1. Select the Objects: Use the Select Tool (S) to select all the distinct vector shapes you want to include. You can do this by dragging a selection box around them or holding Shift and clicking each shape.
  2. Activate the Gradient Tool: Press G or click the Create and edit gradients icon in the left-hand toolbox.
  3. Apply the Gradient: Click and drag across the selected objects from the desired start point to the end point. Inkscape will assign a synchronized linear or radial gradient across all chosen shapes.
  4. Stretch or Compress the Boundaries:
    • Locate the start handle (a square) and the end handle (a circle).
    • Click and drag either handle to alter the gradient span. Pulling the handles further apart stretches the gradient transition across the shapes; pushing them closer together compresses the boundary, resulting in a tighter color shift.
    • Hold Ctrl while dragging to lock the gradient angle to 15-degree increments.

Method 2: Grouping the Objects

Grouping distinct paths is ideal when you want the shapes to permanently share a common fill definition without merging their vector paths.

  1. Group the Shapes: Select all the desired vector shapes using the Select Tool (S) and press Ctrl + G (or go to Object > Group).
  2. Apply the Gradient: Open the Fill and Stroke panel (Ctrl + Shift + F). Go to the Fill tab and click the Linear gradient or Radial gradient button. The gradient is applied to the group as a whole.
  3. Adjust the Boundary: Select the Gradient Tool (G). The group's gradient handles will appear.
  4. Scale the Transition: Drag the square or circular end nodes to stretch or compress the transition zone across the boundary of the grouped objects.

Fine-Tuning the Gradient Extent

  • Repositioning: Click and drag the line connecting the two gradient handles to move the entire gradient transition without changing its stretch or compression ratio.
  • Adding Intermediate Stops: Double-click anywhere along the gradient line with the Gradient Tool active to insert intermediate color stops, allowing for localized compression of specific color phases across your shapes.
