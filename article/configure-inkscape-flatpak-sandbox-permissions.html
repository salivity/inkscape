Configure Inkscape Flatpak Sandbox Permissions

The Flatpak version of Inkscape runs inside an isolated sandbox to enhance system security, but this can sometimes prevent the application from accessing certain files, external drives, or hardware devices like drawing tablets. You can easily modify these sandbox boundaries to grant Inkscape specific access to system resources. This guide covers how to customize Inkscape's permissions using both a graphical interface via Flatseal and the native Flatpak command-line interface.

Method 1: Using Flatseal (GUI)

Flatseal is a graphical permission manager for Flatpak applications that provides a simple toggle-based interface.

  1. Install Flatseal:
    If you do not have Flatseal installed, install it using your software manager or run:

    flatpak install flathub com.github.juankmorales.flatseal

  2. Open Flatseal and Select Inkscape:
    Launch Flatseal from your application menu and locate Inkscape in the list of applications on the left panel.

  3. Adjust Permissions:
    Scroll through the categories on the right to modify access:

    • Filesystem: Enable All system files (host) or add specific paths under Other files (e.g., /run/media for external drives or ~/.local/share/fonts for user fonts).
    • Device: Ensure Direct 3D rendering (dri) and Input devices are toggled on if you experience issues with graphics acceleration or drawing tablets.
    • Sockets: Ensure X11 windowing system and Wayland windowing system are enabled according to your desktop display server.

Changes made in Flatseal apply immediately. Restart Inkscape to load the new permissions.

Method 2: Using the Command Line (flatpak override)

You can configure persistent permission changes directly from the terminal using the flatpak override command targeting Inkscape’s application ID, org.inkscape.Inkscape.

Granting Filesystem Access

  • Access the entire host filesystem:

    flatpak override org.inkscape.Inkscape --filesystem=host

  • Access a specific directory (Read/Write):

    flatpak override org.inkscape.Inkscape --filesystem=/path/to/your/folder

  • Access a directory as Read-Only (e.g., custom fonts):

    flatpak override org.inkscape.Inkscape --filesystem=~/.local/share/fonts:ro

  • Access external media drives:

    flatpak override org.inkscape.Inkscape --filesystem=/media --filesystem=/run/media

Granting Hardware and Device Access

  • Allow access to all input devices (useful for stylus and graphics tablets): 
    flatpak override org.inkscape.Inkscape --device=all

Revoking Permissions and Resetting

  • Revoke a specific permission:

    flatpak override org.inkscape.Inkscape --nofilesystem=/path/to/your/folder

  • Reset all custom permissions back to default:

    flatpak override --reset org.inkscape.Inkscape

  • View active overrides:

    flatpak override --show org.inkscape.Inkscape
