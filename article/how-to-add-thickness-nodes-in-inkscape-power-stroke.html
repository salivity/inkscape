How to Add Thickness Nodes in Inkscape Power Stroke

Inkscape's Power Stroke Live Path Effect (LPE) allows you to create dynamic strokes with variable widths along a single vector line. This guide provides a straightforward walkthrough on how to add additional thickness control nodes, reposition them along your path, and fine-tune local width adjustments for precise illustration and calligraphy work.

Step 1: Select the Path with the Node Tool

To interact with Power Stroke parameters directly on the canvas, you must use the Node tool.

  1. Open your document in Inkscape.
  2. Select the Node tool from the left toolbar or press the shortcut N.
  3. Click on the path that has the Power Stroke path effect applied.

Step 2: Locate the Width Control Nodes

When the path is selected with the Node tool, you will see two types of nodes:

  • Path Nodes: Standard gray square or diamond nodes that define the trajectory of the center line.
  • Thickness Control Nodes: Distinct pink (or purple) diamond-shaped handles located along the path edge that control stroke width.

Step 3: Add a New Thickness Node

To introduce a new point of thickness variation along the path:

  1. Hover your cursor over an existing pink thickness control node.
  2. Hold down the Ctrl key.
  3. Left-click on the pink node.

This action duplicates the control point, placing a new pink handle directly on top of the clicked handle.

Step 4: Adjust the New Node's Position and Width

Once the new node is created:

  1. Click and drag the new pink handle along the length of the path to place it where you want the thickness change to occur.
  2. Drag the handle away from or toward the center line to increase or decrease the local thickness at that exact point.

Step 5: Removing Control Nodes (Optional)

If you add too many control points or want to revert an adjustment:

  1. Hold Ctrl + Alt.
  2. Left-click on the pink thickness node you wish to delete.
