How to Fix and Relink Broken Images in Inkscape

When working with linked external raster images in Inkscape, moving, renaming, or deleting the source files results in broken links represented by a red "X" or a placeholder box. This guide explains how to quickly identify missing image paths within your Inkscape project, update the broken file links to restore your graphics, and embed the assets directly to prevent future link breakage.

Identifying Broken Images

When an image path is broken, Inkscape displays an empty bounding box with a red "X" and the missing file's original name or path. If you have a large document with multiple assets, locating them manually on the canvas can be difficult.

To find all linked images in your project:

  1. Open the XML Editor by pressing Shift + Ctrl + X or navigating to Edit > XML Editor.
  2. Expand the document tree and search for <svg:image> nodes.
  3. Select an image node to highlight it on the canvas and view its attributes in the right-hand pane.
  4. Check the xlink:href or href attribute to see the exact file path Inkscape is looking for.

Relinking the Missing Image

Once you have identified the missing image, you can update its file path directly without needing to reposition or resize a new import.

Method 1: Using the XML Editor

  1. Select the broken image placeholder on your canvas.
  2. In the XML Editor (Shift + Ctrl + X), the corresponding <svg:image> node will be selected automatically.
  3. In the attribute panel on the right, click on xlink:href (or href in newer SVG specifications).
  4. In the text field below the attribute list, replace the broken path with the new absolute or relative path of the image file on your system (e.g., file:///C:/Users/Name/Pictures/image.png or images/photo.png).
  5. Click Set (or press Ctrl + Enter) to apply the change. The image will immediately render on the canvas.

Method 2: Replacing the Image via File Import

If updating the path manually is inconvenient:

  1. Note the dimensions and position of the broken placeholder in the tool controls bar.
  2. Import the correct image by going to File > Import (Ctrl + I).
  3. Select Link when prompted by the import dialog.
  4. Position the new image over the old placeholder and delete the broken object.

Preventing Broken Links by Embedding Images

To ensure that your SVG file remains intact when shared across different computers or moved to other directories, you can permanently embed the linked images into the document.

  1. Embed a Single Image: Right-click the relinked image on the canvas and select Embed Image.
  2. Embed All Images at Once: Go to Extensions > Images > Embed Images..., select your preferred settings, and click Apply. Inkscape will convert all linked external files into base64-encoded data stored directly inside the SVG file.
