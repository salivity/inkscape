Assign Single-Key Shortcuts to Inkscape Extensions

Custom Python extensions can significantly accelerate your workflow in Inkscape, and binding them to single-key shortcuts eliminates the need to navigate multi-level menus. This guide explains how to map single-character keys directly to your installed Python extensions using Inkscape's built-in preferences or by manually editing the shortcut configuration file.

Method 1: Using the Inkscape Preferences Menu

The simplest way to bind a single-key shortcut is through the graphical interface.

  1. Open Keyboard Preferences:

    • Go to Edit > Preferences (or press Ctrl + Shift + P).
    • In the left sidebar, expand Interface and select Keyboard.

  2. Locate Your Custom Extension:

    • In the search bar at the top of the Keyboard Shortcuts pane, type the exact display name of your custom Python extension.
    • Alternatively, expand the Extensions category in the command tree and scroll to the submenu where your extension is categorized.

  3. Assign the Single Key:

    • Click on the row of your extension under the Shortcut column. The text will change to indicate it is listening for key input (typically reading New accelerator...).
    • Press the single key you wish to assign (for example, J, Q, or 1).

  4. Resolve Key Conflicts (If Prompted):

    • Inkscape uses many single keys for standard tools (e.g., S for Selector, R for Rectangle). If your chosen key is already mapped, Inkscape will display a warning dialog showing the conflicting action.
    • Confirm that you want to overwrite the existing shortcut to reassign it to your extension.

  5. Test the Extension:

    • Close the Preferences window.
    • Return to your canvas and press the assigned key to confirm the extension runs immediately.

Method 2: Manually Editing the Shortcut XML File

If your extension does not appear cleanly in the search or you want to maintain a portable configuration, you can assign shortcuts by modifying Inkscape's user configuration file.

  1. Find the Extension ID:

    • Open your extension's .inx file in a text editor.
    • Locate the <id> tag (e.g., <id>org.inkscape.render.my_custom_script</id>). Copy this ID string.

  2. Locate or Create default.xml:

    • Navigate to your Inkscape user profile directory:
      • Linux: ~/.config/inkscape/keys/
      • Windows: %APPDATA%\inkscape\keys\
      • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/keys/
    • If default.xml does not exist in the keys folder, create a new text file and name it default.xml.

  3. Add the Key Binding:

    • Structure your default.xml as follows, replacing the key and action values with your chosen key and extension ID:
<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns:inkscape="http://www.inkscape.org/namespaces/inkscape">
  <bind key="q" action="org.inkscape.render.my_custom_script" />
</inkscape-extension>
  1. Restart Inkscape:
    • Save the file and restart Inkscape. The key specified in the key attribute will now trigger the extension.
