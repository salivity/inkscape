How to Hide Rulers in Inkscape

This guide explains how to completely hide both the horizontal and vertical canvas rulers in Inkscape. Whether you want to maximize your workspace or eliminate visual clutter, you can quickly disable the rulers using a fast keyboard shortcut or through the application's view settings.

Method 1: Use the Keyboard Shortcut

The fastest way to toggle the rulers off in Inkscape is using the default keyboard shortcut:

  • Windows and Linux: Press Ctrl + R
  • macOS: Press Cmd + R

Pressing this key combination immediately hides both the horizontal and vertical rulers. Pressing it again will restore them.

Method 2: Use the View Menu

If you prefer using the graphical menu, you can turn off the rulers through the main navigation bar:

  1. Click on View in the top menu bar.
  2. Hover your cursor over the Show/Hide submenu.
  3. Click on Rulers to uncheck the option.

Once unchecked, the rulers will disappear completely from the canvas border. You can re-enable them at any time by navigating back to the same menu and clicking Rulers again to check the box.
