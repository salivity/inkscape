Inkscape CLI: Export Specific Element ID to PDF

This article explains how to use the Inkscape command-line interface (CLI) to isolate and export an individual SVG element to a PDF document using its unique ID. By leveraging specific export flags, you can crop the output to the target object's bounding box and completely exclude the surrounding canvas and background elements.

Identifying the Element ID

Before running the command, you need the exact ID of the element you wish to export. Open the SVG file in Inkscape, select the object, and open the Object Properties dialog (Shift + Ctrl + O) or the XML Editor (Shift + Ctrl + X) to locate the id attribute (for example, rect4153 or logo_layer).

Modern Inkscape Command (v1.0 and Newer)

For Inkscape 1.0 and later versions, use the --export-id and --export-id-only options. The basic syntax is:

inkscape input.svg --export-id="my_element_id" --export-id-only --export-filename="output.pdf"

Here is how each flag operates:

  • input.svg: The path to your source SVG file.
  • --export-id="my_element_id": Specifies the exact ID of the element, group, or layer you want to export.
  • --export-id-only: Hides all other elements on the canvas so that only the selected element is rendered. It also sets the PDF page dimensions to match the bounding box of the exported object.
  • --export-filename="output.pdf": Defines the destination file. Inkscape automatically determines the PDF output format based on the .pdf extension.

If you prefer to define the output format explicitly, append --export-type="pdf":

inkscape input.svg --export-id="my_element_id" --export-id-only --export-type="pdf" --export-filename="output.pdf"

Legacy Inkscape Command (v0.92 and Older)

If you are using an older version of Inkscape, the shorthand flags are required:

inkscape -i my_element_id -j -A output.pdf input.svg
  • -i my_element_id: Corresponds to --export-id.
  • -j: Corresponds to --export-id-only (exports only the selected object).
  • -A output.pdf: Specifies export directly to a PDF file format.

Key Considerations

  • Case Sensitivity: Object IDs are strictly case-sensitive. Ensure the ID provided in the CLI exactly matches the ID in the SVG source code.
  • Groups and Layers: You can target entire groups (<g>) or layers by their ID. The --export-id-only flag will export the group and all of its nested children while excluding everything else.
