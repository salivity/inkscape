Export Inkscape Vectors to DaVinci Resolve Fusion

Exporting vector artwork from Inkscape into DaVinci Resolve’s Fusion page enables you to create infinitely scalable, crisp motion graphics titles. This workflow requires converting artwork to standardized paths in Inkscape, saving it in a compatible format, and importing it into Fusion as native vector nodes. Once imported, the vector paths become fully animatable elements that you can control using keyframes and modifiers.

Step 1: Prepare the Vector in Inkscape

Before exporting, you must simplify your artwork so Fusion can interpret the data without errors.

  1. Convert Strokes to Paths: Select all elements and navigate to Path > Stroke to Path. Fusion cannot interpret native vector stroke properties properly without this conversion.
  2. Convert Objects to Paths: Select all shapes (rectangles, text, circles) and go to Path > Object to Path.
  3. Ungroup Elements: Select everything and press Ctrl + Shift + G (or Cmd + Shift + G on macOS) repeatedly until there are no nested groups.
  4. Organize Layers: Ensure separate design elements you plan to animate independently are separated on distinct paths or layers.
  5. Fit Canvas to Selection: Go to File > Document Properties and click Resize page to drawing or selection to remove unnecessary transparent padding, or set the page size to your project's resolution (e.g., 1920x1080).

Step 2: Save as Plain SVG

Inkscape defaults to its own proprietary SVG format containing metadata that Fusion does not need.

  1. Go to File > Save As...
  2. In the file format dropdown, choose Plain SVG (*.svg) instead of Inkscape SVG.
  3. Name your file and save it to your project directory.

Step 3: Import the SVG into DaVinci Resolve Fusion

Fusion features a dedicated import tool that converts standard SVG files directly into node-based vector graphics.

  1. In DaVinci Resolve, create a new Fusion Composition in your timeline and switch to the Fusion page.
  2. Click the top menu and select Fusion > Import > SVG...
  3. Locate and select your saved Plain SVG file, then click Open.
  4. In the import dialog box, set the frame size to match your project timeline resolution, then confirm.

Step 4: Organize and Animate Nodes

Once imported, Fusion automatically creates a network of nodes representing your design.

  1. Node Structure: Fusion imports the SVG as a series of Polygon mask nodes connected to colored Background nodes, combined through a chain of Merge nodes.
  2. Identify Elements: Rename the generated Background or Polygon nodes to identify the specific parts of your title (e.g., "MainText", "IconLogo", "AccentBar").
  3. Add Transforms: Insert a Transform (XF) node after any individual Merge or Background node to animate its position, scale, or rotation independently.
  4. Animate Native Paths: Select a Polygon node to directly keyframe individual vector points, animate the path drawing on with the Length control, or soften edges using Soft Edge.
  5. Connect to Output: Connect the final Merge node of your imported vector chain to the MediaOut1 node to make the motion graphics visible in the Edit page.
