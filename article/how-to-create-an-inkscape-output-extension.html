How to Create an Inkscape Output Extension

This guide details how to build a custom Inkscape Output Extension to export SVG documents into proprietary or alternative file formats. By creating an XML definition file (.inx) and a Python implementation script using the inkex library, you can integrate your custom file exporter directly into Inkscape’s "Save As" dialog.

Understanding the Extension Architecture

Inkscape extensions rely on two primary files placed within the Inkscape extensions directory:

  1. The Descriptor File (.inx): An XML file that registers the extension, defines its UI parameters, and specifies its role as an output filter.
  2. The Execution Script (.py): A Python script that parses the SVG document tree via the inkex library and serializes the data into your target format.

Locate your user extensions folder by opening Inkscape and navigating to Edit > Preferences > System > User extensions. Typically, this directory is found at:

  • Linux: ~/.config/inkscape/extensions/
  • Windows: %APPDATA%\inkscape\extensions\
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/

Step 1: Create the INX Descriptor

Create a file named custom_export.inx in your user extensions directory. This file instructs Inkscape to display your format in the "Save As" menu.

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>Custom Format Exporter</name>
    <id>org.example.output.customformat</id>
    
    <output>
        <extension>.custom</extension>
        <mimetype>text/plain</mimetype>
        <filetypename>Custom Vector Format (*.custom)</filetypename>
        <filetypetooltip>Exports the document to a custom plain text format</filetypetooltip>
    </output>

    <script>
        <command location="inx" interpreter="python">custom_export.py</command>
    </script>
</inkscape-extension>
  • <id>: A globally unique identifier for your extension.
  • <extension>: The target file extension appended to saved files.
  • <filetypename>: The label that appears in the "Save As" file type dropdown.
  • <command>: The script interpreter and the name of your Python file.

Step 2: Implement the Exporter in Python

Create the corresponding custom_export.py file in the same directory. Modern versions of Inkscape (1.0+) provide the inkex.OutputExtension class, which handles standard stream interactions automatically.

#!/usr/bin/env python3
import inkex
from inkex import paths

class CustomOutputExtension(inkex.OutputExtension):
    def save(self, stream):
        # Access the root SVG element
        svg = self.svg
        
        # Write header or metadata to the output stream
        stream.write(f"# Document Dimensions: {svg.width}x{svg.height}\n".encode("utf-8"))
        
        # Iterate over paths and visual elements in the document
        for elem in svg.descendants():
            if isinstance(elem, inkex.PathElement):
                elem_id = elem.get("id", "unnamed")
                path_data = elem.get("d")
                
                # Transform path data or extract raw coordinates
                stream.write(f"PATH id={elem_id} data={path_data}\n".encode("utf-8"))
                
            elif isinstance(elem, inkex.Rectangle):
                elem_id = elem.get("id", "unnamed")
                x = elem.get("x", "0")
                y = elem.get("y", "0")
                w = elem.get("width", "0")
                h = elem.get("height", "0")
                stream.write(f"RECT id={elem_id} x={x} y={y} w={w} h={h}\n".encode("utf-8"))

if __name__ == "__main__":
    CustomOutputExtension().run()

Step 3: Parse and Convert Elements

Inside the save(self, stream) method:

  • Access Elements: Use self.svg.descendants() to traverse all nodes, or query specific elements using XPath via self.svg.xpath('//svg:path').
  • Handle Transforms: Inkscape shapes often contain transformations. Resolve global positioning using elem.composed_transform() to obtain an element's absolute coordinates rather than local offsets.
  • Convert Geometry to Paths: To handle circles, rects, and polygons uniformly, use inkex.PathElement conversion utilities or generate standardized path commands using elem.path.to_absolute().
  • Output Stream: The stream parameter expects binary data (bytes). Ensure strings are encoded (e.g., .encode('utf-8')) before writing.

Step 4: Test the Extension

  1. Restart Inkscape to force it to re-scan the extensions folder.
  2. Open or create an SVG document containing basic shapes and paths.
  3. Click File > Save As... or File > Export....
  4. In the format selection menu, choose Custom Vector Format (*.custom).
  5. Save the file and inspect the generated output in a text editor to verify the data structure.
