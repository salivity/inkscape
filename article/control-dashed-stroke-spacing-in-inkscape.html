Control Dashed Stroke Spacing in Inkscape

This guide demonstrates how to apply and configure the Dashed Stroke Live Path Effect (LPE) in Inkscape to gain exact control over dash spacing and placement using subpath nodes. While standard stroke dash patterns wrap uniformly around an entire path, combining the Dashed Stroke effect with subpaths allows you to anchor, split, and manipulate dash distributions across specific segments of a design.

1. Prepare the Path and Subpaths

  1. Select the Pen (Bezier) Tool (B) or Pencil Tool (P) and draw your path.
  2. Switch to the Node Tool (N) and click on the path to reveal its nodes.
  3. To define custom dash boundaries, split the line into subpaths. Select any node where you want a boundary or independent dash behavior and click the Break path at selected nodes button in the top tool controls bar.
  4. The path remains a single vector object, but it now contains distinct subpaths anchored by the broken nodes.

2. Apply the Dashed Stroke LPE

  1. Select your path using either the Select Tool (S) or the Node Tool (N).
  2. Go to the top menu and select Path > Path Effects... to open the Path Effects panel.
  3. Click the Add Path Effect button (the + icon).
  4. Search for or scroll to Dashed Stroke in the effects list and click it to apply it to your path.

3. Configure the Dash Parameters

Once the effect is added, its settings appear in the Path Effects panel:

  • Number of dashes: Defines how many dash segments are generated across each segment.
  • Hole factor / length: Controls the gap distance between individual dashes.
  • Dash length: Specifies the length of the visible stroke segments.
  • Equalize dashes / Half dashes: Check these options if you want the start and end of each subpath to begin and conclude with half-length dashes for symmetrical alignment.

4. Adjust Dash Spacing with Subpath Nodes

Because the Dashed Stroke effect calculates distribution relative to each continuous segment within the path object, your subpath nodes act as direct layout anchors:

  1. With the Node Tool (N) active, drag any of the subpath endpoint nodes along the path direction.
  2. Moving a node changes the length of that specific subpath, dynamically expanding or compressing the dash intervals in that section without distorting other segments.
  3. To add more controlled spacing zones, select a segment and click Insert new nodes into selected segments, followed by Break path at selected nodes.
  4. To merge zones back into a standard distribution, select two overlapping endpoint nodes and click Join selected nodes.
