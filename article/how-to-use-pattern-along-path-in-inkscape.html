How to Use Pattern Along Path in Inkscape

Inkscape's Pattern Along Path Live Path Effect (LPE) allows you to duplicate and stretch or distribute a vector shape along the trajectory of a line. This guide provides a straightforward, step-by-step walkthrough on how to prepare your source objects, apply the effect, and configure options such as spacing, repetition modes, and offsets to achieve clean, repeatable vector designs.

Step 1: Create and Convert Your Objects

  1. Draw the shape you want to repeat (the pattern).
  2. Draw the line or curve you want the pattern to follow (the path).
  3. Ensure both objects are converted to paths. Select each object individually and go to Path > Object to Path (or press Shift + Ctrl + C).

Step 2: Copy the Pattern to the Clipboard

  1. Select the pattern object using the Select Tool (S).
  2. Copy it to your clipboard by pressing Ctrl + C (or Cmd + C on macOS).

Step 3: Apply the Pattern Along Path Effect

  1. Select the destination path (the line or curve).
  2. Open the Path Effects panel by navigating to Path > Path Effects.
  3. Click the + (Add Path Effect) button.
  4. In the search bar, type Pattern Along Path and click on the effect to add it to the path.

Step 4: Link the Pattern to the Path

  1. In the Path Effects panel under the "Pattern Along Path" settings, locate the Pattern source row.
  2. Click the Paste Path (clipboard icon) or Link to path in clipboard button.
  3. The selected path will immediately transform, rendering the copied pattern along its length.

Step 5: Configure the Effect Settings

Fine-tune the output using the controls in the Path Effects panel:

  • Pattern copies:
    • Single: Places one stretched copy along the entire path.
    • Repeated: Duplicates the pattern across the path at its original proportions.
    • Repeated, stretched: Duplicates the pattern and automatically stretches them so they fit the path length evenly.
  • Spacing: Adjusts the gap or overlap between consecutive pattern copies.
  • Normal offset: Moves the pattern perpendicular to the path (above or below the line).
  • Tangential offset: Shifts the start position of the pattern along the path.
  • Pattern is vertical: Toggle this if your original pattern was drawn vertically rather than horizontally.

Step 6: Finalizing the Output (Optional)

If you want to freeze the design and turn the repeated shapes into permanent, editable vector nodes, select the object and go to Path > Object to Path. This removes the dynamic effect and converts the result into standard editable geometry.
