Create Inkscape Python Extensions Using inkex

Developing custom Python extensions for Inkscape allows you to automate repetitive vector tasks, create procedural artwork, and manipulate SVG elements directly within the application. This guide outlines the end-to-end process of building a custom extension using Inkscape's official inkex Python module, covering the required file structure, XML configuration (.inx), Python implementation, and installation.

1. Extension Architecture

An Inkscape extension requires two primary files sharing the same base name:

  1. The Descriptor File (.inx): An XML-based file that defines the extension's user interface, menu location, and parameter inputs.
  2. The Script File (.py): A Python script utilizing the inkex library to process and modify the SVG document.

2. Creating the .inx Descriptor File

The .inx file informs Inkscape where to place your tool in the menu hierarchy and what parameters to pass to your Python script.

Create a file named my_custom_extension.inx:

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>Add Custom Rectangle</name>
    <id>org.example.add_custom_rect</id>
    
    <!-- User Input Parameters -->
    <param name="width" type="float" min="1.0" max="1000.0" gui-text="Width (px):">100.0</param>
    <param name="height" type="float" min="1.0" max="1000.0" gui-text="Height (px):">50.0</param>
    <param name="color" type="color" gui-text="Fill Color:">255</param>

    <!-- Menu Location -->
    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Custom Tools"/>
        </effects-menu>
    </effect>

    <!-- Script Call Definition -->
    <script>
        <command location="inx" interpreter="python">my_custom_extension.py</command>
    </script>
</inkscape-extension>

3. Writing the Python Script with inkex

Modern Inkscape versions (1.0+) use an object-oriented API based on inkex.EffectExtension. Your script inherits from this class, parses parameters, and manipulates the SVG Document Object Model (DOM).

Create a file named my_custom_extension.py:

import inkex
from inkex import Rectangle, Color

class CustomRectangleExtension(inkex.EffectExtension):
    def add_arguments(self, pars):
        # Match the param names defined in the .inx file
        pars.add_argument("--width", type=float, default=100.0, help="Width of the rectangle")
        pars.add_argument("--height", type=float, default=50.0, help="Height of the rectangle")
        pars.add_argument("--color", type=Color, default=Color("red"), help="Fill color")

    def effect(self):
        # Access the current SVG layer
        layer = self.svg.get_current_layer()

        # Extract parsed options
        width = self.options.width
        height = self.options.height
        fill_color = self.options.color

        # Create a new rectangle element
        rect = Rectangle()
        rect.set("x", 0)
        rect.set("y", 0)
        rect.set("width", width)
        rect.set("height", height)
        
        # Apply styling
        rect.style = {
            "fill": str(fill_color),
            "stroke": "none"
        }

        # Append the rectangle to the active layer
        layer.append(rect)

if __name__ == "__main__":
    CustomRectangleExtension().run()

4. Working with Selected Elements

If your extension needs to modify existing elements instead of generating new ones, iterate through self.svg.selection:

def effect(self):
    if not self.svg.selection:
        inkex.errormsg("Please select at least one object.")
        return

    for element in self.svg.selection.values():
        # Example: apply a dashed stroke to selected elements
        element.style["stroke"] = "#000000"
        element.style["stroke-dasharray"] = "4,4"

5. Installing and Testing the Extension

  1. Locate the User Extensions Directory:
    • Open Inkscape.
    • Navigate to Edit > Preferences > System.
    • Copy the path listed under User extensions.
  2. Deploy Files:
    • Move both my_custom_extension.inx and my_custom_extension.py into that directory.
  3. Restart Inkscape:
    • Restart Inkscape to register the new XML file.
    • Access your extension via Extensions > Custom Tools > Add Custom Rectangle.
