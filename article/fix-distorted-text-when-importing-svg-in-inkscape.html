Fix Distorted Text When Importing SVG in Inkscape

Opening SVG files created in third-party software like Adobe Illustrator, Figma, CorelDRAW, or Canva in Inkscape often leads to distorted text, overlapping glyphs, misplaced characters, or incorrect fonts. This guide outlines the most effective solutions to resolve these SVG text rendering issues, covering source export adjustments, font reconciliation, flowed text corrections, and XML attribute cleanups.

1. Convert Text to Paths in the Source Software

If you do not need the text to remain editable in Inkscape, converting text into vector paths (outlines) before exporting guarantees that the typography renders identically across all vector editors:

  • Adobe Illustrator: Select the text and press Ctrl + Shift + O (Windows) or Cmd + Shift + O (macOS), or choose Type > Create Outlines.
  • Figma: Right-click the text layer and select Outline Stroke (Ctrl + Shift + O / Cmd + Shift + O).
  • CorelDRAW: Select the text and choose Object > Convert to Curves (Ctrl + Q).

After outlining, export the file as a standard SVG and open it in Inkscape.

2. Install and Match Missing Fonts

When text must remain editable, text distortion usually happens because Inkscape cannot locate the exact font family, weight, or style used in the source program:

  1. Identify the exact font used in the original document.
  2. Install the corresponding TrueType (.ttf) or OpenType (.otf) font file directly onto your operating system.
  3. Restart Inkscape completely to ensure the new font cache is loaded.
  4. Open the SVG, select the distorted text, open the Text and Font dialog (Ctrl + Shift + T), select the correct font family, and click Apply.

3. Convert Flowed Text to Regular Text

Older versions of Inkscape rely on a non-standard <flowRoot> specification, while newer versions use SVG 2.0 flowed text. When third-party editors generate multi-line text blocks with custom wrapping, Inkscape may bunch all words into a single point:

  1. Select the affected text block in Inkscape.
  2. Navigate to the top menu and select Text > Convert to Text.
  3. If the text disappears or wraps incorrectly, choose Text > Unflow or manually re-break lines using Enter.

4. Remove Hardcoded Transforms and Manual Kerning

Third-party exporters frequently assign absolute coordinate arrays (x, y, dx, dy) or matrix transformations to each individual character, causing severe overlap or spacing gaps in Inkscape.

  1. Select the distorted text object.
  2. Open the XML Editor by pressing Ctrl + Shift + X.
  3. Locate the active <text> or <tspan> element in the XML tree.
  4. In the right-hand attribute pane, look for dx, dy, rotate, or transform attributes.
  5. Select these attributes and click the Delete Attribute icon (the red 'X' icon at the top of the pane).
  6. Alternatively, select the text using the Text Tool (T), highlight all text with Ctrl + A, and press Alt + Right/Left Arrow to reset the letter spacing.

5. Export as Plain SVG or PDF as an Alternative

If the source program offers multiple export profiles:

  • Choose Plain SVG or SVG 1.1 instead of proprietary formats (like Illustrator SVG with preserved Illustrator editing capabilities).
  • Alternatively, export the document as a high-resolution PDF from the source program, then import the PDF into Inkscape using the Poppler/Cairo import engine with the option to import text as editable text or paths.
