Trigger Scour SVG Optimizer from Inkscape CLI

This guide explains how to trigger the Scour SVG optimization extension directly through the Inkscape command line interface (CLI). Modern versions of Inkscape allow you to invoke extensions headlessly using the command-line action framework, enabling automated SVG minification, metadata cleanup, and file size reduction within automated build scripts and workflows.

1. Identify the Scour Extension ID

Inkscape addresses all built-in extensions, verbs, and operations via unique action identifiers. The Scour extension, which provides the "Optimized SVG" save functionality, is registered under the ID org.inkscape.output.scour.

You can verify that your local Inkscape installation includes this action by querying the action list:

inkscape --action-list | grep -i scour

The output will confirm the presence of org.inkscape.output.scour.

2. Run the Optimization via the CLI

In Inkscape 1.0 and newer, commands are executed sequentially using the --actions argument. To process an existing SVG file through the Scour extension and save the result, execute the following command:

inkscape input.svg --actions="org.inkscape.output.scour;export-filename:optimized.svg;export-do"

In this command:

  • input.svg specifies the source vector file.
  • org.inkscape.output.scour runs the optimization routine across the active document.
  • export-filename:optimized.svg defines the output destination.
  • export-do writes the processed file to disk and exits.

3. Handling Scour Options and Preferences

When invoked through the --actions flag, the Scour extension does not accept dynamic command-line arguments (such as removing renderer-specific attributes or stripping XML prologues) directly inline. Instead, it reads configuration values saved from your last graphical session.

To adjust Scour parameters for automated CLI runs, define your required settings beforehand:

  1. Open Inkscape with a graphical interface.
  2. Navigate to File > Save As... and select Optimized SVG (*.svg).
  3. Configure your optimization options (e.g., coordinate precision, stripping metadata, ID cleanup) in the dialog box and complete a save.

Inkscape stores these choices in your preferences.xml file under the org.inkscape.output.scour node. Subsequent CLI executions will adopt these saved rules automatically.

4. Alternative: Run the Bundled Scour Script Directly

If you require precise, per-command flag controls (such as --enable-viewboxing or --precision=2) that override default application preferences, you can execute the bundled Scour Python script directly rather than wrapping it in the Inkscape binary.

Locate the bundled script within your Inkscape extensions folder:

  • Linux: /usr/share/inkscape/extensions/scour.py
  • macOS: /Applications/Inkscape.app/Contents/Resources/share/inkscape/extensions/scour.py
  • Windows: C:\Program Files\Inkscape\share\inkscape\extensions\scour.py

Run it directly using Python:

python3 /path/to/inkscape/extensions/scour.py -i input.svg -o optimized.svg --enable-viewboxing --strip-xml-prolog

This alternative provides explicit flag control over individual optimizations while still relying on the Scour version shipped with Inkscape.
