Export Vector Artwork to HPGL in Inkscape

Inkscape provides native support for converting and exporting vector graphics directly into the HPGL (Hewlett-Packard Graphics Language) format commonly used by plotters, vinyl cutters, and CNC machines. This guide details the essential preparation steps and the direct export process required to save clean, plotter-ready .hpgl or .plt files using Inkscape.

1. Prepare Vector Objects and Paths

Plotters interpret line data rather than standard fill colors. Before exporting, ensure your vector data consists of clean, single-line or stroked paths:

  1. Convert Text and Shapes to Paths: Select all elements in your document (Ctrl + A), then navigate to Path > Object to Path (Shift + Ctrl + C).
  2. Convert Fills to Strokes: If working with filled shapes, select the objects, open the Fill and Stroke panel (Ctrl + Shift + F), set Fill to None, and apply a solid line in Stroke paint.
  3. Convert Thick Outlines (Optional): If your cutter needs to trace both the inside and outside of a thick outline, go to Path > Stroke to Path (Ctrl + Alt + C).
  4. Ungroup Elements: Go to Object > Ungroup (Ctrl + Shift + G) repeatedly until all groupings are removed, ensuring the exporter can parse every individual path.

2. Export Directly to HPGL Format

Once the paths are prepared, export the artwork directly through the save dialogue:

  1. Click File > Save As... (or File > Save a Copy...).
  2. Set the destination folder and type the desired file name.
  3. Open the Save as type dropdown menu.
  4. Select HP Graphics Language file (*.hpgl) or HPGL Plotter file (*.plt) depending on your plotter software requirements.
  5. Click Save.

3. Configure HPGL Export Settings

After clicking Save, an HPGL configuration dialog will appear. Adjust the settings to match your machine specifications:

  • Pen Number / Pen Force / Pen Speed: Set the physical pen parameters according to the tool and material loaded in your machine.
  • Resolution (dpi): Specify the target coordinate resolution (standard values are 1016 dpi for standard HPGL devices).
  • Auto-align / Orientation: Choose whether the coordinate origin should align to the bottom-left or center, and adjust rotation if your media feed requires portrait or landscape orientation.
  • Overcut (mm): If cutting thick vinyl, apply an overcut value to ensure complete cuts at the start/end points of closed shapes.

Click OK to process and save the HPGL file to your computer.

Alternative: Direct Plotting via Extensions

If your plotter is connected directly to your computer via a serial or COM port, you can send the vector data straight to the machine:

  1. Navigate to Extensions > Export > Plot...
  2. In the Plotter tab, configure your connection port, baud rate, and flow control.
  3. In the Plot features tab, configure pen speed, pen force, and overcut.
  4. Click Apply to stream the vector data directly to the device.
