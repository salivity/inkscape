Customize Inkscape Toolbox to Show Preferred Tools

Customizing the toolbox in Inkscape allows you to streamline your workspace by hiding tools you rarely use and displaying only your preferred vector creation and editing tools. By adjusting these settings through the built-in preferences menu, you can reduce visual clutter, optimize screen real estate, and create a workflow tailored specifically to your design needs.

Accessing the Toolbars Preferences

  1. Open Inkscape on your computer.
  2. Open the Preferences window:
    • On Windows and Linux, go to Edit > Preferences (or press Ctrl + Shift + P).
    • On macOS, go to Inkscape > Preferences (or press Cmd + Shift + P).
  3. In the left-hand navigation pane of the Preferences window, expand the Interface category.
  4. Click on Toolbars.

Toggling Toolbox Tools

  1. In the Toolbars settings panel, locate the section labeled Toolbox.
  2. You will see a list of all available Inkscape tools categorized by function, such as:
    • Selection and Node editing tools
    • Shape tools (Rectangle, Ellipse, Star, Spiral)
    • Drawing tools (Pencil, Pen/Bézier, Calligraphy)
    • Modification tools (Tweak, Spray, Eraser)
    • Utility tools (Text, Gradient, Dropper, Measure)
  3. Uncheck the box next to any tool you want to remove from the side toolbox.
  4. Check the box next to any tool you want visible.

Applying and Resetting the Layout

  • Changes take effect immediately in the main Inkscape window without requiring a program restart.
  • To adjust the size of the icons in the toolbox, adjust the Toolbox icon size slider located at the top of the Interface settings page.
  • If you ever need to restore hidden tools, return to Interface > Toolbars and re-check the desired items, or check all boxes to restore the default full toolbox layout.
