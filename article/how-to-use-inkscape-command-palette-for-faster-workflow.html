How to Use Inkscape Command Palette for Faster Workflow

The Inkscape Command Palette allows you to quickly search for and execute almost any tool, filter, setting, or action directly from your keyboard. This guide explains how to open the palette, search for commands efficiently, and use it to eliminate tedious menu navigation and dramatically speed up your vector design process.

Opening the Command Palette

To open the Command Palette in Inkscape (version 1.2 and newer), press the question mark key (?) on your keyboard when you do not have an active text editing box.

Alternatively, you can open it via the main menu by navigating to Edit > Command Palette. A search bar overlay will appear in the center of your screen.

Searching and Executing Actions

Once the Command Palette is open, start typing the name of the tool, action, or filter you want to use. Inkscape uses dynamic search filtering to display relevant results in real time.

  1. Type a Keyword: Enter what you want to do (e.g., "Union", "Trace Bitmap", "Export", or "Align").
  2. Navigate Results: Use the Up and Down Arrow keys to cycle through the matching commands.
  3. Execute the Action: Press Enter to apply the selected command immediately to your active canvas or selection.
  4. Exit the Palette: Press Escape at any time to close the Command Palette without executing a command.

Key Benefits for Your Workflow

  • Bypassing Nested Menus: Instead of clicking through multiple drop-down menus to find specialized extensions or path operations (such as Path > Path Effects or Filters > Bevels), you can find and apply them in seconds.
  • Discovering Built-in Shortcuts: Next to each search result, the Command Palette displays the dedicated keyboard shortcut if one exists. This helps you learn native shortcuts over time.
  • Accessing Settings and Preferences: You can search for configuration options and canvas settings directly without manually opening the Preferences dialog.
  • Consistent Access Across Tools: Whether managing layers, adjusting document properties, or transforming objects, the palette serves as a single, centralized control hub.
