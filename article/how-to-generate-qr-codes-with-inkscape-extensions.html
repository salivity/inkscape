How to Generate QR Codes with Inkscape Extensions

Inkscape provides a built-in extension that allows users to quickly generate clean, scalable, vector-based QR codes pointing to custom URLs. This guide walks through the complete process of locating the barcode generation tool, entering your custom link, configuring error correction parameters, and customizing the final vector graphic for print or digital media.

Step 1: Open the QR Code Extension

  1. Launch Inkscape and open a new or existing document.
  2. Navigate to the top menu bar and click Extensions.
  3. Hover over Render, then select Barcode.
  4. Click on QR Code... to open the generation dialog window.

Step 2: Input Your Custom URL and Configure Settings

Inside the QR Code dialog, you can define the data and the structural properties of your code:

  • Text: Paste or type your full custom URL into this field (for example, https://www.example.com). Ensure the protocol (http:// or https://) is included so scanning devices recognize it immediately as a web link.
  • Error Correction Level: Choose between four standard levels:
    • L (Low - 7%): Best for clean, uncluttered codes where data loss is unlikely.
    • M (Medium - 15%): The default balance between size and reliability.
    • Q (Quartile - 25%): Useful if you intend to overlay small logos or design elements.
    • H (High - 30%): Maximum redundancy, best for rugged environments or heavily modified designs.
  • Character Encoding: Keep this set to Default (UTF-8) or Latin-1 for standard URLs.
  • Module Size (px): Sets the base pixel size for each square unit (module) of the QR code.

Step 3: Preview and Generate

  1. Check the Live preview box in the bottom-left corner of the dialog to see how the generated QR code looks on your canvas in real time.
  2. If you are satisfied with the appearance and sizing, click Apply.
  3. Click Close to exit the dialog.

Step 4: Customize the Vector Graphic

Because Inkscape generates QR codes as pure vector objects (paths grouped together), you can edit them directly:

  • Resizing: Select the QR code with the Selection Tool (S), hold Ctrl to maintain proportions, and drag any corner handle to scale the code without losing sharpness.
  • Changing Colors: Select the QR code and pick a new color from the palette at the bottom. Ensure there is high contrast between the modules and the background color so mobile cameras can read it reliably.
  • Adding a Logo: If you used Q or H error correction, you can place a small vector logo in the center of the QR code without rendering the link unreadable.

Step 5: Test the Code

Always scan the newly generated QR code directly from your Inkscape canvas or after exporting it using a smartphone camera to verify that the custom URL opens properly before sending the design to production.
