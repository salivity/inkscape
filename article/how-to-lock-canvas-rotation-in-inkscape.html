How to Lock Canvas Rotation in Inkscape

Accidental canvas rotation in Inkscape can interrupt your workflow and distort your drawing perspective. This guide provides a straightforward method to permanently disable the canvas rotation feature through Inkscape's preferences, preventing accidental trackpad gestures and mouse triggers. It also covers how to quickly reset a tilted canvas back to its default horizontal orientation.

How to Disable Canvas Rotation

To prevent the canvas from tilting accidentally via mouse wheel scrolls or touchpad gestures, turn off the rotation feature entirely:

  1. Open the Preferences menu by navigating to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  2. In the left-hand navigation panel, click on Interface.
  3. Locate the option labeled Enable canvas rotation in the right pane.
  4. Uncheck the box next to Enable canvas rotation.
  5. Close the Preferences window.

Once this setting is disabled, gesture-based rotation and the standard rotation keyboard shortcuts will no longer tilt the workspace.

How to Reset an Accidental Canvas Tilt

If your canvas is already rotated and you need to restore the standard view, you can reset it instantly using any of the following methods:

  • Use the Menu: Go to View > Canvas Orientation > Reset Rotation.
  • Use the Status Bar: Look at the bottom-right corner of the Inkscape window to find the rotation field (marked with an angle icon R:). Double-click the number, type 0, and press Enter. Alternatively, right-click the rotation indicator and select Reset Rotation.
  • Use the Keyboard Shortcut: Press Ctrl + [Keypad 5] to reset the view.

Why Accidental Rotation Happens

Inkscape maps canvas rotation to the combination of Ctrl + Shift while using the mouse scroll wheel. On laptops with multi-touch trackpads, two-finger twisting gestures can also trigger rotation unintentionally while panning or zooming. Disabling canvas rotation in the preferences eliminates both triggers without affecting regular zooming or panning.
