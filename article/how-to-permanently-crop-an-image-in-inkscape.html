How to Permanently Crop an Image in Inkscape

In Inkscape, standard clipping methods are non-destructive, meaning the hidden parts of an image are retained within the project file. To crop a raster image permanently and discard the unwanted pixel data, you need to define a subregion and export it as a standalone image file. This guide walks you through the exact steps to define a boundary, export the selected subregion, and replace the original graphic with the permanently cropped version.

Step 1: Import the Raster Image

  1. Open Inkscape and navigate to File > Import (or press Ctrl + I).
  2. Select your raster image (such as a PNG or JPEG) and choose your preferred import settings (either "Embed" or "Link").
  3. Place the image on your canvas.

Step 2: Define the Subregion to Crop

  1. Select the Create rectangles and squares tool (R) from the left toolbar.
  2. Draw a rectangle directly over the area of the raster image that you want to keep.
  3. If necessary, adjust the opacity of the rectangle in the Fill and Stroke panel (Shift + Ctrl + F) so you can precisely see the underlying image details.
  4. Resize and position the rectangle to frame the exact subregion you want to preserve.

Step 3: Export the Subregion

  1. Open the Export dialog by going to File > Export (or press Shift + Ctrl + E).
  2. With the rectangle shape selected, look at the top of the Export panel and click the Selection tab. This instructs Inkscape to only export the area bounded by your rectangle.
  3. In the export settings below:
    • Choose your desired output format (e.g., PNG, JPEG, or TIFF).
    • Set the resolution (DPI) to match your project needs (typically 96 DPI for web or 300 DPI for print).
  4. Specify the output path and filename in the file field at the bottom.
  5. Click Export to save the permanently cropped image to your computer.

Step 4: Replace the Original Image

  1. Delete the original raster image and the helper rectangle from your canvas.
  2. Go to File > Import and select your newly exported file.
  3. The new image contains only the pixels within the cropped subregion, permanently reducing file overhead and removing the hidden data.
