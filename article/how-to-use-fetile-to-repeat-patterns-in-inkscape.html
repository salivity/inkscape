How to Use feTile to Repeat Patterns in Inkscape

This guide explains how to use the SVG feTile filter primitive within Inkscape to duplicate a filtered graphic seamlessly across a canvas or object. By leveraging the Filter Editor, setting filter primitive subregions, and piping the processed graphic into feTile, you can generate infinite textures, grids, and decorative backgrounds directly inside your vector workspace.

Understanding the feTile Primitive

The feTile primitive takes an input image or graphic—typically processed by preceding filter primitives—and repeats it along both the X and Y axes to fill a target area. For feTile to duplicate a pattern rather than stretching or displaying a single instance, the preceding primitive must have a defined Filter Primitive Subregion (coordinates for X, Y, Width, and Height). This subregion dictates the exact size of one repeating tile unit.

Step 1: Open the Filter Editor

  1. Open Inkscape and navigate to the top menu.
  2. Select Filters > Filter Editor.
  3. In the Filter Editor panel, click the New button at the bottom left to create an empty filter.
  4. Rename your filter (e.g., "Pattern Tile") for easy identification.

Step 2: Build the Tile Unit

Before applying feTile, you need to generate or reference the graphic that will serve as the repeatable unit:

  1. In the Add Primitive drop-down menu inside the Filter Editor, select an initial primitive (such as Turbulence, Flood, or Image).
  2. Click Add Primitive.
  3. With this primitive selected, switch to the Filter General Settings or the primitive parameters tab to specify the subregion:
    • Enable the subregion bounds.
    • Set a fixed Width and Height (for example, 50px by 50px).
    • Set X and Y offsets (typically 0px).
  4. This boundary sets the exact dimensions for each repeated cell in the pattern.

Step 3: Add and Connect feTile

  1. Go back to the Add Primitive drop-down menu and choose Tile.
  2. Click Add Primitive. The feTile node will appear in your filter list.
  3. In the visual node connection area:
    • Locate the input connector of the Tile primitive.
    • Drag the connection line to the output of your previous primitive (the one with the defined subregion).
  4. feTile will automatically read the subregion coordinates from that source and fill the entire bounding box of the target shape with repeated copies of it.

Step 4: Apply the Filter to an Object

  1. Select the Rectangle tool (R) from the toolbar and draw an element over the area of the canvas you want covered.
  2. While this new object is selected, go to the Filter Editor panel.
  3. Check the box next to your custom tile filter.
  4. The object will instantly render the repeating pattern across its entire surface.

Fine-Tuning with the XML Editor

Inkscape's graphical interface for filter primitive subregions can sometimes require manual adjustment for pixel-perfect alignment. To set precise attributes:

  1. Press Ctrl + Shift + X to open the XML Editor.
  2. Locate your <filter> element under <svg:defs>.
  3. Select the child primitive feeding into <feTile>.
  4. Add or modify the x, y, width, and height attributes directly (e.g., width="40", height="40").
  5. Ensure the <feTile> element has in pointing to the result of that sized primitive.
