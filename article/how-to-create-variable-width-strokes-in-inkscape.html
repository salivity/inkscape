How to Create Variable Width Strokes in Inkscape

The Calligraphy tool in Inkscape enables designers to create expressive, hand-drawn vector paths with dynamic thickness. By adjusting parameters such as pressure sensitivity, thinning, and pen angle, you can achieve variable-width strokes that mimic traditional ink pens, brushes, and markers. This guide explains how to configure the Calligraphy tool settings, control stroke dynamics with both a graphics tablet and a mouse, and edit the resulting paths.

1. Activate the Calligraphy Tool

Select the Draw calligraphic or brush strokes tool from the left toolbar, or press C (or Ctrl + F6) on your keyboard.

2. Choose a Preset Profile

On the top Tool Controls bar, open the Preset dropdown menu to select a starting style:

  • Dip pen: Mimics a traditional nib, varying width based on stroke direction and angle.
  • Brush: Produces soft, sweeping strokes that respond well to pressure.
  • Classic: Provides a standard calligraphic line with balanced tapering.

3. Configure Key Settings for Variable Width

Fine-tune the following options in the Tool Controls bar to control how stroke thickness changes:

  • Width: Sets the base thickness of your stroke. You can adjust this with the numerical input or by pressing the Left/Right arrow keys while drawing.
  • Pressure Sensitivity (Tablet icon): Enable this toggle if using a graphics tablet. Higher pen pressure creates wider strokes, while lighter pressure creates thin lines.
  • Thinning: Controls stroke variation based on drawing speed.
    • A positive value (e.g., 30 to 50) makes faster strokes thinner and slower strokes wider.
    • A negative value produces the opposite effect.
    • A value of 0 disables speed-based width variation.
  • Angle: Defines the angle of the pen nib (ranging from -90° to 90°). A fixed angle (such as 30° or 45°) naturally produces thick downstrokes and thin cross-strokes.
  • Fixation: Determines how strictly the nib angle stays locked. A value of 100% keeps the nib orientation completely fixed relative to the canvas, while 0% forces the nib to rotate perpendicular to the stroke direction.
  • Mass: Adds virtual weight to smooth out jitter and stabilize fast movements.

4. Drawing Variable Strokes

Using a Graphics Tablet

  1. Enable the Pressure button next to the Width setting.
  2. Set Thinning to 0 to isolate variation strictly to hand pressure.
  3. Draw strokes across the canvas, altering your downward pressure to taper the lines.

Using a Mouse

  1. Set Thinning to a value between 40 and 60.
  2. Disable the tablet pressure toggle.
  3. Vary the speed of your cursor: move slowly for thick sections and flick quickly for tapered ends.

5. Refining Calligraphic Paths

Strokes created with the Calligraphy tool are generated as closed, filled vector paths rather than standard stroked lines.

To modify a stroke after drawing:

  1. Select the Node tool (N).
  2. Click on the stroke to expose the vector nodes along both outer edges.
  3. Drag individual nodes or curve handles to manually reshape and refine the stroke's width at specific points.
