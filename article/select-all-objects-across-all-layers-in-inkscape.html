Select All Objects Across All Layers in Inkscape

Managing multi-layer projects in Inkscape often requires bulk editing, but the standard selection command only affects the currently active layer. To manipulate your entire design at once, Inkscape provides a dedicated command that targets every unlocked and visible object across the entire canvas simultaneously. This article explains how to use this global selection method using both keyboard shortcuts and the application menu.

The "Select All in All Layers" Command

The most direct method to select every unlocked object across all visible layers is the Select All in All Layers function.

  • Windows / Linux Shortcut: Press Ctrl + Alt + A
  • macOS Shortcut: Press Cmd + Opt + A
  • Menu Navigation: Go to the top menu bar, click Edit, and select Select All in All Layers.

How It Works

  1. Activation: Ensure you are in the workspace with your document open. You do not need to have the Selector tool active beforehand; triggering the shortcut will automatically engage the selection bounding box around the targeted elements.
  2. Layer States: The command respects your layer restrictions:
    • Locked Layers/Objects: Any object or layer marked with the lock icon will remain unselected and unaffected.
    • Hidden Layers/Objects: Any object or layer with visibility toggled off (closed eye icon) will be ignored.
  3. Difference from Standard "Select All": Pressing standard Ctrl + A (or Cmd + A) only selects objects within the currently active layer. Adding the Alt (or Opt) modifier expands the scope to include every visible, unlocked layer in the document.
