How to Create Satin Stitches in Ink/Stitch

Creating satin stitch columns in Ink/Stitch, the open-source embroidery extension for Inkscape, transforms vector artwork into dense, professional embroidery lines, lettering, and borders. This guide explains how to properly construct dual-rail vector paths, add directional rungs, configure stitch parameters, and generate clean satin columns ready for machine embroidery.

Understanding Ink/Stitch Satin Columns

In Ink/Stitch, a satin column is not a standard filled shape. Instead, it is a single vector object composed of two parallel or semi-parallel sub-paths called rails. The software generates zig-zag stitches that bounce back and forth between these rails. Connecting lines, called rungs, can be added between the rails to control the angle, direction, and density of the stitches.

Method 1: Automatic Conversion (Stroke to Satin)

The fastest way to generate a satin column from a single line is by using the automated conversion tool.

  1. Draw the Path: Use the Pen (Bezier) or Pencil tool to draw a single line path.
  2. Set Width: Open the Fill and Stroke panel (Ctrl+Shift+F), remove any fill, and set the stroke width to your desired satin column width.
  3. Convert: Select the path, then navigate to Extensions > Ink/Stitch > Tools: Satin > Stroke to Satin.
  4. Ink/Stitch will automatically generate two outer rails and cross-rungs matching your stroke thickness.

Method 2: Manual Satin Column Construction

For custom shapes with varying widths or specific stitch directions, build the rails manually:

  1. Draw Two Rails: Use the Pen tool to draw two separate lines defining the left and right (or top and bottom) edges of your satin column. Both paths should have equal or similar node counts and follow the same direction.
  2. Draw Rungs (Optional but Recommended): Draw cross-lines that connect the two rails. Each rung must touch or cross both rails to guide the stitch angle.
  3. Combine the Paths:
    • Select both rails and all rungs simultaneously.
    • Go to the top menu and select Path > Combine (or press Ctrl+K). This turns the individual lines into a single compound path.

Configuring Satin Parameters

Once your satin column path is created, configure the stitch generation settings:

  1. Select your combined satin path.
  2. Navigate to Extensions > Ink/Stitch > Params.
  3. The preview window will render the satin column. If it displays correctly, the path geometry is valid.
  4. Adjust key settings:
    • Zig-Zag Spacing (Density): The distance between each stitch (standard values range from 0.35 mm to 0.45 mm).
    • Pull Compensation: Adds extra width to counteract fabric tension pull.
    • Underlay: Enable contour, center-walk, or zig-zag underlay to stabilize the fabric before the top satin layer is stitched.
  5. Click Apply and Quit to save the settings to the object.

Troubleshooting Common Issues

  • Crossed Stitches (Hourglassing): If stitches cross over each other in an X-shape, the two rails are running in opposite directions. Select one rail with the Node tool (N) and click Path > Reverse.
  • Error "Two rails not found": Ensure you combined the paths using Path > Combine (Ctrl+K), not grouped them (Ctrl+G).
  • Uneven Flow: Add more rungs along curved sections to explicitly direct the stitch angles around tight turns.
