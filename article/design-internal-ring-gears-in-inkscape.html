Design Internal Ring Gears in Inkscape

Constructing an internal ring gear for a planetary gearbox requires designing an inverted tooth profile where the gear teeth face inward rather than outward. This guide covers the mathematical constraints required for a planetary gear system, how to generate a standard spur gear using Inkscape's native rendering tools, and the boolean operations needed to turn that external gear into an internal ring gear ready for fabrication.

1. Calculate Planetary Gear Parameters

Before generating paths in Inkscape, ensure your planetary gear parameters are geometrically compatible. All gears in the system (sun, planets, and ring) must share the same module (or diametral pitch) and pressure angle.

Use the standard planetary relationship to calculate the ring gear's tooth count:

  • Tooth Count Formula: \(N_{ring} = N_{sun} + (2 \times N_{planet})\)
  • Pitch Diameter: \(D = N \times m\) (where \(N\) is the number of teeth and \(m\) is the module)

2. Generate the Spur Gear Profile

Inkscape includes a built-in tool to generate involute gear geometry based on tooth count and pitch:

  1. Open Inkscape and navigate to Extensions > Render > Gear > Gear...
  2. In the dialog box:
    • Set Number of teeth to your calculated \(N_{ring}\).
    • Set Circular pitch (px) to match the pitch used for your sun and planet gears.
    • Set the Pressure angle (typically 20°).
  3. Click Apply and close the window.

This produces a standard external spur gear path whose outer perimeter contains the required tooth geometry.

3. Create the Outer Ring Body

An internal ring gear requires an outer mounting body to hold the inward-facing teeth:

  1. Select the Circles and Ellipses tool (F5).
  2. Hold Ctrl + Shift to draw a perfect circle centered over your generated gear.
  3. Set the diameter of this circle sufficiently larger than the root diameter of the generated gear to provide mechanical strength for the gear wall or mounting points.
  4. Align the circle and gear by opening the Align and Distribute panel (Shift + Ctrl + A), selecting both objects, and clicking Center on horizontal axis and Center on vertical axis.

4. Perform the Boolean Subtraction

To invert the tooth profile so that it faces inward:

  1. Select the generated spur gear and convert it into a path if it is grouped (Object > Ungroup, or Shift + Ctrl + G).
  2. Ensure both the gear and the outer circle are paths via Path > Object to Path (Shift + Ctrl + C).
  3. Select the outer circle, then shift-click the gear profile.
  4. Go to Path > Difference (Ctrl + -).

Inkscape will subtract the external gear profile from the outer circular blank, leaving an annular ring with inward-pointing teeth that match your system's pitch.

5. Apply Backlash and Tolerances

Mechanical manufacturing (such as 3D printing or laser cutting) requires clearance between meshing teeth:

  1. Select the newly created internal ring gear.
  2. Go to Path > Outset (Ctrl + )) to enlarge the internal cavity slightly, or open Path > Path Effects..., add an Offset effect, and specify a precise clearance offset (typically 0.15 mm to 0.3 mm depending on manufacturing tolerances).
  3. If using the Path Effect, finalize the geometry with Path > Object to Path.

6. Export for Production

Verify dimensions using the measurement tool (M). Once verified, save the file as an SVG or export to DXF via File > Save As > AutoCAD DXF R14 for CNC milling, laser cutting, or import into CAD software.
