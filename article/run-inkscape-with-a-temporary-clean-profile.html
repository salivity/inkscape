Run Inkscape with a Temporary Clean Profile

Running Inkscape with a temporary clean profile allows you to test default behaviors, troubleshoot bugs, or experiment with new extensions without deleting or modifying your customized settings. By pointing Inkscape to a temporary directory using the dedicated environment variable, you can launch a completely isolated instance that leaves your existing preferences intact once closed.

Understanding the Profile Environment Variable

Inkscape checks the INKSCAPE_PROFILE_DIR environment variable upon launch. If this variable is defined, Inkscape uses the specified folder to read and write all configuration files, keyboard shortcuts, palettes, and extensions instead of using the default user configuration directory.

Linux and macOS

On Unix-based systems, you can generate a temporary directory and pass it to Inkscape in a single terminal command.

  1. Open your terminal.
  2. Run the following command:
INKSCAPE_PROFILE_DIR=$(mktemp -d) inkscape

This command creates a unique, temporary directory via mktemp -d, sets INKSCAPE_PROFILE_DIR exclusively for that single process, and launches Inkscape. Your permanent configuration in ~/.config/inkscape (Linux) or ~/Library/Application Support/org.inkscape.Inkscape (macOS) remains untouched.

Windows

On Windows, you can define a temporary path using either PowerShell or the standard Command Prompt.

Using PowerShell

  1. Open PowerShell.
  2. Run the following commands:
$env:INKSCAPE_PROFILE_DIR = "$env:TEMP\InkscapeCleanProfile"
& "inkscape"

Note: If the Inkscape executable is not in your system's PATH, provide the full path to inkscape.exe (e.g., & "C:\Program Files\Inkscape\bin\inkscape.exe").

Using Command Prompt

  1. Open Command Prompt.
  2. Set the variable and start Inkscape:
set INKSCAPE_PROFILE_DIR=%TEMP%\InkscapeCleanProfile
start "" "C:\Program Files\Inkscape\bin\inkscape.exe"

The specified folder in your system's temporary directory will hold the clean profile. You can delete the InkscapeCleanProfile folder inside your %TEMP% directory at any time after closing the application.

Verifying the Clean Profile

To confirm that Inkscape is utilizing the temporary directory rather than your standard profile:

  1. In Inkscape, navigate to Edit > Preferences (or press Ctrl + Shift + P).
  2. Select the System tab in the left-hand menu.
  3. Check the path listed under User preferences. It should display the temporary directory path defined by your command instead of your standard user profile location.
