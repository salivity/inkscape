How to Create Bean Stitch Paths in Inkscape

This guide demonstrates how to create heavy-duty, triple-pass bean stitch paths in Inkscape using the open-source Ink/Stitch embroidery extension. You will learn how to draft your base vector paths, configure the stroke parameters to enable triple-pass thread reinforcement, adjust stitch lengths to prevent thread bunching, and simulate the result before sending it to an embroidery machine.

Prerequisites

To generate machine embroidery paths in Inkscape, ensure you have the Ink/Stitch extension installed. Bean stitches require simple vector strokes without fills.

Step 1: Draw the Base Path

  1. Select the Draw Bezier curves and straight lines tool (B) or the Freehand Lines tool (P).
  2. Draw the line or outline you want to embroider.
  3. Open the Fill and Stroke panel (Ctrl + Shift + F or Cmd + Shift + F).
  4. In the Fill tab, click the X (No paint) to remove any fill.
  5. In the Stroke paint tab, select Flat color and choose a solid color.
  6. In the Stroke style tab, ensure the line is solid, not dashed. The stroke width in Inkscape does not affect the bean stitch thickness, as thickness is determined by thread weight and the number of passes.

Step 2: Open Ink/Stitch Parameters

  1. Select your path with the Select and Transform objects tool (S).
  2. Navigate to the top menu and select Extensions > Ink/Stitch > Params.
  3. A modal preview window will open, displaying the default running stitch configuration for your line.

Step 3: Configure Triple-Pass Reinforcement

  1. In the parameters window, locate the Running stitch settings.
  2. Find the setting labeled Bean stitch number of repeats.
  3. Set the value to 1.
    • A value of 0 creates a standard single-pass running stitch.
    • A value of 1 creates a standard bean stitch with 3 passes (forward, backward, forward).
    • A value of 2 creates a 5-pass stitch if extra reinforcement is needed.
  4. Adjust the Running stitch length (mm). For a triple-pass bean stitch, set the stitch length between 2.5 mm and 3.5 mm. Shorter stitch lengths can cause excessive needle penetrations in the same location, potentially cutting the fabric or jamming thread.
  5. Click Apply and Quit to save the settings to the selected object.

Step 4: Verify and Simulate

  1. With the path selected, go to Extensions > Ink/Stitch > Visualize > Simulator/Realistic Preview.
  2. Press the Play button to watch the stitch generation.
  3. Verify that the needle steps forward, takes a step backward, and steps forward again along the entire path.
  4. Close the preview window when satisfied.

Step 5: Export to Embroidery Format

  1. Go to File > Save As...
  2. Select your machine's native file format from the drop-down menu (e.g., .PES, .DST, .JEF).
  3. Save the file directly to your machine's USB drive or transfer folder.
