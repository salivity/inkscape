How to Export Vector Lines from Inkscape to Krita

Combining Inkscape’s precision vector tools with Krita’s rich raster brushes gives artists the best of both worlds: crisp line work and dynamic, textured painting. This guide walks you through preparing, exporting, and importing your vector line art from Inkscape into Krita, while preserving line fidelity and setting up an optimized layer hierarchy for painting and raster texturing.

Step 1: Prepare Your Line Work in Inkscape

Before exporting, ensure your vector linework is clean and scaled appropriately.

  1. Finalize Strokes: Ensure all strokes are set to their final desired thicknesses. If you use variable-width paths, make sure path effects are correctly applied.
  2. Set Page Borders: Go to File > Document Properties (Ctrl+Shift+D) and set the page dimensions to the final canvas size you plan to paint on in Krita (e.g., A4, 4K, or custom pixel dimensions).
  3. Align Artwork: Center your artwork within the page boundaries to avoid edge clipping during export.

Step 2: Export from Inkscape as a High-Resolution PNG

While Krita can import SVG files, exporting a high-resolution raster image (PNG with transparency) guarantees that all custom stroke profiles, path effects, and miters render exactly as designed.

  1. Open the export dock via File > Export (Ctrl+Shift+E).
  2. Set the export area to Page so the canvas bounds match your intended layout.
  3. In the export settings, set the Resolution to at least 300 DPI (or higher for large prints) to eliminate visible pixelation when zooming in to paint.
  4. Ensure the output format is set to PNG to preserve transparent backgrounds.
  5. Click Export and choose a designated file path.

(Alternative Method: You can save directly as an Inkscape SVG or Plain SVG if you want to import it as an editable Vector Layer inside Krita via Layer > Import/Export > Import Layer.)

Step 3: Import and Set Up Layers in Krita

Once exported, bring your linework into Krita to prepare it for painting.

  1. Open Krita and open your exported PNG using File > Open, or drag and drop the file directly onto the Krita canvas as a new layer.
  2. If working within an existing project, go to Layer > Import/Export > Add Layer and select your PNG file.
  3. Rename this layer to Line Art.

Step 4: Configure the Canvas for Painting and Texturing

To paint smoothly without damaging your original vector outlines:

  1. Lock the Line Art Layer: Click the lock icon next to the Line Art layer in the Layers Docker. This prevents accidental brush strokes on your clean linework.
  2. Set Blending Mode: If your exported line art has a solid white background instead of transparency, change the layer blending mode from Normal to Multiply. If it is already a transparent PNG, leave it set to Normal.
  3. Alpha Lock for Inking/Recoloring: If you want to color the lines themselves, enable Alpha Lock (the checkerboard icon) on the Line Art layer to paint directly over the lines without spilling onto the canvas.
  4. Create Painting Layers Below: Add new paint layers underneath the Line Art layer for your flats, base colors, shadows, and raster textures.
  5. Use Referencing Tools: When using the Fill Tool or Colorize Mask Tool, ensure the source is set to All Layers or Reference Layer so your color flats automatically conform to the vector contours.
