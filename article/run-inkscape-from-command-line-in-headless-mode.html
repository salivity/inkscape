Run Inkscape from Command Line in Headless Mode

Running Inkscape in headless mode allows you to automate vector graphic tasks such as format conversions, batch exports, and path manipulations without opening the graphical user interface. Modern versions of Inkscape automatically operate headlessly when provided with export arguments, making it an efficient tool for server environments, automated build pipelines, and shell scripts.

Basic Exporting in Modern Inkscape (Version 1.0+)

In Inkscape 1.0 and later, running commands without specifying an interactive GUI mode automatically runs in a headless state. Use the -o (or --export-filename) flag to define the output file. Inkscape determines the output format automatically based on the file extension.

Export an SVG to a PNG:

inkscape input.svg -o output.png

Export an SVG to a PDF:

inkscape input.svg -o output.pdf

Controlling Dimensions and Resolution

You can explicitly set the output dimensions or pixel density using width (-w), height (-h), or DPI (--export-dpi) parameters:

Set explicit width and height (in pixels):

inkscape input.svg -o output.png -w 1920 -h 1080

Export with a specific resolution:

inkscape input.svg -o output.png --export-dpi=300

Export only a specific object by its element ID:

inkscape input.svg -o output.png --export-id=rect123 --export-id-only

Headless Actions and Batch Processing

To perform document modifications or chained commands without the GUI, use the --actions argument combined with --batch-process. The --batch-process flag ensures that the application closes automatically once the specified actions finish executing.

Chain actions together with semicolons:

inkscape --batch-process --actions="select-all;object-to-path;export-filename:output.svg;export-do" input.svg

To list all available action commands supported by your installed version:

inkscape --action-list

Legacy Syntax (Inkscape 0.92 and Older)

If you are using Inkscape version 0.92 or earlier, you must explicitly use the -z (or --without-gui) flag to prevent the interface from launching.

Export to PNG in legacy versions:

inkscape -z input.svg -e output.png

Export to PDF in legacy versions:

inkscape -z input.svg -A output.pdf
