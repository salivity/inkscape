Draw Vector Planet Craters in Inkscape

This guide explains how to construct stylized vector planetary terrain and realistic craters using Inkscape’s Boolean difference operations. You will learn how to create the base planetary body, construct dynamic crater rims using overlapping geometric paths, apply compound differences to generate light and shadow crescents, and nest the finished craters seamlessly across your vector terrain.

Setting Up the Base Terrain

Begin by establishing the main surface of the planet:

  1. Select the Circles and Ellipses tool (E) and hold Ctrl while dragging to draw a perfect circle.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F) and assign a mid-tone surface color, such as dusty red, slate gray, or pale beige.
  3. Duplicate this circle (Ctrl + D) and set it aside to use later as a clipping mask for the finished terrain.

Constructing the Crater Geometry

A realistic crater consists of a raised rim with a highlighted side, a shadow side, and an interior cavity floor. These depth-defining crescents are built cleanly using the Difference path operation.

  1. Draw the Outer Boundary: Use the Circles and Ellipses tool to draw an ellipse matching the perspective of your planet's surface. Tilt the ellipse slightly using the Select and Transform tool (S) to match the terrain angle.
  2. Create the Inner Cavity: Duplicate the ellipse (Ctrl + D), make it slightly smaller by holding Shift + Ctrl while scaling downward, and shift it slightly down and inward along the direction of your intended light source.
  3. Generate the Crescent Rim:
    • Duplicate both the outer and inner ellipses.
    • Select the top inner ellipse and shift it slightly toward the light source.
    • Select both duplicates and go to Path > Difference (Ctrl + -). This leaves behind a thin crescent shape representing the highlighted rim.
    • Set the fill color to a lighter tint of the base terrain.

Creating Interior Shadows with Compound Differences

To generate the deep shadow cast along the inside wall of the crater:

  1. Duplicate the original inner cavity ellipse twice.
  2. Move the topmost copy toward the light source so it partially overlaps the underlying ellipse, exposing a crescent on the side opposite the light.
  3. Select both copies and choose Path > Difference (Ctrl + -).
  4. Set the resulting shape to a dark, desaturated tone of the surface color to represent ambient occlusion and cast shadow.
  5. Lower this shadow crescent behind the rim highlight by pressing Page Down or using the Object > Lower command.

Building Compound Clusters

To scatter multiple craters across the surface without messy overlapping paths, combine your shapes:

  1. Select all components of your completed crater (rim highlight, interior shadow, and floor).
  2. Duplicate the group (Ctrl + D), scale it down, and distribute several variations across the terrain.
  3. For overlapping impact zones, select the shadow paths of overlapping craters and navigate to Path > Union (Ctrl + +) or Path > Combine (Ctrl + K) to merge them into a unified compound shadow layer.
  4. If a newer crater cuts into an older crater rim, duplicate the new crater's outer perimeter, select the older rim, and run Path > Difference to carve the new impact directly into the old geometry.

Clipping to the Planetary Edge

  1. Select the original planetary duplicate circle created in the first step.
  2. Bring it to the very top of the layer stack by pressing Home.
  3. Select the planet base, all crater shapes, and the top circle.
  4. Go to Object > Clip > Set.

Any crater elements extending beyond the horizon will be cleanly masked, leaving a clean, vector planetary surface with accurate crater depth.
