Inkscape Calligraphy: Adjust Tracking, Angle, Thinning

This guide explains how to configure the Calligraphy tool in Inkscape to achieve precise stroke dynamics and styles. By accessing the Tool Controls Bar, you can modify the Angle, Tracking (Fixation), and Thinning parameters to simulate different physical nibs, dynamic line variations, and drawing behaviors.

Accessing the Calligraphy Tool Controls

  1. Select the Calligraphy tool from the left-hand Toolbox or press the shortcut key C (or F6).
  2. Look at the Tool Controls Bar located horizontally across the top of the canvas. This bar displays all active numerical fields and toggles for Calligraphy presets, width, angle, fixation, and stroke dynamics.

Adjusting the Angle

The Angle parameter defines the orientation or tilt of your virtual pen nib relative to the horizontal canvas axis.

  • Where to find it: Locate the Angle input field in the Tool Controls Bar.
  • How to set it: Enter a value between -90° and 90°, or use the up/down arrows.
  • Shortcut: Use the Left Arrow and Right Arrow keys while drawing to dynamically adjust the angle.
  • Visual Effect: A fixed angle (such as 30° or 45°) simulates a traditional broad-edge calligraphy nib, producing wide lines along one directional axis and thin lines perpendicular to it.

Adjusting Tracking (Fixation)

In Inkscape, the tracking behavior of the nib's angle is controlled by the Fixation setting. It determines whether the nib maintains a fixed orientation relative to the page or rotates to track the direction of your stroke.

  • Where to find it: Locate the Fixation input field (often labeled as an angle/direction icon) in the Tool Controls Bar.
  • Values and Behavior:
    • 100% (Maximum Fixation): The nib strictly maintains the set Angle regardless of which direction your hand moves, emulating a standard calligraphy pen.
    • 0% (Zero Fixation / Pure Tracking): The nib completely follows the direction of the path. The pen rotates as you turn corners, producing a stroke of uniform thickness along curved lines.
    • 1% to 99% (Partial Tracking): Blends fixed-angle behavior with directional tracking for semi-flexible brush effects.

Adjusting Thinning

The Thinning parameter controls how stroke thickness changes in response to the drawing speed (velocity) or tablet pressure.

  • Where to find it: Locate the Thinning input field in the Tool Controls Bar.
  • Values and Behavior:
    • Positive Values (0.01 to 1.00): Moving the cursor faster makes the stroke thinner, mimicking an ink brush running out of ink at high speeds.
    • Negative Values (-0.01 to -1.00): Moving the cursor faster makes the stroke wider, creating inverted speed dynamics.
    • Zero (0.00): Disables velocity-based width changes entirely, maintaining a constant stroke width dictated only by your base width setting or active pressure levels.
