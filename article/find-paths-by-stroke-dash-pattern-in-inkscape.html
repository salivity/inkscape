Find Paths by Stroke Dash Pattern in Inkscape

This guide explains how to quickly locate and select specific dashed paths across your Inkscape document using the Find/Replace dialog. By targeting the underlying SVG dash properties, you can filter and select complex stroke patterns across layers in seconds without having to pick them manually.

1. Identify the Dash Pattern Value

Inkscape stores dash configurations using the standard SVG property known as stroke-dasharray. To search for a specific pattern, you must first know its value:

  1. Select a path that uses the target dash pattern on your canvas.
  2. Open the XML Editor by pressing Ctrl + Shift + X (or Cmd + Shift + X on macOS), or go to Edit > XML Editor.
  3. In the XML tree, locate the selected path (it will be highlighted).
  4. Look at the right panel under the attributes list:
    • If Inkscape stored the dash rule inline, look for the stroke-dasharray attribute and copy its value (e.g., 4, 4 or 12, 4, 2, 4).
    • If it is inside the style attribute, click style and find the string beginning with stroke-dasharray: to see the exact numeric sequence.

2. Open the Find/Replace Dialog

Open the search interface using one of the following methods:

  • Press Ctrl + F (Windows/Linux) or Cmd + F (macOS).
  • Navigate to Edit > Find/Replace... from the main menu.

3. Configure the Search Criteria

Set up the dialog parameters to target only the paths matching your dash pattern:

  1. Scope: Choose whether to search within the All, Current layer, or Selection, depending on your project needs.
  2. Search in:
    • Uncheck Texts, Shapes, and other non-relevant types.
    • Ensure Paths is checked.
  3. Properties / Style Filter:
    • If your version of Inkscape provides an Attribute search field:
      • Set the attribute name to stroke-dasharray.
      • Set the attribute value to the numbers copied in Step 1 (e.g., 4, 4).
    • If your dialog searches by Style:
      • Enter stroke-dasharray: [pattern] into the style/value search field, replacing [pattern] with your specific numbers (e.g., stroke-dasharray: 4, 4).

4. Execute the Search

  1. Click the Find button.
  2. Inkscape will evaluate the document and automatically select every path that matches the defined dash array.
  3. With the items selected, you can now group them, change their colors, modify stroke widths, or update their dash patterns simultaneously using the Fill and Stroke panel (Ctrl + Shift + F).
