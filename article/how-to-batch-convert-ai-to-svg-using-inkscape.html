How to Batch Convert AI to SVG Using Inkscape

Converting thousands of Adobe Illustrator (AI) files to Scalable Vector Graphics (SVG) can be fully automated using a shell script that drives Inkscape's command-line interface. This guide demonstrates how to leverage Inkscape in headless mode alongside a Bash script to process directories of files automatically, including optimization techniques like parallel execution to handle large volumes in a fraction of the time.

Prerequisites

Before running the batch conversion, ensure Inkscape is installed and accessible in your system's PATH.

  • Linux (Ubuntu/Debian): sudo apt install inkscape
  • macOS (Homebrew): brew install inkscape
  • Windows: Use WSL (Windows Subsystem for Linux) or Git Bash, ensuring the path to inkscape.exe is added to your environment variables.

Verify the installation by running:

inkscape --version

Basic Inkscape CLI Command

Modern versions of Inkscape (1.0 and newer) use the following syntax to convert an individual file without launching the graphical user interface:

inkscape input.ai --export-filename=output.svg

Alternatively, you can specify the export format directly:

inkscape input.ai --export-type=svg

Sequential Batch Conversion Script

To process an entire folder of .ai files, create a shell script named convert_ai_to_svg.sh:

#!/usr/bin/env bash

# Directory containing your AI files
INPUT_DIR="./ai_files"
# Directory where SVGs will be saved
OUTPUT_DIR="./svg_files"

mkdir -p "$OUTPUT_DIR"

for file in "$INPUT_DIR"/*.ai; do
    # Check if files exist to avoid errors with empty directories
    [ -e "$file" ] || continue

    filename=$(basename "$file" .ai)
    echo "Converting: $filename.ai"
    
    inkscape "$file" --export-filename="$OUTPUT_DIR/$filename.svg"
done

echo "Conversion complete."

Make the script executable and run it:

chmod +x convert_ai_to_svg.sh
./convert_ai_to_svg.sh

High-Performance Parallel Conversion

When processing thousands of files, running conversions sequentially can take hours. You can dramatically speed up the process by utilizing all CPU cores with xargs or GNU parallel.

Using xargs (Built into most Unix systems)

#!/usr/bin/env bash

INPUT_DIR="./ai_files"
OUTPUT_DIR="./svg_files"
CORES=$(nproc 2>/dev/null || sysctl -n hw.ncpu 2>/dev/null || echo 4)

mkdir -p "$OUTPUT_DIR"

find "$INPUT_DIR" -maxdepth 1 -name "*.ai" -print0 | xargs -0 -P "$CORES" -I {} bash -c '
    input="{}"
    filename=$(basename "$input" .ai)
    inkscape "$input" --export-filename="'"$OUTPUT_DIR"'/${filename}.svg"
'

Using GNU Parallel

If you have GNU parallel installed (sudo apt install parallel or brew install parallel), you can use a more concise command:

mkdir -p ./svg_files
parallel inkscape {} --export-filename=./svg_files/{/.}.svg ::: ./ai_files/*.ai

The {/.} placeholder automatically removes the directory path and the .ai extension, ensuring the exported SVG matches the original filename.
