Copy Gradients Without Linking Handles in Inkscape

In Inkscape, copying a gradient from one object to another typically links their definitions, meaning adjustments made to the gradient handles on one object automatically alter the other. This guide explains how to copy an existing gradient onto a new vector object while keeping the handles completely independent, allowing you to reposition, rotate, and resize the gradient without modifying the original artwork.

Why Inkscape Links Gradients

When you copy an object's style using Paste Style (Ctrl + Shift + V on Windows/Linux or Cmd + Shift + V on macOS), Inkscape assigns the exact same gradient resource ID to the target object. Because both objects share this single definition, moving the on-canvas start, stop, or center handles modifies the gradient for every shape linked to it. To edit the handles independently, you must create a separate copy of the gradient definition for the second object.

Method 1: The Paste Style and Duplicate Workflow

The fastest way to copy a gradient without maintaining linked handles is to apply the style and immediately duplicate the gradient definition:

  1. Select the source object that contains the gradient and press Ctrl + C (Cmd + C) to copy it.
  2. Select the target object and press Ctrl + Shift + V (Cmd + Shift + V) to paste the style. Both objects now share the gradient.
  3. Keep the target object selected and activate the Gradient Tool by pressing G (or selecting it from the left-hand toolbar).
  4. Look at the Tool Controls Bar at the top of the screen. Locate the Duplicate gradient icon (represented by two overlapping squares next to the gradient name field).
  5. Click Duplicate gradient. Inkscape will generate a new, unique gradient ID with the identical color stops.

You can now drag the gradient handles on your target object without altering the source shape.

Method 2: Using the Fill and Stroke Dialog

If you prefer using panels, you can duplicate the gradient directly from the Fill and Stroke menu:

  1. Select your target object and open the Fill and Stroke panel (Shift + Ctrl + F or Shift + Cmd + F).
  2. Depending on where the gradient is applied, navigate to either the Fill or Stroke paint tab.
  3. Select the Linear gradient or Radial gradient button.
  4. Open the gradient drop-down menu to select the gradient from your source object.
  5. Once applied, click the Duplicate button located just beneath the gradient palette list in the panel.

This immediately detaches the selected object from the shared gradient and provisions an isolated copy for custom handle positioning.
