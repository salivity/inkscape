How to Share Custom Inkscape Extensions and Scripts

Sharing custom Inkscape extensions and scripts allows other designers and developers to automate workflows, add new vector tools, and streamline complex tasks. This guide covers how to prepare your extension files, distribute them manually via archives or code repositories, and publish them to the official Inkscape community platform for global discovery.

1. Prepare and Package Extension Files

Every Inkscape extension requires at least two fundamental files to work properly:

  • The .inx file: An XML file describing the extension metadata, menu location, parameters, and executable details to the Inkscape interface.
  • The script file: Usually a Python (.py) script, shell script, or compiled executable that executes the actual logic.

Ensure your .inx file has a unique identifier inside the <id> tag to avoid namespace conflicts with existing tools. Place any additional dependencies or helper modules into the same folder or structure them cleanly inside a sub-package.

2. Share Manually via a Compressed Archive (ZIP)

The most direct way to share an extension with a small group or specific users is through a ZIP archive.

  1. Compress your .inx file, script file, and any required assets into a single .zip file.
  2. Provide instructions for the recipient to extract the contents into their local Inkscape user extensions directory:
    • Windows: %APPDATA%\inkscape\extensions
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions
    • Linux: ~/.config/inkscape/extensions
  3. Remind users that they can also locate this directory directly inside Inkscape by navigating to Edit > Preferences > System > User extensions.
  4. Instruct users to restart Inkscape after pasting the files for the new menu items to appear.

3. Distribute via Code Repositories

Hosting your script on platforms like GitHub or GitLab is ideal for version control, issue tracking, and collaborative development.

  • Include a clear README.md specifying the supported Inkscape versions (e.g., Inkscape 1.2+).
  • List any required third-party Python libraries and provide commands on how to install them (such as using pip).
  • Use repository release tags to provide downloadable .zip bundles for non-technical users.

4. Publish to the Official Inkscape Gallery

To reach the entire Inkscape community, you can submit your extension to the official Inkscape website:

  1. Create or log in to your account on the official Inkscape website.
  2. Navigate to the community upload section for Extensions and Add-ons.
  3. Upload your packaged file, provide a clear title, description, usage instructions, and version compatibility details.
  4. Add tags and preview screenshots showing the extension interface and output.

Once published, users can discover, download, and review your extension directly through Inkscape's official resource directory.
