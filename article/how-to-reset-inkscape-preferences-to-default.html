How to Reset Inkscape Preferences to Default

Resetting Inkscape to its default preferences can resolve unexpected interface bugs, tool malfunctions, or misconfigured settings. This guide explains how to restore Inkscape factory defaults using the built-in preferences menu as well as the manual method of deleting the configuration file for Windows, macOS, and Linux users who cannot open the software.

Method 1: Reset Preferences from Within Inkscape

If Inkscape opens normally, the fastest way to reset your settings is through the application menu:

  1. Open Inkscape.
  2. Go to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left navigation menu, click on System.
  4. Locate the User preferences entry in the right pane.
  5. Click the Reset Preferences button.
  6. A confirmation dialog will appear stating that preferences will be reset upon restarting.
  7. Close and relaunch Inkscape to apply the default settings.

Method 2: Manually Delete the Preferences File

If Inkscape crashes on launch or the interface is completely inaccessible, you can reset it manually by deleting or renaming the preferences.xml file. Inkscape will automatically generate a new default file the next time it starts.

Windows

  1. Close Inkscape completely.
  2. Press Win + R to open the Run dialog.
  3. Type %appdata%\inkscape and press Enter.
  4. Locate the file named preferences.xml.
  5. Delete the file (or rename it to preferences.xml.bak to keep a backup).
  6. Start Inkscape.

macOS

  1. Close Inkscape completely.
  2. Open Finder, press Cmd + Shift + G, and enter: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/ (Note: On some versions, the path is ~/.config/inkscape/)
  3. Find the preferences.xml file.
  4. Move the file to the Trash.
  5. Start Inkscape.

Linux

  1. Close Inkscape.
  2. Open your file manager or terminal.
  3. Navigate to ~/.config/inkscape/.
  4. Delete the preferences.xml file or run: 
    rm ~/.config/inkscape/preferences.xml
  5. Start Inkscape.
