Adjust Radial Gradient Focal Point in Inkscape

In Inkscape, controlling radial gradients involves manipulating both the outer color boundaries and the origin point of the gradient's inner color. This guide covers how to use Inkscape's built-in gradient controls to separate and adjust the focal point independently from the geometric center of a radial gradient, allowing you to create dynamic lighting, depth, and 3D effects on vector objects.

The Tool to Use

The primary tool used to adjust the focal point independently from the center is the Gradient Tool (shortcut: G). Alternatively, the Node Tool (N) can also manipulate gradient handles when an object with a gradient applied is active.

Understanding Radial Gradient Handles

When you select an object with a radial gradient applied and activate the Gradient Tool, three default control handles appear:

  • Center Handle (Square): Defines the geometric center of the gradient.
  • Outer Handles (Circles): Two perpendicular handles that control the radius, direction, and aspect ratio of the gradient.
  • Focal Point Handle: By default, the focal point is locked directly over the square center handle, making them look like a single handle.

How to Separate and Move the Focal Point

To offset the focal point from the center:

  1. Select your object using the Select Tool (S).
  2. Switch to the Gradient Tool by pressing G.
  3. Locate the square handle at the center of the radial gradient.
  4. Hold down the Shift key on your keyboard.
  5. Click and drag the square center handle.

Holding Shift detaches the focal point from the center handle, revealing a separate control handle (an "X" or cross-shaped handle in modern versions of Inkscape). You can now position this focal point anywhere on the canvas—either inside or outside the object's boundaries—to simulate off-center highlights and custom light angles.

Re-aligning the Focal Point

If you need to lock the focal point back to the center of the gradient, simply click and drag the separated focal point handle back onto the square center handle until it snaps into place.
