Cycle Open Document Windows in Inkscape

Managing multiple designs at once requires quick navigation between project files. This guide explains the exact keyboard shortcuts used to cycle forward and backward through open document windows in Inkscape across Windows, Linux, and macOS, as well as how to customize these keys to match your workflow.

Default Keyboard Shortcuts to Cycle Windows

Inkscape treats each open SVG file as an independent window. You can switch between these active document windows using native application shortcuts:

  • Cycle to Next Document Window:

    • Windows & Linux: Ctrl + Tab or Ctrl + F6
    • macOS: Cmd + ~ (Tilde) or Ctrl + Tab

  • Cycle to Previous Document Window:

    • Windows & Linux: Ctrl + Shift + Tab or Ctrl + Shift + F6
    • macOS: Cmd + Shift + ~ (Tilde) or Ctrl + Shift + Tab

How to Customize Window Switching Shortcuts

If the default combinations conflict with your operating system shortcuts or personal preferences, you can rebind them directly inside Inkscape:

  1. Open the Preferences dialog by pressing Ctrl + Shift + P (or Cmd + Shift + P on macOS), or navigate to Edit > Preferences.
  2. Select Interface in the left sidebar, then click on Keyboard.
  3. In the search field, type Next window or Previous window.
  4. Click on the shortcut entry you want to modify.
  5. Press the new key combination you want to assign.
  6. Close the Preferences window to apply the changes immediately.
