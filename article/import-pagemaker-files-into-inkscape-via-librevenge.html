Import PageMaker Files into Inkscape via librevenge

This guide explains how to import vector artwork from legacy Adobe PageMaker files into Inkscape using librevenge-based import filters. By leveraging libpagemaker—an open-source parsing library built on top of the librevenge document interface framework—Inkscape can interpret proprietary PageMaker binary data, convert internal vector commands into modern SVG paths, and allow full editing of legacy artwork.

How librevenge and libpagemaker Work

Adobe PageMaker stores vector paths, text, and layout information in proprietary binary formats such as .pmd, .p65, and .pm6. Inkscape cannot read these raw streams natively. Instead, it relies on libpagemaker, a library built specifically on librevenge.

librevenge serves as a translation layer that handles low-level streams, generators, and vector primitives. When a PageMaker file is opened, libpagemaker reverse-engineers the file structure and passes drawing calls (such as bezier curves, polygons, and line properties) through librevenge interfaces directly to Inkscape, which renders them as standard SVG elements.

Direct Import in Inkscape

Most modern distributions of Inkscape on Windows, macOS, and Linux come pre-compiled with libpagemaker and librevenge support enabled by default.

  1. Launch Inkscape.
  2. Go to File > Open (or File > Import if you want to add the artwork into an existing canvas).
  3. In the file selection dialog, set the file type filter to All Files or locate **Adobe PageMaker (*.pmd, .p65, .pm6) in the dropdown menu.
  4. Select your PageMaker document and click Open.
  5. Inkscape invokes the librevenge stream filter to parse the document and render the vector artwork directly onto the canvas.

Cleaning Up Imported Vectors

Because PageMaker files often bundle layout grids, text boxes, and multiple page elements into a single file, imported vector graphics may require isolation:

  1. Select the imported artwork on the canvas.
  2. Press Ctrl + Shift + G (Windows/Linux) or Cmd + Shift + G (macOS) repeatedly to ungroup the nested groups created during the translation process.
  3. Switch to the Node Tool (N) to verify that vector paths, shapes, and control points translated cleanly.
  4. Delete unwanted background boxes, margins, or master page artifacts that may have been imported alongside your vector drawing.
  5. Save the resulting asset in standard SVG format via File > Save As.

Alternative CLI Method Using pmd2svg

If your version of Inkscape lacks the compiled libpagemaker filter or fails to open a particularly complex layout, you can convert the file using the standalone command-line utilities provided by the library.

  1. Install the libpagemaker tools using your operating system package manager (e.g., sudo apt install libpagemaker-tools on Debian/Ubuntu, or via Homebrew on macOS).
  2. Run the pmd2svg utility in your terminal: 
    pmd2svg input_file.pmd > output_file.svg
  3. Open the newly generated output_file.svg directly inside Inkscape to inspect and manipulate your vector paths.
