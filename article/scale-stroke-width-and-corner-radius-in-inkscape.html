Scale Stroke Width and Corner Radius in Inkscape

When resizing objects in Inkscape, stroke widths and rounded corner radii remain at fixed dimensions by default, which can alter the visual proportions of your design. This guide explains how to toggle Inkscape's built-in scaling settings so that strokes and corner radiuses automatically scale up or down proportionally with your vector shapes.

Enable Proportional Scaling via the Tool Controls Bar

The fastest way to scale strokes and corners proportionally is by enabling the corresponding toggles in the Select Tool options.

  1. Switch to the Select and Transform Objects tool by pressing S or F1.
  2. Look at the Tool Controls Bar at the top of the workspace (just above the canvas).
  3. On the right side of this bar, locate the four transformation toggle icons:
    • Scale Stroke Width: Click the icon displaying a rectangle with thick outlines and resizing arrows ("When scaling objects, scale the stroke width by the same proportion").
    • Scale Corner Radii: Click the icon displaying a rectangle with rounded corners ("When scaling rectangles, scale the radius of rounded corners").
  4. With these buttons toggled on (highlighted/depressed), resize any object using the corner selection handles. The stroke thickness and corner curves will now scale in exact proportion to the object's dimensions.

Adjust Preferences Globally

If you want stroke scaling to stay active across all documents by default:

  1. Go to Edit > Preferences (or press Ctrl + Shift + P).
  2. Navigate to Behavior > Transforms.
  3. Under Scale, ensure the checkboxes for "Stroke width" and "Rounded corners in rectangles" are checked.

Alternative: Convert the Shape to a Path

If you are working with shapes that need to maintain their relative geometry permanently across different software or exports:

  1. Select the shape.
  2. Go to the top menu and select Path > Object to Path (or press Ctrl + Shift + C).
  3. Note that this converts parametric shapes and corners into standard vector nodes. The corner radius will scale automatically with the geometry, though stroke scaling will still depend on the stroke scale toggle described above.
