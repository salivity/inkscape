Select Odd Nodes on Open Paths in Inkscape Python

This guide explains how to programmatically identify and isolate odd-numbered nodes along an open path in Inkscape using Python and the official inkex extension API. By reading the SVG path data, verifying that the subpath is open, and filtering the node sequence based on index parity, you can automate precise node-level transformations, deletions, or data extraction.

Understanding Path Data in Inkscape

In Inkscape 1.0 and later, extensions interact with SVG paths through the inkex library. A path consists of a sequence of commands (such as Move, Line, and Curve) stored in the element.path attribute.

To determine whether a path is open:

  • An open path does not end with a Close command (Z or z).
  • Each node corresponds to the end coordinate of a path command. The first node is established by the Move command, followed by successive coordinates from Line, Curve, or Arc commands.

Python Implementation

Below is a complete Python script designed as an Inkscape extension effect. It iterates over selected path elements, checks if they are open paths, and targets odd-numbered nodes (using 1-based indexing: node 1, node 3, node 5, etc.).

import inkex
from inkex.paths import Move, Line, Curve, Arc, Close

class SelectOddNodes(inkex.EffectExtension):
    def effect(self):
        # Ensure elements are selected
        if not self.svg.selection:
            inkex.errormsg("Please select at least one open path.")
            return

        for elem in self.svg.selection.filter(inkex.PathElement):
            path = elem.path
            
            # Check if the path is closed
            is_closed = any(isinstance(cmd, Close) for cmd in path)
            if is_closed:
                inkex.utils.debug(f"Skipping '{elem.id}': Path is closed.")
                continue

            # Extract end coordinates of each command to define the nodes
            nodes = []
            for cmd in path:
                if hasattr(cmd, 'end_point'):
                    nodes.append(cmd.end_point)

            # Filter for odd-numbered nodes (1-based index: 1st, 3rd, 5th, ...)
            # In 0-based indexing, these correspond to index 0, 2, 4, etc.
            odd_nodes = [node for idx, node in enumerate(nodes) if (idx + 1) % 2 != 0]

            # Process the selected odd nodes
            self.process_odd_nodes(elem, odd_nodes)

    def process_odd_nodes(self, elem, odd_nodes):
        # Example action: place a small visual marker at each odd node coordinate
        parent = elem.getparent()
        for i, point in enumerate(odd_nodes):
            circle = parent.add(inkex.Circle())
            circle.center = point
            circle.radius = 2.0
            circle.style = {'fill': '#ff0000', 'stroke': 'none'}

if __name__ == '__main__':
    SelectOddNodes().run()

Step-by-Step Breakdown

1. Filtering Open Paths

The script verifies path openness using isinstance(cmd, Close). If a path contains a Close command anywhere in its command list, the loop ignores it.

2. Extracting Node Coordinates

Each segment command inherits from PathCommand and exposes the end_point property. Iterating over elem.path yields the coordinates in the exact sequence they appear from the path's starting node to its terminus.

3. Applying Node Indexing

Depending on the requirement:

  • 1-based Odd Nodes (1st, 3rd, 5th...): Evaluated as (idx + 1) % 2 != 0 (or idx % 2 == 0 in Python's 0-indexed syntax).
  • 0-based Odd Nodes (indices 1, 3, 5...): Evaluated as idx % 2 != 0.

4. Performing Operations

Because the Inkscape GUI does not expose an external API to set active selections within the interactive Node Tool directly from a background script, typical extension actions on selected nodes include:

  • Generating visual highlight circles or indicators.
  • Rebuilding elem.path to retain or delete specific nodes.
  • Exporting the coordinates to an external file for data analysis.
