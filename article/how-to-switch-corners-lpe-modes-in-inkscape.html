How to Switch Corners LPE Modes in Inkscape

The Corners (Fillet/Chamfer) Live Path Effect (LPE) in Inkscape allows you to dynamically round or bevel the corners of any path without permanently altering the original geometry. You can switch between fillet (standard rounded corner), inverse fillet (concave rounded corner), chamfer (flat bevel), and inverse chamfer modes either individually per node using canvas controls or precisely through a dedicated settings popup.

Applying the Corners LPE

  1. Select your vector path using the Select Tool (S).
  2. Navigate to the top menu and click Path > Path Effects to open the Path Effects panel.
  3. Click the + (Add Path Effect) button, search for Corners (Fillet/Chamfer), and select it.

Method 1: The Quick Click Shortcut (Canvas)

The fastest way to toggle between fillet, inverse fillet, chamfer, and inverse chamfer is directly on the canvas using your mouse and a modifier key.

  1. Switch to the Node Tool by pressing N or selecting it from the left-hand toolbar.
  2. Select the object. Green circular control handles will appear at every corner.
  3. Hold Ctrl and Left-Click directly on a green corner handle.
  4. Each click cycles to the next mode in this sequence:
    • Fillet: Standard outward curve.
    • Inverse Fillet: Inward concave scoop.
    • Chamfer: Straight diagonal cut.
    • Inverse Chamfer: Inward angular notch.

Method 2: The Context Dialog (Precise Control)

If you prefer to pick the mode from a list or need to define an exact numerical radius at the same time:

  1. Select the Node Tool (N).
  2. Right-Click directly on the green handle of the corner you want to modify.
  3. A popup menu will appear displaying the corner's properties.
  4. Open the Method dropdown menu and choose your desired mode:
    • Fillet
    • Inverse Fillet
    • Chamfer
    • Inverse Chamfer
  5. Adjust the Radius value if necessary, then close the dialog to apply the change.

Changing Multiple Corners Simultaneously

To change the corner mode for several nodes at once:

  1. Activate the Node Tool (N).
  2. Drag a selection box around multiple corner handles, or hold Shift and click each green handle you want to adjust.
  3. Hold Ctrl and click any of the selected handles to cycle the mode for all selected corners at the same time, or right-click any selected handle to set the method uniformly via the dialog.
