Make Spirograph Patterns with Inkscape Roughen Effect

This guide explains how to generate complex, interactive Spirograph-like geometric patterns in Inkscape using the Roughen Live Path Effect (LPE). By applying mathematical displacement to a standard geometric path, you can dynamically manipulate frequencies, node counts, and curve tensions to create intricate guilloche and harmonic line art in real time.

1. Create the Base Shape

  1. Select the Circles and Arcs tool (press E) or the Stars and Polygons tool (*).
  2. Hold Ctrl + Shift and drag on the canvas to draw an equilateral base shape, such as a regular circle.
  3. Remove any fill color by clicking the red "X" in the bottom color palette.
  4. Set a thin stroke by holding Shift and clicking a color, then set the stroke width to roughly 0.5 px or 1 px in the Fill and Stroke panel (Ctrl + Shift + F).
  5. Convert the object to a vector path by navigating to Path > Object to Path (Ctrl + Shift + C).

2. Add More Nodes to the Path

For the Roughen effect to generate tight, repeating geometric waves, the underlying path requires a dense distribution of nodes:

  1. Select the Node tool (press N) and select all nodes on your shape (Ctrl + A).
  2. In the top tool controls bar, click the Insert new nodes into selected segments button several times until the perimeter has at least 30 to 60 evenly spaced nodes.

3. Apply the Roughen Path Effect

  1. Open the Path Effects dialog by navigating to Path > Path Effects.
  2. With your shape selected, click the Add Path Effect button (the + icon).
  3. Search for or locate Roughen in the list and click it to apply.

4. Configure the Roughen Parameters for Geometric Harmonics

By default, the Roughen effect adds random jitter. To make it behave like a Spirograph:

  1. In the Path Effects panel under Roughen, locate the displacement and method options.
  2. Change the method from random displacement to a structured variation by unchecking randomized settings where available, or lowering the Random seed variability.
  3. Increase the Divisions or Segments slider to a high value to introduce dense repeating oscillations along the perimeter.
  4. Adjust the Max displacement slider carefully. As you drag the slider, the uniform nodes will expand and cross through the center of the shape, creating overlapping, geometric Spirograph loops.
  5. Toggle between linear segments and smooth Bézier curve interpolation to shift from rigid geometric mandalas to fluid, harmonic curves.

5. Interactively Modify the Pattern

  • Edit with the Node Tool: Press N to activate the Node tool. Drag the original nodes or handles of the base shape; the Roughen effect will recalculate live, producing continuous geometric transformations.
  • Scale and Rotate: Select the shape with the Selector tool (S). Scaling non-proportionally or rotating will warp the harmonic interference patterns interactively.
  • Layering: Duplicate the object (Ctrl + D), scale it slightly, and adjust the stroke color or opacity to create multifaceted, depth-filled vector guilloche designs.
