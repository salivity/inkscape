How to Add Custom Metadata to SVG in Inkscape Python

This article explains how to programmatically add custom metadata to an SVG file header using Inkscape's Python extension framework (inkex). By leveraging the XML manipulation capabilities of inkex and lxml, you can access the SVG document tree, define custom XML namespaces, and inject proprietary or standardized data directly into the <metadata> element of your SVG files.

Understanding SVG Metadata Structure

In standard SVG documents, metadata is stored within a top-level <metadata> element directly under the root <svg> tag. Inkscape typically places standard Dublin Core metadata wrapped inside an <rdf:RDF> block. However, you can also inject custom XML tags or attributes under <metadata> to store application-specific data, such as tracking IDs, software versions, or author details.

Building the Python Extension Script

Modern Inkscape extensions (version 1.0 and later) inherit from inkex.EffectExtension. The inkex module provides built-in methods to parse, modify, and save the SVG DOM using lxml.

Below is a complete Python script that locates or creates the <metadata> tag in the SVG header and appends a custom XML element with a dedicated namespace.

Save this file as add_custom_metadata.py:

import inkex
from lxml import etree

class AddCustomMetadata(inkex.EffectExtension):
    def add_arguments(self, pars):
        pars.add_argument("--meta_key", type=str, default="ProjectID", help="Metadata key name")
        pars.add_argument("--meta_value", type=str, default="123456", help="Metadata value")

    def effect(self):
        root = self.svg

        # 1. Locate the <metadata> element or create one if it does not exist
        metadata = root.find(inkex.addNS('metadata', 'svg'))
        if metadata is None:
            metadata = etree.SubElement(root, inkex.addNS('metadata', 'svg'))

        # 2. Define a custom namespace to avoid conflicts
        CUSTOM_NS = "https://example.com/custom_svg_meta"
        etree.register_namespace("custom", CUSTOM_NS)

        # 3. Create the custom element using the defined namespace
        tag_qname = etree.QName(CUSTOM_NS, self.options.meta_key)
        custom_element = etree.SubElement(metadata, tag_qname)
        custom_element.text = self.options.meta_value

        # Optional: Add attributes to your custom element
        custom_element.set("timestamp", "2023-10-27T10:00:00Z")

if __name__ == '__main__':
    AddCustomMetadata().run()

Creating the Extension Descriptor File (.inx)

Inkscape requires an XML-based .inx file to register the Python script in its user interface and expose parameters.

Save this file as add_custom_metadata.inx in the same directory as the Python script:

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>Add Custom Metadata</name>
    <id>org.example.add_custom_metadata</id>
    
    <param name="meta_key" type="string" gui-text="Metadata Key:">ProjectID</param>
    <param name="meta_value" type="string" gui-text="Metadata Value:">123456</param>
    
    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Document"/>
        </effects-menu>
    </effect>
    
    <script>
        <command location="inx" interpreter="python">add_custom_metadata.py</command>
    </script>
</inkscape-extension>

Installing and Running the Script

  1. Locate your Inkscape User Extensions folder:
    • Linux: ~/.config/inkscape/extensions/
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/
    • Windows: %APPDATA%\inkscape\extensions\
  2. Place both add_custom_metadata.py and add_custom_metadata.inx into that directory.
  3. Restart Inkscape.
  4. Open any SVG document, then navigate to Extensions > Document > Add Custom Metadata.
  5. Enter your key and value, then click Apply.

The Resulting SVG Output

When opening the saved SVG file in a text editor, you will find your custom element located within the SVG header:

<svg xmlns="http://www.w3.org/2000/svg" xmlns:custom="https://example.com/custom_svg_meta" ...>
  <metadata>
    <custom:ProjectID timestamp="2023-10-27T10:00:00Z">123456</custom:ProjectID>
  </metadata>
  ...
</svg>
