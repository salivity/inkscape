Why Inkscape Path Union Makes LPE Objects Disappear

When applying a destructive boolean union to an object using Live Path Effects (LPE) in Inkscape, the shape often vanishes completely. This article explains why this occurs—focusing on the conflict between non-destructive parametric modifiers and native boolean engines—and provides the direct solution to preserve your geometry before merging paths.

The Conflict Between Live Path Effects and Boolean Operations

Live Path Effects (LPE) in Inkscape are non-destructive, mathematical transformations applied dynamically over an underlying base path. The visual output you see on the canvas is a temporary render, not the actual fixed vector nodes stored in the raw SVG data.

Inkscape’s boolean engine calculates operations like Union (Ctrl + +) directly on the base path definition. When a boolean operation is triggered, the software attempts to merge the raw structural paths rather than the visually rendered result, often creating unresolvable geometric conflicts that force the object to collapse or disappear entirely.

Key Technical Causes for Disappearance

  1. Non-Rendered Source Geometry: A complex LPE may rely on a very simple base path (such as a single open line segment for a dynamic stroke or pattern). The boolean engine evaluates the simple base path, ignores or drops the dynamic effect, and calculates a union on an open or dimensionless path, resulting in an empty geometry.
  2. Invalid Manifold and Self-Intersections: Many complex LPEs (such as Power Stroke, Knot, or Spiro Spline) generate self-intersecting segments, zero-area loops, or overlapping edges. Inkscape’s geometry library requires valid 2D manifolds to determine "inside" versus "outside" fills. When it encounters ambiguous self-intersections during a union, the calculation fails and returns a null path.
  3. LPE Stack Incompatibility: Boolean operations are destructive and generally incompatible with an active LPE stack. Applying a destructive operation to an LPE-driven object often strips the effect parameters while failing to write the resulting visual nodes to the SVG, leaving behind an empty <path> element.

How to Prevent Objects from Disappearing

To successfully execute a boolean union on an object utilizing Live Path Effects, you must convert the dynamic mathematical render into permanent, static vector geometry before combining it.

  1. Select the object containing the Live Path Effect.
  2. Navigate to the top menu and select Path > Object to Path (or press Shift + Ctrl + C).
  3. If the LPE converted into a group of multiple paths, select the group and ungroup it using Object > Ungroup (Ctrl + Shift + G).
  4. Select all the target paths and perform the union by choosing Path > Union (Ctrl + +).

Converting the effect to a standard path bakes the rendered coordinates into fixed nodes, allowing the boolean engine to accurately compute the shared boundaries without geometric failure.
