Export DXF R14 with Layer Colors in Inkscape

Exporting engineering drawings from Inkscape to AutoCAD DXF R14 while retaining specific layer and color assignments requires structuring your SVG document correctly before using the native DXF export module. By organizing paths onto dedicated layers, assigning uniform stroke colors based on the AutoCAD Color Index (ACI), and configuring the export settings properly, you can generate CNC- and CAD-ready files with intact layer definitions and distinct color profiles.

1. Organize Elements into Inkscape Layers

Open the Layers panel (Ctrl + Shift + L) in Inkscape. Create separate layers for each distinct operation or component of your drawing (for example: CUT, ENGRAVE, DIMENSIONS, CENTERLINES). Move your vector objects into their corresponding layers. The name assigned to each layer in Inkscape will be carried over directly as the layer name in the DXF file.

2. Convert Objects and Text to Paths

DXF R14 does not reliably support complex SVG primitives, grouped objects, or live text fonts.

  1. Select all objects in the drawing (Ctrl + A).
  2. Go to Path > Object to Path (Shift + Ctrl + C).
  3. Ungroup any nested groups by repeatedly pressing Object > Ungroup (Ctrl + Shift + G) until the status bar indicates no groups are selected.

3. Apply Distinct Stroke Colors

AutoCAD DXF R14 uses the standard AutoCAD Color Index (ACI) to assign colors to entities. To ensure CAD and CAM software correctly read distinct colors per layer:

  1. Select all paths on a specific layer.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Set the Fill to No paint (X).
  4. Set the Stroke paint to a flat, distinct color. For maximum compatibility with ACI standards, use pure primary and secondary RGB values:
    • Red (#FF0000) = ACI Color 1
    • Yellow (#FFFF00) = ACI Color 2
    • Green (#00FF00) = ACI Color 3
    • Cyan (#00FFFF) = ACI Color 4
    • Blue (#0000FF) = ACI Color 5
    • Magenta (#FF00FF) = ACI Color 6
    • White/Black (#FFFFFF or #000000) = ACI Color 7

4. Save and Configure the DXF Export

  1. Go to File > Save As... (Ctrl + Shift + S).
  2. In the file type dropdown menu, select AutoCAD DXF R14 (*.dxf).
  3. Choose your destination folder, enter a filename, and click Save.
  4. In the export configuration dialog that appears, adjust the following parameters:
    • Base unit: Choose mm or in according to your drawing's target scale.
    • Character encoding: Select latin_1 (standard for R14).
    • Layer option: Ensure layers are toggled to export by name rather than flattened into layer 0.
    • Use ROBO-Master / LWPOLYLINE type: Leave unchecked unless specifically required by your target CAM cutter, as standard POLYLINE entities provide broader layer-color compatibility in R14 viewers.
  5. Click OK to generate the file.

Your resulting DXF file will open in AutoCAD or CAM software with separate layers matching your Inkscape hierarchy, each containing vector geometry rendered in its designated color.
