How to Ignore Opacity in Inkscape Dropper

When sampling colors in Inkscape, the Dropper tool can either calculate transparency values or sample the visible color as an opaque value. This guide explains how to configure the Dropper tool settings and use keyboard shortcuts so the tool ignores opacity levels and applies solid color values directly to your selected objects.

1. Select the Target Object

Before sampling a color, choose the object whose fill or stroke you want to change using the Select tool (S or F1).

2. Activate the Dropper Tool

Switch to the Dropper tool by clicking its pipette icon in the toolbox or pressing D (or F7) on your keyboard.

3. Toggle the Opacity Setting in Tool Controls

Look at the Tool Controls Bar directly above the canvas workspace:

  • Locate the Pick section, which contains an icon representing opacity/alpha (resembling an eye or a checkerboard pattern).
  • To ignore opacity: Ensure the Pick alpha / Pick opacity button is disabled (untoggled).

When this setting is disabled, the Dropper tool ignores layer, object, and canvas transparency. It samples the exact RGB composite color visible on your screen and applies it at 100% opacity to your selected object.

4. Use the Keyboard Shortcut for On-the-Fly Sampling

If you frequently switch between sampling true color values and capturing alpha channels, you do not need to click the toolbar toggle every time:

  • Click: Samples color using the current toolbar setting.
  • Alt + Click: Inverts the current opacity setting for that click. If opacity sampling is turned on, holding Alt ignores opacity and samples the color as fully opaque.
  • Shift + Click: Applies the sampled color to the object's stroke rather than its fill.

5. Check Document Background Transparency

If you are sampling over an empty part of the canvas and receiving unexpected transparency:

  1. Open Document Properties by pressing Ctrl + Shift + D.
  2. Under the Display or Page tab, locate Background color.
  3. Ensure the alpha channel slider (A) is set to 255 if you want a solid white canvas rather than a transparent checkerboard background.
