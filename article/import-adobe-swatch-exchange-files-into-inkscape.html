Import Adobe Swatch Exchange Files into Inkscape

Inkscape does not natively support Adobe Swatch Exchange (.ase) files directly, as it relies on the GIMP Palette (.gpl) format for color swatches. To use an ASE palette in Inkscape, you must convert the .ase file into a .gpl file and place it in your Inkscape palettes directory. This guide provides a direct, step-by-step method to convert and load your Adobe swatches into Inkscape.

Step 1: Convert the ASE File to GPL Format

Since Inkscape cannot read ASE files directly, use a converter to translate the palette into the GPL format.

  1. Use a free online converter (such as an ASE to GPL web converter) or a standalone utility to convert your .ase file into a .gpl file.
  2. Download the resulting .gpl file to your computer.

Step 2: Open the Inkscape Palettes Folder

You need to place the converted file into the directory where Inkscape stores user-defined color palettes.

  • Windows: Press Win + R, paste %APPDATA%\inkscape\palettes, and press Enter.
  • macOS: Open Finder, press Cmd + Shift + G, paste ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes, and press Enter.
  • Linux: Open your file manager and navigate to ~/.config/inkscape/palettes.

(Note: If the palettes folder does not exist inside your Inkscape configuration folder, create a new folder and name it palettes.)

Step 3: Move the Palette File

Copy or move your converted .gpl file directly into the palettes folder located in Step 2.

Step 4: Load the Palette in Inkscape

  1. Launch Inkscape (or restart it if it is already open).
  2. Look at the bottom right corner of the window, next to the color palette bar, and click the tiny arrow icon (Palette Menu).
  3. Scroll through the list of available palettes to find the name of your imported .gpl palette.
  4. Click on the palette name to activate it. The colors from your original Adobe Swatch Exchange file will now appear in your Inkscape palette bar.
