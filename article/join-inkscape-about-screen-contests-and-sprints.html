Join Inkscape About Screen Contests and Sprints

Participating in Inkscape About Screen design contests and community sprints is an effective way to contribute to the open-source vector graphics ecosystem. Inkscape regularly invites artists to design the official splash screen for upcoming software releases and hosts collaborative sprints for developers, designers, and writers to build features, fix bugs, and improve documentation. This guide outlines the requirements, submission steps, and engagement methods for both initiatives.

Participating in the Inkscape About Screen Contest

The "About Screen" contest is held prior to major Inkscape releases to select the artwork displayed when the program launches and in the "About Inkscape" dialog.

1. Check Contest Announcements

Contests are announced on the official Inkscape website (inkscape.org), community forums, and social media channels several months before a new version release. Each contest outlines specific themes, deadlines, and technical specifications.

2. Follow Artwork Guidelines

  • Native Tool Usage: The artwork must be created entirely using Inkscape.
  • File Format: Entries must be submitted in the native Scalable Vector Graphics (.SVG) format.
  • Licensing: Submissions must be licensed under Creative Commons Attribution-ShareAlike (CC BY-SA) or Creative Commons Zero (CC0) to comply with open-source distribution.
  • Content Constraints: Third-party copyrighted elements, raster images, and external font dependencies are generally prohibited. Text must usually be converted to paths.
  • Layer Organization: Submissions often require clean layer naming to demonstrate the process and verify that the art was created natively.

3. Submit Your Entry

  1. Create a user account on the Inkscape website.
  2. Navigate to the official Contest Gallery section for the active release.
  3. Upload your original SVG file along with a rendered PNG preview following the requested dimensions.
  4. Provide the required licensing confirmation and design description.

4. Voting and Selection

Contests typically involve a community voting phase followed by a review by the Inkscape Vector Board or development team to ensure technical compliance before the winner is declared.

Participating in Inkscape Community Sprints

Community sprints are focused collaborative events where contributors work on code, user experience, documentation, translation, and community building.

1. Identify Upcoming Sprints

Inkscape organizes both virtual hackathons and in-person sprints (often held around major open-source conferences like FOSDEM or LGM). Announcements and schedules are posted on:

  • The Inkscape website events page.
  • The official Inkscape GitLab repository.
  • The Inkscape mailing lists and developer forums.

2. Set Up Communication Channels

Contributors coordinate before and during sprints using:

  • Chat Platforms: Inkscape’s official Rocket.Chat or Matrix/IRC bridges.
  • GitLab: Issue trackers and project boards on the Inkscape GitLab instance.
  • Video Conferences: Scheduled virtual rooms for sprint planning and wrap-up sessions.

3. Prepare Your Contribution Area

  • Developers: Clone the Inkscape repository from GitLab, build the software locally following the developer documentation, and search for issues labeled "good first issue" or sprint-specific milestones.
  • Designers/UX: Review open UI/UX tickets, draft interface proposals, and provide vector assets or iconography.
  • Writers and Translators: Access the documentation repositories and translation portals (such as Weblate) to update manuals and localize the software interface.

4. Collaborate During the Event

Join the kickoff meeting to claim specific tasks, engage with experienced maintainers for guidance, open merge requests with your updates, and participate in sprint retrospective discussions.
