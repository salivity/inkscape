Automate SVG Batch Resizing with Python and Inkscape

Batch resizing SVG files using Python and the Inkscape binary allows you to programmatically scale large collections of vector graphics to specific dimensions or export formats. By using Python's subprocess module to interface directly with Inkscape's command-line interface (CLI), you can process entire directories of SVGs automatically without launching the graphical user interface.

Prerequisites

Before running the automation script, ensure you have the following installed and configured:

  1. Python 3.x: Installed on your system.
  2. Inkscape: Installed on your system.
  3. Environment Path: Ensure the Inkscape executable is added to your system's PATH. On Windows, the binary is typically located at C:\Program Files\Inkscape\bin\inkscape.exe. On macOS and Linux, it is accessible as inkscape from the terminal.

Understanding the Inkscape CLI Command

Modern versions of Inkscape (version 1.0 and later) use straightforward CLI flags for exporting files:

  • --export-filename=<path>: Specifies the output file path.
  • --export-width=<pixels> or -w <pixels>: Sets the target width.
  • --export-height=<pixels> or -h <pixels>: Sets the target height.
  • --export-plain-svg: Exports clean SVG code without Inkscape-specific metadata (optional).

Python Batch Resizing Script

The following Python script scans an input directory for .svg files, runs the Inkscape CLI command on each file, and saves the resized versions to an output directory.

import os
import subprocess
from pathlib import Path

# Configuration
INPUT_DIR = Path("./input_svgs")
OUTPUT_DIR = Path("./resized_svgs")
TARGET_WIDTH = 512   # Set target width in pixels (or None to infer from height)
TARGET_HEIGHT = 512  # Set target height in pixels (or None to infer from width)
INKSCAPE_PATH = "inkscape"  # Replace with full path if not in system PATH

def resize_svg(input_path: Path, output_path: Path, width: int = None, height: int = None):
    command = [INKSCAPE_PATH, str(input_path)]
    
    if width:
        command.extend(["-w", str(width)])
    if height:
        command.extend(["-h", str(height)])
        
    command.extend(["--export-plain-svg", "--export-filename", str(output_path)])

    try:
        result = subprocess.run(command, check=True, capture_output=True, text=True)
        print(f"Resized: {input_path.name} -> {output_path.name}")
    except subprocess.CalledProcessError as e:
        print(f"Failed to resize {input_path.name}: {e.stderr}")

def batch_resize():
    OUTPUT_DIR.mkdir(parents=True, exist_ok=True)
    
    svg_files = list(INPUT_DIR.glob("*.svg"))
    if not svg_files:
        print("No SVG files found in the input directory.")
        return

    print(f"Found {len(svg_files)} SVG files. Starting processing...")

    for file_path in svg_files:
        output_file_path = OUTPUT_DIR / file_path.name
        resize_svg(file_path, output_file_path, width=TARGET_WIDTH, height=TARGET_HEIGHT)

    print("Batch resizing complete.")

if __name__ == "__main__":
    batch_resize()

Maintaining Aspect Ratios

To maintain the aspect ratio of the original vector image:

  • Set TARGET_WIDTH and set TARGET_HEIGHT = None. Inkscape will calculate the height automatically based on the image's original viewBox.
  • Set TARGET_HEIGHT and set TARGET_WIDTH = None to scale horizontally while fixing vertical bounds.

Optimizing Speed with Inkscape Shell Mode

If you need to process thousands of SVGs, launching a new Inkscape process for every file creates overhead. Inkscape provides an interactive shell mode (inkscape --shell) that keeps a single instance running in memory. You can feed commands into the standard input stream (stdin) of the single running process to drastically reduce processing time.
