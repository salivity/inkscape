Vector Hatching vs Raster Engraving in Inkscape

This guide explains how to configure artwork in Inkscape for vector surface hatching versus traditional raster engraving on a laser cutter. Raster engraving processes solid shapes line by line across an entire area, while vector hatching generates internal geometric stroke paths that the laser traces continuously. Converting solid fills into vector hatch patterns can significantly reduce job runtimes and create distinct surface textures on your materials.

The Core Difference: Fills vs. Strokes

Laser software determines operation types primarily based on whether an element is a filled shape or a stroked path:

  • Raster Engraving: The laser head moves back and forth horizontally like an inkjet printer, pulsing over areas defined by solid fills.
  • Vector Hatching: The laser head follows discrete vector lines using standard strokes (scoring/marking). Because it traces connected vectors rather than scanning the entire bounding box, it is often substantially faster for low- to medium-density patterns.

Setting Up Shapes for Raster Engraving

To configure an object for standard raster engraving, you only need to define its solid fill:

  1. Select your object using the Select Tool (S).
  2. Open the Fill and Stroke panel (Ctrl + Shift + F or Cmd + Shift + F).
  3. In the Fill tab, click Flat color and choose a solid color (typically solid black #000000).
  4. In the Stroke paint tab, click No paint (X) to remove the outer outline.
  5. Your laser control software (such as LightBurn, LaserGRBL, or K40 Whisperer) will interpret this solid fill as an area to be rastered.

Setting Up Shapes for Vector Hatch Engraving

To perform vector hatching, you must replace the solid fill with tightly spaced vector lines enclosed inside the original shape boundary.

Step 1: Convert Objects to Native Paths

  1. Select your object.
  2. Navigate to Path > Object to Path (Ctrl + Shift + C). Text and primitive shapes (rectangles, circles) must be native paths for hatching tools to work.

Step 2: Generate Vector Hatches

Inkscape provides two main methods to generate vector hatches:

Method A: Using the Hatch Fill Extension

  1. Select the path.
  2. Navigate to Extensions > Generate from Path > Hatch Fill.
  3. Set the Hatch Spacing (the distance between lines in pixels or millimeters, depending on your document units). A smaller spacing yields a denser fill.
  4. Set the Hatch Angle (e.g., 45 degrees for diagonal lines, 0 for horizontal).
  5. Enable Crosshatch if you want two intersecting sets of lines for complete surface coverage.
  6. Click Apply and close the dialog.

Method B: Using Live Path Effects (LPE)

  1. Select the path.
  2. Navigate to Path > Path Effects.
  3. Click the Add Path Effect (+) button and select Hatches (rough).
  4. Adjust the spacing, angle, and line count in the effect options.
  5. Once satisfied, finalize the vectors by selecting Path > Object to Path.

Step 3: Configure Fill and Stroke Settings

  1. Select the generated hatch lines.
  2. In the Fill and Stroke panel:
    • Set Fill to No paint.
    • Set Stroke paint to a specific color dedicated to scoring (e.g., blue #0000FF or red #FF0000).
    • Set Stroke style width to a hairline value (such as 0.1 mm or 0.001 in).
  3. (Optional) If you want a clean border around the hatched area, keep the original boundary shape as a separate stroked outline on the same or an adjacent layer.

Laser Software Preparation

Once your SVG file is imported into your laser control software:

  1. Assign Layers: Set your hatch layer to Vector / Score / Cut mode rather than "Fill" or "Raster".
  2. Tune Settings: Vector hatching requires high movement speeds and low-to-medium power to avoid cutting through the material while still leaving an etched line.
  3. Check Defocusing: For a wider hatch mark that blends lines together smoothly, slightly defocus your laser (raise or lower the Z-bed by 1–3 mm) to thicken the focal beam diameter.
