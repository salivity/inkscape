Clean Up Unused SVG Gradients in Inkscape

When working in Inkscape, creating, editing, and deleting objects often leaves behind orphaned gradient definitions inside the SVG file's <defs> tag. This article explains how to efficiently remove these unused gradients using Inkscape's built-in cleanup tool, the XML Editor, and the Optimized SVG export setting to reduce file size and keep your SVG code organized.

Method 1: Use the "Clean Up Document" Command

The fastest and most reliable way to remove unreferenced gradients, patterns, markers, and swatches from the <defs> element is the built-in cleanup feature:

  1. Open your SVG file in Inkscape.
  2. Go to the top menu and select File > Clean Up Document (in older versions of Inkscape, this was labeled Vacuum Defs).
  3. Inkscape will automatically scan the document, compare references, and purge all unreferenced definitions from the <defs> node.
  4. Save your file (Ctrl + S or Cmd + S).

Method 2: Manually Delete via the XML Editor

If you need precise control over which definitions to remove without affecting other elements:

  1. Open the XML Editor by navigating to Edit > XML Editor or pressing Shift + Ctrl + X.
  2. In the tree view on the left, click on the <svg:svg> root node to expand it.
  3. Click on the <svg:defs> node to display all definitions.
  4. Look for <svg:linearGradient> or <svg:radialGradient> nodes.
  5. Click on an unused gradient node and press the Delete node button (trash can icon) in the XML Editor toolbar.

Method 3: Export as an Optimized SVG

To ensure all redundant code, including unused definitions, is stripped during export:

  1. Go to File > Save As... (or Shift + Ctrl + S).
  2. Choose Optimized SVG (*.svg) from the file format dropdown.
  3. In the export settings dialog, navigate to the SVG Output tab.
  4. Ensure the option Remove unused elements/attributes or Remove unused IDs is enabled.
  5. Click OK to save the optimized, cleaned-up SVG file.
