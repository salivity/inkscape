Set Custom Export DPI for Objects in Inkscape

This guide explains how to configure custom export DPI overrides for specific objects in Inkscape rather than relying on global document defaults. Whether you are preparing individual vector elements for high-resolution print or low-resolution web assets, you can control output resolution either on-the-fly using the Export dialog or permanently embed DPI parameters directly into object attributes via the XML Editor.

Method 1: Set DPI Using the Export Panel

The quickest way to export an individual object with a custom resolution is through the Export dialog.

  1. Select the object or group on your canvas that requires a custom DPI.
  2. Open the Export panel by pressing Ctrl + Shift + E (Windows/Linux) or Cmd + Shift + E (macOS), or by navigating to File > Export.
  3. Under the Single Image tab, choose the Selection mode to restrict the export boundaries solely to your selected object.
  4. Locate the Resolution (DPI) input field. By default, it is set to 96 DPI.
  5. Enter your desired custom DPI value (such as 300 DPI for high-quality print). Inkscape will automatically recalculate the pixel width and height dimensions to match.
  6. Choose your output format, select the destination path, and click Export.

Method 2: Embed Permanent DPI Attributes via the XML Editor

If you want an object to retain its custom DPI configuration permanently within the SVG code for future sessions and command-line exports, you can set the export attributes directly.

  1. Select the target object on the canvas.
  2. Open the XML Editor by pressing Ctrl + Shift + X (Windows/Linux) or Cmd + Shift + X (macOS), or by going to Edit > XML Editor.
  3. In the XML tree, confirm the node corresponding to your selected object is highlighted.
  4. In the attribute name field on the right panel, type inkscape:export-xdpi and enter your custom numeric value (e.g., 300) in the value field, then click Set.
  5. Type inkscape:export-ydpi in the attribute name field, set the same numeric value (e.g., 300), and click Set.
  6. (Optional) Set the inkscape:export-filename attribute with your preferred file path to automate output naming.
  7. Save your SVG file. Inkscape will now read these specific resolution overrides whenever the object is referenced for designated export tasks.

Method 3: Batch Exporting Multiple Objects with Custom Sizes

If you have multiple objects that require independent export configurations:

  1. Open the Export panel (Ctrl + Shift + E / Cmd + Shift + E).
  2. Switch to the Batch Export tab.
  3. Select the Selection sub-tab.
  4. Add the items you wish to export to the batch list.
  5. Define your export format and scale suffixes to generate multiple resolutions (e.g., 1x, 2x, 3x scale factors or custom DPI outputs) simultaneously for each independent object.
