How to Scale by Percentage in Inkscape

Scaling an object to exact integer percentage multiples like 200% or 300% in Inkscape cannot be reliably done through freehand canvas dragging. Instead, the most accurate method is using Inkscape's built-in Transform panel, which allows you to define numeric scaling factors and apply them proportionally to any selected vector or path.

Method 1: Using the Transform Panel (Recommended)

The Transform panel provides direct numeric control to scale selections by exact percentages.

  1. Select your object: Use the Select Tool (S or F1) and click on the object, path, or group you want to resize.
  2. Open the Transform dialog: Navigate to Object > Transform in the top menu, or press the keyboard shortcut Shift + Ctrl + M (Windows/Linux) or Shift + Cmd + M (macOS).
  3. Open the Scale tab: In the Transform panel that appears on the right, click on the Scale tab.
  4. Set units to percent: Change the measurement dropdown next to the Width and Height fields from pixels (px) or millimeters (mm) to %.
  5. Lock proportions: Check the Scale proportionally box so changes apply equally to both dimensions.
  6. Enter the target value: Type your desired integer multiple into the Width or Height field (e.g., enter 200 to double the size, or 300 to triple it).
  7. Apply the scale: Click the Apply button at the bottom of the panel.

Method 2: Setting Custom Scaling Steps via Keyboard Shortcuts

If you frequently need to scale objects by a fixed percentage increment using keyboard shortcuts, you can configure Inkscape’s step preferences.

  1. Open Preferences by going to Edit > Preferences or pressing Ctrl + Shift + P.
  2. Navigate to Behavior > Steps in the left-hand menu.
  3. Locate the Scale by: field. Enter your desired increment (for example, entering 200 % or a factor to double size).
  4. Close the Preferences window.
  5. Select your object and press > (Scale up) or < (Scale down) to resize the object by that fixed amount.
