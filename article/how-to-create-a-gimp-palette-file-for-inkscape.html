How to Create a GIMP Palette File for Inkscape

Creating a custom GIMP Palette (.gpl) file for Inkscape allows you to access project-specific color schemes and consistent brand colors directly within your workspace. Because Inkscape natively reads the GIMP palette format, you can generate your own palette using any plain text editor, save it with the .gpl extension, and place it into Inkscape’s user configuration folder for immediate use.

Understanding the .gpl File Format

A .gpl file is an unformatted plain text file that follows a strict structure: a header defining the file type and palette name, an optional column setting, a separator, and a list of RGB values.

The format is structured as follows:

GIMP Palette
Name: Brand Colors
Columns: 4
#
255   0   0   Primary Red
  0 255   0   Primary Green
  0   0 255   Primary Blue
 34  34  34   Dark Charcoal
  • Line 1: Must read GIMP Palette. This is the signature required for software to recognize the file.
  • Line 2: Name: [Your Palette Name]. This defines the name that appears in Inkscape's palette menu.
  • Line 3: Columns: [Number]. Specifies how many columns wide the palette displays in the user interface (default is typically 4 or 0).
  • Line 4: #. A comment line indicating the start of the color list.
  • Data Lines: Three integer values ranging from 0 to 255 representing Red, Green, and Blue channels, separated by spaces or tabs, followed by an optional color name.

Step 1: Create and Save the File

  1. Open a basic text editor such as Notepad (Windows), TextEdit in plain text mode (macOS), or a code editor like VS Code.
  2. Add the required header lines: 
    GIMP Palette
Name: My Project Palette
Columns: 4
#
  3. Convert your project colors into standard 8-bit RGB decimal values (0–255).
  4. List each color on a new line with its Red, Green, and Blue values followed by a label.
  5. Save the file. Ensure the file extension is changed from .txt to .gpl (for example, my_palette.gpl). When saving, choose UTF-8 encoding.

Step 2: Install the Palette in Inkscape

To make the palette available in Inkscape, copy the .gpl file into your local user palettes directory:

  1. Open Inkscape.
  2. Navigate to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. Select System from the left-hand navigation pane.
  4. Locate the path listed next to User palettes.
  5. Click the Open icon next to the path to launch the directory in your file manager.
  6. Paste your .gpl file into this palettes folder.

Step 3: Load the Palette

  1. Restart Inkscape to ensure it indexes the new file.
  2. Locate the color palette bar along the bottom of the Inkscape window.
  3. Click the small arrow icon on the far-right edge of the palette strip to open the palette selection menu.
  4. Select your custom palette from the list by the name you defined on the Name: line in your file.
