Add SVG Title and Desc Tags to Subpaths in Inkscape

Making vector graphics accessible requires semantic metadata that assistive technologies can interpret. This guide explains how to attach <title> and <desc> elements to specific paths and subpaths in Inkscape using the Object Properties panel and the XML Editor. By isolating subpaths and assigning dedicated titles and descriptions, you can provide fine-grained, accessible descriptions for complex vector illustrations.

1. Separate Subpaths into Distinct Path Elements

In SVG specifications, a single compound path (created via Path > Combine) shares a single <path> element in the DOM. Screen readers cannot announce individual subpaths within one <path> node. To provide fine-grained accessibility:

  1. Select the compound path.
  2. Go to Path > Break Apart (Shift + Ctrl + K) to convert individual subpaths into standalone path objects.
  3. If specific subpaths represent a single logical component, select them and press Ctrl + G to group them.

2. Add Title and Description via Object Properties

The Object Properties panel offers the quickest graphical interface for adding metadata:

  1. Select the specific path or group.
  2. Open the panel by navigating to Object > Object Properties (Shift + Ctrl + O).
  3. Locate the Title and Description fields.
  4. Enter a concise label in the Title field (acts as the accessible name).
  5. Enter extended details in the Description field (acts as the accessible description).
  6. Click the Set button to apply the changes to the SVG markup.

3. Add Fine-Grained Tags via the XML Editor

For precise control over SVG markup and namespace validation, use the built-in XML Editor:

  1. Open the XML Editor by navigating to Edit > XML Editor (Shift + Ctrl + X).
  2. In the canvas, select the path element you wish to annotate; it will be highlighted in the XML tree.
  3. Create the <title> element:
    • Select the parent <svg:path> or <svg:g> node in the tree.
    • In the XML toolbar, click New element node.
    • Enter svg:title as the node name and click Create.
    • Select the newly created <svg:title> node, click New text node, enter your short title, and click Set.
  4. Create the <desc> element:
    • Select the parent <svg:path> or <svg:g> node again.
    • Click New element node, enter svg:desc, and click Create.
    • Select the newly created <svg:desc> node, click New text node, enter your detailed description, and click Set.

4. Ensure Screen Reader Compatibility with ARIA Attributes

Browsers and screen readers vary in how natively they support standard SVG <title> and <desc> child elements. To maximize compatibility:

  1. In the XML Editor, select the path or group node.
  2. Ensure the <title> and <desc> nodes have unique id attributes (e.g., id="part1-title" and id="part1-desc").
  3. Add ARIA reference attributes to the parent path or group:
    • Attribute name: aria-labelledby, Attribute value: part1-title
    • Attribute name: aria-describedby, Attribute value: part1-desc
    • Attribute name: role, Attribute value: img (or graphics-symbol)
  4. Click Set for each attribute.

When exported as a standard SVG, screen readers traversing the DOM will announce the specified path or component using the assigned title and description.
