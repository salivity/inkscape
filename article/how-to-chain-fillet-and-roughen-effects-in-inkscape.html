How to Chain Fillet and Roughen Effects in Inkscape

Inkscape allows you to combine multiple Live Path Effects (LPEs) on a single object in a non-destructive pipeline. By stacking the Corners (Fillet/Chamfer) effect first and placing the Roughen effect immediately beneath it in the Path Effects stack, Inkscape rounds your vector geometry before distorting the newly shaped edges, leaving your original base path entirely editable.

Step 1: Open the Path Effects Dialog

  1. Select the vector path you want to modify using the Select tool (S) or Node tool (N).
  2. Open the Live Path Effects panel by navigating to Path > Path Effects in the top menu.

Step 2: Apply the Fillet/Chamfer Effect

  1. In the Path Effects dialog, click the Add Path Effect button (the + icon).
  2. Search for or select Corners (Fillet/Chamfer).
  3. Switch to the Node tool (N). Drag the green circular handles on the path's nodes to adjust the corner radius, or modify the radius values directly in the Path Effects dialog.

Step 3: Add the Roughen Effect to the Stack

  1. With the same object selected, click the Add Path Effect (+) button again.
  2. Search for and select Roughen.
  3. Inkscape evaluates path effects from top to bottom. Confirm that Corners (Fillet/Chamfer) is at the top of the stack and Roughen is positioned below it. If needed, use the up/down arrows in the Path Effects panel to reorder them.

Step 4: Fine-Tune the Stack

  1. Select the Roughen item in the Path Effects list.
  2. Adjust the parameters such as Method, Max displacement, and Frequency to dial in the texture along the filleted edges.
  3. To alter the underlying structure, use the Node tool to move original anchor points. The filleting and edge roughening will recalculate automatically in real time without permanently converting the geometry.
