How to Customize Keyboard Shortcuts in Inkscape

Customizing keyboard shortcuts in Inkscape allows you to streamline your vector design workflow by remapping default keys or assigning new combinations to your most frequently used tools. This guide covers how to access Inkscape’s built-in keyboard configuration menu, search for specific commands, assign custom keybindings, resolve shortcut conflicts, and switch between preset keyboard layouts.

Step 1: Open the Keyboard Preferences Menu

  1. Launch Inkscape.
  2. Navigate to the top menu bar and select Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left-hand sidebar of the Preferences window, expand the Interface category and click on Keyboard.

Step 2: Locate the Command You Want to Modify

The Keyboard settings panel displays a categorized list of all available commands, tools, and actions in Inkscape.

  • Browse Categories: Expand folders such as File, Edit, Object, Path, or Tools to find the specific operation.
  • Search Directly: Use the Search bar at the top of the panel to quickly find a command by typing its name (e.g., "Duplicate", "Bezier", or "Group").

Step 3: Assign or Edit a Shortcut

  1. Find the target command in the list.
  2. Click directly on the row under the Shortcut column for that command. The cell will display a prompt indicating it is listening for user input (typically showing Press keys... or New accelerator...).
  3. Press the exact key or key combination you wish to assign on your keyboard (for example, Alt + D or F4).
  4. Inkscape will automatically record and apply the new combination.

Step 4: Handle Shortcut Conflicts and Removals

  • Overwriting Conflicts: If the key combination you entered is already in use by another function, a warning dialog will appear. You can choose to overwrite the existing shortcut or cancel the operation to choose a different combination.
  • Removing a Shortcut: To delete an assigned shortcut, click on the command in the list to highlight it and press Backspace or Delete, or click the Clear button if visible.

Step 5: Using Predefined Shortcut Profiles

Inkscape includes built-in shortcut configurations that mimic other popular graphic design software, making the transition easier for new users.

  1. At the top of the Keyboard preferences page, locate the Keyboard shortcut file or Preset dropdown menu.
  2. Select an alternative layout such as Adobe Illustrator, CorelDRAW, or Inkscape default.
  3. The interface will instantly map commands according to the selected profile.

All changes take effect immediately without requiring a restart of the application. Custom configurations are saved to your local Inkscape user profile directory as an XML file.
