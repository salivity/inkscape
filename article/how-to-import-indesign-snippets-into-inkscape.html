How to Import InDesign Snippets into Inkscape

Importing vector graphics from Adobe InDesign interchange snippets (.idms) into Inkscape requires converting the snippet data into a format that Inkscape natively supports. Because InDesign snippets are proprietary XML-based files describing InDesign elements, Inkscape cannot parse them directly. This guide details the most effective, lossless methods to transfer your vector artwork from an InDesign snippet into Inkscape using standard vector interchange formats like PDF and SVG.

Method 1: Exporting via InDesign (Recommended)

The most reliable way to retain paths, points, strokes, and color accuracy is to export the snippet content through InDesign as an intermediate vector file.

  1. Open InDesign: Launch Adobe InDesign and create a new blank document.
  2. Place the Snippet: Go to File > Place (or press Ctrl + D on Windows / Cmd + D on macOS), select your .idms file, and click anywhere on the canvas to drop the artwork.
  3. Select the Graphics: Use the Selection Tool to select only the vector objects you want to export.
  4. Export as PDF:
    • Go to File > Export.
    • Set the Format dropdown to Adobe PDF (Print) and choose a destination.
    • In the export settings, select the High Quality Print preset. Under the General panel, set the export range to the current page or ensure your artwork fits cleanly on the page.
  5. Import into Inkscape:
    • Open Inkscape.
    • Go to File > Import and select the exported PDF.
    • In the PDF Import dialog, select Internal import (or Poppler/Cairo) for standard vector handling.
    • Click OK. Ungroup the imported objects (Ctrl + Shift + G or Cmd + Shift + G) to edit individual paths.

Method 2: Direct Copy and Paste

If you only need a quick transfer and have InDesign open, you can bypass saving files entirely by utilizing system clipboard vector transfer.

  1. Configure InDesign Preferences:
    • Go to Edit > Preferences > Clipboard Handling (Windows) or InDesign > Preferences > Clipboard Handling (macOS).
    • Ensure Copy PDF to Clipboard is checked.
  2. Copy the Vector Objects: Place the .idms snippet into an InDesign layout, select the vector elements, and press Ctrl + C (Windows) or Cmd + C (macOS).
  3. Paste into Inkscape: Switch to an active Inkscape canvas and press Ctrl + V (Windows) or Cmd + V (macOS). Inkscape will interpret the clipboard PDF data directly as editable vector paths.

Method 3: Converting via Adobe Illustrator

If you need native SVG output before opening the asset in Inkscape, use Illustrator as an intermediate processor:

  1. Open Adobe Illustrator.
  2. Drag and drop the .idms snippet or place it via File > Place.
  3. Go to File > Save As or File > Export > Export As, and select SVG (*.SVG).
  4. Launch Inkscape, go to File > Open, and select your new SVG file for direct editing.
