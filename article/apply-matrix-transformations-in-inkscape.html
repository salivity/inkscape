Apply Matrix Transformations in Inkscape

Applying matrix transformations in Inkscape allows you to perform advanced geometric manipulations—including custom scaling, rotation, skewing, and translation—through a single mathematical operation. This guide walks you through accessing the Transform dialog, understanding the 2D affine transformation matrix values, and applying custom matrix parameters directly to any selected vector object.

Step 1: Open the Transform Dialog

  1. Select the object, path, or group you want to modify using the Select tool (S or F1).
  2. Open the Transform panel by navigating to Object > Transform... from the top menu, or by pressing the keyboard shortcut Shift + Ctrl + M.

Step 2: Select the Matrix Tab

In the Transform panel that appears on the right side of the screen, click the Matrix tab located on the far right.

Step 3: Enter the Matrix Values

The Transform panel displays a 2D affine transformation matrix represented by six input fields arranged in a 3x2 grid:

  • A (Row 1, Column 1): Controls horizontal scaling and contributes to rotation/shear.
  • B (Row 2, Column 1): Controls vertical skew and contributes to rotation.
  • C (Row 1, Column 2): Controls horizontal skew and contributes to rotation.
  • D (Row 2, Column 2): Controls vertical scaling and contributes to rotation/shear.
  • E (Row 1, Column 3): Controls horizontal translation (movement along the X-axis).
  • F (Row 2, Column 3): Controls vertical translation (movement along the Y-axis).

(Note: The bottom row of an SVG transformation matrix is always implicitly fixed as 0, 0, 1 and is omitted from the UI).

Step 4: Configure Matrix Application Settings

Before applying the matrix, configure the execution behavior using the checkboxes at the bottom of the panel:

  • Edit current matrix: When checked, the entered values replace the object's existing transformation matrix. When unchecked, the new matrix is multiplied with the existing matrix, applying it cumulatively.
  • Apply to each object separately: If multiple objects are selected, checking this option applies the transformation relative to each individual object's origin rather than the common selection bounding box.

Step 5: Apply the Transformation

Click the Apply button at the bottom of the panel. Inkscape will calculate the transformation and update the SVG transform="matrix(...)" attribute on the selected element.
