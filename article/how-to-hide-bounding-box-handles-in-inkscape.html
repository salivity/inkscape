How to Hide Bounding Box Handles in Inkscape

This guide explains how to hide bounding box and transformation handles around selected vector objects in Inkscape. While Inkscape does not feature a dedicated default toggle shortcut like Adobe Illustrator's Ctrl + Shift + B, users can quickly hide these handles without losing their object selection by using quick tool shortcuts or adjusting tool preferences. The following sections outline the quickest keyboard shortcuts and settings to view vector artwork unobstructed.

The Fastest Shortcut: Switch to the Dropper Tool (D or F7)

The most effective and widely used shortcut method to hide bounding box handles while keeping an object actively selected is switching tools using the keyboard:

  1. Select your object with the Select Tool (S or F1).
  2. Press D (or F7) to activate the Dropper Tool.

When you switch to the Dropper tool, the selection remains completely active, but the bounding box, directional arrows, and transformation handles vanish instantly. You can still apply colors from the palette, view strokes clearly, and keep track of object properties. To bring the handles back, press S or F1 to return to the Select Tool.

Alternative Quick Switch: The Zoom Tool (Z)

Pressing Z activates the Zoom Tool. Like the Dropper tool, the Zoom tool retains your active object selection while removing all transform handles and bounding indicators from the canvas, allowing you to inspect line weights, alignments, and details cleanly.

Disabling Transform Handles Permanently in Preferences

If you want to work with objects without transformation arrows cluttering the canvas in the Select Tool, you can disable them in the application settings:

  1. Open the Preferences window by pressing Ctrl + Shift + P (or navigate to Edit > Preferences).
  2. In the left sidebar, expand Tools and click on Selector.
  3. Uncheck the box labeled Show transform handles.

With this option disabled, selected objects will still show a simple dashed bounding box indicating they are active, but the bulky resizing and rotation arrows will remain hidden. You can re-enable the handles at any time by returning to this menu and checking the box.

Assigning a Custom Shortcut

To toggle selection cues or on-canvas controls more dynamically, you can assign custom key combinations:

  1. Navigate to Edit > Preferences > Interface > Keyboard Shortcuts.
  2. Use the search bar to look for Selection cue or Handles.
  3. Select the desired command and press your preferred key combination to assign a direct toggle shortcut tailored to your workflow.
