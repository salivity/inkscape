How to Add, Delete, and Rearrange Pages in Inkscape

Inkscape provides native multi-page support that allows you to manage multiple artboards within a single document. Using the dedicated Page Tool, you can quickly insert new pages, remove unwanted ones, and reorganize your document layout to suit projects like brochures, multi-screen UI designs, or print collateral.

Accessing the Page Tool

To manage pages, you must activate the Page Tool. You can find the Create and Edit Document Pages icon near the bottom of the left-hand toolbar, or you can press the keyboard shortcut Shift + P.

How to Add Pages

  1. Activate the Page Tool (Shift + P).
  2. To add a standard page, click the Create a new page button in the tool control bar at the top of the screen. This creates a new page adjacent to the active page matching its default dimensions.
  3. Alternatively, click and drag anywhere on the canvas to draw a page with a custom size.
  4. You can also duplicate an existing page by selecting it and clicking the Duplicate page button in the control bar.

How to Delete Pages

  1. Activate the Page Tool (Shift + P).
  2. Click inside the border of the page you want to remove to select it. A selected page will display a highlighted border.
  3. Press the Delete or Backspace key on your keyboard, or click the Delete selected page button in the top tool control bar.
  4. Note: Deleting a page removes the canvas boundary, but objects placed on that page will remain on the canvas unless you delete them manually.

How to Rearrange Pages

Moving Page Positions on the Canvas

  1. Activate the Page Tool (Shift + P).
  2. Click the page you wish to move.
  3. Click and drag the page to a new location on the canvas.
  4. To move the artwork along with the page, ensure the Move overlapping objects toggle is enabled in the top tool control bar before dragging.

Changing Page Order (Page Numbering)

  1. Select the page whose order you want to change using the Page Tool.
  2. In the top tool control bar, locate the page number field.
  3. Adjust the order by typing a new number or using the move-forward/move-backward buttons to reorder the page sequence for export and multi-page PDF generation.
