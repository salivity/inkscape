Assign Pantone Names to Swatches in Inkscape

While Inkscape lacks native, proprietary Pantone color libraries due to licensing restrictions, you can accurately assign specific Pantone names to custom swatches for pre-press workflows. This guide explains how to convert RGB or CMYK approximations into named swatches directly within Inkscape, assign precise Pantone labels using the XML Editor, and create reusable custom palette files.

Method 1: Create and Label Swatches in the Swatches Dialog

  1. Draw and Color an Object: Draw any shape and use the Fill and Stroke dialog (Ctrl + Shift + F) to set the color to your desired Pantone approximation (RGB or CMYK values).
  2. Convert to a Swatch: In the Fill tab, click the Swatch icon (a grid of colored squares next to the gradient icons). This converts the solid color into an SVG swatch definition.
  3. Open the Swatches Dialog: Go to Object > Swatches (Ctrl + Shift + W) to view document swatches.
  4. Rename the Swatch: Right-click the newly created swatch in the panel and select Edit. Change the label or name field to your exact Pantone designation (for example, PANTONE 186 C).

Method 2: Assign Pantone Labels Using the XML Editor

To ensure downstream pre-press processors read the swatch metadata reliably, assign the name directly to the SVG swatch definition:

  1. Open the XML Editor by pressing Ctrl + Shift + X or navigating to Edit > XML Editor.
  2. In the tree view, expand the <svg:svg> element and locate the <svg:defs> container.
  3. Find your swatch, which is typically stored as a <svg:linearGradient> element containing your color stop.
  4. Select the gradient node, then locate or add the inkscape:label attribute in the right-hand panel:
    • Attribute Name: inkscape:label
    • Attribute Value: PANTONE [Number] [Suffix] (e.g., PANTONE Reflex Blue C)
    • Click Set.
  5. Optionally, modify the id attribute to match (e.g., swatch_PANTONE_186_C) to make reference easy inside the document structure.

Method 3: Build a Custom Pantone .gpl Palette File

If you frequently use the same set of Pantone colors, load them as an external palette:

  1. Open a plain text editor and create a file formatted for GIMP/Inkscape palettes: 
    GIMP Palette
Name: Custom Pantone
Columns: 4
#
200  16  46 PANTONE 186 C
  0  20 137 PANTONE Reflex Blue C
254 209   0 PANTONE Yellow C
  2. Save the file with a .gpl extension (for example, PantoneCustom.gpl).
  3. Place the file into your Inkscape palettes folder:
    • Windows: %APPDATA%\inkscape\palettes\
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes/
    • Linux: ~/.config/inkscape/palettes/
  4. Restart Inkscape, click the arrow icon in the bottom-right corner of the color palette bar, and select your custom palette name. Hovering over each swatch will display the exact Pantone designation.
