Export Inkscape Vectors to Keynote Shapes

Exporting vector graphics from Inkscape into Apple Keynote as editable shapes allows you to resize graphics without losing quality and customize individual elements directly within your presentation. This guide outlines the fastest and most reliable method to transition your artwork from Inkscape's native SVG format into Keynote's native vector shape system using modern SVG import and shape separation features.

Step 1: Prepare Your Artwork in Inkscape

Before exporting, ensure your vector graphic is structured properly so Keynote can interpret each component correctly:

  1. Select your entire design by pressing Ctrl + A (or Cmd + A on Mac).
  2. Convert all text to paths by navigating to Path > Object to Path. This prevents missing font issues in Keynote.
  3. If you have strokes you want to scale proportionally, convert them to fills by selecting Path > Stroke to Path.
  4. Group related elements logically, or ungroup deeply nested groups using Ctrl + Shift + G to avoid parsing errors.

Step 2: Export as a Plain SVG

Inkscape uses a specialized SVG format containing software-specific metadata. For the best compatibility with Keynote, export a clean SVG file:

  1. Go to File > Save As... (or press Ctrl + Shift + S).
  2. In the file type dropdown menu, select Plain SVG (*.svg) instead of Inkscape SVG.
  3. Choose your destination folder and click Save.

Step 3: Import the File into Keynote

Recent versions of Apple Keynote support direct vector import:

  1. Open your Keynote presentation and navigate to the desired slide.
  2. Drag and drop the saved Plain SVG file directly from your file manager onto the slide canvas. Alternatively, go to Insert > Choose..., select your SVG file, and click Insert.

Step 4: Convert the Graphic to Editable Keynote Shapes

Once imported, the graphic acts as a single vector image. To convert it into editable Keynote shapes:

  1. Click on the imported SVG to select it.
  2. Right-click (or Control-click) the object and select Break Apart from the context menu. You can also access this via the top menu by selecting Format > Shapes and Lines > Break Apart.
  3. Keynote will instantly convert the vector graphic into individual native shapes.

You can now select, recolor, resize, apply styles, or animate individual elements within the illustration using Keynote's standard Format inspector.
