What is Spiro Path Mode in Inkscape?

Spiro path mode is a path creation setting available in Inkscape's Draw Freehand Lines (Pencil) and Draw Bezier Curves (Pen) tools that automatically generates ultra-smooth, flowing curves based on clothoid spirals. Instead of requiring you to manually adjust Bezier direction handles to smooth out transitions, Spiro mode dynamically calculates the curve so that curvature changes continuously between nodes, preventing harsh kinks and unnatural bumps.

How Spiro Path Mode Works

When you draw in standard Bezier mode, curves are determined by cubic Bezier segments controlled by individual node handles. Spiro path mode replaces this behavior with a mathematical model based on Euler spirals (clothoids).

When active, the path automatically routes through the points you place with continuous curvature (G2 continuity). This means the curve transitions smoothly from straight lines into bends without sudden shifts in radius, mirroring the natural physics of bending a flexible strip of metal or wood.

Enabling and Using the Mode

You can find the Spiro option in the Tool Controls Bar at the top of the canvas when either the Pen (B) or Pencil (P) tool is selected:

  1. Select the Pen or Pencil tool.
  2. In the top toolbar under the Mode section, click the Create Spiro path icon (a smooth, swirling line).
  3. Click on the canvas to place your nodes. Inkscape will automatically compute the smooth curve connecting them in real-time.

Node Control and Editing

Paths drawn with Spiro mode use the Node Tool (N) differently than standard paths:

  • Smooth Nodes: Default nodes act as anchor points through which the curve glides seamlessly. Moving a single node recalculates the entire curve across adjacent segments.
  • Cusp/Corner Nodes: Changing a node to a cusp allows you to create sharp angles within an otherwise fluid, curved shape.
  • No Manual Handles: You do not need to drag directional handles; the shape is defined purely by node positions and node types.

Live Path Effect Integration

Spiro mode operates non-destructively as a Live Path Effect (LPE). Behind the scenes, Inkscape applies the Spiro spline effect to a basic polygonal path.

Because it is an LPE, you can:

  • Modify the underlying skeleton path at any time using the Node tool.
  • Switch the path back to a standard Bezier path via the Path > Path Effects panel.
  • Permanently convert the Spiro curve into a standard Bezier path by selecting Path > Object to Path.

Best Use Cases

  • Typography and Lettering: Creating balanced, sweeping character stems and flourishes.
  • Logo Design: Drawing perfectly proportioned geometric and organic curves.
  • Line Art and Inking: Achieving clean, professional contour lines without the wobbles of freehand drawing.
  • Technical Illustration: Routing smooth paths, tracks, or pipelines where consistent curvature radius is required.
