Align Object to Top-Left of Page in Inkscape

This guide demonstrates how to position any object directly against the top-left corner or margins of your current page in Inkscape. By utilizing the Align and Distribute panel or the coordinate inputs on the Tool Controls bar, you can achieve pixel-perfect placement quickly and accurately.

Method 1: Using the Align and Distribute Panel

The most efficient way to position an object relative to the page boundary is by using the alignment dialog.

  1. Select the Object: Click on the object you wish to reposition using the Select and Transform Objects tool (S or F1).
  2. Open the Align and Distribute Panel: Press Shift + Ctrl + A (or Shift + Cmd + A on macOS), or navigate to Object > Align and Distribute in the top menu.
  3. Set the Reference Point: Locate the Relative to: dropdown menu at the top of the panel and select Page.
  4. Align to the Left: Click the Align left edges of objects to the left edge of the anchor icon.
  5. Align to the Top: Click the Align top edges of objects to the top edge of the anchor icon.

The object will immediately move to the absolute top-left corner of the page boundary.

Method 2: Using X and Y Coordinate Inputs

You can also position an object precisely using numerical coordinates in the top toolbar.

  1. Select the Object: Use the Select and Transform Objects tool (S) to select the object.
  2. Check the Anchor Point: Look at the Tool Controls bar along the top. Ensure the measurement units (e.g., px, mm, or in) match your page units.
  3. Set the Bounding Box Origin: In modern versions of Inkscape, the coordinate origin (0,0) is located at the top-left of the page canvas.
  4. Enter the Coordinates:
    • In the X: input field, type 0 and press Enter.
    • In the Y: input field, type 0 and press Enter.

The top-left corner of the object's bounding box will now sit directly at the top-left origin of the canvas.
