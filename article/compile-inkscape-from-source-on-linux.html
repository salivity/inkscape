Compile Inkscape from Source on Linux

Compiling Inkscape from source code on Linux allows you to test the latest developmental features, evaluate patches, and create optimized builds tailored to your system. This guide provides a direct, step-by-step walkthrough covering the installation of prerequisite build dependencies, cloning the official Git repository, configuring the environment with CMake, compiling with Ninja, and running the resulting binary.

Step 1: Install Prerequisites and Dependencies

Before compiling, you must install developer tools (such as Git, CMake, and a C++ compiler) along with Inkscape's library dependencies.

On Ubuntu and Debian-based Distributions

Enable source repositories in your package manager settings, then install the build dependencies:

sudo apt update
sudo apt install -y git cmake ninja-build build-essential
sudo apt build-dep -y inkscape

If apt build-dep is not available, manually install key libraries including libgtkmm-3.0-dev, libboost-all-dev, libgsl-dev, libpoppler-glib-dev, and libpoppler-private-dev.

On Fedora

sudo dnf install -y git cmake ninja-build gcc-c++
sudo dnf builddep -y inkscape

On Arch Linux

sudo pacman -S --needed base-devel git cmake ninja boost gtkmm3 gsl poppler-glib libsoup libcdr libvisio libwpg

Step 2: Clone the Inkscape Repository

Clone the official Inkscape repository from GitLab, ensuring you recursively fetch all required submodules:

git clone --recurse-submodules https://gitlab.com/inkscape/inkscape.git
cd inkscape

If you already cloned without submodules, initialize them using:

git submodule update --init --recursive

Step 3: Configure the Build Directory

Create a dedicated build directory to keep source files isolated from compilation artifacts:

mkdir build
cd build

Configure the project using CMake. Using the Ninja build system is recommended for faster compilation:

cmake -G Ninja ..

To install Inkscape to a custom prefix rather than system-wide directories, append -DCMAKE_INSTALL_PREFIX=/path/to/location to the command above.

Step 4: Compile the Source Code

Start the compilation process with Ninja:

ninja

To utilize all available CPU cores automatically, Ninja handles parallel jobs by default. If you prefer using standard Make instead of Ninja, run cmake .. in the configuration step followed by make -j$(nproc).

Step 5: Run or Install the Compiled Binary

Once the build finishes successfully, you can run Inkscape directly from the build directory without installing it system-wide:

bin/inkscape

If you wish to install the compiled version to your system:

sudo ninja install
