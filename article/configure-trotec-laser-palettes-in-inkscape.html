Configure Trotec Laser Palettes in Inkscape

This guide provides a direct walkthrough on setting up and using Trotec laser color palettes within Inkscape. By matching Inkscape’s color swatches and line weights to the specific RGB values recognized by Trotec JobControl, you can seamlessly assign laser operations—such as cutting, scoring, and engraving—as well as configure speed and power parameters for each element of your design.

1. Understand Trotec Color Mapping

Trotec JobControl recognizes 16 specific RGB colors to assign processing types (cut, engrave, or skip) and cutting parameters (speed, power, and frequency). The primary colors used include:

  • Black: RGB (0, 0, 0) – Typically used for standard raster engraving.
  • Red: RGB (255, 0, 0) – Standard for vector cutting.
  • Blue: RGB (0, 0, 255) – Standard for vector scoring or secondary cutting.
  • Green: RGB (0, 255, 0)
  • Cyan: RGB (0, 255, 255)
  • Magenta: RGB (255, 0, 255)
  • Yellow: RGB (255, 255, 0)

All colors must be 100% saturated in the RGB color space without transparency (alpha set to 255).

2. Install the Trotec Palette in Inkscape

Inkscape uses standard GIMP Palette (.gpl) files for color swatches. To add the Trotec palette:

  1. Locate or create a Trotec.gpl file containing the 16 exact RGB values utilized by Trotec.
  2. In Inkscape, go to Edit > Preferences > System.
  3. Locate the User palettes directory path.
  4. Open this folder on your computer:
    • Windows: %APPDATA%\inkscape\palettes
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes
    • Linux: ~/.config/inkscape/palettes
  5. Place the Trotec.gpl file into the folder.
  6. Restart Inkscape to load the new file.

3. Activate the Palette

  1. Open your project in Inkscape.
  2. Look at the bottom color palette bar and click the small arrow icon on the far right.
  3. Scroll through the list and select your installed Trotec palette.
  4. The color bar will now display only the exact RGB colors calibrated for Trotec processing.

4. Set Line Width and Object Colors

Trotec JobControl distinguishes between engraving and vector cutting based on stroke width:

  1. Select your vector path.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F or Cmd + Shift + F).
  3. Set Fill to "No paint" (unless the object is meant to be raster-engraved).
  4. In the Stroke paint tab, click a color from your Trotec palette (e.g., pure Red for cutting).
  5. In the Stroke style tab, change the units to millimeters (mm) or inches (in).
  6. Set the line width to 0.001 mm (or up to 0.05 mm / hairline). JobControl will only recognize lines as vector cuts if they are hairline-thin.

5. Configure Speed and Power in Trotec JobControl

  1. Print the design to the Trotec printer driver (File > Print > select Trotec Engraver).
  2. Open JobControl and load the print job onto the plate.
  3. Open the Material Database (the plate icon with tools).
  4. Find the color entries matching your design (e.g., Red, Blue, Black).
  5. For each color used:
    • Set the Process Type to Cut or Engrave.
    • Enter the Power percentage.
    • Enter the Speed percentage.
    • Set the Frequency (Hz) according to your material.
  6. Click Save and run the job. The machine will process each path using the precise speed and power values mapped to its corresponding color.
