Extract Individual Faces from a 3D Box in Inkscape

Inkscape’s 3D Box tool creates dynamic, perspective-controlled objects comprised of six individual polygon paths. This guide explains how to convert a parametric 3D box into standard vector shapes and extract its individual polygon faces for independent editing, styling, or exporting.

Method 1: Ungrouping the 3D Box

The most direct way to separate all faces into standalone vector paths is by ungrouping the 3D box element.

  1. Select the 3D Box: Click on the 3D box using the Select and Transform objects tool (S or F1).
  2. Ungroup the Object: Navigate to the top menu and select Object > Ungroup, or press Ctrl + Shift + G (Windows/Linux) or Cmd + Shift + G (macOS).
  3. Separate the Polygons: Ungrouping converts the dynamic 3D box into six distinct 2D path objects (representing the front, back, top, bottom, left, and right faces). Click outside the object to deselect everything, then click and drag any individual face to separate it from the rest.

Method 2: Selecting Individual Faces Without Ungrouping

If you want to modify, copy, or extract a specific face while keeping the parametric 3D box intact, you can target child paths directly.

  1. Direct Selection (Ctrl + Click): Switch to the Select and Transform objects tool (S). Hold Ctrl and click directly on the specific face you want to isolate.
  2. Copy or Cut the Face: Press Ctrl + C to copy or Ctrl + X to cut the selected face.
  3. Paste Outside the Group: Click anywhere on the empty canvas and press Ctrl + V to paste the face as an independent polygon.

Method 3: Using the Node Tool

  1. Switch to Node Tool: Select the Edit paths by nodes tool (N or F2).
  2. Select a Face: Click on the specific plane you wish to manipulate. The bounding nodes of that specific polygon will become visible.
  3. Duplicate the Path: Press Ctrl + D to duplicate the selected face path. You can now switch back to the Selector tool (S) and move the duplicated polygon away from the 3D box.

Working with the Extracted Faces

Once extracted, each face functions as a standard four-node closed path. You can freely change fill colors, apply gradients, adjust stroke settings, modify corner nodes with the Node Tool, or delete unseen rear faces to optimize your SVG file size.
