How to Install Inkscape AppImage on Linux

This guide provides a straightforward walkthrough on how to set up and run Inkscape on any Linux distribution using the AppImage format. You will learn how to download the official AppImage file, grant it the necessary execution permissions, and launch the application directly without altering system files or requiring root privileges.

Step 1: Download the Inkscape AppImage

  1. Open your web browser and navigate to the official Inkscape website.
  2. Go to the download section and select the Linux platform.
  3. Choose the AppImage format to download the .AppImage file to your local computer (usually saved in your Downloads directory).

Step 2: Make the AppImage Executable

Before you can run the AppImage, you must grant it executable permissions. You can do this using either the graphical interface or the command line.

Method A: Using the Graphical User Interface (GUI)

  1. Open your file manager and navigate to the folder containing the downloaded .AppImage file.
  2. Right-click the Inkscape file and select Properties.
  3. Go to the Permissions tab.
  4. Check the box labeled Allow executing file as program (or set Access to "Read and Write / Executable" depending on your desktop environment).
  5. Close the Properties window.

Method B: Using the Terminal

  1. Open your terminal.
  2. Navigate to the directory where the file is stored: 
    cd ~/Downloads
  3. Run the following command to make the file executable (replace filename.AppImage with the exact name of the file you downloaded): 
    chmod +x Inkscape*.AppImage

Step 3: Run Inkscape

Once permissions are set, you can launch Inkscape immediately:

  • From the GUI: Double-click the .AppImage file in your file manager.
  • From the Terminal: Run the application directly with the command: 
    ./Inkscape*.AppImage

Optional: Desktop Integration

If you want Inkscape to appear in your application menu, you can use a utility like AppImageLauncher or manually move the file to a dedicated directory such as ~/Applications and create a custom .desktop shortcut.
