Apply Custom Color Ramps to Paths in Inkscape

Transforming grayscale artwork into vibrant vector graphics can be achieved efficiently in Inkscape by mapping color ramps to paths using extensions. This guide covers how to prepare your grayscale vector paths, apply linear two-tone color ramps using Inkscape's native Color extension, and utilize specialized ramp scripts to remap tonal values across multiple paths simultaneously.

1. Prepare Grayscale Paths

Before applying any extension, ensure your source objects are vector paths with standardized grayscale fill or stroke values:

  1. Select your artwork and convert all shapes to paths via Path > Object to Path.
  2. If your paths are grouped, ungroup them using Object > Ungroup (or Ctrl + Shift + G) so the extension can read individual path properties directly.
  3. Ensure the paths use pure grayscale tones. You can standardize this by navigating to Extensions > Color > Grayscale. This ensures the red, green, and blue channels are equal (r = g = b), which represents luminance from 0.0 (black) to 1.0 (white).

2. Apply a Color Ramp Using the Native "Custom" Extension

Inkscape includes a built-in extension that accepts Python math functions to recalculate RGB channels. You can use this to map grayscale luminance values to a custom two-color gradient ramp.

  1. Select all the grayscale paths you want to colorize.
  2. Go to Extensions > Color > Custom... in the top menu.
  3. Determine your target colors in normalized RGB values (divide standard 0–255 RGB values by 255).
    • Example Target Ramp: Dark Navy (r: 0.1, g: 0.1, b: 0.3) for shadows to Warm Yellow (r: 1.0, g: 0.8, b: 0.2) for highlights.
  4. Use linear interpolation formulas: Start + (End - Start) * r.
  5. Enter the channel formulas into the extension input fields:
    • Red function: 0.1 + (1.0 - 0.1) * r
    • Green function: 0.1 + (0.8 - 0.1) * r
    • Blue function: 0.3 + (0.2 - 0.3) * r
  6. Check the Live preview box to verify the color mapping across your paths.
  7. Click Apply and close the dialog.

3. Apply Multi-Stop Ramps Using Dedicated Extensions

For ramps with more than two color stops, custom third-party extensions (such as Color Ramp or Gradient Map Inkscape scripts) allow mapping paths against a reference gradient or palette strip.

  1. Download the custom extension files (.inx and .py).
  2. Place them into your Inkscape user extensions directory:
    • Linux: ~/.config/inkscape/extensions/
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/
    • Windows: %APPDATA%\inkscape\extensions\
  3. Restart Inkscape to load the new menu item.
  4. Draw a reference rectangle filled with your custom gradient ramp alongside your artwork.
  5. Select both your reference ramp and the target grayscale paths.
  6. Open the installed extension from the Extensions menu (typically under Extensions > Color or Extensions > Generate from Path).
  7. Set the reference path as the palette source, choose whether to affect Fill or Stroke, and click Apply. The extension samples luminance from the paths and replaces their color with the corresponding stop on the reference ramp.
