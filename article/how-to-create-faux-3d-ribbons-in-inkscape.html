How to Create Faux 3D Ribbons in Inkscape

This guide provides a step-by-step walkthrough on how to generate faux 3D ribbon shapes in Inkscape using the Extrude extension. You will learn how to set up source paths, configure the extrusion tool to bridge geometry, and apply lighting effects through gradients to achieve a realistic three-dimensional vector ribbon.

Step 1: Draw the Base Paths

  1. Select the Draw Bézier curves and straight lines tool (B).
  2. Draw a smooth, wavy curve that defines the primary flow of your ribbon.
  3. Duplicate the path by pressing Ctrl + D, then move the duplicated path downward or offset it slightly to establish the thickness and perspective of the ribbon.
  4. Select the Node tool (N) and ensure both paths have an equal number of nodes and flow in the same direction. If one path is reversed, select it and go to Path > Reverse.

Step 2: Combine the Paths

The Extrude extension requires two subpaths within a single path object to calculate the bridging surfaces.

  1. Select both paths simultaneously using the Selection tool (S) or holding Shift.
  2. Navigate to Path > Combine (or press Ctrl + K).

Step 3: Run the Extrude Extension

  1. With the combined path selected, go to Extensions > Generate from Path > Extrude...
  2. In the dialog box, set the Mode to Polygons so Inkscape creates solid surfaces instead of wireframe lines.
  3. Check the Live Preview box to view the generated ribbon shape immediately.
  4. Click Apply and close the extension window.

Step 4: Add Depth with Shading and Gradients

  1. Select the extruded ribbon and ungroup it by pressing Ctrl + Shift + G so you can manipulate individual polygon segments.
  2. Select individual segments where the ribbon folds or turns.
  3. Use the Fill and Stroke panel (Ctrl + Shift + F) to assign darker tones to the underside or recessed folds of the ribbon, and lighter tones to the raised, front-facing surfaces.
  4. Use the Gradient tool (G) to apply linear gradients across segments to create smooth transitions between highlight and shadow zones, completing the faux 3D appearance.
