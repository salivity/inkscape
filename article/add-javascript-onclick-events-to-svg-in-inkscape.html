Add JavaScript Onclick Events to SVG in Inkscape

Adding interactive JavaScript onclick events to SVG graphics inside Inkscape allows you to create responsive web elements, buttons, and animations directly from your vector editor. Inkscape natively supports SVG interactivity through its built-in Object Attributes panel and the XML Editor. This tutorial outlines the exact steps to assign onclick triggers to specific SVG objects, embed custom JavaScript functions, and properly save the file for web browsers.

Method 1: Using the Object Attributes Panel

The most straightforward way to add click events in Inkscape is through the Interactivity section of the Object Attributes dialog.

  1. Select the Object: Click on the vector path, shape, text, or group that you want to make clickable.
  2. Open Object Attributes: Right-click the element and select Object Attributes, or navigate to Object > Object Properties / Object Attributes from the top menu.
  3. Locate Interactivity: In the properties panel, expand the Interactivity dropdown menu.
  4. Enter the Onclick Code: Find the onclick field and type your JavaScript command. For a simple test, enter: 
    alert('Element clicked!');
    You can also call custom functions or manipulate the element directly by passing this: 
    this.style.fill = 'red';

Method 2: Embedding Custom Scripts via the XML Editor

If you need more complex logic, you can define complete JavaScript functions directly inside the SVG document.

  1. Open the XML Editor: Go to Edit > XML Editor (or press Ctrl + Shift + X on Windows/Linux, Cmd + Shift + X on macOS).
  2. Select the Root Node: In the XML hierarchy tree on the left, select the top-level <svg:svg> element.
  3. Add a Script Node: Click the New element node icon at the top of the XML panel. Enter svg:script as the element name and click Create.
  4. Set Script Attributes:
    • With the <svg:script> node selected, type type into the attribute name field on the right, set the value to text/javascript (or text/ecmascript), and click Set.
  5. Add Function Content:
    • Select the text node beneath <svg:script> (or create a text child node) and add your custom JavaScript:
    function handleItemClick(evt) {
    var target = evt.currentTarget;
    target.setAttribute('opacity', '0.5');
    console.log('Clicked element ID:', target.id);
}
  6. Link Function to Element: Select your visual SVG object in the XML Editor, add an onclick attribute to it, and set the value to handleItemClick(evt).

Saving and Testing the Interactive SVG

To verify that your interactive script functions correctly:

  1. Go to File > Save As....
  2. Select Plain SVG (*.svg) from the file type dropdown to strip proprietary editor metadata and produce cleaner code for web use.
  3. Open the saved .svg file directly in any modern web browser (Google Chrome, Firefox, Edge, or Safari).
  4. Click on the configured vector element to execute your JavaScript action.
