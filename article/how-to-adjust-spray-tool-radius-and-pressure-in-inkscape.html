How to Adjust Spray Tool Radius and Pressure in Inkscape

This guide explains how to configure the Spray tool in Inkscape to gain precise control over object distribution. You will learn where to find the Spray tool controls bar, how to adjust the spray area radius (Width), how to modify output density (Amount), and how to enable pressure sensitivity for drawing tablets.

Accessing the Spray Tool Settings

To begin adjusting the Spray tool:

  1. Select the Spray tool from the toolbox on the left side of the screen, or press the shortcut key A (or Shift + F3 depending on your version).
  2. Look at the Tool Controls Bar directly above the canvas. This bar displays all active numerical settings, toggles, and modes for the Spray tool.

Adjusting the Radius (Width)

The radius determines the diameter of the circular area where objects are scattered. In Inkscape, this is referred to as Width.

  • Via the Controls Bar: Locate the Width input box in the top toolbar. Enter a numeric value between 1 and 100, or use the up and down arrow buttons to increase or decrease the spray circle size.
  • Via Keyboard Shortcuts: While the Spray tool is active, press the Left Arrow key to decrease the width or the Right Arrow key to increase the width dynamically.

Adjusting the Pressure and Flow (Amount)

The concentration and flow rate of sprayed items are controlled via the Amount and Pressure settings.

  • Changing the Amount: In the Tool Controls Bar, adjust the Amount value. A lower value sprays fewer items over a set duration, while a higher value creates a dense cluster of objects quickly.
  • Enabling Tablet Pressure Sensitivity: If you are using a graphics tablet with a stylus, click the Pressure sensitivity icon (looks like a pen tip or tablet icon) located next to the Width and Amount fields. Enabling this allows stylus pressure to dynamically dictate the spray radius, object count, or scale depending on your selected mode.

Additional Tips for Precise Spraying

  • Rotation and Scale Jitter: Use the Rotation and Scale fields in the controls bar to add random variations to the objects as they are dispersed.
  • Spray Modes: Choose between spraying independent copies, linked clones, or merging the shapes into a single path using the mode icons on the far left of the Tool Controls Bar.
