How to Rotate Hue by Degree in Inkscape

Rotating color hues across an entire design in Inkscape is a straightforward process achieved through the built-in HSL Adjust extension. By selecting your vector elements and applying a specific degree offset to the hue channel, Inkscape recalculates the fill and stroke colors of all selected artwork simultaneously around the standard 360-degree color wheel while keeping saturation and lightness values intact.

Step 1: Select Your Artwork

Open your project in Inkscape and select all the elements you want to modify.

  • Press Ctrl + A (or Cmd + A on macOS) to select all objects on the canvas.
  • If your artwork contains grouped objects, the extension can still process them, but complex nested structures or locked layers will not be modified. Unlock any relevant layers before proceeding.
  • Note that this method only affects native vector shapes, paths, text, and strokes. It will not alter the colors of imported raster images (PNG, JPEG).

Step 2: Open the HSL Adjust Tool

With your objects selected:

  1. Navigate to the top menu bar.
  2. Click Extensions.
  3. Hover over Color.
  4. Select HSL Adjust... from the drop-down menu.

Step 3: Enter the Hue Rotation Angle

A dialog box will appear with sliders for Hue, Saturation, and Lightness.

  1. Locate the Hue (°) input field.
  2. Enter the exact degree value by which you want to rotate the colors. The value ranges from -360 to 360:
    • Positive values rotate hues clockwise around the color wheel (e.g., entering 120 shifts red to green).
    • Negative values rotate hues counter-clockwise (e.g., entering -120 shifts red to blue).
    • Entering 180 or -180 inverts colors to their complementary opposites.
  3. Ensure the Saturation (%) and Lightness (%) values remain set to 0 so that only the hue angle is modified.

Step 4: Preview and Apply

  1. Check the Live preview box in the lower-left corner of the dialog box to verify the result on your canvas.
  2. If the new color palette matches your requirements, click Apply.
  3. Click Close to exit the tool.
