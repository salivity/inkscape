How to Import WMF and EMF Files in Inkscape

Inkscape natively supports importing both Windows Metafile (.wmf) and Enhanced Metafile (.emf) formats, enabling users to edit, scale, and convert legacy Windows graphics into modern vector files. This guide details the standard methods for bringing these files into your Inkscape workspace, ungrouping their vector components for editing, and addressing potential formatting discrepancies during the import process.

Method 1: Using the Import Menu

  1. Launch Inkscape and open an existing project or create a new document.
  2. Click on File in the top menu and select Import... (or press Ctrl + I on Windows/Linux, Cmd + I on macOS).
  3. In the file browser dialog, navigate to the folder containing your .wmf or .emf file.
  4. Set the file format dropdown to All supported formats or specifically choose Windows Metafiles (*.wmf) or Enhanced Metafiles (*.emf).
  5. Select the file and click Open.
  6. The vector graphic will appear directly on your current canvas.

Method 2: Drag and Drop

  1. Open your Inkscape canvas.
  2. Locate the .wmf or .emf file in your operating system's file manager (File Explorer on Windows, Finder on macOS, or your file manager on Linux).
  3. Click and drag the file directly onto the active Inkscape canvas and release it.

Editing Imported WMF and EMF Files

Once imported, Inkscape converts the proprietary metafile data into standard SVG vectors:

  • Ungrouping Elements: Metafiles are typically imported as a single grouped object. To edit individual paths, select the graphic and go to Object > Ungroup (or press Ctrl + Shift + G / Cmd + Shift + G). You may need to apply this multiple times depending on the nesting level of the original file.
  • Managing Text: Embedded text from older WMF/EMF files may import as converted vector paths rather than editable text objects. If fonts do not render correctly, ensure the original font used in the metafile is installed on your local operating system.
  • Handling Complex Fills: Certain legacy Windows GDI features, such as advanced clipping masks or pattern fills, might import as raster (bitmap) images or simplified flat colors. Inspect paths using the Edit paths by nodes tool (N) to ensure geometry integrity.
