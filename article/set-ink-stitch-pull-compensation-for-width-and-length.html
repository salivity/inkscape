Set Ink/Stitch Pull Compensation for Width and Length

When digitizing embroidery in Inkscape using the Ink/Stitch extension, fabric tension causes stitches to pull inward along the stitch direction and push outward perpendicular to it. While Ink/Stitch applies primary pull compensation along the angle of needle penetrations, you can configure width and length compensations separately by combining directional pull compensation with perimeter expansion settings. This guide explains how to set and balance both dimensions directly within the object parameters.

Understanding Pull Compensation vs. Expansion

In Ink/Stitch:

  • Pull Compensation (mm): Extends the shape only along the stitch angle (the direction the needle threads travel). This directly counters the inward shrinkage along stitch width.
  • Expand (mm): Enlarges the entire outline of the shape uniformly in all directions. This affects both the stitch direction and the perpendicular travel direction (length/push).

Because there is no single checkbox to separate width and length into two isolated sliders, you achieve independent control by using Expand to set the baseline compensation for length, and Pull Compensation to add the remaining required width.

Step-by-Step Configuration for Fill (Tatami) Stitches

To set independent stitch width and stitch length compensations on an auto-fill object:

  1. Select the Object: Click on your embroidery shape in the Inkscape workspace.
  2. Open Parameters: Navigate to Extensions > Ink/Stitch > Params.
  3. Set the Perpendicular/Length Offset (Expand):
    • Locate the Expand field.
    • Enter the millimeter value required to offset fabric distortion along the sides of the stitches (perpendicular to stitch direction).
  4. Set the Stitch Direction/Width Offset (Pull Compensation):
    • Locate the Pull compensation field.
    • Since Expand has already enlarged the entire perimeter, the total compensation in the stitch direction will equal Expand + Pull compensation.
    • Enter only the additional millimeter value needed to counter pull along the stitch angle.
  5. Apply and Quit: Click Apply and Quit to save the compensation settings to the object’s XML data.

Configuration for Satin Columns

Satin columns behave differently than fills because stitch width is defined by the distance between the two bounding rails, while length is defined by the rail paths themselves:

  1. Stitch Width Compensation:
    • Select your satin column and go to Extensions > Ink/Stitch > Params.
    • Enter your desired offset into the Pull compensation field. This widens the column by pushing needle penetrations outward past the rails by that exact millimeter amount.
  2. Column Length Compensation:
    • Ink/Stitch does not apply automated pull compensation to the start and end caps of satin columns.
    • To adjust length compensation, switch to the Node Tool (N) in Inkscape.
    • Manually extend or retract the beginning and ending nodes of the rails to account for push/pull along the column's path.
