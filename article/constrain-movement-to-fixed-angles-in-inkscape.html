Constrain Movement to Fixed Angles in Inkscape

Constraining movement in Inkscape allows you to move objects, adjust nodes, and draw lines along precise horizontal, vertical, or 45-degree angles. This functionality is primarily controlled using the Ctrl modifier key during various operations. This guide covers how to constrain movement across different tools and how to customize the snapping angle increments in your settings.

Constraining Object Movement

To move an existing object strictly horizontally, vertically, or at fixed 45-degree intervals:

  1. Select the Select and Transform Objects tool by pressing S or F1.
  2. Click and begin dragging the object.
  3. Hold down the Ctrl key while dragging.
  4. Inkscape will lock the movement to preset angle increments (defaulting to 15-degree steps, which includes 0°, 45°, and 90°).
  5. Release the mouse button first, then release the Ctrl key to apply the placement.

Constraining Node Movement and Handles

When fine-tuning paths with the Node tool:

  1. Activate the Edit paths by nodes tool by pressing N or F2.
  2. Click and drag an individual node or a bezier handle.
  3. Hold Ctrl while dragging to restrict the movement strictly to the horizontal axis, the vertical axis, or along the handle's original direction.
  4. Release the mouse button before releasing the Ctrl key.

Drawing Straight Paths at Fixed Angles

To draw straight lines locked to horizontal, vertical, or 45-degree angles:

  1. Select the Draw Bezier curves and straight lines tool (Pen tool) by pressing B.
  2. Click on the canvas to place the starting point.
  3. Hold the Ctrl key and move your cursor to define the direction. The line will snap to fixed angle increments.
  4. Click to place the next node, and double-click or press Enter to complete the path.

Customizing Angle Step Increments

By default, Inkscape snaps angles at 15-degree intervals, which natively includes 45-degree and 90-degree alignments. To change this step value:

  1. Open the preferences dialog by going to Edit > Preferences or pressing Ctrl + Shift + P.
  2. In the left sidebar, expand Interface and select Steps.
  3. Locate the Rotation/snapping angle steps field.
  4. Enter your desired degree value (e.g., set to 45.0 if you only want snaps at 0°, 45°, and 90°).
  5. Close the Preferences window to save your changes.
