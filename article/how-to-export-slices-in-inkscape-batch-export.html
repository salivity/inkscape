How to Export Slices in Inkscape Batch Export

Exporting multiple specific sections of a single design in Inkscape can be streamlined by using slice rectangles combined with the Batch Export feature. This guide explains how to define custom export regions using designated rectangles, configure object identifiers for accurate file naming, and leverage Inkscape’s modern Export dialog to simultaneously output all slices into your preferred image format.

1. Create the Slice Rectangles

  1. Select the Rectangle Tool (R) from the left toolbar.
  2. Draw a rectangle over each area of your canvas that you want to export as an individual asset.
  3. Snap the rectangles precisely to your artwork or grid to ensure exact pixel dimensions.
  4. (Optional) Set the Fill and Stroke of these rectangles to transparent, or group them on a dedicated, non-rendered setup layer so they do not visually obscure your artwork.

2. Label the Slices for File Naming

Inkscape uses object IDs or labels to name exported batch files automatically:

  1. Right-click a slice rectangle and select Object Properties (or press Shift + Ctrl + O).
  2. In the ID or Label field, enter the desired file name for that slice (e.g., button_primary, header_banner).
  3. Click Set to apply the change.
  4. Repeat this for each rectangle you created.

3. Open the Export Dialog

  1. Go to the top menu and select File > Export... (or press Ctrl + Shift + E on Windows/Linux, Cmd + Shift + E on macOS).
  2. The Export dialog panel will open on the right side of the workspace.

4. Set Up the Batch Export Tab

  1. At the top of the Export dialog, click on the Batch export tab.
  2. In the sub-tabs beneath Batch export, select Selection (or Layers if your slices are isolated to specific layers).
  3. Select all of your slice rectangles on the canvas by holding Shift and clicking them, or by selecting them from the Objects panel (Ctrl + Shift + X). The selected objects will populate in the Batch export list.
  4. Choose the target Format (e.g., PNG, SVG, JPG, WebP) from the dropdown list.
  5. Set your desired resolution (DPI) or output scale.
  6. Under the export settings, choose the destination directory where your slices should be saved.

5. Export the Slices

  1. Review the list of items in the Batch export queue to confirm all intended rectangles and their corresponding file names are present.
  2. Click the Export button at the bottom of the dialog.

Inkscape will process each rectangle bounds and save the sliced regions as individual files directly into your specified directory.
