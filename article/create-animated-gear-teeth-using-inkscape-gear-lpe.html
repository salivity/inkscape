Create Animated Gear Teeth Using Inkscape Gear LPE

This guide provides a focused walkthrough on using Inkscape’s Gear Live Path Effect (LPE) to procedurally design interlocking gear profiles and prepare them for seamless transmission animation. By leveraging dynamic path parameters alongside SVG transform properties, you can create mechanically accurate, infinitely scalable animated gear trains directly from vector paths.

1. Initialize the Base Path

  1. Open Inkscape and select the Pen (Bezier) Tool (B) or the Circle Tool (E).
  2. Draw a closed circle or a simple closed path on the canvas to serve as the initial geometry for the effect.
  3. Ensure the object is converted to a path by navigating to Path > Object to Path (Shift + Ctrl + C).

2. Apply the Gear Live Path Effect

  1. With your path selected, open the Path Effects panel via Path > Path Effects.
  2. Click the Add Path Effect (+) icon.
  3. In the effect browser, locate and select Gear.
  4. Adjust the fundamental gear geometry in the LPE settings:
    • Teeth: Set the total number of teeth (e.g., 24).
    • Pitch: Set the spacing between tooth profiles.
    • Angle: Adjust the pressure angle to control tooth thickness and undercut depth.

3. Build a Matching Transmission Gear

Gears mesh properly only when they share the same circular pitch and pressure angle.

  1. Duplicate the first gear using Ctrl + D.
  2. In the Path Effects panel for the duplicate gear, adjust the Teeth count (for example, change from 24 to 12 for a 2:1 transmission ratio).
  3. Do not modify the pitch value, ensuring the tooth modules remain compatible.
  4. Move the new gear adjacent to the first so the pitch circles touch.
  5. Rotate the second gear slightly using the Select Tool (F1) to mesh the teeth accurately between the gaps of the first gear.

4. Set the Center of Rotation

  1. Click the first gear twice to reveal its rotation center (the small crosshair +).
  2. Verify the crosshair is located precisely at the mathematical center of the gear. If displaced, snap it back using the bounding box center snap.
  3. Repeat this check for the secondary gear.

5. Animate the Transmission

Because Inkscape generates native SVG vectors, you can animate the rotation directly through SVG code or by exporting layers:

Method A: Direct SVG <animateTransform>

  1. Save the file as Optimized SVG.
  2. Open the file in a code editor and locate the <path> or <g> tags corresponding to your gears.
  3. Add a child <animateTransform> tag inside the driving gear element:
<animateTransform
    attributeName="transform"
    type="rotate"
    from="0 [CenterX] [CenterY]"
    to="360 [CenterX] [CenterY]"
    dur="4s"
    repeatCount="indefinite" />
  1. Add the reciprocal animation to the driven gear. Apply the transmission ratio formula (\(Speed_2 = -Speed_1 \times \frac{Teeth_1}{Teeth_2}\)):
<animateTransform
    attributeName="transform"
    type="rotate"
    from="0 [CenterX2] [CenterY2]"
    to="-720 [CenterX2] [CenterY2]"
    dur="4s"
    repeatCount="indefinite" />

(Replace [CenterX] and [CenterY] with the absolute coordinates of the respective gear pivots).

Method B: Keyframe Animation in External Tools

  1. Convert the dynamic LPE to static vectors via Path > Object to Path if editing geometry is finalized.
  2. Group each gear individually with Ctrl + G.
  3. Export the SVG into an animation tool such as Blender, Synfig, or web-based CSS animation environments, rotating the driven gear in the inverse direction at a speed dictated by your gear ratio.
