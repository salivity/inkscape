Generate Wireframe Mesh Between Two Paths in Inkscape

Generating a wireframe mesh between two arbitrary paths in Inkscape allows you to create pseudo-3D surfaces, ribbon grids, and smooth vector transitions. This guide demonstrates how to combine Inkscape's path interpolation and sub-path stitching tools to generate both the longitudinal and transversal vector lines needed to form a complete wireframe grid between any two boundary paths.

Step 1: Prepare the Boundary Paths

  1. Use the Pen (Bezier) Tool (B) to draw two separate open or closed paths on the canvas.
  2. Ensure both paths share the same general direction (from start node to end node) to avoid twisting. If a generated mesh twists unexpectedly later, select one path with the Node Tool (N) and click Path > Reverse.

Step 2: Generate Longitudinal (Parallel) Lines

  1. Select both boundary paths using the Select Tool (S).
  2. Navigate to Extensions > Generate from Path > Interpolate....
  3. In the dialog box:
    • Set Interpolation Steps to your desired line density (e.g., 10 to 20).
    • Set Interpolation Method to 1 (or 2 for smoother curve transitions).
    • Check Duplicate endpaths if you want the boundary lines included in the generated group.
    • Enable Live Preview to check the result.
  4. Click Apply and close the dialog.

Step 3: Generate Transversal (Cross) Lines

  1. Select the two original boundary paths again.
  2. Duplicate them by pressing Ctrl + D.
  3. With the duplicates selected, combine them into a single compound path by selecting Path > Combine (Ctrl + K).
  4. Navigate to Extensions > Generate from Path > Stitch Sub-Paths....
  5. Set the Number of paths to match or complement the steps used in Step 2.
  6. Click Apply and close the dialog.

Step 4: Finalize and Style the Mesh

  1. Select both the interpolated group and the stitched path group.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Set the Fill to None and choose a consistent Stroke paint and Stroke width to achieve a clean wireframe aesthetic.
  4. Group all components together by pressing Ctrl + G.
