Reorder Paths in Inkscape Fill Between Many

Reordering input paths in Inkscape's Fill Between Many Live Path Effect (LPE) is essential for fixing twisted fills, self-intersections, and incorrect boundary calculations. This guide provides clear, step-by-step instructions to change the order of linked paths using the Path Effects panel and the XML Editor.

Method 1: Using the Path Effects Panel

  1. Select the Object: Click on the generated fill path using the Select Tool (S) or Node Tool (N).
  2. Open Path Effects: Navigate to the top menu and select Path > Path Effects (or press Ctrl + & / Cmd + &) to open the Path Effects dialog.
  3. Locate the Linked Paths List: In the Path Effects panel, locate the Fill Between Many effect. Look for the list of input items under the Curves or Linked Paths section.
  4. Reorder the Paths:
    • Click and drag an item up or down within the list to change its position in the sequence.
    • Alternatively, select a path name in the list and click the Move Up (▲) or Move Down (▼) arrow buttons adjacent to the list.
  5. Observe the Canvas: Inkscape will recalculate the boundary sequence automatically. The fill will update to follow the new path-to-path order.

Method 2: Using the XML Editor

If the graphical list is difficult to manipulate or contains numerous items, use the XML Editor to edit the connection sequence directly.

  1. Open the XML Editor: Go to Edit > XML Editor or press Ctrl + Shift + X.
  2. Select the Fill Object: Click the path containing the Fill Between Many effect on your canvas. The corresponding XML node (<svg:path>) will be highlighted in the XML Editor tree.
  3. Find the Path Effect Definition:
    • Check the inkscape:path-effect attribute to find the ID of the effect definition (e.g., #path-effect1234).
    • In the XML tree, locate the corresponding <inkscape:path-effect> element under <svg:defs>.
  4. Edit the Path Order:
    • Select the effect definition node.
    • Locate the attribute that stores the linked paths (typically named linkedpaths).
    • In the attribute value field, you will see a semicolon- or space-separated list of path IDs (e.g., #path1;#path2;#path3).
    • Edit the text directly to change the order of the IDs.
    • Click the Set button (or press Ctrl + Enter) to apply the change.

Additional Troubleshooting

  • Twisted or Crossed Fills: If reordering the list fixes the sequence but the fill still twists between two lines, the direction of one of the paths may be inverted. Select the offending path and go to Path > Reverse to align its start and end points with the rest of the shape.
  • Sequential Arrangement: For the fill algorithm to create a clean perimeter, input paths should be ordered logically along the intended contour (e.g., clockwise or counter-clockwise around the shape).
