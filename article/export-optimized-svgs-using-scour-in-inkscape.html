Export Optimized SVGs Using Scour in Inkscape

Inkscape is an exceptional tool for creating vector graphics, but its default output files often contain proprietary metadata, hidden editor data, and excessive precision that bloat file sizes. Using the integrated Scour extension, you can strip unnecessary code, simplify paths, and reduce file sizes significantly without compromising visual quality. This guide outlines the exact steps to configure and export web-ready, optimized SVGs directly from Inkscape using Scour.

Step 1: Prepare Your Artwork

Before running the optimization tool, clean up your working file:

  1. Delete any unused or hidden layers, draft objects, and invisible paths.
  2. Convert text to paths (Path > Object to Path) if you do not plan to load external web fonts.
  3. Save a backup of your original project in the native Inkscape SVG (.svg) format so you retain full editing capabilities later.

Step 2: Open the Optimized SVG Export Menu

  1. Go to the top menu and select File > Save As... (or press Ctrl + Shift + S / Cmd + Shift + S).
  2. In the "Save as type" dropdown menu, select Optimized SVG (*.svg).
  3. Choose your destination folder, enter a file name, and click Save. This will open the Scour settings dialogue window.

Step 3: Configure Scour Settings

The Scour configuration window is divided into several tabs. Apply the following recommended settings based on your project requirements:

Options Tab

  • Number of significant digits for coordinates: Set to 3 or 4. Lower numbers reduce file size, while higher numbers preserve precise curves on complex graphics.
  • Shorten color values: Check this box to convert color values to their shortest hex equivalents (e.g., #ffffff to #fff).
  • Convert CSS attributes to XML attributes: Check this box for better compatibility across older SVG renderers.
  • Collapse groups: Check this box to remove empty or non-essential grouping <g> tags.
  • Create groups for similar attributes: Check this box to combine shared styles and reduce repetition.
  • Keep editor data: Leave unchecked to strip Inkscape-specific tags (like sodipodi and inkscape namespaces).
  • Keep unreferenced defs: Leave unchecked to delete unused gradients, patterns, and clip paths.

SVG Output Tab

  • Remove metadata: Check this box to delete author info, creation timestamps, and license text.
  • Remove comments: Check this box to strip non-functional code comments.
  • Embed raster images: Uncheck this if you prefer external references, or check it if you need a completely self-contained SVG.
  • Enable viewboxing: Check this box to ensure the SVG scales responsively within web browsers.
  • Format output with line-breaks and indentation: Uncheck this for production use to minify the code onto fewer lines, or check it if you need human-readable markup.

ID Attributes Tab

  • Remove unused IDs: Check this box to delete element IDs that are not referenced by styles, masks, or scripts.
  • Shorten IDs: Check this box if you want long names replaced with short, randomized identifiers (e.g., id="a").
  • Note: If you target specific elements using JavaScript or external CSS, leave specific IDs intact or uncheck these options.

Step 4: Save and Verify

  1. Click OK (or Apply) in the Scour dialog window to generate the file.
  2. Compare the file size of the new Optimized SVG against the original Inkscape SVG. In most cases, file sizes are reduced by 30% to 70%.
  3. Open the optimized SVG in a web browser to verify that all visual elements, gradients, and shapes render as intended.
