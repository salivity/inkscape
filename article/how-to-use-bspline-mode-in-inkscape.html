How to Use BSpline Mode in Inkscape

B-Spline mode in Inkscape is a powerful drawing feature that allows you to create continuous, organic curves easily without manually adjusting Bézier handles. This guide explains how to activate B-Spline mode, plot smooth curves, create sharp corners when needed, and fine-tune your final paths.

1. Select the Tool and Enable B-Spline Mode

  1. Open your Inkscape document.
  2. Select the Draw Bézier curves and straight lines tool from the left toolbar, or press the shortcut key B.
  3. Look at the Tool Controls Bar at the top of the screen.
  4. Locate the Mode section and click the Create a B-spline path icon (represented by a smooth curve bypassing a corner node).

2. Draw Smooth Curves

  1. Click once on the canvas to set the starting point of your path.
  2. Move your cursor and click again to add subsequent control points.
  3. Notice that the curve does not pass directly through the points you click. Instead, the points act as a gravitational pull, bending the curve smoothly between them.
  4. Continue clicking to outline your desired shape.

3. Create Sharp Corners

While B-Spline mode defaults to smooth curves, you can introduce sharp corners without switching tools:

  • While drawing: Hold the Shift key and click where you want an abrupt angle or sharp corner.
  • Alternatively, double-click on a point while drawing to clamp the curve directly to that point.

4. Finish the Path

  • To create an open path, press Enter or right-click when you place your final node.
  • To create a closed shape, hover over the initial starting node until it highlights, then click it.

5. Edit and Adjust the B-Spline

  1. Switch to the Node Tool by pressing N or selecting it from the toolbar.
  2. Click on your B-Spline path to reveal the control points (represented by small nodes linked by a bounding polygon).
  3. Drag any control point to reshape the curve. The surrounding path will dynamically adjust while maintaining its smooth curvature.
  4. To toggle a node between smooth and sharp after drawing, select the node and press Shift + C or use the corner node buttons in the top controls bar.
