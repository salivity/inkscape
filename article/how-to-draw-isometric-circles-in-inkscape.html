How to Draw Isometric Circles in Inkscape

Drawing isometric circles in Inkscape requires transforming a standard circle to match an isometric grid using the Scale, Shear, and Rotate (SSR) method. By creating a flat circle with the Ellipse tool and applying precise mathematical transformations in the Transform dialog, you can accurately project circles onto the top, left, and right isometric planes without relying on manual eyeballing.

1. Open the Transform Panel

Open the Transform dialog by navigating to Object > Transform in the top menu or pressing Shift + Ctrl + M. Ensure that the Apply to each object separately checkbox is unchecked.

2. Draw the Base Circle

  1. Select the Circles and Ellipses tool (E).
  2. Hold down Ctrl while clicking and dragging to draw a circle with equal width and height.

3. Transform for the Desired Isometric Plane

For all isometric projections, the height must first be scaled to match the true axonometric foreshortening of \(30^\circ\) projection (\(\cos(30^\circ) \approx 86.603\%\)).

Initial Scale (All Planes)

  1. Go to the Scale tab in the Transform panel.
  2. Uncheck Scale proportionally.
  3. Set the measurement unit to %.
  4. Set Width to 100% and Height to 86.603%.
  5. Click Apply.

Top Plane (Horizontal)

  1. Switch to the Skew tab.
  2. Set the unit to degrees (deg), enter Horizontal (X) as -30°, and click Apply.
  3. Switch to the Rotate tab.
  4. Set the angle to 30° clockwise (or -30° counter-clockwise depending on grid orientation) and click Apply.

Left Plane (Vertical Left)

  1. Switch to the Skew tab.
  2. Set Horizontal (X) to -30° and click Apply.
  3. Switch to the Rotate tab.
  4. Set the angle to -30° (counter-clockwise) and click Apply.

Right Plane (Vertical Right)

  1. Switch to the Skew tab.
  2. Set Horizontal (X) to 30° and click Apply.
  3. Switch to the Rotate tab.
  4. Set the angle to 30° (clockwise) and click Apply.

Summary of Parameters

  • Top Face: Scale Height to 86.603% \(\rightarrow\) Skew X by -30° \(\rightarrow\) Rotate by 30°
  • Left Face: Scale Height to 86.603% \(\rightarrow\) Skew X by -30° \(\rightarrow\) Rotate by -30°
  • Right Face: Scale Height to 86.603% \(\rightarrow\) Skew X by 30° \(\rightarrow\) Rotate by 30°

The resulting ellipses will align with isometric cubes, cylinders, and coordinate grids set to the standard \(30^\circ\) isometric angles.
