Realistic Stamped Ink Filter in Inkscape

Achieving an authentic stamped ink effect in Inkscape requires simulating both physical edge erosion and uneven ink distribution across the surface. This article provides the exact SVG filter pipeline—combining Turbulence, Displacement Map, Color Matrix, and Composite primitives—needed to transform clean vector shapes into realistic, weathered rubber stamp prints without destructive path editing.

1. Open the Filter Editor

  1. Select your target vector artwork (text, paths, or silhouettes).
  2. Go to Filters > Filter Editor to open the panel.
  3. Click New at the bottom of the left column and rename your filter to Stamped Ink.
  4. Ensure the checkbox next to your new filter is checked so it applies to your selected object.

2. Configure the Edge Erosion Pipeline

Step A: Add Turbulence (Base Noise)

  1. In the Add Effect dropdown, select Turbulence and click Add Effect.
  2. Select the Turbulence node and adjust the Effect parameters:
    • Type: Fractal Noise
    • Base Frequency: Set horizontal (X) and vertical (Y) to approximately 0.05 to 0.08. Higher values create finer grain, while lower values produce broader tears.
    • Num Octaves: 3 to 5 for natural complexity.

Step B: Add a Displacement Map (Edge Distortion)

  1. Select Displacement Map from the dropdown and click Add Effect.
  2. Connect the inputs in the editor graph:
    • Connect the first input (top connection) to Source Graphic.
    • Connect the second input (bottom connection) to the Turbulence primitive.
  3. In the Effect parameters:
    • Scale: Set between 5 and 12 depending on the size of your graphic. This physically distorts and erodes the boundary edges.
    • X Channel: Red
    • Y Channel: Green

3. Configure the Interior Void Pipeline

Step C: Add a Second Turbulence Node (Pore Texture)

To create the dry, patchy voids inside the stamp imprint, introduce a finer noise layer:

  1. Add another Turbulence primitive.
  2. In the Effect parameters:
    • Type: Turbulence
    • Base Frequency: 0.2 to 0.4 (fine grain).
    • Num Octaves: 2.

Step D: Add Color Matrix (Noise Contrast)

  1. Add a Color Matrix primitive.
  2. Connect its input to the second Turbulence node.
  3. Set the matrix to boost the alpha contrast so that the noise creates stark black-and-white patches:
    • Change the dropdown to Matrix.
    • In the bottom row (controlling Alpha), increase the Alpha multiplier to 3 or 4 and adjust the offset to -1.5 to clamp the midtones, creating crisp gaps.

4. Merge and Composite

Step E: Add Composite (Cut Voids from Displaced Graphic)

  1. Add a Composite primitive.
  2. Connect the inputs:
    • Input 1: Connect to the output of the Displacement Map (the eroded shape).
    • Input 2: Connect to the output of the Color Matrix (the high-contrast void texture).
  3. In the Effect parameters:
    • Operator: Select Out or Arithmetic.
    • If using Arithmetic, set K1 = 0, K2 = 1, K3 = -0.7, and K4 = 0. This subtracts portions of the grain from the graphic, preserving semi-transparent ink falloff.

5. Final Finishing Adjustments

  • Ink Color: Stamped ink is rarely pure black. Use a dark tone such as deep charcoal (#1A1A1A), dark red, or navy.
  • Layer Blend Mode: Set the layer or object blend mode to Multiply with an opacity around 90% to 95% so background textures or paper fibers show through the print voids naturally.
