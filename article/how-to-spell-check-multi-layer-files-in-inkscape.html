How to Spell Check Multi-Layer Files in Inkscape

Inkscape includes a dedicated Check Spelling tool that scans text elements across documents to identify and fix typographical errors. In multi-layer projects, ensuring that the spell checker finds every mistake requires proper layer management and familiarity with the tool's interface. This guide outlines how to prepare your multi-layer Inkscape file, open the Check Spelling dialog, and process corrections across all text objects.

Preparing Multi-Layer Documents

Before initiating the spell check, your document's layers must be set up so Inkscape can access all text elements.

  1. Open the Layers and Objects panel via Layer > Layers and Objects... or by pressing Ctrl + Shift + L.
  2. Ensure that all layers containing text are visible (the eye icon must be open).
  3. Unlock all relevant layers (the padlock icon must be open). Inkscape skips locked and hidden elements during automated text searches.
  4. If your text objects are embedded inside deep groups or clipped masks, ensure the parent objects are not locked.

Accessing the Check Spelling Dialog

Once your layers are accessible, launch the spelling utility:

  1. Deselect all objects by pressing Esc or clicking an empty area on the canvas. If a specific object is selected, Inkscape may restrict the check to that selection.
  2. Go to the top menu and select Text > Check Spelling... (or press Ctrl + Alt + K).
  3. The Check Spelling dialog window will appear.

Correcting Typos

The Check Spelling tool navigates through the document sequentially, jumping to each unrecognized word across your layers.

  1. Review the Flagged Word: The dialog displays the flagged text in the Not in dictionary field and highlights the corresponding text object on the canvas, even if it resides on a different layer.
  2. Select a Suggestion: Choose the correct spelling from the Suggestions list. You can also manually type the correction into the text box above the list.
  3. Apply the Correction:
    • Click Change to replace only the current instance.
    • Click Change All to replace every matching instance throughout the entire file across all unlocked layers.
  4. Skip or Add Terms:
    • Click Ignore to skip the current instance.
    • Click Ignore All to skip all matching instances of the term.
    • Click Add to store proprietary terms, technical names, or brand names in your personal dictionary so they are not flagged in future checks.
  5. Complete the Process: Continue through the prompts until Inkscape displays a notification that the spell check is complete, then close the dialog.
