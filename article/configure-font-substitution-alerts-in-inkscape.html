Configure Font Substitution Alerts in Inkscape

When opening legacy SVG files, Inkscape automatically verifies that all referenced typefaces exist on your current system and triggers a font substitution alert dialog if a font is missing. This guide details how to control, dismiss, or restore these font substitution warnings directly within Inkscape’s settings and preferences to streamline your document workflow.

Understanding the Font Substitution Alert

Older Inkscape documents or files created on different machines often reference fonts that are not installed on your current operating system. When this occurs during file opening, Inkscape substitutes the missing font with a default fallback (typically a generic sans-serif) and displays an alert dialog listing the missing fonts alongside their assigned replacements.

Toggling Alerts from the Dialog Window

The quickest method to adjust alert behavior occurs directly when the alert triggers:

  1. Open your legacy document in Inkscape.
  2. When the Font Substitution dialog appears, review the missing and substituted fonts.
  3. If you no longer wish to see this warning for future files, check the box labeled Do not show this warning again (or equivalent prompt depending on your Inkscape version).
  4. Click OK to proceed into the workspace.

Managing Alerts in Inkscape Preferences

If you want to configure how Inkscape handles missing font notifications or change your text preferences globally:

  1. Go to the top menu and select Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  2. In the Preferences navigation pane on the left, expand Tools and select Text.
  3. Locate the font handling settings:
    • Set your preferred Default font so that substitutions rely on a predictable typeface.
    • If available in your release, toggle the checkbox regarding missing font warnings on file open.
  4. Close the Preferences window to apply your changes.

Restoring Previously Dismissed Alert Dialogs

If you previously opted to hide the font substitution warning and now need it back to troubleshoot missing typefaces in older files, you can restore hidden dialogs:

  1. Open Edit > Preferences.
  2. Navigate to Interface > Windows.
  3. Find the dialog configuration section and look for the option to reset hidden warnings or dismissed dialogs.
  4. Alternatively, to perform a complete warning reset, navigate to System in the Preferences pane and click Reset Preferences next to the user preferences path, then restart Inkscape.

Handling Substitutions in Legacy Documents

Once inside a legacy document where fonts have been replaced:

  1. Select the affected text block using the Text Tool (T).
  2. Open the Text and Font panel (Text > Text and Font... or Ctrl + Shift + T).
  3. Check the warning icon next to the font family name. If a font is substituted, Inkscape displays a warning indicator next to the missing font name in this panel.
  4. Select a new, installed font family from the list and click Apply to permanently update the legacy file with your chosen replacement.
