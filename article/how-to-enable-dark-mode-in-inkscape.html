How to Enable Dark Mode in Inkscape

Switching the user interface to dark mode in Inkscape reduces eye strain during long design sessions and provides a sleek, modern workspace. This step-by-step guide explains how to quickly navigate Inkscape’s preference settings to activate the native dark theme for the interface, toolbars, and icons.

Steps to Turn on Dark Mode in Inkscape

  1. Open Inkscape Preferences:

    • On Windows/Linux: Go to the top menu and select Edit > Preferences, or press Ctrl + Shift + P.
    • On macOS: Select Inkscape in the menu bar > Preferences, or press Cmd + Shift + P.

  2. Navigate to Theming:

    • In the left sidebar of the Preferences window, expand the Interface category.
    • Click on Theming.

  3. Enable Dark Mode:

    • Under the Theme section on the right, locate the option labeled Use dark theme.
    • Check the box next to Use dark theme. The interface will immediately switch to dark mode.

  4. Adjust Icon Colors (Optional):

    • To ensure tool icons remain visible against the dark background, check the box for Use symbolic icons or toggle the option to Invert colors depending on your active icon set.
    • You can also select different options from the Change theme dropdown menu (such as Adwaita or System default) to change the overall styling of buttons and panels.

  5. Apply and Restart:

    • Close the Preferences window. While most changes apply instantly, restarting Inkscape ensures that all UI elements, palettes, and dialog boxes render properly in the new dark theme.
