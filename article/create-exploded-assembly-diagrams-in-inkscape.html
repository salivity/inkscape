Create Exploded Assembly Diagrams in Inkscape

This guide explains how to produce clear, technical exploded assembly diagrams in Inkscape by establishing aligned movement vectors. You will learn how to configure an axonometric grid, prepare your assembled vector assets, displace parts along consistent directional axes using precise numerical or snapped transforms, and generate dashed trajectory lines to illustrate assembly pathways accurately.

1. Configure an Axonometric Grid

Exploded diagrams rely on consistent projection angles—typically isometric (30 degrees).

  1. Open Inkscape and go to File > Document Properties (Ctrl+Shift+D).
  2. Select the Grids tab.
  3. Choose Axonometric grid from the dropdown and click New.
  4. Set the Grid spacing Y to your desired measurement (e.g., 10 px) and confirm Angle X and Angle Z are both set to 30.0 degrees.
  5. Enable snapping via the top-right toolbar: toggle on Snap to Grids and Snap to Paths/Nodes.

2. Prepare and Group the Fully Assembled Model

Always start with the parts illustrated in their final, fully assembled state to guarantee alignment before exploding.

  1. Draw or import all individual parts in their resting positions relative to one another.
  2. Select each discrete component and group it using Object > Group (Ctrl+G).
  3. Name your groups in the Layers and Objects panel (Ctrl+Shift+L) for easy selection.

3. Establish Movement Vectors

Movement vectors dictate the exact angle and direction each part travels as it detaches from the assembly.

  • Method A: Using Numerical Translation (Most Accurate)

    1. Open the Transform panel via Object > Transform (Ctrl+Shift+M) and select the Move tab.
    2. To move an object along a 30-degree isometric axis, calculate horizontal (\(dx\)) and vertical (\(dy\)) offsets using standard trigonometry:
      • Up-Right (+30°): \(dx = Distance \times \cos(30^\circ)\), \(dy = Distance \times \sin(30^\circ)\)
      • Up-Left (+150°): \(dx = -Distance \times \cos(30^\circ)\), \(dy = Distance \times \sin(30^\circ)\)
      • Vertical (+90°): \(dx = 0\), \(dy = Distance\)
    3. Select your part, input the values, and click Apply.

  • Method B: Using Vector Guide Paths

    1. Create a dedicated layer named Vectors.
    2. Use the Draw Freehand/Bezier tool (B) to draw straight paths along the grid lines connecting the center points of the assembled parts.
    3. Enable Snap to Object Midpoints and Snap to Paths.
    4. Drag components along these paths. Inkscape's snapping will constrain the movement directly along the vector.

4. Adjust Z-Order (Depth Stacking)

Exploding parts changes how they overlap in 2D space.

  1. Select each part starting from the furthest back to the closest foreground element.
  2. Use Object > Raise to Top (Home) or Object > Lower to Bottom (End) to correct the visual depth.
  3. Ensure parts closer to the viewer overlap parts positioned behind them along the line of sight.

5. Add Trajectory Lines

Trajectory lines connect exploded components back to their original mating surfaces to indicate the path of assembly.

  1. Switch to your Vectors layer (or create a Callouts layer).
  2. Using the Bezier Tool (B), draw lines connecting the attachment points (e.g., center-of-hole to center-of-bolt).
  3. Open the Fill and Stroke panel (Ctrl+Shift+F).
  4. Under Stroke style, reduce the line width so it is thinner than the part outlines.
  5. Set the Dashes dropdown to a standard dashed pattern (such as Dash 3:3 or Dotted).
  6. Optionally, select Markers to add an arrowhead showing the installation direction.
