Adjust Node Sculpting Radius and Pressure in Inkscape

This guide explains how to adjust the radius and pressure settings when sculpting nodes and paths in Inkscape. While the dedicated Tweak tool provides explicit numeric controls for brush radius (Width) and sculpting pressure (Force), the standard Node tool relies on node selection ranges and graphics tablet pressure sensitivity. Below are the precise steps to control both parameters using both methods.

Method 1: Using the Tweak Tool (Brush-Based Node Sculpting)

The Tweak tool (W) is Inkscape’s primary tool for sculpting paths and nodes using a circular brush with adjustable radius and force.

  1. Activate the Tool: Select your path and press W to switch to the Tweak tool.
  2. Select Sculpting Mode: In the top Tool Controls bar, click the Push path in any direction icon (or another path-sculpting mode such as Shrink, Grow, or Roughen).
  3. Adjust the Radius (Width):
    • Controls Bar: Change the numerical value in the Width box on the Tool Controls bar. A higher value creates a larger brush radius.
    • Keyboard Shortcut: Press the Left Arrow to decrease the radius or the Right Arrow to increase it.
  4. Adjust the Pressure (Force):
    • Controls Bar: Change the numerical value in the Force box. Higher values cause paths and nodes to deform more aggressively.
    • Keyboard Shortcut: Press the Down Arrow to decrease the force or the Up Arrow to increase it.
    • Stylus Pressure: Click the Pressure icon (represented by a pen tip next to the Width and Force inputs) to allow a graphics tablet’s pressure sensitivity to dynamically control the brush force.

Method 2: Sculpting with the Node Tool (Alt + Drag)

Inkscape's Node tool (N or F2) includes a built-in node sculpting feature that moves selected nodes according to a bell-curve (Gaussian) falloff.

  1. Activate the Tool: Press N to select the Node tool, then select the path.
  2. Define the Sculpting Radius:
    • In the Node tool, the radius is determined by your node selection rather than a brush size setting.
    • Select the group of nodes you want the sculpting effect to cover. The outer boundary of your selection defines the effective radius of the deformation.
  3. Sculpt the Nodes:
    • Hover over the node you want to move the most.
    • Hold Alt and click-drag the node. The node directly under the cursor will experience the maximum displacement, while adjacent selected nodes will move proportionally less based on their distance from the cursor.
  4. Modulate Pressure and Intensity:
    • Drag Distance: The primary control over force is the distance you drag your cursor.
    • Tablet Pressure: If you are using a drawing tablet, ensure pressure sensitivity is enabled under Edit > Input Devices. Inkscape modulates the displacement force of the Alt + drag action based on the physical pressure applied by the stylus.
