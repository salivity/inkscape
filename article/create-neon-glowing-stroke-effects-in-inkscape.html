Create Neon Glowing Stroke Effects in Inkscape

This guide demonstrates how to create a realistic neon glowing stroke effect in Inkscape using layered paths, Gaussian blur, and blend modes. By building a white-hot inner core surrounded by progressively blurred, vibrant color strokes, and combining them with light-enhancing blend modes, you can easily turn any path or text into an illuminated neon sign.

1. Set Up a Dark Background

Neon effects require a dark backdrop to achieve maximum contrast and vibrancy:

  1. Select the Rectangle tool (R) and draw a box covering your canvas.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Set the Fill to a deep dark color, such as dark navy (#0b0d17) or near-black (#111111).
  4. Lock the background layer or object to prevent accidental movement.

2. Create the Base Path or Text

  1. Select the Pen tool (Bezier curves) (B) or the Text tool (T).
  2. Draw your path or type your text. If using text, ensure you use a clean, rounded, or script-style font resembling neon tubing.
  3. If using text, convert it to paths by selecting Path > Object to Path (Ctrl + Shift + C), then ungroup it using Object > Ungroup (Ctrl + Shift + G).
  4. Set the Fill to None and apply a Stroke color using a bright, saturated hue (such as cyan, magenta, or lime green).

3. Build the Neon Layers

A convincing neon effect consists of at least three layers: a wide ambient glow, an intense inner glow, and a bright core.

  1. The Wide Outer Glow:

    • Select your stroke and duplicate it (Ctrl + D).
    • In the Fill and Stroke panel, go to the Stroke style tab and set the stroke width to a thick value (e.g., 16 px to 24 px).
    • In the Stroke paint tab, keep the vibrant neon color.
    • Under the bottom of the panel, increase the Blur (Gaussian blur) to around 15% – 25%.

  2. The Mid-Intensity Glow:

    • Duplicate the path again (Ctrl + D).
    • Set the stroke width to a medium size (e.g., 8 px to 12 px).
    • Keep the same vibrant color.
    • Set the Blur slider to approximately 5% – 10%.

  3. The Hot White Core:

    • Duplicate the path one more time (Ctrl + D).
    • Set the stroke width to a thinner size (e.g., 2 px to 4 px).
    • Change the stroke color to pure white (#FFFFFF) or a very pale tint of your neon color.
    • Set the Blur to 0% – 1% to keep the core crisp and bright.

4. Apply Blending Modes for Extra Luminance

To make the light feel additive and realistic when strokes overlap or interact with background elements:

  1. Select all the glow layers (excluding the dark background) and group them together (Ctrl + G).
  2. Open the Layers and Objects panel (Ctrl + Shift + L).
  3. Select the group or individual glow objects, and in the Blend mode dropdown located in the Fill and Stroke panel or Layers panel, change the mode from Normal to Screen or Lighten.
  4. The Screen mode mathematically blends the light values, producing an intense, shining intersection wherever glow areas cross.

5. Fine-Tuning

  • Adjusting Color: Change the stroke color of the mid and outer glow layers simultaneously to test different neon gas colors.
  • Rounded Terminals: In the Stroke style tab, set Cap and Join to Round on all strokes for authentic rounded neon tube ends.
  • Opacity: If the glow looks overly solid, reduce the Opacity of the outermost glow layer to 60%–80%.
