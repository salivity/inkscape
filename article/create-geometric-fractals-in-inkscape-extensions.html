Create Geometric Fractals in Inkscape Extensions

This guide demonstrates how to programmatically generate geometric fractals inside an Inkscape extension using Python and the inkex library. You will learn the structural requirements of an Inkscape extension, how to define user controls via an XML description file, and how to implement a recursive mathematical algorithm—such as the Sierpinski Triangle—to directly render vector geometry onto the Inkscape canvas.

Inkscape Extension Architecture

An Inkscape extension requires two primary files placed in the Inkscape user extensions directory:

  1. An .inx file: An XML-based definition file that specifies the extension name, menu location, and user-configurable inputs (such as recursion depth or sizing).
  2. A .py file: A Python script that utilizes the inkex library to parse parameters, compute fractal geometry, and generate SVG elements.

Step 1: Create the Extension Definition File

Create a file named fractal_generator.inx. This file places the tool into Inkscape's Extensions > Render menu and exposes a numerical input for recursion depth:

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespaces/inkscape">
    <name>Geometric Fractal Generator</name>
    <id>org.inkscape.render.geometric_fractal</id>
    <param name="depth" type="int" min="1" max="8" gui-text="Recursion Depth:">4</param>
    <param name="size" type="float" min="10.0" max="1000.0" gui-text="Initial Size (px):">300.0</param>
    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Render"/>
        </effects-menu>
    </effect>
    <script>
        <command location="inx" interpreter="python">fractal_generator.py</command>
    </script>
</inkscape-extension>

Step 2: Implement the Python Script

Create fractal_generator.py in the same directory. The script subclasses inkex.GenerateExtension (or inkex.EffectExtension) and uses recursion to calculate coordinates for geometric shapes, subsequently creating SVG path elements.

import math
import inkex
from inkex import PathElement

class FractalGenerator(inkex.GenerateExtension):
    def add_arguments(self, pars):
        pars.add_argument("--depth", type=int, default=4, help="Recursion depth")
        pars.add_argument("--size", type=float, default=300.0, help="Initial size")

    def generate(self):
        depth = self.options.depth
        size = self.options.size
        
        # Center starting coordinates on the canvas
        cx, cy = self.svg.namedview.center
        height = size * (math.sqrt(3) / 2)
        
        # Define vertices of the initial equilateral triangle
        p1 = (cx, cy - (2 / 3) * height)
        p2 = (cx - size / 2, cy + (1 / 3) * height)
        p3 = (cx + size / 2, cy + (1 / 3) * height)
        
        # Group element to contain all generated triangles
        group = inkex.Group()
        group.set('id', self.svg.get_unique_id('fractal_'))
        
        self.draw_sierpinski(group, p1, p2, p3, depth)
        return group

    def draw_sierpinski(self, container, p1, p2, p3, depth):
        if depth == 1:
            # Base case: generate SVG polygon path
            d = f"M {p1[0]},{p1[1]} L {p2[0]},{p2[1]} L {p3[0]},{p3[1]} Z"
            elem = PathElement()
            elem.set('d', d)
            elem.style = {
                'fill': 'none',
                'stroke': '#000000',
                'stroke-width': '1.0'
            }
            container.append(elem)
        else:
            # Calculate midpoints of all three edges
            mid12 = ((p1[0] + p2[0]) / 2, (p1[1] + p2[1]) / 2)
            mid23 = ((p2[0] + p3[0]) / 2, (p2[1] + p3[1]) / 2)
            mid31 = ((p3[0] + p1[0]) / 2, (p3[1] + p1[1]) / 2)

            # Recurse on three sub-triangles
            self.draw_sierpinski(container, p1, mid12, mid31, depth - 1)
            self.draw_sierpinski(container, mid12, p2, mid23, depth - 1)
            self.draw_sierpinski(container, mid31, mid23, p3, depth - 1)

if __name__ == '__main__':
    FractalGenerator().run()

Core Implementation Principles

  • Algorithm Selection: Deterministic geometric fractals (e.g., Sierpinski Triangles, Koch Snowflakes, Dragon Curves) are constructed via recursive self-similarity. Ensure your algorithm includes a clear base case to prevent stack overflows.
  • Path Generation: Construct valid SVG path commands using standard path syntax (M for move-to, L for line-to, Z for closepath) or use inkex.paths.Path for complex multi-segment curves.
  • Styling: Styles are applied as CSS attribute dictionaries on elements (e.g., elem.style = {'stroke': '#000', 'fill': 'none'}).
  • Coordinate Space: Access the canvas view attributes using self.svg.namedview to ensure objects are rendered in the visible viewport rather than outside boundaries.

Deploying the Extension

  1. Locate your Inkscape user extensions directory:
    • Linux: ~/.config/inkscape/extensions/
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/
    • Windows: %APPDATA%\inkscape\extensions\
  2. Copy both fractal_generator.inx and fractal_generator.py into that directory.
  3. Restart Inkscape.
  4. Navigate to Extensions > Render > Geometric Fractal Generator to run the tool.
