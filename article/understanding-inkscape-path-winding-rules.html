Understanding Inkscape Path Winding Rules

Winding rules in Inkscape determine which enclosed areas of a vector path are treated as the "interior" to be filled with color and which remain transparent holes. When working with complex, overlapping, or compound paths, Inkscape relies on two mathematical algorithms—the Non-Zero rule and the Even-Odd rule—to interpret path direction and geometry. These rules directly dictate how vector shapes render on screen, ensuring predictable behavior during design creation, boolean operations, and file exports.

The Ray-Casting Concept

To determine whether any given point lies inside or outside a path, Inkscape conceptually casts an imaginary ray from that point outward to infinity in any direction. The software then counts how many times this ray intersects the path's outline. How Inkscape interprets these intersections depends entirely on the active winding rule assigned to the path.

The Non-Zero Winding Rule

The Non-Zero rule is the default standard in SVG specifications and Inkscape. This rule accounts for the direction in which the path was drawn (clockwise versus counter-clockwise):

  • Every time the test ray crosses a path segment drawn from left to right relative to the ray, a value of +1 is added to a counter.
  • Every time the ray crosses a segment drawn from right to left, 1 is subtracted from the counter.
  • If the final count equals zero, the point is outside the shape and remains unfilled. If the count is anything other than zero, the point is inside the shape and receives the fill color.

Because direction matters, two overlapping shapes drawn in the same direction will merge into a single solid fill. If one shape is nested inside another and drawn in the opposite direction, the inner shape creates an empty hole.

The Even-Odd Winding Rule

The Even-Odd rule ignores path direction completely and focuses purely on the number of boundary crossings:

  • Inkscape counts the total number of path segments the ray intersects on its way to infinity.
  • If the total number of intersections is odd, the point is considered inside the shape and is filled.
  • If the total number of intersections is even, the point is outside the shape and left unfilled.

This rule creates alternating filled and unfilled regions. It is especially useful for nested concentric shapes, such as target rings, where alternating bands of fill and transparency are desired without needing to manually manage path directions.

Practical Impact in Inkscape Workflows

The winding rule plays a critical role in several core Inkscape functions:

  • Compound Paths: When combining multiple paths using Path > Combine (Ctrl+K), the winding rule dictates whether overlapping shapes cut holes through one another or merge seamlessly.
  • Fixing Fill Anomalies: If a combined path unexpectedly fills in an intended cutout, the issue is typically that both sub-paths share the same direction under the Non-Zero rule. Flipping the direction of the inner path via Path > Reverse resolves the issue without altering the outer geometry.
  • Switching Fill Rules: Inkscape allows designers to manually toggle between the Non-Zero and Even-Odd rules for any selected object directly within the Fill and Stroke dialog (Shift+Ctrl+F) under the Fill tab, providing immediate control over complex geometric cutouts.
