Create Flat Long Shadows on Icons in Inkscape

This guide explains how to create flat-style long shadows for vector icons using Inkscape. You will learn how to generate consistent 45-degree geometric projections from an icon shape, merge the resulting paths, apply transparency gradients, and clip the shadow within a background boundary for a clean, modern aesthetic.

Step 1: Prepare Your Icon and Background

  1. Open your vector icon inside Inkscape.
  2. Ensure the icon elements are combined into a single path. If your icon consists of multiple shapes, select them all and go to Path > Union (or Ctrl + +). If there are strokes, convert them to paths first via Path > Stroke to Path.
  3. Place a background shape (such as a circle, rounded rectangle, or square) directly beneath the icon.

Step 2: Generate the Shadow Geometry

Inkscape provides an automated tool to extend shapes along a specified vector angle.

  1. Select your unified icon path.
  2. Duplicate the path by pressing Ctrl + D.
  3. Go to the top menu and select Extensions > Generate from Path > Motion.
  4. In the Motion dialog window, configure the following settings:
    • Magnitude: Set a value large enough to extend past the background boundary (e.g., 100 to 300 px depending on your canvas size).
    • Angle: Set to 315 degrees (for a standard bottom-right 45-degree shadow) or 225 degrees (for bottom-left).
  5. Check the Live Preview box to ensure the shadow extends fully past the background, then click Apply and close the window.

Step 3: Merge and Position the Shadow

  1. Inkscape will generate multiple path segments. While the generated shadow group is still selected, ungroup it by pressing Ctrl + Shift + G.
  2. Select the duplicated icon and all newly generated shadow segments, then combine them by clicking Path > Union.
  3. Lower the shadow path beneath the original icon by pressing Page Down or using the Lower selection one step button on the toolbar.

Step 4: Style the Shadow

  1. Open the Fill and Stroke panel (Ctrl + Shift + F).
  2. Set the shadow fill color to black (#000000) or a darker shade of your background color.
  3. Choose your preferred shading style:
    • Flat Opacity: Keep the fill solid and lower the layer Opacity slider to between 10% and 25%.
    • Fading Gradient: Switch the fill to Linear Gradient. Set the starting stop near the icon to a semi-transparent dark tone and the ending stop at the edge of the canvas to 0% opacity.

Step 5: Trim the Shadow to the Background

  1. Select the background shape and duplicate it using Ctrl + D.
  2. Hold Shift and select the shadow path as well (you should now have the duplicated background and the shadow selected).
  3. Go to Path > Intersection (or Ctrl + *). Alternatively, you can use Object > Clip > Set to non-destructively mask the shadow within the background boundary.
