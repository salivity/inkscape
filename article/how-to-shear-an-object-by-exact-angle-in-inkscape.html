How to Shear an Object by Exact Angle in Inkscape

Shearing (or skewing) an object in Inkscape allows you to slant its shape along the horizontal or vertical axis without changing its overall height or width. While you can skew objects manually using on-canvas selection handles, achieving a precise angle requires the dedicated Transform tool. This guide provides a straightforward walkthrough on using Inkscape’s Transform dialog to shear any vector object or path by an exact angle in degrees.

Step 1: Select Your Object

  1. Open your project in Inkscape.
  2. Choose the Select and Transform Objects tool (the top black arrow on the toolbar, or press S / F1).
  3. Click on the object or path you want to shear. If you want to shear multiple objects together, hold Shift and click each one, or drag a selection box around them.

Step 2: Open the Transform Dialog

You can open the Transform panel using either the top menu or a keyboard shortcut:

  • Menu: Go to the top menu bar and select Object > Transform...
  • Shortcut: Press Shift + Ctrl + M on Windows/Linux, or Shift + Cmd + M on macOS.

The Transform panel will appear as a dock on the right side of the workspace.

Step 3: Switch to the Skew Tab

Inside the Transform panel, you will see several tabs across the top: Move, Scale, Rotate, Skew, and Matrix.

  1. Click on the Skew tab.
  2. Ensure your unit of measurement is set correctly. Next to the input fields, click the dropdown menu and select deg (degrees).

Step 4: Enter the Exact Angle

Inkscape allows you to shear along the horizontal axis (Horizontal (X)) or the vertical axis (Vertical (Y)):

  • Horizontal Skew (X): Slants the sides of the object to the left or right while keeping the top and bottom edges parallel to the horizontal axis. Enter a positive degree value to slant to the right, or a negative value to slant to the left.
  • Vertical Skew (Y): Slants the top and bottom of the object up or down while keeping the vertical sides aligned. Enter a positive degree value to slant upward, or a negative value to slant downward.

Note: If you only want to shear in one direction, make sure the other axis value is set to 0.00.

Step 5: Apply the Transformation

  1. If you are shearing multiple objects, decide whether you want them to shear as a unified group or individually by checking or unchecking the Apply to each object separately box.
  2. Click the Apply button at the bottom of the dialog.

Inkscape will immediately slant the selected object to the exact angle specified. If you need to revert the change, press Ctrl + Z (or Cmd + Z on macOS).
