How to Use the Connector Tool in Inkscape

Inkscape's Connector tool allows you to create dynamic flowcharts, network diagrams, and system architectures with lines that automatically stay attached to objects even when you move them. This guide explains how to set up your diagram elements, draw and route connecting lines, configure automatic object avoidance, and style connectors for clean, professional diagrams.

1. Create Your Diagram Shapes

Before drawing connectors, place the nodes for your diagram:

  1. Use the Rectangle Tool (R) or Ellipse Tool (E) to create the base shapes representing network devices, process steps, or decisions.
  2. Use the Text Tool (T) to label each shape.
  3. Group each shape with its text label by selecting both and pressing Ctrl + G so they move as a single unit.

2. Activate the Connector Tool

Select the Create Diagram Connectors tool from the left-hand toolbar, or press the shortcut key O (or Ctrl + F11 depending on your version).

When the tool is active, hovering over any shape reveals a connection handle in the center or along the boundaries of the object.

3. Connect Shapes Together

  1. Click and hold on the connection handle of the source object.
  2. Drag the cursor to the target object until its connection handle highlights.
  3. Release the mouse button.

The two shapes are now linked. If you switch back to the Select Tool (S) and move either shape, the connecting line automatically stretches, compresses, and repositions itself to maintain the link.

4. Adjust Connector Routing Modes

With the Connector tool active, use the top Tool Controls bar to modify how lines navigate between shapes:

  • Avoid Overlapping Objects: Toggle the Make connectors avoid selected objects button to force lines to route around shapes rather than passing through them.
  • Orthogonal vs. Polyline: Choose between right-angle connectors (ideal for standard flowcharts and circuit-style diagrams) and direct diagonal lines.
  • Set Connector Spacing: Adjust the curvature or length properties to define how much clearance the connector maintains from nearby objects.

5. Style Lines and Add Arrowheads

To turn plain paths into standard flowchart arrows:

  1. Select the connector using either the Connector Tool or the Select Tool.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Go to the Stroke style tab.
  4. Adjust the Width to set the line thickness.
  5. Use the Markers drop-down menus to assign arrowheads to the start or end of the path.
  6. In the Stroke paint tab, change the line color to match your color scheme.

6. Rearrange and Optimize the Layout

Inkscape includes automatic graph arrangement features within the Connector Tool Controls:

  • Arrange Network: Click the Arrange button in the top controls bar to automatically distribute connected objects cleanly across the canvas.
  • Detaching Connectors: To remove a connection, click the connector line and press Delete, or drag one end away from an object's connection handle to disconnect that specific end.
