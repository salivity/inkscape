How to Use Perspective Envelope in Inkscape

This guide explains how to dynamically distort vector designs using the Perspective/Envelope Live Path Effect (LPE) in Inkscape. By mapping 2D paths to custom four-point grids, this tool allows you to simulate 3D vanishing points, fit designs onto mockups, and create curved typographic envelopes while keeping your original vectors fully editable.

Step 1: Prepare Your Artwork

The Perspective/Envelope LPE requires your artwork to be composed of paths.

  1. Select your artwork. If it includes text or primitive shapes (rectangles, circles), convert them to paths by navigating to Path > Object to Path.
  2. If your artwork consists of multiple separate paths, group them together by pressing Ctrl + G (or Cmd + G on macOS), or combine them into a single compound path using Path > Combine (Ctrl + K).

Step 2: Open the Path Effects Dialog

  1. With your artwork selected, open the Path Effects panel by navigating to Path > Path Effects.
  2. In the panel that opens on the right, click the + (Add Path Effect) button.
  3. In the search bar of the selector dialog, type Perspective/Envelope and click on it to apply the effect to your selected object.

Step 3: Choose Your Deformation Mode

In the Path Effects panel, you will see two primary modes under the Perspective/Envelope settings:

  • Perspective: Constrains the bounding edges to straight lines. This mode mimics geometric 3D planes and vanishing points, making it ideal for placing artwork on flat surfaces like billboards, boxes, or book covers.
  • Envelope deformation: Allows each bounding edge to bend independently via Bézier handles. This mode is best for fitting artwork onto curved surfaces like mugs, cylinders, or arching banners.

Select the mode that matches your desired outcome.

Step 4: Deform the Vector Artwork

  1. Switch to the Node Tool by pressing N or selecting it from the left toolbar.
  2. A green bounding frame with four corner control nodes will appear around your artwork.
  3. Click and drag the corner nodes to alter the perspective:
    • In Perspective mode, dragging a node stretches the artwork proportionally along linear projection lines.
    • In Envelope mode, clicking along the edge reveals Bézier handles, allowing you to curve the top, bottom, left, or right sides independently.

Step 5: Finalize the Design (Optional)

Because Live Path Effects are non-destructive, you can re-adjust the deformation at any time using the Node tool.

If you need to export the file to another vector program, send it to a laser cutter, or plot it, convert the dynamic effect into static geometry. With the artwork selected, go to Path > Object to Path. This bakes the deformation permanently into the vector nodes and removes the dynamic effect.
