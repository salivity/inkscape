Create Embroidery PDF Worksheets in Inkscape

Generating PDF embroidery worksheets with thread color charts directly from Inkscape is achieved through the free, open-source Ink/Stitch extension. This guide details the exact steps to convert your vector embroidery designs into professional, printable instruction sheets that outline stitch counts, stop sequences, design dimensions, and manufacturer-specific thread color palettes.

1. Prepare Design and Thread Palettes

Before generating instructions, assign real-world embroidery thread brands to your design elements so the worksheet can display accurate color codes and manufacturer names:

  1. Open your finished embroidery design in Inkscape.
  2. Open the palette selection menu by clicking the small arrow at the bottom right corner of the color palette bar.
  3. Select an embroidery manufacturer's color palette (e.g., Madeira, Brother, Sulky, or Robison-Anton).
  4. Apply these specific palette colors to the strokes and fills of your embroidery elements. Ink/Stitch uses these exact swatches to read thread numbers and descriptions.

2. Open the Print Setup Tool

Ink/Stitch includes a built-in rendering tool designed specifically for technical printouts:

  1. Navigate to the top menu bar.
  2. Click Extensions > Ink/Stitch > Visualize and Export > Print / Make PDF Worksheets...
  3. A preview dialog window will appear showing the preliminary layout of your instruction sheet.

3. Configure Sheet Details and Thread Charts

Customize the technical data that appears on the instruction sheet:

  • Page Settings: Choose the standard page format (such as Letter or A4) and select either Portrait or Landscape orientation depending on the shape of your embroidery design.
  • Thread List Options: Ensure the Color Palette or Thread List toggle is enabled. Ink/Stitch will construct an itemized table listing color blocks in sewing order, complete with thread numbers, brand names, color swatches, and estimated stitch counts per color.
  • Design Visuals: Check the options to include a scaled design preview, an alignment grid, hoop outlines, and center markers to help machine operators position the fabric correctly.
  • Metadata: Enter custom metadata such as the project name, author, and specific production notes in the designated fields.

4. Export the PDF File

  1. Review the generated layout within the preview window to confirm that the thread sequence matches your desired production order.
  2. Click the Save or Export to PDF button in the dialog box.
  3. Choose a destination folder on your computer, enter a file name, and confirm to save the PDF.

The resulting PDF contains a complete operator worksheet that can be printed or viewed on a tablet alongside your embroidery machine.
