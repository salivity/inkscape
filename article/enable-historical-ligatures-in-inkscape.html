Enable Historical Ligatures in Inkscape

This guide explains how to enable historical ligatures, such as the long s-t ligature, in Inkscape using built-in OpenType controls. Inkscape supports advanced typographic features natively, allowing you to access archaic glyph pairings and stylistic variants as long as the selected font contains the necessary OpenType data.

Step 1: Choose a Font That Supports Historical Ligatures

Inkscape relies on the font itself to supply historical glyphs. Standard system fonts rarely contain them, so you must use an OpenType font designed with historical typography support, such as EB Garamond, Junicode, Cardo, or Linux Libertine.

Step 2: Open the Text and Font Dialog

  1. Select the Text tool (T) from the left toolbar.
  2. Type or select the text containing the characters you want to merge (such as "st").
  3. Open the typographic settings by navigating to Text > Text and Font... in the top menu bar, or press Shift + Ctrl + T.

Step 3: Access OpenType Features

  1. In the Text and Font panel on the right, switch to the Features tab located next to the "Font" tab.
  2. Expand the Ligatures category by clicking the arrow next to it.
  3. Locate Historical Ligatures (OpenType feature tag hlig) and check the box next to it.
  4. If your font stores the long s-t pairing under standard optional ligatures, check Discretionary Ligatures (dlig) as well.
  5. If you need the single long s ("ſ") throughout the text rather than just paired in ligatures, expand the Historical Forms section and check Historical Forms (hist).

Step 4: Apply the Changes

  1. Ensure the relevant text on the canvas is still selected.
  2. Click the Apply button at the bottom of the Text and Font panel.
  3. The selected character combination will automatically render as the historical ligature.

Alternative Method: Insert via Glyphs Dialog

If the font lacks OpenType ligature automation, you can insert the precomposed character manually:

  1. Double-click the text object to activate the text cursor where you want the character.
  2. Go to Text > Glyphs... in the top menu.
  3. Set the font family to your chosen font and select Latin Extended-A or Alphabetic Presentation Forms from the script/range dropdown.
  4. Locate the desired historical ligature (such as "ﬅ", Unicode U+FB05), select it, and click Append.
