How to Create Custom Palettes in Inkscape

This guide explains how to create, import, and manage custom color swatches and palettes in Inkscape. By learning how to generate document-specific swatches and save global palette files (.gpl), you can streamline your design workflow and quickly access consistent color schemes directly from Inkscape’s bottom Palette bar.

Step 1: Create Document Swatches

Document swatches allow you to store reusable colors within a specific file.

  1. Select an object on your canvas.
  2. Open the Fill and Stroke dialog by pressing Ctrl + Shift + F (or Cmd + Shift + F on macOS).
  3. Choose your desired color in the Fill or Stroke paint tab.
  4. Click the Swatch button (the icon depicting a grid of color tiles) located next to the solid color and gradient icons.
  5. Open the Swatches dialog by navigating to View > Swatches or pressing Ctrl + Shift + W. Your new color will appear here.

Step 2: Export or Create a Custom Palette File

Inkscape uses the GIMP Palette format (.gpl) for its color bars. You can create a permanent palette file using your document colors.

Method A: Using Built-in Extensions

  1. Ensure all your custom colors are applied to objects on the canvas.
  2. Go to Extensions > Export > Export to Palette....
  3. Enter a name for your palette and choose an output location.
  4. Click Apply to generate the .gpl file.

Method B: Manual File Creation

You can create a .gpl file in any plain text editor:

  1. Open a text editor (such as Notepad or TextEdit) and add the following header: 
    GIMP Palette
Name: My Custom Palette
Columns: 4
#
  2. Below the # line, add your colors using RGB values followed by the color name: 
    255   0   0   Primary Red
  0 128 255   Sky Blue
 40  40  40   Dark Charcoal
  3. Save the file with the .gpl extension (for example, My_Palette.gpl).

Step 3: Install the Palette into Inkscape

To make your custom palette appear in the Palette bar across all projects:

  1. Locate your Inkscape User Palettes directory:
    • Open Inkscape and go to Edit > Preferences > System.
    • Look for the path listed next to User palettes.
  2. Click the Open button next to the path to open the directory in your file manager.
  3. Move your .gpl file into this folder.
  4. Restart Inkscape to load the new palette.

Step 4: Access and Manage the Palette Bar

  1. Look at the bottom right corner of the Inkscape window, next to the color strip.
  2. Click the small arrow icon (or menu icon) located at the far right of the color bar.
  3. Scroll through the list and select the name of your custom palette.
  4. Use the same menu to configure the display settings:
    • Tile Size: Adjust the size of individual color swatches.
    • Shape: Set tiles to be rectangular, circular, or square.
    • Border: Enable or disable spacing borders between swatches.
    • Rows: Increase the number of rows displayed at the bottom of your workspace.
