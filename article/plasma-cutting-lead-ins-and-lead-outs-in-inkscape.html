Plasma Cutting Lead-Ins and Lead-Outs in Inkscape

Creating lead-in and lead-out paths in Inkscape ensures that the initial plasma pierce and final cut-off occur away from your finished part's edge, preventing unsightly gouges and blemishes. This step-by-step guide explains how to manually draw, connect, and configure precise lead-in and lead-out geometry using Inkscape's native path and node tools for clean plasma CNC cutting.

Why Lead-Ins and Lead-Outs Are Essential

When a plasma torch pierces metal, it blasts molten slag upward and creates a crater wider than the standard cutting kerf. A lead-in moves this initial pierce point into the scrap material and guides the torch onto the cut perimeter at cutting speed. A lead-out gently moves the torch away from the finished edge as the arc shuts off, preventing end-point divots.

Method 1: Drawing Manual Lead-In and Lead-Out Paths

Manual path creation gives you full control over entry angles, curve radii, and placement on complex contours.

Step 1: Prepare Your Vector Shape

  1. Select your graphic or shape using the Select Tool (S).
  2. Convert it to a path by going to Path > Object to Path (Shift + Ctrl + C).
  3. Set the stroke to a visible thickness and remove any fill color (Object > Fill and Stroke).

Step 2: Split the Contour at the Entry Point

  1. Select the Node Tool (N).
  2. Click on the perimeter where you want the cut to begin (flat sections or inside corners are ideal).
  3. If no node exists there, double-click the line to create a new node.
  4. With the node selected, click the Break path at selected nodes button on the top toolbar. This separates your closed shape into an open path with matching start and end nodes.

Step 3: Draw the Lead-In Line

  1. Switch to the Draw Bezier Curves and Straight Lines Tool (B).
  2. For an inside cut (a hole/cutout), place your starting point inside the scrap area. For an outside cut (part perimeter), place your starting point outside the part.
  3. Draw a straight line or an arc toward the start node created in Step 2:
    • Straight/Angled Lead-In: Click once in the scrap area, then click directly on the start node (enable snapping to nodes for precision).
    • Curved/Radiused Lead-In: Click and drag in the scrap area to create a smooth tangent arc leading into the contour.

Step 4: Draw the Lead-Out Line (Optional)

  1. Using the Bezier tool, click on the end node of your cut profile.
  2. Extend the path back into the scrap material (often crossing over the lead-in line slightly to ensure the part drops free).
  3. Double-click or press Enter to finish the path.

Step 5: Join the Path Segments

  1. Switch back to the Select Tool (S) and select the lead-in segment, the main profile, and the lead-out segment simultaneously (Shift + Click).
  2. Combine them into one path object by going to Path > Combine (Ctrl + K).
  3. Switch to the Node Tool (N).
  4. Select the overlapping nodes where the lead-in connects to the part perimeter, then click Join selected nodes in the top control bar. Repeat this for the lead-out connection if applicable.

Method 2: Verifying Cut Direction

Plasma torches have a swirling gas vortex that leaves one side of the cut squarer than the other (typically the right side relative to torch movement).

  1. Select your completed path with the Node Tool (N).
  2. Go to Edit > Preferences > Tools > Node and ensure Show path direction on outlines is checked.
  3. Check the directional arrows along your path:
    • Outside cuts: The torch should move clockwise.
    • Inside cuts: The torch should move counterclockwise.
  4. If the path runs the wrong way, select the path and go to Path > Reverse.

Exporting for CAM

Once your lead-in and lead-out paths are connected and verified:

  1. Save your master design as an Inkscape SVG.
  2. Go to File > Save As and choose Desktop Cutting Plotter (AutoCAD DXF R14) or Plain SVG, depending on the file format required by your CNC plasma CAM software (such as SheetCAM, Fusion 360, or Pronterface).
  3. Ensure base units match your CAM scale (inches or millimeters) during export to maintain accurate lead-in dimensions.
