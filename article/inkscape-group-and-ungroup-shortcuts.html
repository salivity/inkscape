Inkscape Group and Ungroup Shortcuts

Managing complex vector artwork requires organizing multiple objects efficiently, and Inkscape provides dedicated keyboard shortcuts to accomplish this instantly. This guide covers the fastest shortcuts to group and ungroup vector elements in Inkscape, explaining how combining multiple paths into single selectable units or breaking apart nested structures can significantly speed up your design workflow.

The Fastest Shortcuts

  • Group: Press Ctrl + G (Windows/Linux) or Cmd + G (macOS).
  • Ungroup: Press Ctrl + Shift + G or Ctrl + U (Windows/Linux) or Cmd + Shift + G / Cmd + U (macOS).

How to Group Elements

  1. Activate the Select and Transform objects tool by pressing S or F1.
  2. Select the vector objects you want to combine. You can drag a selection box around them or hold Shift while clicking each element.
  3. Press Ctrl + G.

The individual bounding boxes will merge into a single bounding box. All grouped paths can now be moved, scaled, and transformed together without altering their relative positions.

How to Ungroup Elements

  1. Click on the grouped object using the Selector tool.
  2. Press Ctrl + Shift + G (or Ctrl + U).

The single bounding box will split back into individual selection frames, returning each component to an independent vector element.

Managing Nested Groups

When elements contain groups within groups (nested groups), pressing the ungroup shortcut once only dissolves the outermost container.

  • Full Ungroup: Press Ctrl + Shift + G repeatedly until the status bar at the bottom of the window confirms there are no more groups to ungroup.
  • Edit Inside a Group: Double-click any grouped item with the Selector tool to enter the group context. This lets you modify individual shapes without dissolving the overall group structure. Double-click an empty area of the canvas or press Esc to exit.
