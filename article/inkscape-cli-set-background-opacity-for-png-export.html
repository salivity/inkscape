Inkscape CLI: Set Background Opacity for PNG Export

Exporting PNG images with custom page background opacity via the Inkscape command line is accomplished using the --export-background-opacity parameter (or its shorthand, -y). This article details how to control background transparency across different Inkscape versions, provides exact command-line syntax for both fully transparent and semi-transparent backgrounds, and covers complementary options such as defining background color.

The Background Opacity Flag

Inkscape controls background alpha through the following flags:

  • --export-background-opacity=VALUE (or -y VALUE): Defines the alpha value of the exported canvas background.
  • --export-background=COLOR (or -b COLOR): Defines the background color using standard hex codes (e.g., #ffffff) or color names.

In modern versions of Inkscape, the opacity value is represented either as a float from 0.0 (fully transparent) to 1.0 (fully opaque), or as a percentage/integer up to 255 depending on your environment. Using a decimal value between 0.0 and 1.0 is the standard cross-platform approach.

Modern Syntax (Inkscape 1.0 and Newer)

Starting with Inkscape 1.0, the command-line interface uses --export-filename and --export-type.

Exporting with a Fully Transparent Background

By default, SVG documents often inherit their defined document properties, but you can explicitly force a transparent background (alpha of 0.0):

inkscape input.svg --export-type="png" --export-background-opacity=0.0 --export-filename="output.png"

Exporting with a Semi-Transparent Background

To export an image with a specific background color and 50% opacity, combine --export-background and --export-background-opacity:

inkscape input.svg --export-type="png" --export-background="#ffffff" --export-background-opacity=0.5 --export-filename="output.png"

Using short options:

inkscape input.svg -o output.png -b "#000000" -y 0.75

Legacy Syntax (Inkscape 0.92 and Older)

If you are using Inkscape version 0.92 or earlier, the CLI required the headless mode flag (-z or --without-gui) and used -e for PNG export.

Fully Transparent Background (Legacy)

inkscape -z -e output.png -y 0.0 input.svg

Colored Semi-Transparent Background (Legacy)

inkscape -z -e output.png -b "#ffffff" -y 0.5 input.svg

Common Use Cases and Tips

  • Overriding SVG Document Settings: If your SVG file has a background color set within <sodipodi:namedview pagecolor="..." inkscape:pageopacity="..." />, passing --export-background-opacity at the command line overrides the file's internal settings.
  • Batch Processing: To batch convert SVGs to transparent PNGs, pair the flag with standard shell loops: 
    for file in *.svg; do
  inkscape "$file" --export-type="png" --export-background-opacity=0.0 --export-filename="${file%.svg}.png"
done
