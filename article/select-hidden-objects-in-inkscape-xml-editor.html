Select Hidden Objects in Inkscape XML Editor

This guide explains how to locate and select all hidden objects within an active layer using Inkscape's built-in XML Editor. By navigating the underlying SVG document tree, you can directly identify child elements possessing hidden visibility attributes and select them for modification, unhiding, or deletion without disrupting the visible artwork on your canvas.

Step 1: Open the XML Editor

  1. Open your project in Inkscape.
  2. Launch the XML Editor by navigating to Edit > XML Editor from the top menu, or by pressing the keyboard shortcut Ctrl + Shift + X (or Cmd + Shift + X on macOS).
  3. Dock or position the XML Editor dialog alongside your canvas for easy viewing.

Step 2: Locate the Active Layer

  1. In the XML Editor tree (left pane), look for the main <svg:svg> root node and expand it.
  2. Layers in Inkscape are grouped as <svg:g> elements. To find your active layer, click on the layer in your main workspace or locate the <svg:g> node that contains the attribute inkscape:groupmode="layer".
  3. Verify the layer's identity by checking the inkscape:label attribute in the right-hand attribute list, which corresponds to the layer's display name.

Step 3: Identify Hidden Child Elements

  1. Click the arrow icon next to the active layer’s <svg:g> tag to expand all elements nested directly inside that layer.
  2. Hidden elements in Inkscape are defined by their inline styles or visibility attributes. Click through the child tags (such as <svg:path>, <svg:rect>, or <svg:circle>).
  3. In the attribute panel on the right, look for the style attribute containing either:
    • display:none
    • visibility:hidden

Step 4: Multi-Select the Hidden Objects

  1. Click on the first XML node within the layer that contains the hidden attribute.
  2. Hold down the Ctrl key (or Cmd on macOS) and click each subsequent hidden object node in the tree to add it to your selection.
  3. If the hidden objects are listed consecutively within the layer, you can click the first hidden node, hold Shift, and click the last hidden node to select the entire range.

Once selected in the XML tree, the hidden objects are fully active in your selection. You can delete them by pressing Delete, remove the display:none property in the attribute panel to make them visible, or adjust their XML properties simultaneously.
