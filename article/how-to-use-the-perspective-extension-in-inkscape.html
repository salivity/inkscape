How to Use the Perspective Extension in Inkscape

This guide explains how to project 2D vector artwork onto an angled plane using Inkscape's Envelope/Perspective extension. You will learn how to prepare your source artwork, draw the target quadrilateral frame correctly, and apply the extension to achieve realistic perspective and vanishing point effects in your vector illustrations.

Step 1: Prepare Your Artwork

The Perspective extension requires the source object to be a path or a combined set of paths.

  1. Select your artwork or text.
  2. If working with text or basic shapes (rectangles, circles), convert them to paths by going to Path > Object to Path.
  3. If your artwork consists of multiple separate paths, select all of them and go to Path > Combine (or group them together, depending on your Inkscape version; combining into a single path yields the most reliable results).

Step 2: Draw the Destination Plane

The extension maps the rectangular bounding box of your artwork to a four-node path. The direction and starting point of this path dictate the orientation of the projected artwork.

  1. Select the Draw Bezier curves and straight lines tool (pen tool).
  2. Click four times to create a four-sided polygon (quadrilateral) that represents the plane or surface where the artwork should appear.
  3. Draw the nodes in this specific order to prevent the artwork from appearing flipped or inverted:
    • Node 1: Bottom-Left
    • Node 2: Top-Left
    • Node 3: Top-Right
    • Node 4: Bottom-Right
  4. Close the path by clicking back on the starting node (Node 1).

Step 3: Select the Objects in Order

The Perspective tool relies on a strict selection order to identify the source and the target.

  1. Select your source artwork first.
  2. Hold Shift and click the four-sided destination path to select it second.

Step 4: Apply the Extension

  1. Navigate to the top menu and select Extensions > Modify Path > Perspective (or Envelope, depending on whether you want a linear perspective mapping or a curved envelope deformation).
  2. Wait a moment for Inkscape to process the transformation.
  3. The source artwork will warp to fit precisely inside the four-sided polygon.
  4. Delete or hide the destination polygon path if it is no longer needed.

Important Troubleshooting Tips

  • Inverted or Rotated Results: If the artwork appears upside down or sideways, the target path was drawn in the wrong direction. Reverse the path direction using Path > Reverse, or redraw the four-sided shape starting strictly from the bottom-left corner and moving clockwise.
  • Extension Fails to Execute: Ensure that the target shape contains exactly four nodes. Shapes with fewer or more than four nodes will cause the extension to produce an error.
