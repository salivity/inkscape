Set SVG preserveAspectRatio in Inkscape

Configuring the preserveAspectRatio attribute in an SVG file allows you to control how graphics scale inside responsive viewports using the meet or slice operators. Because Inkscape does not have a dedicated GUI toggle for the meetOrSlice parameter in standard menus, you must apply this setting directly to the root SVG element using the built-in XML Editor. This guide explains how to set and adjust these scaling rules directly within Inkscape.

Understanding the meetOrSlice Syntax

The preserveAspectRatio attribute requires an alignment value paired with a scaling mode:

  • meet (default): Scales the graphic so the entire viewBox fits within the viewport while preserving the aspect ratio. All content remains visible, but letterboxing or pillarboxing (empty space) may occur.
  • slice: Scales the graphic so the viewBox covers the entire viewport while preserving the aspect ratio. Any parts of the graphic that extend beyond the viewport bounds are clipped.

The standard syntax is formatted as: preserveAspectRatio="<alignment> <meetOrSlice>", such as xMidYMid meet or xMidYMid slice.

Step 1: Ensure a viewBox Exists

The preserveAspectRatio attribute only functions if a viewBox is defined on the SVG.

  1. Open your document in Inkscape.
  2. Go to File > Document Properties (or press Ctrl + Shift + D).
  3. Check the Viewbox fields (X, Y, Width, Height).
  4. If they are empty or zero, set appropriate dimensions matching your desired canvas size.

Step 2: Open the XML Editor

  1. Open the XML Editor by navigating to Edit > XML Editor or pressing Ctrl + Shift + X.
  2. In the left panel of the XML Editor, locate and select the top-level element, typically labeled <svg:svg ...>.

Step 3: Add or Edit preserveAspectRatio

  1. Look at the attributes list on the right side of the XML Editor.
  2. Check if preserveAspectRatio already exists:
    • If it exists: Select it, update the value field at the bottom, and click the Set button (or press Ctrl + Enter).
    • If it does not exist: In the attribute name field at the bottom right, type preserveAspectRatio. In the attribute value field, enter your desired alignment and meetOrSlice choice.
  3. Click the Set button to apply the attribute.

Common Value Examples:

  • xMidYMid meet: Centers the graphic horizontally and vertically, scaling down to fit the entire image inside the frame without clipping.
  • xMidYMid slice: Centers the graphic and scales it to fill the entire container, clipping edges that overflow.
  • xMinYMin slice: Aligns the graphic to the top-left corner and scales it to fill the container, clipping the right and bottom edges.
  • xMaxYMax meet: Aligns the graphic to the bottom-right corner and scales it to fit completely within the container.

Step 4: Save the SVG

Once the attribute is applied in the XML tree, save the file by choosing File > Save (Ctrl + S). For maximum compatibility with web environments, select Plain SVG (*.svg) in the save dialog to strip out proprietary Inkscape metadata.
