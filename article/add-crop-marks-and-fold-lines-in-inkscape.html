Add Crop Marks and Fold Lines in Inkscape

This guide explains how to generate standard crop marks and fold lines in Inkscape using the native Printing Marks extension. You will learn how to configure your document boundaries, generate precise trim indicators, create dashed fold lines for scoring, and export the final layout as a print-ready PDF suitable for commercial printing.

Step 1: Set Up the Document Dimensions

  1. Open Inkscape and navigate to File > Document Properties (or press Ctrl+Shift+D / Cmd+Shift+D).
  2. Under the Page tab, set your document to the final trim size of your printed piece (for example, standard Letter or A4).
  3. If your print shop requires an external bleed margin (typically 3 mm or 0.125 inches), ensure your artwork extends beyond the canvas edge by this amount.

Step 2: Generate Crop Marks

Inkscape includes a built-in layout tool that automatically draws trim marks around your page or selected objects.

  1. Navigate to Extensions > Render > Layout > Printing Marks...
  2. In the configuration window, locate the Marks tab:
    • Check Crop Marks to draw lines indicating where the paper should be trimmed.
    • Check Bleed Marks if you want secondary indicators showing the bleed limit.
    • Optionally enable Registration Marks and Color Bars if your commercial printer requests them.
  3. Switch to the Positioning tab:
    • Set the Bleed measurement to match your external bleed (e.g., 3.00 mm or 0.125 in).
    • Adjust the Offset to create a gap between the page edge and the start of the crop marks, preventing marks from printing inside the trimmed design.
  4. Set Selection/Page to Page (unless you want marks calculated around a specific selected object).
  5. Click Apply and then Close. Inkscape will create a new locked layer containing the generated vector marks.

Step 3: Create Standard Fold Lines

While the Printing Marks extension natively renders perimeter cuts and bleeds, standard fold lines require a dashed visual indicator to distinguish scoring from cutting.

  1. Create a new layer named Folds by going to Layer > Add Layer...
  2. Select the Pen (Bezier) Tool (B).
  3. Hold Ctrl to draw perfectly straight lines outside the page trim area at your fold locations (such as the two fold boundaries on a tri-fold brochure).
  4. Open the Fill and Stroke panel (Ctrl+Shift+F).
  5. In the Stroke paint tab, choose standard Registration Black (C:100 M:100 Y:100 K:100) or standard Black.
  6. In the Stroke style tab:
    • Set the line width to match your crop marks (typically 0.25 pt to 0.5 pt).
    • In the Dashes drop-down menu, select a standard dashed pattern. Dashed strokes represent folds to pre-press technicians, whereas solid strokes represent cut lines.
  7. Align the fold marks precisely with your fold coordinates using the Align and Distribute panel (Ctrl+Shift+A).

Step 4: Export to Print-Ready PDF

  1. Go to File > Save As... or File > Export...
  2. Select Portable Document Format (*.pdf) from the file type options.
  3. In the PDF export dialogue:
    • Ensure the Bleed/margin is set to cover the full area of your printing marks (do not clip to page size, or the marks outside the trim will be cropped out).
    • Set Output resolution to 300 dpi or higher.
    • If required by your printer, convert text to paths or ensure fonts are embedded.
  4. Click OK to generate the final PDF.
