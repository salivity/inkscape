How to Interpolate Stroke Widths in Inkscape

Interpolating stroke widths across an intermediate sequence of paths allows you to create smooth transitions in line thickness between vector elements. In Inkscape, this effect is achieved using the built-in Interpolate extension, which calculates both the geometry and the style attributes—including stroke width—between two paths. This guide explains how to prepare your paths and configure the extension to generate intermediate paths with progressively changing line weights.

1. Prepare the Starting and Ending Paths

  1. Draw your starting path using the Pen (Bezier) tool (B) or Pencil tool (F6).
  2. Duplicate the path (Ctrl + D) and move it to your desired end position, or draw a second distinct path. For the cleanest geometric transition, ensure both paths contain the same number of nodes.
  3. Open the Fill and Stroke panel (Ctrl + Shift + Shift + F or Object > Fill and Stroke).
  4. Select the starting path, navigate to the Stroke style tab, and enter the starting stroke width (for example, 2 px).
  5. Select the end path and set the target stroke width (for example, 16 px).

2. Apply the Interpolation Extension

  1. Select both paths simultaneously by holding Shift and clicking on each path.
  2. Go to the top menu and navigate to Extensions > Generate from Path > Interpolate....
  3. In the Interpolate dialogue box, configure the following parameters:
    • Interpolation Steps: Enter the number of intermediate paths you want to generate between the two originals.
    • Interpolation Method: Set this to 1 or 2 depending on how closely you want the curvature calculation to adhere to the control points (Method 2 tends to work better with sharp transitions).
    • Interpolate style: Check this box. This is the critical setting that instructs Inkscape to interpolate CSS styles, including stroke width and stroke color, rather than just geometric shapes.
  4. Check the Live preview box in the bottom-left corner to verify that the stroke widths scale smoothly from the first path to the last.
  5. Click Apply, then close the dialog window.

3. Adjust and Finalize the Output

  • Ungrouping: Inkscape places the generated intermediate paths into a single group. To modify, recolor, or adjust individual strokes, select the group and press Ctrl + Shift + G (or Object > Ungroup).
  • Path Direction: If the shapes twist or invert as they scale, the start and end paths are running in opposite directions. Select one of the original paths before interpolating and choose Path > Reverse to align their direction.
