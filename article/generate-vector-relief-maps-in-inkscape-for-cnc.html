Generate Vector Relief Maps in Inkscape for CNC

This guide details how to transform grayscale digital elevation data into layered vector contours using Inkscape for 3D wood CNC carving. By importing heightmaps, utilizing multi-scan brightness tracing, simplifying vector paths, and exporting them to CAM software, you can create clean, stepped topographical relief files optimized for efficient pocketing toolpaths in timber.

1. Acquire a Grayscale Heightmap

CNC relief carving requires height-based elevation data. Source a grayscale Digital Elevation Model (DEM) from platforms like OpenTopography, USGS EarthExplorer, or online heightmap generators. In these images, absolute white represents the highest elevation, pure black represents the lowest terrain or sea level, and shades of gray represent the elevations in between. Save your map as a high-resolution PNG or TIFF to maintain smooth gradient transitions.

2. Prepare the Canvas in Inkscape

  1. Open Inkscape and access File > Document Properties (Ctrl + Shift + D).
  2. Set your display units to millimeters or inches, matching the exact physical dimensions of your wood stock.
  3. Go to File > Import (Ctrl + I) and load your grayscale heightmap.
  4. Scale and align the image to fit your defined carving area, locking the aspect ratio to prevent geographical distortion.

3. Trace Elevation Contours

To convert the continuous grayscale raster into stepped vectors, use Inkscape’s bitmap tracing engine:

  1. Select the heightmap image.
  2. Navigate to Path > Trace Bitmap (Shift + Alt + B).
  3. In the Trace Bitmap panel, select the Multicolor tab and choose Brightness steps.
  4. Set the Scans count to your intended number of carving layers. For example, 10 scans on a 20 mm thick board allows for 2 mm depth increments per contour.
  5. Check Stack to create solid nested polygons rather than thin bands, which simplifies pocket toolpaths in CAM software.
  6. Check Remove background to eliminate flat borders around the map.
  7. Click Apply. Inkscape will generate a grouped set of vector paths directly over your raster image.

4. Clean and Optimize the Vectors

Raw traced contours often contain stray nodes and micro-islands that cause toolpath errors or prolonged CNC machining times:

  1. Select the newly created vector group and press Ctrl + Shift + G to ungroup the individual elevation levels.
  2. Delete the original raster heightmap from the background to reduce file size.
  3. Select all paths and open Path > Simplify (Ctrl + L) to reduce node density without altering key geographic features.
  4. Inspect the paths with the Node Tool (N). Manually select and delete any microscopic artifacts that are smaller than the diameter of your smallest CNC end mill.

5. Organize Layers for Depth Assignment

  1. Open the Layers and Objects panel (Ctrl + Shift + L).
  2. Rename each traced path according to its cut depth (e.g., Level_01_Base, Level_02_Mid, Level_03_Peak).
  3. Set the fill to empty and the stroke to a visible solid color for clear visibility, or assign a distinct color to each layer to help your CAM program automate depth assignment.

6. Export for CAM

  1. Verify that all objects are standard paths by selecting everything and clicking Path > Object to Path (Ctrl + Shift + C).
  2. Save your file as an Inkscape SVG or Plain SVG. If your CAM software requires CAD formats (such as Vectric VCarve, Carbide Create, or Fusion 360), go to File > Save As and select Desktop Cutting Plotter (AutoCAD DXF R14).
  3. In your CAM software, assign stepped 2D/2.5D pocket toolpaths to each layer, programming the cut depths sequentially from the widest base layer down to the highest topographical peaks.
