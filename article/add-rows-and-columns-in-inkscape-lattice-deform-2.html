Add Rows and Columns in Inkscape Lattice Deform 2

This guide explains how to increase the number of horizontal and vertical grid divisions in Inkscape's Lattice Deform 2 Live Path Effect (LPE). By adjusting the grid settings directly within the Path Effects panel, you can gain finer control over complex vector warping and deformation.

1. Open the Path Effects Panel

Ensure the Path Effects dialog is visible by selecting Path from the top menu and clicking Path Effects, or by pressing the shortcut Ctrl + & (or Ctrl + Shift + 7 depending on your version and OS).

2. Select Your Object

Using the Select and Transform objects tool (S), click on the vector path or grouped object that has the Lattice Deform 2 effect applied.

3. Adjust the Grid Control Points

In the Path Effects panel on the right side of the workspace, locate the settings for Lattice Deform 2:

  • Locate the parameters governing the grid resolution, typically labeled as Grid, Horizontal divisions, Vertical divisions, or numeric control point steppers.
  • Increase the horizontal value to add more columns.
  • Increase the vertical value to add more rows.

The default lattice typically begins with a 4x4 control grid. Increasing these numerical values dynamically inserts additional control rows and columns into the deformation cage.

4. Edit the Nodes

Switch to the Node Tool by pressing N or selecting it from the left toolbar. The newly added rows and columns will appear on your canvas as an expanded mesh of draggable handles, allowing you to manipulate the path with higher precision.
