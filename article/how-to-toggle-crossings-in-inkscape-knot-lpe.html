How to Toggle Crossings in Inkscape Knot LPE

Inkscape’s Knot Live Path Effect (LPE) automatically creates interlacing ribbon or Celtic-style patterns by generating gaps wherever paths intersect. While the effect assigns a default over-and-under pattern, you can manually control which path segment appears on top at each intersection. This guide explains how to switch into the correct editing mode and click through crossing points to toggle their crossover order directly on your canvas.

1. Apply or Select the Knot Effect

Ensure your path or group of paths already has the Knot effect applied. If you haven't added it yet, select your path, navigate to Path > Path Effects..., click the + (Add Path Effect) icon, and choose Knot.

2. Switch to the Node Tool

To interact with the path effect's hidden on-canvas controls, switch to the Node Tool by pressing N on your keyboard or clicking the Node Tool icon in the left-hand toolbar.

3. Click the Intersection Handles to Toggle

With the Node Tool active and the knotted path selected, Inkscape reveals interactive control handles:

  • Look closely at the intersections where the paths cross over each other. You will see small, circular handles located directly over each crossing point.
  • Click directly on any crossing handle.
  • Each click immediately flips the crossover order, toggling which segment passes over and which passes under.

4. Fine-Tune Gap Properties (Optional)

If the crossing handles are difficult to see or click, open the Path Effects dialog panel (Path > Path Effects...) with the path selected. Here you can adjust:

  • Gap length: Increase this value to make the break between paths wider, making the intersection handles easier to locate and select.
  • Stroke width: Ensure proportional spacing if using varied stroke profiles.

Once you have toggled all the intersections to your preferred arrangement, switch back to the Selector Tool (S) to resume standard editing.
