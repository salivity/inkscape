Inkscape Division vs Cut Path on Polygons

In Inkscape, both the Division and Cut Path operations use an overlapping top object to slice an underlying object, but they yield fundamentally different geometric results when applied to filled polygons. While the Division operation cuts a polygon into smaller, independent closed shapes that preserve the original fill and styling, the Cut Path operation slices only the polygon's perimeter into separate, open stroke segments and discards the fill entirely.

The Division Operation

When you select two overlapping paths and execute Path > Division (shortcut: Ctrl + /), the top path acts as a cookie cutter that slices through the entirety of the bottom filled polygon.

The resulting objects are multiple distinct, fully closed paths. Because each new piece remains a closed shape, all resulting segments retain the original object's fill color, opacity, and stroke properties. Division is primarily used when you need to split a 2D shape into puzzle-like pieces, create cross-sections, or slice an illustration into multiple colored sections while maintaining solid surfaces.

The Cut Path Operation

When you apply Path > Cut Path (shortcut: Ctrl + Alt + /), the top path acts like a pair of scissors that only cuts through the outline of the bottom polygon where the two paths intersect.

Instead of generating new closed shapes, Cut Path converts the boundary of the bottom polygon into disconnected, open path segments. Because the resulting paths are open lines rather than closed boundaries, the interior fill disappears completely. The outcome consists solely of stroke segments representing the perimeter. This operation is designed for wireframing, extracting specific borders, or trimming line art rather than splitting solid areas.

Summary of Differences

  • Geometry: Division produces multiple closed polygons. Cut Path produces multiple open line segments.
  • Fill Appearance: Division preserves the interior fill across all resulting pieces. Cut Path removes the fill because the resulting paths are no longer closed.
  • Top Object Consumption: Both operations consume and delete the cutting object (the top path) once the operation is executed.
  • Typical Use Case: Use Division to create multi-part solid graphics, shading areas, or sliced shapes. Use Cut Path to trim outlines, isolate perimeter segments, or open up closed vector loops.
