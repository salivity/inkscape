Adjust Saturation with feColorMatrix in Inkscape

This guide explains how to control color saturation in Inkscape using custom matrix math inside the feColorMatrix SVG filter primitive. While Inkscape provides a basic saturation slider, utilizing raw matrix mathematics allows for precise, non-destructive control over channel weights and luminance balancing. The following sections break down the underlying mathematical formula and detail the exact steps needed to implement a custom saturation matrix using Inkscape's Filter Editor.

The Mathematics of the Saturation Matrix

The standard SVG specification defines saturation through a 5x4 transformation matrix based on standard relative luminance coefficients: Red (\(0.2126\)), Green (\(0.7152\)), and Blue (\(0.0722\)).

When adjusting saturation by a factor of \(s\) (where \(s = 1\) is normal saturation, \(s = 0\) is complete grayscale, and \(s > 1\) increases saturation), the matrix operations scale each color channel relative to luminance:

  • Red output row:
    • \(R = 0.2126 + 0.7874s\)
    • \(G = 0.7152 - 0.7152s\)
    • \(B = 0.0722 - 0.0722s\)
  • Green output row:
    • \(R = 0.2126 - 0.2126s\)
    • \(G = 0.7152 + 0.2848s\)
    • \(B = 0.0722 - 0.0722s\)
  • Blue output row:
    • \(R = 0.2126 - 0.2126s\)
    • \(G = 0.7152 - 0.7152s\)
    • \(B = 0.0722 + 0.9278s\)

The fourth column represents the Alpha channel (which remains unmodified: \(0, 0, 0, 1, 0\)), and the fifth column represents an additive color offset (\(0\) across all rows).

Calculating Matrix Values

To increase saturation by 50% (\(s = 1.5\)):

  1. Row 1 (Red Output):
    • \(R = 0.2126 + (0.7874 \times 1.5) = 1.3937\)
    • \(G = 0.7152 - (0.7152 \times 1.5) = -0.3576\)
    • \(B = 0.0722 - (0.0722 \times 1.5) = -0.0361\)
  2. Row 2 (Green Output):
    • \(R = 0.2126 - (0.2126 \times 1.5) = -0.1063\)
    • \(G = 0.7152 + (0.2848 \times 1.5) = 1.1424\)
    • \(B = 0.0722 - (0.0722 \times 1.5) = -0.0361\)
  3. Row 3 (Blue Output):
    • \(R = 0.2126 - (0.2126 \times 1.5) = -0.1063\)
    • \(G = 0.7152 - (0.7152 \times 1.5) = -0.3576\)
    • \(B = 0.0722 + (0.9278 \times 1.5) = 1.4639\)

Applying the Matrix in Inkscape

  1. Select the object or image on your canvas you want to modify.
  2. Open the Filter Editor by navigating to Filters > Filter Editor.
  3. Click New in the Filter Editor panel to generate an empty filter, and check the box next to it to assign it to your selected object.
  4. In the "Add Effect" dropdown at the bottom of the panel, select Color Matrix and click Add Effect.
  5. Ensure the input node of the feColorMatrix primitive is connected to Source Graphic.
  6. Select the Color Matrix primitive in the list. Under the Effect parameters tab below, change the Type dropdown from Matrix to ensure the full 5x4 grid is visible (if it defaults to another mode, choose Matrix).
  7. Enter your calculated values into the respective cells of the grid:
    • Row 1: 1.3937 | -0.3576 | -0.0361 | 0 | 0
    • Row 2: -0.1063 | 1.1424 | -0.0361 | 0 | 0
    • Row 3: -0.1063 | -0.3576 | 1.4639 | 0 | 0
    • Row 4: 0 | 0 | 0 | 1 | 0

The object on your canvas will immediately update, rendering the custom saturation level via SVG matrix math. You can alter the values at any time to fine-tune channel intensity or achieve custom tinting effects within the same operation.
