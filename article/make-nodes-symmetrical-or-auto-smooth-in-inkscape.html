Make Nodes Symmetrical or Auto-Smooth in Inkscape

This guide explains how to convert path nodes into symmetrical or auto-smooth nodes using Inkscape's Node Tool. Mastering these node types allows you to create fluid, perfectly balanced curves and streamline your vector editing workflow.

Accessing the Node Tool

  1. Select your object on the canvas.
  2. Activate the Edit paths by nodes tool by pressing N (or F2), or by clicking the node icon in the left toolbar.
  3. Click directly on the path to reveal its nodes, then click on the specific node you want to adjust.

Making Node Handles Symmetrical

Symmetrical nodes lock both handles into a straight line and force them to maintain the exact same length. Adjusting the length or angle of one handle will automatically update the opposite handle identically.

  • Method 1 (Keyboard Shortcut): Select the node and press Shift + Y.
  • Method 2 (Toolbar): Select the node and click the Make selected nodes symmetric icon located in the top Tool Controls bar (represented by a square node with equal handles).

Making Node Handles Auto-Smooth

Auto-smooth nodes dynamically adjust the direction and length of their handles to maintain a natural, continuous curve whenever you move the node or its neighboring nodes.

  • Method 1 (Keyboard Shortcut): Select the node and press Shift + A.
  • Method 2 (Toolbar): Select the node and click the Make selected nodes auto-smooth icon in the top Tool Controls bar (represented by a circle node with automatic handles).

Note: If you manually drag the handle of an auto-smooth node, Inkscape will automatically convert it to a standard smooth node.

Key Differences Between Node Types

  • Symmetric (Shift + Y): Handles are locked in collinear alignment and equal distance.
  • Auto-Smooth (Shift + A): Handles adjust dynamically based on surrounding geometry.
  • Smooth (Shift + S): Handles remain aligned in a straight line, but you can adjust their lengths independently.
  • Cusp/Corner (Shift + C): Handles move independently of each other, allowing for sharp angles.
