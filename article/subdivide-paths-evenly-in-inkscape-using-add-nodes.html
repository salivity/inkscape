Subdivide Paths Evenly in Inkscape Using Add Nodes

This guide explains how to use Inkscape's built-in "Add Nodes" extension to subdivide path segments evenly across your artwork. By using this tool, you can automatically insert equidistant nodes along any vector line or shape, enabling precise geometric modifications, uniform deformations, and cleaner path manipulation without manually measuring and placing points.

1. Convert Your Shape to a Path

The Add Nodes extension only works on standard paths. If you are working with a predefined shape (such as a rectangle, ellipse, or star) or text, you must convert it first:

  1. Select the object using the Select Tool (S).
  2. Go to the top menu and click Path > Object to Path (or press Shift + Ctrl + C).

2. Select the Target Path

Ensure the path you wish to subdivide is actively selected on your canvas. If you only want to subdivide a specific part of a complex path, use the Node Tool (N) to select specific nodes; otherwise, selecting the whole object will apply the subdivision across all segments.

3. Open the Add Nodes Extension

  1. Navigate to the top menu and select Extensions.
  2. Hover over Modify Path.
  3. Click on Add Nodes... to open the tool's dialog box.

4. Configure Subdivision Settings

The dialog provides two primary methods for adding nodes:

  • By number of segments: Divides each existing segment between two nodes into a specified number of equal parts. For example, entering 2 will insert a single node directly in the middle of each segment, creating two equal halves.
  • By max segment length (px): Subdivides segments so that no individual segment exceeds the specified pixel length, spacing new nodes evenly along the path.

Check the Live preview box in the bottom-left corner of the dialog to see the adjustments directly on your canvas before applying them.

5. Apply and Verify

  1. Once satisfied with the preview, click Apply.
  2. Click Close to dismiss the dialog window.
  3. Switch to the Node Tool (N) to view and manipulate the newly generated, evenly spaced nodes along your path.
