How Inkscape Calculates Path Normal Vectors

This article explains the mathematical and algorithmic processes Inkscape uses to calculate normal and tangent vectors along a path when rendering SVG markers. Inkscape utilizes its underlying computational geometry engine, lib2geom, to evaluate parametric path derivatives, determine direction vectors at vertices, compute angle bisectors for intermediate nodes, and rotate these vectors to establish the surface normals required to orient markers correctly according to the SVG specification.

Parametric Curve Representation and Tangents

Inkscape represents vector paths as a series of parametric curve segments, typically cubic Bézier curves, line segments, or elliptical arcs. A 2D parametric segment is defined as:

\[\mathbf{P}(t) = (x(t), y(t)) \quad \text{where} \quad t \in [0, 1]\]

To establish an orientation at any point along a segment, Inkscape first calculates the tangent vector by taking the first derivative with respect to the parameter \(t\):

\[\mathbf{P}'(t) = \left( \frac{dx}{dt}, \frac{dy}{dt} \right)\]

Once the tangent vector \(\mathbf{T}(t) = \mathbf{P}'(t)\) is obtained, it is normalized to unit length:

\[\hat{\mathbf{T}}(t) = \frac{\mathbf{P}'(t)}{\|\mathbf{P}'(t)\|}\]

The corresponding normal vector \(\hat{\mathbf{N}}(t)\) is derived by rotating the unit tangent vector 90 degrees counterclockwise (or clockwise, depending on coordinate system conventions, typically \((-y', x')\) in standard Cartesian coordinates or \((y', -x')\) in computer graphics screen coordinates where the Y-axis points downward):

\[\hat{\mathbf{N}}(t) = (-\hat{T}_y(t), \hat{T}_x(t))\]

Calculating Vectors at Path Terminals

For marker-start and marker-end, Inkscape evaluates the directional vectors at the boundary limits of the respective segments:

  • Start Marker: The incoming tangent is evaluated at the start of the first segment as \(t \to 0^+\). The tangent is \(\mathbf{T}_{start} = \mathbf{P}'(0)\).
  • End Marker: The outgoing tangent is evaluated at the end of the final segment as \(t \to 1^-\). The tangent is \(\mathbf{T}_{end} = \mathbf{P}'(1)\).

The normal vectors at these boundaries are the perpendicular complements of these boundary tangents.

Angle Bisectors at Intermediate Vertices (Mid Markers)

For intermediate vertices (marker-mid), an incoming segment ends and an outgoing segment begins. Inkscape follows the W3C SVG specification for markers configured with orient="auto":

  1. Calculate Incident Tangents: The normalized incoming tangent vector \(\hat{\mathbf{u}}_{in}\) is computed at \(t = 1\) of the preceding segment. The normalized outgoing tangent vector \(\hat{\mathbf{u}}_{out}\) is computed at \(t = 0\) of the subsequent segment.
  2. Vector Summation (Bisector): Inkscape computes the average directional vector by summing the two unit vectors: \[\mathbf{V}_{mid} = \hat{\mathbf{u}}_{in} + \hat{\mathbf{u}}_{out}\]
  3. Normalization: If \(\|\mathbf{V}_{mid}\| \neq 0\), the vector is normalized: \[\hat{\mathbf{T}}_{mid} = \frac{\mathbf{V}_{mid}}{\|\mathbf{V}_{mid}\|}\]
  4. Normal Derivation: The marker normal \(\hat{\mathbf{N}}_{mid}\) is generated directly orthogonal to \(\hat{\mathbf{T}}_{mid}\). This bisects the interior/exterior angle between the two joining segments, ensuring the marker aligns symmetrically across the joint.

Edge Cases and Degenerate Segments

Inkscape must handle specific degenerate states where the first derivative evaluates to zero:

  • Zero-Length Segments and Cusps: If \(\mathbf{P}'(t) = (0, 0)\) (such as at a cusp point on a Bézier curve), lib2geom evaluates higher-order derivatives (such as the second derivative \(\mathbf{P}''(t)\)) using L'Hôpital's rule principles to find the limiting direction of the curve.
  • Opposing Collinear Segments (180° Reversals): When the incoming and outgoing vectors point in exactly opposite directions (\(\hat{\mathbf{u}}_{in} + \hat{\mathbf{u}}_{out} = \mathbf{0}\)), vector addition yields a zero vector. In this case, Inkscape falls back to using the incoming vector \(\hat{\mathbf{u}}_{in}\) or the outgoing vector depending on subpath context to compute the orthogonal normal.
  • Subpath Discontinuities: For non-continuous subpaths created by SVG M (moveto) commands, terminal rules apply to each open boundary rather than computing bisectors.
