How to Make Sunburst Charts in Inkscape

This guide explains how to generate scalable vector sunburst charts for hierarchical data visualization using Inkscape. Because Inkscape does not feature a dedicated one-click sunburst tool, you will learn how to structure your hierarchical values into proportional angles, build concentric layers using the circle and arc tools, slice them into distinct path segments, and style the resulting vector visualization for high-resolution output.

1. Prepare Your Data and Proportions

A sunburst chart visualizes hierarchical trees using concentric rings: the center circle represents the root or main categories, and each outward ring breaks down into subcategories.

  1. Calculate the percentage of the whole for each category and subcategory.
  2. Convert these percentages into degrees by multiplying each proportion by 360.
  3. Keep track of cumulative start and end angles for each segment so that child categories align precisely with their parent category arcs.

2. Set Up Snapping and Guides

Accurate segment placement requires strict circular alignment:

  1. Open Document Properties (Shift + Ctrl + D) and ensure your display units are set to pixels or millimeters.
  2. Enable snapping from the top-right toolbar.
  3. Ensure Snap to Object Centers and Snap to Nodes, Paths, and Handles are active.
  4. Drag a horizontal and vertical guide from the rulers to intersect at your intended chart center.

3. Create Concentric Rings

Use stroked circles to define the levels of your hierarchy:

  1. Select the Circles and Ellipses tool (E).
  2. Hold Ctrl + Shift, click on the guide intersection, and drag outward to create a uniform circle centered on your guides.
  3. Open the Fill and Stroke panel (Shift + Ctrl + Y).
  4. Set Fill to "No paint" and set Stroke paint to a flat color.
  5. In Stroke style, set the stroke width to the desired thickness for that hierarchy level (e.g., 40 px).
  6. Duplicate the circle (Ctrl + D), hold Ctrl + Shift, and resize it to create the next outer ring. Repeat this for each level of your hierarchy.

4. Segment the Rings

To turn continuous rings into individual data cells, divide them into precise angular segments.

Method A: Using Precise Arc Values

  1. Select one of your stroked circles.
  2. Switch to the Circles and Ellipses tool (E). The toolbar will show Start and End angle inputs.
  3. Enter your calculated starting and ending degree values for each segment.
  4. Convert the stroked segment into an editable path by selecting Path > Stroke to Path (Ctrl + Alt + C).
  5. Duplicate the original circle to repeat this process for adjacent segments.

Method B: Slicing with Radial Lines

  1. Use the Draw Freehand Lines or Bezier Curves tool (B) to draw a straight line from the center outward past the outermost ring.
  2. Open the Transform panel (Shift + Ctrl + M) and go to the Rotate tab.
  3. Set the angle to your calculated interval and click Apply while duplicating the line (Ctrl + D) for each boundary.
  4. Convert all concentric rings into paths: select them and choose Path > Stroke to Path.
  5. Select a radial line and an underlying ring segment, then select Path > Cut Path (Ctrl + Alt + /) to slice the ring at the line boundary. Repeat across segments.

5. Color and Organize the Hierarchy

  1. Select each path segment and assign colors based on your data taxonomy.
  2. Keep parent categories unified with a base hue, and assign varying tints or shades of that hue to their respective child segments in the outer rings.
  3. Add a slight stroke (1–2 px) in the background color to create clean margins between segments.
  4. Group each hierarchy level or logical category using Object > Group (Ctrl + G) to keep the SVG layer structure clean.

6. Add Radial Labels

  1. Select the Text tool (T) and type the label for a segment.
  2. Draw an invisible guide circle centered in the middle of the target ring layer.
  3. Select both the text object and the guide circle, then choose Text > Put on Path.
  4. Rotate the guide circle to position the label squarely within its corresponding segment.
  5. Alternatively, place straight labels inside larger segments and rotate them via Object > Transform > Rotate to match the segment’s median angle.
