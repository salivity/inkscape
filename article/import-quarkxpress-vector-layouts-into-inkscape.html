Import QuarkXPress Vector Layouts into Inkscape

Migrating vector artwork and page layouts from QuarkXPress to Inkscape requires the use of intermediate file formats, as Inkscape does not natively support the proprietary .qxp format. By exporting your QuarkXPress documents into standardized vector-friendly formats like PDF or EPS, you can successfully open and edit your vector shapes, paths, and text elements inside Inkscape. This guide outlines the most effective intermediate formats, the export settings required in QuarkXPress, and the proper import techniques in Inkscape.

Choosing the Best Intermediate Format

Because QuarkXPress cannot export directly to Inkscape’s native Scalable Vector Graphics (SVG) format, you must rely on vector-capable container formats:

  • PDF (Portable Document Format): The recommended standard. PDF preserves complex vector paths, gradients, layers, and transparency, and Inkscape features a dedicated PDF import engine.
  • EPS (Encapsulated PostScript): A reliable fallback for pure vector shapes. However, EPS does not handle modern features like native transparency as well as PDF does.

Step 1: Export the Layout from QuarkXPress

To prepare your vector layout for Inkscape, export it as a high-quality PDF directly from QuarkXPress:

  1. Open your project in QuarkXPress.
  2. If your layout relies heavily on proprietary fonts that you might not have installed on the destination machine, consider converting critical text elements to paths first via Item > Convert Text to Boxes.
  3. Go to File > Export as > PDF.
  4. In the export dialog, choose a high-resolution preset such as Press - High Quality/High Resolution or PDF/X-4.
  5. Ensure that vector graphics are not set to downsample or rasterize during export. Under the Layers settings, choose to include all active layers if you wish to preserve the layout structure.
  6. Click Save to generate the PDF file.

(Alternative for EPS): If choosing EPS, select File > Export as > EPS, ensure the color space matches your target output, and save.

Step 2: Import the Intermediate File into Inkscape

Once you have generated the intermediate file, bring it into Inkscape:

  1. Launch Inkscape.
  2. Go to File > Open (to open the layout as a new document) or File > Import (to insert the layout into an existing document).
  3. Select your exported PDF or EPS file and click Open.
  4. The PDF Import Settings dialog will appear. Configure the following:
    • Internal import: Generally best for preserving editable vector paths and text objects.
    • Cairo import: Recommended if the layout contains complex clipping paths or mesh gradients that don't render correctly with the internal engine.
    • Font handling: Select "Draw missing fonts" to render text as vector outlines if the original QuarkXPress fonts are missing, or keep it unchecked to retain editable text using system fonts.
  5. Click OK to complete the import.

Step 3: Ungroup and Optimize the Layout

Imported vector documents often arrive grouped inside multiple nested containers and clipping masks:

  • Remove Clipping Masks: QuarkXPress exports page boundaries as clipping paths. Select the imported object and choose Object > Clip > Release to access elements that extend beyond the margins.
  • Ungroup Elements: Select the layout and press Ctrl+Shift+G (or Cmd+Shift+G on macOS) repeatedly to ungroup elements down to individual vector paths.
  • Inspect Paths: Switch to the Edit paths by nodes tool (N) to verify that your vector shapes are clean and fully editable.
