How to Triangulate Vector Art in Inkscape

This guide provides a step-by-step walkthrough on how to use Inkscape's built-in Voronoi and Delaunay extension to create geometric, triangulated vector artwork. By distributing a network of points across an existing shape or image, you can quickly generate a low-poly triangulation mesh directly within Inkscape.

Step 1: Prepare Your Base Object

  1. Open Inkscape and create or import the vector artwork you want to triangulate.
  2. If you are working with an imported raster image, ensure you have drawn a vector shape (such as a rectangle) over it to define the boundary for your triangulation.

Step 2: Generate a Network of Points

The Delaunay triangulation algorithm requires a cloud of coordinates (nodes or objects) to calculate the triangles:

  1. Select your vector shape.
  2. Convert it to a path by going to Path > Object to Path if it is a basic shape.
  3. Add dense nodes across your path by navigating to Extensions > Modify Path > Add Nodes. Set the maximum segment length to a smaller value to create more nodes, or manually place small dot objects/nodes across the target area where you want triangle vertices to appear.
  4. If using separate dots, select all the dots and group them by pressing Ctrl + G or combining them via Path > Combine.

Step 3: Run the Voronoi / Delaunay Extension

  1. Select the points, nodes, or grouped vector objects you prepared.
  2. Go to the top menu and select Extensions > Generate from Path > Voronoi Diagram....
  3. In the extension dialog box, set the Diagram-Type dropdown to Delaunay Triangulation.
  4. Check the Live preview box to view the generated mesh in real time.
  5. Click Apply to generate the triangulated mesh on your canvas, then close the dialog.

Step 4: Style and Color the Mesh

  1. Select the newly generated triangulation mesh and ungroup it by pressing Ctrl + Shift + G so you can manipulate individual triangles.
  2. Select each triangle and use the Dropper Tool (F7 or D) to sample colors from your underlying artwork or reference image.
  3. Adjust the stroke width to zero in the Fill and Stroke panel (Ctrl + Shift + F) if you prefer seamless facet boundaries, or increase the stroke width to create distinct borders between each triangle.
