Query All Objects Bounding Box in Inkscape CLI

This guide demonstrates how to extract the exact combined bounding box—comprising the X coordinate, Y coordinate, width, and height—of all objects within an SVG file using the Inkscape command-line interface. By executing built-in query flags without specifying an object ID, you can instantly retrieve the global dimensions of your artwork without launching the graphical interface.

The Query Command

To get the combined bounding box of all objects in an SVG file, omit the --query-id option. When no ID is passed, Inkscape defaults to calculating the bounding box of the entire drawing.

Run the following command in your terminal:

inkscape --query-x --query-y --query-width --query-height input.svg

Understanding the Output

The command outputs four numerical values separated by newlines, measured in SVG user units (typically pixels at 96 DPI):

  1. X: The horizontal coordinate of the leftmost edge of the combined objects.
  2. Y: The vertical coordinate of the top edge of the combined objects.
  3. Width: The total width spanning from the leftmost to the rightmost point.
  4. Height: The total height spanning from the top to the bottom point.

Storing the Output in Shell Variables

If you are automating workflows in a Bash or POSIX shell, you can capture the four values into distinct variables:

read -r X Y WIDTH HEIGHT < <(inkscape --query-x --query-y --query-width --query-height input.svg)

echo "X: $X"
echo "Y: $Y"
echo "Width: $WIDTH"
echo "Height: $HEIGHT"

Alternative: Querying All Elements via CSV

If you need to verify whether the global dimensions match specific root layers or groups, use --query-all:

inkscape --query-all input.svg

This prints a comma-separated list of every object's ID followed by its x, y, width, and height. The row corresponding to the root <svg> element or the outermost group will match the total boundary calculated by the individual query flags.
