How to Assign an ICC Profile to an Image in Inkscape

Managing color accuracy in Inkscape requires correctly linking color spaces to your imported assets so they render predictably on screen and in print. While vector paths rely on standard RGB or CMYK definitions, raster graphics require dedicated profile mappings. This guide explains how to enable color management in Inkscape, add target profiles to your document, and link an ICC profile directly to a specific placed raster image.

Step 1: Enable Color Management in Inkscape Preferences

Before assigning profiles, Inkscape’s LittleCMS color engine must be active:

  1. Go to Edit > Preferences (or press Shift + Ctrl + P).
  2. In the left panel, select Color management.
  3. Set your Display profile to match your monitor's calibrated ICC profile.
  4. Ensure your preferred color rendering intents and working spaces (such as sRGB or a standard CMYK profile like Coated FOGRA39) are selected.

Step 2: Add the ICC Profile to the Document

To make an ICC profile available to individual elements inside your SVG, you must register it in the document’s definitions:

  1. Open File > Document Properties (or press Shift + Ctrl + D).
  2. Navigate to the Color tab.
  3. Under Available Color Profiles, locate the ICC profile you want to apply to your raster image.
  4. Click Link to attach the profile to the active SVG document. Inkscape creates an internal reference ID for this profile within the SVG <defs> block.

Step 3: Place the Raster Image

  1. Go to File > Import (Ctrl + I) and choose your raster file (such as a PNG, TIFF, or JPEG).
  2. Choose either Embed or Link in the import dialog and click OK.
  3. Keep the image selected on the canvas.

Step 4: Assign the Profile Using the XML Editor

Because Inkscape lacks a dedicated contextual menu for reassigning raster color spaces on the canvas, the assignment is completed via the XML Editor:

  1. Open the XML Editor by pressing Shift + Ctrl + X or navigating to Edit > XML Editor.
  2. With your placed image selected on the canvas, the corresponding <svg:image> node will automatically be highlighted in the XML tree.
  3. In the right-hand attribute pane, type color-profile into the Name field.
  4. In the Value field, enter the exact name or identifier of the ICC profile linked in Step 2.
  5. Click Set (or press Ctrl + Enter).

Alternative Approach: Pre-Embedding ICC Profiles

If you frequently work with color-critical raster graphics, embed the ICC profile directly into the image file using dedicated image manipulation software (such as GIMP or Photoshop) prior to importing it into Inkscape. When color management is enabled in Inkscape preferences, the rendering engine automatically reads and respects embedded ICC tags in TIFF, JPEG, and PNG files without requiring manual XML edits.
