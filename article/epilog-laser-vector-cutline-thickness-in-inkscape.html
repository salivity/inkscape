Epilog Laser Vector Cutline Thickness in Inkscape

Setting up vector cutlines in Inkscape for an Epilog laser requires a precise stroke width so the print driver interprets paths as cuts rather than raster engravings. This guide covers the exact millimeter stroke thickness recognized by Epilog laser drivers, why this specific value is required, and how to properly configure your stroke settings in Inkscape for clean, accurate vector cuts.

The Exact Vector Stroke Thickness

To be recognized as a vector cutline by an Epilog laser driver, the stroke width must be set to 0.0254 mm (the metric equivalent of 0.001 inches).

Epilog drivers distinguish between vector cutting and raster engraving based entirely on line width:

  • 0.0254 mm (0.001 in) or smaller: Processed as a vector cut (the laser follows the path continuously).
  • Greater than 0.0254 mm: Processed as a raster engraving (the laser fires left-to-right to etch the shape).

While many graphic design programs offer a default "Hairline" setting, Inkscape does not include a dedicated hairline option. Instead, you must manually type the numeric dimension into the stroke style controls.

How to Set the Cutline in Inkscape

  1. Select the object or path you intend to cut.
  2. Open the Fill and Stroke menu by pressing Ctrl + Shift + F (or Cmd + Shift + F on macOS).
  3. Under the Fill tab, ensure fill is set to No paint (unless the interior is meant to be raster-engraved).
  4. Under the Stroke paint tab, select Flat color and set the alpha channel (opacity) to 100%.
  5. Under the Stroke style tab:
    • Change the measurement unit dropdown to mm.
    • Enter 0.0254 in the Width field (entering 0.025 is also accepted by the driver).

Important Considerations

  • On-Screen Visibility: A 0.0254 mm stroke appears extremely faint or nearly invisible when zoomed out in Inkscape. To verify paths without altering their true width, use View > Display mode > Outline.
  • Color Mapping: Although stroke thickness determines whether a line is a vector cut, Epilog drivers also support color mapping (e.g., using pure RGB Red 255, 0, 0 for cutting and RGB Blue for vector scoring). Ensure your stroke color matches the specific job parameters assigned in your Epilog driver settings.
  • Transforms and Scaling: If you resize an object after defining the line width, ensure that the "Scale stroke width by the same proportion" toggle on Inkscape's top toolbar is disabled, or re-verify that the stroke remains set to 0.0254 mm prior to printing.
