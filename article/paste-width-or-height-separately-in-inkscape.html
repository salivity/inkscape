Paste Width or Height Separately in Inkscape

Inkscape allows you to transfer specific dimensions from one object to another without manually copying numerical values or altering unintended proportions. This guide explains how to copy an object's size and paste either its width or height independently onto a target shape using built-in commands and keyboard shortcuts.

Copying the Source Dimension

  1. Use the Select Tool (S or F1) to click on the object with the dimensions you want to replicate.
  2. Copy the object to your clipboard by pressing Ctrl + C (or Cmd + C on macOS), or by navigating to Edit > Copy.

Pasting Width or Height to the Target Object

  1. Click on the target shape that needs resizing.
  2. To transfer only the horizontal dimension:
    • Go to Edit > Paste Size > Paste Width.
    • Alternatively, press the shortcut Ctrl + Alt + X (or Cmd + Alt + X on macOS).
  3. To transfer only the vertical dimension:
    • Go to Edit > Paste Size > Paste Height.
    • Alternatively, press the shortcut Ctrl + Alt + Y (or Cmd + Alt + Y on macOS).

Resizing Multiple Target Objects

If you select multiple target objects at once, standard paste commands treat the entire selection as a single bounding box. To resize each object individually:

  • For Width: Go to Edit > Paste Size > Paste Width Separately.
  • For Height: Go to Edit > Paste Size > Paste Height Separately.

Important Note on Proportions

Ensure the Lock Aspect Ratio (padlock icon in the top toolbar) is unlocked if you want to modify only one axis without proportionally scaling the other dimension automatically.
