How to Delete Unused Filters in Inkscape Defs

Inkscape files frequently accumulate orphan filter elements inside the document's <defs> tag when elements are duplicated, modified, or deleted, leading to bloated file sizes and messy SVG code. This guide outlines the most effective ways to purge these unused filters directly within Inkscape using the automated document cleanup tool, the XML Editor, and the Filter Editor panel.

Method 1: The "Clean Up Document" Tool (Automated)

The quickest way to remove unused filters, gradients, markers, and patterns from the <defs> block is to let Inkscape audit the file automatically.

  1. Open your SVG file in Inkscape.
  2. Go to the top menu and select File > Clean Up Document. (In older versions of Inkscape, this command is labeled Vacuum Defs).
  3. Inkscape immediately scans the <defs> section and removes any filter definitions not actively referenced by elements on the canvas.
  4. Save your file (File > Save).

Method 2: Use the XML Editor (Manual Precision)

If you want complete control over which filter elements are removed from the code, use the internal XML tree viewer.

  1. Open the XML Editor by navigating to Edit > XML Editor or by pressing Ctrl + Shift + X (Cmd + Shift + X on macOS).
  2. In the XML tree on the left, expand the root svg:svg node.
  3. Locate and click on the svg:defs node to expand its contents.
  4. Scroll through the items inside svg:defs until you locate child nodes named svg:filter.
  5. Select the unused svg:filter node you want to eliminate.
  6. Click the Delete node button (represented by a red "X" or trash can icon) at the top of the XML Editor panel.
  7. Repeat for any other unwanted filters and save the file.

Method 3: Use the Filter Editor Panel

Inkscape provides a dedicated GUI panel for managing all filter definitions in the current SVG.

  1. Open the panel by selecting Filters > Filter Editor.
  2. The left pane of this dialog lists all filter presets defined in your document.
  3. Select the filter you wish to delete from the list.
  4. Click the Delete button located below the list of filters.
  5. This permanently removes the <filter> definition from <defs>.
