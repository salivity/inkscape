How to Use OpenType Font Alternates in Inkscape

Inkscape provides built-in support for advanced typography, allowing you to access OpenType features such as stylistic alternates, discretionary ligatures, and contextual swashes. By using the dedicated Text and Font dialog, you can easily customize individual glyphs or entire text blocks to elevate your vector typography.

Step 1: Add Your Text

  1. Select the Text tool (T or F8) from the left toolbar.
  2. Click on the canvas and type your text.
  3. Ensure you are using an OpenType font (.otf or .ttf) that includes stylistic alternates (e.g., Gabriola, EB Garamond, or Montserrat).

Step 2: Open the Text and Font Dialog

  1. Select the text object with the Selector tool (S or F1) or highlight specific characters using the Text tool.
  2. Go to the top menu and select Text > Text and Font... (or press Shift + Ctrl + T on Windows/Linux, Shift + Cmd + T on macOS).

Step 3: Access OpenType Features

  1. In the Text and Font panel docked on the right, switch to the Features tab (located next to the Font tab).
  2. Inkscape will automatically detect and list all available OpenType tables for the selected font.

Step 4: Enable Stylistic Alternates

  1. Scroll through the feature categories to find:
    • Stylistic Alternates (salt): Replaces standard glyphs with aesthetic alternatives.
    • Stylistic Sets (ss01 through ss20): Pre-packaged sets of alternate glyphs designed to work together harmoniously.
    • Swashes (swsh): Adds decorative extensions to letterforms.
  2. Check the box next to the alternate style you wish to activate. A live preview of the text will appear in the lower preview box of the dialog.
  3. Click the Apply button at the bottom right of the panel to apply the changes to your canvas.

Step 5: Convert to Vector Paths (Optional)

If you plan to export the design for print, cutting machines, or sharing across systems where the font is not installed:

  1. Select the modified text object.
  2. Go to Path > Object to Path (Shift + Ctrl + C).
  3. Your text will now be converted into permanent vector nodes, preserving the stylistic alternates across all software.
