Non-Destructive Difference with Boolean LPE in Inkscape

Inkscape allows designers to subtract shapes dynamically using the Boolean Operation Live Path Effect (LPE). Unlike traditional destructive commands (Path > Difference), the Boolean LPE retains the original geometry of both shapes, allowing you to reposition, resize, or alter the cutting object at any time without losing the original artwork. This guide provides a straightforward walkthrough on how to configure and control the Boolean LPE to achieve live, non-destructive difference operations.

1. Prepare Your Paths

  1. Create the two vector shapes on your canvas: the base shape (the object you want to cut into) and the cutting shape (the object performing the cut).
  2. If your shapes are primitive shapes (like rectangles, circles, or stars), convert them to paths by selecting each and choosing Path > Object to Path (Shift + Ctrl + C).

2. Copy the Cutting Path

  1. Select the shape you intend to use as the cutting tool.
  2. Copy it to your clipboard by pressing Ctrl + C (or Cmd + C on macOS).

3. Apply the Boolean Operation LPE

  1. Select the base shape that you want to be cut.
  2. Open the Path Effects dialog by navigating to Path > Path Effects.
  3. Click the + (Add Path Effect) button.
  4. In the search bar of the selector dialog, type Boolean operation and select it.

4. Configure the Effect for Difference

  1. With your base shape still selected, locate the Boolean operation settings inside the Path Effects panel.
  2. Open the Operation dropdown menu and select Difference.
  3. Next to the Operand parameter, click the Link to path on clipboard icon (indicated by a clipboard and chain link).

The base path will instantly update, cutting out the shape stored in your clipboard.

5. Interacting with the Live Operation

  • Live Updates: Because the cutting shape is linked rather than merged, any edits you make to the original cutting object on your canvas will automatically update the subtracted area on the base path.
  • Canvas Editing: Switch to the Node Tool (N) and select the base shape to view and manipulate the interactive handles for both the base geometry and the linked operand directly on the canvas.
  • Hiding the Cutter: If you do not want the original cutting shape to appear in your final export, either hide its layer, turn its opacity to 0%, or set its stroke and fill to none.
