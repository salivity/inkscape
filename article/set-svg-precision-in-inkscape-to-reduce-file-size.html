Set SVG Precision in Inkscape to Reduce File Size

Reducing numeric precision in SVG files strips redundant decimal data from coordinate points, creating leaner, faster-loading vector assets for the web. This guide explains how to configure Inkscape to restrict path coordinates to three decimal places—a setting that maintains visual fidelity on modern displays while significantly decreasing overall payload size.

Why Reduce Path Precision?

Vector coordinates exported from design software often contain excessive floating-point precision, such as d="M 12.3456789,98.7654321". On the web, screen pixels do not require eight or nine decimal points of accuracy. Truncating coordinates to three decimal places (e.g., 12.346) removes thousands of unnecessary characters from complex paths without causing noticeable visual degradation.

Method 1: Exporting as Optimized SVG (Recommended)

The most direct way to cap coordinate precision to three decimal places during export is using Inkscape's built-in optimizer:

  1. Open your graphic in Inkscape.
  2. Go to File > Save As... (or press Shift + Ctrl + S).
  3. In the "Save as type" dropdown, select Optimized SVG (*.svg).
  4. Choose your destination and click Save.
  5. An Optimized SVG Output configuration dialog will appear.
  6. Click the SVG Output tab.
  7. Locate the Number of significant digits for coordinates field and set it to 3 (or adjust Decimal places depending on your Inkscape version).
  8. Enable Format numbers to avoid unnecessary zeros.
  9. Click OK to export the optimized file.

Method 2: Adjusting Global SVG Output Preferences

If you want Inkscape to consistently write coordinates with lower precision across standard saves, change the default application preferences:

  1. Navigate to Edit > Preferences (or press Shift + Ctrl + P).
  2. In the left-hand sidebar, expand Input/Output and select SVG output.
  3. Under the Numbers section, find Numeric precision.
  4. Set the value to 3.
  5. Close the Preferences window. Future standard SVG saves will now limit decimal expansion automatically.

Verification

To verify the optimization, open the exported SVG file in any text editor or code inspection tool. Inspect the d="..." attributes of your <path> elements to confirm that coordinate values contain no more than three numbers after the decimal point.
