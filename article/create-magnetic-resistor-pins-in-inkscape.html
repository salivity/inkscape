Create Magnetic Resistor Pins in Inkscape

This guide explains how to create magnetic connection pins on electrical resistor symbols in Inkscape. By combining precise terminal nodes with Inkscape's snapping engine and Diagram Connector tool, you can build reusable schematic symbols whose terminal leads automatically pull and lock connecting wires into place.

1. Draw the Resistor Symbol

  1. Select the Draw Bezier curves and straight lines tool (B or Shift + F6).
  2. Draw your preferred resistor geometry:
    • US/IEEE Style (Zigzag): Click to create alternating peaks and troughs, holding Ctrl if you want fixed angles.
    • IEC Style (Rectangle): Select the Rectangle tool (R) and draw a narrow, hollow rectangle.
  3. Add two straight horizontal lines extending outwards from the left and right sides of the resistor body to act as terminal leads.
  4. Select both the body and leads, open the Align and Distribute panel (Ctrl + Shift + A), and align them along a common horizontal axis.

2. Establish Terminal Cusp Nodes

Magnetic attachment points rely on distinct path endpoints (cusp nodes):

  1. Switch to the Edit paths by nodes tool (N).
  2. Verify that the outer tip of each terminal lead consists of a single endpoint (cusp node).
  3. If you want dedicated, non-rendered anchor points, draw a tiny circle (0.5 mm diameter) at the tip of each lead, set its fill and stroke to fully transparent, and leave it positioned exactly over the terminal end.

3. Configure the Snapping System for Magnetic Behavior

To make wires jump magnetically to your resistor terminals, configure the snapping controls on the top or right toolbar:

  1. Enable Snapping globally by clicking the magnet icon or pressing %.
  2. Expand the snapping menu and enable:
    • Snap to nodes, paths, and handles
    • Snap to cusp nodes
    • Snap to path intersections
    • Snap to endpoints of open paths
  3. Open Edit > Preferences > Behavior > Snapping to adjust the Snap sensitivity. Increasing the pixel distance makes the pins feel significantly more "magnetic" as you approach them with drawing tools.

4. Wire the Resistor Using the Connector Tool

Inkscape includes a dedicated connection system that maintains links between components even when moved:

  1. Select the Create diagram connectors tool (O or Ctrl + F3).
  2. Hover the connector cursor over the terminal ends of your resistor symbol. The cursor displays a red or green highlight when it detects a valid connection point.
  3. Click and drag away from the terminal pin to draw an electrical net. The wire remains locked magnetically to the terminal point, automatically routing around obstacles and staying connected if the resistor is repositioned.

5. Group and Save as a Symbol

  1. Select all elements of the resistor using the Select and transform objects tool (S).
  2. Press Ctrl + G to group the components into a single object.
  3. Open Object > Symbols (Ctrl + Shift + Y).
  4. Click Add Symbol from current document to store the resistor with its functioning snap points in your library for future schematic designs.
