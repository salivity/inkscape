How to Nest Cut Layouts in Inkscape

Generating nested cut layouts for standard plywood sheets in Inkscape allows makers to significantly reduce material waste and optimize CNC or laser cutting runtimes. This process involves defining a realistic sheet boundary, preparing cut vectors with proper tool kerf allowances, and using nesting tools—either via Inkscape extensions or integrated bin-packing software—to automatically pack parts tightly before final export.

1. Set Up the Sheet Dimensions

Before arranging parts, establish a workspace that reflects the usable area of your plywood sheet.

  1. Open Inkscape and navigate to File > Document Properties.
  2. Set the Display units and Page size units to inches or millimeters, depending on your workflow.
  3. Input the dimensions of your standard plywood sheet (e.g., 48" x 96" for a full sheet, or 24" x 48" for a half sheet).
  4. Draw a rectangle matching these dimensions, apply a stroke with no fill, and create an inner margin (typically 0.5 to 1 inch) to account for hold-down clamps, screws, or edge imperfections.

2. Prepare Your Vector Parts

Clean geometry is critical for nested layouts to calculate correctly.

  1. Select all cutting parts and convert them to paths by clicking Path > Object to Path.
  2. If your parts contain internal cutouts (such as holes or mortises), combine the outer boundary with the inner holes using Path > Combine. This ensures internal features stay locked to the outer perimeter.
  3. Account for your cutting tool's kerf. For CNC routers, ensure there is enough clearance between parts to accommodate the bit diameter (e.g., 0.25 inches) plus a small safety margin. For laser cutters, offset paths outward using Path > Outset or leave spacing equivalent to the laser beam width.

3. Nesting Using Automated Tools

Inkscape does not have an advanced, multi-part true-shape nesting engine built directly into its core interface, but it integrates seamlessly with dedicated nesting engines.

Method A: Deepnest (Recommended Workflow)

  1. Save your prepared parts and sheet rectangle as a standard SVG file via File > Save As.
  2. Open Deepnest, an open-source packing application built for laser and CNC cutting.
  3. Import your saved SVG. Deepnest will detect all closed paths.
  4. Select the bounding rectangle that represents your plywood sheet and mark it as the sheet/container.
  5. Set your part-to-part spacing (tool diameter + safety margin) and part rotations.
  6. Click Start Nest. Allow the algorithm to run iterations until it achieves maximum material efficiency.
  7. Export the optimized result as an SVG, then reopen it in Inkscape to inspect the layout.

Method B: Inkscape Nesting Extensions

If you prefer to stay entirely within Inkscape, install community extensions such as the SVG Nest or Inks2Nest scripts.

  1. Place the extension files into your Inkscape extensions directory.
  2. Select your parts and the bounding sheet rectangle.
  3. Go to Extensions > Nest (or the respective extension name).
  4. Define spacing tolerances, rotation step angles (e.g., 90° for grain-sensitive plywood, or 45°/15° for non-directional sheets), and execute the script to arrange parts inside the boundary.

4. Manual Nesting and Fine-Tuning

For small part batches or grain-sensitive plywood:

  1. Enable Snapping on the right-hand toolbar, particularly Snap to paths and Snap to bounding boxes.
  2. Use the Transform panel (Object > Transform) to rotate rectangular or complementary parts at 90-degree increments to align matching edges.
  3. Nest small parts inside the negative spaces of larger, hollow parts.
  4. Use the Align and Distribute panel (Object > Align and Distribute) to maintain uniform spacing between adjacent cuts.

5. Final Verification and Export

  1. Check the grain direction. If using finished plywood with visible veneer grain, verify that all structural or aesthetic parts are rotated along the correct axis.
  2. Verify that no parts overlap the boundary margins or each other.
  3. Delete or hide the outer sheet boundary rectangle so the machine does not attempt to cut along the edge of the plywood.
  4. Export the file to your CAM software or cutter control software using standard formats like SVG or DXF (File > Save a Copy).
