How to Scale an Object from Center in Inkscape

Scaling an object in Inkscape defaults to anchoring the transformation at the opposite corner handle of your selection. This guide explains how to override that default behavior to scale an object symmetrically outward or inward from its exact center point using simple keyboard shortcuts and the built-in transform tools.

The Keyboard Shortcut Method (Fastest)

The quickest way to scale an object relative to its center is by using modifier keys while dragging the selection handles:

  1. Click on the object with the Select and Transform objects tool (S or F1).
  2. Hover your mouse over any of the bounding box handles (the small arrows surrounding the object).
  3. Hold down the Shift key on your keyboard.
  4. Click and drag the handle. The object will now expand or shrink symmetrically around its center point instead of the opposite corner.

To scale the object symmetrically from the center while maintaining its original aspect ratio, hold down both Shift + Ctrl simultaneously while dragging a corner handle.

The Transform Panel Method (Precise Measurements)

If you need to scale an object from its center using exact numerical values or percentages:

  1. Select your object.
  2. Open the Transform dialog by going to Object > Transform or pressing Shift + Ctrl + M.
  3. Select the Scale tab.
  4. Enter your desired dimensions or percentage. Check Scale proportionally if you want to lock the aspect ratio.
  5. Click Apply. Inkscape automatically applies transformations from this panel using the object's center point as the origin.
