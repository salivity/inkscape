Convert Smooth Node to Cusp Node in Inkscape

In Inkscape, converting a smooth or symmetric node into a sharp cusp node without disturbing its existing control handles is a common requirement for precise vector path editing. This guide explains the specific command and keyboard shortcut needed to break the handle alignment while preserving their exact lengths and angles, ensuring your curve shapes remain intact until you decide to modify them.

The Command to Make a Node a Cusp

The command to convert any node into a cusp (corner) node without moving its handles is Make selected nodes corner.

  • Keyboard Shortcut: Press Shift + C while the node is selected.
  • Toolbar Icon: Click the Make selected nodes corner button (depicted as a sharp angle icon) on the Node Tool Controls bar at the top of the workspace.

How to Use the Command

  1. Select the Edit paths by nodes tool from the left toolbox, or press N on your keyboard.
  2. Click on the path to reveal its nodes.
  3. Click directly on the smooth node you wish to convert to select it (it will change color or highlight).
  4. Press Shift + C or click the Make selected nodes corner icon in the top toolbar.

Why This Method Preserves Handle Positions

Inkscape provides multiple node types: Cusp, Smooth, Symmetric, and Auto-smooth. When a node is set to smooth or symmetric, the two control handles are locked in a collinear line (180 degrees opposite each other).

Applying the Shift + C command changes the node's mode to a cusp node. This action unlocks the angle relationship between the handles. The handles remain in their exact current coordinates, leaving your path's curvature unchanged. Once converted, dragging either handle will move it independently, allowing you to create sharp corners without affecting the opposite side of the node.
