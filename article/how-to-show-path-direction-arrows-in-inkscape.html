How to Show Path Direction Arrows in Inkscape

Displaying path direction arrows in Inkscape is essential for tasks like cutting paths, applying custom stroke markers, or preparing vector files for laser cutting and CNC routing. This guide explains how to display directional arrowheads along path segments during node editing using both the Node Tool controls bar and the global Inkscape preferences.

Method 1: Using the Node Tool Controls Bar

The fastest way to toggle directional arrows is directly from the toolbar while working with nodes:

  1. Select the Edit paths by nodes tool from the left toolbar, or press the shortcut key N.
  2. Look at the Tool Controls bar positioned horizontally above the canvas.
  3. Locate the toggle icon labeled Show path direction on outlines (represented by a path segment with a small arrow on it).
  4. Click the icon to activate it.
  5. Click on any path on your canvas to enter node edit mode. Small red arrowheads will appear along the path segments, pointing from the starting node toward the end node.

Method 2: Enabling the Feature in Preferences

If the icon is hidden or you want to ensure the setting persists across all documents:

  1. Open the Preferences window by going to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  2. In the left-hand menu, expand Tools and select Node.
  3. Under the editing options, check the box labeled Show path direction on outlines.
  4. Close the Preferences window. The directional arrows will now appear automatically whenever you edit nodes on a selected path.

How to Reverse the Path Direction

If you observe the directional arrows and find that the trajectory is reversed:

  1. Select the path with the Node Tool or the Select Tool (S).
  2. Navigate to the top menu and select Path > Reverse.
  3. The directional arrowheads will immediately flip, changing the designated start and end points of the vector outline.
