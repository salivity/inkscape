Add Hyperlinks with Target Blank in Inkscape

This guide explains how to convert static vector graphics into interactive SVG elements by embedding clickable web links directly onto objects within Inkscape. By utilizing Inkscape's built-in link properties and XML attributes, you can assign web addresses to shapes, paths, or text and configure them with the target="_blank" attribute so that URLs open in a new browser window or tab.

Step 1: Select Your Vector Object

Open your SVG file in Inkscape and use the Select Tool (S or F1) to click on the vector path, shape, group, or text element that you want to make clickable.

Step 2: Create the Anchor Link

With the object selected, convert it into an SVG hyperlink element (<a> tag):

  1. Right-click the selected object.
  2. Select Create Link from the context menu.

The object is now wrapped in an anchor container within the SVG document structure.

Step 3: Configure Link Properties and Target

Once the link wrapper is created, you must assign the destination URL and the target behavior:

  1. Right-click the object again and select Link Properties.
  2. In the Link Properties dialog, locate the Href field and enter the full URL (including https://, for example: https://example.com).
  3. Locate the Target field. Enter or select _blank to ensure the link opens in a new browser tab.
  4. Click Set to apply the changes.

Step 4: Verify via the XML Editor (Optional)

To guarantee the attributes are correctly written to the raw SVG markup:

  1. Open the XML Editor by pressing Ctrl + Shift + X (or Cmd + Shift + X on macOS).
  2. Locate the svg:a node wrapping your selected object.
  3. Verify that the following attributes are present on the svg:a node:
    • xlink:href (or href): Set to your destination URL.
    • target: Set to _blank.
  4. If the target attribute is missing, click the attribute name field at the top right of the XML panel, type target, enter _blank in the value field, and click Set.

Step 5: Save and Test the SVG

  1. Go to File > Save As...
  2. Choose either Plain SVG or Optimized SVG (if using Optimized SVG, ensure settings do not strip link attributes).
  3. Open the saved .svg file in any modern web browser (such as Chrome, Firefox, or Edge) and click the vector object to confirm that it redirects properly in a new tab.
