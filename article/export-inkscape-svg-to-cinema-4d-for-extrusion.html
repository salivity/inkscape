Export Inkscape SVG to Cinema 4D for Extrusion

Transferring vector artwork from Inkscape into Cinema 4D allows you to transform flat 2D designs into dynamic 3D geometry using procedural generators. This workflow requires properly preparing and converting your vectors into raw paths in Inkscape, saving them in a compatible format, importing them into Cinema 4D, and pairing the resulting splines with an Extrude generator for non-destructive 3D modeling.

1. Prepare Your Vectors in Inkscape

Before exporting, you must convert all text, shapes, and strokes into standard vector paths so Cinema 4D can interpret them as splines:

  1. Convert Objects to Paths: Select all elements in your document and go to Path > Object to Path (Shift + Ctrl + C). This converts primitive shapes (rectangles, circles) and text into editable nodes.
  2. Convert Strokes (If Applicable): If your artwork relies on visible stroke outlines rather than fills, go to Path > Stroke to Path (Ctrl + Alt + C).
  3. Combine Shapes: If your design features compound shapes (such as letters with holes like "O" or "A"), select the overlapping paths and choose Path > Combine (Ctrl + K) to ensure Cinema 4D cuts out the negative space correctly.
  4. Ungroup Elements: Select everything and press Ctrl + Shift + G repeatedly until no groups remain in the status bar.
  5. Save the File: Go to File > Save As... and choose Plain SVG (*.svg) from the format dropdown. This removes Inkscape-specific metadata and leaves clean XML data.

2. Import the SVG into Cinema 4D

Modern versions of Cinema 4D support direct SVG imports through the Vector Import engine or standard spline conversion:

  1. Open Cinema 4D.
  2. Go to File > Merge Project... (Ctrl + Shift + O) and select your saved .svg file, or simply drag and drop the SVG directly into the viewport.
  3. In the import settings dialog, leave the scale at 1 unless your document requires a specific unit conversion, then click OK.
  4. Your vector will appear in the Object Manager either as a hierarchy of spline objects or inside a Vector Import node. If it is imported as a Vector Import node, you can right-click it and choose Current State to Object if you need raw, direct access to the underlying splines.

3. Set Up Procedural Extrusion

Once your curves are inside Cinema 4D as splines, you can extrude them non-destructively:

  1. Add an Extrude Generator: Click the Generator icon on the top palette and select Extrude.
  2. Parent the Spline: In the Object Manager, drag your spline object (or spline group) so it becomes a child of the Extrude generator.
  3. Enable Hierarchy (For Multiple Splines): If your imported artwork contains multiple spline layers grouped under a Null object, select the Extrude generator, navigate to the Object tab in the Attributes panel, and check the Hierarchical box. Alternatively, select all individual splines, right-click, and select Connect Objects + Delete to merge them into a single spline before parenting.
  4. Adjust Depth and Direction: In the Object tab of the Extrude generator, modify the Offset values along the X, Y, or Z axis to set the extrusion thickness.
  5. Add Caps and Bevels: Switch to the Caps tab to configure bevel size, shape, and curvature to refine the edges of your 3D mesh.
