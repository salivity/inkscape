Create Vector Pencil Sketch Texture in Inkscape

This guide explains how to convert clean vector shapes and paths into a realistic, hand-drawn pencil sketch using Inkscape’s native SVG Filter Editor. By stacking filter primitives such as fractal turbulence, displacement mapping, and color matrix adjustments, you can simulate paper tooth, uneven graphite deposits, and wobbly hand-drawn edges entirely within a non-destructive vector workflow.

Step 1: Prepare the Base Vector Art

  1. Select your target object or path in Inkscape.
  2. Set the stroke color to a dark charcoal gray (for example, #2b2b2b) rather than pure black, which better mimics graphite.
  3. If using filled shapes, lower the fill opacity or replace the solid fill with a loose hatch pattern, as genuine pencil sketches rely primarily on line weight and stippling rather than flat fills.
  4. Set an initial stroke width between 1 px and 3 px.

Step 2: Open the SVG Filter Editor

  1. Navigate to Filters > Filter Editor.
  2. Click New in the bottom-left of the Filter Editor panel to create an empty filter template.
  3. Rename the filter to "Pencil Sketch" for clarity.
  4. Check the box next to your new filter while the object is selected to apply it.

Step 3: Add the Texture Foundation with feTurbulence

  1. In the Add Primitive drop-down menu, select Turbulence and click Add Primitive.
  2. In the settings panel for feTurbulence, set:
    • Type: Fractal Noise
    • Base Frequency: Set horizontally and vertically between 0.6 and 0.9 to generate a fine, gritty grain.
    • Num Octaves: 3 or 4 to add complexity and mimic rough paper fibers.

Step 4: Distort the Edges with feDisplacementMap

  1. Select Displacement Map from the drop-down menu and click Add Primitive.
  2. Connect the nodes in the filter graph:
    • Connect Input 1 (Image) to Source Graphic.
    • Connect Input 2 (Displacement) to the output of Turbulence.
  3. In the feDisplacementMap parameters:
    • Set X Channel to R and Y Channel to G.
    • Set Scale to a value between 2 and 6. This breaks up the sharp edges of your path into irregular, jittery lines characteristic of a hand-drawn stroke.

Step 5: Simulate Graphite Density with feComposite and feColorMatrix

  1. Select Composite from the drop-down and click Add Primitive.
  2. Connect the inputs:
    • Set the first input to the output of your Displacement Map.
    • Set the second input to the output of Turbulence.
  3. Set the Operator to In or Arithmetic (with low coefficients) to subtract parts of the stroke where the simulated paper texture is raised. This creates broken pencil marks and variations in line pressure.
  4. Select Color Matrix from the drop-down and click Add Primitive.
  5. Connect its input to the output of the Composite primitive.
  6. Set the matrix type to Matrix and slightly reduce the Alpha (A) multiplier to soften the overall stroke and allow underlying paper layers to show through.

Step 6: Fine-Tune the Appearance

  • Line Weight: Adjust the original stroke width in the Fill and Stroke panel (Shift + Ctrl + F). The filter scales its distortion based on the stroke dimension.
  • Paper Roughness: Increase the feTurbulence frequency if the texture looks too clumped, or lower it if the texture looks too digital.
  • Filter Region: If the pencil strokes appear clipped around the bounding box, go to the Filter General Settings tab in the Filter Editor and increase the boundary coordinates (X, Y, Width, Height) by 10% to 20%.
