How to Offset Cutlines for Laser Kerf in Inkscape

When laser cutting interlocking parts, the laser beam vaporizes a small width of material known as the kerf, resulting in loose-fitting joints if uncompensated. To achieve tight, press-fit assemblies, cutlines must be shifted outward for exterior parts and inward for interior cutouts by half the total kerf width. This article explains how to determine your required offset distance and apply precise cutline adjustments in Inkscape using the Live Path Effect tool and numerical Inset/Outset commands.

1. Calculate Your Offset Distance

The laser kerf typically ranges between 0.08 mm and 0.25 mm depending on your lens, laser wattage, material type, and thickness.

To compensate correctly:

  • Measure your total kerf: Cut a rectangle with known dimensions (e.g., 50 mm wide), measure the resulting piece with digital calipers, and subtract the cut width from the original vector width.
  • Determine the offset: Divide the total kerf width by two (Offset = Kerf / 2). For example, a 0.16 mm kerf requires a 0.08 mm offset.
  • Apply direction: Outer edges must be expanded outward (+0.08 mm), while internal cutouts, such as slots and holes, must be shrunk inward (-0.08 mm).

2. Method 1: Using the Offset Live Path Effect (Most Precise)

The Live Path Effect (LPE) method allows you to enter exact decimal values for your offset.

  1. Select the Object: Click on the path you want to modify using the Selector tool (S). If the object is a shape (rectangle, circle), convert it by going to Path > Object to Path.
  2. Separate Inner and Outer Paths: If your object contains both outer perimeters and inner holes combined into one path, go to Path > Break Apart. This ensures you can offset interior and exterior cutlines in opposite directions.
  3. Open Path Effects: Go to Path > Path Effects to open the panel on the right.
  4. Add the Offset Effect: Click the + (Add Path Effect) icon and search for Offset.
  5. Set the Parameters:
    • In the Offset input field, set the units to millimeters (mm) or inches (in).
    • Enter your half-kerf value (e.g., 0.08 for external expansion, or -0.08 for internal reduction).
    • Set the Join style to Miter or Round, matching your design's corner styles.
  6. Bake the Path: Once the offset is applied, select the object and choose Path > Object to Path to convert the effect into permanent cutting geometry.

3. Method 2: Using Inset/Outset with Step Preferences

If you frequently cut materials using the same kerf, you can configure Inkscape’s default Inset/Outset shortcuts.

  1. Configure Step Size: Go to Edit > Preferences > Behavior > Steps.
  2. Set Inset/Outset by: Enter your half-kerf value directly in the input box (e.g., 0.08 mm). Close the preferences window.
  3. Separate Paths: If working with a composite design, use Path > Break Apart so interior holes and exterior contours can be modified independently.
  4. Apply the Adjustment:
    • Select an outer path and press Ctrl + ) (Path > Outset) to expand it by your preset value.
    • Select an inner path (such as a slot or hole) and press Ctrl + ( (Path > Inset) to contract it by your preset value.
  5. Recombine Paths: Select both the interior cutouts and exterior path, then choose Path > Combine (Ctrl + K).

4. Finalizing the File for Laser Software

  1. Check Stroke Width: Ensure your stroke style is set to a hairline thickness required by your laser software (commonly 0.001 in or 0.05 mm) via Object > Fill and Stroke.
  2. Verify Node Geometry: Switch to the Node Tool (N) and inspect corners to ensure sharp vertices did not deform or overlap during the offset process.
  3. Save File: Save the finalized vector as an SVG, DXF, or PDF depending on the format required by your laser control software.
