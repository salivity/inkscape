Create Agate Patterns in Inkscape Using SVG Filters

This guide explains how to generate realistic banded agate mineral patterns in Inkscape using procedural SVG filter primitives. By pairing feTurbulence to create organic, distorted noise with feColorMatrix to manipulate luminance values into distinct color stripes, you can procedurally simulate the cyclic, stratified layers found in natural cut stones directly inside your vector workspace.

Understanding the Filter Pipeline

Natural agate is characterized by undulating, concentric bands of varied mineral opacity and color. In SVG, procedural textures rely on noise functions. The feTurbulence primitive generates Perlin-style noise coordinates, while the feColorMatrix primitive transforms the pixel channels of that noise mathematically. By stretching the noise along one or more axes and applying high-contrast color shifts via the color matrix, smooth noise transitions become sharp, stratified bands.

Step 1: Initialize the Filter in Inkscape

  1. Draw a base shape (such as a circle or an irregular pebble-like polygon) on your canvas using the Pen (B) or Ellipse (E) tool. Set the fill to a neutral color.
  2. Open the Filter Editor panel by navigating to Filters > Filter Editor.
  3. Click New at the bottom of the Filter Editor panel to initialize an empty custom filter, and rename it to "AgateBanding".
  4. Check the box next to your new filter while your shape is selected to assign the filter to the target object.

Step 2: Generate the Base Distortion with feTurbulence

The feTurbulence primitive generates the structural foundation of the mineral veins.

  1. In the Add Primitive dropdown menu, select Turbulence and click Add Primitive.
  2. Select the feTurbulence node in the filter list to view its properties in the panel below:
    • Type: Set to Fractal Noise for soft, cloud-like transitions, or Turbulence for sharper, jagged transitions.
    • Base Frequency: Agate banding requires stretched, directional variation rather than uniform isotropic noise. Set unequal frequencies for the X and Y axes (for example, X: 0.015, Y: 0.060). This stretches the pattern into stratified layers.
    • NumOctaves: Set between 3 and 5. Higher octaves introduce fine, microscopic veins, while lower octaves produce broad, smooth bands.
    • Seed: Adjust this value to alter the randomization until the flow lines mimic natural mineral strata.

Step 3: Create Banding with feColorMatrix

The feColorMatrix primitive applies a 5x4 transformation matrix to the RGBA channels of the turbulence output. To turn continuous gradient noise into bands, you must map the continuous grayscale or alpha values into distinct color ranges.

  1. In the Add Primitive dropdown, select Color Matrix and click Add Primitive.
  2. Connect the output of the feTurbulence primitive to the input of the feColorMatrix primitive by dragging the connector line in the editor graph.
  3. Select the feColorMatrix node and set the Type dropdown to Matrix.
  4. Input custom values into the matrix grid to isolate bands. A standard SVG color matrix operates as:
| R' |   | a00 a01 a02 a03 a04 |   | R |
| G' | = | a10 a11 a12 a13 a14 | * | G |
| B' |   | a20 a21 a22 a23 a24 |   | B |
| A' |   | a30 a31 a32 a33 a34 |   | A |
| 1  |                             | 1 |

To create sharp agate rings:

  • Multiply the noise input across channels with large contrasting values to force rapid clipping between color steps.
  • Use alternating high-positive and negative coefficients in the Red, Green, and Blue rows relative to the input channel (typically the Red or Alpha output from the turbulence). For example, setting high multipliers on the Red channel while leaving Blue negative forces the intermediate noise values to split sharply into warm carnelian, cream, and deep amber bands.
  • Adjust the fifth column (offset values) to slide the color distribution up or down, effectively revealing or hiding interior rings.

Step 4: Fine-Tuning Mineral Realism

To refine the agate appearance:

  • Layer Multiplication: Chain a second feColorMatrix set to Saturate or Hue Rotate to calibrate the final tone without rebuilding the matrix bands.
  • Blend with Base Vectors: Add a Composite (feComposite) primitive at the end of the chain, setting the Operator to In or Atop with the Source Graphic to ensure the mineral pattern clips cleanly to the original geometry of your stone cut.
