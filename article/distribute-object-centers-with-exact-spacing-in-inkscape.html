Distribute Object Centers with Exact Spacing in Inkscape

Setting exact numerical spacing between object centers in Inkscape is essential for technical illustration, UI design, and precise geometric layouts. While the standard Align and Distribute panel distributes objects evenly across a relative area, setting a specific numerical distance (such as 50 mm or 100 px) between center points requires tools like the Arrange dialog, the Transform tool, or Tiled Clones. This guide explains the most direct methods to achieve mathematically exact center-to-center distribution.

Method 1: Using the Arrange Dialog (Best for Multiple Existing Objects)

The Arrange panel allows you to order multiple selected objects into a grid or single row/column with exact numerical spacing based on their bounding box centers.

  1. Select the Objects: Click and drag to select all the objects you want to space out.
  2. Open the Arrange Panel: Navigate to Object > Arrange... in the top menu bar.
  3. Configure the Grid Settings:
    • Under the Grid tab, set the number of Rows or Columns (for a single horizontal line, set Rows to 1).
    • Check the box for Equal spacing.
    • Under Distance, ensure you select the appropriate unit (e.g., px, mm, in).
    • Enter your desired center-to-center distance in the X (horizontal) or Y (vertical) input fields.
    • Check the Center option for alignment to ensure calculations use the object centers rather than the edges.
  4. Apply: Click the Arrange button to immediately position the object centers at the defined distance.

Method 2: Using the Transform Tool (Step-and-Repeat Workflow)

If you are creating a sequence of identical or sequential objects, the Transform panel provides exact incremental movement from center to center.

  1. Select the Source Object: Click the object you want to duplicate and space out.
  2. Open the Transform Panel: Go to Object > Transform... (or press Shift + Ctrl + M).
  3. Set the Numerical Offset:
    • Switch to the Move tab.
    • Choose your unit of measurement.
    • Enter the exact center-to-center distance in the Horizontal (X) or Vertical (Y) field.
    • Ensure the Relative move checkbox is checked.
  4. Duplicate and Move:
    • Press Ctrl + D to duplicate the object in place.
    • Click Apply in the Transform panel to shift the new object by the exact distance.
    • Repeat Ctrl + D followed by Apply for each additional object required.

Method 3: Using Create Tiled Clones (For Large Sets of Objects)

For generating large, precise arrays with exact spacing relative to the original object's dimensions:

  1. Select the Base Object.
  2. Open Tiled Clones: Go to Edit > Clone > Create Tiled Clones...
  3. Set Shift Values:
    • In the Symmetry tab, choose P1 (simple translation).
    • In the Shift tab, define the shift percentage. Note that Shift X: 100% places the clone edge-to-edge; values above 100% add positive center-to-center offset relative to the object's width.
    • Alternatively, use the Shift > Spacing options to define absolute offset values.
  4. Set Rows and Columns: Define how many duplicates you need in the Rows, columns field at the bottom.
  5. Generate: Click Create to instantly generate the evenly spaced array.
