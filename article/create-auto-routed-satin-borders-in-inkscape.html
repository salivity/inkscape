Create Auto-Routed Satin Borders in Inkscape

This guide provides a direct walkthrough on creating clean, auto-routed satin stitch borders around complex letterforms using Inkscape and the Ink/Stitch embroidery extension. You will learn how to convert typography into suitable vector paths, generate dual-rail satin columns automatically, configure auto-routing to eliminate unnecessary trims, and preview the final embroidery design for production.

1. Prepare the Letterforms

  1. Type your text using the Text Tool (T). Choose your desired font and finalize your sizing.
  2. Select the text object and convert it to vector paths by navigating to Path > Object to Path (Shift + Ctrl + C).
  3. Ungroup the resulting letters by selecting Object > Ungroup (Shift + Ctrl + G).
  4. If your font is a script style or has overlapping glyphs, combine them into a single continuous shape by selecting all letters and clicking Path > Union (Ctrl + +).

2. Generate the Border Path

  1. Select the prepared letterform paths and duplicate them using Edit > Duplicate (Ctrl + D).
  2. Open the Fill and Stroke panel (Shift + Ctrl + Y).
  3. Set the Fill tab to No paint (X).
  4. Set the Stroke paint tab to a Flat color that contrasts with your fill.
  5. In the Stroke style tab, set the stroke width to match your desired satin border width (typically between 1.5 mm and 3.0 mm for standard embroidery threads).
  6. With the stroked path selected, convert it into an outline by going to Path > Stroke to Path (Ctrl + Alt + C).
  7. Break the path apart to separate the inner and outer boundaries by clicking Path > Break Apart (Shift + Ctrl + K).

3. Convert Outlines to Satin Columns

  1. Select the paths that define your border edges.
  2. Ensure direction: Satin columns require two subpaths (rails) traveling in the same relative direction.
  3. Open the Ink/Stitch tools by navigating to Extensions > Ink/Stitch > Tools: Satin > Convert Line to Satin. Ink/Stitch will automatically generate rungs between the inner and outer paths, transforming them into a standard satin column.

4. Apply Auto-Routing

Complex letters (such as "B", "P", or "R") feature sharp intersections and enclosed counters that cause excessive thread cuts if digitized manually. Auto-routing resolves this.

  1. Select your satin borders.
  2. Navigate to Extensions > Ink/Stitch > Tools: Satin > Auto-Route Satin Along Paths.
  3. In the dialog box, configure your routing preferences:
    • Check Add underlay to reinforce the letter borders.
    • Specify your preferred trim minimization settings.
  4. Click Apply. Ink/Stitch will calculate the path, split complex junctions into stitchable segments, insert connector travel stitches, and organize the sewing order to minimize jump stitches.

5. Adjust Embroidery Parameters and Simulate

  1. Select the routed satin group and navigate to Extensions > Ink/Stitch > Params.
  2. Fine-tune your stitch settings:
    • Zigzag spacing (density): Recommended between 0.35 mm and 0.45 mm.
    • Pull compensation: Set between 0.2 mm and 0.4 mm to prevent gaps between the border and the inner fill of the letter.
  3. Click Apply and Quit.
  4. Test the design by running Extensions > Ink/Stitch > Visualize and Export > Simulator/Preview to verify that stitch angles, travel stitches, and corner transitions flow cleanly around every letter.
