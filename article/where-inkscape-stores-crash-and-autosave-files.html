Where Inkscape Stores Crash and Autosave Files

When Inkscape encounters an unexpected error and crashes, it attempts to create an emergency backup of your unsaved work. This guide outlines the exact default storage locations for emergency saves and periodic autosaves across Windows, macOS, and Linux, along with instructions on how to locate your recovery files and verify your autosave settings.

Default Emergency Save Locations

When an unexpected crash occurs, Inkscape attempts an emergency document save. By default, it places the emergency file directly into your user home directory rather than a temporary cache folder.

Windows

  • Path: C:\Users\<YourUsername>\
  • Note: Open File Explorer, click on your main user folder (or press Windows Key + R, type %USERPROFILE%, and press Enter).

macOS

  • Path: /Users/<YourUsername>/ (User Home Directory)
  • Note: Open Finder and navigate to your Home folder (Shift + Cmd + H).

Linux

  • Path: /home/<YourUsername>/ (or ~)
  • Note: Check your primary user directory.

Emergency File Naming Convention

Emergency files are saved in the standard SVG format. Inkscape names the recovered file using the original document name (or "New document" if unnamed) appended with a timestamp:

  • filename.YYYY_MM_DD_HH_MM_SS_#.svg
  • Example: drawing.2024_03_15_14_30_22_0.svg

To locate the file quickly, open your user folder and sort the files by Date Modified in descending order.

Checking the Standard Autosave Directory

If an emergency crash save was not generated, the file may still exist in your regular autosave directory if autosave was enabled prior to the crash.

  1. Open Inkscape.
  2. Go to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + , on macOS).
  3. In the left sidebar, expand Input/Output and select Autosave.
  4. Check the Autosave directory field to see the exact folder path where background saves are stored.
  5. If the field is blank, Inkscape uses your default user directory or system temporary folder.

Best Practices for File Recovery

  • Enable Autosave: In Preferences > Input/Output > Autosave, ensure Enable autosave is checked and set an interval (e.g., 5 to 10 minutes).
  • Search by Extension: If the file is not in your home folder, run a system search for *.svg files modified within the last hour.
