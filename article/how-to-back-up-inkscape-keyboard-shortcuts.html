How to Back Up Inkscape Keyboard Shortcuts

Upgrading to a major version of Inkscape can sometimes reset or overwrite your configuration files, leading to the loss of personalized keybindings. This guide provides a straightforward method to locate, back up, and restore your custom keyboard shortcuts file across Windows, macOS, and Linux, ensuring a seamless transition during your software upgrade.

1. Locate the Shortcuts Folder Through Inkscape

The easiest way to find the exact location of your custom shortcuts is directly within Inkscape:

  1. Open Inkscape.
  2. Open the Preferences dialog by pressing Ctrl + Shift + P (Windows/Linux) or Cmd + Shift + P (macOS), or navigate to Edit > Preferences.
  3. In the left-hand menu, select System.
  4. Look for the User keys or User config entry. Inkscape displays the exact file system path to this directory.
  5. Click the Open button next to the path to launch the directory directly in your operating system's file manager.

2. Default File Paths by Operating System

If you cannot open Inkscape, manually navigate to the configuration directory:

  • Windows: %APPDATA%\inkscape\keys\ (Full path: C:\Users\<Username>\AppData\Roaming\inkscape\keys\)
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/keys/ or ~/.config/inkscape/keys/
  • Linux: ~/.config/inkscape/keys/

(Note: Custom shortcut files are saved with a .xml extension, typically named default.xml or whatever custom profile name you assigned.)

3. Back Up the File

  1. Locate the keys folder or the specific .xml file containing your custom shortcuts inside the directory found in step 1 or 2.
  2. Copy the .xml file (or the entire keys folder).
  3. Paste the copy into a secure location outside the Inkscape directories, such as your Desktop, Documents folder, or an external backup drive.

4. Restore Shortcuts After the Upgrade

Once your major Inkscape upgrade is complete, verify whether your shortcuts were retained. If they were reset:

  1. Close Inkscape completely.
  2. Navigate back to the keys folder using the paths mentioned above. If the keys folder does not exist in the new installation's directory, create a new folder named keys.
  3. Paste your backed-up .xml file into the keys folder.
  4. Launch Inkscape, open Preferences > Interface > Keyboard Shortcuts, and select your custom configuration from the shortcut profile list.
