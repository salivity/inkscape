How to Invert Selection of Nodes in Inkscape

Inverting a node selection in Inkscape allows you to quickly deselect your currently active nodes on a path while selecting all the unselected ones. This technique is useful when working with complex vector shapes where selecting the desired nodes manually would be tedious. By using the Node tool along with a simple keyboard shortcut, you can toggle your selection instantly.

Step-by-Step Guide to Inverting Node Selection

  1. Activate the Node Tool:
    Click the Edit paths by nodes tool in the left toolbar, or press N (or F2) on your keyboard.

  2. Select the Path:
    Click on the path containing the nodes you want to modify so that its outline and existing nodes become visible.

  3. Select Your Initial Nodes:
    Select the nodes you want to exclude from your final selection. You can click individual nodes while holding Shift, or click and drag a bounding box around them.

  4. Invert the Selection:
    Press ! (the exclamation mark key, typically Shift + 1 on most keyboards).

All previously selected nodes will be deselected, and all unselected nodes on that path will become highlighted and active.

Alternative Method via the Menu

If you prefer using the application menu rather than keyboard shortcuts:

  1. With your initial nodes selected using the Node Tool, look at the top menu bar.
  2. Go to Edit.
  3. Select Invert Selection.

Key Points to Remember

  • The inversion applies only to the subpaths or paths that are currently being edited.
  • Ensure the Node Tool (N) is active. If the primary Select and Transform Tool (S) is active instead, inverting will toggle the selection of entire objects on your canvas rather than individual nodes.
