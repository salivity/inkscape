How to Extract Text from SVG with Inkscape CLI

Extracting text strings from an SVG vector graphic into a plain text file can be fully automated using the Inkscape Command Line Interface (CLI). By leveraging Inkscape's built-in file export converters from your terminal, you can pull raw strings out of native SVG text tags without manually opening the graphic editor or copying text by hand.

The Basic Command

Inkscape detects output formats automatically based on the file extension you provide in the export command. To extract text strings from a single SVG file into a text document, run:

inkscape input.svg -o output.txt

Alternatively, you can use the long-form syntax:

inkscape --export-filename=output.txt input.svg

How It Works

When you supply a target filename ending in .txt, Inkscape invokes its internal plain text export routine. This process scans the SVG document tree for standard text elements—such as <text>, <tspan>, and <flowRoot>—and strips the XML formatting, coordinates, and styling attributes. The resulting .txt file contains only the plain text characters, separated by newlines reflecting the document's text hierarchy.

Batch Processing Multiple SVG Files

To extract text from multiple SVG files across a directory, use standard command-line scripting to process the files in sequence.

On Linux / macOS (Bash):

for file in *.svg; do
    inkscape "$file" -o "${file%.svg}.txt"
done

On Windows (PowerShell):

Get-ChildItem *.svg | ForEach-Object {
    inkscape $_.FullName -o "$($_.BaseName).txt"
}

Important Considerations

  • Text as Paths: This method only extracts live, editable text stored within SVG <text> elements. If text in the SVG has already been converted to geometric outlines (paths via Path > Object to Path), the characters are stored as vector coordinates rather than string data, meaning Inkscape cannot extract them as text.
  • Inkscape in System PATH: Ensure the inkscape executable is added to your operating system's system environment variables (PATH) so you can run the command from any working directory.
