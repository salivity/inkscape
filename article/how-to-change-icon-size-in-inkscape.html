How to Change Icon Size in Inkscape

Adjusting the icon theme size in the Inkscape interface is a straightforward process handled directly through the software's built-in preferences. Whether you are using a high-resolution 4K monitor and need larger icons for better visibility, or working on a smaller laptop screen where saving screen space is essential, Inkscape provides dedicated scaling sliders for each toolbar.

Steps to Adjust Icon Sizes

  1. Open the Preferences Menu

    • On Windows/Linux: Go to Edit > Preferences or press Ctrl + Shift + P.
    • On macOS: Go to Inkscape > Preferences or press Cmd + Shift + P.

  2. Navigate to Interface Settings

    • In the left sidebar of the Preferences window, click the arrow next to Interface to expand the category.
    • Select Toolbars (in Inkscape 1.0 and newer).

  3. Adjust Toolbar Icon Sliders Under the Toolbar Icon Sizes section, you will find independent sliders to scale different areas of the user interface:

    • Toolbox: Changes the size of the main drawing tools located on the left side of the screen.
    • Control bar: Adjusts the icons along the top tool controls bar.
    • Secondary toolbar: Changes the size of auxiliary panels, such as the Snap Controls and Command bar.

  4. Change Icon Size via UI Theme (Optional)

    • In the Preferences menu, click on Interface > Theming.
    • Under the Installed Themes section, you can adjust the global UI scale or toggle the Use small base icons option for a more compact workspace.

  5. Apply Changes

    • Most icon scaling changes occur immediately. If the new sizes do not render properly, close and restart Inkscape to ensure all interface elements refresh correctly.
