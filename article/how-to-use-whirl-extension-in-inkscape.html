How to Use Whirl Extension in Inkscape

This guide explains how to use the Whirl extension in Inkscape to create dynamic vortex and spiral distortions on vector paths. You will learn how to properly prepare your vector objects with sufficient nodes, access and configure the Whirl tool settings, and apply smooth rotational distortions to achieve compelling graphic effects.

Step 1: Prepare Your Vector Object

The Whirl extension works by shifting the existing nodes of a path in a circular pattern around the center. For a smooth vortex effect, the path must contain enough nodes.

  1. Select your object on the canvas.
  2. If working with text or a basic shape (like a rectangle or star), convert it to a path by going to Path > Object to Path.
  3. To add more nodes for a smoother distortion, go to Extensions > Modify Path > Add Nodes....
  4. Set the division method (by maximum segment length or number of segments) and click Apply, then Close.

Step 2: Open the Whirl Extension

  1. Ensure your path is selected with the Select Tool (S).
  2. Navigate to the top menu and select Extensions > Modify Path > Whirl....

Step 3: Adjust the Whirl Parameters

A dialog box will appear with options to control the distortion:

  • Whirl angle: Defines the strength and direction of the spiral. A positive value twists the object clockwise, while a negative value twists it counter-clockwise. Higher values produce tighter, more dramatic vortexes.
  • Live Preview: Check the Live Preview box at the bottom of the dialog window to see the transformation in real time before applying it permanently.

Step 4: Apply the Effect

  1. Once you are satisfied with the preview, click the Apply button.
  2. Click Close to exit the extension dialog.

Step 5: Refine the Distorted Path

After applying the distortion, you can fine-tune the result:

  • Use the Edit paths by nodes tool (N) to manually adjust any stray or overlapping node handles.
  • If the edges appear too sharp, select the path and choose Path > Simplify (Ctrl + L) to reduce excess nodes and smooth out the curves.
