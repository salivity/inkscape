How to Unlink Dynamic Offset in Inkscape

This guide explains how to convert a dynamic offset object into a standard, standalone vector path in Inkscape. Converting the offset freezes its geometry, removing the dynamic sizing handle and unlocking the standard node-editing capabilities found in standard vector shapes.

Step-by-Step Instructions

  1. Select the Dynamic Offset Choose the Select and Transform objects tool from the left toolbar (shortcut: S or F1), then click directly on the dynamic offset shape to highlight it.

  2. Convert the Object to a Path Navigate to the top menu bar, click on Path, and select Object to Path from the dropdown menu (shortcut: Shift + Ctrl + C on Windows/Linux, or Shift + Cmd + C on macOS).

  3. Verify the Path Conversion Switch to the Edit paths by nodes tool (shortcut: N or F2). If the conversion was successful, the single round dynamic offset handle will be replaced by standard square and diamond path nodes along the perimeter of the shape.

Handling Linked Offsets

If your shape was created as a Linked Offset rather than a dynamic offset, it remains connected to an original source path. Using the same command—Path > Object to Path—severs this connection, turning the linked offset into an independent path that will no longer update when the original source object is modified.
