Create Custom Dash Patterns in Inkscape

This guide explains how to design and apply custom stroke dash patterns in Inkscape. While Inkscape provides a collection of default dashed presets in the Stroke Style menu, creating unique, non-standard patterns requires either modifying the SVG dash array properties using the XML Editor or utilizing the Live Path Effects panel. The steps below provide a direct walkthrough for both methods.

Method 1: Using the XML Editor (Recommended)

The most precise way to define a custom dash pattern is by directly modifying the stroke-dasharray attribute within Inkscape's built-in XML Editor.

  1. Select the Object: Use the Select tool (S) to click on the path or shape you want to modify.
  2. Apply a Stroke: Ensure the object has a stroke enabled. Open the Fill and Stroke panel (Ctrl + Shift + F on Windows/Linux or Cmd + Shift + F on macOS) and select the Stroke paint tab to set a solid color.
  3. Open the XML Editor: Go to Edit > XML Editor or press Ctrl + Shift + X (Cmd + Shift + X on macOS).
  4. Locate the Style Attribute: In the XML tree, the selected object will be highlighted. In the right-hand panel of the XML Editor, locate the style attribute.
  5. Add or Edit stroke-dasharray:
    • Look for stroke-dasharray inside the style string. If it exists, edit its values. If it does not exist, append it to the end of the style definition.
    • Enter a comma- or space-separated list of numbers that define the lengths of alternating dashes and gaps (e.g., stroke-dasharray: 10, 4, 2, 4;).
    • Pattern Logic: The numbers represent [dash length], [gap length], [dash length], [gap length]. For example, 12, 3, 3, 3 creates a long dash followed by a short gap, a dot/short dash, and another short gap.
  6. Apply Changes: Click the Set button or press Ctrl + Enter to update the path immediately on your canvas.

Method 2: Using the "Dashed Stroke" Path Effect

For a non-destructive, visual approach without editing code, use Inkscape's Live Path Effects (LPE).

  1. Select Your Path: Click the path with the Select tool. (If using a shape like a rectangle or circle, convert it first via Path > Object to Path).
  2. Open Path Effects: Go to Path > Path Effects to open the panel.
  3. Add the Effect: Click the + (Add Path Effect) button, search for Dashed Stroke, and add it.
  4. Customize Pattern Values:
    • In the effect settings, customize the Number of dashes, Dash lengths, and Hole lengths.
    • Adjust the pattern interactively to achieve alternating sequences and custom spacing along the length of the path.

Method 3: Adjusting Dash Phase and End Caps

To refine how your custom dash pattern appears at the corners and endpoints of your stroke:

  • Dash Phase (Offset): In the Fill and Stroke > Stroke style tab, adjust the Pattern offset value to shift where the dash cycle begins along the path.
  • Cap Style: Change the Cap setting in the Stroke style panel to Round, Square, or Butt caps. Round caps turn short dashes into rounded dots, while butt caps maintain sharp rectangular segments.
