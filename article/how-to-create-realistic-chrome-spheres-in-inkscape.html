How to Create Realistic Chrome Spheres in Inkscape

Creating realistic metallic reflections on vector chrome spheres in Inkscape relies on high-contrast gradients that mimic an environment’s horizon, ambient bounce light, and intense specular highlights. This tutorial explains how to set up your base geometry, build a multi-stop metallic gradient, curve the horizon reflection, and add the necessary light sources to achieve a polished, photorealistic chrome effect entirely with vector tools.

1. Set Up the Base Sphere

  1. Select the Circles and Ellipses tool (E). Hold Ctrl and drag on the canvas to create a perfect circle.
  2. Open the Fill and Stroke panel (Shift + Ctrl + F).
  3. Set the base fill to a Radial Gradient. Chrome objects are heavily influenced by the vignette effect of their own curvature, meaning edges are generally darker than the center.
  4. Position the center of the radial gradient slightly off-center toward the direction of your intended primary light source (e.g., top-left).
  5. Set the gradient stops:
    • Center stop: Light silver-gray (#D0D5DD).
    • Mid stop: Neutral metallic gray (#8A92A0).
    • Outer edge stop: Dark charcoal (#2A2E35).

2. Create the Curved Horizon Reflection

The defining characteristic of chrome is a sharp reflection of the ground and sky, curved around the sphere's surface.

  1. Select the circle and press Ctrl + D to duplicate it in place.
  2. Select the Path > Inset command (or press Ctrl + () once or twice to create a very subtle rim gap, or keep it the exact size of the base.
  3. Switch the fill of this duplicate to a Linear Gradient using the Gradient tool (G).
  4. Drag the gradient handle vertically from top to bottom. Metallic reflections require high-contrast, multi-stop transitions:
    • Top stop (Zenith): Medium steel blue (#5C6B80).
    • Upper-middle stop (Sky): Very pale, near-white blue (#EAF0F8).
    • Center-upper stop (Horizon line): Pure white (#FFFFFF) to represent the brightest part of the horizon.
    • Center-lower stop (Ground line): Deep charcoal or dark earth tone (#1E2229) placed immediately next to the white horizon stop to create a razor-sharp division.
    • Bottom stop (Foreground/Ground): Mid-tone neutral gray (#6B7280).
  5. Double-click along the gradient line in the canvas to add stops as needed. Keep the white horizon stop and the dark ground stop extremely close together to produce a sharp horizon line.

3. Warp the Horizon to Simulate Spherical Distortion

A flat linear gradient looks artificial on a sphere. To bend the reflection:

  1. Draw an ellipse overlapping the bottom half of the sphere, bowing upward into a crescent or dome shape to match the curvature of a ball.
  2. Apply the ground colors to this curved shape rather than relying purely on a flat linear line.
  3. Alternatively, convert the linear gradient into a Mesh Gradient or use the Bend Path Effect (Path > Path Effects > Bend) on the reflection layer to bow the horizon line across the sphere's contour.

4. Add the Primary Specular Highlight

A chrome surface reflects the light source with almost mirror-like clarity.

  1. Select the Circles and Ellipses tool and draw a small, slightly squashed ellipse near the upper-left quadrant of the sphere (matching your main light angle).
  2. Rotate the ellipse slightly so its curve follows the curvature of the outer edge of the sphere.
  3. Apply a Radial Gradient to this highlight:
    • Center stop: Pure white (#FFFFFF) at 100% opacity.
    • Outer stop: Pure white (#FFFFFF) at 0% opacity.
  4. In the Fill and Stroke panel, set a slight Blur (between 0.5% and 1.5%) to soften the extreme edge while keeping the core bright and sharp.

5. Add Secondary Rim and Bounce Highlights

  1. Duplicate the original base sphere (Ctrl + D) and bring it to the front (Home key).
  2. Set the fill to None and give it a thin Stroke of 1px to 2px.
  3. Set the stroke color to a Linear Gradient running diagonally opposite the main light source (from bottom-right to top-left).
  4. Set the bottom-right stop to a pale sky-blue or ground-bounce color at 60% opacity, and fade the top-left stop to 0% opacity. This simulates the light bouncing off the floor back onto the bottom edge of the metal.
  5. Select all reflection layers and adjust their layer blend modes in the Fill and Stroke panel to Overlay or Hard Light if you want the underlying spherical volume gradient to blend seamlessly with the environment reflections.
