How to Fix Blurry PNG Exports in Inkscape

Exporting PNG images from Inkscape often results in blurry or fuzzy edges when vector objects do not align precisely with the raster pixel grid. This problem is typically caused by fractional coordinates, odd stroke widths, non-integer dimensions, or incorrect export DPI settings that trigger unwanted anti-aliasing. By setting up a pixel grid, snapping elements to exact integer coordinates, adjusting stroke alignments, and exporting at standard screen resolution, you can ensure crisp, pixel-perfect PNG exports every time.

1. Set Document Units to Pixels

Before drawing or exporting, ensure your workspace is configured to measure everything in screen pixels rather than millimeters or inches.

  1. Go to File > Document Properties (or press Ctrl + Shift + D).
  2. Under the Display tab, set Display units to px.
  3. Under the Format section, change the page measurement unit to px.

2. Enable the Pixel Grid and Snapping

Using a pixel grid visualizes the boundaries of your exported image and helps you position shapes accurately.

  1. In the Document Properties window, switch to the Grids tab.
  2. Select Rectangular grid and click New.
  3. Set Grid units to px with Spacing X and Spacing Y set to 1.0.
  4. Enable snapping on the right toolbar, making sure Snap to grids and Snap bounding boxes are turned on.

3. Remove Fractional Coordinates and Dimensions

Inkscape shapes placed on fractional pixels (e.g., X: 10.4px or Width: 99.7px) force the export engine to interpolate colors across adjacent pixels, causing blurriness.

  1. Select your object or group with the Select tool (S).
  2. Look at the top control bar for X, Y, W (Width), and H (Height).
  3. Ensure the unit dropdown is set to px.
  4. Round all X, Y, W, and H values to whole integers (e.g., change 100.4px to 100px).

4. Account for Stroke Width Offsets

Strokes in Inkscape are centered on path outlines by default. A 1px stroke centered on an integer grid line occupies 0.5px on each side, leading to anti-aliased, blurry borders.

  • For 1px, 3px, or odd-numbered strokes: Shift the object's X and Y coordinates by 0.5px so the stroke edges align cleanly with the pixel grid.
  • For 2px, 4px, or even-numbered strokes: Align the path directly to whole pixel coordinates.
  • Alternative: Convert the stroke to a filled path via Path > Stroke to Path (Ctrl + Alt + C) and snap the resulting shape's edges directly to the grid.

5. Use Correct Export Settings

Mismatched export resolutions can reintroduce scaling blur, even on perfectly aligned vectors.

  1. Open the export panel via File > Export (or press Ctrl + Shift + E).
  2. Choose Single Image and select the appropriate export area (Page or Selection).
  3. Set the export DPI to 96 (the native pixel density for Inkscape).
  4. Verify that the Width and Height in pixels match your intended design dimensions exactly without decimal places.
  5. Click Export to save your clean, sharp PNG.
