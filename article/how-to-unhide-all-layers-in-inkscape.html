How to Unhide All Layers in Inkscape

Managing complex vector designs often involves hiding multiple layers to focus on specific elements, but making them all visible again one by one can be time-consuming. This guide explains how to simultaneously unhide all hidden layers and objects in Inkscape using built-in panel controls and batch-selection shortcuts.

Method 1: Using the Layers and Objects Panel (Inkscape 1.2+)

In modern versions of Inkscape, the unified Layers and Objects panel allows you to modify the visibility of multiple layers at once.

  1. Open the Layers and Objects panel by pressing Ctrl + Shift + L (or Cmd + Shift + L on macOS), or go to Layer > Layers and Objects... in the top menu.
  2. Select all the layers you want to reveal:
    • Click the first layer, hold Shift, and click the last layer to select a continuous range.
    • Alternatively, hold Ctrl (Cmd on macOS) and click specific layers.
    • To select everything in the list, click inside the panel and press Ctrl + A.
  3. Click the Eye icon next to any of the selected layers. This action toggles visibility for all highlighted layers simultaneously, turning them visible.

Method 2: Using the Canvas Context Menu

If you have hidden objects or entire layers directly on the canvas, you can make them visible via the global context menu:

  1. Right-click anywhere on the empty canvas.
  2. Select Unhide All from the context menu (or navigate to Object > Unhide All in the top menu bar).
  3. Inkscape will immediately restore visibility to all hidden elements and top-level layers across your entire document.

Method 3: Unhiding Nested Layers via the XML Editor

If certain sub-layers or grouped objects remain hidden due to nested visibility attributes:

  1. Press Ctrl + Shift + X to open the XML Editor.
  2. Locate the parent <svg:g> layer elements.
  3. Check the style attribute on the right-hand pane for display:none.
  4. Remove the display:none property or change it to display:inline to force full visibility.
