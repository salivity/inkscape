How to Transfer Paths from Inkscape to FontLab

Transferring vector artwork from Inkscape into FontLab allows type designers to leverage Inkscape’s flexible drawing environment while utilizing FontLab’s robust font engineering tools. This guide covers how to prepare vector paths in Inkscape, import them into FontLab via the system clipboard or SVG files, and perform essential post-processing steps like metric alignment, path cleanup, and node optimization to ensure high-quality digital type production.

Step 1: Prepare Paths in Inkscape

Before transferring any artwork, your paths must be converted into clean, closed outlines compatible with font technology.

  1. Convert Strokes to Outlines: Select all elements and go to Path > Stroke to Path. Fonts cannot use open strokes with stroke widths; every line must be a closed shape.
  2. Combine Shapes: If a character consists of overlapping shapes, select them and apply Path > Union to merge them into a single compound path. For counters (like the inside of an "O"), use Path > Difference.
  3. Minimize Nodes: Excess nodes lead to file bloat and rendering issues. Clean up nodes manually or use Path > Simplify sparingly. Ensure smooth nodes have collinear handles.
  4. Set Up Dimensions: To minimize scaling issues later, match your Inkscape document units to FontLab’s Units Per Em (typically 1000 UPM). You can set your document size to 1000 × 1000 px in File > Document Properties.

Step 2: Transfer the Vectors

There are two primary methods to move vector data from Inkscape to FontLab: direct copy-paste or SVG file import.

Method A: Direct Copy and Paste (Fastest for Single Glyphs)

  1. In Inkscape, select the finished path and copy it (Ctrl+C or Cmd+C).
  2. Open your font project in FontLab.
  3. Double-click the target glyph cell in the Font Window to open the Glyph Window.
  4. Paste the path directly into the canvas (Ctrl+V or Cmd+V).

Method B: Exporting and Importing SVG (Best for Accuracy and Batch Work)

  1. In Inkscape, select your artwork and navigate to File > Save As.
  2. Select Plain SVG from the file type dropdown to remove Inkscape-specific metadata.
  3. In FontLab, open the desired glyph slot.
  4. Go to File > Import > Artwork (or drag and drop the SVG file directly into the Glyph Window).

Step 3: Clean and Scale in FontLab

Once the outlines are in FontLab, they require font-specific corrections to meet professional type standards.

  1. Scale and Position: Use the Free Transform tool to align the baseline, x-height, and cap height to your font’s metric lines. Adjust the left and right sidebearings.
  2. Round Coordinates to Integers: Digital fonts require integer coordinates. Select your contours and run Contour > Round Coordinates to eliminate fractional pixels.
  3. Correct Path Direction: Font formats require specific contour winding rules (TrueType uses clockwise outer contours; PostScript/OpenType uses counter-clockwise). Go to Contour > Detect Direction or use FontAudit to automatically correct path orientation.
  4. Run FontAudit: Click the FontAudit button in the status bar or choose Contour > FontAudit > Fix All to automatically resolve stray points, missing extrema, and unintended flat curves.
  5. Add Extremum Nodes: Curves in digital type should have nodes at their extreme horizontal and vertical positions. Go to Contour > Add Extremes to insert these required nodes.
