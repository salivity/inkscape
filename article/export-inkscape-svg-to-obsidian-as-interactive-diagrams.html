Export Inkscape SVG to Obsidian as Interactive Diagrams

Integrating vector graphics from Inkscape into Obsidian allows you to enrich your personal knowledge base with dynamic, scalable illustrations that support hyperlinks, hover states, and custom CSS styling. By properly preparing your artwork in Inkscape, choosing the correct export settings, and embedding the raw SVG code or linking it via native HTML tags in Obsidian, you can transform static illustrations into interactive visual hubs.

1. Prepare Interactive Elements in Inkscape

Before exporting, configure your vector paths and shapes to respond to interaction:

  1. Assign Identifiers and Classes: Open the Object Properties panel (Shift + Ctrl + O). Select an element, then assign a unique ID or Class (e.g., interactive-node). This enables custom CSS targeting inside Obsidian.
  2. Add Hyperlinks: Right-click any shape, text, or group and select Create Link. In the link settings, set the href attribute. You can use standard URLs (https://example.com) or Obsidian URI schemes (obsidian://open?vault=MyVault&file=TargetNote) to navigate directly to other notes.
  3. Clean Up the Document: Navigate to File > Clean Up Document to remove unused definitions, gradients, and metadata that inflate file size.

2. Export as Optimized SVG

Standard Inkscape SVGs contain proprietary editor metadata that can interfere with web rendering.

  1. Go to File > Save As....
  2. Set the file format dropdown to Optimized SVG (*.svg).
  3. In the export dialog:
    • Enable Convert CSS attributes to XML attributes (or keep CSS depending on your preference).
    • Ensure Remove unused IDs is unchecked if you plan to target specific elements with CSS or JavaScript.
    • Check Shorten color values and Collapse groups to streamline markup.
  4. Save the file to your Obsidian vault's attachment directory.

3. Embed the Diagram into Obsidian

Obsidian handles standard markdown image syntax (![[diagram.svg]]) as a flat, static image. To retain full vector interactivity, choose one of the following methods:

Method A: Direct Inline SVG (Recommended for Styling and Links)

Open the exported .svg file in a code editor, copy the entire <svg>...</svg> block, and paste it directly into your Obsidian markdown note.

  • Pros: Complete access to embedded links, tooltips (<title> tags), and internal CSS.
  • Cons: Clutters the markdown source mode with code.

Method B: The HTML <object> Tag

If you prefer to keep your markdown clean, reference the SVG file using an HTML <object> element:

<object type="image/svg+xml" data="app://local/full/path/to/your/vault/attachments/diagram.svg" class="interactive-svg"></object>

Alternatively, if using an active web server or static asset plugin, use the relative vault path:

<object type="image/svg+xml" data="attachments/diagram.svg"></object>

This isolates the SVG document while preserving internal click events and pointer dynamics.

4. Style and Animate with CSS Snippets

To add hover effects or match your Obsidian theme (light/dark mode):

  1. Go to Settings > Appearance > CSS snippets in Obsidian and open your snippets folder.
  2. Create a file named svg-styling.css.
  3. Add custom rules targeting the classes or IDs defined in Inkscape:
/* Change color on hover */
.interactive-node:hover {
  fill: var(--interactive-accent) !important;
  cursor: pointer;
  transition: fill 0.2s ease-in-out;
}

/* Adapt stroke to dark/light theme */
.theme-dark .interactive-svg path {
  stroke: var(--text-normal);
}
  1. Reload and enable the snippet inside Obsidian's appearance settings.
