Measure Segments in Inkscape: Technical Dimensions

Inkscape's Measure Segments Live Path Effect (LPE) provides an automated way to generate precise technical dimension lines, arrows, and distance labels directly on vector paths. This guide covers how to prepare your vector objects, apply the Measure Segments effect, and customize the measurement units, text styling, and projection lines to create clear, CAD-style dimensioning for technical illustrations and blueprints.

1. Prepare Your Vector Object

The Measure Segments effect only works directly on path objects.

  1. Select the object you want to measure.
  2. If your object is a primitive shape (like a rectangle or circle) or text, convert it to a path by going to Path > Object to Path (or press Shift + Ctrl + C).
  3. If measuring multiple disconnected objects, combine them using Path > Combine (Ctrl + K).

2. Apply the Measure Segments Path Effect

  1. Open the Path Effects dialog by navigating to Path > Path Effects in the top menu.
  2. With your path selected, click the Add Path Effect button (the + icon) in the Path Effects panel.
  3. In the search bar, type Measure Segments and select it from the list.

Inkscape will immediately apply default dimension lines and text readouts to all segments of your selected path.

3. Configure Measurement Units and Precision

In the Path Effects panel, adjust the primary measurement parameters under the Measure Segments settings:

  • Unit: Choose your preferred unit of measurement (e.g., millimeters mm, centimeters cm, inches in, or pixels px).
  • Precision: Set the number of decimal places to display (e.g., set to 2 for 10.50mm or 0 for whole numbers).
  • Scale: Adjust this value if your drawing uses a custom scale factor (e.g., set to 10 if 1 canvas unit represents 10 real-world units).

4. Customize Position and Projection Lines

To make the dimensions readable and separate them from your drawing geometry:

  • Position: Adjust the Offset slider to push the dimension lines and labels away from the actual path segments.
  • Projection Lines: Enable projection (extension) lines to draw lines connecting the dimension markers back to the path vertices. Adjust their length and offset to keep the drawing clean.
  • Orientation: Choose whether the dimension lines should be parallel to the segments or aligned to specific axes (horizontal/vertical).

5. Format Text and Line Appearance

  • Font and Size: Adjust the Font size field in the Path Effects panel. To change the font family, use the text controls provided within the effect settings.
  • Color and Line Width: The dimension lines inherit the stroke color and width from your path by default, but you can override the stroke styling directly within the effect parameters to make dimension lines thinner or a different color than the primary object.
  • Arrows and Markers: Select custom end markers to use standard engineering arrowheads, ticks, or dots at the ends of each measurement segment.

6. Managing Dynamic and Static Measurements

  • Dynamic Updating: By default, the dimensions remain linked to the path. If you edit the path's nodes using the Node Tool (N), the dimension measurements and lines will update automatically in real time.
  • Baking the Dimensions: If you need to edit the dimension lines and text labels as regular vector objects, select the object and choose Path > Object to Path. Note that this permanently disconnects the dynamic link.
