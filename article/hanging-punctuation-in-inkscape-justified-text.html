Hanging Punctuation in Inkscape Justified Text

While Inkscape does not currently feature an automated, one-click toggle for optical margin alignment or hanging punctuation, you can achieve properly aligned quotation marks in justified text blocks using manual typographical adjustments. This guide explains how to push quotation marks into the margin using manual kerning, negative indents, and separate text containers to maintain clean vertical margins.

Method 1: Manual Kerning (Recommended)

The most precise way to hang a quotation mark outside a justified text block without breaking the text flow is by adjusting the horizontal character positioning (kerning).

  1. Select the Text tool (T) and click inside your justified text frame.
  2. Highlight the opening quotation mark, or place your cursor immediately between the quotation mark and the first letter of the word.
  3. Hold down Alt and press the Left Arrow key repeatedly to nudge the quotation mark to the left, shifting it outside the boundary of the justified text box.
  4. To shift the quotation mark independently without moving the rest of the line:
    • Place the text cursor directly between the quotation mark and the first letter.
    • Hold Alt and press the Right Arrow key to restore the spacing between the quotation mark and the adjacent text, counteracting the previous shift for the rest of the sentence.

Method 2: Negative First-Line Indent

If you are working with a flowed text box (created by clicking and dragging with the Text tool):

  1. Select your justified text object using the Text tool.
  2. Open the Text and Font dialog (Shift + Ctrl + T).
  3. Increase the overall left margin or position the entire text box slightly to the right of your intended guide or margin line.
  4. Place your cursor before the opening quotation mark.
  5. In the Text tool controls bar at the top of the screen, locate the Horizontal kerning field (Dx) or manually press Shift + Left Arrow / Alt + Left Arrow to shift the character into the negative space, placing it flush with your document's true alignment grid.

Method 3: Independent Text Objects for Pull Quotes

For large quotes or prominent display text where justification and optical balance are critical:

  1. Create your main justified text block omitting the opening quotation mark.
  2. Create a separate, single-character text object containing only the quotation mark (" or “).
  3. Position the quotation mark visually to the left of the main justified text block, hanging entirely within the margin.
  4. Select both the quotation mark and the text frame, then open the Align and Distribute panel (Shift + Ctrl + A) to align the top edges cleanly.
