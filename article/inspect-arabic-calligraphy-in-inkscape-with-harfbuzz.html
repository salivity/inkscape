Inspect Arabic Calligraphy in Inkscape with HarfBuzz

Inkscape uses the HarfBuzz text shaping engine alongside Pango to process complex scripts, making it a capable environment for rendering, inspecting, and manipulating Arabic calligraphy. This guide details how to leverage Inkscape’s typography tools and path conversion features to inspect HarfBuzz-shaped Arabic glyphs, verify OpenType features, and analyze cursive attachments.

1. Configure the Document for Arabic Typography

Open Inkscape and select the Text tool (T). Set the writing direction to Right-to-Left (RTL) on the top toolbar to allow HarfBuzz to sequence bidirectional text correctly. Choose an OpenType Arabic font with rich shaping tables, such as Amiri, Scheherazade New, or an Arabic script font like Nastaliq or Diwani.

2. Access the OpenType Features Tab

HarfBuzz executes font features automatically, but fine-grained inspection requires accessing the font layout engine settings:

  1. Open the Text and Font dialog (Shift + Ctrl + T).
  2. Switch to the Features tab.
  3. Review the available OpenType feature categories:
    • Common Ligatures (liga) and Contextual Alternates (calt): Crucial for standard Arabic cursive flow.
    • Required Ligatures (rlig): Ensures foundational characters (like Lam-Alef) shape correctly.
    • Discretionary Ligatures (dlig): Enables calligraphic flourishes and complex extended ligatures.
    • Stylistic Sets (ss01–ss20): Alters the visual style of specific character sequences depending on the font design.

Toggle these options to observe in real time how HarfBuzz changes glyph forms and reshapes adjacent characters.

3. Inspect Diacritic and Mark Positioning

HarfBuzz manages Mark-to-Base (mark) and Mark-to-Mark (mkmk) positioning tables. To verify that diacritics (Tashkeel) are placed properly without overlapping base letters:

  1. Type a sequence featuring stacked diacritics (e.g., a letter with both a Shaddah and a Fatha).
  2. Zoom in using the Zoom tool (Z).
  3. Test font sizes to ensure HarfBuzz scales mark offsets proportionally without vertical clipping or misalignments.

4. Convert to Paths for Vector-Level Inspection

To inspect the precise outlines generated by HarfBuzz:

  1. Select the rendered Arabic text object.
  2. Go to Path > Object to Path (Ctrl + Shift + C).
  3. HarfBuzz transforms the shaped text into standard SVG paths.
  4. Press Ctrl + Shift + G to ungroup the characters into distinct shapes.
  5. Select the Node tool (N) to examine how HarfBuzz resolved cursive overlap, ligature fusion, and anchor placement between connecting strokes.

5. Validate Styling via the XML Editor

To check the raw CSS rules passed to HarfBuzz:

  1. Open the XML Editor (Shift + Ctrl + X).
  2. Select the Arabic text element.
  3. Check the style attribute for font-feature-settings declarations to ensure specific typographic features are formatted correctly for the rendering pipeline.
