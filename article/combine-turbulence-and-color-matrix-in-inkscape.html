Combine Turbulence and Color Matrix in Inkscape

This guide explains how to combine SVG filter primitives in Inkscape using the Filter Editor dialog. By chaining the Turbulence primitive into a Color Matrix primitive, you can generate dynamic procedural textures, noise, and customized color effects directly inside your vector graphics.

1. Open the Filter Editor

  1. Select the vector object you want to apply the texture to.
  2. Go to the top menu and select Filters > Filter Editor.
  3. In the Filter Editor panel, click the New button at the bottom left to create a new filter.
  4. Check the box next to your new filter name to assign it to your selected object.

2. Add the Turbulence Primitive

  1. In the Add primitive drop-down menu at the bottom of the panel, select Turbulence.
  2. Click Add.
  3. Select the Turbulence entry in the primitive list and use the Effect parameters tab below to configure it:
    • Type: Choose between Fractal Noise (smoother) or Turbulence (cloudier/harder edges).
    • Base Frequency: Adjust the X and Y frequencies to scale the noise pattern.
    • Octaves: Increase the value (e.g., 3 to 5) for greater visual detail.

3. Add the Color Matrix Primitive

  1. From the Add primitive drop-down menu, select Color Matrix.
  2. Click Add.
  3. In the primitive list, ensure the Color Matrix is listed below Turbulence.

4. Connect the Primitives

Inkscape allows you to route the output of one primitive into another using connection lines in the Filter Editor:

  1. Locate the connection arrows on the right side of the primitive list.
  2. Connect the Input triangle of the Color Matrix primitive to the output of the Turbulence primitive.
  3. Leave the Turbulence input connected to the Source Graphic or leave it empty (Turbulence generates its own data).

5. Adjust the Color Matrix Values

  1. Click on the Color Matrix primitive in the list.
  2. Go to the Effect parameters tab.
  3. Select a Type:
    • Matrix: Edit the 4x5 RGBA matrix to remap specific color and alpha channels generated by the noise.
    • Saturate / Hue Rotate: Easily change the color vibrancy or shift the color spectrum.
    • Luminance to Alpha: Convert the noise brightness directly into transparency values.

6. Blend with the Source Object (Optional)

To overlay the colored noise onto your original graphic:

  1. Add a Composite or Blend primitive.
  2. Route the output of Color Matrix into Input 1.
  3. Route Source Graphic into Input 2.
  4. Set the blend mode to Multiply, Screen, or Normal depending on the desired visual finish.
