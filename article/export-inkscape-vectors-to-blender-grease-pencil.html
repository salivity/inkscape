Export Inkscape Vectors to Blender Grease Pencil

This guide explains how to export vector contours from Inkscape and import them into Blender as native Grease Pencil objects. By following this workflow, you can leverage Inkscape's precision vector drawing tools to design assets, import the Scalable Vector Graphics (SVG) data into Blender, and convert the resulting curve data into editable Grease Pencil strokes ready for 2D animation.

Step 1: Prepare and Export Your Artwork in Inkscape

Before exporting, your artwork must be composed strictly of vector paths rather than raw shapes, text, or groups.

  1. Ungroup Elements: Select everything (Ctrl + A) and ungroup your elements (Ctrl + Shift + G) repeatedly until no groups remain.
  2. Convert Shapes and Text to Paths: Select all elements and navigate to Path > Object to Path (Shift + Ctrl + C). Blender requires true path data to generate curves.
  3. Handle Strokes: If you want your lines to be treated as single-line Grease Pencil strokes, leave them as open or closed path strokes. If you want outlines converted to filled shapes, use Path > Stroke to Path.
  4. Export to SVG: Go to File > Save As..., choose Plain SVG (instead of Inkscape SVG to strip out unnecessary software-specific metadata), and save your file.

Step 2: Import the SVG into Blender

Blender natively supports SVG importing through its built-in curve engine.

  1. Open Blender and select a standard workspace or the 2D Animation workspace.
  2. Go to File > Import > Scalable Vector Graphics (.svg).
  3. Navigate to your saved file and click Import SVG.
  4. Locate and Scale the Curves: Imported SVGs typically appear at the 3D cursor at a very small scale. Select the imported curve collection in the Outliner, press S, drag your mouse to scale the artwork up, and press Ctrl + A > Apply All Transforms.
  5. Join Paths (Optional): Inkscape exports each path as an individual curve object. If you want your art in a single object, select all the imported curve objects and press Ctrl + J to join them.

Step 3: Convert Curves to Grease Pencil

Once your vectors are in Blender as curve objects, they can be instantly converted into Grease Pencil data.

  1. Select your curve object in the viewport or Outliner.
  2. Right-click the object in the 3D Viewport (or go to the Object menu in the top bar).
  3. Select Convert To > Grease Pencil.

Blender will create a new Grease Pencil object matching your vector contours. The original curve object will remain in your scene; you can hide or delete it.

Step 4: Configure for Animation

After conversion, the artwork operates as native Grease Pencil geometry.

  1. Adjust Stroke Thickness: Select the new Grease Pencil object, navigate to the Object Data Properties (green squiggle icon) in the Properties panel, and adjust the stroke thickness or stroke offset.
  2. Clean Up Nodes: Enter Edit Mode (Tab). Grease Pencil automatically generates points along the imported lines. Use the Stroke > Simplify tool to reduce dense point clusters if the imported paths are too heavy.
  3. Materials: The converter assigns default materials based on the SVG colors. You can edit these under the Material Properties tab to change stroke colors, fill colors, or blending modes.
  4. Animate: Switch to Draw Mode or Sculpt Mode to edit lines, utilize the Dope Sheet set to Grease Pencil mode, and start keyframing your drawing on the timeline.
