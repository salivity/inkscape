How to Invert Selection in Inkscape

Inverting a selection in Inkscape allows you to instantly deselect currently highlighted objects and select everything else on your canvas or within a specific layer. This guide explains the fastest methods to invert your object selection using keyboard shortcuts and the main application menu.

Method 1: Using the Keyboard Shortcut

The fastest way to invert your selection is by using the default keyboard shortcut:

  1. Select the object or objects you want to exclude.
  2. Press ! (which is Shift + 1 on most keyboards).
  3. Inkscape will immediately deselect your current items and select all other unlocked, visible objects in the active layer.

Method 2: Using the Edit Menu

If you prefer using the graphical menu interface:

  1. Use the Selector Tool (S or F1) to select the items you wish to exclude.
  2. Click on Edit in the top menu bar.
  3. Select Invert Selection from the dropdown list.

Invert Selection Across All Layers

By default, inverting a selection only applies to the currently active layer. If you are working with multiple layers and want to invert the selection across your entire document:

  1. Select your target object(s).
  2. Go to Edit in the top menu.
  3. Choose Invert Selection in All Layers (or press Alt + !).

Note: Inkscape will ignore any objects that are currently locked or located on hidden layers during an inverted selection.
