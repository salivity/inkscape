How to Use the Slice Path Effect in Inkscape

Inkscape provides a non-destructive way to divide vector artwork using the Slice Live Path Effect (LPE). Unlike traditional Boolean operations that permanently alter geometry, this tool allows you to dynamically cut an object along an open line or path while keeping the original shapes fully editable.

The Slice Live Path Effect

The specific path effect designed for this task is called Slice. Introduced in modern versions of Inkscape, the Slice LPE uses an auxiliary path—such as an open Bézier curve—as a cutting line across a target shape. Because it is a Live Path Effect, the underlying object and the cutting line remain completely intact and adjustable at any time.

How It Differs from Destructive Boolean Operations

Standard commands like Path > Division or Path > Cut Path permanently break vector shapes into separate components, discarding original curves and overlapping geometry. The Slice LPE, by contrast, acts as a dynamic procedural filter. If you move, curve, or rescale the cutting path, Inkscape recalculates the slice in real time without destroying the source shape.

How to Apply the Slice Effect

  1. Prepare Your Paths: Draw the main vector object you want to cut, along with an open path or line that intersects it where you want the cut to occur.
  2. Copy the Cut Line: Select your cutting line and copy it to your clipboard (Ctrl + C or Cmd + C).
  3. Open Path Effects: Select the base object and open the Path Effects panel via Path > Path Effects.
  4. Add Slice: Click the + (Add Path Effect) icon and choose Slice from the menu.
  5. Assign the Cutting Path: In the Slice parameters, locate the Cut line property and click the Link to path on clipboard icon (or use the node editor to link the path directly).

Key Parameters and Modes

Once connected, the Slice effect provides several options to control the result:

  • Slice Mode: Choose whether to keep the cut object as a single dynamically cleaved item, display only one of the sliced halves, or hide specific portions of the shape.
  • Live Node Editing: Activate the Node tool (N) on the sliced object to see interactive handles, allowing you to manipulate the angle, curvature, and position of the cut line directly on the canvas.
  • Non-Destructive Reversibility: Removing or disabling the Slice effect in the Path Effects panel instantly restores the original, uncut object.
