Inkscape Trace Bitmap: Stacked vs Cutout Layers

Vectorizing raster graphics in Inkscape requires choosing how color layers interact with one another. When using the Trace Bitmap tool, you can create stacked layers where colors sit on top of each other, or non-overlapping cutouts where each color piece fits together like a jigsaw puzzle. This guide explains the core differences between these two output methods and provides step-by-step instructions on how to generate both in Inkscape.

Understanding Stacked vs. Non-Overlapping Layers

  • Stacked Layers: The software generates base shapes that cover larger background areas, placing smaller detail colors directly on top of them. This eliminates visible gaps between colors and is ideal for standard vector illustrations, digital art, and print design.
  • Non-Overlapping Cutouts: Each color is traced as an isolated shape with no underlying layers. The pieces fit edge-to-edge. This approach is essential for vinyl cutting, plotter machines, laser engraving, and heat transfer vinyl (HTV) where overlapping layers create unwanted thickness or material waste.

How to Trace as Stacked Color Layers

  1. Import the Image: Open Inkscape and import your raster graphic (File > Import).
  2. Open Trace Bitmap: Select the image, then navigate to Path > Trace Bitmap (or press Shift + Alt + B).
  3. Select Multicolor Mode: In the Trace Bitmap panel, switch to the Multicolor tab and choose Colors from the detection dropdown menu.
  4. Set Scans: Adjust the Scans count to match the number of colors in your image.
  5. Enable Stacking: Ensure the Stack checkbox is checked. This tells Inkscape to build each scan on top of the previous layer.
  6. Execute Trace: Click Apply. Inkscape will generate a grouped set of overlapping vector paths.

How to Trace as Non-Overlapping Cutouts

  1. Select the Image: Click on your raster image on the canvas.
  2. Open Trace Bitmap: Go to Path > Trace Bitmap.
  3. Configure Multicolor Settings: Select the Multicolor tab and set the detection method to Colors.
  4. Disable Stacking: Ensure the Stack checkbox is unchecked.
  5. Execute Trace: Click Apply.
  6. Verify Separation: Ungroup the result (Ctrl + Shift + G or Object > Ungroup) and move the individual pieces apart to confirm that each color exists as a distinct cutout with empty spaces beneath.

Fixing Overlaps Manually via Boolean Operations

If an existing vector file is stacked and needs to be converted into non-overlapping cutouts:

  1. Ungroup the vector shapes (Ctrl + Shift + G).
  2. Duplicate the top layer shape (Ctrl + D).
  3. Select the duplicate and the underlying layer beneath it.
  4. Go to Path > Difference (or press Ctrl + -).
  5. Repeat this process for each overlapping layer until all shapes fit together without overlapping.
