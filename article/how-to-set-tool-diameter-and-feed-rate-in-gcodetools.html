How to Set Tool Diameter and Feed Rate in Gcodetools

Configuring the cutting tool diameter and feed rates in the Gcodetools extension for Inkscape is essential for generating accurate and safe G-code for CNC machines. This guide explains how to generate the tool definition box using the Tools Library, edit critical parameters such as cutter diameter, horizontal feed, and plunge rate directly on the canvas, and prepare your vector paths for precise machining.

Step 1: Open the Gcodetools Tools Library

  1. Open your vector project in Inkscape.
  2. In the top menu, navigate to Extensions > Gcodetools > Tools library....
  3. In the dialog window that appears, select the tool type suitable for your job (such as default, cylinder, or cone).
  4. Click Apply, then click Close.

Step 2: Locate the Tool Definition Box on the Canvas

After applying the tool library, Gcodetools will generate a green rectangular box containing text on your Inkscape canvas. This graphic box acts as the configuration table for the active cutting tool.

Step 3: Modify the Tool Diameter

  1. Select the Text Tool from the left toolbar (or press T on your keyboard).
  2. Click directly on the numeric value next to the diameter field inside the green box.
  3. Change the number to match your actual tool diameter in your project's measurement units (typically millimeters).
    • Example: For an 1/8-inch bit in a millimeter workspace, set the value to 3.175.

Step 4: Configure Feed Rates and Spindle Speed

Using the Text Tool, adjust the following operational parameters within the same text box:

  • feed: Sets the horizontal (X/Y axis) cutting speed in units per minute (e.g., 800 for 800 mm/min).
  • penetration feed: Sets the vertical (Z axis) plunging speed into the material. This should typically be slower than the horizontal feed (e.g., 200 to 300 mm/min).
  • spindle rpm: Defines the rotational speed of the spindle if supported by your CNC controller.
  • depth step: Sets the maximum depth the tool will cut in a single pass.

Step 5: Important Editing Rules

  • Preserve Text Formatting: Do not delete the parameter labels (e.g., diameter:, feed:) or the colons. Only change the numeric values following the labels.
  • Do Not Ungroup the Box: The green rectangle and its text are grouped internally so Gcodetools can read the data. Avoid ungrouping the object.
  • Multiple Tools: If performing multi-tool operations, you can generate multiple tool boxes. Ensure the active tool box corresponds to the paths being processed.

Once the parameters are set, you can proceed to Extensions > Gcodetools > Path to Gcode to calculate toolpaths using your customized tool diameter and feed rates.
