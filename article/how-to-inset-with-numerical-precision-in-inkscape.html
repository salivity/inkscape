How to Inset with Numerical Precision in Inkscape

By default, Inkscape's standard Inset command applies an offset based on a fixed pixel increment rather than an explicit, customizable measurement. This guide explains how to bypass this limitation and create precise, numerically defined insets using two methods: the Live Path Effect (LPE) Offset tool for non-destructive, variable-unit sizing, and the global Steps setting in Preferences for single-step keyboard shortcuts.

Method 1: Use the Offset Path Effect (Recommended)

The most accurate way to apply a numerically defined inset in Inkscape without altering path geometry is through the Path Effects panel.

  1. Select the path you want to inset.
  2. Open the Path Effects dialog by navigating to Path > Path Effects.
  3. Click the + (Add Path Effect) button.
  4. Search for or select Offset from the list of available effects.
  5. In the Offset effect settings panel, locate the Offset numerical field.
  6. Enter a negative value to inset the path (for example, -5.000). A positive value will outset the path.
  7. Change the unit dropdown (such as px, mm, in, or pt) adjacent to the numerical field to match your desired measurement system.
  8. (Optional) If you need the inset path converted permanently back to standard nodes, go to Path > Object to Path.

Method 2: Adjust the Inset/Outset Step Preference

If you prefer using the standard keyboard shortcut (Ctrl + (), you can define the exact distance it moves per press in the application preferences.

  1. Open the Preferences window via Edit > Preferences (or Inkscape > Preferences on macOS).
  2. In the left sidebar, click on Tools and then select Steps.
  3. Locate the field labeled Inset/Outset by.
  4. Enter your exact numerical value and choose your desired unit (px, mm, etc.).
  5. Close the Preferences dialog.
  6. Select your path and apply the inset once by going to Path > Inset or pressing Ctrl + ( (or Cmd + ( on macOS).

Applying the command exactly once will inset the path by the precise numerical increment configured in your preferences.
