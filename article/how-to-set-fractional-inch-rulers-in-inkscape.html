How to Set Fractional Inch Rulers in Inkscape

This guide explains how to configure Inkscape for architectural drawings using imperial measurements and fractional increments. While Inkscape’s on-screen canvas rulers natively represent subdivisions in decimal formats, you can effectively set up an architectural workspace with fractional inch increments (such as 1/16", 1/8", or 1/4") by adjusting your document units, custom scale, and snap grids.

1. Set the Document Display Units to Inches

  1. Open Inkscape and create a new document.
  2. Open the Document Properties dialog by pressing Ctrl + Shift + D (or Cmd + Shift + D on macOS), or go to File > Document Properties.
  3. Under the Display tab, locate Display units and change the dropdown setting to in (inches). This updates the canvas rulers to measure in inches rather than pixels or millimeters.

2. Configure the Architectural Drawing Scale

Architectural plans typically use scales such as 1/4" = 1'-0" (1:48) or 1/8" = 1'-0" (1:96).

  1. In the Document Properties window, stay on the Display tab and locate the Scale section.
  2. Set the Scale x value to match your drawing ratio. For example:
    • Full Scale (1:1): Set Scale x to 1.0.
    • 1/4" = 1'-0" (1:48): Set Scale x to 0.020833 (calculated as 1 divided by 48).
    • 1/8" = 1'-0" (1:96): Set Scale x to 0.010417 (calculated as 1 divided by 96).

3. Create a Fractional Inch Grid

Because the canvas rulers display decimal ticks (such as 0.25, 0.5, 0.75), you must set up a custom grid to align and snap objects to traditional fractional increments.

  1. In the Document Properties window, switch to the Grids tab.
  2. Select Rectangular grid from the dropdown and click New.
  3. Set Grid units to in.
  4. In the Spacing X and Spacing Y fields, enter your desired fraction in decimal format:
    • 1/2 inch: 0.5
    • 1/4 inch: 0.25
    • 1/8 inch: 0.125
    • 1/16 inch: 0.0625
    • 1/32 inch: 0.03125
  5. Set Major grid line every to an interval that makes visual sense (for example, enter 8 if your grid spacing is set to 0.125 so that major lines appear at every full inch).

4. Enable Fractional Grid Snapping

  1. Ensure snapping is globally toggled on using the snap control bar on the right side of the window (or press %).
  2. Expand the snap options and enable Snap to Grid.
  3. When drawing or moving paths, your cursor will now lock directly to fractional increments of an inch.

5. Display Fractional Measurements with the Measure Tool

To inspect distances across your drawing:

  1. Select the Measure Tool from the left toolbar (or press M).
  2. In the top tool control bar, set the measurement units to in.
  3. Click and drag across any two points on your canvas to view real-time imperial dimensions aligned to your fractional scale.
