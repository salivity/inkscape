Prepare Spot UV Business Cards in Inkscape

This guide explains how to set up and export print-ready spot-UV varnish overlays for business cards using the free vector editor Inkscape. Preparing a spot-UV job requires creating two separate, perfectly aligned files: a standard full-color artwork file for the base print, and a specialized black-and-white mask file that indicates precisely where the clear varnish will be applied. By organizing your document with dedicated layers, converting overlay elements into 100% black solid vector paths, and exporting aligned PDFs, you ensure a flawless finish without production delays or misregistration.

1. Set Up the Document with Bleed

Open Inkscape and configure your canvas to the final dimensions of your business card, including standard bleed margins:

  • Go to File > Document Properties (Ctrl + Shift + D).
  • Under Custom size, change the units to inches or millimeters (e.g., 3.5 in x 2.0 in).
  • Add standard bleed margins if your printer requires them (typically 0.125 inches / 3.175 mm on all sides).

2. Structure Your Layers

Keeping your base artwork separate from the varnish overlay is essential for clean file preparation:

  1. Open the Layers and Objects panel (Ctrl + Shift + L).
  2. Rename the default layer to Artwork.
  3. Create a new layer on top and name it Spot UV.

Design your full-color business card entirely within the Artwork layer.

3. Duplicate Elements for the UV Mask

Select the specific graphics, typography, or background patterns that will receive the varnish treatment:

  1. Select the elements on the Artwork layer.
  2. Copy them (Ctrl + C).
  3. Select the Spot UV layer.
  4. Go to Edit > Paste in Place (Ctrl + Alt + V) to ensure the elements align identically with the underlying artwork.

4. Convert Elements into Solid Vectors

Spot-UV masks rely on crisp, binary vector information:

  • Convert text to paths: Select any text and choose Path > Object to Path (Shift + Ctrl + C).
  • Expand strokes: If your overlay includes outlines or strokes, convert them to fills by selecting Path > Stroke to Path (Ctrl + Alt + C).
  • Flatten groups: Ungroup compound elements (Ctrl + Shift + G) and combine overlapping shapes using Path > Union (Ctrl + +).

5. Color the Mask Elements 100% Black

Commercial printers read spot-UV masks as binary data, where 100% solid black denotes the application of varnish, and white/empty space denotes no varnish. Gradients, opacities, and feathering cannot be used.

  1. Open the Fill and Stroke panel (Ctrl + Shift + F).
  2. Select all items on the Spot UV layer.
  3. In the Fill tab, choose the CMYK color mode.
  4. Set the sliders to:
    • C: 0%
    • M: 0%
    • Y: 0%
    • K: 100%
  5. Ensure the opacity slider is set to 100% and no blur is applied.

6. Account for Production Tolerances

Varnish application processes can shift slightly during printing:

  • Avoid thin lines narrower than 0.5 pt (0.18 mm).
  • Avoid small body text (below 7 pt) under spot UV, as the varnish can spread and make the text illegible.
  • If overlaying varnish directly over printed elements, keep the mask shape identical in size to the underlying graphic—do not artificially scale it up unless aiming for a blind UV effect (varnish over unprinted card stock).

7. Export the Two PDF Files

Export two separate PDF documents with identical dimensions and page settings.

File 1: CMYK Artwork

  1. In the Layers panel, turn on the visibility of the Artwork layer (eye icon open).
  2. Turn off the visibility of the Spot UV layer (eye icon closed).
  3. Go to File > Save As..., choose Portable Document Format (*.pdf), and save the file as Card_Front_CMYK.pdf.

File 2: Spot UV Mask

  1. Turn off the visibility of the Artwork layer.
  2. Turn on the visibility of the Spot UV layer.
  3. Ensure the background behind the black elements is completely transparent or white.
  4. Go to File > Save As..., select Portable Document Format (*.pdf), and save the file as Card_Front_SpotUV.pdf.

Submit both files together to your print service provider.
