Adjust Start Offset of Text on Path in Inkscape

This guide explains how to precisely position text along a curve in Inkscape by editing the startOffset attribute inside the XML Editor. While Inkscape allows you to move text using spaces or kerning tools, adjusting the XML attribute directly provides exact, non-destructive control over where your text begins along a path.

1. Select the Text on Path

Open your document and select the text that has already been linked to a path using the Text > Put on Path command.

2. Open the XML Editor

Open the XML Editor using one of the following methods:

  • Go to the top menu and select Edit > XML Editor.
  • Press the keyboard shortcut: Ctrl + Shift + X (Windows/Linux) or Cmd + Shift + X (macOS).

3. Locate the textPath Element

  1. In the XML tree panel on the left side of the XML Editor, locate the currently selected <svg:text> element.
  2. Click the arrow or plus icon next to <svg:text> to expand its child nodes.
  3. Select the <svg:textPath> element beneath it.

4. Adjust or Add the startOffset Attribute

Once <svg:textPath> is selected:

  1. Check the attributes list in the right-hand panel of the XML Editor for an attribute named startOffset.
  2. If it exists: Click on startOffset. In the lower-right text field, change its value.
  3. If it does not exist: Click the empty input field above the attribute list, type startOffset, and enter your desired value in the larger box below it.

5. Apply the Value

Click the Set button (or press Ctrl + Enter) to apply the change to the canvas.

Supported Value Formats

  • Percentages: Using percentages is the easiest way to position text relative to the path's total length. For example, setting the value to 50% places the start of the text exactly halfway along the path.
  • Absolute Measurements: You can enter explicit measurements such as 20px, 10mm, or 1in to shift the text by a fixed distance from the starting node of the path.
