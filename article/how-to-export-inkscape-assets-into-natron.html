How to Export Inkscape Assets into Natron

Integrating 2D vector artwork into visual effects pipelines requires bridging vector design software with raster-based compositing tools. This guide explains how to properly prepare, format, and export vector graphics created in Inkscape for use inside Natron, the open-source node-based compositor. By following these steps, you will preserve alpha transparency, maintain visual fidelity, and ensure your assets integrate seamlessly into Natron's node graph.

1. Prepare Vector Elements in Inkscape

Natron handles assets on a layer-by-layer or element-by-element basis within its node tree. Before exporting, organize your artwork according to how it will be animated or composited.

  • Separate Animated Components: If different elements of your vector graphic need independent movement, rotoscoping, or color grading in Natron, place them on separate layers or group them individually.
  • Fit Canvas to Selection: Go to File > Document Properties and under the Page tab, expand Custom size and click Resize to content if you want the exported asset cropped tightly. Alternatively, keep a standardized project frame (such as 1920x1080 or 3840x2160) to maintain relative spatial alignment.
  • Remove Backgrounds: Ensure your document background has zero opacity so that an alpha channel is generated.

2. Export Assets as High-Resolution PNGs

Natron does not parse dynamic vector shapes like SVG files directly inside its node graph; it relies on raster image data. To prevent pixelation when scaling or transforming in 3D space, export your vectors at high resolutions.

  1. Open the Export panel using File > Export or by pressing Shift + Ctrl + E.
  2. Select your target scope:
    • Document / Page: Exports the full layout relative to the frame.
    • Selection: Exports individual highlighted objects.
    • Batch Export: Use this tab if you have organized parts into separate layers or objects and wish to output multiple elements at once.
  3. Choose PNG as the output format. PNG fully supports 8-bit per channel RGBA transparency.
  4. Set the DPI (Dots Per Inch) or pixel dimensions:
    • For standard 1:1 framing, match your Natron project resolution (e.g., 1920x1080 at 96 DPI).
    • If the asset will be scaled up, camera-projected, or moved close to the camera in Natron, increase the DPI to 192 or 300 to generate a 2K or 4K asset to preserve sharp edges.
  5. Click Export to render the files to your project directory.

3. Import Assets into Natron

Once your rasterized vector assets are rendered, load them into Natron's node graph:

  1. Press R in the Node Graph viewer or right-click and select Image > Read.
  2. Browse to the directory containing your exported PNG files and select the asset.
  3. Connect the Read node's output to the Viewer by pressing 1 to verify the image loads correctly.

4. Configure Color Space and Alpha Settings

Proper composite blending depends on Natron correctly interpreting the alpha channel and color profile exported from Inkscape.

  • Premultiplication: In the properties panel of the Read node, check the Premult settings. Inkscape exports unassociated (straight) alpha by default. Set the Read node's alpha handling to match the file, or add a Premult node immediately after the Read node to prepare the asset for standard blending operations.
  • Color Space: Natron operates internally in a 32-bit float linear color space. By default, Natron converts incoming PNG files from standard sRGB to Linear. Confirm that the Color Space drop-down in the Read node is set to sRGB to ensure colors match what was designed in Inkscape.

5. Composite and Transform

With the asset loaded and normalized:

  • Attach a Transform node (T) to scale, rotate, or translate the vector asset without modifying the original graphic file.
  • Use a Merge node (M) to combine the asset over your background footage or 3D renders using standard composite modes such as over, multiply, or screen.
  • If you need to make design modifications, update the artwork in Inkscape and overwrite the exported PNG; Natron will automatically reload the updated asset on the next frame refresh.
