Draw Top-Down RPG Dungeon Doors in Inkscape

This guide explains how to design a complete top-down RPG dungeon door sprite set in Inkscape featuring closed, locked, and open states. You will learn how to configure a pixel-aligned grid, construct a modular stone frame, style the door panel using basic shapes and shading, create visual indicators for the locked variation, and render the threshold geometry for the open state to export as a clean game-ready sprite asset.

Canvas Setup and Grid Configuration

  1. Open Inkscape and access File > Document Properties.
  2. Under the Page tab, set the Display units and Page size units to px. Set the width and height to your target tile size (for example, 64 x 64 px).
  3. Switch to the Grids tab, choose Rectangular grid, and click New.
  4. Set Spacing X and Spacing Y to 1 px (or 2 px for low-resolution pixel-art styles).
  5. Enable snapping by toggling the Enable snapping icon in the top right. Turn on Snap to paths, Snap to cusp nodes, and Snap to grid.

Building the Static Door Frame

The frame remains identical across all three states to ensure seamless animation transitions inside your game engine.

  1. Select the Rectangle tool (R).
  2. Draw two vertical pillars along the left and right edges of the canvas (e.g., 8 px wide, 64 px tall). Fill them with a mid-tone slate gray (#555568).
  3. Draw a horizontal lintel across the top between the two pillars (e.g., 48 px wide, 12 px tall) using a slightly lighter gray (#6b6b7f) to indicate the top surface facing the light source.
  4. Add top-down depth by drawing a 2 px dark rectangle (#252530) beneath the top lintel to serve as a cast shadow.
  5. Group the frame elements by selecting them and pressing Ctrl + G. Place this group in a dedicated layer named Frame and lock it.

Creating the Closed Door State

  1. Create a new layer named Door_Closed beneath the Frame layer so the frame naturally overlaps the door edges.
  2. Select the Rectangle tool and draw a rectangle that fills the opening between the two side pillars, extending from just below the lintel shadow to the bottom of the canvas.
  3. Apply a dark brown base fill (#4a2e18) to represent aged wood.
  4. Draw thin vertical lines or 1 px wide rectangles across the door using a darker brown (#2e1b0d) to separate individual planks.
  5. Add horizontal iron reinforcement bands: draw two horizontal rectangles across the width of the wooden door—one near the top, one near the bottom. Fill them with a dull metallic gray (#474747).
  6. Place a small circular brass handle on the right side using the Circle tool (E), filled with dull yellow (#b88a3b) and a darker outline.

Designing the Locked State

The locked state should clearly communicate obstruction without altering the core structure of the closed door.

  1. Duplicate the Door_Closed layer and rename the duplicate to Door_Locked.
  2. Hide the Door_Closed layer.
  3. Add a heavy padlock:
    • Select the Rectangle tool, set the corner rounding handles to create a rounded body (8 x 8 px), and fill it with brass or silver (#c29a45).
    • Select the Circle tool, draw a circle for the shackle, set the fill to none, and set a thick stroke (#3a3a3a).
    • Use Path > Stroke to Path, then slice the lower half using a cutting shape with Path > Difference to leave an inverted U-shape.
    • Position the shackle on top of the padlock body and align the padlock over the door seam or handle.
  4. Optional - Add crossed chains:
    • Draw two overlapping diagonal bars across the wooden door.
    • Apply a repeating pattern of light and dark alternating strokes to create the illusion of chain links, finishing under the edges of the stone frame.

Constructing the Open State

In a top-down perspective, an open door exposes the floor threshold and the depth of the passage beyond.

  1. Create a new layer named Door_Open. Hide the closed and locked layers.
  2. Draw the floor threshold:
    • Fill the open area between the pillars with the dungeon floor texture or a stone tile color (#3b3b47).
    • Add horizontal mortar lines or flagstone details to match your dungeon ground tiles.
  3. Add the open door leaf:
    • For a swing-in door: Draw a narrow vertical rectangle (4 px to 6 px wide) tucked tight against the inner edge of one pillar. Add a slight angled perspective to indicate the door has swung into the room.
    • For an open archway/raised portcullis: Leave the passage completely open, with the door recessed vertically out of view.
  4. Cast environmental shadows:
    • Draw a semi-transparent black rectangle (#000000, 40% Opacity) directly beneath the top lintel spanning 8 px downward to simulate the ceiling shadow over the open doorway.
    • Add a small vertical shadow cast by the inner edges of the side pillars onto the threshold floor.

Organizing and Exporting the Sprites

  1. If exporting as single tiles, toggle the visibility of each door layer (Door_Closed, Door_Locked, Door_Open) one at a time with the Frame layer visible.
  2. Go to File > Export.
  3. Set the export area to Page to ensure dimensions remain strictly uniform.
  4. Set the resolution to your desired scaling factor (e.g., standard 96 DPI for 1:1 pixel assets, or higher for modern displays).
  5. If creating a horizontal spritesheet, open Document Properties, expand your canvas width by 3x (e.g., 192 px for a 64 px tile), and position the Closed, Locked, and Open door groups side by side on exact pixel increments before exporting.
