Recover Vector Shapes from Inkscape Autosave Files

When Inkscape crashes or terminates unexpectedly, unsaved work can often be retrieved using the software's built-in autosave and emergency document features. This guide explains how to locate Inkscape’s autosave cache directory, identify the most recent emergency backup files, open and repair partially corrupted Scalable Vector Graphics (SVG) data, and safely extract your vector paths into a new, stable project.

1. Locate the Inkscape Autosave Directory

Inkscape automatically saves backup files at regular intervals if the autosave feature was enabled prior to the crash. The location of these files depends on your operating system:

  • Windows: Press Win + R, paste %UserProfile%\AppData\Local\Inkscape\autosave (or %UserProfile%), and press Enter. If not there, check your system's temporary directory by typing %temp% in the Run dialog.
  • macOS: Open Finder, press Cmd + Shift + G, and navigate to ~/Library/Application Support/org.inkscape.Inkscape/ or check ~/.cache/inkscape/.
  • Linux: Open your file manager or terminal and check ~/.cache/inkscape/ or ~/.config/inkscape/.

If you are unsure where your autosaves are stored, open Inkscape, navigate to Edit > Preferences > Input/Output > Autosave, and check the Autosave directory path.

2. Identify the Backup File

Inside the autosave or temporary directory, look for files containing your original document name followed by a timestamp and the .svg extension (for example, drawing.2023_10_12_14_30_05.0.svg). Sort the folder by "Date Modified" to find the most recent file generated right before or during the crash. Inkscape also creates emergency files named inkscape-emergency.svg in your primary user directory if a sudden crash routine was triggered.

3. Open and Inspect the Vector Elements

Double-click the identified SVG file or launch Inkscape and go to File > Open to inspect the file.

  • If the file opens successfully: Check the canvas for your missing vector shapes. Open the Layers and Objects panel (Layer > Layers and Objects...) to ensure all groups and paths are present.
  • Copy the clean vectors: Select the recovered shapes, copy them (Ctrl + C or Cmd + C), open a fresh, clean document (File > New), and paste them (Ctrl + V or Cmd + V). Save this new document immediately under a distinct name to avoid referencing corrupted metadata from the crashed session.

4. Recover Shapes from Corrupted Autosaves

If Inkscape refuses to open the autosave file because the sudden shutdown interrupted the write process, the XML structure may be incomplete.

  1. Right-click the backup .svg file and open it with a plain text editor such as Notepad, TextEdit, or VS Code.
  2. Scroll to the very bottom of the document.
  3. Ensure the file ends with the closing SVG tag: </svg>.
  4. If the file cuts off abruptly inside a <path> or <g> tag, delete the broken, incomplete tag line and manually type </svg> at the end of the document.
  5. Save the text file and try reopening it in Inkscape. Even if the very last drawn path is lost, this will restore all preceding vector shapes.
