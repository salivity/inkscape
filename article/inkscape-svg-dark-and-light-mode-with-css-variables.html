Inkscape SVG Dark and Light Mode with CSS Variables

This guide explains how to configure an Inkscape SVG to automatically adapt between light and dark modes using CSS custom properties (variables) and the prefers-color-scheme media query. By modifying Inkscape's default inline styling into a clean, variable-driven CSS structure, you can maintain a single vector file that shifts seamlessly across system appearance themes or custom class toggles on the web.

1. Prepare the Artwork in Inkscape

By default, Inkscape exports geometry with hardcoded inline presentation attributes (such as style="fill:#000000;..." or fill="#000000"). To make these elements responsive to CSS, group or label them logically:

  1. Open your artwork in Inkscape.
  2. Select an element or group that should change color based on the theme.
  3. Open the Object Properties panel (Shift + Ctrl + O).
  4. Assign a descriptive Class name to the target element (for example, theme-fill or theme-stroke).
  5. Save the file as an Optimized SVG or standard Inkscape SVG.

2. Open and Clean the SVG Markup

Open the exported .svg file in a text or code editor. Inkscape often embeds inline presentation styles directly onto element tags, which have higher specificity than external CSS variables.

Locate the target elements and remove their hardcoded color properties:

  • Before: 
    <path class="theme-fill" style="fill:#1a1a1a;stroke:none;" d="..." />
  • After: 
    <path class="theme-fill" d="..." />

Ensure any hardcoded fill or stroke values that must be dynamic are removed from the inline style attribute.

3. Inject CSS Variables and Media Queries

Inside the <svg> container, directly beneath the opening <svg ...> tag, insert an embedded <style> block. Define your default light theme variables alongside a @media (prefers-color-scheme: dark) query to redefine those variables when the user switches to dark mode.

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <style>
    :root {
      --bg-color: #ffffff;
      --primary-color: #1f2937;
      --accent-color: #3b82f6;
    }

    @media (prefers-color-scheme: dark) {
      :root {
        --bg-color: #111827;
        --primary-color: #f9fafb;
        --accent-color: #60a5fa;
      }
    }

    .theme-bg {
      fill: var(--bg-color);
    }

    .theme-fill {
      fill: var(--primary-color);
    }

    .theme-stroke {
      stroke: var(--accent-color);
    }
  </style>

  <!-- Vector Elements -->
  <rect class="theme-bg" width="100" height="100" />
  <circle class="theme-stroke" cx="50" cy="50" r="40" fill="none" stroke-width="4" />
  <path class="theme-fill" d="M30 30 h40 v40 h-40 Z" />
</svg>

4. Supporting Manual Theme Switching

If your website toggles themes using a root class (such as .dark on the <html> or <body> element) rather than system-level preferences:

  1. Inline SVG Embedding: Embed the <svg> directly into your HTML document rather than using an <img> tag. This allows the SVG to inherit CSS variables defined in your global website stylesheet.
  2. Global CSS Mapping: 
    :root {
  --primary-color: #1f2937;
}

html.dark {
  --primary-color: #f9fafb;
}

/* Target the SVG class directly */
.theme-fill {
  fill: var(--primary-color);
}

5. Deployment Considerations

  • Avoid <img> tags for external CSS: Browsers isolate SVGs loaded via <img src="graphic.svg"> into a separate browsing context. External webpage stylesheets cannot access the internals of an <img>. For isolated SVGs, the @media (prefers-color-scheme: dark) block must live inside the SVG itself.
  • Direct Embedding: To allow external JavaScript and CSS classes to dynamically alter your Inkscape SVG variables, embed the SVG using inline <svg> tags or an <object type="image/svg+xml" data="..."> element.
