How to Convert Stroke to Path in Inkscape

Converting an outline or line stroke into an independent, editable vector shape is a fundamental skill in vector illustration. In Inkscape, the Stroke to Path tool allows you to transform standard line widths, dashed borders, or custom stroke styles into filled vector objects. This guide provides a straightforward, step-by-step walkthrough for using the Stroke to Path feature, explaining how it works and when you should use it.

Step 1: Create and Style Your Stroked Path

  1. Select the Pen (Bezier) Tool (B) or the Pencil Tool (P) to draw a line, or create any basic shape using the shape tools.
  2. Open the Fill and Stroke panel by pressing Ctrl + Shift + F (or Cmd + Shift + F on macOS).
  3. Go to the Stroke paint tab and ensure a color is applied.
  4. Switch to the Stroke style tab to adjust the line width, join styles (round, bevel, or miter), cap styles, or dash patterns to your desired appearance.

Step 2: Apply the Stroke to Path Command

  1. Activate the Select Tool (S) and click on the stroked object you want to convert.
  2. Navigate to the top menu and select Path > Stroke to Path.
    • Alternatively, use the keyboard shortcut: Ctrl + Alt + C on Windows/Linux or Cmd + Option + C on macOS.

Step 3: Verify and Edit the New Shape

Once the conversion is complete, Inkscape automatically alters the object's properties:

  • Fill and Stroke Adjustment: The original stroke is removed, and the interior of the outline is converted into a Fill.
  • Node Placement: Switch to the Node Tool (N) to view the new structure. You will see nodes outlining both the inner and outer boundaries of where the stroke previously existed.
  • Resizing and Styling: You can now scale the shape freely without worrying about stroke width distortion, add a new border to this shape, or apply vector operations (such as Union, Difference, or Intersection) with other objects on your canvas.

Common Use Cases for Stroke to Path

  • Scalable Icons and Logos: Ensures line weights remain proportional regardless of how an asset is scaled across different platforms.
  • Boolean Operations: Allows lines to be combined with, or cut out from, other solid shapes using the Path menu tools.
  • Vinyl Cutting, CNC, and Laser Cutting: Prepares vector paths for fabrication machines that require closed vector outlines rather than open stroked lines.
