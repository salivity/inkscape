Set CNC Cutting Order by Layers in Inkscape

Controlling the cut sequence on a CNC router prevents workpieces from coming loose before all internal features are machined. This guide explains how to configure a deterministic cutting order in Inkscape using layer organization and the built-in Gcodetools extension, ensuring your machine processes drilling, internal cutouts, and exterior profiles in the correct order.

Why Layer-Based Sequencing Matters

When cutting parts on a CNC router, operations must follow a strict hierarchy to maintain workpiece rigidity:

  1. Drilling and engraving: Detail operations performed while the stock has maximum stability.
  2. Inner cutouts and pockets: Inside features cut before the part is separated from the stock material.
  3. Outer perimeter (profile cut): The final operation that cuts the finished part free from the sheet.

By assigning each operation to a dedicated layer in Inkscape, you can precisely control the sequence in which the G-code generator translates vector paths into machine coordinates.

Step 1: Organize Your Vector Geometry into Layers

Inkscape's internal structure evaluates elements based on the Document Object Model (DOM) tree. By default, paths are processed from the bottom of the stack upward.

  1. Open the Layers and Objects dock by pressing Ctrl + Shift + L (or Cmd + Shift + L on macOS).
  2. Create three or more distinct layers according to your job requirements. For example:
    • 01_Drill
    • 02_Inside_Pockets
    • 03_Outside_Cut
  3. Drag the layers in the panel so the first operation is at the bottom and the final operation is at the top, or vice versa, depending on your preferred workflow. By convention, arranging layers from bottom to top corresponds to the ascending XML order that G-code parsers read sequentially.

Step 2: Move Paths to the Correct Layers

  1. Select the vectors meant for the initial operation.
  2. Right-click the selection and choose Move to Layer..., then select the appropriate layer (e.g., 01_Drill).
  3. Repeat this process for all interior cutouts, placing them in your secondary layer.
  4. Move the final boundary profile paths to your exterior layer.

Step 3: Set Path Direction and Ordering Within Layers

Within an individual layer, Inkscape still processes objects from the lowest sub-item to the highest sub-item:

  1. Expand each layer in the Layers and Objects dock to inspect the path list.
  2. Drag individual paths up or down within the layer to define the exact sequence of cuts within that specific operation.
  3. Verify that all paths are closed vectors (if performing profile or pocket cuts) by selecting them and using Path > Combine (Ctrl + K) where necessary.

Step 4: Generate G-Code Using Gcodetools

Inkscape includes the Gcodetools extension for toolpath generation:

  1. Navigate to Extensions > Gcodetools > Orientation points.... Set your surface Z-level and depth, then click Apply.
  2. Navigate to Extensions > Gcodetools > Tools library..., select the tool type (e.g., cylinder cutter), and click Apply to drop the green tool definition block onto your canvas. Modify cutting parameters (feed rate, depth step) using the Text tool directly on the canvas.
  3. Open Extensions > Gcodetools > Path to Gcode....
  4. In the Preferences tab, define the output directory and filename.
  5. In the Path to Gcode tab, configure the cutting order:
    • If processing all layers at once, ensure the paths are ordered sequentially in the object hierarchy.
    • Alternatively, hide all layers except the one you wish to cut first, generate the G-code for that operation, and repeat for subsequent layers to produce individual, modular G-code files for each stage of production.
  6. Click Apply to generate the toolpaths.

Step 5: Verify the Toolpath Sequence

Before sending the file to your CNC controller, always verify the output:

  1. Open the exported .ngc or .gcode file in a G-code visualizer (such as CAMotics, ncviewer, or your machine controller software like LinuxCNC, Mach4, or Candle).
  2. Run the simulation to confirm that the tool executes the lowest layer features first, processes interior cutouts second, and finishes with the exterior profile.
