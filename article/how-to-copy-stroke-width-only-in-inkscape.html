How to Copy Stroke Width Only in Inkscape

While Inkscape's standard "Paste Style" command applies all fill and stroke properties simultaneously, transferring only the stroke width requires a more targeted approach to avoid overwriting your shape's original colors. Inkscape does not include a dedicated shortcut to paste isolated style attributes, but you can achieve this quickly using the Fill and Stroke panel or batch selection.

Method 1: Copy and Paste via the Stroke Style Tab

The most reliable way to transfer stroke width while keeping existing colors intact is through the Fill and Stroke dialog:

  1. Select the original object that has the stroke width you want to copy.
  2. Open the Fill and Stroke panel by pressing Ctrl + Shift + F (or Cmd + Shift + F on macOS), or by going to Object > Fill and Stroke.
  3. Click on the Stroke style tab.
  4. Highlight the numerical value inside the Width field and copy it (Ctrl + C or Cmd + C). Take note of the unit of measurement (such as px, mm, or pt).
  5. Select the target shape whose stroke width you want to update.
  6. Return to the Width field in the Stroke style tab, paste the value (Ctrl + V or Cmd + V), make sure the measurement unit matches, and press Enter.

The target shape's stroke thickness will update instantly without altering its fill or stroke color.

Method 2: Batch Updating Multiple Shapes

If you need to apply the same stroke width to multiple objects without altering their distinct colors:

  1. Select all the target shapes by holding down Shift and clicking on each shape.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Switch to the Stroke style tab.
  4. Enter the desired thickness in the Width box and press Enter.

Inkscape applies the new stroke width uniformly across every selected object while leaving individual fill paints and stroke colors completely untouched.

Why Not Use "Paste Style"?

Using Edit > Paste Style (Ctrl + Shift + V) copies the entire CSS style string of the copied object. This overwrites the target object’s fill paint, stroke paint, stroke style, and opacity all at once. Until Inkscape introduces granular paste options, manually assigning the numerical width in the Stroke style tab remains the fastest method to preserve color data.
