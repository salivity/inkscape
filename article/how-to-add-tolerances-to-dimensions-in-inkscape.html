How to Add Tolerances to Dimensions in Inkscape

While Inkscape is a general vector graphics program rather than a dedicated parametric CAD package, you can still produce precise technical drawings by applying mechanical tolerance annotations directly to dimension lines. This guide demonstrates how to generate standard dimension lines and configure bilateral, unilateral, stacked, or limit tolerances using Inkscape's path extensions and typography controls.

1. Generate the Base Dimension Line

Inkscape provides an automated tool for generating dimension lines rather than drawing them manually.

  1. Select the path or object edge you wish to dimension.
  2. Navigate to Extensions > Visualize Path > Dimensions.
  3. Set your parameters:
    • Offset: Distance between the object edge and the dimension line.
    • Unit: Choose your measurement standard (e.g., mm, in).
    • Text format: Configure your significant digits and format prefix/suffix.
  4. Click Apply to generate the dimension line, arrows, and default measurement text.

2. Add Symmetrical Tolerances (±)

For standard bilateral tolerances where the upper and lower limits are identical (e.g., 50 ±0.05):

  1. Double-click the text object created by the Dimension tool to enter text edit mode.
  2. Place the cursor at the end of the dimension value.
  3. Insert the plus-minus symbol (±):
    • Windows: Press Alt + 0177 on the numeric keypad.
    • Mac: Press Option + Shift + =.
    • Linux / Universal: Press Ctrl + Shift + U, type 00b1, and press Enter.
  4. Type your tolerance value (e.g., ±0.05).
  5. (Optional) Highlight the tolerance text and reduce the font size by 20–30% relative to the nominal dimension size to adhere to standard drafting conventions (such as ASME Y14.5).

3. Create Stacked Tolerances (Asymmetric / Unilateral)

When upper and lower variations differ (e.g., +0.05 / -0.02), mechanical standards require stacked text.

Method A: Multi-Line Text with Adjusted Line Height

  1. Double-click the dimension text and position your cursor where the tolerance begins.
  2. Press Enter to drop to a new line and type the upper and lower tolerances (e.g., line 1: +0.05, line 2: -0.02).
  3. Highlight both tolerance values and reduce their font size to roughly 60% of the nominal size.
  4. Open the Text and Font panel (Ctrl + Shift + T).
  5. Reduce the Line spacing value (e.g., to 0.8 or 0.9) until the two numbers stack neatly without excessive gap.
  6. Use the Baseline shift setting in the top tool control bar to center the stacked block vertically against the nominal dimension number.

Method B: Separate Text Blocks (Recommended for Complex Callouts)

  1. Keep the nominal dimension (e.g., 25.00) as one text object.
  2. Select the Text Tool (T) and click to create a separate text block for the upper limit (+0.05).
  3. Press Enter and type the lower limit (-0.02).
  4. Set the font size smaller and reduce the line spacing.
  5. Open the Align and Distribute panel (Ctrl + Shift + A).
  6. Align the stacked tolerance block vertically centered and horizontally adjacent to the nominal dimension.

4. Create Limit Dimensions

Limit tolerancing displays the maximum and minimum allowable sizes directly (e.g., high limit above low limit) rather than using a nominal value with an offset.

  1. Double-click the dimension text generated by the extension.
  2. Replace the single number with the maximum limit on the top line (e.g., 50.05).
  3. Press Enter and type the minimum limit on the bottom line (e.g., 49.95).
  4. Ensure both numbers share the same font size, align them to the center or left, and adjust the line spacing so the text remains readable between the witness lines.

5. Group Dimension Elements

Because the Dimensioning extension creates separate vector paths for arrows, extension lines, and text, changes to the text can cause visual misalignments.

  1. Click and drag to select the dimension line, arrows, and modified tolerance text.
  2. Press Ctrl + G (or go to Object > Group).
  3. Lock or move the group as a single drafting entity to prevent unintentional displacement during the rest of your layout process.
