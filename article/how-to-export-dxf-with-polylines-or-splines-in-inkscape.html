How to Export DXF with Polylines or Splines in Inkscape

Exporting vector designs to DXF in Inkscape often requires choosing between polylines and splines depending on the requirements of your CNC controller, laser cutter, or CAD software. Inkscape handles this choice primarily through its DXF export dialogs and file format versions. This guide explains how to select the right DXF output format, toggle spline and polyline conversion settings, and ensure your paths translate correctly for manufacturing or drafting.

Step 1: Prepare Your Vector Paths

Before exporting, ensure all shapes and text objects are converted to native paths:

  1. Select all objects (Ctrl + A).
  2. Go to Path > Object to Path (Shift + Ctrl + C).
  3. If you have active strokes that need cutting as outlines rather than single-line center paths, select Path > Stroke to Path.

Step 2: Choose the DXF Export Filter

Inkscape provides two different DXF export filters under File > Save As... (or Save a Copy...):

  • AutoCAD DXF R14 (*.dxf): Supports modern CAD entities, including native SPLINE entities and modern LWPOLYLINE (lightweight polyline) entities. Choose this if you need smooth curves or lightweight polylines.
  • AutoCAD DXF R12 (*.dxf): An older format that does not support true spline curves. It automatically approximates all curved Bézier paths into segmented polylines (lines). Choose this for older CNC, vinyl cutting, or plasma software.

Step 3: Configure Polyline vs. Spline Settings

Option A: Exporting via AutoCAD DXF R14

When you select AutoCAD DXF R14 (*.dxf) and click Save, an export options window appears:

  1. For True Splines:
    • Uncheck the Use LWPOLYLINE type of line option.
    • Inkscape will export curves as cubic SPLINE entities. This produces smooth, continuous curves ideal for modern CAD platforms like Fusion 360, SolidWorks, or AutoCAD.
  2. For Polylines:
    • Check the Use LWPOLYLINE type of line option.
    • Inkscape will convert paths into LWPOLYLINE entities instead of splines.

Option B: Exporting via AutoCAD DXF R12

When using AutoCAD DXF R12 (*.dxf):

  1. The exporter cannot write splines; it will automatically convert every curve into a series of short straight-line polyline segments.
  2. In the export pop-up window, adjust the curve approximation settings if prompted, or use the pre-processing method below for tighter control over vertex density.

Manual Pre-Conversion: Flattening Beziers to Polylines

If your CAM software requires polylines with strict tolerance limits, converting curves directly on the canvas prior to export provides the most control:

  1. Select the paths you want to convert.
  2. Go to Extensions > Modify Path > Flatten Beziers...
  3. Set the Flatness parameter:
    • A lower number (e.g., 0.1 to 0.5) creates more line segments for a smoother curve.
    • A higher number creates fewer segments, resulting in a coarser polyline.
  4. Click Apply.
  5. Save the file using either DXF R12 or DXF R14.

Which Option Should You Choose?

  • Choose Splines (R14, LWPOLYLINE unchecked) when importing into 3D modeling software, parametric CAD, or CAM tools with built-in curve-smoothing algorithms. This keeps file sizes small and geometries editable.
  • Choose Polylines (R14 with LWPOLYLINE checked, or R12) when working with legacy CNC machine controllers, waterjet cutters, plasma tables, or vinyl plotters whose firmware fails to parse spline coordinates.
