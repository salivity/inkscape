How to Import CMYK EPS into Inkscape

Importing CMYK-defined vector EPS files into Inkscape requires specific preparation because Inkscape natively operates in an RGB color space and relies on third-party interpreters to parse PostScript data. By installing Ghostscript to handle EPS rendering and configuring Inkscape’s color management system with appropriate CMYK ICC profiles, you can import vector EPS artwork, preserve editable paths, and manage CMYK color data accurately.

1. Install Ghostscript

Inkscape does not have a native EPS decoder. It requires Ghostscript to translate Encapsulated PostScript (EPS) code into vector objects.

  1. Download and install the 64-bit or 32-bit version of Ghostscript matching your Inkscape installation architecture.
  2. Add Ghostscript's bin and lib directories to your operating system's system PATH environment variable (common on Windows).
  3. Restart Inkscape to allow the software to detect the Ghostscript installation.

2. Configure Inkscape Color Management

Because Inkscape renders documents internally using the sRGB color space, you must configure color management to prevent CMYK color values from distorting upon import.

  1. Obtain a standard CMYK ICC profile (such as Coated FOGRA39 or US Web Coated SWOP v2).
  2. Install the profile to your operating system's color directory.
  3. In Inkscape, navigate to Edit > Preferences > Color management.
  4. Set the Display profile to your monitor's profile.
  5. Set the Device profile to your installed CMYK ICC profile.
  6. Enable Retrieve profile from display or select the CMYK profile under the soft-proofing options.

3. Direct Import Method

Once Ghostscript is linked:

  1. Open Inkscape.
  2. Go to File > Open or File > Import.
  3. Set the file format filter to Encapsulated PostScript (*.eps).
  4. Select your CMYK EPS file and click Open.
  5. When the PostScript/PDF import settings dialog appears, choose Internal import.
  6. Ensure Precision of paths is set appropriately and click OK.

The EPS vectors will import onto the canvas as grouped editable paths.

4. Alternative: Convert EPS to PDF Prior to Import

Direct EPS import via Ghostscript can occasionally convert CMYK definitions into standard sRGB values automatically. To maintain maximum color precision, convert the EPS to a PDF before bringing it into Inkscape:

  1. Use Ghostscript via command line to convert the EPS to PDF while retaining CMYK definitions: gs -dSAFER -dBATCH -dNOPAUSE -sDEVICE=pdfwrite -sColorConversionStrategy=LeaveColorUnchanged -dAutoFilterColorImages=false -sOutputFile=output.pdf input.eps
  2. In Inkscape, go to File > Open and select the newly generated PDF.
  3. In the PDF Import Settings, select Internal import to retain vector structures.

5. Verifying CMYK Values in Inkscape

  1. Select an imported vector object.
  2. Open the Fill and Stroke panel (Shift + Ctrl + F).
  3. Switch the color selector tab to CMS (Color Management System).
  4. Select the configured CMYK ICC profile to view and manipulate the specific Cyan, Magenta, Yellow, and Key (Black) percentages directly on the vector paths.
