Clean Up Unused SVG Definitions in Inkscape

When creating or modifying vector graphics in Inkscape, elements such as unused gradients, patterns, markers, and clipped paths linger inside the file's <defs> tag, unnecessarily increasing the SVG file size. This guide provides a direct, step-by-step walkthrough on how to locate and remove these unused SVG definitions using Inkscape's built-in Document Properties feature, ensuring your final vector graphic is optimized and lightweight.

Why Remove Unused Definitions?

Every time you create and modify swatches, gradients, filters, or patterns, Inkscape stores their definitions within the SVG source code. If you delete the object using that gradient or filter, the definition often remains stored in the file. Cleaning up these unused elements reduces file size, improves rendering performance in web browsers, and keeps your project structure clean.

Steps to Clean Up Definitions via Document Properties

  1. Open Your SVG File
    Launch Inkscape and open the SVG document you want to optimize.

  2. Open Document Properties
    Access the Document Properties panel through one of the following methods:

    • Navigate to the top menu and select File > Document Properties.
    • Use the keyboard shortcut Ctrl + Shift + D (Windows/Linux) or Cmd + Shift + D (macOS).

  3. Locate the Clean Up Option
    In the Document Properties window, make sure you are on the General tab (or check the bottom-right actions area depending on your Inkscape version). Look for the Clean up button (formerly labeled as Vacuum Defs in older versions).

  4. Execute the Clean Up
    Click the Clean up button. Inkscape will immediately scan the <defs> section of the SVG file, identify any gradients, swatches, patterns, or markers that are not actively assigned to an existing canvas object, and delete them from the file.

  5. Save the Cleaned File
    After running the cleanup, save your optimized file by pressing Ctrl + S (or Cmd + S), or choose File > Save As... to save it under a new name.

Alternative Quick Method

You can also trigger this cleanup directly from the main menu without opening the Document Properties panel by going to File > Clean Up Document. Both methods perform the identical operation of purging unreferenced definitions from the SVG markup.
