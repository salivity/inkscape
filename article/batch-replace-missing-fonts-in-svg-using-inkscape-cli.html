Batch Replace Missing Fonts in SVG Using Inkscape CLI

Batch-processing SVG files to replace missing fonts can be automated entirely through the command line using Inkscape’s headless action system. By executing scripted actions, you can query text elements, apply fallback or target font families across hundreds of files, and re-export the results without launching the graphical user interface. This guide covers how to construct Inkscape action sequences, write batch scripts for multiple operating systems, and ensure text styling remains consistent.

Understanding Inkscape CLI Actions

Starting with version 1.2, Inkscape provides an action-based command-line interface. Instead of relying on legacy flags, commands can be chained together sequentially using the --actions argument or loaded from a dedicated action script file.

To view all available actions supported by your installed version of Inkscape, run:

inkscape --action-list

For font replacement, the primary actions used are:

  • select-by-element:text: Selects all <text> elements within the document.
  • object-set-property:font-family,<FontName>: Updates the font-family CSS/SVG property for the selected elements.
  • export-plain-svg (or export-filename:<path>): Defines the output format and destination.
  • export-do: Executes the export pipeline.

Replacing Fonts Globally Across All Text Elements

If your SVG files contain missing fonts and you want to standardize all text elements to an installed system font (such as "Arial" or "Roboto"), you can chain these actions directly.

Single File Execution

inkscape input.svg --actions="select-by-element:text;object-set-property:font-family,'Roboto';export-filename:output.svg;export-do"

Creating a Reusable Action Script

For more complex workflows, save the actions in a plain text file (e.g., replace_font.actions):

select-by-element:text
object-set-property:font-family,Roboto
export-plain-svg
export-do

Run the action file against an SVG:

inkscape input.svg --action-file=replace_font.actions --export-filename=output.svg

Batch Processing Multiple Files

To apply font replacement across an entire directory of SVG files, use shell scripting to iterate through your files.

Bash (Linux and macOS)

Save this script in the directory containing your SVG files:

#!/usr/bin/env bash

TARGET_FONT="Open Sans"
OUTPUT_DIR="./processed"

mkdir -p "$OUTPUT_DIR"

for file in *.svg; do
    [ -f "$file" ] || continue
    echo "Processing $file..."
    inkscape "$file" \
      --actions="select-by-element:text;object-set-property:font-family,'$TARGET_FONT';export-filename:$OUTPUT_DIR/$file;export-do"
done

echo "Batch processing complete."

PowerShell (Windows)

Run the following commands inside PowerShell:

$targetFont = "Segoe UI"
$outputDir = ".\processed"

New-Item -ItemType Directory -Force -Path $outputDir

Get-ChildItem -Filter *.svg | ForEach-Object {
    $outPath = Join-Path $outputDir $_.Name
    Write-Host "Processing $($_.Name)..."
    inkscape $_.FullName --actions="select-by-element:text;object-set-property:font-family,'$targetFont';export-filename:$outPath;export-do"
}

Write-Host "Batch processing complete."

Replacing Specific Missing Fonts (Targeted Replacement)

Inkscape's built-in select-by-element:text selects every text node in the document. If your SVGs have multiple fonts and you only want to substitute a specific missing font without modifying others, use a two-step pipeline: perform a regex substitution on the XML source, then process the file with Inkscape.

  1. Substitute the Font Name in the XML: SVGs store font names as plain text within style attributes or inline font-family attributes. Use sed (or Python) to swap the missing font name:

    sed -i 's/font-family:"OldMissingFont"/font-family:"NewAvailableFont"/g' *.svg
sed -i "s/font-family:'OldMissingFont'/font-family:'NewAvailableFont'/g" *.svg
sed -i 's/font-family:OldMissingFont/font-family:NewAvailableFont/g' *.svg

  2. Normalize and Clean with Inkscape: Once the font declarations are updated, run Inkscape to re-render the file and validate internal structures:

    inkscape input.svg --actions="clean-up;export-plain-svg;export-filename:fixed_output.svg;export-do"

Preventing Future Font Issues: Converting Text to Paths

If the output SVGs will be distributed to systems that might also lack the replacement font, convert the newly updated text into vector shapes as the final step of the action chain:

inkscape input.svg --actions="select-by-element:text;object-set-property:font-family,'Roboto';object-to-path;export-plain-svg;export-filename:final.svg;export-do"

The object-to-path action converts glyphs into vector outlines based on the newly assigned font, ensuring the graphics appear identically across any machine or browser.
