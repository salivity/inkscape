How to Create Responsive SVGs with Inkscape

Creating responsive Scalable Vector Graphics (SVGs) ensures that illustrations, icons, and UI assets dynamically scale to any screen size without distortion. This guide explains how to properly configure canvas properties, manage viewports, and remove fixed dimensions in Inkscape to output fully fluid, responsive SVG code ready for web integration.

1. Configure the Document Dimensions

Open your artwork in Inkscape and adjust the document properties to tightly wrap your graphics:

  1. Navigate to File > Document Properties (or press Ctrl+Shift+D / Cmd+Shift+D).
  2. Set the Display units to px (pixels).
  3. Under the Page tab, expand Resize page to content... and click Resize page to drawing or selection. This eliminates unnecessary margins and ensures the coordinate origin aligns precisely with your graphic.

2. Understand the ViewBox Attribute

Responsiveness in SVGs relies heavily on the viewBox attribute. The viewBox establishes an internal coordinate system and an aspect ratio, allowing the browser to scale the graphic proportionally. When you adjust the page bounds in Inkscape, the program automatically sets the correct viewBox coordinate values (e.g., viewBox="0 0 800 600").

3. Save as an Optimized SVG

Inkscape introduces proprietary metadata by default. Exporting a clean file makes editing the SVG attributes straightforward:

  1. Go to File > Save As...
  2. In the file type dropdown, choose Optimized SVG (*.svg).
  3. In the export dialog, ensure options to convert coordinates and remove unused namespaces are checked, then click OK.

4. Remove Fixed Width and Height

By default, Inkscape writes absolute width and height attributes (such as width="800px") onto the root <svg> tag. These absolute values restrict the graphic from scaling dynamically:

  1. Open the saved .svg file in any text or code editor (or use Inkscape's built-in XML Editor under Edit > XML Editor).
  2. Locate the root <svg> opening tag.
  3. Delete the width="..." and height="..." attributes, ensuring the viewBox attribute remains intact.

Example before:

<svg width="800px" height="600px" viewBox="0 0 800 600" xmlns="http://www.w3.org/2000/svg">

Example after:

<svg viewBox="0 0 800 600" xmlns="http://www.w3.org/2000/svg">

5. Control Scaling via CSS

Once the fixed dimensions are removed and the viewBox is in place, the SVG adapts dynamically to the dimensions of its parent container in the browser. You can control its behavior using CSS:

svg, img.responsive-svg {
  width: 100%;
  max-width: 800px;
  height: auto;
  display: block;
}

This setup ensures the SVG shrinks fluidly on mobile viewports while expanding up to its maximum defined width on larger displays.
