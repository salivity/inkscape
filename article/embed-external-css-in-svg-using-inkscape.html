Embed External CSS in SVG Using Inkscape

This guide explains how to link and embed external CSS stylesheets into an SVG file using Inkscape. By attaching an external stylesheet, you can maintain consistent styling across multiple vector assets, separate design from markup, and easily update colors, strokes, and typography for web-based SVG graphics.

Method 1: Using the XML Editor and @import

Inkscape does not have a dedicated "Attach Stylesheet" button in its standard toolbar, but its built-in XML Editor allows you to inject CSS rules and @import statements directly into the document structure.

  1. Open the XML Editor
    Open your SVG file in Inkscape and launch the XML Editor by navigating to Edit > XML Editor or pressing Shift + Ctrl + X.

  2. Select the Root SVG Node
    In the XML tree on the left side of the panel, click on the top-level element, which is typically labeled <svg:svg>.

  3. Add a <style> Element

    • In the XML Editor toolbar, click the New element node icon.
    • Enter svg:style as the node name and click Create.

  4. Insert the CSS Link

    • Select the newly created <svg:style> node.
    • Click the New text node icon in the toolbar.
    • In the text field on the right, enter the import rule pointing to your stylesheet path:
      @import url("styles.css");
    • Click Set to apply the text to the node.

Method 2: Adding the XML-Stylesheet Processing Instruction

For standalone SVGs rendered directly in web browsers, linking via an XML processing instruction is standard practice.

  1. Open the XML Editor (Shift + Ctrl + X).
  2. Add a new element node to the root or edit the source using a text editor.
  3. Place the following processing instruction before the opening <svg> tag or within the document header: 
    <?xml-stylesheet href="styles.css" type="text/css"?>

Assigning Classes to SVG Objects in Inkscape

For external CSS rules to target specific shapes, text, or paths, assign CSS classes to your objects within Inkscape:

  1. Select the object on your canvas.
  2. Open the Object Properties panel by pressing Shift + Ctrl + O or via Object > Object Properties.
  3. Locate the Class field and enter your desired class name (e.g., primary-fill or icon-border).
  4. Click Set.

Alternatively, you can open the Selectors and CSS panel via Object > Selectors and CSS (Shift + Ctrl + Q) to manage classes and inspect styles attached to selected elements.

Saving the File

To prevent Inkscape-specific metadata from conflicting with external web styles:

  1. Go to File > Save As....
  2. Select Plain SVG (*.svg) from the file format dropdown.
  3. Save the SVG in the same directory or relative path as referenced in your CSS @import or processing instruction URL.
