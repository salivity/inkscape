Create a Sepia Filter in Inkscape Using feColorMatrix

Applying a sepia tone effect to vector artwork or embedded bitmaps in Inkscape gives modern designs an aged, warm, and vintage appearance. This guide explains how to build a custom SVG filter utilizing Inkscape's Filter Editor and the feColorMatrix primitive, which mathematically shifts standard red, green, and blue color channels into classic sepia tones using a standard color matrix.

Step 1: Open the Filter Editor

  1. Open your document in Inkscape and select the image or object you wish to modify.
  2. Go to the top menu and select Filters > Filter Editor....
  3. The Filter Editor panel will appear, displaying a list of current filters on the left and primitive parameters on the right.

Step 2: Create a New Filter

  1. In the Filter Editor panel, click the New button below the filter list.
  2. A new entry named filter1 (or similar) will appear.
  3. Double-click the filter's name to rename it to something recognizable, such as Sepia Tone.

Step 3: Add the feColorMatrix Primitive

  1. Beneath the filter list, locate the dropdown menu next to the Add Effect: label.
  2. Select Color Matrix from the list (which corresponds to the SVG <feColorMatrix> element).
  3. Click the Add Effect button.
  4. The effect will now appear in the node graph in the center of the panel. Ensure the input of the Color Matrix node connects to the "Source Graphic" input.

Step 4: Configure the Sepia Matrix Values

  1. Select the Color Matrix primitive inside the graph or list.
  2. In the lower settings tab labeled Effect parameters, change the Type dropdown to Matrix.
  3. A 4x5 grid representing the color transformation channels (Red, Green, Blue, and Alpha) will appear.
  4. Enter the standard W3C sepia coefficient values into the corresponding fields:
  • Row 1 (Red output): 0.393, 0.769, 0.189, 0, 0
  • Row 2 (Green output): 0.349, 0.686, 0.168, 0, 0
  • Row 3 (Blue output): 0.272, 0.534, 0.131, 0, 0
  • Row 4 (Alpha output): 0, 0, 0, 1, 0

Step 5: Apply the Filter

  1. Select the target object or image on your canvas.
  2. Check the box next to your new Sepia Tone filter in the filter list of the Filter Editor.
  3. The canvas will update immediately, applying the sepia effect while preserving your original image non-destructively.
