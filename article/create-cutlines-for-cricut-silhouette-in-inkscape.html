Create Cutlines for Cricut & Silhouette in Inkscape

This guide explains how to generate clean, precise vinyl decal cutlines using Inkscape for both Cricut and Silhouette cutting machines. You will learn how to prepare your artwork, create an offset contour path to serve as the cutline, style your vector lines, and export the final file in the proper format (SVG or DXF) for your specific cutting software.

Step 1: Import and Prepare the Artwork

  1. Open Inkscape and go to File > Import to load your image or design.
  2. If using a raster image (PNG or JPEG), convert it into a vector:
    • Select the image.
    • Go to Path > Trace Bitmap.
    • Choose Single scan > Brightness cutoff, adjust the threshold to capture clean edges, and click Apply.
    • Delete the original raster image underneath.
  3. If using an existing vector graphic:
    • Select all elements of your graphic.
    • Go to Path > Object to Path.
    • Go to Path > Ungroup until all components are separated into individual paths.

Step 2: Combine Elements into a Solid Silhouette

To create a single continuous outline around your entire decal:

  1. Select your entire design and duplicate it by pressing Ctrl + D (or Cmd + D on Mac).
  2. With the duplicate selected, go to Path > Union. This merges all overlapping shapes into a single solid silhouette.

Step 3: Generate the Offset Cutline

Create the border offset that defines where the blade will cut around the graphic:

  1. Select the merged silhouette.
  2. Open the Path Effects panel by going to Path > Path Effects.
  3. Click the + (Add Path Effect) button and select Offset.
  4. In the Offset settings:
    • Set the Join style to Round (recommended for smooth sticker cuts).
    • Increase the Offset value (e.g., 2 mm to 5 mm) until the border reaches your desired margin width.
  5. Once satisfied, go to Path > Object to Path to bake the offset effect into a permanent vector path.

Step 4: Format the Cutline Path

  1. Select the newly generated offset path.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F or Cmd + Shift + F).
  3. In the Fill tab, click No paint (X) to remove the interior color.
  4. In the Stroke paint tab, click Flat color and select a high-contrast color (such as red or black).
  5. In the Stroke style tab, set the width to a thin value (e.g., 0.5 px or 0.1 mm).
  6. Send the cutline behind your original graphic by pressing End on your keyboard or selecting Object > Lower to Bottom.

Step 5: Clean Up Stray Interior Cutlines

If your design has internal gaps or holes that you do not want the machine to cut:

  1. Select the cutline path.
  2. Go to Path > Break Apart.
  3. Hold Shift and click the outermost perimeter line to deselect it.
  4. Press Delete to remove all remaining interior path nodes.

Step 6: Export for Your Cutting Software

For Cricut Design Space

  1. Go to File > Save As...
  2. Choose Plain SVG (*.svg) from the file format dropdown.
  3. Import the SVG into Cricut Design Space. In the Layers panel, designate your artwork layer to "Print Then Cut" or "Basic Cut," and your offset line to "Basic Cut." Use the Attach tool to keep them locked together.

For Silhouette Studio

  • Silhouette Studio Designer Edition or higher: Save your file as Plain SVG (*.svg). Open it in Silhouette Studio, go to the Send panel, select the outer line, and set the action to Cut.
  • Silhouette Studio Basic (Free) Edition: Go to File > Save As... in Inkscape and select Desktop Cutting Plotter (AutoCAD DXF R14) (*.dxf). In the export settings, check ROBO-Master export and set base units to mm or in to preserve scale when imported into Silhouette Studio.
