How to Export SVG Tiny 1.2 in Inkscape

This guide explains how to prepare, configure, and export vector graphics to the SVG Tiny 1.2 profile using Inkscape for deployment on resource-constrained mobile and embedded platforms. Because embedded hardware often lacks support for the complete SVG specification, following these specific preparation steps, optimization settings, and XML profile declarations ensures broad compatibility, minimal memory overhead, and fast rendering on low-power devices.

1. Prepare Artwork for SVG Tiny 1.2 Specifications

The SVG Tiny 1.2 profile excludes many advanced features found in the full SVG specification to ensure lightweight processing on microcontrollers, mobile screens, and embedded operating systems. Before exporting, prepare your document to adhere to these constraints:

  • Convert Text to Outlines: Embedded SVG engines often lack local font libraries. Select your text objects and click Path > Object to Path (Shift + Ctrl + C).
  • Remove Unsupported Filter Effects: SVG Tiny 1.2 does not support gaussian blurs, blend modes, drop shadows, or lighting filters. Open Filters > Remove Filters on selected objects to clear any applied raster effects.
  • Simplify Gradients: Restrict fills to solid colors or standard linear and radial gradients. Remove complex multi-stop mesh gradients.
  • Flatten Clipping and Masking: Remove masks and complex clips where possible. Use boolean path operations (Path > Intersection, Path > Difference) to crop shapes permanently into raw geometry.
  • Clean the Document: Open File > Clean Up Document to remove unused swatches, defs, and unused layers from memory.

2. Declare SVG Tiny 1.2 Attributes in the XML Editor

Inkscape saves documents as SVG Full by default. To identify the file correctly to embedded parsers, set the required header attributes using the built-in XML Editor:

  1. Open the XML Editor by pressing Ctrl + Shift + X (or Edit > XML Editor).
  2. Select the top-level <svg:svg> node in the tree.
  3. In the attributes panel on the right, create or update the following string attributes:
    • Attribute name: version | Attribute value: 1.2
    • Attribute name: baseProfile | Attribute value: tiny
  4. Click Set after entering each attribute to apply the changes to the root element.

3. Export as Optimized SVG

To strip proprietary Inkscape metadata, editor namespaces, and non-conforming styling rules, export using Inkscape’s optimization pipeline:

  1. Click File > Save As... (or Ctrl + Shift + S).
  2. In the file format dropdown menu, select Optimized SVG (*.svg).
  3. Name your file and click Save to bring up the Scour optimization configuration dialog.
  4. In the Options tab:
    • Enable Convert styles to XML attributes (crucial for embedded engines that do not parse CSS blocks).
    • Enable Collapse groups.
    • Enable Remove unused defs.
  5. In the SVG Output tab:
    • Enable Remove metadata.
    • Enable Remove Inkscape and Sodipodi namespace attributes.
    • Set Coordinate precision to 2 or 3 to reduce file size without distorting visual geometry.
  6. Click OK to generate the final file.

4. Verify the Output for Embedded Systems

Open the generated file in a plain text editor to verify that it adheres to embedded standards:

  • Ensure the root element starts cleanly with <svg version="1.2" baseProfile="tiny" ...>.
  • Confirm there are no <style> tags; attributes such as fill, stroke, and stroke-width should exist as inline XML attributes directly on shape tags like <path>, <rect>, or <circle>.
  • Test the output on your target runtime engine (such as Qt Quick, NanoSVG, or LVGL) to verify rendering speed and correct scaling across different display resolutions.
