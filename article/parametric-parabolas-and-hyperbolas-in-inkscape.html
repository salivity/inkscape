Parametric Parabolas and Hyperbolas in Inkscape

Inkscape provides a built-in mathematical rendering engine that enables the generation of mathematically precise geometric curves without manual path tracing. By leveraging the Parametric Curves extension, you can plot exact conic sections such as parabolas and hyperbolas defined by parametric equations. This guide details how to access the tool, configure the plotting parameters, and input the exact mathematical expressions required to construct both curves cleanly on your vector canvas.

Accessing the Parametric Plotter

To open the plotting interface, navigate to the top menu and select Extensions > Render > Parametric Curves.... This tool accepts functions of an independent parameter, \(t\), and outputs a path based on \(X(t)\) and \(Y(t)\) coordinates using Python's mathematical syntax.

Constructing a Parabola

A standard vertical parabola opening upward follows the Cartesian equation \(y = ax^2\). In parametric form, this is expressed using the parameter \(t\) as:

  • \(x(t) = t\)
  • \(y(t) = a \cdot t^2\)

Follow these steps in the Parametric Curves dialog:

  1. Set the Parameter Range: Define the start and end values for \(t\). For a symmetric parabola, set Start value of t to -10 and End value of t to 10.
  2. Enter the Equations:
    • In the X-Function field, enter: t
    • In the Y-Function field, enter: 0.05 * t**2 (adjust the coefficient 0.05 to make the curve wider or narrower).
  3. Configure Resolution: Set Number of samples to at least 50 to ensure smooth curvature.
  4. Render: Click Apply to generate the parabola as a path object.

Constructing a Hyperbola

A standard horizontal hyperbola centered at the origin follows the Cartesian equation \((x/a)^2 - (y/b)^2 = 1\). The cleanest parametric representation uses hyperbolic functions (\(\cosh\) and \(\sinh\)):

  • Right branch: \(x(t) = a \cdot \cosh(t)\), \(y(t) = b \cdot \sinh(t)\)
  • Left branch: \(x(t) = -a \cdot \cosh(t)\), \(y(t) = b \cdot \sinh(t)\)

Because a hyperbola consists of two disconnected branches, each branch must be rendered separately:

  1. Plotting the Right Branch:
    • Start value of t: -3
    • End value of t: 3
    • X-Function: 50 * cosh(t)
    • Y-Function: 30 * sinh(t)
    • Click Apply.
  2. Plotting the Left Branch:
    • Keep the same \(t\) range.
    • Change the X-Function to: -50 * cosh(t)
    • Keep the Y-Function as: 30 * sinh(t)
    • Click Apply.

Adjusting Scale and Origin

  • Visual Inversion: In Inkscape, the \(Y\)-axis increases downward by default in computer graphics coordinates. If your parabola renders upside down, invert the sign in the Y-function (e.g., -0.05 * t**2).
  • Placement: The generated paths are placed relative to the current selection or canvas origin. Once rendered, select the curves using the Select and Transform Objects tool (\(S\)) to reposition, scale, or edit the stroke weight via the Fill and Stroke panel.
