Save and Restore Window Layouts in Inkscape

This guide outlines how to configure, save, and restore custom window layouts and dialog arrangements in Inkscape. While Inkscape lacks a one-click workspace switcher found in some other graphic suites, you can consistently preserve and reload your preferred dock layouts and multi-screen configurations using built-in window preferences, custom templates, and profile configurations.

1. Enable Automatic Geometry and Dialog Saving

Inkscape can automatically memorize your toolbars, dialog docks, and window sizes between sessions.

  1. Open Inkscape and navigate to Edit > Preferences (or press Ctrl + Shift + P / Cmd + Shift + P).
  2. In the left sidebar, click on Interface and select Windows.
  3. Under Window state, choose Remember and use last window’s geometry.
  4. Set Dialog behavior to your preference (typically Dockable for fixed workspace panels).
  5. Ensure the option Save and restore dialogs status is checked.

Once enabled, any arrangement of panels (such as Layers and Objects, Align and Distribute, or Fill and Stroke) will reopen automatically in the same position upon relaunching.

2. Lock Layouts to Custom Document Templates

To create specific layouts for different tasks (e.g., vector illustration, typography, or UI design), tie your layout to document templates.

  1. Arrange your dialog panels on the screen as desired for your specific workflow.
  2. Go to File > Save Template....
  3. Enter a name for the workspace (e.g., Illustration Workspace).
  4. If you want this to be your standard interface on launch, check Set as default template.
  5. Click Save.

You can now restore this setup at any time by selecting File > New from Template... and choosing your saved configuration.

3. Manage Multiple Workspaces Using Profiles

Because Inkscape stores dialog docking and interface state in its preferences file, you can maintain distinct workspaces by managing user configuration directories.

Inkscape stores configuration files in the following default paths:

  • Windows: %APPDATA%\inkscape\
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/
  • Linux: ~/.config/inkscape/

To create switchable workspaces:

  1. Configure Inkscape with the layout and dialog positions for your first workspace, then close the application.
  2. Navigate to the configuration path above and make a copy of the preferences.xml file (e.g., rename the copy to preferences_illustration.xml).
  3. Reopen Inkscape, arrange your panels for a different task (e.g., technical drafting), and close the application to update preferences.xml.
  4. Make a second copy named preferences_drafting.xml.
  5. Restore any workspace by replacing preferences.xml with your desired preset before starting Inkscape, or launch Inkscape via command line using the environment variable INKSCAPE_PROFILE_DIR pointing to separate dedicated configuration folders.
