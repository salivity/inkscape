Insert a Node at Curve Midpoint in Inkscape

This guide explains how to accurately insert a new node at the exact midpoint of a path or curve segment using Inkscape's Node tool. By selecting the target segment or its bounding nodes and using the built-in node insertion feature, you can subdivide a curve symmetrically without guessing the center point or distorting the original path geometry.

Step 1: Select the Path with the Node Tool

  1. Open your document in Inkscape.
  2. Activate the Edit paths by nodes tool from the left toolbar, or press the shortcut N (or F2).
  3. Click on the path containing the curve segment you want to edit. The existing nodes on the path will become visible.

Step 2: Select the Curve Segment

To tell Inkscape where the midpoint should be calculated, specify the segment between two existing nodes:

  • Method A (Direct Segment Selection): Click directly on the line or curve between two nodes. The segment will be highlighted, and the two bounding nodes will automatically become selected.
  • Method B (Node Selection): Hold Shift and click both nodes that border the curve segment you wish to divide.

Step 3: Insert the Midpoint Node

Once the segment or the two bounding nodes are selected:

  1. Look at the Tool Controls Bar at the top of the Inkscape window.
  2. Click the first icon on the left: Insert new nodes into selected segments (it looks like a plus sign over a path segment between two nodes).
  3. Alternatively, press Insert (or Shift + I) on your keyboard.

Inkscape automatically calculates the mathematical center of the curve and places a single new node at the exact midpoint, keeping the curvature and handle angles intact.
