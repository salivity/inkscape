Export Color Separations to Monochromatic PDF in Inkscape

This guide details how to export color separations as individual monochromatic PDF pages in Inkscape for applications like screen printing, plate making, and offset printing. Because Inkscape handles colors in an RGB-native workspace, creating true monochromatic separations requires isolating each color channel or spot color, converting the artwork to solid black, placing each separation onto dedicated pages, and exporting the final layout as a multi-page PDF.

Step 1: Isolate Colors Using Layers or Selection

  1. Open your artwork in Inkscape.
  2. Select an object containing the first color you want to separate.
  3. Go to Edit > Select Same > Fill Color (or Fill and Stroke) to select all elements sharing that color across the canvas.
  4. Press Ctrl + G to group the selected elements.
  5. Open the Layers and Objects panel (Layer > Layers and Objects).
  6. Create a new layer for each color separation (for example: Black Plate, Red Plate, Blue Plate) and move the corresponding grouped elements into their dedicated layers.

Step 2: Convert Elements to Monochromatic Black

For physical separations like film positives or printing plates, every printable area must be solid black (100% K) regardless of its intended final print color.

  1. Select the group or layer representing your first color separation.
  2. Open the Fill and Stroke panel (Shift + Ctrl + F).
  3. Set the Fill color to pure black (#000000 or CMYK: 0, 0, 0, 100).
  4. If the objects have outlines, set the Stroke paint to pure black as well.
  5. Repeat this process for every color layer until all separations consist entirely of black graphics on transparent backgrounds.

Step 3: Align Plates Using Registration Marks

  1. Create a new top layer named Registration.
  2. Draw registration marks (such as crosshairs or targets) outside the printable artwork area at opposite corners of the page.
  3. Color these marks solid black.
  4. Keep this layer visible across all separations so each exported plate aligns accurately on press.

Step 4: Arrange Separations on Separate Pages

Inkscape includes native multi-page document support, allowing you to export each plate as an individual page within a single PDF document:

  1. Select the Create and Edit Pages tool from the left toolbar (or press Shift + P).
  2. Click the Add Page button in the top toolbar to create a new page for each color separation. Ensure all pages are the same dimensions.
  3. Align each color group onto its respective page at the exact same X and Y coordinates. Alternatively, duplicate the original page and keep only one color layer visible per page.

Step 5: Export the Monochromatic PDF

  1. Go to File > Save As... (or press Shift + Ctrl + S).
  2. Set the file format dropdown to Portable Document Format (*.pdf).
  3. Choose your destination folder and click Save.
  4. In the PDF export dialog window:
    • Ensure the Output page size is set to match your document pages.
    • Under Pages, select All to output every separation page into a single PDF file.
    • Set Rasterize filter effects resolution to 300 dpi or higher if your artwork uses blurs or gradients.
  5. Click OK to generate the PDF.

Each page in the resulting PDF will contain a single, registration-aligned monochromatic separation ready for film output or digital platemaking.
