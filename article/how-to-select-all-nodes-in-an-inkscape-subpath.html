How to Select All Nodes in an Inkscape Subpath

Selecting all nodes belonging to a single subpath within a compound path is a common requirement when modifying complex vector graphics in Inkscape. Because a compound path treats multiple independent outlines as a single object, standard selection commands often target the entire path rather than individual components. This guide covers the most efficient methods to isolate and select every node of a specific subpath using the Node tool, lasso selection, and path-splitting features.

Method 1: Marquee Box Selection

If the subpath is physically separated from other parts of the compound path, a simple drag-selection is the fastest approach:

  1. Press N to activate the Node tool.
  2. Click on the compound path to display its nodes.
  3. Click and drag a rectangular bounding box completely around the subpath you want to select.
  4. Release the mouse button. All nodes within that rectangle will turn yellow (or your theme's selected color), indicating they are selected.

Method 2: Lasso Selection (Alt + Drag)

When subpaths overlap, are nested within one another (such as a donut hole), or sit too close for a rectangular box:

  1. Select the compound path with the Node tool (N).
  2. Hold down the Alt key.
  3. Click and drag your mouse around the target subpath to draw a freehand red selection line around its nodes.
  4. Release the mouse button. Any node touched by or enclosed within the drawn path will be selected.

Method 3: Inverting the Node Selection

If the subpath you want to select is complex, but the other subpaths are simple:

  1. Use the Node tool (N) to select all the nodes you do not want.
  2. Press ! (Shift + 1) on your keyboard.
  3. Inkscape will invert the node selection across the active path, deselecting the initial nodes and selecting all nodes on the remaining subpath.

Method 4: Splitting the Path Temporarily

If you need to perform extensive edits on a subpath and want to use standard whole-path selection commands (like Ctrl + A):

  1. Switch to the Select tool (S) and select the compound path.
  2. Go to the menu and choose Path > Split Path (Inkscape 1.2 or newer) or Path > Break Apart (Ctrl + Shift + K).
  3. Click outside to deselect, then click directly on the isolated subpath.
  4. Switch to the Node tool (N) and press Ctrl + A to select all of its nodes.
  5. Once your edits are complete, select all the separated paths and choose Path > Combine (Ctrl + K) to restore the compound path structure.
