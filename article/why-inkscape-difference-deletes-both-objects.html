Why Inkscape Difference Deletes Both Objects

When using the Path Difference tool in Inkscape, users often encounter an issue where both selected objects disappear instead of cutting one shape out of the other. This usually happens due to incorrect object stacking order, attempting to use Boolean operations on groups or raw geometric shapes instead of paths, or having the top object completely enclose the bottom object. Understanding how Inkscape processes Boolean operations resolves this issue quickly.

The Top Object Fully Covers the Bottom Object

Inkscape's Difference operation (Path > Difference or Ctrl + -) uses the top object as a "cookie cutter" to subtract its shape from the bottom object. Once the operation is complete, the cutting object (top) is deleted automatically. If the top object is larger than and completely covers the bottom object, it subtracts the entire bottom shape. Since the bottom shape is reduced to nothing and the top shape is discarded by design, both objects disappear from the canvas. To fix this, ensure the cutting object only covers the portion of the bottom object you want to remove.

The Objects Are Groups Instead of Single Paths

Boolean operations in Inkscape only function on individual path elements. If one or both of the selected items is a group, the software cannot calculate the intersection correctly, often resulting in the entire selection vanishing.

  • Select the objects and look at the Status Bar at the bottom of the screen.
  • If it says "Group of X objects," ungroup them by pressing Ctrl + Shift + G (or Object > Ungroup).
  • If you need to cut multiple shapes at once, combine them first using Path > Combine (Ctrl + K) before applying the Difference operation.

The Objects Have Not Been Converted to Paths

Basic shapes created with the Rectangle, Circle, or Star tools, as well as live Text objects, are not raw vector paths by default. Attempting a Difference operation on primitive shapes or text can cause unpredictable behavior or total deletion.

  • Select your shapes.
  • Navigate to Path > Object to Path (Ctrl + Shift + C).
  • Perform the Difference operation again.

The Path Stacking Order Is Inverted

Because the top object always acts as the cutter, having the wrong shape on top can lead to accidental deletion of the geometry you intended to keep. You can adjust the Z-order using the keyboard:

  • Select the object intended to be the cutter and press Page Up to raise it to the top.
  • Alternatively, select the object you want to keep and press Page Down to move it to the bottom.

Working with Open Paths

Difference operations require closed 2D areas. If you attempt to subtract using an open stroke (a line with unconnected endpoints), Inkscape may fail to create a valid closed path and discard the resulting geometry. Close any open paths using the Node tool (F2) before running the operation.
