Create Paths with inkex.PathElement in Inkscape

This guide demonstrates how to programmatically create and insert new SVG path elements into an Inkscape document using Python and the inkex.PathElement class. You will learn the core steps required to initialize a path, define its vector coordinates, apply styling attributes, and append the finished element to the document tree within an Inkscape extension.

1. Import Required Modules

To work with paths in modern Inkscape extensions (Inkscape 1.0+), import the inkex package. You will typically interact with inkex.PathElement directly or create one using generic element factory methods.

import inkex
from inkex import PathElement

2. Instantiate the PathElement

You can instantiate PathElement directly. Once created, define the shape by assigning SVG path commands to its path property or d attribute. You can supply raw SVG path data as a string, or use the inkex.Path object for programmatic coordinate construction.

# Create the element
new_path = PathElement()

# Define the geometry using standard SVG path string syntax
new_path.set('d', 'M 10,10 L 100,10 L 100,100 Z')

# Alternatively, assign directly to the path property
# new_path.path = "M 10,10 L 100,10 L 100,100 Z"

3. Apply Styling and Attributes

Configure the visual appearance by setting the element's style attribute. In inkex, styles can be assigned using a dictionary-like interface or directly as CSS style strings.

# Setting attributes using a dictionary-style update
new_path.style = {
    'fill': '#ff0000',
    'stroke': '#000000',
    'stroke-width': '2px',
    'stroke-linecap': 'round'
}

# You can also assign an optional ID or label
new_path.set_id('custom_triangle_path')

4. Append the Element to the Document

The new path will not appear in Inkscape until it is added to a parent element in the XML tree, such as the active layer or the root SVG element.

# To add to the current layer:
current_layer = self.svg.get_current_layer()
current_layer.append(new_path)

# Or directly to the SVG root:
# self.svg.append(new_path)

Complete Extension Example

Below is a complete implementation inside a basic inkex.EffectExtension showing how these steps work together:

import inkex
from inkex import PathElement

class DrawCustomPath(inkex.EffectExtension):
    def effect(self):
        # 1. Instantiate the path
        path_elem = PathElement()
        
        # 2. Define geometry (draws an arrow or triangle)
        path_elem.path = 'M 50,50 L 150,50 L 100,150 Z'
        
        # 3. Apply stroke and fill
        path_elem.style = {
            'fill': '#4CAF50',
            'stroke': '#2E7D32',
            'stroke-width': '3px'
        }
        
        # 4. Insert into the active layer
        layer = self.svg.get_current_layer()
        layer.append(path_elem)

if __name__ == '__main__':
    DrawCustomPath().run()
