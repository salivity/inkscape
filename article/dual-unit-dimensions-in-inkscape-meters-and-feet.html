Dual-Unit Dimensions in Inkscape: Meters and Feet

Configuring dual-unit dimension scales showing both meters and feet in Inkscape allows technical illustrators and designers to produce drawings readable across different measurement standards. While Inkscape does not offer a single-click native toggle for simultaneous dual units, you can achieve precise, professional dual-unit readouts using stacked Live Path Effects (LPE) for dynamic scaling or by utilizing the Dimensions extension with custom offsets.

Method 1: Using Stacked "Measure Segments" Live Path Effects (Dynamic)

The Measure Segments Live Path Effect automatically updates dimension values whenever an object is scaled, making it the most robust method for ongoing technical drafts.

  1. Prepare the Object: Select the path, line, or shape you want to dimension. If working with a primitive shape (like a rectangle), convert it first by navigating to Path > Object to Path.
  2. Open Path Effects: Go to Path > Path Effects to open the side panel.
  3. Add the Primary Unit (Meters):
    • Click the + button in the Path Effects dialog and select Measure Segments.
    • Set Unit to m.
    • Configure the Precision (typically 2 decimal places).
    • Set the Position or Offset so the label sits comfortably above the line (e.g., an offset of 15).
  4. Add the Secondary Unit (Feet):
    • Click the + button again to stack a second Measure Segments effect onto the exact same path.
    • In the new effect settings, set Unit to ft.
    • Set the Precision as needed (typically 2).
    • Invert or increase the Offset (e.g., -15 to place it below the line, or 30 to place it directly above the meter label) to prevent the two text fields from overlapping.
  5. Adjust Display Format: Use the Format fields within each effect to append brackets or labels, such as setting the secondary format to display values inside brackets ([{value} ft]).

Method 2: Using the Dimensions Extension (Static)

If you require traditional architectural dimension lines with arrows and witness lines, use the built-in path visualization extension.

  1. Set Up the Path: Select the segment or object requiring dimensions.
  2. Generate Metric Dimension:
    • Go to Extensions > Visualize Path > Dimensions....
    • Set Units to m.
    • Adjust Offset (for example, 20 px) to place the dimension line at a designated distance from the path.
    • Enable arrows, customize text size, and click Apply.
  3. Generate Imperial Dimension:
    • Keep the path selected and reopen Extensions > Visualize Path > Dimensions....
    • Change Units to ft.
    • Change the Offset to a greater distance (for example, 40 px) to place the feet measurement parallel to the meters measurement without collision.
    • Click Apply.
  4. Group Dimensions: Select the path and both generated dimension groups, then press Ctrl + G to keep them bound together.

Method 3: Combined In-Line Dual Labels

For drawings requiring a single dimension line reading X.XX m [Y.YY ft]:

  1. Apply Extensions > Visualize Path > Dimensions... using meters as the primary unit.
  2. Calculate the equivalent measurement in feet (\(1\text{ meter} \approx 3.28084\text{ feet}\)).
  3. Double-click the generated text label using the Text Tool (T).
  4. Manually append the conversion in brackets after the primary metric reading (e.g., 5.00 m [16.40 ft]).
