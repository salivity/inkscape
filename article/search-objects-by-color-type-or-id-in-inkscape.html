Search Objects by Color, Type, or ID in Inkscape

Inkscape includes a dedicated Find/Replace dialog that allows you to quickly locate, select, and modify vector elements across complex projects. This guide covers how to access the tool and search for specific objects within your document based on their fill and stroke colors, object types, and unique element IDs.

Opening the Find/Replace Dialog

To open the search utility in Inkscape:

  • Press Ctrl + F (Windows/Linux) or Cmd + F (macOS).
  • Alternatively, go to the top menu and select Edit > Find/Replace....

A dockable panel or floating window will appear with multiple search fields and filtering options.

Searching by Object Type

To locate specific kinds of vector elements:

  1. In the Find/Replace panel, locate the Object types section.
  2. Check the boxes corresponding to the elements you want to find (e.g., Rectangles, Ellipses, Paths, Texts, or Groups).
  3. Choose the search scope at the bottom (All, Current layer, or Selection).
  4. Click the Find button. Inkscape will automatically select every object matching the chosen types.

Searching by Color (Fill and Stroke)

You can find objects based on their exact color properties:

  1. In the Find/Replace panel, locate the Style or Properties field.
  2. Enter the CSS style string or color hex code (e.g., fill:#ff0000 for a red fill or stroke:#000000 for a black outline).
  3. Click Find to select all elements containing that color definition.

Note: For an even faster color search, you can right-click any object on the canvas, hover over Select Same, and choose Fill Color, Stroke Color, or Fill and Stroke.

Searching by Object ID

Every object in an SVG document is assigned a unique identifier:

  1. In the Find/Replace panel, find the Id input field.
  2. Type the exact ID or a partial string of the ID you are looking for (e.g., path1024 or rect45).
  3. Click Find. Inkscape will directly target and highlight the element matching that ID.

Refining Search Scope

Before running a search, you can refine where Inkscape looks:

  • Scope: Toggle between searching the Current layer, the Selection, or the entire Document.
  • Include Hidden/Locked: Check the options to include or exclude locked and hidden layers to avoid unintentional edits to protected artwork.
