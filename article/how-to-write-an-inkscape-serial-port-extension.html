How to Write an Inkscape Serial Port Extension

Building an Inkscape extension to control external hardware involves creating an XML-based descriptor file (.inx) to generate the user interface within Inkscape and a Python script using the inkex and pyserial libraries to process drawing data and transmit commands over a serial connection. This guide details how to configure the extension files, extract vector path coordinates from an active SVG document, and stream formatted motion commands directly to a connected microcontroller such as an Arduino.

1. Prerequisites and Setup

Inkscape relies on its own internal Python environment to execute extensions. To communicate via a COM port, the pyserial library must be installed into that environment.

Run the following command using the Python interpreter packaged with your Inkscape installation:

python -m pip install pyserial

2. Define the Extension Interface (.inx)

Inkscape requires an .inx file to display the extension in the menu bar and to collect user inputs such as the serial port identifier and baud rate.

Create a file named serial_controller.inx and place it in your Inkscape user extensions directory (located at Edit > Preferences > System > User extensions):

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>Hardware Serial Controller</name>
    <id>org.example.hardware.controller</id>
    
    <param name="port" type="string" gui-text="Serial Port:">/dev/ttyUSB0</param>
    <param name="baud" type="int" min="1200" max="115200" gui-text="Baud Rate:">115200</param>

    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Hardware Control"/>
        </effects-menu>
    </effect>

    <script>
        <command location="inx" interpreter="python">serial_controller.py</command>
    </script>
</inkscape-extension>

3. Implement the Extension Logic (.py)

Create a Python file named serial_controller.py in the same directory. This script uses the inkex API to parse the selected paths, convert coordinate positions into hardware-readable instructions, and transmit them through serial.Serial.

import inkex
from inkex.paths import Move, Line
import serial
import time

class SerialHardwareExtension(inkex.EffectExtension):
    def add_arguments(self, pars):
        pars.add_argument("--port", type=str, default="/dev/ttyUSB0", help="Serial port")
        pars.add_argument("--baud", type=int, default=115200, help="Baud rate")

    def effect(self):
        port = self.options.port
        baud = self.options.baud

        try:
            ser = serial.Serial(port, baud, timeout=2)
            time.sleep(2)  # Wait for microcontroller reset upon connection
        except serial.SerialException as e:
            inkex.errormsg(f"Failed to open serial port: {e}")
            return

        try:
            for element in self.svg.selection.filter(inkex.PathElement):
                path = element.path.to_absolute()
                for command in path:
                    if isinstance(command, Move):
                        x, y = command.x, command.y
                        # Send pen-up or rapid move command
                        ser.write(f"G0 X{x:.2f} Y{y:.2f}\n".encode("utf-8"))
                    elif isinstance(command, Line):
                        x, y = command.x, command.y
                        # Send pen-down or linear feed move command
                        ser.write(f"G1 X{x:.2f} Y{y:.2f}\n".encode("utf-8"))
                    
                    # Read hardware acknowledgment
                    response = ser.readline().decode("utf-8").strip()
        finally:
            ser.close()

if __name__ == "__main__":
    SerialHardwareExtension().run()

4. Running the Extension

  1. Restart Inkscape to register the new .inx configuration.
  2. Draw or import a vector shape, convert all objects to paths using Path > Object to Path, and select the paths.
  3. Open the extension via Extensions > Hardware Control > Hardware Serial Controller.
  4. Enter your microcontroller's port (e.g., COM3 on Windows or /dev/ttyUSB0 on Linux) and target baud rate.
  5. Click Apply to execute the script and stream the coordinates directly to your hardware.
