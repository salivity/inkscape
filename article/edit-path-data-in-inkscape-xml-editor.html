Edit Path Data in Inkscape XML Editor

This guide provides a straightforward walkthrough on modifying raw SVG path strings directly using Inkscape's built-in XML Editor. By accessing the underlying d attribute of vector paths, you can manually inspect, adjust, copy, or rewrite path commands and numerical coordinates with precise programmatic control.

Step 1: Open the XML Editor

To access the raw SVG document tree in Inkscape:

  • Go to the top menu and select Edit > XML Editor..., or
  • Press the keyboard shortcut Ctrl + Shift + X (Windows/Linux) or Cmd + Shift + X (macOS).

A panel will dock into your workspace displaying the hierarchical XML structure of the current document.

Step 2: Select the Target Path

  1. Use the standard Select Tool (S or F1) on the canvas to click the path you want to modify.
  2. The XML Editor will automatically highlight the corresponding <svg:path> node in the node tree. Alternatively, expand the tree structure in the XML panel manually to find and click the specific <svg:path> element.

Step 3: Locate the Path Data Attribute (d)

In the right-hand sub-panel of the XML Editor:

  1. Look at the table listing the element's attributes (such as id, style, and d).
  2. Click on the d attribute.
  3. The raw string value of the path will appear in the text input box directly below the attribute list.

Step 4: Edit the Raw Path Commands

You can now edit the coordinate string directly in the text area. SVG path syntax relies on command letters followed by numeric coordinates:

  • M / m: Move to (M x,y absolute; m dx,dy relative)
  • L / l: Line to (L x,y absolute; l dx,dy relative)
  • H / h: Horizontal line to (H x absolute; h dx relative)
  • V / v: Vertical line to (V y absolute; v dy relative)
  • C / c: Cubic Bézier curve (C x1,y1, x2,y2, x,y)
  • S / s: Smooth cubic Bézier curve (S x2,y2, x,y)
  • Q / q: Quadratic Bézier curve (Q x1,y1, x,y)
  • T / t: Smooth quadratic Bézier curve (T x,y)
  • A / a: Elliptical arc command (A rx ry x-axis-rotation large-arc-flag sweep-flag x y)
  • Z / z: Close path

Modify the numbers, remove segments, or paste external SVG path strings directly into this field.

Step 5: Apply the Changes

  1. After editing the string, click the Set button located next to the text input box, or press Ctrl + Enter.
  2. The canvas will immediately re-render the path using your updated coordinate data.
