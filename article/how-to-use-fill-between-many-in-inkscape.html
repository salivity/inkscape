How to Use Fill Between Many in Inkscape

This guide explains how to use Inkscape's Fill between Many Live Path Effect (LPE) to generate dynamic skinning and complex surfaces across multiple curves. You will learn how to prepare your source paths, apply the effect to a target path, link the curves together, and adjust effect settings to create smooth, editable vector skins that automatically update when the underlying skeleton curves are modified.

1. Prepare the Skeleton Curves

  1. Select the Draw Freehand Lines (Pencil) or Draw Bézier Curves (Pen) tool.
  2. Draw two or more distinct, open or closed paths across the canvas that will act as the ribs or boundary curves for the skin.
  3. Ensure the direction of the paths is consistent. If the fill appears twisted, select a path, switch to the Node Tool (N), and go to Path > Reverse to fix alignment.

2. Set Up the Target Path

The "Fill between Many" effect must be applied to a dedicated path that will become the generated fill surface:

  1. Draw a simple placeholder shape, such as a basic rectangle or single line.
  2. Ensure this object has a visible fill and no stroke (or a stroke, depending on your desired output).
  3. Select this placeholder path.

3. Apply the Path Effect

  1. Open the Path Effects panel by navigating to Path > Path Effects.
  2. Click the Add Path Effect button (+).
  3. Search for or locate Fill between Many and select it.

4. Link the Source Curves

  1. Select all the skeleton curves you drew in Step 1.
  2. Copy them to your clipboard (Ctrl + C or Cmd + C).
  3. Select the target path containing the "Fill between Many" effect.
  4. In the Path Effects dialog under the "Fill between Many" settings, find the Linked Paths parameter.
  5. Click the Paste path icon (clipboard icon) next to the input list. This assigns all copied paths into the effect stack.

Alternatively, you can link individual paths manually by clicking the Link to path in clipboard button for each curve.

5. Configure Skinning and Path Order

  1. Reorder Curves: If the generated shape folds or connects incorrectly, adjust the order of the linked paths within the effect list by moving individual path references up or down.
  2. Close Options: Use the checkboxes or mode dropdowns (such as Fuse Paths or Closed Path) in the effect panel to determine whether the beginning and end curves connect into a complete loop or form an open ribbon.
  3. Change Fills and Styles: Modify the fill color, gradients, opacity, and stroke settings on the target path just like standard vector objects.

6. Edit Dynamically

Once configured, the skin is fully parametric:

  • Select the Node Tool (N) and adjust the nodes or handles of any original skeleton curve.
  • The skinned target path will automatically recalculate and deform in real time to match the new curve geometry.
