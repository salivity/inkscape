Create Koch Anti-Snowflakes in Inkscape with LPE

This guide explains how to generate a Koch anti-snowflake in Inkscape by utilizing the VonKoch Live Path Effect (LPE). Unlike the standard Koch snowflake, which expands outward, the anti-snowflake folds equilateral triangular bends inward toward the center of the base geometry. By configuring a base polygon, applying the fractal effect, and adjusting the sub-path orientation, you can produce precise inward fractal patterns in a few simple steps.

Step 1: Create the Base Geometry

  1. Select the Stars and Polygons tool (* or F8) from the left toolbar.
  2. In the top controls bar, choose the regular polygon icon (not the star) and set Corners to 3.
  3. Click and drag on the canvas while holding Ctrl to draw an equilateral triangle with a flat horizontal base.
  4. With the triangle selected, convert it from a parametric shape into a standard vector path by navigating to Path > Object to Path (Shift + Ctrl + C).

Step 2: Apply the VonKoch Live Path Effect

  1. Open the Live Path Effects dialog by navigating to Path > Path Effects....
  2. Select the triangle and click the Add Path Effect button (the + icon) in the Path Effects panel.
  3. Search for VonKoch in the effect list and select it to apply it to your shape.

Step 3: Configure Inward Triangular Bends

By default, the VonKoch LPE projects segments outward to create a standard snowflake. To invert these into inward triangular bends:

  1. Reverse Path Direction: The simplest method to invert the fractal is flipping the path winding. With the object selected, go to Path > Reverse. This swaps the orientation of each vector segment, instantly forcing the generated triangular notches to point inward.
  2. Alternative (Manual Generator Editing): In the VonKoch LPE settings, locate the Generating path option and click the Edit on-canvas icon (node tool). Drag the middle peak node of the generation guide toward the inside of the polygon. Ensure the inward indentation forms an angle of 60 degrees to maintain exact Koch fractal geometry.

Step 4: Increase Fractal Iterations

  1. In the VonKoch settings panel, find the Order (or Max generations) parameter.
  2. Increase the value from 1 to 3 or 4. Each increase subdivides the inward segments recursively.
  3. Avoid setting the order higher than 5 or 6, as exponential node growth can cause Inkscape to freeze or crash.

Step 5: Finalize and Bake the Path (Optional)

If you need to export, laser-cut, or edit the individual nodes of the anti-snowflake:

  1. Select the object.
  2. Go to Path > Object to Path. This applies the LPE permanently and turns the fractal into a standard editable vector path.
