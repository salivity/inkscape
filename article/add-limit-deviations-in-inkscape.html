Add Limit Deviations in Inkscape

This guide explains how to add upper and lower limit deviation text (bilateral tolerances) to technical dimension lines in Inkscape. While Inkscape provides dimensioning extensions and line tools, it does not include an automated CAD-style stacked tolerance generator. You can quickly achieve professional, standard-compliant stacked limit deviations by combining nominal dimension text with custom-spaced stacked text blocks or by utilizing manual character shifts.

Step 1: Draw the Base Dimension Line

  1. Select the Draw Freehand Lines or Draw Bezier Curves tool (B).
  2. Draw your dimension line between the two reference points, holding Ctrl to constrain the line horizontally or vertically.
  3. Open the Fill and Stroke panel (Ctrl + Shift + F).
  4. In the Stroke style tab, set the start and end markers to dimension arrows.

Step 2: Add the Nominal Dimension Text

  1. Select the Text tool (T) and click near your dimension line.
  2. Type the nominal dimension value (for example, 50).
  3. Set your desired font family and base font size (for example, 12 pt).

Step 3: Create the Stacked Deviation Text

The cleanest way to stack upper and lower deviations (such as +0.05 and -0.02) without distorting font metrics is using a dedicated multi-line text block:

  1. With the Text tool (T), click directly to the right of your nominal dimension.
  2. Type the upper limit deviation, press Enter, and type the lower limit deviation (for example, +0.05 on the top line and -0.02 on the bottom line).
  3. Highlight both deviation values:
    • Decrease the font size to approximately 60%–70% of the nominal text size (for example, 7 pt or 8 pt).
    • In the Text controls bar at the top, reduce the Line height (spacing between baselines) to approximately 0.8 to 0.9 so the numbers sit closely together without overlapping.

Step 4: Align the Nominal Value and Tolerances

  1. Switch to the Select and Transform objects tool (S).
  2. Select both the nominal text object and the stacked deviation text object.
  3. Open the Align and Distribute panel (Ctrl + Shift + A).
  4. Set Relative to to Selection area.
  5. Click Center on horizontal axis to ensure the deviation block centers symmetrically against the nominal dimension.
  6. Press Ctrl + G to group the nominal dimension and deviations into a single unified object.

Step 5: Position on the Dimension Line

  1. Select your grouped text and the dimension line.
  2. In the Align and Distribute panel, use Center on vertical axis and Center on horizontal axis to place the text directly over the midpoint of the dimension line.
  3. If placing the text directly across the line, select the dimension line, switch to the Node tool (N), and split or break the path behind the text block to maintain standard technical drawing clearance. Alternatively, give the text object a solid background or white stroke to mask the line beneath it.
