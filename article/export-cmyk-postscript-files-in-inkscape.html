Export CMYK PostScript Files in Inkscape

This guide explains how to prepare and export vector artwork to high-resolution CMYK PostScript (.ps) files using Inkscape. While Inkscape works natively in an sRGB color space, you can achieve print-ready CMYK PostScript output by configuring the appropriate International Color Consortium (ICC) profiles, applying CMYK values to your objects, and configuring the export settings for high-resolution output.

1. Install and Configure a CMYK Color Profile

Because Inkscape requires an external ICC profile to calculate CMYK values accurately, you must ensure a print-standard profile (such as Coated FOGRA39 or US Web Coated SWOP) is installed on your operating system.

  1. Download your preferred ICC profile if it is not already installed on your system.
  2. Open Inkscape and navigate to Edit > Preferences > Color management.
  3. Set the Display profile and select your chosen CMYK profile in the Device profile dropdown.
  4. Go to File > Document Properties > Color.
  5. Click the + icon to add your installed CMYK profile to the current document.

2. Apply CMYK Colors to Your Artwork

For accurate color separation, the artwork elements must reference the assigned CMYK profile rather than standard RGB definitions.

  1. Select your object or path.
  2. Open the Fill and Stroke panel (Ctrl+Shift+F or Cmd+Shift+F).
  3. Select either the CMS tab or the CMYK color slider tab.
  4. If using the CMS tab, select your linked CMYK profile from the dropdown and input the desired cyan, magenta, yellow, and key (black) percentages.

3. Export to PostScript (.ps)

Once the artwork is prepared, you can output the document as a high-resolution PostScript file.

  1. Navigate to File > Save As... (or File > Export > Export As...).
  2. Choose PostScript (*.ps) from the file format dropdown menu.
  3. Choose your destination folder, enter a file name, and click Save.

4. Configure the PostScript Export Dialog

In the export dialog that appears, define the parameters for resolution and PostScript compatibility:

  • PostScript level: Select PostScript Level 3. Level 3 supports advanced color spaces, CMYK shading, and improved vector handling compared to Level 2.
  • Resolution for create raster graphics (dpi): Set this value to 300, 600, or higher depending on your commercial print requirements. Any vector filters, blurs, or drop shadows that cannot be rendered natively as vectors will be rasterized at this DPI setting.
  • Convert texts to paths: Check this box if you need to ensure typography renders identically on machines that do not have your fonts installed.
  • Output page size: Choose whether to export the entire page canvas or only the selected drawing bounds.

Click OK to generate the high-resolution .ps file.

5. Alternative Verification via Ghostscript (Optional)

Inkscape's internal Cairo graphics library may occasionally fall back to RGB for certain rasterized elements. If strict CMYK separation is required by your printing facility, you can alternatively export your file as a PDF with CMYK output enabled, then convert the PDF to a pure CMYK PostScript file via Ghostscript using the terminal command:

gs -dSAFER -dBATCH -dNOPAUSE -sDEVICE=ps2write -sProcessColorModel=DeviceCMYK -sOutputFile=output.ps input.pdf

This guarantees that all embedded vectors and raster components conform strictly to the DeviceCMYK color space without RGB artifacts.
