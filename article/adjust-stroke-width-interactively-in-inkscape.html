Adjust Stroke Width Interactively in Inkscape

In Inkscape, dynamically altering the thickness of a path using on-canvas handles is achieved using the PowerStroke Live Path Effect (LPE) in conjunction with the Node Tool. This feature allows designers to create variable-width strokes—similar to pressure-sensitive brush strokes—without requiring a graphics tablet. By manipulating specialized control points directly on the canvas, you can precisely widen or narrow specific segments of any vector line.

How PowerStroke Works

When you apply the PowerStroke effect to a path, Inkscape adds specialized, diamond-shaped control handles (typically purple or pink) along the line. Selecting the Node Tool (N) activates these handles directly on your canvas. Dragging a handle away from the path increases the stroke thickness at that location, while dragging it inward narrows the stroke.

How to Apply and Use PowerStroke

  1. Draw a Path: Create a line using the Pen Tool (Bézier) (B) or the Pencil Tool (Freehand) (P).
  2. Open Path Effects: With the path selected, open the Path Effects panel by going to Path > Path Effects.
  3. Add PowerStroke: Click the Add Path Effect (+) button, search for PowerStroke, and click to apply it.
  4. Adjust Thickness On-Canvas:
    • Switch to the Node Tool (N).
    • Locate the diamond control handles along the path.
    • Click and drag any handle perpendicular to the line to adjust the width at that point.

Managing Width Handles

You can customize the profile of your stroke by adding or removing control handles:

  • Add a Handle: Hold Ctrl and click on an existing diamond handle to duplicate it, then drag it to a new location along the path.
  • Delete a Handle: Hold Ctrl + Alt and click an existing handle to remove it.
  • Move Along the Path: Simply drag the handle along the length of the path to reposition where the thickness change occurs.

Additional Adjustments

Through the Path Effects dialog, PowerStroke provides additional control over the stroke's appearance:

  • End Caps: Choose between rounded, flat, or peak (pointed) caps for the start and end of the line.
  • Join Types: Control how corners and bends are rendered (round, bevel, or miter).
  • Smoothing: Adjust the interpolation between points to create either gradual, sweeping tapers or sharp transitions.

Once the desired look is achieved, the result can be converted into a standard filled vector shape at any time by selecting Path > Object to Path.
