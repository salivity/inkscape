Use inkex Command to Call Inkscape CLI in Python

The inkex.command module provides Python wrappers around system processes, enabling developers to programmatically execute the Inkscape command-line interface directly from an extension or standalone script. By using the inkscape() wrapper alongside modern Inkscape action sequences, you can chain nested CLI commands, manipulate document nodes, and batch-process files cleanly without manually configuring low-level subprocess pipelines.

Prerequisites and Setup

To use the helper functions, your script must have access to the inkex library, typically provided within Inkscape’s bundled Python environment or via pip install inkex.

Import the inkscape wrapper directly from the command module:

import inkex.command
from inkex.command import inkscape, ProgramRunError

Calling Chained Actions via the Helper

Inkscape versions 1.0 and newer structure nested CLI workflows through the --actions argument. Individual actions are chained using semicolons, allowing multiple operations (such as selecting elements, running path operations, and exporting) within a single CLI call.

The inkex.command.inkscape function accepts command-line flags as keyword arguments or positional parameters:

import inkex.command

input_file = "input.svg"
output_file = "output.png"

# Define nested/chained CLI actions
actions = (
    "select-by-element:path;"
    "path-union;"
    f"export-filename:{output_file};"
    "export-do"
)

try:
    # Execute the nested CLI sequence
    result = inkex.command.inkscape(
        input_file,
        actions=actions,
        batch_process=True
    )
    print("Command executed successfully.")
except inkex.command.ProgramRunError as err:
    print(f"Inkscape CLI failed with code {err.returncode}: {err.stderr.decode()}")

Passing Raw CLI Arguments

If your nested command structure requires custom flags or piping standard input directly into the Inkscape process, pass positional arguments and use the stdin keyword:

import inkex.command

svg_data = '<svg height="100" width="100"><circle cx="50" cy="50" r="40" fill="red" /></svg>'

# Nest commands to transform the input and output SVG to stdout
actions = "select-all;object-to-path;export-plain-svg;export-do"

process_output = inkex.command.inkscape(
    "-",  # Read from stdin
    actions=actions,
    export_type="svg",
    pipe_output=True,
    stdin=svg_data.encode("utf-8")
)

transformed_svg = process_output.stdout.decode("utf-8")

Key Parameter Reference

  • actions: Maps to --actions="...". Use this to nest sequential commands separated by semicolons.
  • batch_process: Maps to --batch-process. Prevents the GUI from launching and closes the process once actions complete.
  • pipe_output: Set to True to capture standard output (stdout) instead of sending it directly to the terminal.
  • stdin: Accepts bytes to pipe directly into the command line when processing dynamic XML or SVG data without saving to disk first.
