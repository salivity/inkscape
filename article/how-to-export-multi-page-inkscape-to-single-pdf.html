How to Export Multi-Page Inkscape to Single PDF

Starting with Inkscape version 1.2, native multi-page document support allows creators to design and manage multiple pages within a single workspace. Exporting all of these pages into a single, unified PDF document is straightforward and can be completed directly through Inkscape’s native save options without needing third-party merging tools.

Prerequisites

Ensure you are using Inkscape version 1.2 or newer, as earlier versions do not support native multi-page document creation.

Step-by-Step Export Instructions

  1. Open Your Document Open your multi-page project in Inkscape and verify that all your artboards or pages are arranged in the desired order using the Pages tool (shortcut: Shift + D).

  2. Open the Save Dialog

    • Click on File in the top menu bar.
    • Select Save a Copy... (or use the shortcut Ctrl + Shift + Alt + S on Windows/Linux or Cmd + Option + Shift + S on macOS). Using Save a Copy is recommended to prevent accidental overwriting of your original .svg file.

  3. Select PDF Format

    • Choose your desired destination folder and enter a file name.
    • Open the Save as type (format) dropdown menu.
    • Select Portable Document Format (*.pdf).
    • Click Save.

  4. Configure PDF Output Settings A dialog window titled Portable Document Format will appear. Configure the following settings:

    • Output Page Size: Choose how you want the page sizes handled (default settings maintain individual page dimensions).
    • Rasterize filter effects / Resolution: Set your DPI (typically 300 DPI for print, 96 DPI for screen display).
    • Text output options: Choose whether to keep text as editable paths or convert text to paths depending on font-embedding requirements.

  5. Finalize Export Click OK. Inkscape will process each page in your document and compile them into a single, multi-page PDF file saved at your chosen location.
