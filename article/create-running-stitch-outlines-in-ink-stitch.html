Create Running Stitch Outlines in Ink/Stitch

This guide provides a straightforward walkthrough for generating clean, delicate running stitch outlines using the free Ink/Stitch extension for Inkscape. You will learn how to properly configure vector paths, adjust stitch length and repetition parameters for fine details, optimize path routing to prevent unnecessary trims, and preview the final design to ensure high-quality machine embroidery results.

1. Draw and Prepare the Vector Path

Running stitches in Ink/Stitch are generated directly from open or closed vector strokes.

  • Select the Draw Bézier curves tool (shortcut: B) or the Pencil tool (shortcut: P) to draw the outline for your delicate detail.
  • Open the Fill and Stroke panel (Ctrl+Shift+F or Cmd+Shift+F).
  • In the Fill tab, ensure fill is completely disabled (click the X icon).
  • In the Stroke paint tab, assign a solid color to your line.
  • In the Stroke style tab, set the line to a continuous, solid dash pattern. Inkscape's visual stroke width does not dictate the physical thread thickness, but setting it between 0.2 mm and 0.4 mm helps visualize the path accurately.

2. Configure Running Stitch Parameters

Once your path is drawn, you must define the embroidery parameters:

  • Select your path.
  • Go to the top menu and click Extensions > Ink/Stitch > Params.
  • A modal window will open with a live preview of the stitch. Ink/Stitch automatically designates a stroke without a fill as a running stitch.
  • Adjust the Running stitch length (mm). For delicate, tight curves, set this between 1.2 mm and 1.8 mm so the thread closely follows the contours. For straighter sections, a standard length of 2.0 mm to 2.5 mm is recommended to prevent excessive needle penetrations.
  • Adjust the Repeats setting. A value of 1 produces a single, ultra-fine line. Setting repeats to 3 converts the line into a "Bean stitch" (triple run), which adds slight prominence to delicate details without requiring a wider satin column.
  • Click Apply and Quit to save the settings to the object.

3. Control Stitch Direction and Path Flow

Machine embroidery requires logical entry and exit points to avoid fabric distortion and unwanted jump threads.

  • Select the Node tool (shortcut: N) to inspect the direction of your path.
  • If you need the needle to start from the opposite end, select the path and go to Path > Reverse.
  • For intricate, multi-line outlines, select all connected strokes and navigate to Extensions > Ink/Stitch > Tools: Stroke > Auto-Route Running Stitch. This automated utility arranges the stitching order and duplicates paths where necessary to ensure continuous sewing without manual jump trims.

4. Simulate and Verify Needle Penetrations

Before exporting the file to your embroidery machine, verify how the needle moves:

  • Navigate to Extensions > Ink/Stitch > Visualize and Export > Simulator/Pre-view.
  • Use the playback controls to monitor stitch placement. Ensure the stitches do not bunch up into dense clusters along sharp corners, as high density can perforate delicate fabrics.
  • Once satisfied, save your working file as an Inkscape SVG to preserve editable parameters, then go to File > Save As... and select your machine's native embroidery format (such as .DST, .PES, or .JEF).
