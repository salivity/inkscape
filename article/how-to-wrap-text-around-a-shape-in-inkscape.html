How to Wrap Text Around a Shape in Inkscape

Wrapping text around the exterior contour of a vector shape in Inkscape allows you to create circular badges, custom logos, and dynamic typography. This guide explains how to use Inkscape’s "Put on Path" tool alongside path offsets to position text seamlessly along the outside boundary of any vector object without overlapping the artwork.

Step 1: Prepare the Vector Shape

  1. Open your document in Inkscape and select your vector shape.
  2. If your shape is an object (such as a standard circle or rectangle), convert it to a path by going to Path > Object to Path.

Step 2: Create an Exterior Offset Guide

Placing text directly on an existing shape aligns the text baseline directly onto the path line, which often causes letters to overlap the shape's fill or stroke. Creating an expanded guide ensures the text sits cleanly on the exterior contour.

  1. Select your shape and duplicate it by pressing Ctrl + D (or Cmd + D on macOS).
  2. With the duplicate selected, enlarge its boundary by going to Path > Outset (keyboard shortcut: Ctrl + )). Repeat this shortcut until you achieve the desired margin around your original shape.
  3. Alternative: Go to Path > Linked Offset and drag the top handle outward to precisely set the exterior distance.

Step 3: Create and Format Your Text

  1. Select the Text tool (T) from the left toolbar.
  2. Click anywhere on the canvas and type your desired text.
  3. Use the top tool controls bar to adjust the font family, font size, and letter spacing before attaching it to the shape.

Step 4: Attach the Text to the Exterior Contour

  1. Switch to the Select and Transform tool (S or F1).
  2. Select both your text object and the offset path simultaneously by holding Shift and clicking on both elements.
  3. Navigate to the top menu and select Text > Put on Path. The text will instantly conform to the contour of the offset path.

Step 5: Adjust Text Position and Orientation

  • Rotate Position: Click twice on the path to activate rotation handles, then rotate the shape. The attached text will follow along the contour.
  • Flip Orientation: If the text appears inverted or inside the shape, select the path (not the text) and click Path > Reverse. You can also use the flip buttons on the top toolbar (Flip selected objects horizontally or vertically) to adjust orientation.

Step 6: Finalize the Design

Once the text is correctly positioned, select only the offset guide shape. Open the Fill and Stroke panel (Ctrl + Shift + F) and set both the Fill and Stroke paint to "No paint" (the X icon). This hides the helper outline while preserving the text's curvature along the exterior contour.
