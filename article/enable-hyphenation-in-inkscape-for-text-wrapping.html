Enable Hyphenation in Inkscape for Text Wrapping

Automating paragraph text wrapping with hyphenation in Inkscape produces balanced, publication-ready typography without manual line breaks. This guide explains how to activate the automated hyphenation setting, configure the required language dictionary, and ensure your text frames wrap hyphenated words correctly.

The Hyphenation Setting in Inkscape

The setting that enables automated hyphenation is the Hyphenate toggle located in the Text Tool controls bar and the Text and Font dialog. However, the hyphenation engine cannot function without assigning an appropriate Language code to the text element, which tells Inkscape which dictionary to load.

Step 1: Create Flowed Text

Hyphenation only works on flowed or framed text, not on regular single-line text objects.

  1. Select the Text tool (shortcut T).
  2. Click and drag on the canvas to create a rectangular text frame.
  3. Type or paste your paragraph content inside the frame.

Step 2: Enable the Hyphenate Option

  1. Keep the text selected with the Text tool.
  2. Look at the Tool Controls bar at the top of the workspace.
  3. Locate and click the Hyphenate button (an icon showing text split with a hyphen).
  4. Alternatively, open the Text and Font panel (Shift + Ctrl + T), navigate to the text formatting options, and check the box for Hyphenation.

Step 3: Specify the Language Dictionary

For Inkscape to apply correct hyphenation patterns, it must know which language rules to use:

  1. Open the Text and Font dialog (Shift + Ctrl + T).
  2. Go to the text properties and locate the Language field.
  3. Enter the standard two-letter or four-letter language code corresponding to your text (such as en-US for American English, en-GB for British English, or de for German).
  4. Click Apply.

Dictionary Requirements

Inkscape relies on standard system hyphenation dictionaries (typically Hunspell or libhyphen dictionaries). If you enable the hyphenation toggle and set the language code but words still do not hyphenate:

  • Linux: Ensure hyphenation packages for your language (e.g., hyphen-en, hyphen-de) are installed via your package manager.
  • Windows & macOS: Inkscape bundles standard dictionaries, but you must ensure the language code entered in the text properties precisely matches an installed dictionary code.
