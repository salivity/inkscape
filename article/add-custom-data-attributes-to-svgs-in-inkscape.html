Add Custom Data Attributes to SVGs in Inkscape

This guide explains how to attach custom data-* attributes to SVG vector elements directly inside Inkscape using its built-in XML Editor. By embedding these custom attributes into your graphic elements, you can easily select, manipulate, and pass dynamic data to vector objects using JavaScript for web interactions, animations, and data visualizations.

Step 1: Open the XML Editor

  1. Open your document and select the vector shape you want to modify.
  2. Open Inkscape's built-in XML tree view by navigating to Edit > XML Editor from the top menu bar, or press the keyboard shortcut Ctrl + Shift + X (Windows/Linux) or Cmd + Shift + X (macOS).

Step 2: Locate the Target Element

  1. When you select a shape on your canvas, the XML Editor automatically highlights the corresponding node in the XML hierarchy tree (typically a <path>, <rect>, <circle>, or <g> tag).
  2. Ensure the correct element node is active before attempting to add attributes.

Step 3: Add the Custom Attribute

  1. In the right-hand panel of the XML Editor, locate the two text fields at the bottom: the attribute name field and the attribute value field.
  2. In the top/left input field (name), type your custom attribute following standard HTML5 data-attribute conventions, such as data-id, data-tooltip, or data-state.
  3. In the larger input field (value), enter the desired value for the attribute.
  4. Click the Set button (or press Enter) to commit the attribute to the selected node. The new attribute will now appear in the list of properties for that element.

Step 4: Save the SVG

Save your file as an Optimized SVG or Plain SVG via File > Save As.... Avoid formats or export cleaners that strip custom data attributes, ensuring that "Remove metadata" or similar aggressive optimization settings leave data-* attributes intact.

Step 5: Access the Attribute via JavaScript

Once the SVG is embedded inline within an HTML document, you can access your custom vector elements and their properties using standard DOM methods:

// Select the vector element by its custom attribute
const shape = document.querySelector('[data-id="my-shape"]');

// Read the value using the dataset API
const shapeId = shape.dataset.id;

// Alternatively, read using getAttribute
const state = shape.getAttribute('data-state');

// Modify the attribute dynamically
shape.dataset.state = 'active';
