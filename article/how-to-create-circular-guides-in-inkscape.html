How to Create Circular Guides in Inkscape

Inkscape does not feature a single-click circular guide tool like its standard rectangular canvas rulers, but you can build precise circular and polar guide systems using built-in extensions and dedicated guide layers. This article covers the fastest methods to generate polar grids, create custom radial spokes, and configure snapping so you can design symmetrical, circular artwork with precision.

Method 1: Use the Built-In Polar Grid Extension

The most efficient way to generate a complete circular guide system is by using Inkscape's native rendering extension.

  1. Open your document and go to Extensions > Render > Grids > Polar Grid...
  2. In the dialog box, configure the following parameters:
    • Circular Divisions: Set the number of concentric rings you need.
    • Circumferential Subdivisions: Set the number of radial angle lines (spokes).
    • Radius: Define the outer radius of the overall grid.
    • Angle/Radius Tick Marks: Enable or disable additional sub-divisions as needed.
  3. Check Live Preview to adjust values in real-time, then click Apply and close the window.

Setting Up the Polar Grid as a Guide Layer

Because the polar grid is generated as vector paths rather than native guides:

  1. Open the Layers and Objects panel (Ctrl + Shift + L).
  2. Create a new layer and name it Guides.
  3. Move the generated polar grid into this layer.
  4. Lower the layer opacity to 30–50% to make it less intrusive.
  5. Lock the layer by clicking the Lock icon to prevent accidental edits while designing.

Method 2: Create Custom Radial Spokes with the Transform Tool

If you only need specific angle intervals rather than a dense grid, you can create radial spokes manually.

  1. Select the Draw Freehand Lines or Draw Bézier Curves tool (B).
  2. Hold Ctrl and draw a straight vertical line through the center of your canvas.
  3. Click the line twice to reveal its rotation center (the small crosshair +).
  4. Drag the rotation center to the exact center point of your design (or snap it to an existing circle center).
  5. Open the Transform panel (Object > Transform or Ctrl + Shift + M) and switch to the Rotate tab.
  6. Enter your desired angle (for example, 30° or 45°).
  7. Duplicate the line (Ctrl + D), then click Apply in the Transform panel.
  8. Repeat the duplicate and rotate process until you complete the 360-degree layout.

Method 3: Convert Radial Lines to Native Inkscape Guides

You can convert vector spokes into native infinite guides to take advantage of Inkscape's built-in guide snapping.

  1. Select the radial lines you created with the Bézier or Transform tool.
  2. Go to Object > Object to Guides (or press Shift + G).
  3. The paths will disappear and convert into native infinite guide lines intersecting at the center angle.

(Note: Standard Inkscape guides are strictly straight infinite lines; concentric circular guides must remain as locked paths on a guide layer).

Configuring Snapping for Circular Guides

To ensure your shapes lock accurately onto your circular guide setup:

  1. Enable the main Snap toggle in the top-right corner of the interface.
  2. Open the Snap Controls popover.
  3. Enable Snap to Paths and Snap to Path Intersections.
  4. Enable Snap to Object Centers and Snap to Guides.

With these snapping options active, your cursor and objects will automatically lock to the concentric rings and radial spokes of your polar guide system.
