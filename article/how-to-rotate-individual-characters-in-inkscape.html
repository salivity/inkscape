How to Rotate Individual Characters in Inkscape

This guide explains how to rotate individual characters within a single, editable text block in Inkscape. By using built-in keyboard shortcuts or the Text tool controls bar, you can adjust the orientation of specific letters without breaking the text block into separate objects or converting the text into paths.

Method 1: Using Keyboard Shortcuts

The fastest way to rotate individual characters while typing or editing is through keyboard shortcuts.

  1. Select the Text tool (shortcut: T or F8) from the left toolbar.
  2. Click inside your text object and place the text cursor immediately before the character you want to rotate, or highlight the specific character.
  3. Hold down Alt and press the bracket keys:
    • Alt + [ : Rotates the character counter-clockwise.
    • Alt + ] : Rotates the character clockwise.
  4. To rotate in larger increments, hold Ctrl + Alt + [ or Ctrl + Alt + ], which turns the character by 90 degrees at a time.

Note: If you have placed the cursor before a letter without selecting it, the rotation applies to that character and all subsequent characters in the line. To rotate only a single letter within a word, highlight just that specific letter before pressing the keys.

Method 2: Using the Text Tool Controls Bar

If you need precise angle values, use the numeric input field in the top toolbar.

  1. Select the Text tool (T).
  2. Highlight the specific character or characters you wish to rotate.
  3. Locate the Character rotation field in the tool controls bar at the top of the screen (represented by an icon showing a tilted letter or a degree symbol).
  4. Type your desired rotation angle in degrees (e.g., 45 for a 45-degree clockwise rotation, or -45 for counter-clockwise) and press Enter.

How to Reset Character Rotation

To return rotated characters back to their default orientation:

  1. Highlight the modified character(s) with the Text tool.
  2. Go to the top tool controls bar and set the Character rotation value to 0.
  3. Alternatively, go to the top menu and select Text > Remove Manual Kerns to reset all rotations, vertical shifts, and horizontal spacing adjustments applied to the selected text.
