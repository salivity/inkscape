How to Generate Vector Barcodes in Inkscape

Inkscape features a powerful built-in tool that allows users to generate fully scalable, print-ready vector barcodes directly within the application. Using the Render extension, you can create standard linear barcodes like EAN, UPC, and Code 128, as well as 2D codes like QR codes. This guide walks you through locating the extension, configuring your barcode settings, and generating crisp vector graphics for product packaging, labels, or digital assets.

Step 1: Open the Barcode Extension

  1. Launch Inkscape and open a new or existing document.
  2. Navigate to the top menu bar and select Extensions.
  3. Hover over Render and then select Barcode.
  4. Choose the appropriate barcode generator from the submenu:
    • Classic: Includes traditional 1D barcodes (EAN-13, UPC-A, Code 39, Code 128, etc.).
    • QR Code: Generates 2D Quick Response codes.
    • DataMatrix: Generates 2D Data Matrix codes.

Step 2: Configure Your Barcode Data

  1. In the extension window, ensure the correct barcode symbology is selected in the Barcode Type dropdown.
  2. In the Text or Barcode Data field, enter the alphanumeric string or numeric sequence you want to encode.
  3. If using standard retail codes like EAN-13 or UPC-A, ensure your input adheres to the required digit length (e.g., 12 or 13 digits). Inkscape can automatically compute and append the final checksum digit for compatible formats.

Step 3: Customize Dimensions and Styling

  1. Adjust the Bar Height to set how tall the vertical lines should appear.
  2. Modify the Module Width or Bar Width to control the overall scaling and scanning density of the code.
  3. Configure the Text visibility settings if you wish to display human-readable numbers beneath the vertical bars.

Step 4: Generate the Vector Object

  1. Click the Live Preview checkbox to view the generated barcode directly on your canvas before finalizing.
  2. Once the barcode looks correct, click Apply and close the dialog box.

Step 5: Edit and Position the Vector Barcode

The generated barcode is inserted as a grouped vector path. You can move, rotate, and scale it proportionally by holding Ctrl while dragging the bounding box handles. To change the color or spacing, select the object and press Ctrl + Shift + G to ungroup the individual vector paths and text elements.
