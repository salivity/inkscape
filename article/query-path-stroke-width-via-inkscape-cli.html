Query Path Stroke Width via Inkscape CLI

This guide explains how to extract element dimensions using the Inkscape command-line interface (CLI) with the --query-all command, how to filter the output for a specific path ID, and how to accurately determine the stroke width of that path given the geometry-focused output of the command.

Understanding the --query-all Flag

The Inkscape CLI includes the --query-all option to extract positional and dimensional data for every object in an SVG document. When executed, Inkscape outputs a comma-separated values (CSV) list with the following format:

id,x,y,width,height

Because --query-all only outputs the bounding box coordinates and dimensions (x, y, width, and height), it does not have a dedicated field for the CSS stroke-width attribute. However, you can retrieve the object's dimensional data and determine the stroke width using the methods below.

Step 1: Querying a Specific Path ID

To isolate a specific path by its ID from the --query-all output, pipe the command output to text processing utilities such as grep or awk.

Using grep:

inkscape --query-all drawing.svg | grep "^path123,"

Using awk:

inkscape --query-all drawing.svg | awk -F, '$1=="path123" {print "ID:", $1, "Width:", $4, "Height:", $5}'

Replace path123 with the target path ID and drawing.svg with your SVG filename.

Step 2: Determining Stroke Width from CLI Geometry

Inkscape calculates bounding boxes based on user preferences: Visual bounding box (includes stroke width) or Geometric bounding box (excludes stroke width).

If you configure Inkscape to toggle these modes, the difference between the visual width and geometric width represents the stroke width.

  1. Query visual bounding box (default in standard UI): 
    inkscape --query-id=path123 --query-width drawing.svg
  2. Calculate the difference: For axis-aligned paths or simple rectangles, subtracting the geometric width from the visual width yields the total stroke width (as stroke is centered along the path outline).

Step 3: Direct Extraction of Stroke Width via XML

Because --query-all is strictly designed for geometric bounding boxes rather than styling attributes, pairing your CLI workflow with an XML parser like xmllint or xmlstarlet is the standard approach to retrieve the exact stroke-width value for that specific ID.

Using xmllint:

xmllint --xpath "string(//*[@id='path123']/@style)" drawing.svg | grep -o 'stroke-width:[^;]*'

Using xmlstarlet (handling direct attributes):

xmlstarlet sel -t -v "//*[@id='path123']/@stroke-width" drawing.svg

If the stroke width is defined inside a style string, extract the specific value with sed:

xmlstarlet sel -t -v "//*[@id='path123']/@style" drawing.svg | sed -n 's/.*stroke-width:\([^;]*\).*/\1/p'
