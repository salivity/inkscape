How to Convert OSM XML to Inkscape Using osm2svg

This guide explains how to convert raw OpenStreetMap (OSM) XML data files into an SVG format using the osm2svg workflow so you can edit map elements natively in Inkscape. Because Inkscape does not natively parse the raw node, way, and relation data stored within .osm XML files, using an intermediary converter like osm2svg transforms geographic coordinates and topology into styled vector paths while retaining layer organization and scalability.

1. Export Your OSM XML Data

  1. Navigate to the OpenStreetMap website.
  2. Pan and zoom to the area of interest.
  3. Click the Export button in the top navigation bar.
  4. Click the blue Export button in the sidebar to download a file named map.osm. For larger areas, use an Overpass API query to extract the .osm XML file to avoid server timeouts.

2. Set Up the osm2svg Utility

The osm2svg workflow utilizes a conversion script (commonly implemented in Python, Perl, or Java depending on your chosen toolchain) designed to parse OSM tags and project spherical coordinates into a flat, 2D Cartesian SVG canvas.

  1. Ensure your environment has the required runtime installed (typically Python 3 or Perl).
  2. Download or clone the osm2svg repository to your local machine.
  3. If using a Python-based implementation, install any required dependencies (such as lxml or pyproj) via your terminal: 
    pip install -r requirements.txt

3. Run the Conversion

Execute the conversion tool through the command line by providing your input .osm file and specifying the output .svg file.

Run the command:

osm2svg -i map.osm -o map.svg

Depending on your specific osm2svg package, you can pass optional flags to define:

  • Projection: Set your desired map projection (e.g., Mercator or local UTM zones).
  • Rule/Style sheets: Apply a predefined CSS or XML style sheet to automatically categorize highways, waterways, and buildings into separate visual classes.
  • Bounding Box: Restrict rendering strictly to a specified coordinate boundary.

4. Import and Edit in Inkscape

  1. Open Inkscape.
  2. Go to File > Open and select your newly generated map.svg file.
  3. Choose Include SVG as editable object if prompted.
  4. Open the Layers and Objects panel (Layer > Layers and Objects...) to view the converted structure.
  5. Ungroup elements (Ctrl + Shift + G or Cmd + Shift + G) as needed to select, modify, recolor, or delete specific paths such as roads, land boundaries, or points of interest.
  6. Adjust document boundaries via File > Document Properties > Resize to content to match your map's exact dimensions.
