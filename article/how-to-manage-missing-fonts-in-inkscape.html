How to Manage Missing Fonts in Inkscape

When you open an Inkscape document on a computer that does not have the original fonts installed, Inkscape automatically substitutes them with default system fonts, which can disrupt your layout and styling. This guide explains how to identify missing fonts, substitute them using Inkscape's built-in tools, install the required fonts on your system, and convert text to paths to prevent font compatibility issues entirely.

1. Identify and Replace Fonts Using the Text and Font Tool

If a font is missing, Inkscape uses a fallback font. You can manually assign a new, available font using the Text and Font dialog:

  1. Select the text element on your canvas.
  2. Open the Text and Font panel by pressing Shift + Ctrl + T (or navigate to Text > Text and Font).
  3. The original missing font may appear with a warning icon or a strikethrough.
  4. Browse the font list, choose an installed alternative font that fits your design, and click Apply.

2. Install the Missing Fonts on the New Computer

To keep the text editable with its original appearance, install the required font files directly onto the target computer:

  1. Obtain the font file (.ttf or .otf) from the original computer or a licensed font provider.
  2. Install the font on the operating system:
    • Windows: Right-click the font file and select Install or Install for all users.
    • macOS: Double-click the font file and click Install Font in Font Book.
    • Linux: Copy the font file to ~/.local/share/fonts/ or /usr/share/fonts/, then refresh the font cache using the terminal command fc-cache -f -v.
  3. Restart Inkscape so it can detect the newly installed font.

3. Convert Text to Paths (Permanent Solution for Distribution)

If you do not need to edit the text on the new computer and want to guarantee that the artwork renders identically everywhere, convert the text into vector shapes before transferring the file:

  1. Open the file on the original computer where the font is installed.
  2. Select the text objects.
  3. Go to the menu and select Path > Object to Path (or press Shift + Ctrl + C).
  4. Save the file (or save a copy to preserve an editable version).

Once converted to paths, the text becomes standard vector curves and no longer requires any font files to display correctly.
