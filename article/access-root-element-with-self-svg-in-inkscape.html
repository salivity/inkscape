Access Root Element with self.svg in Inkscape

This article explains how to target and manipulate the document root element in an Inkscape Python extension using the self.svg property. In modern Inkscape development (Inkscape 1.0 and later), the inkex module wraps the XML document tree into high-level objects, making the self.svg property the primary interface for interacting directly with the root <svg> node.

In Inkscape extensions inheriting from inkex.EffectExtension, the self.svg property references the SvgDocumentElement instance, which represents the root <svg> tag of the document. Unlike older versions of Inkscape that required calling self.document.getroot(), modern inkex extensions treat self.svg directly as the root element itself.

To read or update attributes on the root element, you can treat self.svg like a standard dictionary or use dedicated helper methods:

import inkex

class MyExtension(inkex.EffectExtension):
    def effect(self):
        # Access the root element directly
        root = self.svg

        # Read root attributes
        width = root.get('width')
        height = root.get('height')
        viewbox = root.get('viewBox')

        # Modify root attributes
        root.set('data-processed', 'true')
        root.set('id', 'main-svg-root')

if __name__ == '__main__':
    MyExtension().run()

Because self.svg functions as the root DOM node, you can also query, iterate, or append child elements directly from this property. For example, to add a new element to the top level of the document:

# Create a new circle element
new_circle = inkex.Circle(cx="50", cy="50", r="20")

# Append the element directly to the root
self.svg.append(new_circle)

To search for child elements starting from the root, use the built-in XPath and search methods provided by self.svg:

# Find all path elements anywhere under the root
all_paths = self.svg.xpath('//svg:path')

# Find direct children of the root
direct_children = list(self.svg)

If your extension requires the raw lxml root element rather than the wrapped inkex.SvgDocumentElement, you can still call self.document.getroot(). However, using self.svg is the standard and recommended approach because it provides built-in units handling, viewBox calculations, and geometric utility methods natively supported by modern inkex.
