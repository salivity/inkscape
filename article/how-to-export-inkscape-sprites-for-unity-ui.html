How to Export Inkscape Sprites for Unity UI

Exporting vector game sprites from Inkscape to Unity for user interface (UI) elements involves optimizing your vector artwork, choosing the right file format, and configuring the assets correctly within Unity's Canvas system. This guide covers the preparation of your artwork in Inkscape, exporting as either high-resolution PNGs or native SVGs, and configuring the Unity import settings to ensure crisp rendering on any screen resolution.

1. Prepare Vector Artwork in Inkscape

Before exporting, organize your artwork to ensure clean geometry and proper alignment:

  1. Align to Pixel Grid: Turn on snapping (% key) and snap paths to the pixel grid to prevent blurry anti-aliasing edges.
  2. Combine Elements: Group individual UI components (Ctrl + G) or combine related paths (Path > Union or Ctrl + +) so each sprite functions as a single object.
  3. Fit Canvas to Selection: Select your finished UI element, go to File > Document Properties (Shift + Ctrl + D), expand Resize to content, and click Resize page to drawing or selection. This eliminates empty margins around your sprite.

2. Exporting the Sprites

You can export your vectors in two ways: as scalable vector files (SVG) using Unity's Vector Graphics package, or as pre-rasterized high-density PNG files.

Option A: Export as Plain SVG (Resolution-Independent)

To use native vectors directly inside Unity UI:

  1. Go to File > Save As....
  2. Choose Plain SVG (*.svg) from the file type dropdown (avoid "Inkscape SVG" to remove editor-specific metadata).
  3. Save the file directly into your Unity project's Assets directory.

Option B: Export as High-Resolution PNG (Standard Raster Sprites)

If you prefer traditional raster sprites without runtime tessellation overhead:

  1. Open the Export panel via File > Export (Shift + Ctrl + E).
  2. Set the export area to Selection or Page.
  3. Under Advanced, ensure the DPI is set appropriately for your target screen densities (for example, 192 DPI or 300 DPI for high-DPI/Retina screens).
  4. Select PNG as the format and click Export As to save the file into your Unity project's Assets folder.

3. Setting Up Unity for Vector Sprites

If you exported as an SVG, Unity requires the official vector package to parse the format:

  1. In Unity, open Window > Package Manager.
  2. Select Packages: Unity Registry.
  3. Search for Vector Graphics and click Install.

4. Configure Import Settings in Unity

Once the assets appear in the Unity Project window, configure their import parameters so they can be assigned to UI elements:

  1. Select the imported SVG or PNG file in the Project window.
  2. In the Inspector, set Texture Type to Sprite (2D and UI).
  3. If using an SVG via the Vector Graphics package:
    • Set Generated Asset Type to Vector Sprite.
    • Adjust the Resolution (pixels per unit) to scale the vector properly relative to your Canvas.
  4. If using a PNG:
    • Set Sprite Mode to Single (or Multiple if you exported a sprite sheet).
    • Uncheck Generate Mip Maps to preserve sharp edges for 2D UI.
    • Set Filter Mode to Bilinear (or Point (no filter) for pixel art).
  5. Click Apply.

5. Assign to Unity UI Elements

  1. In the Hierarchy, create a UI Image by right-clicking and selecting UI > Image.
  2. Select the newly created Image object.
  3. Drag your imported sprite from the Project window into the Source Image slot in the Inspector.
  4. Click Set Native Size on the Image component to match the original proportions established in Inkscape.
