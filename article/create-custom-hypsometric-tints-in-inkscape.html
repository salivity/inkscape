Create Custom Hypsometric Tints in Inkscape

Hypsometric tinting is the cartographic practice of applying color bands to topographic maps to visually depict elevation above sea level. This article explains how to build, customize, and apply multi-stop hypsometric color ramps in Inkscape using vector gradient tools, custom stops, and palette management to enhance contour maps and digital elevation models.

1. Establish the Elevation Color Sequence

Before creating the ramp in Inkscape, determine your elevation hierarchy and select a color progression. Traditional cartographic hypsometric ramps follow natural terrain transitions:

  • Lowlands / Depressions: Deep greens to light greens.
  • Low Plateaus / Foothills: Yellow-greens to warm yellows.
  • Mid-Elevations / Mountains: Buffs, oranges, and warm browns.
  • High Alpine / Peaks: Cool grays, slate, and pure white.

Ensure the values maintain high contrast against your hillshade or contour linework.

2. Create the Base Gradient Object

  1. Open Inkscape and select the Rectangle Tool (R).
  2. Draw a tall, narrow rectangle on the canvas to serve as the master ramp template.
  3. Open the Fill and Stroke panel (Shift + Ctrl + F).
  4. Under the Fill tab, click the Linear Gradient icon. Inkscape will apply a default two-stop gradient across the shape.

3. Insert and Configure Intermediate Stops

To represent distinct elevation levels, you must divide the gradient into multiple color stops.

  1. Select the Create and Edit Gradients Tool (G).
  2. Click on the gradient line running through your rectangle. Handles will appear at both ends.
  3. Double-click anywhere along the line to add a new gradient stop. Add as many stops as you have elevation intervals.
  4. Drag each stop along the line to match your target elevation proportions (e.g., placing lowland colors closer together if the terrain rises steeply).
  5. Click on an individual stop handle to select it, then choose your intended tint from the Fill and Stroke color wheel or paste a specific hex code.
  6. Repeat this process for each elevation tier from sea level (bottom) to summit (top).

4. Convert Continuous Gradients to Stepped Bands (Optional)

If your topographic map uses discrete contour levels rather than continuous shading:

  1. Duplicate stops at identical positions along the gradient line.
  2. Position two stops with different colors immediately adjacent to each other. This creates a hard edge between elevation zones instead of a smooth blend.
  3. Alternatively, draw separate vector shapes for each elevation band, apply the corresponding color to each, and group them vertically.

5. Save and Export the Tint Ramp

To reuse the custom hypsometric ramp across different cartographic projects:

  1. Open the Swatches panel (Shift + Ctrl + W).
  2. With the gradient selected, click the Add Gradient to Swatches option.
  3. To export the palette for external GIS software or future Inkscape documents, go to Extensions > Export > Export Swatches or save the gradient definition within an Inkscape template file in your user templates directory.

6. Apply the Ramp to Topographic Layers

  • For Vector Polygons: Import your vectorized elevation contours. Select all elevation layers and use the Extensions > Generate from Path > Interpolate Attribute tool, or manually sample colors from your custom ramp using the Dropper Tool (D).
  • For Raster Underlays: If you are coloring a grayscale hillshade or DEM, place the raster layer directly beneath your gradient, set the gradient layer's blend mode to Multiply or Overlay in the Layers and Objects panel, and adjust opacity to achieve proper terrain depth.
