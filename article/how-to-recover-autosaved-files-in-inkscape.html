How to Recover Autosaved Files in Inkscape

Unexpected crashes in Inkscape do not necessarily mean your unsaved work is permanently lost. Inkscape features an automated backup system that regularly saves emergency snapshots of your active documents. This guide outlines how to find the default autosave directories across different operating systems, locate your recovered files, and properly restore your project.

Step 1: Check Default Autosave Locations

When Inkscape crashes, it attempts to generate an emergency document. If Autosave is enabled, it periodically saves timestamped .svg files to a specific directory on your computer.

  • Windows: Check C:\Users\<YourUsername>\ or C:\Users\<YourUsername>\AppData\Local\Microsoft\Windows\INetCache\inkscape
  • macOS: Check /Users/<YourUsername>/ (your user Home folder)
  • Linux: Check /home/<YourUsername>/ (your user Home folder) or /tmp/

Autosaved files are typically named using the original file name appended with the date, time, and an index (for example: drawing_2023_10_25_14_30_00_0000.svg or New document 1.svg).

Step 2: Verify Your Specific Autosave Directory

If you cannot find the files in the default folders, look up the exact path configured inside Inkscape's settings:

  1. Open Inkscape.
  2. Go to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left sidebar, expand Input/Output and select Autosave.
  4. Look at the Autosave directory (folder) field. If this field is blank, Inkscape saves backups to your user home directory. If a path is specified, navigate to that exact folder using your file manager.

Step 3: Open and Re-save the Backup

  1. Open your system's file manager and navigate to the autosave directory.
  2. Sort the folder contents by Date Modified to easily spot the most recent file.
  3. Open the latest .svg backup directly in Inkscape.
  4. Verify your artwork, then navigate to File > Save As....
  5. Save the file in your intended project directory with your preferred filename to resume normal working operations.

Optimizing Autosave Settings for Future Crashes

To prevent data loss in future sessions, ensure the backup feature is properly configured:

  1. Navigate to Edit > Preferences > Input/Output > Autosave.
  2. Ensure the Enable autosave box is checked.
  3. Set the Interval (in minutes) to a frequent duration, such as 5 to 10 minutes.
  4. Set the Maximum number of backups to at least 10 or 20 to maintain a rolling history of changes without consuming excessive disk space.
