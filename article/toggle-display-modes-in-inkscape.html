Toggle Display Modes in Inkscape

Inkscape provides multiple display modes—Normal, No Filters, and Outline—allowing you to inspect vector paths, manage system performance, and debug complex artwork. This guide explains what each display mode does and how to quickly switch between them using the main menu and keyboard shortcuts.

Understanding the Display Modes

  • Normal: The default rendering mode. It displays all fills, strokes, gradients, patterns, and complex SVG filter effects (such as blurs and drop shadows) exactly as they will appear in final exports.
  • No Filters: Renders full colors, strokes, and fills but disables SVG filters and gaussian blurs. This significantly speeds up canvas rendering when working on intricate, resource-heavy documents.
  • Outline (Wireframe): Strips away all fills, strokes, colors, and opacity, displaying only the underlying geometric wireframes and path lines. This mode is ideal for locating hidden objects, aligning overlapping paths, and precision node editing.

Method 1: Using the Top Menu

  1. Click on View in the top menu bar.
  2. Hover your cursor over Display mode.
  3. Select your preferred mode from the submenu:
    • Normal
    • No Filters
    • Outline

Method 2: Using Keyboard Shortcuts

You can cycle or jump between display modes without opening the menu:

  • Toggle Outline Mode: Press Ctrl + Keypad 5 (Windows/Linux) or Cmd + Keypad 5 (macOS) to switch between Normal and Outline mode.
  • Cycle Display Modes: Depending on your configuration and Inkscape version, pressing Ctrl + Shift + Keypad 5 cycles through the available rendering modes.

Using Split View and X-Ray Modes (Inkscape 1.0+)

Modern versions of Inkscape also include interactive viewing options within the same menu:

  • Split View Mode: Splits your canvas with an interactive divider, showing the standard view on one side and the Outline view on the other.
  • X-Ray Mode: Creates a circular viewing lens around your cursor that reveals the Outline/Wireframe view beneath your cursor while keeping the rest of the canvas in Normal mode.

To access these, navigate to View > Display mode > Split View Mode or X-Ray Mode.
