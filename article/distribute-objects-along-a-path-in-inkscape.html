Distribute Objects Along a Path in Inkscape

Distributing objects evenly along an irregular curved line in Inkscape can be achieved quickly without manually repositioning each element. This article explains how to use Inkscape’s native tools—specifically the "Pattern Along Path" Live Path Effect and the "Scatter" extension—to place single or repeated shapes along any arbitrary curve with consistent spacing.

Method 1: Using the "Pattern Along Path" Path Effect

This method provides non-destructive, real-time control over spacing and orientation along your curve.

  1. Prepare Your Elements:

    • Draw your irregular curved line using the Draw Freehand Lines tool (Pencil / P) or the Draw Bezier Curves tool (Pen / B).
    • Create or select the object you want to distribute.
    • Convert your object to a path if it is a primitive shape or text: select it and go to Path > Object to Path (Ctrl + Shift + C).

  2. Copy the Pattern Object:

    • Select the object you want to place along the curve and press Ctrl + C to copy it to your clipboard.

  3. Apply the Path Effect:

    • Select your curved guide line.
    • Open the Path Effects panel via Path > Path Effects.
    • Click the + (Add Path Effect) button, search for Pattern Along Path, and select it.

  4. Configure the Distribution:

    • In the Path Effects settings, locate the Pattern source row and click the Link to clipboard path icon (or the Paste path icon).
    • Change the Pattern copies dropdown to Repeated.
    • Adjust the Spacing field to set the exact distance between each instance. Increasing or decreasing this value will recalculate the placement evenly across the total length of the curve.
    • If objects overlap at sharp bends, lower the pattern size or increase spacing to maintain separation.

Method 2: Using the "Scatter" Extension

If you prefer generating static, independent duplicates directly onto the curve:

  1. Prepare Your Shapes:

    • Ensure both the curve and the object are converted to paths (Path > Object to Path).
    • Ensure the object you want to duplicate is placed higher in the Z-order (stacking order) than the path. Select the object and press Home (or Object > Raise to Top).

  2. Select Both Paths:

    • Hold Shift and click the object first, then the curved line.

  3. Open the Scatter Tool:

    • Navigate to Extensions > Generate from Path > Scatter.

  4. Adjust Placement Parameters:

    • Check the Live preview box to see updates in real time.
    • Set Follow path orientation to maintain alignment with the curve's direction, or uncheck it to keep the original rotation.
    • Adjust the Space between copies to set uniform gaps along the line.
    • Click Apply to generate the duplicates as distinct vector paths.
