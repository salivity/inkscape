Write an Inkscape Python Extension for SVG clipPath

This article outlines how to create a custom Inkscape extension using Python and the inkex library to directly locate and modify SVG <clipPath> definitions. By creating a standard two-file extension setup consisting of an INX XML descriptor and a Python script, you can query SVG elements, extract referenced clipping paths from the document definitions, and programmatically alter their geometric data or styling attributes.

Extension Architecture

An Inkscape extension requires two files placed in the user extensions directory (~/.config/inkscape/extensions/ on Linux/macOS or %APPDATA%\inkscape\extensions\ on Windows):

  1. An INX file (.inx): Defines the menu entry, parameters, and metadata for the Inkscape GUI.
  2. A Python script (.py): Contains the execution logic utilizing the inkex framework.

1. Define the INX Descriptor

Create a file named modify_clippath.inx. This file instructs Inkscape how to display the tool in its menu hierarchy and which script to execute.

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>Modify ClipPath</name>
    <id>org.example.modify_clippath</id>
    <param name="scale_factor" type="float" min="0.1" max="10.0" gui-text="Scale Clip Shape:">1.2</param>
    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Modify"/>
        </effects-menu>
    </effect>
    <script>
        <command location="inx" interpreter="python">modify_clippath.py</command>
    </script>
</inkscape-extension>

2. Create the Python Script

Create modify_clippath.py in the same directory. The script subclasses inkex.EffectExtension, parses arguments defined in the .inx file, and manipulates the DOM elements representing <clipPath>.

import inkex
from inkex import Transform

class ModifyClipPath(inkex.EffectExtension):
    def add_arguments(self, pars):
        pars.add_argument(
            "--scale_factor",
            type=float,
            default=1.2,
            help="Scale factor for the clipPath geometry"
        )

    def effect(self):
        scale = self.options.scale_factor

        # Iterate over all selected elements, or all elements if none selected
        elements = self.svg.selection.values() or self.svg.xpath('//*[@clip-path]')

        for elem in elements:
            # Extract the clip-path attribute (format: 'url(#clipPathId)')
            clip_url = elem.get('clip-path')
            if not clip_url:
                continue

            # Parse the ID from the URL reference
            clip_id = clip_url.strip().replace('url(#', '').rstrip(')')
            clip_path = self.svg.getElementById(clip_id)

            if clip_path is None or clip_path.TAG != 'clipPath':
                continue

            # Modify child elements inside the <clipPath>
            for child in clip_path:
                # Apply a transformation matrix directly to child elements
                t = Transform(f"scale({scale})")
                child.transform = child.transform @ t

if __name__ == '__main__':
    ModifyClipPath().run()

Key Technical Operations

  • Locating Clip Paths: Inkscape stores clipping objects inside the document's <defs> container as <clipPath id="..."> elements. Elements reference them using the clip-path="url(#id)" attribute.
  • Resolving Elements: Use self.svg.getElementById(clip_id) to resolve the ID string extracted from the attribute string into an inkex.ClipPath instance.
  • Modifying Direct Geometries: You can modify attributes of shapes inside the <clipPath> element directly (such as d on <path>, r on <circle>, or transform on any child shape).
  • Updating Document State: The inkex.EffectExtension class automatically handles document parsing, synchronization, and output generation; changes made to the XML tree during effect() are saved automatically back to the current Inkscape canvas.

Running the Extension

  1. Save modify_clippath.inx and modify_clippath.py in your Inkscape extensions folder.
  2. Restart Inkscape or run Edit > Check for Extensions.
  3. Select an object with an assigned clip path.
  4. Run the extension via Extensions > Modify > Modify ClipPath.
