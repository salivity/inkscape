Convert Gradients to Solid Flat Colors in Inkscape

Converting gradient fills and strokes into solid flat colors across an entire Inkscape document can be done quickly without manually selecting each object one by one. By utilizing Inkscape’s Find/Replace feature to query gradient definitions in object styles, you can select every gradient-filled element on your canvas at once and switch their fill or stroke properties to a flat color in the Fill and Stroke dialog.

Step 1: Unlock All Layers and Objects

To ensure Inkscape searches the entire document, make sure no objects or layers are hidden or locked.

  1. Open the Layers and Objects panel by pressing Ctrl + Shift + L.
  2. Ensure all layer eye icons are open (visible) and lock icons are unlocked.
  3. Go to the top menu and click Edit > Unlock All to ensure no grouped or individual paths are restricted.

Step 2: Select All Gradient Objects with Find/Replace

Inkscape stores gradients internally as URL references (such as url(#linearGradient...)). You can locate all elements using this style attribute.

  1. Press Ctrl + F to open the Find/Replace dialog.
  2. Clear any text from the Find input field.
  3. Expand the search options by clicking the arrow next to Properties.
  4. In the Style field, type: url(#
  5. Under the Search in section, check All (or check Selection if you only want to affect a specific group).
  6. Click Find. Inkscape will automatically select every object across your canvas that contains a gradient fill or stroke.

Step 3: Switch Fills to Flat Color

With all gradient objects selected:

  1. Open the Fill and Stroke panel by pressing Shift + Ctrl + F.
  2. Go to the Fill tab.
  3. Click the Flat color icon (the solid square next to the "No paint" X icon).
  4. Inkscape will convert the gradient fills into a uniform solid color. You can now use the color wheel, sliders, or the bottom palette to define the desired flat color.

Step 4: Switch Stroke Gradients (If Applicable)

If your artwork also uses gradients along outlines or strokes:

  1. Keep the objects selected (or repeat the Find/Replace step if deselected).
  2. In the Fill and Stroke panel, switch to the Stroke paint tab.
  3. If any strokes use gradients, click the Flat color icon to convert them to solid lines.

Step 5: Clean Up Unused Gradient Definitions

After converting the gradients to solid colors, the original gradient definitions remain stored in the document's XML code. To reduce file size and keep your SVG clean:

  1. Go to File in the top menu.
  2. Select Clean Up Document (in older versions, this is labeled Vacuum Defs).
  3. Save your file (Ctrl + S).
