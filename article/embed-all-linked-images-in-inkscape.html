Embed All Linked Images in Inkscape

Embedding externally linked raster images into your Inkscape SVG makes the file completely self-contained and portable, preventing broken image links when sharing or moving your files. Instead of manually re-importing or embedding each graphic one by one, Inkscape provides a built-in extension that allows you to convert all linked bitmap images into embedded assets simultaneously.

Steps to Batch Embed Linked Images

  1. Open Your SVG File: Launch Inkscape and open the document containing the linked raster images you want to embed.
  2. Access the Image Extension: In the top menu bar, click on Extensions, hover over Images, and select Embed Images....
  3. Configure the Settings: A dialog window will appear with several options:
    • Selected images only: Leave this box unchecked to process all linked images throughout the entire document.
    • Embed only images whose path contains: Leave this field blank to include all file paths, or enter specific text if you only want to target certain directories.
  4. Apply the Changes: Click the Apply button. Inkscape will process the file, convert all linked image data into Base64-encoded strings, and store them directly inside the SVG code.
  5. Close the Dialog: Once the progress bar finishes, click Close.
  6. Save the Document: Go to File > Save (or press Ctrl + S / Cmd + S) to write the embedded images to your file.

Important Considerations

  • File Size: Embedding raster images will increase the overall SVG file size substantially, as the image data is stored directly within the XML text.
  • Original Links: Once an image is embedded, changes made to the external source file on your hard drive will no longer update automatically inside the Inkscape document.
