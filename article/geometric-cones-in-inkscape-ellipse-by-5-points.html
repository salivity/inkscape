Geometric Cones in Inkscape: Ellipse by 5 Points

This guide demonstrates how to construct mathematically precise geometric cones in Inkscape using the Ellipse by 5 Points Live Path Effect (LPE). By defining five distinct coplanar points, you can generate a true perspective or oblique ellipse for the base, establish an apex, and project exact tangent lines to produce a clean, geometrically sound cone suitable for technical drawing and vector illustration.

1. Understanding the 5-Point Conic Principle

In projective geometry, any conic section—including an ellipse representing a circular base in perspective—is uniquely determined by five points in a plane, provided no four are collinear. Inkscape’s Ellipse by 5 Points LPE calculates this exact conic path dynamically from a five-node path, eliminating the guesswork of using manual Bezier handles.

2. Plotting the 5 Base Points

  1. Enable the Snap Controls Bar (%) and activate snapping to the grid, guides, or bounding boxes to ensure precision.
  2. Select the Pen (Bezier Curves and Straight Lines) tool (B).
  3. Click on the canvas to place five distinct nodes that represent the perimeter of your intended base.
    • For an axonometric or perspective projection, place points corresponding to the front, back, lateral extremes, or known projective coordinates of your base circle.
  4. Press Enter to finalize the open path.

3. Applying the Live Path Effect

  1. Select the five-node path using the Selector tool (S).
  2. Open the Path Effects panel by navigating to Path > Path Effects.
  3. Click the Add Path Effect button (+).
  4. Locate and select Ellipse by 5 Points from the list.
  5. Inkscape immediately solves the quadratic equation for the five nodes and renders a smooth, closed ellipse traversing all five points.
  6. Switch to the Node tool (N) if you need to adjust any of the five control points. The ellipse recalculates and updates in real time.

4. Establishing the Apex and Drawing Tangents

  1. Use the Pen tool (B) to place a single point above the ellipse to act as the cone's apex.
  2. In the snapping panel, turn on Snap to paths and Snap to tangents.
  3. Activate the Pen tool, click on the apex point, and drag the line toward the outer curvature of the ellipse until the tangent snap indicator appears.
  4. Click to place the tangent point on the ellipse, and press Enter.
  5. Repeat this process from the apex to the opposite side of the ellipse to create the second silhouette edge.

5. Finalizing the Cone Structure

  1. To split the base ellipse into visible and hidden geometry, convert the LPE to a static path via Path > Object to Path.
  2. Select the ellipse with the Node tool (N), insert new nodes exactly where the tangent lines meet the curve, and use Break path at selected nodes to split the path.
  3. Apply a solid stroke to the foreground half of the base and the silhouette edges.
  4. Style the rear arc of the ellipse with a dashed stroke to depict hidden lines, or remove it entirely for a shaded 3D rendering.
