How to Design Embroidery Patterns with Ink/Stitch

Designing embroidery patterns with the free, open-source Ink/Stitch extension transforms the vector graphics software Inkscape into a full-featured digitizing suite. This guide outlines the entire digitizing workflow, from setting up your document and creating compatible vector artwork to configuring specific stitch types—such as running, satin, and fill stitches—running stitch simulations, and exporting the final design into machine-readable embroidery formats like PES or DST.

1. Document Setup and Hoop Sizing

Before creating artwork, set up the workspace to match your physical embroidery hoop:

  1. Open Inkscape and navigate to File > Document Properties.
  2. Change the display units to mm or in (standard for embroidery).
  3. Set the custom page width and height to match your specific embroidery hoop dimensions.
  4. Keep all artwork within these page boundaries to avoid design clipping.

2. Preparing Vector Artwork

Ink/Stitch converts vector paths into needle movements. Vector graphics must be clean and organized:

  • Convert Objects to Paths: Select all shapes or text and go to Path > Object to Path.
  • Ungroup and Simplify: Ungroup all grouped elements (Object > Ungroup) and eliminate redundant nodes (Path > Simplify or using the Node Tool).
  • Separate Fill and Stroke: In Inkscape, an object should generally contain either a fill or a stroke, not both. Duplicate the object if you need both a filled shape and an outline.

3. Configuring Embroidery Stitch Types

Ink/Stitch uses stroke and fill properties to determine the stitch type:

Running Stitch (Outlines and Details)

  • Create an open or closed path with a simple stroke color and no fill.
  • Set the stroke style in the Fill and Stroke panel (Shift + Ctrl + F) to a solid line.
  • To create a manual running stitch, use a simple line. To create a bean/triple stitch, adjust the stitch repeat value in the Ink/Stitch parameter window.

Fill Stitch (Tatami)

  • Create a closed vector path with a solid fill and no stroke.
  • Ensure the path does not self-intersect.
  • Ink/Stitch automatically calculates the Tatami grid fill, including underlay stitches, based on the shape.

Satin Column (Borders and Lettering)

  • A satin column requires a single path composed of two sub-paths (rails) running in the same direction, connected by cross-lines (rungs) if necessary.
  • Select two parallel lines and join them into a single path using Path > Combine.
  • In the node editor, ensure the direction of both sub-paths aligns from start to finish.

4. Adjusting Parameters

Fine-tune your stitch properties using the Ink/Stitch parameter editor:

  1. Select the object or path you want to configure.
  2. Go to Extensions > Ink/Stitch > Params.
  3. A live preview window will open with configuration options:
    • Stitch Length: Sets the distance between needle penetrations.
    • Spacing (Density): Controls the distance between rows in fill and satin stitches.
    • Angle: Defines the direction of the fill or satin stitch lines.
    • Pull Compensation: Expands the shape slightly perpendicular to the stitch angle to counteract fabric pull.
    • Underlay: Adds stabilizing stitches beneath top layers to prevent fabric puckering.
  4. Click Apply and Quit once settings are dialed in.

5. Organizing Stitch Order

Embroidery machines stitch objects based on the layer and object stack:

  • Open the Objects and Layers panel (Layer > Layers and Objects...).
  • Arrange objects from bottom to top; the machine stitches elements at the bottom of the list first.
  • Group like colors together to minimize thread changes.
  • Use Extensions > Ink/Stitch > Tools: Stroke > Auto-Route Running Stitch to optimize path routing and reduce jump stitches.

6. Simulating and Validating the Design

Before sending the file to an embroidery machine, run the visual validation checks:

  1. Check for Errors: Run Extensions > Ink/Stitch > Troubleshoot > Troubleshoot Objects to identify unclosed paths, invalid satin rails, or overlapping nodes.
  2. Run the Simulator: Go to Extensions > Ink/Stitch > Visualize and Export > Simulator/Realistic Preview.
  3. Inspect needle penetration points, stitch order, trims, and jump stitches in the visual playback window.

7. Exporting to Machine Formats

Once validated, save the file into your embroidery machine's proprietary format:

  1. Go to File > Save a Copy... (keep the original .svg file for future editing).
  2. Select your machine's file extension from the drop-down menu (e.g., .pes for Brother/Babylock, .dst for Tajima, .jef for Janome, or .exp for Bernina/Melco).
  3. Transfer the exported file to your embroidery machine via USB or direct connection.
