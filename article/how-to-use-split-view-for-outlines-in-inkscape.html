How to Use Split View for Outlines in Inkscape

Inkscape’s Split View mode allows designers to inspect the underlying vector paths and wireframe geometry of an illustration while simultaneously previewing the fully rendered artwork. This guide explains how to enable Split View mode, manipulate the interactive on-canvas divider, and use wireframe outlines to troubleshoot hidden paths, overlapping nodes, and alignment issues in your SVG projects.

What is Split View Mode?

Split View mode divides the Inkscape canvas with an interactive separator bar. One side of the bar displays your artwork in standard rendering with full colors, gradients, and filters, while the other side displays a pure outline (wireframe) mode. This enables real-time vector inspection without constantly toggling between different display modes.

How to Enable Split View Mode

  1. Open your vector project in Inkscape.
  2. Navigate to the top menu bar and select View.
  3. Hover over Display Mode or look directly for Split View (depending on your Inkscape version).
  4. Select Split View (or press the corresponding toggle icon located in the top-right control bar of the canvas window).

Once activated, a vertical divider line will appear across your drawing canvas.

Navigating and Adjusting the Split Controller

  • Move the Divider: Hover your cursor over the divider line until the cursor changes to a double-sided arrow. Click and drag left or right to reveal more or less of the outline view.
  • Inspect Hidden Geometry: Position the divider directly over complex sections of your design. The outline side reveals hidden objects, stray nodes, invisible clipping paths, and duplicate overlapping strokes that might not be visible in normal render mode.
  • Edit in Real Time: You can select, move, and edit nodes using the Node Tool (N) or Selector Tool (S) on either side of the split divider. Any changes made on the outline side immediately reflect on the rendered side.

Key Use Cases for Outline Inspection

  • Finding Duplicate Paths: Identify unnecessary duplicate lines that can cause issues with plotters, laser cutters, or CNC machines.
  • Fixing Masking and Clipping Errors: View the actual boundaries of clipped paths that are visually hidden behind clipping masks.
  • Precise Node Snapping: Align complex paths precisely to edges or nodes without visual interference from thick stroke widths or blur effects.

How to Exit Split View Mode

To return to the standard editing interface:

  1. Click on the View menu at the top.
  2. Go to Display Mode and select Normal.
  3. Alternatively, toggle off the Split View icon in the canvas corner to restore the default canvas view.
