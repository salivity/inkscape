Inkscape Difference on Non-Overlapping Objects

Applying the Difference path operation to two non-overlapping objects in Inkscape results in the deletion of the top object while leaving the bottom object completely unchanged. Because the Difference tool functions as a boolean subtraction where the upper shape acts as a cutting stencil for the lower shape, a lack of intersection means there is nothing to cut away. Consequently, Inkscape consumes the cutting object and leaves the target object intact.

How the Difference Operation Functions

In Inkscape, the Difference command (Path > Difference or Ctrl + -) follows a specific mathematical logic: Bottom Object minus Top Object.

  1. The Target (Bottom Object): This is the shape that retains its identity, color, and stroke properties.
  2. The Cutter (Top Object): This is the shape used to carve out an area from the target. In boolean operations, the cutting tool is treated as a temporary operand and is discarded once the action executes.

The Result of Zero Overlap

When two selected vector shapes share no overlapping area on the canvas:

  • The Top Shape Disappears: Inkscape processes the top path as the cutting boundary. Regardless of whether it intersects with the bottom object, the software completes the calculation and deletes the top object from the workspace.
  • The Bottom Shape Remains Untouched: Because the cutting path did not intersect any portion of the bottom path's coordinates, no nodes are added, moved, or deleted from the target shape. Its geometry, dimensions, and styling remain identical to their original state.
  • No Error Message Appears: Inkscape does not display a warning dialog indicating that the shapes do not touch. The operation silently executes, leaving only the bottom shape selected.

Z-Order Determines the Outcome

The outcome depends entirely on the Z-order (stacking order) of the two objects, not the order in which you select them.

If you apply Difference to two separate shapes and the wrong object disappears, the stacking order was reversed. To preserve the other object instead, you must first raise the intended target above the cutter (Page Up or Home) or lower the cutter beneath it before executing the operation.
