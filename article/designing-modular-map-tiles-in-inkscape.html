Designing Modular Map Tiles in Inkscape

Designing modular road and river tiles for strategy board games requires establishing precise grids, standardized edge connections, and reusable vector assets in Inkscape. By aligning path endpoints strictly to tile borders and maintaining consistent entry and exit angles, you can produce interchangeable square or hexagonal tiles that seamlessly link together during gameplay. This guide outlines the exact workflow for configuring your canvas, setting up anchor points, drawing paths, and exporting your modular tile system.

1. Configure the Document Grid and Units

Open Inkscape and access Document Properties (Ctrl+Shift+D). Set the display units to either millimeters or inches depending on your physical manufacturing specs. For a standard square tile game, set a custom page size of 50x50 mm (or 2x2 inches).

Navigate to the Grids tab and create a Rectangular grid. Set the grid spacing to a sub-unit that divides evenly into your tile dimensions (e.g., 2.5 mm or 5 mm).

Enable Snapping (%) on the right-hand toolbar. Ensure the following snap targets are active:

  • Snap to grids
  • Snap to nodes, paths, and handles
  • Snap to cusp nodes
  • Snap to midpoint of line segments

2. Establish Standardized Connection Points

For modular tiles to fit interchangeably, features must enter and exit at identical coordinates across every tile edge.

  1. Select the Rectangle tool (R) and draw a square matching your tile canvas size (e.g., 50x50 mm). Lock this layer as your reference border.
  2. Define the crossing points. For standard centered paths, roads and rivers should cross the exact midpoint of an edge.
  3. For multi-lane or offset configurations, place guides at measured distances (e.g., 15 mm from the corners). Pull guides from the rulers and double-click them to set precise coordinates.

3. Draw Path Connections

Use the Draw Bezier Curves tool (B) in regular path mode to create your waterways and roadways.

Roads

  1. Click on the border snap point on one side of the tile, click in the interior to define the curve, and end the path snapped to the target border point.
  2. Open the Fill and Stroke panel (Ctrl+Shift+Y). Remove fill and give the stroke a fixed thickness (e.g., 4 mm).
  3. To ensure that two connected tiles do not form a sharp, unnatural kink at the border, select the Edit paths by nodes tool (N). Select the endpoint on the border and its adjacent node handle. Hold Ctrl while adjusting the handle so it remains strictly perpendicular (90 degrees) to the border edge.

Rivers

  1. Rivers typically feature variable widths and natural curves. Draw the path centerline using the Bezier tool just like a road.
  2. In Fill and Stroke, assign a wider stroke width (e.g., 8 mm to 12 mm).
  3. If designing organic banks, convert the path to an outline via Path > Stroke to Path (Ctrl+Alt+C). You can then manipulate individual bank nodes using the node tool without moving the edge intersection points.

4. Create Intersections and Layering

  1. When roads cross rivers, duplicate the road segment (Ctrl+D), color it to match a bridge asset, and ensure it sits above the river in the Layers and Objects panel.
  2. For T-junctions or four-way intersections, draw overlapping paths and select Path > Union (Ctrl++) to merge the outlines into a single continuous shape, preventing visible overlap artifacts.

5. Clip Assets to the Tile Boundary

To keep artwork strictly within tile borders:

  1. Duplicate your base tile rectangle (Ctrl+D) and bring it to the top of your layer stack.
  2. Group all map features (roads, rivers, background terrain) using Ctrl+G.
  3. Select both the top boundary rectangle and the art group.
  4. Right-click and choose Set Clip. This truncates all overflowing strokes cleanly at the tile edge without destroying the vector data.

6. Build the Core Tile Set and Export

Construct the primary connection archetypes needed for a functional modular system:

  • Straight: Paths entering on one side and exiting directly opposite.
  • Turn/Curve: Paths entering on one side and exiting on an adjacent side (90 degrees).
  • T-Junction: Three connection points merged in the center.
  • Dead End: A path entering one edge and terminating at an internal point of interest.

Once your master components are designed, navigate to File > Export (Ctrl+Shift+E). Choose Page export to render each tile at its exact boundary, select PNG or PDF at 300 DPI for print readiness, and save your modular library.
