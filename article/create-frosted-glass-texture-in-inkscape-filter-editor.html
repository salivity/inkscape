Create Frosted Glass Texture in Inkscape Filter Editor

This guide explains how to generate a realistic frosted glass texture natively in Inkscape using the Filter Editor. By chaining together procedural primitives such as Turbulence, Displacement Map, and Gaussian Blur, you can create a reusable SVG filter that simulates the diffusion and micro-roughness of semi-opaque, frosted glass without external plugins.

Step 1: Set Up the Test Environment

  1. Open Inkscape and place a colorful background image, pattern, or text on the canvas.
  2. Draw a rectangle or shape over the background where you want the frosted glass effect to appear.
  3. Set the shape’s fill color to white (or a very light blue) and lower its opacity to around 20–40% in the Fill and Stroke panel (Shift + Ctrl + F).

Step 2: Open the Filter Editor and Create a Filter

  1. Go to Filters > Filter Editor in the top menu to open the Filter Editor dock.
  2. Click New at the bottom left of the panel to create an empty filter.
  3. Rename the filter to "Frosted Glass" for easy identification.
  4. Ensure the overlay shape is selected on your canvas, then check the box next to your new filter in the list to assign it.

Step 3: Add the Turbulence Primitive

  1. In the Add Effect drop-down menu at the bottom of the Filter Editor, select Turbulence and click Add Effect.
  2. Select the Turbulence node in the filter tree to adjust its parameters in the panel below:
    • Set Type to Fractal Noise.
    • Set Base Frequency to roughly 0.05 to 0.1 for both X and Y (higher values create a finer, tighter grain).
    • Set Num Octaves to 3 or 4 to add detailed roughness.

Step 4: Map the Distortion with a Displacement Map

  1. In the Add Effect drop-down, select Displacement Map and click Add Effect.
  2. In the node graph, connect the inputs of the Displacement Map:
    • Drag the top connector (Input 1 / Image) to Source Graphic.
    • Drag the bottom connector (Input 2 / Map) to the output of the Turbulence node.
  3. Select the Displacement Map node to edit its properties:
    • Set Scale to a value between 5 and 15 depending on how heavily distorted you want the refraction to be.
    • Set X Channel to Red and Y Channel to Green.

Step 5: Soften the Texture with Gaussian Blur

  1. Select Gaussian Blur from the Add Effect list and click Add Effect.
  2. Connect the input of the Gaussian Blur node to the output of the Displacement Map node.
  3. Set the Standard Deviation of the blur to a small value, typically between 0.5 and 1.5, to diffuse the sharp edges of the displacement noise.

Step 6: Blend the Surface and Highlights (Optional)

  1. Add a Composite primitive to mix the blurred, displaced background with the original surface color.
  2. Connect Input 1 of the Composite node to the output of the Gaussian Blur node, and connect Input 2 to Source Graphic.
  3. Set the Operator to Over or Arithmetic (adjusting K1–K4 values) to control how much surface reflection and white tint sits on top of the distorted background.
  4. Close the Filter Editor. The resulting filter will dynamically apply frosted diffusion to any vector object or backdrop beneath it.
