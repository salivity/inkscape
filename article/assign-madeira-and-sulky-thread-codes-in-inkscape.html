Assign Madeira and Sulky Thread Codes in Inkscape

Assigning manufacturer thread codes such as Madeira or Sulky to vector artwork in Inkscape is primarily achieved through embroidery color palettes provided by the Ink/Stitch extension. This guide walks through activating manufacturer color palettes, assigning precise thread codes to vector fills and strokes, and managing color metadata for production-ready embroidery files.

Step 1: Install and Enable Manufacturer Palettes

Inkscape uses GIMP Palette (.gpl) files to display color swatches. The open-source embroidery extension Ink/Stitch includes built-in palettes for Madeira Rayon, Madeira Polyneon, Sulky Rayon, and other major thread lines.

  1. If not already installed, install the Ink/Stitch extension. During installation, it automatically installs thread manufacturer palettes into Inkscape's palettes directory.
  2. If you do not use Ink/Stitch, download the .gpl palette files for Madeira or Sulky and manually place them into your Inkscape user palette folder:
    • Windows: %APPDATA%\inkscape\palettes
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes
    • Linux: ~/.config/inkscape/palettes
  3. Restart Inkscape to load the new palettes.

Step 2: Select the Manufacturer Palette

  1. Locate the color palette bar along the bottom of the Inkscape workspace.
  2. Click the small arrow (>) icon located at the far right edge of the bottom color bar.
  3. Scroll through the list and select your desired manufacturer line (for example, Ink/Stitch: Madeira Polyneon or Ink/Stitch: Sulky Rayon).
  4. Alternatively, open the dedicated Swatches dialog by navigating to View > Swatches (or press Shift + Ctrl + W) and select the thread palette from the dropdown menu.

Step 3: Assign the Thread Code to Vector Objects

Once the palette is active, each swatch represents a specific manufacturer thread number and color name.

  1. Select the vector path or shape you want to color using the Select and Transform objects tool (S or F1).
  2. Hover your mouse over the swatches in the palette bar. A tooltip will appear displaying the exact manufacturer code and color name (e.g., Madeira Polyneon 1801 - White or Sulky 1005 - Black).
  3. To assign the code as a fill color, left-click on the swatch.
  4. To assign the code as a stroke color, hold Shift and left-click on the swatch.

Inkscape sets the object's RGB values to the exact specification of that thread swatch, while embedding the color name and thread code into the SVG's XML attributes.

Step 4: Verify Thread Assignments with Ink/Stitch

To confirm that the thread codes are properly recognized by embroidery formats (such as PES, DST, or EXP):

  1. Select your colored vector object.
  2. Navigate to Extensions > Ink/Stitch > Params.
  3. The preview window will render the path with the assigned thread code displayed in the color description.
  4. If you need a comprehensive list of all assigned threads in your document, go to Extensions > Ink/Stitch > Visualize and Export > Print/PDF Export. The generated production sheet will list each Madeira or Sulky code, its color preview, and the total stitch count associated with that thread.
