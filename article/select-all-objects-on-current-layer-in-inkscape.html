Select All Objects on Current Layer in Inkscape

Managing complex vector illustrations requires precise control over your layers, especially when selecting multiple objects without disturbing the rest of your artwork. This guide explains the exact keyboard shortcut combination used to select all objects exclusively on the current active layer in Inkscape, contrasts it with selecting across multiple layers, and covers the essential settings needed to ensure this shortcut behaves as expected.

The Shortcut: Ctrl + A (or Cmd + A)

In Inkscape, the default shortcut combination to select all objects on the active layer while ignoring objects on other layers is:

  • Windows / Linux: Ctrl + A
  • macOS: Cmd + A

By default, Inkscape confines the standard "Select All" command to the currently selected layer or sublayer. Any elements residing in locked layers, hidden layers, or non-active layers remain unselected.

Difference Between Layer Selection Shortcuts

Inkscape provides two distinct commands for selecting all artwork to prevent accidental modifications:

  • Select All in Current Layer (Ctrl + A / Cmd + A): Targets every unlocked and visible object located inside the active layer only.
  • Select All in All Layers (Ctrl + Alt + A / Cmd + Opt + A): Overrides layer boundaries and selects every visible, unlocked object across the entire document.

Verifying Inkscape Layer Selection Preferences

If pressing Ctrl + A selects objects across your entire canvas rather than restricting itself to the active layer, you can adjust the behavior in your preferences:

  1. Open Edit in the top menu and choose Preferences (or press Shift + Ctrl + P).
  2. In the left navigation pane, navigate to Behavior > Selecting.
  3. Locate the option labeled "Ctrl+A" selects all in current layer only.
  4. Check the box to activate this restriction.

Once checked, Ctrl + A will strictly isolate its selection to whichever layer is currently highlighted in your Layers and Objects dock (Ctrl + Shift + L).
