Inkscape feTurbulence Filter: Create Water Ripples

Creating realistic, wavy water ripple distortions on vector graphics in Inkscape is achieved by combining the feTurbulence and feDisplacementMap primitives using the Filter Editor. This guide covers how to construct a custom ripple filter from scratch, configure the frequency and octaves of the procedural noise to mimic liquid surfaces, and map the distortion onto any path, text, or grouped vector object.

1. Prepare Your Vector Shape

Select or draw the vector artwork you wish to distort. This technique works on basic paths, complex illustrations, and live text. Group multiple objects together using Ctrl + G if you want the ripple effect to distort them as a unified graphic.

2. Open the Filter Editor

  1. Navigate to the top menu and select Filters > Filter Editor.
  2. In the Filter Editor panel, click the New button at the bottom to create a blank filter.
  3. Double-click the default name and rename it to something recognizable, such as "Water Ripples."

3. Add and Configure the feTurbulence Primitive

The feTurbulence primitive generates the mathematical Perlin noise that drives the wave pattern.

  1. In the Add primitive drop-down menu at the bottom of the panel, select Turbulence, then click Add Primitive.
  2. Select the added Turbulence layer to reveal its parameters in the lower tab:
    • Type: Set to Turbulence for sharper ripples or Fractal Noise for softer, smoother swells.
    • Base Frequency: This controls the wave size. For horizontal ripples, set an asymmetrical frequency, such as X: 0.01 and Y: 0.08. A lower number yields larger, broader waves, while a higher number creates tighter ripples.
    • Num Octaves: Set this to 1 or 2. Higher values add fine, chaotic texture, whereas low values produce the clean, smooth waves typical of water surfaces.

4. Add the feDisplacementMap Primitive

The displacement map uses the color data generated by the turbulence to physically distort the original graphic.

  1. From the Add primitive drop-down, select Displacement Map and click Add Primitive.
  2. In the node graph inside the Filter Editor:
    • Connect the Image (first input) triangle of Displacement Map to Source Graphic.
    • Connect the Map (second input) triangle of Displacement Map to the output of Turbulence.
  3. Select the Displacement Map layer to adjust its parameters:
    • Scale: This slider determines the intensity of the distortion. Set it between 10 and 30 depending on the desired wave height.
    • X Channel: Set to Red.
    • Y Channel: Set to Green.

5. Apply and Refine the Ripple Effect

  1. Select your vector graphic on the canvas.
  2. In the Filter Editor list, check the box next to your "Water Ripples" filter to apply it.
  3. Fine-tune the appearance in real time:
    • Increase the Scale in Displacement Map if the ripples are too subtle.
    • Modify the Base Frequency Y in Turbulence to control how tightly packed the horizontal waves are.
    • Adjust Base Frequency X to make the waves wider across the surface.
