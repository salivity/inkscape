Inkscape 1.2 User Interface Changes

Inkscape 1.2 introduced significant updates to its user interface, focusing on workflow efficiency, modern aesthetics, and enhanced workspace customization. This article details the primary UI modifications introduced in the release, including the implementation of native multi-page document management, a unified Layers and Objects panel, an overhauled Export dialog, a redesigned snapping system, and improved toolbar customization options.

Native Multi-Page Document Support

The most prominent addition to the interface is the Page tool, accessible directly from the main toolbox on the left side of the screen. This tool allows users to create, resize, move, and delete multiple pages within a single canvas workspace. A dedicated control bar at the top provides inputs for standard page sizes, orientation, and margins, while navigation controls appear in the status bar to jump between pages quickly.

Merged Layers and Objects Dialog

Inkscape 1.2 unified the previously separate "Layers" and "Objects" dialogs into a single, cohesive panel. This consolidated dialog gives full visibility into the document hierarchy, allowing users to:

  • View layers, groups, and individual paths in a single tree view.
  • Color-code layers and objects for rapid identification.
  • Toggle visibility, locking, and masking directly with one-click icons.
  • Drag and drop elements between different hierarchy levels without switching menus.

Redesigned Export Dialog

The Export dialog was rebuilt from the ground up to replace the legacy "Export PNG Image" panel. The new UI features:

  • A tabbed layout separating single-item export from batch exporting.
  • Live preview thumbnails showing the exact bounding box and contents being exported.
  • Multi-format support in one location, allowing exports to PNG, SVG, PDF, WebP, and other formats without using the "Save As" menu.
  • Direct integration with multi-page documents to export individual pages or all pages simultaneously.

Streamlined Snapping System

The snapping controls, which previously occupied an entire vertical or horizontal toolbar, were condensed into a single icon in the top-right corner of the window. Clicking this icon opens a popover menu with a simple toggle switch for basic users and an expandable "Advanced mode" for granular control over bounding boxes, node points, grid intersections, and alignment guides.

Configurable Toolbars and Canvas

Workspace personalization was expanded to reduce visual clutter on smaller screens:

  • Toolbox Customization: Users can hide specific tools via the interface preferences to remove unused utilities from the main toolbar.
  • Continuous Scrolling and Panning: Canvas navigation became smoother with updated scrollbar behavior and extended panning boundaries.
  • Visual Palette Adjustments: The color palette at the bottom of the screen gained options to adjust tile height, borders, and multi-row displays through a dedicated configuration popover.
