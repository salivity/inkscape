How to Use Autotrace in Inkscape Trace Bitmap

This guide explains how to switch from the default Potrace engine to AutoTrace within the Inkscape Trace Bitmap tool. While Potrace is designed to trace solid shapes by creating filled outlines, AutoTrace excels at centerline tracing, converting line drawings and sketches into editable single-stroke paths. By selecting the built-in AutoTrace mode within the Trace Bitmap dialog, you can quickly vectorize line art without generating double-walled outlines.

Accessing AutoTrace in Inkscape

AutoTrace is integrated directly into modern versions of Inkscape under the Centerline Tracing mode. Follow these steps to use it:

  1. Import and Select Your Image: Open Inkscape and import the raster image (PNG, JPG, etc.) you want to vectorize. Click on the image with the Select Tool (S) to ensure it is active.
  2. Open Trace Bitmap: Navigate to the top menu and select Path > Trace Bitmap, or press the keyboard shortcut Shift + Alt + B.
  3. Select the Single Scan Tab: In the Trace Bitmap panel that opens on the right, ensure you are on the Single scan tab.
  4. Choose Centerline Tracing (AutoTrace): Locate the tracing method dropdown menu or radio button list. Change the method from the default Potrace options (such as Brightness cutoff or Edge detection) to Centerline tracing (autotrace).
  5. Adjust Tracing Parameters:
    • Filter threshold (despeckle): Adjust this value to ignore small spots and noise in your source image.
    • Error threshold: Controls how tightly the generated vector paths adhere to the original pixels. Lower values yield higher precision, while higher values create smoother, simpler lines.
  6. Apply the Trace: Click the Apply button at the bottom of the dialog. Inkscape will run the AutoTrace algorithm and place the resulting vector path directly on top of your original bitmap.

When to Use AutoTrace Instead of Potrace

  • Centerline Vectorization: Use AutoTrace when vectorizing technical drawings, signatures, handwriting, or coloring-book style line art where you want standard strokes rather than filled shapes.
  • Plotters and Laser Cutters: AutoTrace is ideal for creating single-line toolpaths for CNC machines, pen plotters, and laser engravers.
  • Filled Silhouettes: Stick with Potrace (standard Brightness cutoff) if your goal is to vectorize solid logos, icons, or high-contrast filled graphics.
