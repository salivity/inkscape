Merge Overlapping Shapes with Inkscape Path Division

Combining overlapping vector shapes in Inkscape often forces them into a single color when using the standard Union tool. By using the Path Division operation instead, you can cut overlapping vectors along their intersection lines, allowing you to maintain distinct color boundaries or eliminate hidden overlapping geometry. This guide explains how to properly prepare your paths, execute the division, and manage the resulting segments for clean, edge-to-edge color fills.

1. Position and Convert Your Objects

Ensure both objects are true vector paths. If you are using standard shape primitives (such as rectangles or circles), select them and go to Path > Object to Path (or press Shift + Ctrl + C). Arrange the two shapes so that they overlap on the canvas and set each to your preferred fill color.

2. Duplicate the Cutting Path

The Division command uses the top object to slice the bottom object, consuming the top object in the process. To preserve the original top shape:

  1. Select the top shape.
  2. Duplicate it by pressing Ctrl + D (or right-click and choose Duplicate).
  3. The duplicate will appear directly above the original shape in the exact same position.

3. Apply Path Division

  1. Hold Shift and select the duplicate top shape and the bottom shape beneath it.
  2. Navigate to the top menu and select Path > Division (or press Ctrl + /).
  3. The bottom shape will be split into two separate paths: the region outside the overlap and the region directly beneath the top shape.

4. Remove Hidden Overlaps (Edge-to-Edge Seam)

If your goal is to merge the visual footprint into an abutting seam without overlapping layers:

  1. Temporarily hide or move the original top shape, or use the Objects panel (Ctrl + Shift + O) to locate the divided segments.
  2. Select the cut piece that sits directly underneath the top shape.
  3. Press Delete.
  4. The remaining bottom shape now perfectly aligns with the contours of the top shape with zero overlap, eliminating color bleed when printing or exporting.

5. Color Three Distinct Zones (Optional)

If your goal is to create a multi-colored composite where the intersection itself has a unique color boundary:

  1. Do not delete the divided segment.
  2. Select the divided segment that represents the overlapping area.
  3. Pick a new color from the palette at the bottom of the workspace.
  4. If you want the two original shapes to form a single continuous outline with the intersection intact, select the non-overlapping segments and use Object > Group (Ctrl + G) to keep the components organized as a single graphic asset.
