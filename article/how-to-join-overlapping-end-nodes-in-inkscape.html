How to Join Overlapping End Nodes in Inkscape

Joining multiple overlapping end-nodes across separate paths in Inkscape is a common necessity when cleaning up CAD imports, DXF files, or traced line art. Instead of manually selecting and merging each pair of vertices individually, you can use Inkscape's built-in node editing operations to batch-merge all coincident endpoints at once. This guide outlines the exact, step-by-step process to automatically fuse overlapping end-nodes into continuous paths.

Step 1: Combine the Separate Paths

Before Inkscape can merge nodes between separate objects, those objects must belong to the same compound path.

  1. Switch to the Select tool (S or F1).
  2. Select all the disjoint paths you want to join.
  3. Go to the top menu and select Path > Combine (or press Ctrl + K).

All separate segments are now part of a single compound path object, which allows their nodes to interact.

Step 2: Switch to the Node Tool

  1. Switch to the Node tool (N or F2).
  2. Click anywhere on your combined path to activate its nodes.

Step 3: Select All Nodes

  1. With the Node tool active, select every node in the combined path by pressing Ctrl + A (or drag a selection box around the entire drawing).
  2. All nodes across the entire path will highlight (turn yellow/blue depending on your theme).

Step 4: Automatically Join the Overlapping Nodes

  1. Look at the Tool Controls Bar at the top of the canvas.
  2. Locate the node editing buttons and click Join selected nodes (icon showing two node squares merging into a single node with arrows pointing together).

Inkscape will evaluate every selected node. Intermediate nodes along curves will remain unaffected, while any two end-nodes that occupy the exact same coordinate space will automatically merge into a single, continuous node.

Troubleshooting Non-Merging Nodes

If some nodes fail to merge automatically using this method, consider the following:

  • Nodes Must Be True Endpoints: The "Join selected nodes" command only works if both vertices are open ends of a line segment. It will not merge an open end-node with an intermediate node along another segment unless the path is split first.
  • Nodes Are Not Perfectly Coincident: Inkscape's batch "Join selected nodes" function requires overlapping nodes to share the exact same coordinates. If your nodes have a small gap:
    1. Enable snapping by clicking the Snap toggle in the top-right corner.
    2. Ensure Snap to nodes, paths, and handles is activated.
    3. Drag the non-merged node over the target node until it snaps into place, then run the command again.
