Convert SVG to PDF Automatically Using Bash and Inkscape

This guide demonstrates how to build an automated Bash script that continuously monitors a directory for newly created or modified SVG files and converts them into PDF documents using the Inkscape command-line interface. By combining inotify-tools for file system monitoring with Inkscape's headless export engine, you can create a seamless, hands-free pipeline for document and asset processing.

Prerequisites

To implement this workflow on a Linux system, install Inkscape and the inotify-tools utility.

For Debian/Ubuntu-based distributions, run:

sudo apt update
sudo apt install inotify-tools inkscape

For RHEL/Fedora:

sudo dnf install inotify-tools inkscape

The Automation Script

Create a script file named watch_svg_to_pdf.sh and populate it with the following code:

#!/usr/bin/env bash

# Define directories (adjust paths as needed)
WATCH_DIR="/path/to/watch_folder"
OUTPUT_DIR="/path/to/output_folder"

# Ensure directories exist
mkdir -p "$WATCH_DIR"
mkdir -p "$OUTPUT_DIR"

echo "Watching $WATCH_DIR for new SVG files..."

# Monitor the directory for files that have finished writing
inotifywait -m -e close_write --format "%w%f" "$WATCH_DIR" | while read -r FILE
do
    # Check if the modified file has an .svg extension
    if [[ "$FILE" =~ \.svg$ ]]; then
        FILENAME=$(basename "$FILE")
        BASENAME="${FILENAME%.*}"
        TARGET_PDF="$OUTPUT_DIR/$BASENAME.pdf"

        echo "Processing: $FILENAME"

        # Execute the Inkscape export command
        inkscape "$FILE" --export-filename="$TARGET_PDF"

        if [ $? -eq 0 ]; then
            echo "Successfully converted: $TARGET_PDF"
        else
            echo "Error converting: $FILE"
        fi
    fi
done

How the Script Works

  1. inotifywait -m -e close_write:

    • The -m (monitor) flag keeps the command running persistently instead of exiting after the first event.
    • The -e close_write flag ensures the script only triggers after a file has finished being written and closed. This prevents Inkscape from attempting to read partially transferred or incomplete files.
    • The --format "%w%f" parameter outputs the full absolute file path directly.

  2. File Validation:

    • The conditional [[ "$FILE" =~ \.svg$ ]] ensures that non-SVG files written to the watched directory do not trigger unnecessary Inkscape processes.

  3. Inkscape CLI:

    • inkscape "$FILE" --export-filename="$TARGET_PDF" invokes Inkscape in non-GUI (headless) mode. Inkscape determines the output format from the .pdf extension provided in --export-filename and renders vector paths directly into vector PDF elements.

Running the Script

Make the script executable:

chmod +x watch_svg_to_pdf.sh

Run the script directly in your terminal to test:

./watch_svg_to_pdf.sh

To run the script persistently in the background, detach it using nohup:

nohup ./watch_svg_to_pdf.sh > svg_converter.log 2>&1 &

For a persistent production deployment, set up this script as a systemd service to ensure it automatically starts at system boot and restarts if a failure occurs.
