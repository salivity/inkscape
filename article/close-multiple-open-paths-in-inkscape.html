Close Multiple Open Paths in Inkscape

Closing multiple separate open paths simultaneously in Inkscape is a common task when preparing vector artwork, CAD imports, or cut files for CNC and laser machining. Rather than manually bridging the endpoints of each path one by one, Inkscape provides an automated extension designed to draw straight connecting segments between the start and end nodes of multiple paths in a single action. This guide details how to perform this operation quickly and efficiently.

Using the Close Paths Extension

Inkscape includes a dedicated extension that allows you to close every selected open path on its own without needing to combine them first or manually select individual node pairs.

  1. Select the Paths: Use the Select Tool (S or F1) and click-drag a bounding box around all the open paths you want to close, or hold Shift and click each path individually.
  2. Open the Extension Menu: Go to the top menu bar and navigate to Extensions > Modify Path > Close Path(s)... (in some versions listed as Close Paths).
  3. Configure the Settings:
    • In the dialog box that appears, you can choose the closure method. Select the option that closes all paths or open subpaths with a straight line segment.
    • If you want to preview the result before committing, check the Live Preview box.
  4. Apply the Closure: Click Apply, then click Close to exit the dialog.

Inkscape will immediately insert a straight line segment between the start and end nodes of each separate open path, converting them all into closed shapes in one step.

Alternative: Combining and Closing with the Node Tool

If you prefer using core path tools or need to treat the resulting shapes as a combined compound path, you can use the Node Tool:

  1. Select All Paths: Select the desired open paths using the Select Tool (S).
  2. Combine Paths: Press Ctrl + K (or choose Path > Combine). This groups the paths into a single object containing multiple open subpaths.
  3. Switch to the Node Tool: Press N to activate the Edit paths by nodes tool.
  4. Select All Nodes: Press Ctrl + A while inside the Node Tool to select every node across all subpaths.
  5. Join End Nodes: On the tool controls bar at the top of the canvas, click the Join selected end nodes with a new segment icon.

Inkscape will detect open endpoints and connect them with straight segments, closing each subpath across the entire combined object. If you need the paths as independent objects afterward, simply navigate to Path > Split Apart (Shift + Ctrl + K).
