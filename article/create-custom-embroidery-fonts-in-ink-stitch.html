Create Custom Embroidery Fonts in Ink/Stitch

This guide provides a comprehensive, step-by-step walkthrough on how to design, digitize, and configure custom embroidery glyphs for the Ink/Stitch lettering tool in Inkscape. By following these instructions, you will learn how to set up character baselines, digitize stitches for each letter, configure the necessary font metadata, and save your custom typography so it can be typed directly onto the canvas using your keyboard.

1. Prepare the Document Setup

Ink/Stitch requires specific guides and structure to calculate character heights, line spacing, and kerning.

  1. Open Inkscape and create a new document.
  2. Open File > Document Properties and set your display units to millimeters (mm).
  3. Set up horizontal guidelines to define vertical font metrics:
    • Baseline: The bottom line where characters sit.
    • Ascender: The top limit for tall letters (like b, d, h).
    • Descender: The bottom limit for descending letters (like p, g, y).
    • Cap Height: The top limit for uppercase letters.
    • X-Height: The top limit for flat lowercase letters (like a, c, x).

2. Digitize the Glyphs

Each glyph must consist of valid Ink/Stitch embroidery elements—typically satin columns or running stitches.

  1. Draw your character using the Bézier tool (B).
  2. Convert your shapes into stitch paths:
    • Satin Columns: Use two parallel subpaths connected by rungs, or a single stroke styled with standard satin line properties.
    • Running Stitches: Use simple open paths for underlay or single-line fonts.
    • Fills: Use standard closed paths if creating large filled-letter embroidery.
  3. Apply embroidery parameters via Extensions > Ink/Stitch > Params to confirm that the stitches generate without errors.
  4. Keep the start and stop points of each character optimized for minimal jump stitches, usually starting on the lower left and exiting on the lower right.

3. Organize Characters into Layers and Groups

Ink/Stitch identifies glyphs based on Inkscape’s layer and object labeling structure.

  1. Create a dedicated top-level layer for your font.
  2. Group all elements for a single character together (Ctrl + G).
  3. Open the Object > Objects... panel.
  4. Rename the group or sublayer to match the exact keystroke of the character. For example:
    • Label the uppercase A group as A.
    • Label the lowercase a group as a.
    • Label punctuation directly, such as ?, !, or ..
  5. For special characters or spaces:
    • Create an empty path or invisible boundary object named space to define word spacing.

4. Define Character Width and Spacing

Each character group must have a defined width so Ink/Stitch knows where the next character begins.

  1. Inside each character group, add a horizontal line on the baseline path representing the width of the letter, or position your characters with consistent margins.
  2. Alternatively, use a transparent rectangle (stroke: none, fill: none) bounding the character to represent its advance width.

5. Generate and Package the Font

Ink/Stitch uses a specific JSON and SVG structure to load fonts into the Lettering interface.

  1. Navigate to Extensions > Ink/Stitch > Font Management > Generate JSON.
  2. Fill out the required metadata fields:
    • Font Name: The name that will appear in the Lettering dropdown.
    • Description: Details on recommended size ranges and design style.
    • Default Size: The native height (in mm) at which the font was digitized.
  3. Save the resulting .svg file containing the glyphs and the accompanying .json file containing the font settings.

6. Install the Font into Ink/Stitch

To make the font available in the Lettering tool:

  1. Locate your Ink/Stitch custom font directory:
    • Windows: %APPDATA%\inkstitch\fonts
    • macOS: ~/Library/Application Support/inkstitch/fonts
    • Linux: ~/.config/inkstitch/fonts
  2. Create a new folder inside the fonts directory named after your custom font.
  3. Copy both the .svg and .json files into this directory.

7. Test the Custom Font

  1. Restart Inkscape to ensure newly added files are indexed.
  2. Navigate to Extensions > Ink/Stitch > Lettering.
  3. Select your custom font from the Font dropdown menu.
  4. Type test phrases into the text box to verify:
    • Vertical alignment along the baseline.
    • Proportional spacing between different letter combinations.
    • Correct rendering of satin angles and density settings.
  5. Click Apply and Quit to place your customized embroidery lettering onto the canvas.
