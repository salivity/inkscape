How to Distribute Nodes Horizontally in Inkscape

This guide explains how to evenly space nodes across the horizontal axis in Inkscape using the built-in alignment and distribution tools. Because vector nodes are zero-dimensional coordinate points, distributing them horizontally spaces them with mathematically equal distances across the horizontal plane. Below, you will find the exact steps to space your path nodes evenly, along with how to achieve edge-to-edge spacing if you are working with multi-node objects.

Step 1: Select the Node Tool

  1. Open your project in Inkscape.
  2. Select the Node Tool from the left toolbar, or press N (or F2) on your keyboard.
  3. Click on the path containing the nodes you wish to arrange.

Step 2: Select the Target Nodes

  1. Click and drag a selection box around the nodes you want to distribute, or hold Shift and click each node individually.
  2. Ensure you select at least three nodes; the two outermost nodes will define the boundary, and the interior nodes will adjust between them.

Step 3: Open the Align and Distribute Dialog

  1. Open the panel by pressing Shift + Ctrl + A (or Cmd + Shift + A on macOS).
  2. Alternatively, go to the top menu and choose Object > Align and Distribute.
  3. When the Node Tool is active and nodes are selected, this panel automatically switches from object mode to Node Mode.

Step 4: Distribute Nodes Evenly

  1. Locate the Distribute section inside the panel.
  2. Click the icon labeled Distribute selected nodes horizontally.
  3. Inkscape will calculate the horizontal distance between the leftmost and rightmost selected nodes and space all intermediate nodes at strictly equal intervals.

Distributing Objects by Edge-to-Edge Distance

If your design consists of distinct paths, shapes, or groups rather than individual nodes on a single path, true edge-to-edge distribution (equal gaps between bounding boxes) is handled via Object Mode:

  1. Switch to the Select Tool by pressing S or F1.
  2. Select all the objects you want to arrange.
  3. In the Align and Distribute panel, look under the Distribute category.
  4. Click the button labeled Make horizontal gaps between objects equal.
  5. This sets the distance from the right edge of each object to the left edge of the next object to an identical measurement, regardless of varying object widths.
