Export Inkscape SVG Paths to LaserWeb

This guide provides a straightforward workflow for preparing, exporting, and importing vector SVG paths from Inkscape into LaserWeb for precise laser cutting and engraving. By following proper path conversion, scale settings, and g-code generation steps, you will ensure your vector designs translate accurately to your laser machine without dimensional errors or missing cut lines.

1. Prepare Your Vector Paths in Inkscape

Before exporting, all elements must be converted into vector paths so LaserWeb can generate toolpaths for them.

  • Convert Objects to Paths: Select all shapes and text, then navigate to Path > Object to Path (Shift + Ctrl + C). Text that is not converted to a path will not render in LaserWeb.
  • Convert Strokes to Paths (Optional): If you want to cut along the outer boundary of a thick line rather than trace the center, select the line and go to Path > Stroke to Path. For standard vector cuts along the stroke centerline, leave the stroke intact.
  • Ungroup Elements: Select everything and press Ctrl + Shift + G repeatedly until no groups remain. Grouped layers can occasionally cause parsing errors in CAM software.

2. Set Units and Document Scale

Scaling mismatches between Inkscape and LaserWeb are usually caused by incorrect DPI settings or document unit mismatches.

  • Open File > Document Properties (Shift + Ctrl + D).
  • Set both Display units and Page size units to mm (millimeters).
  • Ensure the Scale is set to 1.00000.
  • Resize the page to fit your drawing or to match the dimensions of your laser machine bed.

3. Save as a Plain SVG

Inkscape's default format includes editor-specific XML data that LaserWeb does not need.

  • Go to File > Save As... (Shift + Ctrl + S).
  • Choose Plain SVG (*.svg) from the file format dropdown instead of "Inkscape SVG."
  • Name your file and click Save.

4. Import and Process in LaserWeb

Once your file is saved, bring it into LaserWeb to assign machining operations.

  • Open LaserWeb and go to the Files tab on the left panel.
  • Click Add Document and select your saved Plain SVG file.
  • Confirm that the imported geometry matches your intended dimensions on the grid.
  • In the document tree, select the imported paths and drag them into the Operations area at the bottom left.
  • Choose your operation type:
    • Laser Cut: For cutting entirely through material using your designated stroke paths.
    • Laser Vector: For marking or surface-engraving along the vector lines without cutting through.
  • Set your machine parameters, including Passes, Cut Rate (mm/min), and Laser Power percentage.
  • Click Generate Gcode to create the machine instructions, then preview the toolpath before sending the job to your laser engraver.
