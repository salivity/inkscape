Make Interlocking Puzzle Joints in Inkscape

This guide explains how to design custom interlocking puzzle joints using Inkscape's vector path operations. By combining basic shapes, node editing, and Boolean tools like Union and Difference, you can create unique male and female tabs that fit together seamlessly for laser cutting, woodworking, or digital art projects.

Step 1: Create the Base Pieces

  1. Select the Rectangle tool (R) and draw two adjacent squares or rectangles on the canvas.
  2. Open the Align and Distribute panel (Shift + Ctrl + A) and align the two shapes so their edges touch edge-to-edge without overlapping. Enable Snapping (%) with "Snap to paths" and "Snap to cusp nodes" checked to ensure exact alignment along the seam.

Step 2: Draw the Custom Key Shape

  1. Use the Draw Bezier curves and straight lines tool (B) or standard geometric shape tools to design your custom key (the interlocking tab). This can be a traditional bulb, a heart, a polygon, or any asymmetrical design.
  2. If using standard shapes, convert them by selecting Path > Object to Path (Shift + Ctrl + C).
  3. Use the Edit paths by nodes tool (N) to refine the shape, ensuring the base (neck) of the key is narrower than the head so that the pieces physically lock together.

Step 3: Position and Duplicate the Key

  1. Drag the custom key over the seam between your two base pieces. The head of the key should extend into one piece, while the base sits on the other.
  2. Align the key to the center of the edge using the Align and Distribute panel.
  3. Select the key and press Ctrl + D to create an exact duplicate directly on top of the original.

Step 4: Create the Male Joint

  1. Select the original key and the base piece where you want the tab to protrude.
  2. Go to the top menu and select Path > Union (Ctrl + +). This merges the key with the first base piece, forming the male interlocking side.

Step 5: Create the Female Joint

  1. Select the duplicate key that remains in place.
  2. Hold Shift and select the second, opposing base piece.
  3. Select Path > Difference (Ctrl + -). This cuts the exact profile of the custom key out of the second piece, forming the female slot.

Step 6: Adjust for Kerf or Clearance (Optional)

If cutting the pieces on a CNC machine or laser cutter, account for material removal (kerf):

  1. Select the female piece.
  2. Go to Path > Outset (Ctrl + )) or use the Offset tool to enlarge the cut-out slightly, ensuring the physical pieces fit together smoothly.
