How to Draw Tangent Lines in Inkscape with CAD Tools

This guide provides a step-by-step walkthrough on how to install, configure, and use the CAD Tools extension in Inkscape to create precise tangent lines between two circles. By converting your shapes into recognizable paths and selecting the appropriate tangent calculation settings within the extension, you can generate both internal and external tangents without manual geometric calculations.

Step 1: Install the CAD Tools Extension

  1. Download the CAD Tools extension files (the .inx and .py script files) designed for Inkscape.
  2. Open Inkscape and navigate to Edit > Preferences > System.
  3. Locate the User extensions entry and click the folder icon to open the directory on your computer.
  4. Copy the downloaded .inx and .py files into this folder.
  5. Restart Inkscape so the software registers the new extension.

Step 2: Prepare the Circles

The CAD Tools extension relies on path data to calculate intersection and tangency points:

  1. Select the Circle/Ellipse tool (F5 or E) and draw your two circles on the canvas.
  2. Select both circles using the Select and Transform objects tool (S or F1).
  3. Convert the shapes into native vector paths by navigating to Path > Object to Path (or press Shift + Ctrl + C).

Step 3: Configure and Run the CAD Tools Extension

  1. With both circle paths selected, go to the top menu and click Extensions > CAD Tools > Tangents (or the specific tangent operation sub-menu provided by your version of CAD Tools).
  2. A configuration window will appear with options for your tangent line generation:
    • Outer/External Tangents: Enable this option if you want direct tangent lines running along the outer boundaries of the circles (parallel or tapering without crossing).
    • Inner/Internal Tangents: Enable this option if you want cross tangents that intersect each other in the space between the circles.
    • Line Type / Layer: Select whether you want the generated tangents to be drawn on the active layer or on a dedicated new layer.
  3. Check the Live Preview box (if available) to verify the placement of the tangent lines on your canvas.
  4. Click Apply to generate the path lines, then click Close to exit the dialogue box.

Step 4: Finalize the Tangents

Once generated, the tangent lines exist as standard path objects. You can select them to adjust stroke width, color, or path endpoints using the Fill and Stroke panel (Shift + Ctrl + F) or the Edit paths by nodes tool (N).
