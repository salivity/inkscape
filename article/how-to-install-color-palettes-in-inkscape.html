How to Install Color Palettes in Inkscape

Inkscape allows users to expand their creative toolkit by importing custom color palettes using standard GIMP Palette (.gpl) files. This guide provides a straightforward walkthrough on locating your Inkscape user directory, adding your custom palette files across Windows, macOS, and Linux, and activating them directly inside your workspace.

Step 1: Obtain a Compatible Palette File

Inkscape uses the .gpl (GIMP Palette) file format for its color swatches. Ensure the custom palette you downloaded or created is saved with the .gpl extension.

Step 2: Locate the Inkscape Palettes Folder

The easiest way to find the correct directory is through Inkscape itself:

  1. Open Inkscape.
  2. Go to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left sidebar, click System.
  4. Look for the User palettes entry. Click the Open folder icon next to the file path to open the directory directly in your file manager.

Alternatively, you can manually navigate to the default paths:

  • Windows: C:\Users\<YourUsername>\AppData\Roaming\inkscape\palettes
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes
  • Linux: ~/.config/inkscape/palettes

Step 3: Copy the Palette File

Move or copy your downloaded .gpl file into the palettes folder you just opened.

Step 4: Load the New Palette in Inkscape

  1. Restart Inkscape to ensure it detects the new file (or continue if the application automatically refreshes).
  2. Locate the color palette bar at the bottom of the Inkscape window.
  3. Click the small right-facing arrow (menu button) located at the bottom-right corner of the color bar.
  4. Scroll through the pop-up list and click on the name of your newly installed palette.

Your custom colors will now appear in the palette bar, ready to be applied to any path or object in your design.
