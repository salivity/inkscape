How to Inspect Linked Assets in Inkscape

This guide explains how to use Inkscape's Document Resources dialog to locate, inspect, and manage all linked and embedded assets within your vector projects. You will learn how to open the dialog, identify external dependencies such as linked raster images and fonts, and check for missing file paths to ensure your SVG files are portable and error-free.

Accessing the Document Resources Dialog

To open the Document Resources panel in Inkscape:

  1. Open your project in Inkscape.
  2. Navigate to the top menu bar and click File.
  3. Select Document Resources... from the dropdown menu.

A dedicated dialog dock will appear on your screen, cataloging all assets referenced by the current document.

Navigating the Asset Categories

The Document Resources dialog organizes components into distinct categories for easy inspection:

  • Images: Displays all bitmap graphics (PNG, JPEG, etc.) used in the document, distinguishing between linked external files and embedded data.
  • Fonts: Lists all typefaces applied to text objects throughout the document, showing whether the required fonts are installed locally.
  • External Files / Linked SVG: Shows other external vector files or sub-resources referenced via SVG links.
  • Patterns and Markers: Catalogs reusable visual assets defined in the document's <defs> section.

Inspecting Linked Assets and File Paths

To inspect specific linked assets:

  1. Click on the Images section in the dialog.
  2. Select an image from the list to view its properties in the details pane.
  3. Review the Location/URI field to verify the exact file path pointing to the linked asset.
  4. Check the asset status:
    • Valid Link: The absolute or relative file path points to an existing file on your storage drive.
    • Broken Link: Highlighted or flagged when the source file has been moved, renamed, or deleted.

Managing Linked Assets

Once you have inspected your linked assets, the dialog allows you to perform several maintenance actions:

  • Locate on Canvas: Double-click any asset in the list to automatically center and select the corresponding object on the drawing canvas.
  • Embed Linked Images: Select a linked image and choose the embed option to save the image data directly inside the SVG file, preventing future broken link issues when sharing the file.
  • Relink Missing Files: Update the URI path to point to the correct folder location if a linked asset was moved.
