How to Soft Proof CMYK in Inkscape for Print

Soft-proofing in Inkscape allows you to preview on-screen how your vector artwork will appear when printed using CMYK inks, eliminating surprises caused by color shifts. Because computer monitors display in RGB and commercial printers use CMYK, many vibrant screen colors fall outside the printable color gamut. This guide explains how to install target print profiles, configure Inkscape's color management settings, and enable real-time soft-proofing on your canvas.

Step 1: Install a CMYK ICC Profile

Inkscape relies on standard International Color Consortium (ICC) profiles to simulate print colors.

  1. Obtain the target ICC profile recommended by your print provider (common standards include U.S. Web Coated (SWOP) v2 or FOGRA39).
  2. Place the .icc or .icm file into your operating system's color profile directory:
    • Windows: C:\Windows\System32\spool\drivers\color
    • macOS: /Library/ColorSync/Profiles or ~/Library/ColorSync/Profiles
    • Linux: ~/.local/share/icc or ~/.color/icc

Step 2: Configure Color Management in Inkscape Preferences

Once the profile is installed on your system, configure Inkscape to use it for simulation.

  1. Open Inkscape and navigate to Edit > Preferences (or press Ctrl + Shift + P / Cmd + Shift + P).
  2. In the left sidebar, expand Interface and select Color management.
  3. Set your profiles:
    • Display profile: Set to your monitor's calibrated profile, or default to sRGB.
    • Device profile: Set to your desired CMYK print profile (e.g., U.S. Web Coated (SWOP) v2).
    • Proofing profile: Select the same CMYK print profile.
  4. Set the Proofing rendering intent to Relative Colorimetric (standard for most graphics) or Perceptual.
  5. Enable Black Point Compensation to ensure shadow details translate accurately.

Step 3: Link the Profile to Your Document

To ensure your document references the correct color space:

  1. Open File > Document Properties (or press Ctrl + Shift + D / Cmd + Shift + D).
  2. Go to the Color tab.
  3. Select your CMYK profile from the Available Profiles list and click Link Profile.

Step 4: Enable Soft-Proofing on the Canvas

With your profiles configured, you can toggle the CMYK preview directly on your workspace.

  1. Go to the top menu and select View > Color-managed display.
  2. Alternatively, toggle color management using the color calibration icon located in the bottom-right corner of the status bar.
  3. The colors on your canvas will immediately shift to simulate the restricted CMYK gamut, showing muted tones where screen-only RGB values cannot be replicated in ink.

Step 5: Identify and Adjust Out-of-Gamut Colors

While soft-proofing is active, inspect vibrant colors such as bright greens, saturated blues, and neon tones, which typically experience the most significant desaturation. Manually tweak your fill and stroke shades using the HSL or CMS color pickers until the soft-proofed display matches your intended design aesthetic before exporting the final artwork.
