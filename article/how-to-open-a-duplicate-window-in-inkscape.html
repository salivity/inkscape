How to Open a Duplicate Window in Inkscape

Inkscape allows you to view and edit a single document across multiple canvas windows simultaneously using the Duplicate Window feature. This guide explains how to open a second synchronized window, how real-time synchronization functions between the views, and how to utilize independent display settings to streamline your design workflow.

Steps to Open a Second Synchronized Window

  1. Open your project in Inkscape.
  2. In the top menu bar, click on View.
  3. Select Duplicate Window from the dropdown menu.

A second window containing your active document will open immediately. You can now drag this window to a secondary monitor or position it side-by-side with your original window.

How Synchronization Works

Both windows represent the exact same file in real time rather than a separate copy. Any modification made in one window—such as drawing paths, editing text, moving objects, or altering colors—instantly renders in the other window without needing to save or refresh.

Saving the file from either window saves all modifications made during the session. Closing one duplicate window will simply close that specific view; the document remains open in the remaining window until the final view is closed.

Independent View Capabilities

While the document data is synchronized, the viewport controls for each canvas remain completely independent:

  • Zoom Levels: You can zoom in closely to adjust anchor points in one window while keeping the other window zoomed out to view the entire composition.
  • Canvas Rotation: One canvas can be rotated at an angle for easier drawing while the other stays in standard orientation.
  • Display Modes: You can set one window to Outline Mode via View > Display mode > Outline to inspect vector paths cleanly, while keeping the other set to Normal to monitor the final rendered output.
