Passing Matrix Transformations to Inkscape CLI

This article explains how to supply numeric 2D transformation matrix strings to the Inkscape command-line interface (CLI) actions pipeline. It details the exact syntax for the transform-matrix action, the mathematical mapping of its parameters, delimiter handling, and complete command-line examples for automating SVG transforms without launching the graphical user interface.

The Action Syntax and Matrix Structure

Inkscape's modern action pipeline accepts affine transformations via the transform-matrix action. The affine transformation in 2D space follows the standard SVG 3x3 matrix representation:

[ a  c  e ]
[ b  d  f ]
[ 0  0  1 ]

In this system:

  • a affects horizontal scaling and rotation.
  • b affects vertical skewing and rotation.
  • c affects horizontal skewing and rotation.
  • d affects vertical scaling and rotation.
  • e specifies horizontal translation (\(dx\)).
  • f specifies vertical translation (\(dy\)).

The action is declared using the parameter pattern transform-matrix:a,b,c,d,e,f, with values separated by commas.

Constructing the Action Pipeline

Inkscape commands require you to target elements before transforming them. The transformation applies to the active selection. An action string must chain the selection, transformation, and export actions, separated by semicolons.

The general structure is:

inkscape input.svg --actions="select-by-id:<TARGET_ID>;transform-matrix:<a>,<b>,<c>,<d>,<e>,<f>;export-filename:output.svg;export-do"

Action Pipeline Execution Order

  1. Target Selection: Use select-by-id:<ID> to isolate a specific node, or select-all:all to transform all elements across layers.
  2. Matrix Application: Call transform-matrix:a,b,c,d,e,f.
  3. Write and Export: Use export-filename:<path> followed by export-do to write the changes to disk. Alternatively, use export-overwrite to save directly back to the source file.

Command-Line Examples

1. Translation via Matrix

To shift an element with ID rect1 horizontally by 50 units and vertically by 100 units (\(a=1, b=0, c=0, d=1, e=50, f=100\)):

inkscape input.svg --actions="select-by-id:rect1;transform-matrix:1,0,0,1,50,100;export-filename:translated.svg;export-do"

2. Scaling and Translation

To scale an element by 2x horizontally, 1.5x vertically, and offset it by 20 units on the X-axis (\(a=2, b=0, c=0, d=1.5, e=20, f=0\)):

inkscape input.svg --actions="select-by-id:path45;transform-matrix:2,0,0,1.5,20,0;export-filename:scaled.svg;export-do"

3. Transforming All Elements

To apply a 45-degree rotation and scale matrix across all objects in a document:

inkscape input.svg --actions="select-all:all;transform-matrix:0.7071,0.7071,-0.7071,0.7071,0,0;export-filename:rotated.svg;export-do"

Syntax Rules and Shell Escaping

  • No Unquoted Spaces: Avoid spaces around the commas or semicolons inside the matrix argument string unless the entire argument is properly quoted, as command shells may split arguments on whitespace.
  • Floating-Point Values: Pass floating-point numbers in standard decimal notation (e.g., 0.5, -1.25). Scientific notation is not consistently parsed across different operating systems.
  • Semicolons: Because semicolons terminate commands in Unix-like shells (Bash, Zsh), the entire string passed to --actions="..." must be enclosed in double or single quotes. In PowerShell, ensure the argument is enclosed in single quotes ('...') or escaped double quotes to prevent string interpolation issues.
