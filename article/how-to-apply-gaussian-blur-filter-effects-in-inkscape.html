How to Apply Gaussian Blur Filter Effects in Inkscape

Applying interactive raster filters like Gaussian Blur to vector artwork in Inkscape allows you to create depth, soft shadows, and realistic textures without losing the flexibility of vector paths. Inkscape utilizes SVG-standard filter primitives to render these pixel-based effects dynamically on the canvas. This guide covers how to quickly apply a standard Gaussian blur using the Fill and Stroke panel, how to build customized, interactive blur chains using the Filter Editor, and how to manage performance while working with complex raster effects.

Method 1: The Quick Gaussian Blur Slider

For standard, uniform blurring on any path, text, or shape, Inkscape provides a direct slider in the object styling properties.

  1. Select the object or group you want to blur using the Select tool (S or F1).
  2. Open the Fill and Stroke panel by pressing Ctrl + Shift + F (or Cmd + Shift + F on macOS) or navigating to Object > Fill and Stroke.
  3. Locate the Blur (%) slider at the bottom of the Fill and Stroke panel.
  4. Drag the slider to the right or type a specific numerical percentage to increase the blur radius interactively.

This method automatically generates a basic SVG Gaussian Blur filter and attaches it to the selected object.

Method 2: Creating Advanced Blur Effects with the Filter Editor

The Filter Editor provides granular control over the blur's horizontal and vertical axes, as well as the ability to chain blur operations with other raster primitives like blend modes and offsets.

  1. Open the Filter Editor by going to Filters > Filter Editor.
  2. Click the New button at the bottom of the left-hand column to create a new custom filter.
  3. In the Add Effect drop-down menu, select Gaussian Blur and click Add Primitive.
  4. In the visual node graph, connect the input arrow of the Gaussian Blur primitive to Source Graphic.
  5. Select the Gaussian Blur primitive in the list to reveal the Effect parameters section at the bottom.
  6. Adjust the Standard Deviation sliders for X and Y. Unchecking the lock icon allows you to blur the object horizontally or vertically at different intensities to create motion-blur styles.
  7. Apply the filter to your selected canvas object by checking the box next to the filter name in the Filter Editor list.

Modifying and Removing Filter Effects

  • Adjusting Built-in Presets: Inkscape includes various pre-configured blur filters under Filters > Blurs (such as Apparition, Clean Blur, or Soft Focus). Once applied, their parameters can be tweaked inside the Filter Editor.
  • Removing Filters: To strip all filter effects from an object, select the target element and choose Filters > Remove Filters, or simply set the Blur slider in the Fill and Stroke panel back to 0%.
  • Duplicating Filters: Within the Filter Editor, right-click any existing filter to duplicate it, allowing you to iterate on different blur intensities across multiple design elements.

Optimizing Canvas Performance

Because interactive raster filters are calculated on the GPU/CPU in real time, complex blurs can slow down canvas navigation. If you experience lag:

  1. Go to View > Display mode > No Filters to temporarily disable filter rendering while editing paths.
  2. Switch back to View > Display mode > Normal when you are ready to review the final visual output.
