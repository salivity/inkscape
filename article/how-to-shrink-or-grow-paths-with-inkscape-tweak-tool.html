How to Shrink or Grow Paths with Inkscape Tweak Tool

The Tweak tool in Inkscape is a powerful feature that allows you to sculpt and deform vector graphics intuitively, much like working with digital clay. This guide provides a straightforward walkthrough on how to use the Tweak tool to organically shrink and grow paths, adjust brush settings for fine control, and achieve smooth, natural vector distortions without manually editing individual nodes.

1. Prepare Your Object

The Tweak tool only works on vector paths, not raw shapes (like rectangles or stars) or grouped objects.

  1. Select the object you want to modify using the Select tool (S).
  2. Convert it to a path by going to the top menu and clicking Path > Object to Path (or press Shift + Ctrl + C).
  3. If your path has very few nodes, the deformation may look blocky. You can add more nodes by selecting the Node tool (N), selecting all nodes, and clicking Insert new nodes into selected segments.

2. Activate the Tweak Tool

  1. With your path selected, select the Tweak tool from the toolbox on the left, or press W on your keyboard.
  2. Ensure your target path remains highlighted with a selection outline so the tool knows which object to alter.

3. Select the Shrink or Grow Mode

In the Tool Controls bar along the top of the screen, choose your desired mode:

  • Shrink Path: Click the Shrink path icon (the icon showing arrows pulling the outline inward). This deflates or thins out the sections of the path under your brush.
  • Grow Path: Click the Grow path icon (the icon showing arrows pushing the outline outward). This expands or thickens the sections of the path under your brush.

Tip: You can quickly switch between Grow and Shrink modes by holding down the Shift key while dragging.

4. Adjust Tool Parameters

Set the brush behavior in the Tool Controls bar to suit the scale of your design:

  • Width: Controls the radius of the sculpting brush. You can also adjust this dynamically on the canvas by pressing the Left Arrow or Right Arrow keys, or by holding Home/End.
  • Force: Controls the strength and speed of the deformation. For subtle, organic results, set the Force to a lower value (between 10 and 30).
  • Use Pressure: If you are using a graphics tablet, enable the pressure sensitivity toggle to control the force using stylus pressure.

5. Sculpt the Path

  1. Click and drag the circular brush cursor over the parts of the path you want to resize.
  2. Moving the cursor slowly creates smoother, more gradual changes, while holding the brush in one spot intensifies the growth or shrinkage in that specific area.
  3. Release the mouse button to preview the result. Repeat the strokes as needed until you achieve the desired organic shape.
