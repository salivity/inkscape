How to Make a CRT Scanline Filter in Inkscape

This guide demonstrates how to build an authentic retro CRT monitor effect from scratch using the native Filter Editor in Inkscape. By combining SVG filter primitives—including Turbulence, Color Matrix, Composite, and Gaussian Blur—you will learn how to generate procedural horizontal scanlines, adjust line density, and add a luminous phosphor glow to any vector artwork or bitmap image.

Step 1: Open the Filter Editor and Prepare Your Graphic

  1. Place your target artwork, text, or imported image onto the canvas.
  2. Open the Filter Editor panel by navigating to Filters > Filter Editor.
  3. In the Filter Editor panel, click the New button at the bottom left to create a new filter. Rename it to CRT Scanlines for clarity.
  4. With your graphic selected on the canvas, check the box next to CRT Scanlines in the list to attach the filter to your object.

Step 2: Generate the Horizontal Scanline Texture

  1. In the Add Effect dropdown menu, select Turbulence and click Add.
  2. In the connection graph, leave the input disconnected or attached to Source Graphic (Turbulence generates its own texture procedurally).
  3. Select the Turbulence primitive in the list to edit its parameters:
    • Set Type to Turbulence or Fractal Noise.
    • Uncheck the lock icon between the frequency values so they can be adjusted independently.
    • Set the Horizontal Frequency (X) to 0.000.
    • Set the Vertical Frequency (Y) between 0.200 and 0.500. A higher vertical frequency creates thinner, denser scanlines.
    • Set Octaves to 1.

Step 3: Increase Contrast with Color Matrix

To transform the smooth noise gradient into sharp, alternating dark and light scanline bands:

  1. Select Color Matrix from the Add Effect dropdown and click Add.
  2. Connect the input of Color Matrix to the output of Turbulence.
  3. Set the matrix type to Matrix.
  4. Adjust the Alpha row (the bottom row) or set the RGB values to dramatically scale contrast. For standard horizontal stripe clipping, set:
    • Red: 0 0 0 0 0
    • Green: 0 0 0 0 0
    • Blue: 0 0 0 0 0
    • Alpha: 0 0 0 20 -10 (values may be tuned depending on the desired darkness of the gaps).

Step 4: Blend Scanlines with the Source Graphic

  1. Select Composite from the Add Effect dropdown and click Add.
  2. Connect the first input (Image 1) of the Composite node to Source Graphic.
  3. Connect the second input (Image 2) to the output of your Color Matrix.
  4. Set the Operator dropdown to Arithmetic or Multiply:
    • If using Multiply, the dark scanline stripes will naturally darken the underlying image.
    • If using Arithmetic, set K1 = 1, K2 = 0, K3 = 0, K4 = 0 to control the exact blend ratio.

Step 5: Add CRT Phosphor Glow (Bloom)

  1. Select Gaussian Blur from the Add Effect dropdown and click Add.
  2. Connect the input of the Gaussian Blur node directly to Source Graphic.
  3. Set the blur Standard Deviation to roughly 1.5 to 3.0 to generate a soft radiance.
  4. Add a final Composite primitive.
  5. Connect Image 1 of this new Composite primitive to the output of your first Composite node (the scanline-merged graphic).
  6. Connect Image 2 to the output of the Gaussian Blur node.
  7. Set the Operator to Screen or Lighter to overlay the glowing bloom on top of the rasterized scanline image.
