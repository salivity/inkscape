Adjust Text Baseline Offset for Math in Inkscape

Adjusting text baseline offsets in Inkscape allows you to properly align mathematical formulas, subscripts, superscripts, and inline symbols with standard text. This guide covers how to adjust the vertical baseline shift for editable text strings using Inkscape's typography controls, how to use keyboard shortcuts for rapid micro-adjustments, and how to vertically align LaTeX-rendered vector formulas with surrounding text.

Method 1: Using the Text Tool Toolbar (Editable Text)

If your formula consists of standard Unicode characters or native text elements:

  1. Select the Text tool from the left toolbar or press T.
  2. Click inside your text object and highlight the specific character, variable, or symbol you need to offset (such as an exponent, index, or limit).
  3. Look at the Tool Controls bar at the top of the canvas. Locate the Vertical shift input box (represented by an icon showing characters shifted vertically, or labeled as vertical kerning/shift).
  4. Enter a numerical value (measured in pixels, points, or your document's default unit):
    • A negative value moves the selected character upward (ideal for superscripts or numerators).
    • A positive value moves the selected character downward (ideal for subscripts or denominators).
  5. Press Enter to apply the shift.

Method 2: Keyboard Shortcuts for Real-Time Fine-Tuning

For manual adjustments where visual alignment is preferred over exact numerical input:

  1. Select the Text tool (T) and highlight the characters to be adjusted.
  2. Hold Alt and press the Up Arrow to raise the character above the baseline.
  3. Hold Alt and press the Down Arrow to lower the character below the baseline.
  4. To apply larger increments, hold Shift + Alt while pressing the Up or Down arrow keys.

Method 3: Adjusting LaTeX Formula Objects (Vector Paths)

When formulas are generated via Extensions > Render > Mathematics > LaTeX (pdflatex), Inkscape creates grouped vector paths rather than native text. Because these paths lack font baseline metadata, adjust them using coordinates or alignment tools:

  1. Select the formula object with the Select and Transform tool (S or F1).
  2. Open the Align and Distribute panel by pressing Ctrl + Shift + A.
  3. Set the Relative to dropdown to First selected or Biggest object.
  4. Select both the standard text block and the formula object, then use the alignment options (such as Center on horizontal axis) to approximate placement.
  5. For fine-tuning, select only the formula object and use the Y coordinate field in the top toolbar to adjust its vertical placement, or tap Alt + Up/Down Arrow to nudge the object in sub-pixel increments until it sits naturally on the adjacent text's baseline.

Method 4: Modifying the SVG XML Directly

For SVG-compliant formulas requiring absolute programmatic precision:

  1. Select the text element and press Ctrl + Shift + X to open the XML Editor.
  2. Locate the specific <tspan> node containing the formula component.
  3. In the right pane, locate or create the dy attribute.
  4. Assign a relative offset value (such as -0.4em for superscripts or 0.3em for subscripts).
  5. Click Set to apply the attribute change directly to the SVG structure.
