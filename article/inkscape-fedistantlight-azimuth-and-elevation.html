Inkscape feDistantLight Azimuth and Elevation

This article explains how to set and adjust the azimuth and elevation parameters for the feDistantLight filter primitive in Inkscape. By adjusting these two angles, you define the 3D direction of an infinite, parallel light source—similar to sunlight—across your 2D SVG artwork. You will learn what each parameter represents, how to configure them using Inkscape's built-in Filter Editor, and how to fine-tune them directly through the XML Editor.

Understanding Azimuth and Elevation

The feDistantLight element is a child of the feDiffuseLighting or feSpecularLighting filter primitives. It requires two directional angles:

  • Azimuth: The direction of the light source in the horizontal (X-Y) plane, measured in degrees from 0 to 360. An azimuth of 0 positions the light to the right (positive X-axis), rotating clockwise as the value increases (e.g., 90 is at the bottom, 180 is at the left, and 270 is at the top).
  • Elevation: The angle of the light source above the surface plane toward the Z-axis, measured in degrees from 0 to 90. An elevation of 0 means the light is parallel to the surface (grazing light, casting long shadows), while an elevation of 90 places the light directly overhead, pointing straight down.

Method 1: Using the Filter Editor

  1. Open the Filter Editor: Go to the top menu and select Filters > Filter Editor.
  2. Select or Create a Lighting Filter:
    • Select an existing filter containing lighting primitives from the list.
    • Alternatively, click New to create a custom filter, select Diffuse Light or Specular Light from the drop-down menu at the bottom, and click Add Primitive.
  3. Set Light Source to Distant Light:
    • Click on the Diffuse Light or Specular Light primitive in the list.
    • In the Effect parameters panel at the bottom, locate the Light source option.
    • Select Distant light from the drop-down menu.
  4. Adjust the Parameters:
    • Locate the Azimuth slider and drag it or type a specific angle (from 0 to 360) to change the horizontal direction of the light.
    • Locate the Elevation slider and adjust the value (from 0 to 90) to determine the height/angle of the light source relative to the plane.
  5. Apply to an Object: Select your object on the canvas and check the box next to your filter's name in the Filter Editor list to see the real-time lighting changes.

Method 2: Using the XML Editor

If you need precise numerical control or the visual slider in the Filter Editor does not update properly, you can edit the attributes directly in the SVG code:

  1. Open the XML Editor by navigating to Edit > XML Editor (or press Ctrl+Shift+X / Cmd+Shift+X).
  2. In the XML tree, expand the <svg:defs> tag to find your <svg:filter> element.
  3. Expand the filter element, locate <svg:feDiffuseLighting> or <svg:feSpecularLighting>, and expand it to reveal the <svg:feDistantLight> child node.
  4. Select <svg:feDistantLight>.
  5. In the attribute panel on the right:
    • Select or create the attribute azimuth and set its value (e.g., 225 for top-left illumination).
    • Select or create the attribute elevation and set its value (e.g., 45 for a balanced mid-height light).
  6. Click Set (or press Ctrl+Enter) to apply the changes immediately to the canvas.
