Inkscape Custom Filter Template Locations

This article explains where Inkscape stores filter templates, covering both user-defined custom filters and system-wide default files. You will learn the exact file paths across Windows, macOS, and Linux, how Inkscape recognizes these files, and how to verify your storage paths directly within the application settings.

Inkscape Filter Storage Concept

Inkscape stores filters as SVG files containing standard SVG <filter> element definitions. Instead of using a proprietary configuration file, Inkscape reads .svg files placed in designated filter folders and automatically displays them in the Filters menu.

While built-in presets reside in the system installation directory, user-created custom filters are meant to be saved in the user profile directory so they persist across software updates. However, administrators can also place custom filter SVG files into the system directory to make them available globally to all users on that machine.

System Directory Locations

If you want custom filter templates to be available system-wide across all user accounts on a computer, place your SVG filter files into the following system directories:

  • Windows:
    C:\Program Files\Inkscape\share\inkscape\filters\
  • Linux:
    /usr/share/inkscape/filters/
    (or /app/share/inkscape/filters/ if installed via Flatpak)
  • macOS:
    /Applications/Inkscape.app/Contents/Resources/share/inkscape/filters/

Files placed here require administrative or root permissions to create or modify.

User-Defined Directory Locations

By default, Inkscape expects user-defined templates and custom filters to be stored in your user configuration profile. This keeps your modifications safe when updating or reinstalling the software:

  • Windows:
    %APPDATA%\inkscape\filters\
    (Full path: C:\Users\<YourUsername>\AppData\Roaming\inkscape\filters\)
  • Linux:
    ~/.config/inkscape/filters/
  • macOS:
    ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/filters/

Note: If the filters folder does not exist inside your user profile directory, you can create it manually.

Finding Paths via Inkscape Preferences

If your installation uses a non-standard path, a portable setup, or a package manager (such as Snap or Flatpak), you can identify the exact directory paths through the program itself:

  1. Open Inkscape.
  2. Go to Edit > Preferences (or press Ctrl + Shift + P / Cmd + Shift + P).
  3. Select System from the left-hand navigation tree.
  4. Locate the User config and Inkscape data entries to see the exact base folders for both your user directory and system directory.
  5. Append /filters/ to either path to locate your active filter storage folder.
