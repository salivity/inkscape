Create Spirograph Curves in Inkscape

Inkscape features a built-in rendering tool designed to produce intricate, geometric Spirograph patterns known mathematically as hypotrochoids and epitrochoids. By adjusting mathematical parameters such as fixed ring radius, moving gear radius, and pen distance, you can quickly generate complex vector line art. This guide provides a straightforward walkthrough on how to locate, configure, and generate these curves directly inside Inkscape.

Accessing the Spirograph Extension

To open the Spirograph generator:

  1. Open Inkscape and create a new document or open an existing project.
  2. In the top menu, navigate to Extensions.
  3. Hover over Render.
  4. Select Spirograph... from the submenu.

A dialog window will appear containing the numerical settings and a preview toggle.

Configuring Curve Parameters

The pattern's shape is determined by the relationship between the fixed circle, the moving circle, and the drawing point:

  • \(R\) (Ring Radius): Defines the radius of the fixed outer circle.
  • \(r\) (Gear Radius): Defines the radius of the inner moving circle that rolls along the fixed ring. A negative value generates an epitrochoid (rolling along the outside of the ring), while a positive value generates a hypotrochoid (rolling along the inside).
  • \(d\) (Pen Distance): Sets the distance from the center of the rolling gear to the drawing pen point. Setting \(d < r\) creates a standard hypotrochoid, while \(d > r\) yields elongated, looped shapes.
  • Rotation: Sets the initial angular offset of the pattern in degrees.
  • Quality / Steps: Determines the smoothness and resolution of the resulting vector path. Higher values generate smoother curves at the expense of more path nodes.

Generating the Pattern

  1. Check the Live Preview box in the bottom-left corner of the dialog box to see real-time updates on your canvas.
  2. Adjust the values of \(R\), \(r\), and \(d\) until you achieve the desired number of petals and overlap density. Using integer ratios between \(R\) and \(r\) will produce closed, symmetrical patterns.
  3. Click Apply to generate the vector path on your active layer.
  4. Click Close to exit the tool.

Styling the Rendered Path

Once generated, the Spirograph pattern is a standard vector path:

  • Stroke Width and Color: Open the Fill and Stroke panel (Shift + Ctrl + F) to modify line thickness, stroke paint color, or gradient fills.
  • Layering Patterns: You can run the extension multiple times with slight variations in the Rotation or Pen Distance fields to create multi-layered, multicolored geometric designs.
