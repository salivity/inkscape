How to Install Inkscape on macOS Using Homebrew

Installing Inkscape on macOS using Homebrew is one of the fastest and cleanest ways to set up this popular open-source vector graphics editor. This guide provides a straightforward, step-by-step walkthrough to get Inkscape running on your Mac via the command line, along with essential commands to update and remove the application when needed.

Prerequisites

Before proceeding, ensure you have the following:

  • A Mac running macOS.
  • Access to the Terminal application (found in /Applications/Utilities/ or via Spotlight).
  • Homebrew installed. If you do not have it, install it by pasting the official installation script into your Terminal.

Step 1: Update Homebrew

Ensure your local Homebrew repository has the latest package definitions by running:

brew update

Step 2: Install Inkscape

Because Inkscape is a graphical user interface (GUI) application, it is distributed through Homebrew Cask. Run the following command to download and install Inkscape:

brew install --cask inkscape

Homebrew will download the official .dmg file, verify it, and move the Inkscape application to your /Applications directory automatically.

Step 3: Launch Inkscape

Once the installation completes, you can open Inkscape in several ways:

  1. Via Finder / Launchpad: Open your Applications folder and double-click the Inkscape icon.
  2. Via Spotlight: Press Cmd + Space, type Inkscape, and press Enter.
  3. Via Terminal: Launch it directly from the command line using: 
    open -a Inkscape

Managing Your Inkscape Installation

To keep Inkscape up to date or remove it in the future, use the following Homebrew commands:

  • Update Inkscape:

    brew upgrade --cask inkscape

  • Uninstall Inkscape:

    brew uninstall --cask inkscape
