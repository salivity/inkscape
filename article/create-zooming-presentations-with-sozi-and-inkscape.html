Create Zooming Presentations with Sozi and Inkscape

This guide provides a straightforward walkthrough on using Inkscape alongside Sozi to build dynamic, non-linear presentations. You will learn how to design your visual canvas in Inkscape, define individual camera frames, configure fluid pan and zoom transitions, and export the final interactive presentation as a web-ready file that runs in any modern browser.

1. Prepare Your Visual Canvas in Inkscape

  1. Open Inkscape and create a new document.
  2. Group related graphics, diagrams, and text blocks across a single large canvas rather than dividing them across multiple pages.
  3. Keep the visual hierarchy clear. You can place smaller details inside larger illustrations to take full advantage of Sozi's deep zooming capabilities.
  4. (Optional) Create placeholder rectangles over the specific regions you want the camera to focus on during each slide. Set their stroke and fill to transparent if you do not want them visible in the final presentation.
  5. Save your document in the standard Inkscape SVG format.

2. Open the SVG in Sozi

Modern versions of Sozi operate as a standalone application that directly reads and writes Inkscape SVG files:

  1. Launch the Sozi desktop application.
  2. Click the open icon or press Ctrl + O (Cmd + O on macOS) to select your saved SVG file.
  3. Your Inkscape artwork will load directly into the central workspace.

(Note: If using a legacy version of the Sozi Inkscape extension, navigate directly within Inkscape to Extensions > Sozi to launch the frame editor interface.)

3. Create and Position Presentation Frames

  1. Click the + (Add Frame) button in the Sozi timeline panel to create your first frame.
  2. Use your mouse to frame the view:
    • Click and drag to pan across the canvas.
    • Scroll the mouse wheel to zoom in or out.
    • Right-click and drag (or hold Shift while dragging) to rotate the view if desired.
  3. Alternatively, click on one of the transparent placeholder rectangles you created in Inkscape; Sozi can automatically fit the camera view to match that object's boundaries.
  4. Give each frame a meaningful title in the properties panel to easily track the flow.
  5. Repeat this process for each stop in your presentation.

4. Adjust Transition Properties

Select a frame in the timeline to customize how the camera moves toward it:

  • Duration: Set the transition time in seconds (e.g., 1.0 to 1.5 seconds for smooth movement).
  • Timing Function: Choose an easing profile such as Linear, Accelerate, or Decelerate to control the acceleration of the camera.
  • Path Profile: Adjust the zoom-out factor during transitions. A higher profile forces the camera to pull backward before diving into the next frame, providing spatial context.
  • Layer Visibility: Hide or reveal specific Inkscape layers on a per-frame basis to show details progressively.

5. Save and Present

  1. Save your project in Sozi using Ctrl + S (Cmd + S).
  2. Sozi automatically generates a companion HTML file in the same directory as your SVG (e.g., presentation.sozi.html).
  3. Open the resulting HTML file in any modern web browser to view the presentation.
  4. Navigate during the live presentation using:
    • Spacebar / Right Arrow: Move to the next frame.
    • Left Arrow: Move to the previous frame.
    • Mouse Click: Advance forward.
    • F: Toggle full-screen mode.
