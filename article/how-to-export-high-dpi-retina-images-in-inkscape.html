How to Export High-DPI Retina Images in Inkscape

Exporting crisp raster images for high-density and Retina displays requires increasing the pixel density beyond standard web resolution. This guide explains how to configure Inkscape's export settings to output raster images (such as PNG or WebP) at 2x (@2x) and 3x (@3x) resolutions, ensuring your graphics appear sharp on modern high-DPI screens without blurriness.

Understanding DPI for Retina Displays

Standard web graphics are typically rendered at a baseline of 96 DPI (dots per inch) in Inkscape, representing a 1x standard display. High-DPI (Retina) screens pack more physical pixels into the same display space, requiring assets with higher pixel density:

  • 1x (Standard): 96 DPI (Base dimensions)
  • 2x (Retina / High-DPI): 192 DPI (Double the pixel dimensions)
  • 3x (Super Retina / Ultra-DPI): 288 DPI (Triple the pixel dimensions)

Step-by-Step Export Process

1. Open the Export Panel

  1. Select the graphic, layer, or page you want to export.
  2. Navigate to File > Export... in the top menu, or press the keyboard shortcut Ctrl + Shift + E (Windows/Linux) or Cmd + Shift + E (macOS).

2. Choose the Export Area

Select the appropriate scope for your image from the top tabs of the Export panel:

  • Document: Exports the entire canvas area.
  • Page: Exports only the defined page boundary.
  • Selection: Exports only the currently selected objects.
  • Custom: Exports a user-defined bounding box.

3. Adjust the DPI or Pixel Dimensions

Under the Image size section of the Export panel:

  1. Locate the DPI field (default is 96.0).
  2. For standard Retina (@2x), change the value to 192.0. Inkscape will automatically double the Width (px) and Height (px) values.
  3. For ultra-high density (@3x), change the value to 288.0. Inkscape will automatically triple the pixel dimensions.

Alternatively, you can leave the DPI field alone and manually multiply the Width and Height pixel values by 2 or 3.

4. Set Format and File Name

  1. Choose your desired raster format from the dropdown menu (typically PNG for transparent graphics, or WebP/JPEG for photos).
  2. Click the folder icon next to the file path to name your file. Use standard naming conventions for high-DPI assets, such as icon@2x.png or graphic-retina.png.

5. Complete the Export

Click the Export button at the bottom of the panel. Inkscape will render the vector elements into a high-resolution raster graphic optimized for crisp rendering on Retina displays.
