Align Text to a Specific Node on a Path in Inkscape

Placing text along a closed path in Inkscape often results in the text starting at an unintended location, as the software automatically aligns text to the path’s original starting node. To control precisely where the text begins, you must designate your desired anchor point as the path's new start node. This guide covers the exact steps to select a specific node, set it as the starting anchor, and attach your text accurately.

Step 1: Convert the Shape to a Path

If your closed shape is a native Inkscape primitive (such as an ellipse, rectangle, or star), it must first be converted into a standard path:

  1. Select the shape with the Select Tool (S).
  2. Navigate to the top menu and click Path > Object to Path (or press Shift + Ctrl + C).

Step 2: Select the Anchor Node

  1. Switch to the Node Tool (N) from the left toolbar.
  2. Click on the path to reveal its nodes.
  3. Identify where you want the text to begin. If a node does not already exist at that exact spot, double-click on the path line to insert a new node.
  4. Click directly on the target node to select it (it will change color to show it is active).

Step 3: Set the Node as the Starting Point

Inkscape defines the starting position of text along an open path at the first terminal node. For a closed path, you can set the start point by splitting the path at the chosen node:

  1. With the node selected, look at the tool controls bar at the top of the canvas.
  2. Click the Break path at selected nodes button.
  3. This action splits the single node into two overlapping endpoint nodes, resetting this location as the official start and end of the path without altering its visual shape.

Step 4: Put the Text on the Path

  1. Select both the text object and the modified path simultaneously by holding Shift and clicking each item.
  2. Go to the menu and select Text > Put on Path.
  3. The text will automatically anchor its beginning to the node you broke in Step 3.

Step 5: Adjust Direction and Alignment

  • Inverted or Backward Text: If the text appears upside down or runs counter-clockwise along the path, select only the path using the Node Tool and click Path > Reverse.
  • Centering or Right-Aligning: By default, text is left-aligned, starting directly at the anchor node. You can change this by selecting the text, opening the Text and Font dialog (Shift + Ctrl + T), and choosing Center or Right alignment relative to that anchor.
