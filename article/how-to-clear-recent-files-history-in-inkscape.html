How to Clear Recent Files History in Inkscape

Inkscape automatically tracks previously opened documents to allow quick access through the Welcome screen and the File menu. While convenient, this list can expose client names, personal project details, and file paths on shared or monitored workstations. This guide outlines the steps required to clear and disable the recent files history in Inkscape to maintain your privacy.

Method 1: Remove Files from the Welcome Screen

In modern versions of Inkscape, you can remove items directly from the startup dialog without altering system files.

  1. Open Inkscape to display the Welcome Screen. If Inkscape is already open, you can view this screen by navigating to Help > About Inkscape or opening a new window depending on your configuration.
  2. Click on the Existing Files tab on the left side of the window.
  3. Locate the thumbnail of the file you wish to remove.
  4. Click the small X icon in the corner of the thumbnail or right-click the item and select Remove from list.
  5. Repeat this process for each file you want to erase from view.

Method 2: Adjust Recent File Limits in Preferences

To prevent Inkscape from recording your file history in the future, you can limit or turn off the history tracking directly in the application settings.

  1. Launch Inkscape and go to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  2. In the left navigation menu, expand the Interface section.
  3. Locate the setting for Maximum recent files or Recent files count.
  4. Change this numerical value to 0.
  5. Close the Preferences window and restart Inkscape. Setting this value to zero forces the application to stop logging opened documents.

Method 3: Delete the History Files Manually

Because Inkscape is built on the GTK framework, it relies on system-level configuration files to maintain its history. Deleting or editing these files guarantees complete removal.

On Windows:

  1. Close Inkscape completely.
  2. Press Windows Key + R to open the Run prompt.
  3. Type %APPDATA%\inkscape and press Enter.
  4. Open the preferences.xml file using a text editor such as Notepad.
  5. Search for the section tagged <group id="recent" or lines referencing recent file paths.
  6. Delete the entries containing the file paths, save the file, and close the editor.
  7. Clear your Windows Recent list by opening the Run prompt again, typing recent, and deleting the shortcuts.

On Linux:

Inkscape stores file history inside the shared GTK recent files list.

  1. Close Inkscape.
  2. Open a terminal.
  3. Remove or clear the recent document cache using the command: 
    rm ~/.local/share/recently-used.xbel
  4. Restart your session or reopen Inkscape to confirm the history has been wiped.

On macOS:

  1. Quit Inkscape.
  2. Open Finder, press Cmd + Shift + G, and navigate to: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/
  3. Open preferences.xml in a text editor, remove the entries under the recent files tag, and save the file.
