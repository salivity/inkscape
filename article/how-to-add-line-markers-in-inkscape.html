How to Add Line Markers in Inkscape

Adding start, mid, and end markers to lines in Inkscape is a straightforward way to create arrows, dimension lines, and custom vector diagrams. This guide walks you through selecting your path, accessing the Fill and Stroke panel, and applying and configuring markers at the beginning, middle, and end points of any stroke.

Step 1: Draw or Select Your Line

  1. Select the Draw Bézier curves and straight lines tool (B) or the Freehand Lines tool (P) from the left toolbar.
  2. Click and drag on the canvas to create your line. If you want mid markers to appear, click multiple times to add intermediate nodes along the path.
  3. If the line is already drawn, switch to the Select and transform objects tool (S) and click on the line to select it.

Step 2: Open the Fill and Stroke Dialog

  1. Navigate to the top menu and select Object > Fill and Stroke..., or press the keyboard shortcut Ctrl + Shift + F (Windows/Linux) or Cmd + Shift + F (macOS).
  2. In the panel that opens on the right side of the screen, click the Stroke style tab.

Step 3: Apply the Markers

Within the Stroke style tab, locate the Markers section. You will see three dropdown menus:

  • Start Marker (Left Dropdown): Controls the marker placed at the very first node of the path. Click the dropdown to choose from predefined arrows, dots, squares, or custom shapes.
  • Mid Markers (Center Dropdown): Controls the markers applied to every node between the first and last node. If your path is a simple two-node line, add more nodes using the Edit paths by nodes tool (N) by double-clicking on the path segment to make mid markers visible.
  • End Marker (Right Dropdown): Controls the marker applied to the final node of the path. Select your desired arrowhead or ending symbol.

Step 4: Adjust Marker Size and Color

  • Size and Width: In Inkscape, marker size scales automatically with the Stroke width setting located directly above the Markers section. Increasing or decreasing the stroke width will resize the attached markers proportionally.
  • Color: By default, markers automatically inherit the color defined in the Stroke paint tab.
  • Orientation and Customization: In Inkscape 1.2 and later, you can click the small settings/edit icon next to the marker dropdowns to flip, scale, offset, or rotate the markers independently of the stroke.
