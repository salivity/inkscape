Create Stained Glass with Light Rays in Inkscape

This guide explains how to design a vibrant vector stained-glass window and complement it with glowing, volumetric light rays using Inkscape. You will learn how to create the structural lead framework, apply rich color gradients to individual glass panes, and construct realistic light shafts using basic shapes, Gaussian blur, and blend modes.

Step 1: Create the Window Frame and Lead Lines

Begin by creating the outer silhouette of the window using the Rectangle tool, converting the top corners to arches, or using the Circle tool for a rosette style.

  1. Use the Draw Freehand Lines or Bezier Curves tool (B) to divide the interior into your desired pattern (geometric, floral, or pictorial).
  2. Select all intersecting lines, open the Fill and Stroke panel (Shift + Ctrl + F), and set the stroke width to a thick size (e.g., 6 px to 12 px depending on canvas scale) to mimic the lead came.
  3. Set the stroke color to a very dark charcoal rather than pure black (#1a1a1a) to allow for subtle depth.
  4. Convert the strokes to filled shapes by navigating to Path > Stroke to Path (Ctrl + Alt + C), then merge them into a single object using Path > Union (Ctrl + +).

Step 2: Fill and Color the Glass Panes

To easily color each glass section:

  1. Select your unified lead framework.
  2. Select the Fill Bounded Areas (Paint Bucket) tool (U). Ensure the threshold is properly tuned so fills touch the borders without gaps.
  3. Click inside each individual segment to generate a unique vector shape for that pane.
  4. Color each pane with vibrant jewel tones (emerald, cobalt, ruby, amber).
  5. Switch to the Gradient tool (G) and apply linear or radial gradients across individual panes. Angling light-to-dark transitions adds authenticity and simulates the varying thickness of hand-blown glass.

Step 3: Add Glass Highlights and Internal Reflections

To make the glass look reflective and translucent:

  1. Duplicate the colored panes (Ctrl + D) and group them (Ctrl + G).
  2. Give the duplicate group a semi-transparent white fill.
  3. Draw diagonal slices across the shapes using the Bezier tool and use Path > Difference to leave thin, diagonal glare strips across the glass.
  4. Lower the opacity of these glare shapes to between 10% and 25%.

Step 4: Construct the Volumetric Light Rays

Light rays emerge outward from the light source and broaden as they travel into a room:

  1. Create a new layer beneath the window frame or directly in front of the background, labeled "Light Rays."
  2. Using the Bezier Curves tool, draw long trapezoidal shapes extending from the window outward across the canvas. The narrow end should align with bright sections of the window, and the wide end should extend off-screen or toward the floor.
  3. Set the fill of these shapes to a pale, warm white, light yellow, or tint matching the glass color they emanate from. Remove any stroke.
  4. With multiple light shapes selected, combine them into one path using Path > Union.

Step 5: Apply Blur and Blend Modes for the Glow Effect

To turn the hard-edged polygons into soft, diffused shafts of light:

  1. Open the Fill and Stroke panel.
  2. Adjust the Blur slider on your light ray path to between 5% and 15% to soften the edges into a haze.
  3. Reduce the overall Opacity of the rays to around 20% to 40%.
  4. Open the Layers and Objects panel (Shift + Ctrl + L), locate the light layer, and set its Blend Mode to Screen or Lighten. This ensures the light interacts naturally with underlying surfaces without flattening darker shadows.

Step 6: Create the Central Window Flare

Enhance the intensity of the light source directly at the window:

  1. Draw an ellipse over the center of the window using the Circle tool.
  2. Apply a radial gradient to the ellipse, with pure white in the center and transparent white at the perimeter.
  3. Increase the Blur to approximately 30% to 50% and lower the Opacity to 50%.
  4. Set the blend mode to Screen to create a bloom effect that washes slightly over the lead lines, reinforcing the illusion of intense backlighting.
