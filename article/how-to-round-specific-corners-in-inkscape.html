How to Round Specific Corners in Inkscape

Inkscape provides a non-destructive way to smooth individual sharp vertices using the Corners (Fillet/Chamfer) Live Path Effect (LPE). This guide explains how to apply the effect, select specific nodes, and adjust corner radiuses to create precise, rounded corners on any vector path.

Step 1: Convert the Shape to a Path

The Corners effect only functions on paths. If you are starting with a basic shape (such as a rectangle, star, or polygon):

  1. Select the object using the Select Tool (S).
  2. Go to the menu and choose Path > Object to Path (or press Shift + Ctrl + C).

Step 2: Add the Corners (Fillet/Chamfer) Path Effect

  1. Keep your path selected.
  2. Open the Path Effects dialog by navigating to Path > Path Effects (or press Ctrl + & / Ctrl + Shift + 7 depending on your version).
  3. In the Path Effects panel, click the + (Add Path Effect) button.
  4. Search for Corners (Fillet/Chamfer) in the list and click it to apply.

Step 3: Select and Round Specific Nodes

  1. Switch to the Node Tool by pressing N or selecting the icon from the left toolbar.
  2. Click on the path. You will notice temporary green control handles appearing next to each sharp corner node.
  3. Select the specific node (or multiple nodes by holding Shift or dragging a selection box) that you want to round.
  4. Drag the green control handle associated with the selected node toward the center of the shape to increase the corner radius.

Step 4: Adjust Corner Settings Precisely

For exact numerical control or alternative corner styles:

  • Radius via Node Tool: When a node handle is selected, look at the tool controls bar at the top of the screen to input an exact radius value.
  • Fillet vs. Chamfer: In the Path Effects panel, you can switch the corner mode from Fillet (rounded) to Inverse Fillet, Chamfer (straight bevel), or Inverse Chamfer.
  • Global vs. Individual Control: Unselected nodes will remain sharp, allowing you to round only the specific corners required for your design.

Step 5: Finalize the Geometry (Optional)

Because this is a Live Path Effect, the corners remain editable at any time. If you need to export the file to formats that do not support Inkscape's live effects or perform Boolean operations:

  1. Select the object.
  2. Go to Path > Object to Path to permanently bake the rounded corners into standard Bézier curves.
