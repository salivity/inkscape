How to Lasso Select Nodes in Inkscape

Selecting specific groups of nodes on complex vector shapes in Inkscape can be tedious using standard rectangular selection boxes. This guide covers how to use the freehand lasso selection feature to surround and select any arbitrary group of path nodes quickly using the Node Tool and a simple keyboard shortcut.

How to Use the Lasso Selection for Nodes

  1. Activate the Node Tool: Select your vector object, then switch to the Node Tool by pressing N or F2 on your keyboard, or by clicking the Node Tool icon in the left-hand toolbar.
  2. Hold the Alt Key: Press and hold the Alt key (or Option on macOS).
  3. Draw the Selection: Click and drag your mouse around the nodes you want to select. Inkscape will draw a red freehand path tracing your cursor's movement.
  4. Complete the Selection: Enclose the target nodes and release the mouse button. All nodes falling inside or intersected by the drawn loop will become selected.

Modifier Keys for Advanced Selection

  • Add to Selection: Hold Shift + Alt while dragging to add another group of arbitrary nodes to your current selection without deselecting the previous nodes.
  • Invert or Subtract: You can toggle the selection state of nodes within a new lasso area by using Shift + Alt over already selected nodes.

If the Alt key is captured by your window manager (common in some Linux desktop environments), you can configure Inkscape's modifier keys under Edit > Preferences > Interface > Windows or use your operating system settings to disable the window-moving shortcut assigned to Alt.
