Set Vertical Asian Text Orientation in Inkscape

This guide explains how to configure vertical text layouts for East Asian typography—such as Chinese, Japanese, and Korean (CJK)—directly within Inkscape. You will learn how to activate top-to-bottom writing modes, manage line progression, and ensure characters are oriented correctly using Inkscape's native text tools.

Enabling Vertical Text Mode

  1. Select the Text tool from the left toolbar, or press T (or F8).
  2. Look at the Tool Controls Bar at the top of the workspace.
  3. Locate the Text orientation icon, which displays characters stacked vertically rather than horizontally.
  4. Click this icon to toggle from horizontal writing (horizontal-tb) to vertical writing (vertical-rl).
  5. Click on your canvas and begin typing; text will now flow from top to bottom, with new lines progressing from right to left.

Using the Text and Font Dialog

For greater precision and access to font-specific OpenType features:

  1. Open the Text and Font panel by pressing Shift + Ctrl + T or navigating to Text > Text and Font... in the menu.
  2. In the panel, choose an East Asian font that natively supports vertical glyph forms (such as Noto Sans CJK, Meiryo, or MS Gothic).
  3. If an existing horizontal text object is selected, switch its orientation using the top controls bar, then click Apply in the Text and Font dialog to refresh glyph metrics and baseline alignments.

Adjusting Glyph Orientation and Mixed Scripts

When working with mixed-script content (such as English letters or numbers within vertical Asian text):

  • Upright Latin Characters: Standard vertical writing typically rotates Latin text 90 degrees clockwise. To keep individual Latin letters or numbers upright within a vertical column, select the specific characters with the Text tool and adjust the Character rotation field on the top control bar to -90 or 270 degrees.
  • Line Spacing and Kerning: Use the Line height and Letter spacing fields on the Tool Controls Bar to properly space full-width vertical glyphs according to standard CJK typographic conventions.
