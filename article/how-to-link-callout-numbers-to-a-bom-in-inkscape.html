How to Link Callout Numbers to a BOM in Inkscape

This guide explains how to establish interactive, clickable connections between technical callout numbers and a Bill of Materials (BOM) table using Inkscape. By utilizing Inkscape’s native SVG hyperlinking and element identification tools, you can transform static assembly diagrams and technical schematics into responsive documents where clicking a callout bubble instantly directs the viewer to its corresponding entry in the parts list.

1. Assign an ID to the Target BOM Row

To link to a specific line in your Bill of Materials, that line must have a unique identifier.

  1. Select the text or grouped row in your BOM table that corresponds to the component.
  2. Open the Object Properties panel by pressing Shift + Ctrl + O (or navigate to Object > Object Properties).
  3. In the ID field, enter a concise, unique name (e.g., bom-part-01).
  4. Click Set to apply the ID to the element.

2. Group the Callout Elements

Callout numbers typically consist of a number inside a circular or polygonal border. These should be combined before adding a link.

  1. Select both the callout number and the bounding shape.
  2. Group them together by pressing Ctrl + G (or navigate to Object > Group).

3. Create the Internal Hyperlink

Inkscape uses standard SVG anchor tags (<a>), allowing you to create internal document jumps using the # symbol followed by the target element's ID.

  1. Right-click the grouped callout object on your canvas.
  2. Select Create Link from the context menu. This wraps the object in an anchor tag and opens the link attributes in the Object Properties panel.
  3. In the Href field, enter # followed immediately by the ID you assigned in Step 1 (e.g., #bom-part-01).
  4. (Optional) Set the Title field to display a tooltip when a user hovers over the callout (e.g., Jump to Part 01 in BOM).
  5. Click Set.

4. Create Two-Way Navigation (Optional)

To enhance usability, you can allow users to jump from the BOM table back to the drawing.

  1. Select the callout group and open Object Properties to note or set its ID (e.g., callout-part-01).
  2. Select the item number or description in the BOM table.
  3. Right-click and choose Create Link.
  4. In the Href field, enter #callout-part-01 and click Set.

5. Export for Interactive Viewing

Internal SVG anchors require a viewer that supports standard web hyperlinks to function properly.

  • For Web or Direct SVG Viewing: Save the file as an Optimized SVG or Plain SVG via File > Save As. The links will work automatically when opened in any modern web browser.
  • For PDF Delivery: Go to File > Save As and select Portable Document Format (*.pdf). Ensure that standard text and vector output is maintained so PDF readers can parse the embedded hyperlinked anchors.
