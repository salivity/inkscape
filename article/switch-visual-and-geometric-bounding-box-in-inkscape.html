Switch Visual and Geometric Bounding Box in Inkscape

This guide explains how to toggle between visual and geometric bounding boxes in Inkscape using the Selector tool preferences. Inkscape allows users to define how object dimensions are calculated, either by including design elements like stroke width or by relying strictly on path nodes. Learning how to access and adjust these settings ensures your measurements, alignments, and exports are accurate for your specific design workflow.

Visual vs. Geometric Bounding Boxes

  • Visual Bounding Box: Encloses the entire visible object, including stroke width, blur, markers, and other applied effects. This mode is best for visual layout, alignment, and determining the true footprint of an element.
  • Geometric Bounding Box: Calculated exclusively from the exact coordinates of the path nodes, ignoring stroke widths and outer effects. This mode is best for precision technical drawings, exact snapping, and aligning objects based strictly on their underlying geometry.

How to Change the Bounding Box Mode

Follow these steps to toggle the bounding box type via the Selector tool settings:

  1. Access the Selector Tool Preferences:

    • Method A: Double-click the Selector tool icon (the black arrow) located in the vertical toolbox on the left side of the screen.
    • Method B: Open the main preferences window by navigating to Edit > Preferences from the top menu, or by pressing Ctrl + Shift + P (Windows/Linux) or Cmd + Shift + P (macOS). Then, expand the Tools category in the left-hand menu and select Selector.

  2. Select Your Desired Bounding Box Type:

    • In the Selector preferences panel, locate the section titled Bounding box to use.
    • Choose Visual bounding box to calculate sizes based on the visible boundaries of strokes and effects.
    • Choose Geometric bounding box to calculate sizes strictly according to node locations.

  3. Apply the Changes:

    • Close the Preferences dialog. The setting applies immediately to all currently selected objects and future selections within your document.
