Batch Convert SVG to PNG with Inkscape CLI

Batch converting multiple SVG files into PNG format using the Inkscape Command-Line Interface (CLI) is an efficient way to automate your graphic workflow. This guide outlines how to process entire directories of vector graphics into high-resolution raster images across Windows, macOS, and Linux without opening the graphical user interface.

Prerequisites

Ensure Inkscape is installed and accessible via your system's terminal or command line. In Inkscape version 1.0 and later, the CLI syntax uses --export-type and --export-filename.

To verify your installation, run:

inkscape --version

If the command is not recognized, add the Inkscape installation directory to your system's PATH variable, or use the full path to the executable (e.g., C:\Program Files\Inkscape\bin\inkscape.exe on Windows or /Applications/Inkscape.app/Contents/MacOS/inkscape on macOS).

Method 1: Native Inkscape Batch Command (Linux & macOS)

The simplest method is to pass all SVG files directly to Inkscape using a wildcard selector.

inkscape *.svg --export-type=png

This processes every .svg file in the current directory and generates a corresponding .png file with the same base name.

Method 2: Shell Loop (Linux & macOS)

Using a shell loop allows you to customize the output dimensions, DPI, or target folder.

Basic Loop

for file in *.svg; do
    inkscape "$file" --export-type=png --export-filename="${file%.svg}.png"
done

Loop with Custom Width and DPI

for file in *.svg; do
    inkscape "$file" --export-filename="${file%.svg}.png" --export-width=1920 --export-dpi=300
done

Method 3: Windows PowerShell

On Windows, open PowerShell in the directory containing your SVG files and run:

Get-ChildItem -Filter *.svg | ForEach-Object {
    inkscape $_.FullName --export-type=png --export-filename="$($_.DirectoryName)\$($_.BaseName).png"
}

To define specific output dimensions, append -w (width) or -h (height):

Get-ChildItem -Filter *.svg | ForEach-Object {
    inkscape $_.FullName --export-filename="$($_.BaseName).png" -w 1080
}

Method 4: Windows Command Prompt (CMD)

If you are using the traditional Windows Command Prompt, use the for loop:

for %f in (*.svg) do inkscape "%f" --export-type=png --export-filename="%~dpnf.png"

Note: If placing this command inside a .bat or .cmd batch script, use %%f instead of %f.

Useful CLI Flags for PNG Export

  • --export-type=png: Specifies the output format as PNG.
  • --export-filename=<path>: Defines the target file path and name.
  • -w <int> or --export-width=<int>: Sets the output image width in pixels.
  • -h <int> or --export-height=<int>: Sets the output image height in pixels.
  • -d <int> or --export-dpi=<int>: Sets the export resolution in dots per inch (default is 96 DPI).
  • --export-area-drawing: Crops the export area to the bounding box of all objects in the SVG rather than the full page canvas.
