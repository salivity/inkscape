Rotate Canvas View by 15 Degrees in Inkscape

Rotating the canvas view in Inkscape allows you to work comfortably on angled artwork without altering the actual coordinates of your design. While Inkscape provides built-in keyboard shortcuts to rotate selected objects by 15-degree increments, rotating the canvas view itself by exact 15-degree steps is primarily achieved through modifier-key combinations, status bar controls, or custom-assigned keyboard shortcuts.

Method 1: Using Modifier Keys with the Mouse (Constrained 15° Snapping)

Inkscape does not assign a single-key keyboard shortcut for 15-degree canvas rotation by default, but it provides a modifier-assisted shortcut that snaps the canvas view to exact 15-degree increments:

  1. Hold down Ctrl + Middle Mouse Button (scroll wheel click).
  2. Drag the mouse in a circular motion.
  3. Holding the Ctrl key forces the canvas to snap strictly to 15-degree increments (e.g., 15°, 30°, 45°).
  4. Release the mouse button when you reach the desired angle.

Alternatively, you can hold Ctrl + Shift and turn your Mouse Scroll Wheel to rotate the canvas smoothly.

Method 2: Adjusting via the Status Bar Using the Keyboard

You can precisely control the canvas angle using the keyboard via the Canvas Orientation field in the Status Bar:

  1. Locate the Rotation input box (R:) in the bottom-right corner of the Inkscape interface.
  2. Click into the box, or double-click to highlight the current degree value.
  3. Use the Up Arrow or Down Arrow keys to increment or decrement the angle.
  4. Type any multiple of 15 (e.g., 15, 30, 45, -15) and press Enter to instantly apply the rotation.
  5. To reset the canvas back to the default horizontal view, right-click the rotation field and select Reset rotation, or press Ctrl + 1 (or middle-click the canvas rotation field).

Method 3: Assigning Custom Keyboard Shortcuts

If you require dedicated keyboard keys to rotate the view in fixed steps without using the mouse:

  1. Open Edit > Preferences (or press Ctrl + Shift + P).
  2. In the left panel, navigate to Interface > Keyboard Shortcuts.
  3. Use the search bar to search for Canvas Orientation or Rotate.
  4. Locate the commands for rotating the canvas view clockwise and counter-clockwise.
  5. Click on the shortcut column for the command and press your desired key combination to assign it.

Canvas View Rotation vs. Object Rotation

It is common to confuse rotating the canvas view with rotating artwork:

  • Object Rotation: Pressing [ (rotate counter-clockwise) and ] (rotate clockwise) rotates selected objects by 15 degrees. This angle step can be modified in Preferences > Behavior > Steps > Rotation snaps every.
  • Canvas View Rotation: Affects only your viewing angle on screen and does not modify the positions, transforms, or exported coordinates of any artwork in your document.
