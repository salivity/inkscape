Split a Node into Two Overlapping Nodes in Inkscape

This guide explains how to divide a single node into two distinct, coincident nodes on a path in Inkscape. By utilizing the built-in path-breaking functionality, you can split a path at an exact coordinate, creating two separate overlapping endpoints without altering the shape, curve handles, or spatial positioning of your original vector artwork.

Step 1: Select the Path and the Node Tool

Activate the Edit paths by nodes tool from the left-hand toolbar, or press the shortcut key N. Click directly on the vector object containing the node you want to duplicate.

Step 2: Select the Target Node

Click directly on the specific node you wish to expand into two. The selected node will change color (typically highlighting in red or blue depending on your theme) to indicate it is active.

Step 3: Break the Path at the Selected Node

Look at the Node Tool control bar located directly above the canvas. Locate and click the Break path at selected nodes icon (represented by an icon showing a node breaking apart into two squares with an opening between them). Alternatively, you can use the keyboard shortcut Shift + B.

Inkscape instantly splits the single node into two separate end nodes. Both nodes remain at the exact same coordinates, perfectly overlapping each other without any shift in position.

Step 4: Verify or Separate the Overlapping Nodes

To verify the operation succeeded:

  • Click and drag one of the nodes away; you will see the second node remains stationary underneath it. Press Ctrl + Z to undo the movement and return it to its overlapping position.
  • If you need these two nodes to belong to completely separate vector objects rather than sub-paths of the same object, go to the top menu and select Path > Break Apart (or press Ctrl + Shift + K).
