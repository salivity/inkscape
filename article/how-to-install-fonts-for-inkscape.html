How to Install Fonts for Inkscape

Inkscape does not have an internal font manager; instead, it automatically detects and loads the TrueType (.ttf) and OpenType (.otf) fonts installed directly on your operating system. To use new typography in your design projects, you simply need to install the font files on your computer (Windows, macOS, or Linux) and restart Inkscape if it is currently open.

Installing Fonts on Windows

  1. Download the font file and extract the contents if it is inside a ZIP archive.
  2. Locate the .ttf or .otf file.
  3. Right-click the font file and select Install (or Install for all users if you want it available to every user account on the machine).
  4. Alternatively, double-click the font file to open the Windows Font Viewer and click the Install button in the top-left corner.

Installing Fonts on macOS

  1. Download and extract the font archive.
  2. Double-click the .ttf or .otf file to open the macOS Font Book preview window.
  3. Click the Install Font button at the bottom of the window.
  4. The font is now registered with the system and available to all applications.

Installing Fonts on Linux

  1. Download and extract your font files.
  2. Move the .ttf or .otf files to your personal fonts directory located at ~/.local/share/fonts (or ~/.fonts on older distributions). If the folder does not exist, create it.
  3. To install system-wide for all users, move the files to /usr/local/share/fonts (requires sudo privileges).
  4. Open a terminal and run the command fc-cache -f -v to refresh your system's font cache.

Accessing the New Fonts in Inkscape

  1. If Inkscape was running while you installed the font, save your work, close the application, and reopen it so it can index the newly installed fonts.
  2. Select the Text tool (T or F8) from the left toolbar.
  3. Open the Text and Font panel by pressing Ctrl + Shift + T (Windows/Linux) or Cmd + Shift + T (macOS).
  4. Scroll through the font list or type the name of the new font in the search bar, select your desired style, and click Apply.
