How to Create Choropleth Maps in Inkscape

This guide outlines the complete process of creating data-driven choropleth maps using Inkscape, the free vector graphics editor. You will learn how to acquire an editable vector base map, structure your data classification, establish an effective color ramp, and efficiently select and color individual country vector paths to produce clean, professional thematic maps.

1. Acquire a Blank Vector Map

To color countries individually, you need an SVG file where each country is an independent path or object.

  • Download a blank SVG world or regional map (e.g., from Wikimedia Commons, Natural Earth Data, or simplemaps.com).
  • Ensure the file uses standard ISO country codes (such as "US", "FR", "DE") as path IDs, which makes finding specific territories significantly easier.

2. Prepare the File in Inkscape

  1. Open your downloaded SVG in Inkscape via File > Open.
  2. Select the map and check if it is locked inside groups. Press Ctrl + Shift + G (or Cmd + Shift + G on macOS) repeatedly to ungroup elements until individual countries can be clicked separately.
  3. Open the Fill and Stroke dialog (Ctrl + Shift + F).
  4. Open the Layers and Objects panel (Object > Layers and Objects) to view the hierarchy of your paths.

3. Establish a Data Scale and Color Palette

Before applying colors, organize your numerical data into 3 to 7 distinct bins or classes (e.g., Low, Medium, High).

  1. Select a scientifically tested color progression (such as palettes from ColorBrewer) suitable for sequential or diverging data.
  2. Using the Rectangle tool (R), draw a series of small squares next to your map canvas to serve as a visual palette.
  3. Fill each square with one of your classification colors from lowest to highest value.

4. Apply Colors to Country Paths

Method A: Direct Eyedropper Application (Best for few countries)

  1. Select the Dropper tool by pressing D.
  2. Click the country you want to color on the map.
  3. While holding the appropriate modifier or switching quickly to the Selector tool (S), select the country, then use the Dropper tool to click on your reference palette square.

Method B: Batch Selection by Data Class (Best for full maps)

  1. Switch to the Selector tool (S).
  2. Hold Shift and click on all countries that fall into your first data category.
  3. With all of those countries selected, click the corresponding color swatch in your bottom palette bar or use the Dropper tool on your reference square to fill them simultaneously.
  4. Repeat this process for each subsequent data category.

Method C: Finding Countries via the XML Editor

If tiny island nations or enclaves are difficult to click:

  1. Open the XML Editor (Edit > XML Editor or Ctrl + Shift + X).
  2. Use the search field to find the country by its ISO code (e.g., id="LU" for Luxembourg).
  3. Select the node in the XML tree; the corresponding shape will be selected on the canvas.
  4. Assign the color via the Fill and Stroke panel.

5. Standardize Country Borders (Strokes)

Consistent boundary styling keeps the thematic map legible:

  1. Select all countries on the canvas (Ctrl + A).
  2. Go to the Stroke paint tab in the Fill and Stroke panel.
  3. Set the stroke to a flat color—typically white (#FFFFFF) for dark fills or a neutral dark gray (#444444) for light fills.
  4. Go to the Stroke style tab and assign a uniform border width (e.g., 0.5 px to 1 px).

6. Build the Legend and Export

  1. Move your reference palette squares into an empty corner of the canvas to act as the map legend.
  2. Use the Text tool (T) to add numerical labels and data ranges beside each color block.
  3. Add a title, data source, and date.
  4. Go to File > Export, set your export area to Page or Custom, choose your desired resolution (300 DPI is standard for print, 96 DPI for web), and export the file as PNG, PDF, or optimized SVG.
