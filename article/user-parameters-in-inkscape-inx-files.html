User Parameters in Inkscape INX Files

Inkscape extensions rely on .inx XML files to build graphical interfaces and capture user settings before executing a Python script. This guide explains how to declare common input types—specifically integer fields and dropdown selection menus—within an .inx file, configure their attributes, and capture their values inside an Inkscape extension script.

Declaring Parameters in the INX File

In an .inx file, UI elements are defined inside the <page> or directly under the <inkscape-extension> root using <param> elements. Each parameter requires a unique name, a type, and a gui-text attribute to display a readable label in the user interface.

Handling Integer Inputs

To collect a whole number from the user, set the type attribute to "int". You can define boundary limits and step increments using optional attributes:

  • min: The minimum allowed integer value.
  • max: The maximum allowed integer value.
  • The default value is placed directly as text inside the opening and closing <param> tags.
<param name="item_count" type="int" min="1" max="100" gui-text="Number of Items:">10</param>

When rendered by Inkscape, this creates a numeric spinbox widget bounded between 1 and 100 with an initial value of 10.

Handling Dropdown Menus

Dropdown menus are created using the "optiongroup" parameter type with the appearance="combo" attribute. Each choice in the dropdown is declared using nested <option> tags:

  • The text inside the <option> tag is the user-facing label.
  • The value attribute specifies the internal string passed to the script.
<param name="render_mode" type="optiongroup" appearance="combo" gui-text="Render Mode:">
    <option value="outline">Outline Only</option>
    <option value="fill">Solid Fill</option>
    <option value="both">Fill and Stroke</option>
</param>

Setting appearance="combo" generates a dropdown select box. If you omit the appearance attribute or set it to "radio", Inkscape renders the choices as a vertical list of radio buttons instead.

Receiving Inputs in Python

Inkscape passes .inx parameter values to your Python script as command-line arguments matching the name attribute prefixed with --.

When building an extension derived from inkex.EffectExtension, declare these parameters using self.arg_parser.add_argument in your script's __init__ or add_arguments method:

import inkex

class MyExtension(inkex.EffectExtension):
    def add_arguments(self, pars):
        pars.add_argument(
            "--item_count", 
            type=int, 
            default=10, 
            help="Number of items to generate"
        )
        pars.add_argument(
            "--render_mode", 
            type=str, 
            default="outline", 
            help="Rendering style"
        )

    def effect(self):
        # Access the user-submitted values
        count = self.options.item_count
        mode = self.options.render_mode

if __name__ == "__main__":
    MyExtension().run()

The parsed values are automatically cast to their appropriate Python data types and stored within self.options for use during the extension's execution.
