Stepped Retro Drop Shadows in Inkscape with feOffset

This guide explains how to create a multi-layered, stepped retro drop shadow in Inkscape using the Filter Editor. By chaining several feOffset primitives alongside feFlood and feComposite nodes, you can build a customizable, non-destructive vector effect that creates clean, offset color bands behind text or shapes without duplicating base geometry.

1. Set Up Your Base Object and Open the Filter Editor

  1. Select your target object or text on the canvas.
  2. Open the Filter Editor by navigating to Filters > Filter Editor.
  3. Click the New button at the bottom of the left panel to create an empty custom filter. Check the box next to your new filter to apply it to your selected object.

2. Understand the Primitive Chain

To create each distinct "step" in the retro shadow, you need three primitives working together:

  • feOffset (Offset): Shifts the shape along the X and Y axes.
  • feFlood (Flood): Defines the color of that specific shadow step.
  • feComposite (Composite): Constrains the flood color to the shape of the offset shadow using the in operator.

Once each step is generated, an feMerge (Merge) primitive layers them back-to-front, finishing with the original graphic on top.

3. Build the Shadow Steps

For a two-step drop shadow, add the following primitives using the Add Primitive drop-down menu:

  1. Step 1 (Deepest Shadow):

    • Add an Offset primitive. Set its input to SourceAlpha. In the Effect parameters tab, set dx to 10 and dy to 10.
    • Add a Flood primitive. Choose your deepest shadow color (e.g., dark blue) and set the opacity to 100%.
    • Add a Composite primitive. Connect Input 1 to the Flood and Input 2 to the first Offset. In the parameters, set the operator to in.

  2. Step 2 (Middle Shadow):

    • Add a second Offset primitive. Set its input to SourceAlpha. Set dx to 5 and dy to 5.
    • Add a second Flood primitive. Pick an intermediate color (e.g., orange or yellow).
    • Add a second Composite primitive. Connect Input 1 to the second Flood and Input 2 to the second Offset. Set the operator to in.

4. Merge the Layers in Proper Stacking Order

To display the retro steps correctly, combine all branches into a single output:

  1. Add a Merge primitive (feMerge) to the list.
  2. In the connections graph, attach the merge inputs sequentially from bottom to top:
    • First node: Output of the first Composite (deepest offset).
    • Second node: Output of the second Composite (middle offset).
    • Third node: SourceGraphic (the original, unshifted artwork).
  3. Inkscape automatically renders the connected nodes from back to front. The deepest offset appears at the base, the intermediate offset layers over it, and the crisp original graphic sits on top.

5. Adjust Spacing and Additional Steps

To expand the retro effect to three or more steps, repeat the Offset > Flood > Composite sequence before the merge node. Ensure the dx and dy increments remain mathematically consistent (e.g., offsets of 4px, 8px, 12px, and 16px) to maintain a uniform stepped appearance across the graphic.
