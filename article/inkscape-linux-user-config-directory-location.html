Inkscape Linux User Config Directory Location

Finding the Inkscape user configuration directory on Linux depends primarily on how the software was installed. This guide provides the exact file paths for standard native installations, Flatpaks, and Snaps, as well as the method to view the location directly from within the Inkscape interface.

Standard Native Installation (APT, DNF, Pacman, PPA)

For most standard installations managed via your Linux distribution's native package manager, Inkscape follows the XDG Base Directory specification. The configuration folder is located at:

~/.config/inkscape/

If the $XDG_CONFIG_HOME environment variable is customized on your system, the path is $XDG_CONFIG_HOME/inkscape/.

Flatpak Installation

If Inkscape was installed via Flatpak (Flathub), the sandbox environment isolates configuration files to the following path:

~/.var/app/org.inkscape.Inkscape/config/inkscape/

Snap Installation

If you installed Inkscape as a Snap package, the configuration directory is kept inside the user's snap directory:

~/snap/inkscape/current/.config/inkscape/

Finding the Path via Inkscape GUI

To quickly verify the exact path your active installation is using:

  1. Open Inkscape.
  2. Navigate to Edit > Preferences (or press Ctrl + Shift + P).
  3. In the left sidebar, click on System.
  4. Look for the User config entry in the main pane, which displays the precise directory path along with an Open button to launch it in your file manager.

Contents of the Configuration Directory

This directory contains user-specific customizations, including:

  • preferences.xml: General application settings and tool configurations.
  • keys/: Custom keyboard shortcut files.
  • templates/: Custom default document templates.
  • extensions/: User-installed third-party plugins and scripts.
  • palettes/: Custom color palettes.
  • symbols/: Custom symbol libraries.
