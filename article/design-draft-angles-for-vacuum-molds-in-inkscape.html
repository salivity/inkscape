Design Draft Angles for Vacuum Molds in Inkscape

Designing vacuum-forming molds requires incorporating draft angles—typically between 3° and 5°—to allow the cooled plastic sheet to release cleanly from the mold buck without sticking. This guide outlines how to use Inkscape's vector toolset to accurately calculate, draw, and offset mold silhouette profiles and cross-sections, enabling you to produce clean designs ready for CNC routing, laser-cut stacked fabrication, or 3D extrusion.

1. Calculate the Required Offset

To create a draft angle in a 2D vector environment, you must calculate the horizontal taper distance based on the vertical height of your mold. Use the trigonometric formula:

\[\text{Offset} = \text{Mold Height} \times \tan(\text{Draft Angle})\]

For example, a mold section that is 20 mm high with a standard 3° draft angle requires an offset of approximately 1.05 mm (\(20 \times \tan(3^\circ) \approx 1.048\text{ mm}\)). This value determines how much smaller the top profile of your mold must be compared to the base footprint.

2. Draw the Base Mold Profile

  1. Select the Rectangle tool (R) or Draw Bezier curves tool (B) to create the base silhouette of the mold.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F) and set the path to have a visible stroke with no fill.
  3. Switch to the Select and transform objects tool (S) and use the top toolbar to set the exact dimensions (width and length) of your mold buck's base in millimeters.

3. Generate the Drafted Top Profile

Inkscape provides precise path operations to generate the drafted inner profile from the base footprint:

  1. Select your base shape and duplicate it by pressing Ctrl + D.
  2. Navigate to Path > Path Effects to open the Path Effects panel.
  3. Click the + icon and select Offset.
  4. In the effect settings, set the offset distance to the negative value of your calculated offset (e.g., -1.05 mm).
  5. Choose Miter or Round join depending on whether you want sharp or radiused corners (rounded corners are generally preferred for vacuum forming to prevent localized sheet thinning).
  6. Convert the effect to a permanent path by selecting Path > Object to Path (Ctrl + Shift + C).

4. Create Layer Slices for Stacked Fabrication

If you are fabricating the mold by laser-cutting stacked sheet material (such as MDF or acrylic), each layer requires its own incremental draft offset:

  1. Determine your sheet material thickness (\(T\)).
  2. Calculate the per-layer offset step: \(\text{Step} = T \times \tan(\text{Draft Angle})\).
  3. Duplicate the base outline for the total number of physical layers.
  4. Apply an incremental offset to each layer: the bottom layer uses the base size (\(0\times \text{Step}\)), the second layer uses \(-1\times \text{Step}\), the third uses \(-2\times \text{Step}\), and so on.
  5. Arrange each slice on your canvas, clearly labeling them with text outside the cut area to maintain proper assembly order.

5. Verify the Mold Cross-Section

To ensure your silhouette has no negative drafts (undercuts) that would trap the plastic:

  1. Use the Draw Bezier curves tool (B) while holding Ctrl to sketch a 2D side cross-section of your mold buck.
  2. Select the Measure tool (M) and drag a line along the sloped edge.
  3. Check the angle readout in the status bar to verify that all vertical walls diverge at minimum 3° to 5° relative to the vertical axis.
  4. Add corner radii to all top edges using the Corners (Fillet/Chamfer) Path Effect, as sharp upper corners cause webbing and tearing during vacuum drawdown.

6. Prepare and Export

  1. Select all paths and navigate to Path > Object to Path to ensure all dynamic effects and primitives are flattened into raw vectors.
  2. Verify in the Fill and Stroke panel that all cut lines have a uniform stroke width (e.g., 0.001 in or 0.02 mm for standard laser cutters).
  3. Save your file as a standardized vector format via File > Save As, choosing DXF for CNC routers or Plain SVG / PDF for laser cutting systems.
