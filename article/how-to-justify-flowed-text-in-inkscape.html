How to Justify Flowed Text in Inkscape

Justifying text in Inkscape aligns your copy evenly along both the left and right margins of a text frame, creating clean and structured document layouts. This guide provides step-by-step instructions on how to create a flowed text box and apply justified alignment using both the Tool Controls Bar and the Text and Font dialog.

1. Create or Select a Flowed Text Box

Justification only works when text is contained inside a defined bounding box.

  1. Select the Text Tool from the left-hand toolbar or press T.
  2. Click and drag across the canvas to draw a rectangular text frame.
  3. Type or paste your text inside the frame.

(Note: If you already have standard text and a shape on your canvas, select both objects and navigate to Text > Flow into Frame to convert it into flowed text.)

2. Apply Justified Alignment

You can justify your flowed text using either the Tool Controls Bar or the Text and Font panel.

Method A: Using the Tool Controls Bar

  1. Activate the Text Tool (T) and click inside the text box (or highlight the specific paragraphs you want to adjust).
  2. Look at the Tool Controls Bar along the top of the workspace.
  3. Click the Justify alignment button (represented by an icon with four lines of equal width).

Method B: Using the Text and Font Panel

  1. Open the panel by navigating to Text > Text and Font... or by pressing Shift + Ctrl + T (Shift + Cmd + T on macOS).
  2. In the panel, locate the alignment icons.
  3. Click the Justify icon.
  4. Click the Apply button in the bottom right corner of the panel to apply the alignment to your selected text.

Troubleshooting and Spacing Tips

  • Resize the Frame: If lines contain excessive whitespace ("rivers"), switch to the Text Tool, click the text, and drag the blue handle at the bottom-right corner of the frame to widen or narrow the bounding box.
  • Adjust Spacing: Fine-tune spacing using the Word spacing and Letter spacing fields located in the top Tool Controls Bar while the Text Tool is active.
