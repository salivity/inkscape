How to Change Gradient Spread in Inkscape

This guide explains how to adjust the gradient spread method in Inkscape, detailing the exact steps to switch between Pad, Reflect, and Repeat modes. You will learn what each spread option does and how to apply them using both the Fill and Stroke panel and the Gradient Tool's control bar to control how colors render beyond your gradient's defined handles.

Understanding Gradient Spread Modes

When you create a linear or radial gradient in Inkscape, the gradient handles define the starting and ending points of your color transition. The spread method determines what happens to the fill outside of these boundary handles:

  • Pad: The default behavior. Inkscape takes the colors of the first and last stops and extends them solid and unchanged to the edges of the shape.
  • Reflect: Reverses and mirrors the gradient pattern indefinitely outward from the end handles.
  • Repeat: Loops the gradient pattern from the start stop to the end stop repeatedly outward in sequential order.

Method 1: Using the Fill and Stroke Panel

  1. Select the object containing your gradient using the Select Tool (S).
  2. Open the Fill and Stroke panel by pressing Shift + Ctrl + F (or navigate to Object > Fill and Stroke in the top menu).
  3. Depending on where your gradient is applied, ensure you are on the Fill or Stroke paint tab.
  4. Locate the Spread section below the gradient preview bar. You will see three small icons representing Pad, Reflect, and Repeat:
    • Click the first icon (horizontal bar with solid ends) for Pad.
    • Click the second icon (mirrored ramp) for Reflect.
    • Click the third icon (sawtooth/stair ramp) for Repeat.
  5. The canvas will immediately update with the selected spread behavior.

Method 2: Using the Gradient Tool Controls

  1. Select the Gradient Tool from the left toolbar or press the shortcut key G.
  2. Click directly on the object to activate its gradient handles on the canvas.
  3. Look at the Tool Controls Bar running horizontally along the top of the Inkscape window.
  4. Locate the Repeat or Spread option (displayed as a dropdown menu or toggle buttons depending on your Inkscape version).
  5. Select none (Pad), reflected, or direct (Repeat) from the options provided.

Adjusting the Visible Effect

If you select Reflect or Repeat and do not notice a difference, your gradient handles may be stretched to the very edges of the shape:

  1. Press G to activate the Gradient Tool.
  2. Click and drag the endpoint handles inward so they occupy a smaller area inside the shape.
  3. As the distance between the start and end handles decreases, the reflected or repeated cycles will multiply and become visible across the rest of the object.
