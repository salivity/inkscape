How to Merge Layers Down in Inkscape

In Inkscape, layers function as specialized SVG groups, meaning there is no single raster-style "Merge Down" button. However, you can easily merge a layer into the one below it by transferring all objects from the upper layer to the target lower layer and then deleting the empty layer. This guide covers the fastest and most effective methods to merge layers in Inkscape using keyboard shortcuts and the Layers panel.

Method 1: Using Keyboard Shortcuts (Fastest)

  1. Open the Layers and Objects panel by pressing Ctrl + Shift + L (or Cmd + Shift + L on macOS).
  2. Click on the upper layer you want to merge down so it becomes active.
  3. Make sure the layer is unlocked and visible.
  4. Press Ctrl + A (Cmd + A on macOS) to select all objects within that active layer.
  5. Press Shift + Page Down to move all selected objects directly into the layer below.
  6. Delete the now-empty upper layer by clicking the minus (-) icon in the Layers panel or selecting Layer > Delete Current Layer from the top menu.

Method 2: Drag and Drop in the Layers Panel

  1. Open the Layers and Objects panel (Ctrl + Shift + L).
  2. Click the arrow next to the upper layer to expand its contents.
  3. Select all the objects listed inside the upper layer (hold Shift and click the first and last object).
  4. Click and drag the selected objects into the layer beneath it.
  5. Right-click the empty upper layer and select Delete, or click the trash/minus icon at the bottom of the panel.

Method 3: Cut and Paste in Place

  1. Select the upper layer in the Layers panel.
  2. Select all elements on that layer by pressing Ctrl + A.
  3. Cut the elements by pressing Ctrl + X.
  4. Click on the lower layer in the Layers panel to make it active.
  5. Press Ctrl + Alt + V (Cmd + Option + V on macOS) to Paste in Place, which pastes the objects into the lower layer at their exact original coordinates.
  6. Delete the original upper layer.
