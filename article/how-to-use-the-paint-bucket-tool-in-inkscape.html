How to Use the Paint Bucket Tool in Inkscape

The Paint Bucket tool in Inkscape allows you to quickly fill enclosed or bounded areas with color by creating a new vector path based on visible screen pixels. Unlike traditional vector tools that modify existing paths, this tool works similarly to raster paint buckets by analyzing the visible canvas. This guide covers how to select the tool, adjust critical settings like threshold and gap closing, and achieve seamless vector fills without unwanted gaps.

Basic Steps to Fill an Area

  1. Select the Tool: Click the Paint Bucket icon in the left-hand toolbar, or press the shortcut key U (or Shift + F7).
  2. Choose a Color: Select your desired fill color from the color palette at the bottom of the screen.
  3. Click to Fill: Click inside the bounded region you want to color. Inkscape will instantly generate a new vector object fitted to the contours of that area.

Key Settings in the Tool Controls Bar

When the Paint Bucket tool is active, the top control bar provides several essential parameters to refine the fill:

  • Fill by: Determines the color metric used to detect boundaries (typically left on Visible Colors, but can be set to specific channels like Red, Green, Blue, or Alpha).
  • Threshold: Controls the sensitivity of boundary detection. A higher value allows the fill to span broader color variations, while a lower value stops the fill at subtle color shifts.
  • Grow/Shrink by: Expands or contracts the generated fill path by a set amount (measured in pixels, millimeters, etc.). Adding a slight positive value (e.g., 0.5 px to 1.5 px) helps tuck the fill beneath the surrounding stroke, preventing thin white gaps.
  • Close Gaps: Sets whether the fill should bridge small openings in line art. Choose between None, Small, Medium, or Large to fill imperfectly closed boundaries.
  • Reset: Restores all settings to their default values.

Tips for Better Results

  • Zoom Level Matters: Because the tool operates on visible pixels on your screen, zooming in before clicking results in a more precise, higher-resolution path with smoother edges.
  • Independent Shapes: The resulting fill is a standard, editable vector path placed on top of the canvas. You can select it with the Selection Tool (S) or modify its nodes with the Node Tool (N) independently of the boundary lines.
