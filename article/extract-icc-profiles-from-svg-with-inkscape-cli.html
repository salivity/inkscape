Extract ICC Profiles from SVG with Inkscape CLI

This guide provides a straightforward method for locating and extracting embedded ICC color profiles from SVG files using Inkscape and standard command-line tools. Because SVG files store color management data within XML tags using Base64 encoding, you can combine Inkscape's command-line processing with shell utilities to inspect the file, isolate the embedded profile, and decode it into a standard .icc or .icm file.

How SVG Files Store ICC Profiles

In standard SVG files created or modified by Inkscape, ICC color profiles are defined inside the <defs> section using the <color-profile> element. The binary ICC profile itself is serialized into an ASCII string using Base64 encoding and assigned to the xlink:href attribute with a data URI scheme:

<color-profile
   name="Custom-CMYK"
   xlink:href="data:application/vnd.iccprofile;base64,AAAMSExpbm8..." />

Because the Inkscape command line does not offer a single, built-in flag specifically named --export-icc, extracting this data requires exporting or reading the XML definition and decoding the Base64 payload.

Step 1: Normalize the SVG with Inkscape

Before extracting, ensure the SVG is cleanly rendered and its definitions are accessible. Use Inkscape to export a clean version of the file, which strips unnecessary editor GUI state while preserving document definitions and color profiles:

inkscape input.svg --export-plain-svg=normalized.svg

Alternatively, if you are working with Inkscape in headless server environments, you can verify that the color management elements are present by querying the file structure via Inkscape actions:

inkscape normalized.svg --query-all

Step 2: Extract and Decode the Base64 Stream

Once the SVG structure is normalized, use standard command-line streaming utilities (grep, sed, or awk) alongside base64 to extract and decode the raw ICC profile.

Run the following one-line command in a Linux or macOS terminal:

grep -o 'data:application/vnd.iccprofile;base64,[^"'\'' ]*' normalized.svg \
  | sed 's/data:application\/vnd.iccprofile;base64,//' \
  | base64 --decode > output_profile.icc

Explanation of the Pipeline:

  1. grep -o 'data:application/vnd.iccprofile;base64,[^"'\'' ]*': Finds the ICC profile data URI within the XML file and isolates the string.
  2. sed 's/data:application\/vnd.iccprofile;base64,//': Strips the data URI prefix, leaving only the pure Base64 character string.
  3. base64 --decode > output_profile.icc: Converts the ASCII Base64 sequence back into binary form and saves it as a valid ICC profile file.

(Note: On macOS, use base64 -D instead of base64 --decode if using BSD utilities.)

Step 3: Verify the Extracted ICC Profile

To ensure the extraction succeeded and the resulting file is not corrupt, verify its contents using the file command:

file output_profile.icc

A properly extracted profile will output information similar to:

output_profile.icc: Color coordinate profile data: [Description], [Device Class], [Color Space]

You can now import output_profile.icc into color management systems, operating system display settings, or graphic editing software.
