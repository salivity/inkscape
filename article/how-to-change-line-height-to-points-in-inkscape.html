How to Change Line Height to Points in Inkscape

Adjusting line height from a proportional percentage to fixed typographical points in Inkscape allows for precise typographic control and consistent vertical rhythm across your designs. By default, Inkscape calculates line spacing proportionally relative to font size, but you can switch this setting directly to points (pt) using the Text Tool Controls Bar. This guide walks you through the exact steps to locate the unit selector and apply fixed point-based leading to your text.

Step-by-Step Instructions

  1. Select the Text Tool
    Click the Text Tool icon in the left-hand toolbox, or press T (or F8) on your keyboard.

  2. Select Your Text
    Click on the text object on your canvas to select the entire block, or click and drag to highlight specific lines of text you wish to modify.

  3. Locate the Line Height Control
    Look at the Tool Controls Bar positioned directly above the canvas workspace. Find the icon representing line spacing (labeled as Spacing between baselines when hovered over), which sits beside a numeric input field and a unit dropdown menu.

  4. Change the Measurement Unit
    Click the unit dropdown menu immediately to the right of the line height value. By default, this may be set to proportional units such as lines, % (percent), or unitless multipliers. From the dropdown list, select pt (typographical points).

  5. Set the Desired Value
    Enter your required point size into the numeric box (for example, entering 14 sets a fixed 14 pt line height). Press Enter to apply the changes immediately.

Key Considerations

  • Proportional vs. Fixed Units: When using proportional units (such as %), line spacing scales automatically if you alter the font size. When set to fixed points (pt), the baseline spacing remains strictly locked to that specified numerical measurement, regardless of font size adjustments.
  • Global vs. Local Spacing: To apply a consistent point-based leading across an entire document, ensure the unit is set to pt before creating new text frames, as Inkscape remembers the last used line-height settings for subsequent text elements.
