Stretch Both Bezier Handles at Once in Inkscape

Adjusting Bezier handles is essential for creating smooth, balanced curves in Inkscape. When refining paths, you often need to elongate both opposing handles evenly without manually editing each side. This guide explains how to use keyboard shortcuts and modifier keys to stretch both Bezier handles outward simultaneously to maintain symmetry and streamline your vector editing workflow.

Using the Shift Modifier Shortcut

The quickest way to stretch both handles outward at the same time is by holding a modifier key while dragging:

  1. Select the Node Tool by pressing N on your keyboard (or clicking the Node Tool icon in the left toolbar).
  2. Click the path to reveal its nodes, then click the specific node whose handles you want to adjust.
  3. Hover over one of the circular handle ends.
  4. Press and hold Shift, then click and drag the handle outward away from the node.

Holding Shift forces the opposite handle to mirror the action, stretching both handles outward in opposite directions at the exact same distance.

Locking Angles While Stretching

If you want to stretch both handles outward while locking their movement to standard angular increments (such as 15-degree steps):

  1. Hold both Shift + Ctrl.
  2. Click and drag one of the handles outward.

This combination scales both handles simultaneously while preventing accidental rotation or tilting of the curve tangent.

Converting to a Symmetric Node

Alternatively, you can set the node behavior to inherently link both handles using a keyboard shortcut:

  1. With the Node Tool (N) active, select the target node.
  2. Press Shift + S to convert the node into a Symmetric Node.
  3. Click and drag either handle outward.

Because symmetric nodes enforce equal handle lengths, dragging one handle will automatically stretch the opposite handle simultaneously without requiring you to hold Shift during the drag.
