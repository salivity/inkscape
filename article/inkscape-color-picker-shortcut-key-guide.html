Inkscape Color Picker Shortcut Key Guide

This article explains how to quickly sample colors in Inkscape using keyboard shortcuts without manually clicking the Dropper tool in the toolbar. By using the dedicated shortcut key, you can activate the interactive color picker instantly, apply fill or stroke colors to selected objects, and return to your active workflow without interruption.

The Shortcut Key: Press or Hold D

The primary keyboard shortcut to activate the interactive color picker in Inkscape is the D key (alternatively, you can use F7).

Temporary Color Picker (Spring-Loaded Mode)

If you want to sample a color without permanently switching away from your active tool (such as the Select or Node tool):

  1. Select the object you want to recolor.
  2. Press and hold down the D key. The cursor will temporarily change into the Dropper eyedropper.
  3. Click anywhere on the canvas to sample the color.
  4. Release the D key. Your tool will immediately revert to the previously active tool, keeping your workflow seamless.

Permanent Switch

Tapping D once without holding it will switch your active tool to the Dropper tool directly, bypassing the need to find and click its icon in the left-hand toolbox. Pressing S or the Spacebar will switch back to the Select tool.

Useful Modifiers While Sampling Colors

Once the color picker is active via the shortcut, use these modifier keys to control how colors are sampled and applied:

  • Left-Click: Applies the sampled color to the selected object's Fill.
  • Shift + Click: Applies the sampled color to the selected object's Stroke.
  • Click and Drag: Draws a sampling circle that calculates and applies the average color of the enclosed area.
  • Alt + Click: Applies the inverse of the sampled color.
  • Ctrl + Click: Picks the color along with the source object's opacity and alpha value.
