Switch Vertical Text Direction in Inkscape

Switching text orientation between top-to-bottom and bottom-to-top in Inkscape allows you to create custom typographic layouts, vertical banners, and technical diagrams. This guide outlines how to use the built-in vertical writing mode tools to set text from top to bottom, as well as how to invert the text flow from bottom to top using object rotation or directional paths.

Setting Text to Top-to-Bottom

Inkscape includes a native vertical writing mode that arranges characters in a column reading downwards.

  1. Select the Text tool (shortcut: T) from the left toolbar.
  2. Click on the canvas and type your text, or click an existing text object to select it.
  3. Look at the Tool Controls bar along the top of the workspace.
  4. Locate the Text direction buttons (represented by directional letters like "A" stacked vertically or horizontally).
  5. Click the Vertical text button. Your text will instantly reorganize into a vertical line that reads from top to bottom.
  6. If the glyphs are rotated sideways, click the Toggle text orientation button next to the direction options on the Tool Controls bar to switch between stacked vertical glyphs and sideways vertical text.

Switching from Top-to-Bottom to Bottom-to-Top

SVG and Inkscape do not have a single dedicated button for native bottom-to-top reading order, but you can achieve this effect using two reliable methods depending on whether you want the letters upright or rotated.

Method 1: Using 180-Degree Rotation (Fastest)

If you have sideways vertical text reading downward and want it to read upward:

  1. Select the text object using the Select tool (shortcut: S).
  2. Click Object in the top menu and select Rotate 90° CCW (or Rotate 90° CW) depending on your initial orientation.
  3. Alternatively, to invert an existing vertical block, click Object > Rotate 180° or press the Rotate 90° button on the top toolbar twice. This flips the direction of reading from bottom to top.

Method 2: Using "Put on Path" (Keeps Glyphs Upright or Custom Aligned)

If you need your letters to read sequentially upward along a vertical guide:

  1. Select the Draw Freehand Lines or Draw Bezier Curves tool (shortcut: B).
  2. Hold Ctrl to constrain the angle, click at the bottom of the canvas, drag upward, and double-click at the top to create a straight, vertical line pointing up.
  3. Select your text object and switch it to standard horizontal mode.
  4. With the Select tool, hold Shift and select both the text object and the upward vertical line.
  5. Go to the top menu and click Text > Put on Path.
  6. The text will automatically align along the path starting from the bottom node and flowing to the top node.
  7. To hide the guide line, select the path, open the Fill and Stroke panel (Ctrl + Shift + F), and set the stroke paint to No paint.
