How to Set Up Ink Trapping in Inkscape

Ink trapping prevents unsightly white gaps caused by plate misregistration during commercial offset or screen printing by overlapping adjacent colors. This guide details how to manually create both "spread" (expanding a lighter foreground color into a darker background) and "choke" (expanding a lighter background under a darker foreground) values in Inkscape. By adjusting step preferences and using native path offset tools, you can ensure precise, press-ready vector traps.

Step 1: Configure Offset Precision in Preferences

Inkscape does not have an automated trapping engine, so you must define precise increment values for path expansion.

  1. Go to Edit > Preferences (or press Ctrl + Shift + P).
  2. In the left panel, navigate to Behavior > Steps.
  3. Locate the Inset/Outset by field.
  4. Set your unit to points (pt) or millimeters (mm). Commercial printing typically requires a trap value between 0.25 pt and 0.5 pt (approximately 0.08 mm to 0.18 mm). Check with your print shop for their recommended specification.
  5. Close the Preferences window.

Step 2: Creating a Spread Trap (Lighter Object on Darker Background)

Use a spread when the foreground object is lighter than the background it rests upon. The lighter foreground color must expand slightly into the darker background.

  1. Select the foreground path with the Selector Tool (S).
  2. Duplicate the path in place by pressing Ctrl + D.
  3. With the duplicate selected, navigate to Path > Outset (or press Ctrl + )). Inkscape will expand the path boundary by the exact increment configured in your preferences.
  4. Send the expanded path directly behind the original object by pressing Lower Selection One Step (Page Down).
  5. Ensure the expanded duplicate keeps the same color as the lighter foreground path. The expanded shape will now overlap the darker background beneath it.

Step 3: Creating a Choke Trap (Darker Object on Lighter Background)

Use a choke when the foreground object is darker than the surrounding background. The lighter background color must expand inward under the edge of the darker foreground.

  1. Select the background path that touches the dark foreground object.
  2. Duplicate the darker foreground path by pressing Ctrl + D.
  3. Select the duplicated foreground path and apply an inset: go to Path > Inset (or press Ctrl + (). This shrinks the path boundary inward by the specified trap amount.
  4. Select both the background path and this inset duplicate.
  5. Go to Path > Difference (or press Ctrl + -) to cut the shrunken shape out of the background, or simply recolor the duplicate to match the lighter background color and position it directly below the original dark foreground path (Page Down).

Alternative: The Stroke Trapping Method

For regular geometric shapes, you can create a trap directly via strokes without duplicating paths:

  1. Select the lighter object.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Switch to the Stroke paint tab and set it to match the object’s fill color.
  4. In the Stroke style tab, set the stroke width to twice your target trap value (for example, use 0.5 pt to achieve a 0.25 pt trap on each side).
  5. In the Order row within the Stroke style tab, choose the option that renders the fill over the stroke (the icon showing the stroke behind the fill). This prevents the trap from reducing the perceived interior size of your original artwork.
