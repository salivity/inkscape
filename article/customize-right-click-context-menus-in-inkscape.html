Customize Right-Click Context Menus in Inkscape

Customizing the canvas right-click context menu in Inkscape allows you to streamline your design workflow by placing frequently used commands directly at your cursor. In modern versions of Inkscape (version 1.0 and newer), the interface elements—including popup context menus—are defined using GTK XML configuration files. By creating an override file in your personal configuration folder, you can safely add, remove, or reorder items in the canvas right-click menu without modifying core program files.

Step 1: Locate the Default Menu File

Inkscape defines its menu structures in a file named menus.ui. To safely modify it, first locate the default installation file:

  • Linux: /usr/share/inkscape/ui/menus.ui
  • Windows: C:\Program Files\Inkscape\share\inkscape\ui\menus.ui
  • macOS: /Applications/Inkscape.app/Contents/Resources/share/inkscape/ui/menus.ui

Step 2: Copy the File to Your User Profile

Modifying the original installation file directly is not recommended, as application updates will overwrite your changes. Instead, copy menus.ui into your personal user directory:

  • Linux: ~/.config/inkscape/ui/
  • Windows: %APPDATA%\inkscape\ui\
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/ui/

Note: If the ui folder does not exist in your user directory, create it manually.

Step 3: Edit the Context Menu in a Text Editor

Open the copied menus.ui file in a plain text editor such as VS Code, Notepad++, or Kate.

  1. Use the search function (Ctrl+F or Cmd+F) to locate the canvas popup menu section. Look for the <menu id="canvas-context-menu"> or related context menu tags (such as menus for objects, paths, or text selections).
  2. Inside the target menu block, you will see a list of <item> elements that define each entry. Each item consists of a label attribute and an action attribute.

To remove an item: Delete the entire <item ... /> line for that command.

To reorder items: Cut and paste the <item> lines into your preferred sequential order.

To add a new item: Insert a new <item> tag referencing a valid Inkscape action ID. For example:

<item action="app.selection-group" />
<item action="app.selection-ungroup" />
<item action="win.dialog-open(id='AlignDistribute')" />

Step 4: Find Valid Action IDs

To bind commands correctly, you must use valid Inkscape action IDs. You can discover available action names by navigating in Inkscape to Edit > Preferences > Interface > Keyboard Shortcuts, where actions and their internal identifiers are listed. You can also run the terminal command inkscape --action-list to output all supported actions.

Step 5: Save and Relaunch

Save your changes to menus.ui and restart Inkscape. When you right-click on the canvas or an object, the context menu will reflect your custom layout. If the menu fails to load properly, verify that the XML syntax is well-formed with matching opening and closing tags.
