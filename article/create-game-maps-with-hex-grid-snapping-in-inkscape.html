Create Game Maps with Hex Grid Snapping in Inkscape

Designing game maps with precise hexagonal grids is an essential skill for tabletop role-playing games, strategy board games, and video game prototyping. This guide provides a direct, step-by-step walkthrough for configuring Inkscape's built-in axonometric grid system, enabling accurate node and grid snapping, generating standardized hexagon tiles, and assembling modular terrain layouts ready for digital or print use.

Step 1: Set Up the Hexagonal Grid

  1. Open a new document in Inkscape.
  2. Open the Document Properties window by pressing Shift + Ctrl + D (or navigate to File > Document Properties).
  3. Go to the Grids tab.
  4. Select Axonometric grid from the dropdown menu and click New.
  5. Adjust the grid settings to create regular hexagons:
    • Grid units: Set to px, mm, or in based on your map scale.
    • Spacing Y: Set your desired vertical spacing (e.g., 50 px).
    • Angle X: Set to 30.0.
    • Angle Z: Set to 30.0.
    • Ensure the Enabled and Visible checkboxes are checked.

Step 2: Configure Snapping Controls

Precise alignment requires enabling specific snapping rules to ensure tiles and terrain features lock directly onto the grid intersections.

  1. Toggle the global snapping icon on the top right of the interface to Enable Snapping (or press %).
  2. Click the snapping dropdown arrow to expand detailed snap controls.
  3. Enable Snap to Grids.
  4. Enable Snap to Paths and Nodes, specifically activating:
    • Snap to Cusp Nodes
    • Snap to Smooth Nodes
    • Snap to Midpoints of Lines
  5. Disable bounding box snapping to prevent the outer rectangular boundaries of your hex shapes from interfering with node placement.

Step 3: Create the Base Hexagon Tile

  1. Select the Stars and Polygons tool (* or F8) from the left toolbar.
  2. In the top tool control bar, set the shape mode to Regular Polygon and set Corners to 6.
  3. Click and drag on the canvas while holding Ctrl to constrain the angle.
  4. Drag a corner vertex directly to a grid intersection point until it snaps into place.
  5. Set your preferred fill color for terrain (such as grass, water, or stone) and set the stroke to a defined border line width (e.g., 1 px or 2 px).

Step 4: Build and Assemble the Map

  1. Duplicate Tiles: Select the base hexagon and press Ctrl + D to duplicate it. Click and drag the duplicate tile toward an adjacent grid cell; the snapping engine will automatically pull the vertices into precise alignment with neighboring edges.
  2. Organize Layers: Open the Layers and Objects panel (Shift + Ctrl + L). Create separate layers for:
    • Background Grid / Base Terrain
    • Roads, Rivers, and Paths
    • Icons and Structures
    • Labels and Text
  3. Add Rivers and Roads: Use the Draw Freehand Lines or Draw Bézier Curves tool (B) with node snapping enabled. Paths drawn across the map will cleanly snap from the center or corners of one hex to another.
  4. Use Clones for Modular Assets: For recurring terrain features (like forests, mountains, or towns), select an asset and press Alt + D to create a linked clone. Modifying the original master tile later will automatically update every instance placed across your map.

Step 5: Export the Map

  1. Open the Export panel with Shift + Ctrl + E.
  2. Choose Page (to export the entire canvas) or Selection (to export only the drawn map area).
  3. Select your output format:
    • PNG: Ideal for Virtual Tabletop (VTT) platforms like Roll20 or Foundry VTT. Set the resolution to at least 150 DPI or 300 DPI.
    • PDF / SVG: Ideal for high-resolution vector printing.
  4. Click Export.
