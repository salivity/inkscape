Calculate Element Transforms with inkex.transforms

This guide explains how to use Inkscape's inkex.transforms module to parse, calculate, compose, and apply affine transformations to SVG elements. You will learn how to extract an element's current transform matrix, generate new transformation matrices, combine them sequentially, and apply the resulting calculations directly to element attributes or specific point coordinates.

Understanding the Transform Class

The core of element transformation in Inkscape's Python extension system is the Transform class within the inkex.transforms module. A transformation is represented as a 3x3 affine transformation matrix, which can handle translation, scaling, rotation, and shearing.

To begin working with transformations, import the class:

from inkex.transforms import Transform

Accessing an Element's Transform

Every SVG element node in inkex provides a transform property, which directly interacts with the SVG transform attribute:

# Returns an inkex.transforms.Transform object
current_transform = element.transform

If an element has no defined transformation, element.transform returns an identity matrix (Transform()).

Creating New Transformations

You can instantiate specific transformations using keyword arguments or transformation strings:

  • Translation: t_translate = Transform(translate=(dx, dy))
  • Scale: t_scale = Transform(scale=(sx, sy))
  • Rotation: t_rotate = Transform(rotate=angle_in_degrees) or centered around a point: Transform(rotate=(angle_in_degrees, cx, cy))
  • String representation: t_from_str = Transform("translate(10, 20) rotate(45)")

Composing and Calculating Transformations

Affine transformations are combined using matrix multiplication. In modern Python extensions for Inkscape, use the matrix multiplication operator (@) or standard multiplication (*):

# Create independent transforms
translation = Transform(translate=(50, 100))
rotation = Transform(rotate=45)

# Calculate the combined transform (order matters)
# This rotates the element first, then translates it:
combined_transform = translation @ rotation

To append or prepend transformations to an existing element:

# Apply an additional transformation after the existing one
element.transform = Transform(translate=(10, 0)) @ element.transform

# Or update in-place
element.transform @= Transform(scale=1.5)

Calculating Cumulative Document Transforms

An element's local transform attribute only reflects transformations applied directly to that element. If its parent groups also have transformations, you must compute the cumulative (effective) transform to find its absolute canvas position:

# Computes the full transform chain from the root down to this element
absolute_transform = element.composed_transform()

Transforming Points and Coordinates

You can calculate the resulting position of a coordinate without altering the SVG element itself by using apply_to_point():

original_point = (100, 150)
transform = Transform(translate=(20, -30)) @ Transform(rotate=90)

# Calculate transformed coordinates
new_x, new_y = transform.apply_to_point(original_point)

Inverting Transforms

To reverse an element's transformation or map canvas coordinates back into local element space, calculate the inverse matrix:

# Compute the inverse transform
inverse_transform = -element.transform

# Map a canvas point back to local element space
local_point = (-element.composed_transform()).apply_to_point((canvas_x, canvas_y))
