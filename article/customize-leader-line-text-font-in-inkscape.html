Customize Leader Line Text Font in Inkscape

This guide explains how to customize technical leader line text fonts independently from global document fonts in Inkscape. By overriding inherited styles, using dedicated CSS classes, or configuring tool-specific parameters, you can ensure your technical annotations, callouts, and dimension labels maintain distinct typography without being altered by global document-level font changes.

Method 1: Apply Direct Styling via the Text and Font Dialog

Inkscape text elements automatically inherit global or parent layer styles unless explicitly styled inline. Applying a direct font override isolates that text object from document-wide changes.

  1. Select the Text tool (T) from the left toolbar.
  2. Highlight the specific text attached to your technical leader line.
  3. Open the Text and Font dialog by pressing Shift + Ctrl + T.
  4. Choose your desired font family, style, and size.
  5. Click Apply.

Applying the style directly to the selected text writes local inline CSS attributes (font-family, font-size) directly to that <text> or <tspan> element in the SVG code. This prevents the text from adopting default styles defined on the root SVG element or the active layer.

Method 2: Create a Dedicated Class Using the Selectors and CSS Dialog

For technical drawings with numerous leader lines, defining a dedicated CSS class ensures typography remains consistent across all callouts while remaining decoupled from the rest of the document.

  1. Open the Selectors and CSS panel by pressing Ctrl + Shift + Q (or navigate to Object > Selectors and CSS).
  2. Click the + icon to add a new CSS rule and name it .leader-text.
  3. Add font properties to this class, such as:
    • font-family: "Consolas", monospace;
    • font-size: 8pt;
  4. Select all the text objects attached to your leader lines.
  5. In the Selectors and CSS panel, right-click the .leader-text rule and select Set class on selection.

Now, modifying standard document text styles will not alter your leader lines, and you can adjust all technical annotations globally from a single class definition.

Method 3: Configure Measure Tool and Dimension Live Path Effects

If your leader lines and text were generated using the Measure Tool or the Measure Segments Live Path Effect (LPE):

  1. Switch to the Node tool (N) and click on the leader line containing the measurement.
  2. Open the Path Effects panel (Path > Path Effects).
  3. Locate the Measure Segments effect settings.
  4. Uncheck any option linking the label to standard text defaults if present, and locate the Font specification field.
  5. Specify your technical font explicitly in the effect parameters.

This ensures that the dynamic label generated by the algorithm relies strictly on the parameters set within the effect rather than the document's fallback text properties.
