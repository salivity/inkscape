How to Pull Out Retracted Node Handles in Inkscape

When working with vector paths in Inkscape, node handles can retract fully into a cusp (corner) node, making it seem impossible to adjust path curvature. This guide provides the quickest, most reliable methods to reveal and pull out hidden or retracted handles on any cusp node using standard node-editing tools and keyboard shortcuts.

Method 1: Shift-Drag from the Node (Fastest)

  1. Select the Edit paths by nodes tool from the left toolbar (or press N).
  2. Click on the path to make its nodes visible, then click the cusp node that has the retracted handle.
  3. Hold down the Shift key on your keyboard.
  4. Click directly on the node and drag the cursor away from it.

Holding Shift forces Inkscape to extract a single handle from the node without affecting the opposite side, keeping the node configured as a cusp (corner).

Method 2: Drag the Adjacent Path Segment

  1. Activate the Edit paths by nodes tool (N).
  2. Click and hold the line or curve segment directly connected to the cusp node.
  3. Drag the segment in any direction.

Inkscape will automatically pull out a handle from the adjacent cusp node to shape the curve according to your drag movement. You can then click and adjust the newly exposed handle directly.

Method 3: Temporarily Convert to a Smooth Node

  1. Select the node using the Edit paths by nodes tool (N).
  2. In the top Tool Controls bar, click the Make selected nodes smooth icon. This forces both opposing handles to extend outward.
  3. In the same toolbar, click the Make selected nodes corner icon (or press Shift + C).

This restores independent control over each handle without retracting them, allowing you to reposition them individually as needed.
