How to Create Linked Clones in Inkscape

Linked clones in Inkscape allow you to create dynamic copies of an object that automatically inherit any changes made to the original design's shape, color, or style. This guide provides a straightforward walkthrough on how to generate single linked clones, use the Create Tiled Clones tool for complex patterns, locate original source objects, and unlink clones when independent editing is required.

Creating a Single Linked Clone

  1. Select the Object: Use the Select Tool (S or F1) to click on the object or path you want to duplicate.
  2. Create the Clone: Navigate to the menu and select Edit > Clone > Create Clone, or press the keyboard shortcut Alt + D.
  3. Reposition the Clone: The newly generated clone appears directly on top of the original object. Click and drag the clone to a new position on your canvas.

When you modify the original object—such as editing its nodes, changing its fill color, or altering its stroke—the linked clone will instantly update to reflect those changes.

Creating Multiple Clones (Tiled Clones)

To generate multiple linked clones arranged in grids, radial patterns, or randomized distributions:

  1. Select your target object.
  2. Go to Edit > Clone > Create Tiled Clones... to open the tool panel.
  3. Configure the parameters:
    • Symmetry: Choose the arrangement pattern (e.g., Simple translation, P1 symmetry).
    • Shift / Scale / Rotation: Adjust spacing, size increments, or angles per row and column.
    • Rows, columns: Specify the total number of clones to generate in a grid.
  4. Click Create at the bottom of the dialog box.

Managing and Editing Linked Clones

  • Find the Original Object: If you have many clones and need to identify the master shape, select any clone and press Shift + D (or go to Edit > Clone > Select Original). Inkscape will automatically select the parent object.
  • Unlink a Clone: To convert a clone into an independent, editable object that no longer updates with the original, select the clone and go to Edit > Clone > Unlink Clone, or press Shift + Alt + D.
  • Relink a Clone: If you need to attach an existing clone to a different master object, select the clone, then Shift-click the new master object, and go to Edit > Clone > Relink to Copied.
