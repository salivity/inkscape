How to Plot Mathematical Functions in Inkscape

Inkscape includes a built-in tool called the Function Plotter that allows you to generate precise 2D mathematical graphs directly onto your canvas as editable vector paths. This guide provides a step-by-step walkthrough for accessing the tool, configuring mathematical expressions, defining domain and range values, and styling the resulting vector plots for technical diagrams, academic documents, or illustrations.

1. Open the Function Plotter Extension

  1. Launch Inkscape and open a new or existing document.
  2. In the top menu, navigate to Extensions > Render > Mathematics > Function Plotter...
  3. A dialog window will appear containing two main tabs: Function and Sampling.

2. Enter the Mathematical Formula

In the Function tab, define the mathematical equation you want to plot:

  • Function / f(x): Enter your formula using standard Python mathematical syntax.
    • Addition/Subtraction: x + 2, x - 5
    • Multiplication/Division: 3 * x, x / 2
    • Exponents: x**2 (represents \(x^2\))
    • Trigonometric functions: sin(x), cos(x), tan(x)
    • Other functions: sqrt(x) (square root), exp(x) (exponential), log(x) (natural logarithm)

3. Set the Domain and Axis Ranges

Still within the Function tab, set the boundaries for your plot:

  • Start X-value and End X-value: Set the domain of \(x\) (e.g., -10 to 10).
  • Multiply X-range by 2*pi: Enable this checkbox if you are plotting periodic trigonometric functions.
  • Y-value minimum and Y-value maximum: Define the visible vertical limits for \(y\). Values exceeding this range will be clipped.

4. Configure Sampling and Dimensions

Switch to the Sampling tab to configure the resolution and physical size of the output:

  • Number of samples: Controls the number of calculated points along the curve. A higher number (e.g., 200–500) results in a smoother curve, especially for rapidly changing functions.
  • Width and Height: Set the physical dimensions (in pixels) of the bounding box that will contain the plotted graph on the canvas.
  • Draw axes: Check this box to generate visible horizontal (\(X\)) and vertical (\(Y\)) axes along with the function curve.
  • Add isometric grid / marks: Enable additional tick marks or grid references if required for your diagram.

5. Generate and Customize the Output

  1. Check the Live preview box at the bottom of the window to view the graph in real-time before applying changes.
  2. Once the plot looks correct, click Apply and then Close.
  3. The generated graph is placed on the canvas as a standard SVG group.
  4. To style the plot, select it and open the Fill and Stroke panel (Shift + Ctrl + F). You can adjust the stroke color, line thickness, and dash patterns for both the function curve and the axes independently by ungrouping the object (Ctrl + Shift + G).
