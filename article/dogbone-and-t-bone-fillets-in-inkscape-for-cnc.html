Dogbone and T-Bone Fillets in Inkscape for CNC

Because CNC router bits are round, they cannot cut sharp 90-degree internal corners, leaving behind a radius that prevents square mating parts from fitting flush. To solve this, CNC operators use dogbone and T-bone corner reliefs—small undercuts that allow square corners of mating pieces to seat fully. This guide explains how to quickly and accurately generate both dogbone and T-bone corner fillets in Inkscape using standard vector tools and boolean operations.

Understanding Bit Clearance Fillets

  • Dogbone Fillet: The relief cut extends diagonally into the 90-degree corner at a 45-degree angle. It removes equal material from both walls and is ideal when symmetrical strength or uniform appearance is needed.
  • T-Bone Fillet: The relief cut extends entirely into one wall of the slot. This is often preferred in woodworking because the cut can be hidden on the non-visible side of a joint.

Step 1: Calculate the Tool Clearance Circle

  1. Select the Circles and Ellipses tool (E).
  2. Hold Ctrl and drag to create a perfect circle.
  3. In the toolbar, change the dimensions to match your router bit diameter plus an optional small clearance tolerance (typically 0.1 mm to 0.2 mm or 0.005" to 0.010"). For a 1/4" (6.35 mm) bit, a 6.5 mm circle is standard.
  4. Convert the circle to a path via Path > Object to Path (Ctrl + Shift + C).

Step 2: Position the Relief

Enable Snapping in the top-right corner, ensuring Snap to path intersections and Snap to cusp nodes are active.

For a Dogbone Relief:

  1. Turn on the bounding box midpoint snap or node snap.
  2. Select the circle and snap its center directly to the sharp 90-degree inside corner of your shape.
  3. With the circle centered on the corner, move it diagonally into the corner along the 45-degree axis until the outer edge of the circle clears the original corner vertex.
  4. Alternatively, use the Align and Distribute panel (Ctrl + Shift + A) or snap the perimeter of the circle to the corner vertex while maintaining a 45-degree offset.

For a T-Bone Relief:

  1. Snap the circle to the inside corner.
  2. Align the edge of the circle flush with one flat edge of the slot, allowing the circle to cut only into the opposing perpendicular edge.
  3. Ensure the deepest part of the circle extends at least far enough so the router bit can reach or pass the original corner vertex line.

Step 3: Apply the Boolean Operation

Once the clearance circles are positioned at all required internal corners:

  1. If you have multiple circles, select all of them and go to Path > Union (Ctrl + +) to join them into a single object.
  2. Select your main part path and the relief circle(s).
  3. If creating an internal cutout/pocket:
    • Perform Path > Union (Ctrl + +) if the relief circle extends outward from the pocket boundary.
  4. If creating a slot on an external perimeter:
    • Perform Path > Difference (Ctrl + -) to subtract the circles from the main stock outline.

Alternative: Automated Inkscape Extensions

For projects with numerous joints, third-party Inkscape extensions (such as the open-source Inkscape Dogbone Generator) can automate this process:

  1. Install the extension into your Inkscape extensions directory.
  2. Select your path with the Node Tool (N).
  3. Select the corner nodes that require clearance.
  4. Run the extension from the Extensions menu, input your tool diameter, select either Dogbone or T-bone, and apply the generated reliefs automatically.
