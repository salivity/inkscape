Convert RGB and HSL Colors in Inkscape with inkex

This guide explains how to convert colors between the RGB and HSL color spaces using the inkex.Color module in Inkscape 1.x+ Python extensions. By utilizing Inkscape's built-in color classes, you can parse color values, transform them between different color models, and apply the converted values directly to SVG elements.

Understanding inkex.Color

The inkex library provides native support for parsing, manipulating, and converting color formats via the inkex.Color class and its specific space implementations (such as ColorRGB and ColorHSL). Rather than requiring manual mathematical conversion algorithms, the library handles the color matrix transformations internally.

Converting RGB to HSL

To convert an RGB color to HSL, initialize a color object with RGB data and call the .to_hsl() method.

import inkex
from inkex import Color

# 1. Initialize an RGB color using hex, RGB string, or tuple
rgb_from_hex = Color("#3498db")
rgb_from_tuple = Color((52, 152, 219))
rgb_from_css = Color("rgb(52, 152, 219)")

# 2. Convert to HSL
hsl_color = rgb_from_hex.to_hsl()

# 3. Access HSL components
# Hue is in degrees [0, 360], Saturation and Lightness are normalized [0.0, 1.0]
hue = hsl_color.hue
saturation = hsl_color.saturation
lightness = hsl_color.lightness

print(f"H: {hue}, S: {saturation * 100}%, L: {lightness * 100}%")

Converting HSL to RGB

To convert an HSL color back to RGB, parse the HSL string or create an HSL object, then use the .to_rgb() method.

import inkex
from inkex import Color
from inkex.colors import ColorHSL

# Method A: Parse directly using CSS HSL format string
hsl_parsed = Color("hsl(204, 70%, 53%)")
rgb_color_a = hsl_parsed.to_rgb()

# Method B: Instantiate using ColorHSL directly
# Note: Values typically take hue (0-1 or 0-255 internally depending on format), 
# but passing a CSS string via Color() is standard and safest across versions.
hsl_direct = ColorHSL([204 / 360.0, 0.70, 0.53])
rgb_color_b = hsl_direct.to_rgb()

# Access RGB components (values range from 0 to 255)
red = rgb_color_a.red
green = rgb_color_a.green
blue = rgb_color_a.blue

# Export as Hex or standard CSS string
hex_output = str(rgb_color_a)  # e.g., "#3498db"

Applying Color Conversions to SVG Elements

Within an Inkscape extension class inheriting from inkex.EffectExtension, you can read an element's style attribute, convert its fill or stroke, and write it back.

import inkex
from inkex import Color

class AdjustColorEffect(inkex.EffectExtension):
    def effect(self):
        for elem in self.svg.selection:
            # Retrieve the fill color from the element style
            fill_value = elem.style.get("fill")
            
            if fill_value and fill_value != "none":
                # Parse current fill to Color
                current_color = Color(fill_value)
                
                # Convert to HSL to adjust lightness
                hsl = current_color.to_hsl()
                hsl.lightness = min(1.0, hsl.lightness * 1.2)  # Increase lightness by 20%
                
                # Convert back to RGB for SVG compatibility
                new_rgb = hsl.to_rgb()
                
                # Update element style
                elem.style["fill"] = str(new_rgb)

if __name__ == "__main__":
    AdjustColorEffect().run()
