Create Geometric Patterns with Inkscape Tiled Clones

This guide provides a straightforward walkthrough on using the Create Tiled Clones tool in Inkscape to generate precise geometric patterns, mandalas, and seamless tessellations. You will learn how to prepare your base shape, navigate the primary tabs in the dialog, configure shifts and rotations, and manage your cloned designs efficiently.

Accessing the Tool and Preparing the Base Shape

  1. Draw a base object using any tool (such as the Polygon, Circle, or Pen tool).
  2. With the object selected, click it a second time to reveal its rotation center (the crosshair icon).
  3. If creating radial or circular patterns, drag the rotation center away from the center of the shape to establish the pivot point. For standard grid patterns, leave it centered.
  4. Open the dialog by navigating to Edit > Clone > Create Tiled Clones... from the top menu.

Key Dialog Tabs and Settings

  • Symmetry: Controls the underlying mathematical layout. The default P1: simple translation works best for basic grids and radial arrays. Other options like P4 or P6 enable complex kaleidoscope and hexagonal tiling patterns.
  • Shift: Controls spacing between elements. Enter percentages in Shift X and Shift Y to create gaps or overlaps. To create staggered brick or honeycomb patterns, apply an offset in the Shift X > Per row field.
  • Scale: Adjusts the size of clones progressively across rows and columns. Enter positive percentages to grow clones or negative values to shrink them.
  • Rotation: Rotates each clone incrementally. This is essential for circular, spiral, and starburst designs.
  • Rows, columns: Located at the bottom of the dialog. Defines the exact grid dimension (e.g., 1 row and 12 columns for a 12-point circular pattern, or 10 rows and 10 columns for a full grid).

Creating a Radial Pattern (Mandala / Starburst)

  1. Select your shape with its rotation center offset.
  2. In the Symmetry tab, select P1: simple translation.
  3. In the Shift tab, set Shift X > Per column to -100% so all clones share the exact same starting origin.
  4. In the Rotation tab, calculate the angle by dividing 360 by your desired number of clones (e.g., for 12 clones, enter 30 in Angle > Per column).
  5. At the bottom, set Rows to 1 and Columns to 12.
  6. Click Create.

Creating a Geometric Hexagonal Grid

  1. Create a regular hexagon using the Stars and Polygons tool.
  2. Open the Create Tiled Clones dialog and reset previous settings using the Reset button at the bottom right.
  3. In the Shift tab:
    • Set Shift X > Per row to 50%.
    • Set Shift Y > Per row to -25%.
  4. Set the desired number of Rows and Columns (such as 8 and 8).
  5. Click Create.

Editing and Managing Clones

  • Live Editing: Any modification made to the original parent shape—such as changing nodes, color, or stroke width—instantly updates all clones across the entire pattern.
  • Removing Patterns: To undo a generation, click Remove in the dialog while the original parent object is selected.
  • Separating Clones: To edit shapes individually, select all generated clones and go to Edit > Clone > Unlink Clone.
