Automated Jump-Stitch Trimming in Ink/Stitch

This guide explains how to configure automated jump-stitch trimming commands in Ink/Stitch for Inkscape. By attaching native trim commands to specific embroidery elements or configuring global jump-distance thresholds, you can command compatible embroidery machines to cut travel threads automatically between sections, significantly reducing manual cleanup after stitching.

Method 1: Attaching Direct Trim Commands to Objects

Attaching an explicit trim command to an object instructs the embroidery machine to cut the thread immediately after completing that specific element.

  1. Select the Object: In your Inkscape workspace, use the Select tool (S) to click the path or shape after which you want the thread trimmed.
  2. Open the Commands Menu: Navigate to the top menu and select Extensions > Ink/Stitch > Commands > Attach commands to selected objects...
  3. Select the Trim Option: In the dialog window that appears, look for the option labeled Trim thread after this object (or simply Trim thread depending on your Ink/Stitch version) and check its box.
  4. Apply: Click Apply, then Close.

A visual trim indicator—represented by a small scissors icon or marker connected by a dashed line to your object—will appear on your canvas. This marker signals the exact point where the trim instruction is injected into the stitch sequence. Do not delete this marker; it will not be stitched, but it must remain on the canvas to generate the machine trim command.

Method 2: Automatic Trimming via Jump-Stitch Length

If you do not want to place individual commands manually, Ink/Stitch can automatically insert trims whenever a jump stitch exceeds a specified distance.

  1. Open Document or Layer Properties: Select your object or entire layer, then navigate to Extensions > Ink/Stitch > Params.
  2. Set Jump Distance: Locate the jump stitch settings or travel path configurations. For designs with long distances between objects, ensure your export format settings recognize jumps as trims.
  3. Configure Export Settings: Go to Extensions > Ink/Stitch > Preferences (or output settings for specific formats like DST). Set the minimum jump stitch threshold to trigger a trim command. When a travel line exceeds this value, Ink/Stitch will automatically convert the jump into a trim event.

Exporting and Machine Compatibility

For automated trims to function on your embroidery machine:

  • File Format Support: Save your finished file using File > Save As... or File > Save a Copy... into a format that supports trim commands, such as .PES, .DST, .EXP, or .JEF. Note that some older machines or basic formats may interpret trim signals as multiple jump stitches rather than hard cuts.
  • Machine Settings: Ensure that your embroidery machine's internal settings have automated thread cutting enabled for jump stitches, as hardware toggles can override file instructions.
