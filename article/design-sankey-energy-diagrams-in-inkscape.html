Design Sankey Energy Diagrams in Inkscape

This guide explains how to construct professional Sankey energy flow diagrams using custom Bezier ribbons in Inkscape. You will learn how to accurately set up scaled nodes, draw smooth cubic Bezier connectors that depict changing energy magnitudes, ensure uniform or tapering ribbon widths, and apply styling techniques such as linear gradients and transparency to visualize complex multi-directional energy distributions effectively.

1. Set Up the Document and Proportional Scale

Before drawing paths, establish a strict spatial and proportional grid:

  • Go to File > Document Properties and enable a rectangular grid. Ensure snapping is turned on, particularly Snap to paths and Snap to cusp nodes.
  • Determine your scale ratio (for example, 10 pixels of height = 100 kW or 10 MJ).
  • Use the Rectangle tool (R) to create vertical blocks representing your source, conversion, and end-use stages. The height of each rectangle must match the total energy entering or leaving that point.

2. Method A: Drawing Closed Bezier Ribbons

For flows that split, merge, or change thickness to depict energy losses:

  1. Select the Draw Bezier curves tool (B) in regular Bezier mode.
  2. Click the top-right corner of the source node.
  3. Move across to the top-left corner of the destination node and click.
  4. Move down to the bottom-left corner of the destination node's segment and click.
  5. Move back to the bottom-right corner of the source node and click.
  6. Click the original starting node to close the path.
  7. Switch to the Node tool (N). Select the top horizontal segment and drag it to create an S-curve, or pull the node handles horizontally to create smooth horizontal entry and exit angles.
  8. Repeat the handle adjustments on the bottom segment, keeping the handles parallel to ensure a smooth, fluid transition between the two nodes.

3. Method B: Stroke-to-Path for Constant Flows

If the flow represents a conserved amount of energy without losses between two points:

  1. Select the Draw Bezier curves tool (B) and draw a single center line from the source to the target.
  2. Switch to the Node tool (N) and pull the handles horizontally to produce the characteristic S-curve flow.
  3. Open Object > Fill and Stroke (Shift+Ctrl+F), go to the Stroke style tab, and set the Width exactly to your energy scale equivalent (e.g., 50 px for 500 kW).
  4. Set the cap to Butt cap to keep the ends flat.
  5. Go to Path > Stroke to Path (Ctrl+Alt+C). This transforms the stroke into a closed polygon with independent top and bottom Bezier edges, allowing you to manually snap the ends flush to adjacent node blocks.

4. Splitting and Branching Flows

Energy diagrams commonly feature splits, such as useful work continuing forward while dissipated heat drops downward:

  1. When branching a ribbon, align the starting edges of both paths along the same source boundary so their combined heights equal the source's total height.
  2. For losses (e.g., thermal waste), route the Bezier curve downward at a 90-degree angle. Ensure the curve enters vertically by holding Ctrl while adjusting the lower handle downward.
  3. Snap the terminator of the loss ribbon to a flat horizontal line or a designated waste node.

5. Applying Gradients and Color Coding

  • Source-to-Target Gradients: Select a ribbon and choose the Create and edit gradients tool (G). Drag a linear gradient from the source node to the destination node. Set the starting stop to match the source category color (e.g., chemical energy in green) and the ending stop to match the destination category color (e.g., thermal energy in red).
  • Opacity: Set the ribbon opacity to between 80% and 90% in the Fill and Stroke panel. This prevents visual clash where flows branch or overlap.

6. Final Alignment and Labels

  • Group each flow ribbon with its corresponding node using Object > Group (Ctrl+G) to maintain layout stability.
  • Use the Text tool (T) to place clear, horizontal labels above or directly inside nodes. Include both the stream name and the numerical flow value with correct units (e.g., "Electricity: 450 GWh"). Align text elements to the grid rather than the curved ribbons for clean readability.
