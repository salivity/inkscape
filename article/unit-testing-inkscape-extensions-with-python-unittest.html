Unit Testing Inkscape Extensions with Python unittest

This article provides a comprehensive guide to building reliable unit tests for custom Inkscape extensions using Python's built-in unittest framework. You will learn how modern Inkscape extensions (inkex) operate, how to instantiate and feed mock SVG data to your extension without running the Inkscape GUI, and how to assert XML modifications and outputs within standard test suites.

The Architecture of an Inkscape Extension

Modern Inkscape extensions are Python scripts powered by the inkex module, typically subclassing inkex.EffectExtension or inkex.InputExtension. Under normal operation, Inkscape passes CLI arguments, the path to a temporary SVG file, and receives the modified SVG via standard output.

To unit test an extension effectively:

  1. Bypass the Inkscape application process entirely.
  2. Provide a controlled SVG string or file as input.
  3. Pass mock command-line arguments to simulate user settings.
  4. Execute the extension's execution lifecycle in memory.
  5. Parse the output or inspect the modified XML document using unittest assertions.

Setting Up the Test Structure

A standard Inkscape extension project typically organizes its code into a root directory containing the .inx and .py extension files, alongside a dedicated tests/ directory:

my_extension/
│
├── my_extension.py
├── my_extension.inx
└── tests/
    ├── __init__.py
    └── test_my_extension.py

Writing a Sample Extension

Consider a basic extension, ColorInvertExtension, located in my_extension.py. It iterates through paths and changes their fill color:

import inkex
from inkex import PathElement

class ColorInvertExtension(inkex.EffectExtension):
    def add_arguments(self, pars):
        pars.add_argument("--target-id", type=str, dest="target_id", default="")

    def effect(self):
        target_id = self.options.target_id
        if target_id:
            elem = self.svg.getElementById(target_id)
            if elem is not None:
                elem.style["fill"] = "#ffffff"

Implementing the Unit Test

To test ColorInvertExtension, construct a unittest.TestCase that initializes the extension, feeds it a minimal SVG tree, executes the run method, and inspects the resulting DOM elements.

Here is tests/test_my_extension.py:

import io
import unittest
from my_extension import ColorInvertExtension

class TestColorInvertExtension(unittest.TestCase):

    def setUp(self):
        """Define a minimal SVG document for testing."""
        self.sample_svg = (
            b'<?xml version="1.0" encoding="UTF-8"?>\n'
            b'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">\n'
            b'  <rect id="rect_target" x="10" y="10" width="50" height="50" style="fill:#000000" />\n'
            b'  <circle id="circle_untouched" cx="80" cy="80" r="10" style="fill:#ff0000" />\n'
            b'</svg>'
        )

    def test_color_inversion_applied_to_target(self):
        """Verify target element fill changes to #ffffff."""
        extension = ColorInvertExtension()
        
        args = ["--target-id=rect_target"]
        input_stream = io.BytesIO(self.sample_svg)
        output_stream = io.BytesIO()

        # Run the extension in-memory
        extension.run(args=args, input_stream=input_stream, output=output_stream)

        # Inspect the modified document
        modified_rect = extension.svg.getElementById("rect_target")
        self.assertIsNotNone(modified_rect)
        self.assertEqual(modified_rect.style.get("fill"), "#ffffff")

    def test_untouched_element_remains_unchanged(self):
        """Verify non-target elements are not modified."""
        extension = ColorInvertExtension()
        
        args = ["--target-id=rect_target"]
        input_stream = io.BytesIO(self.sample_svg)
        output_stream = io.BytesIO()

        extension.run(args=args, input_stream=input_stream, output=output_stream)

        untouched_circle = extension.svg.getElementById("circle_untouched")
        self.assertEqual(untouched_circle.style.get("fill"), "#ff0000")

    def test_missing_target_handles_gracefully(self):
        """Verify passing a nonexistent ID does not raise unhandled exceptions."""
        extension = ColorInvertExtension()
        
        args = ["--target-id=nonexistent_id"]
        input_stream = io.BytesIO(self.sample_svg)
        output_stream = io.BytesIO()

        try:
            extension.run(args=args, input_stream=input_stream, output=output_stream)
        except Exception as exc:
            self.fail(f"Extension raised an unexpected exception: {exc}")

if __name__ == "__main__":
    unittest.main()

Best Practices for Inkscape Extension Unit Tests

  1. Avoid Disk I/O: Use io.BytesIO for both standard input and output streams. This keeps the test suite fast and independent of the local filesystem.
  2. Test Edge Cases: Include tests for invalid IDs, empty layers, complex transforms, and missing style attributes.
  3. Assert Specific XML Nodes: Query elements via extension.svg.getElementById() or standard XPath selectors like extension.svg.xpath('//svg:path') to check element attributes, coordinates, and CSS styling.
  4. Inspect Generated Elements: If your extension generates new shapes, assert that the newly inserted node exists under the expected parent node (self.assertIn(new_node, parent_element)).

Running the Tests

Execute the unit tests directly from the root directory of your project using Python's standard test discovery:

python -m unittest discover -s tests
