Using Path Difference on Text in Inkscape

Performing a path Difference operation between text and a background rectangle is a common way to create cut-out or stencil effects in Inkscape. However, trying to run this operation directly will fail because Inkscape cannot perform Boolean operations on editable text objects. This guide explains the essential prerequisite steps required to convert your live text into a compatible path format before cutting it out of a background shape.

The Required Step: Convert Text to Paths

Before you can perform a path Difference (Path > Difference or Ctrl + -), you must convert the live text object into a unified vector path. Live text is stored as typography data rather than pure vector nodes, making it incompatible with Boolean path operations.

Follow these steps to prepare your text and complete the operation:

  1. Convert the Text Object to a Path
    Select your text with the Select Tool (S). Go to the top menu and select Path > Object to Path (or press Shift + Ctrl + C).

  2. Ungroup the Letter Paths
    Inkscape converts text into a group of individual paths (one path per letter). Boolean operations require two single paths, not a group. With the converted text still selected, go to Object > Ungroup (or press Ctrl + Shift + G).

  3. Combine the Letters into a Single Path
    With all the individual letter paths selected, go to Path > Union (or press Ctrl + +). This merges all the separate letters into one single, compound path.

  4. Perform the Path Difference
    Ensure your unified text path is positioned above the background rectangle in the z-order (layer stack). Select both the text path and the background rectangle by holding Shift and clicking each. Finally, choose Path > Difference (or press Ctrl + -).

The text shape will cut directly through the rectangle, leaving you with a clean, cut-out vector shape.
