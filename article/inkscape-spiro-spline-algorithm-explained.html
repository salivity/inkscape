Inkscape Spiro Spline Algorithm Explained

Inkscape’s Spiro Spline mode relies on an algorithm based on Euler spirals, also known as clothoids or Cornu spirals, implemented through Raph Levien’s libspiro library. Unlike standard Bézier curves that can introduce abrupt changes in curvature, the Spiro algorithm computes smooth trajectories by ensuring that curvature changes linearly with respect to arc length. This overview details the mathematical foundation of Euler spirals, how the algorithm optimizes curves across control points, and how Inkscape converts these paths into standard SVG vectors.

The Foundation: Euler Spirals

The core mathematical primitive behind the Spiro spline is the Euler spiral (clothoid). In an Euler spiral, curvature (\(\kappa\)) is directly proportional to the curve's arc length (\(s\)), represented by the relationship:

\[\kappa(s) = \frac{d\theta}{ds} = cs\]

where \(c\) is a constant scaling factor and \(\theta\) is the tangent angle. Because the curvature changes steadily rather than abruptly, transitions between straight lines and curved segments—or between opposite bends—occur seamlessly without sudden spikes in centrifugal acceleration or visual flatness.

The Optimization Algorithm in libspiro

Inkscape delegates the trajectory calculation to libspiro, an open-source library created by Raph Levien based on his doctoral research into curve design. When a user places knots in Spiro mode, the algorithm solves a global optimization problem:

  1. System of Equations: The algorithm models each segment between consecutive control points as an Euler spiral. It sets up a non-linear system of equations enforcing boundary conditions at each knot, such as point positions, continuous tangents (\(G^1\) continuity), and continuous curvature (\(G^2\) continuity).
  2. Minimizing Curvature Variation: The solver iterates to find the parameters for each spiral segment that minimize the overall variation of curvature (the integral of \((d\kappa/ds)^2\) over the path length).
  3. Handling Constraints: The algorithm supports multiple knot types—including smooth continuous points, sharp corners, and inflection points—by adjusting the boundary constraints for specific segments within the solver matrix.

By minimizing the rate of curvature change across the entire spline, the algorithm avoids unwanted inflections, loops, and "pinching" artifacts commonly produced by standard cubic splines.

Conversion to Bézier Curves for SVG

Because the SVG specification does not natively support clothoids or Euler spirals, Inkscape uses Spiro calculations strictly as a Path Effect (LPE). Once libspiro computes the optimal spiral trajectory, Inkscape runs an approximation algorithm to subdivide the Euler curve into a series of standard cubic Bézier segments. It fits control handles to match the spiral’s path within a strict tolerance threshold, allowing the resulting graphic to remain fully compatible with SVG renderers while preserving the aesthetic smoothness of the underlying spiral.
