Map Raster Depth Soundings to Contours in Inkscape

This guide details the end-to-end process of transforming static raster depth soundings from nautical charts into scalable vector bathymetric contours using Inkscape. By importing your georeferenced or scanned chart, interpreting soundings through manual interpolation, drawing continuous depth curves with the Bézier tool, and applying hydrographic styling conventions, you can generate clean, publishable vector bathymetry suitable for digital cartography and navigational visualization.

1. Import and Setup the Raster Chart

  1. Open Inkscape and create a new document.
  2. Go to File > Import to load your raster nautical chart (PNG, TIFF, or JPEG). In the dialog, select Embed and set image resolution to From file.
  3. Open the Layers and Objects panel (Shift + Ctrl + L). Rename the default layer to Raster Chart.
  4. Select the imported image and lock the layer by clicking the padlock icon in the Layers panel. This prevents accidental movement while tracing.
  5. Create a new layer above it and name it Bathymetric Contours.

2. Identify Soundings and Plan Contour Intervals

Nautical charts use scattered numerical soundings (spot depths) rather than continuous contour lines. Before drawing:

  • Determine the contour interval you want to generate (e.g., 2m, 5m, 10m, or 20m depth lines).
  • Mentally or digitally interpolate between numbers. For example, if a 4 sounding sits next to an 8, a 6-meter depth contour will pass roughly halfway between them.
  • Locate shoals, reefs, and navigational channels to maintain navigational safety margins (contours traditionally favor the shallower soundings).

3. Trace Contours Using the Bézier Tool

  1. Switch to the Draw Bézier curves and straight lines tool by pressing B.
  2. In the top tool controls bar, set the mode to Create regular Bézier path and shape to None.
  3. Click to drop nodes along an interpolated depth path. Keep nodes relatively sparse; you will refine curvature later.
  4. For closed depth areas (like underwater knolls or depressions), return to the starting node and click it to close the path. For continuous coast-to-edge contours, extend the path slightly beyond the chart boundary.
  5. Press Enter to complete the path.

4. Refine Curvature and Nodes

  1. Switch to the Edit paths by nodes tool (N).
  2. Click and drag the line segments between nodes to smooth them into natural curves following the underwater topography.
  3. Select nodes that appear sharp or jagged, and click Make selected nodes smooth in the top toolbar.
  4. If a contour requires minor simplification without losing its overall geometry, select the path and press Ctrl + L (Path > Simplify). Adjust the simplification threshold under Edit > Preferences > Behavior > Steps if the command alters the line too aggressively.

5. Structure Depth Polygons

If your goal is to generate color-filled depth bands rather than single contour lines:

  1. Create a duplicate of each boundary line (Ctrl + D).
  2. Join adjacent contour lines together at the document boundaries using the Node tool by selecting two endpoints and clicking Join selected endnodes with a new segment.
  3. Ensure every depth band forms a closed polygon representing a specific depth range (e.g., 0–2m, 2–5m, 5–10m).
  4. Organize the layers or stack order so that the deepest bathymetric layer sits at the bottom and shallow waters sit on top (Page Down / Page Up).

6. Apply Hydrographic Styling

  1. Open the Fill and Stroke panel (Shift + Ctrl + F).
  2. For line contours:
    • Select the paths and set the Stroke paint to a uniform nautical blue (e.g., #1b4d7e) or neutral dark grey.
    • Adjust Stroke style width to maintain visual hierarchy (use thicker strokes for index contours like 10m/50m/100m, and thinner lines for intermediate contours).
    • Apply dashed patterns for approximate or low-confidence soundings.
  3. For depth tint bands:
    • Apply color fills ranging from white or light blue for deep water to progressively darker cyan/blue tints for shallow water, matching standard navigational charting conventions.
    • Set stroke to none on polygon fills to prevent edge artifacts.

7. Clean and Export the Vector Bathymetry

  1. Toggle the visibility of the Raster Chart layer off by clicking the eye icon in the Layers panel to inspect the vector contours against a blank background.
  2. Select all vector paths and check for unintended gaps, overlapping nodes, or crossed segments.
  3. Go to File > Save As to save the master vector file as an Inkscape SVG.
  4. To export for publication or GIS post-processing, choose File > Export, select your format (such as PDF, DXF, or optimized SVG), and set your desired output DPI.
