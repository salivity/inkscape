How to Apply Blur Effects in Inkscape

Applying blur effects in Inkscape allows designers to create depth, soft shadows, and glowing highlights on vector graphics. This guide provides a direct walkthrough on how to use Inkscape's Fill and Stroke dialog to adjust the Gaussian blur on any selected path, shape, or text object efficiently.

1. Select Your Object

Open your project in Inkscape and use the Select tool (S or F1) to click on the object, path, or group you want to blur.

2. Open the Fill and Stroke Dialog

Access the Fill and Stroke panel using any of the following methods:

  • Press Shift + Ctrl + F on Windows/Linux or Shift + Cmd + F on macOS.
  • Go to the top menu bar and select Object > Fill and Stroke.
  • Click the Fill and Stroke icon in the command bar.

3. Adjust the Blur Slider

Look at the bottom of the Fill and Stroke panel. You will find two sliders beneath the color controls: Blur (%) and Opacity (%).

  • Drag the Slider: Move the Blur slider to the right to increase the blur intensity, or to the left to decrease it.
  • Enter a Numerical Value: Type an exact percentage directly into the input box next to the slider for precise control. A value of 0% means completely sharp, while higher values progressively soften the edges.

4. Fine-Tune the Effect

  • Combine with Opacity: Use the Opacity slider located directly below the Blur slider to make blurred elements, such as drop shadows, appear more subtle and translucent.
  • Color Adjustments: You can change the base color of the blurred object within the Fill or Stroke paint tabs without resetting the blur level.
  • Remove the Blur: To return the object to its sharp state, reset the Blur value back to 0%.
