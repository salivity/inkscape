Pipe SVG to PNG Using Inkscape CLI

Converting SVG data to a PNG image directly through command-line streams avoids creating unnecessary temporary files on disk. Modern versions of Inkscape (version 1.0 and later) support piping input directly from standard input (stdin) and streaming the exported raster image to standard output (stdout). This approach is particularly effective for backend automation, cloud functions, and shell scripts.

The Command Syntax

To feed an SVG string into Inkscape and receive a PNG via standard output, use the --pipe argument combined with --export-type=png and --export-filename=-.

Here is the standard Bash command:

echo '<svg xmlns="http://www.w3.org/2000/svg" width="100" height="100"><circle cx="50" cy="50" r="40" fill="red"/></svg>' | \
inkscape --pipe --export-type=png --export-filename=- > output.png

How the Parameters Work

  • --pipe: Instructs Inkscape to read the incoming SVG file directly from standard input rather than looking for a file path on the filesystem.
  • --export-type=png: Specifies that the rendering engine should output a PNG raster file.
  • --export-filename=-: Using the hyphen (-) as the export target directs the resulting binary stream to standard output rather than saving it to a local file.

Controlling Dimensions and Quality

By default, Inkscape renders the image using the dimensions and DPI specified within the SVG document. You can override these dimensions directly in the pipe command:

  • Export DPI: Add --export-dpi=300 to increase resolution for print quality.
  • Explicit Width and Height: Add --export-width=800 or --export-height=600 to scale the image proportionally or to strict dimensions.
  • Transparent Background: Add --export-background-opacity=0 to ensure transparent areas remain clear.

Example with resolution options:

cat graphic.svg | inkscape --pipe --export-type=png --export-dpi=300 --export-filename=- > high_res.png

Integration in Applications

When invoking this command within languages like Python or Node.js, execute the process with standard I/O configured to pipes:

  • Set stdin to PIPE and write your raw SVG UTF-8 string into the stream.
  • Close stdin to signal EOF (End of File) so Inkscape knows the input is complete.
  • Read the binary buffer directly from stdout to process or serve the resulting PNG image in memory.
