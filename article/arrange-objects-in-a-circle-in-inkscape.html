Arrange Objects in a Circle in Inkscape

Arranging multiple shapes or objects into a perfect circular formation in Inkscape is simple when using the dedicated Polar Coordinates tab in the Arrange dialog. This guide provides a straightforward, step-by-step walkthrough on how to locate the tool, configure its settings such as radius and rotation angle, and instantly distribute your objects into circles or arcs.

Step 1: Open the Arrange Dialog

  1. Launch Inkscape and prepare the objects you want to arrange.
  2. Select all the target objects using the Selection Tool (S or F1).
  3. Open the Arrange dialog by going to the top menu and selecting Object > Arrange....
  4. In the Arrange panel that appears on the right side of the screen, click on the Polar coordinates tab.

Step 2: Set the Anchor Point

Under the Anchor point section, define which part of each object will align to the circular path:

  • Bounding box center: Aligns the middle of each object along the circumference (recommended for most symmetrical designs).
  • Object's rotational center: Uses the custom pivot point set on the individual objects.

Step 3: Define the Circle Parameters

Adjust the circular dimensions in the Radius and Center sections:

  • Radius: Set the desired size of the circle (X and Y radii). You can set both to equal values for a perfect circle, or different values for an ellipse. Selecting Calculate radius automatically will size the circle based on the selected objects.
  • Center of circle: Set the specific X and Y coordinates for the center point of the circular pattern, or leave it set to the selection's default center.

Step 4: Configure Angle and Object Orientation

Adjust how the objects are distributed around the circular path:

  • Angle span: Choose the total arc length. Enter 360° for a full closed circle, or a smaller angle (such as 180°) for a semi-circle.
  • Angle offset: Set the starting position of the first object (e.g., 0° starts at the right, 90° starts at the top).
  • Rotate objects: Check this box if you want the objects to orient themselves radially to face along the curvature of the circle. Leave it unchecked if you want all objects to maintain their original, upright rotation.

Step 5: Apply the Arrangement

Once all parameters are configured, click the Arrange button at the bottom of the panel. Inkscape will immediately reposition the selected objects along the designated circular path.
