Generate Cartesian and Polar Grids in Inkscape

Inkscape provides built-in render extensions that allow you to generate fully customizable Cartesian and polar grids automatically. This guide explains how to locate these tools, configure their core parameters such as spacing, divisions, and line weights, and render precise vector coordinate systems directly onto your canvas without manual drawing.

Generating a Cartesian Grid

A Cartesian grid consists of perpendicular horizontal and vertical lines, ideal for standard charts, graph paper designs, and technical layouts.

  1. Open the Grid Tool: Go to the top menu and select Extensions > Render > Grids > Grid... (or Cartesian Grid... depending on your Inkscape version).
  2. Set Dimensions and Spacing:
    • Width and Height: Define the overall dimensions of the entire grid area.
    • Horizontal and Vertical Spacing: Enter the distance between the main grid lines.
  3. Configure Subdivisions: Set the number of sub-grid lines between major lines to create finer subdivisions.
  4. Adjust Line Styles:
    • Configure the Major Grid Line Width and Minor Grid Line Width to distinguish between primary and secondary divisions.
  5. Render: Check the Live Preview box to verify the dimensions, then click Apply to generate the vector grid on your canvas.

Generating a Polar Grid

A polar grid consists of concentric circles intersected by radial lines originating from a central point, commonly used for circular charts, radar layouts, and radial symmetry designs.

  1. Open the Polar Grid Tool: Go to the top menu and select Extensions > Render > Grids > Polar Grid...
  2. Set Grid Dimensions:
    • Radius: Define the radius of the outermost circle.
    • Center X / Center Y: Set the coordinates for the grid's origin (defaulting to the center of the selection or canvas).
  3. Configure Circular (Circumferential) Lines:
    • Set the number of Circumferential Divisions to determine how many concentric rings to draw.
    • Specify subdivisions between the main concentric rings if necessary.
  4. Configure Radial Lines:
    • Set the Angular Divisions to define how many radial lines extend outward from the center (e.g., 12 divisions for 30-degree increments).
  5. Adjust Styling: Set individual stroke widths for major and minor circles, as well as radial spokes.
  6. Render: Enable Live Preview to check the layout, then click Apply.

Managing Rendered Grids

Once generated, both Cartesian and polar grids are inserted as grouped vector paths. You can modify them at any time:

  • Ungrouping: Select the grid and press Ctrl + Shift + G (or Cmd + Shift + G on macOS) to separate individual lines and rings for independent editing.
  • Styling: Use the Fill and Stroke panel (Ctrl + Shift + F) to change line colors, opacity, or dash patterns.
  • Snapping: Enable path snapping in the top-right toolbar to snap other vector shapes directly to the intersections of your generated grid.
