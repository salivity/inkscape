Export Specific Pages Using Inkscape CLI

This guide provides a straightforward walkthrough on how to export specific pages from a multi-page document using the Inkscape command-line interface (CLI). By using the --export-page argument introduced in modern versions of Inkscape, you can automate rendering individual pages to formats such as PDF, PNG, or PS directly from your terminal or shell scripts without opening the graphical interface.

Prerequisites

Multi-page document handling was introduced natively in Inkscape 1.2. Ensure you have Inkscape 1.2 or higher installed and that the inkscape executable is accessible in your system's PATH.

Basic Syntax

To export a specific page, pass the input file, specify the target page number using the --export-page argument, and define the destination output with --export-filename.

inkscape input.svg --export-page=PAGE_NUMBER --export-filename=output.pdf

Page Indexing Rules

  • Page numbering uses 1-based indexing. The first page in your document is page 1, the second is page 2, and so on.
  • The --export-page argument accepts an integer representing the single page you wish to render.

Examples

Exporting a Single Page to PDF

To export the second page of a multi-page SVG file called document.svg to a PDF named page_2.pdf:

inkscape document.svg --export-page=2 --export-filename=page_2.pdf

Exporting a Single Page to PNG

To render the first page of document.svg directly to a high-resolution raster image:

inkscape document.svg --export-page=1 --export-filename=page_1.png --export-dpi=300

Exporting Multiple Specific Pages via Scripting

Because --export-page targets one page per command execution, export multiple specific pages by chaining commands or using a shell loop:

Bash (Linux / macOS):

for PAGE in 1 3 5; do
  inkscape document.svg --export-page=$PAGE --export-filename="page_${PAGE}.pdf"
done

PowerShell (Windows):

1, 3, 5 | ForEach-Object {
    inkscape document.svg --export-page=$_ --export-filename="page_$_.pdf"
}
