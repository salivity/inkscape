How to Assign an ICC Color Profile in Inkscape

Assigning an ICC color profile in Inkscape ensures that your vector artwork displays accurately and exports with consistent colors across different screens and print devices. This guide covers how to install, link, and apply an ICC color profile directly to your Inkscape document using the built-in Document Properties and Color Management settings.

1. Install the ICC Profile on Your System

Before Inkscape can use a specific ICC profile, the profile file (.icc or .icm) must be installed on your operating system:

  • Windows: Right-click the .icc file and select Install Profile, or copy it to C:\Windows\System32\spool\drivers\color.
  • macOS: Copy the file to /Library/ColorSync/Profiles or ~/Library/ColorSync/Profiles.
  • Linux: Copy the file to ~/.local/share/icc/ or ~/.color/icc/.

Restart Inkscape if it was open during installation so it detects the new profile.

2. Open Document Properties

  1. Launch Inkscape and open the document you want to configure.
  2. Go to File in the top menu and select Document Properties (or press Ctrl + Shift + D on Windows/Linux, Cmd + Shift + D on macOS).

3. Link the Color Profile to the Document

  1. In the Document Properties dialog, click on the Color tab.
  2. Look for the Available Profiles drop-down menu, which lists all ICC profiles recognized by your system.
  3. Select the desired color profile from the list.
  4. Click the Link Profile (or Add) button. The profile will now appear under the list of linked profiles for this document.
  5. Close the Document Properties dialog.

4. Apply the Profile to Document Objects

To render specific colors using the assigned profile:

  1. Open the Fill and Stroke panel (Object > Fill and Stroke or Shift + Ctrl + F).
  2. Select the object you want to adjust.
  3. In the Fill or Stroke tab, select the CMS (Color Management System) color selector icon.
  4. Choose your linked ICC profile from the profile menu within the CMS tab to assign and adjust colors precisely according to that profile's color space.
