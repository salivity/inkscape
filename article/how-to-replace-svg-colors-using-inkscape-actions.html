How to Replace SVG Colors Using Inkscape Actions

This article explains how to automate color replacement in SVG files by leveraging Inkscape’s command-line action system combined with custom scripting. You will learn the specific command-line syntax for chaining Inkscape actions to select and modify color attributes, as well as how to integrate these commands into an automated script to process files without opening the graphical interface.

Understanding Inkscape Command-Line Actions

Inkscape provides a robust command-line interface (CLI) powered by the --actions argument. This feature allows you to chain multiple internal operations—such as selecting objects, modifying XML attributes, and exporting files—sequentially by separating commands with semicolons.

To inspect all supported actions in your installed version of Inkscape, open your terminal and run:

inkscape --action-list

Constructing the Color Replacement Action Chain

Color replacement in an SVG via actions relies on selecting the target elements by their current color and applying the new color attribute before saving the file.

The core action sequence consists of:

  1. Clearing existing selections: select-clear
  2. Selecting elements containing the old color: select-by-fill:#OLD_HEX or select-by-stroke:#OLD_HEX
  3. Setting the new color attribute: set-attribute:style,fill:#NEW_HEX (or using object-set-property:fill,#NEW_HEX)
  4. Writing the changes to a destination file: export-filename:output.svg;export-do

A complete one-line command looks like this:

inkscape input.svg --actions="select-clear;select-by-fill:#ff0000;set-attribute:fill,#00ff00;export-filename:output.svg;export-do"

Creating an Automated Color Replacement Script

To handle dynamic inputs and batch operations, wrap the Inkscape actions inside a shell or Python script. Below are practical implementations for both environments.

Bash Automation Script

Save the following code as replace_svg_color.sh:

#!/usr/bin/env bash

INPUT_FILE="$1"
OLD_COLOR="$2"
NEW_COLOR="$3"
OUTPUT_FILE="$4"

if [ "$#" -ne 4 ]; then
    echo "Usage: $0 <input.svg> <old_hex> <new_hex> <output.svg>"
    exit 1
fi

ACTION_STRING="select-clear;select-by-fill:${OLD_COLOR};set-attribute:fill,${NEW_COLOR};export-filename:${OUTPUT_FILE};export-do"

inkscape "${INPUT_FILE}" --actions="${ACTION_STRING}"

Make the script executable and run it:

chmod +x replace_svg_color.sh
./replace_svg_color.sh icon.svg "#3498db" "#e74c3c" icon_modified.svg

Python Automation Script

For cross-platform environments or integration into larger pipelines, Python’s subprocess module provides robust handling:

import subprocess
import sys

def replace_svg_color(input_svg, old_hex, new_hex, output_svg):
    actions = (
        f"select-clear;"
        f"select-by-fill:{old_hex};"
        f"set-attribute:fill,{new_hex};"
        f"export-filename:{output_svg};"
        f"export-do"
    )
    
    command = [
        "inkscape",
        input_svg,
        f"--actions={actions}"
    ]
    
    result = subprocess.run(command, capture_output=True, text=True)
    
    if result.returncode == 0:
        print(f"Successfully generated {output_svg}")
    else:
        print(f"Error processing SVG: {result.stderr}", file=sys.stderr)

if __name__ == "__main__":
    replace_svg_color("source.svg", "#000000", "#ffffff", "result.svg")

Key Considerations

  • Inline Styles vs. Presentation Attributes: Some SVGs define colors using CSS styles (style="fill:#000000"), while others use direct attributes (fill="#000000"). Using set-attribute:style,fill:#NEW_HEX overwrites style declaration properties directly.
  • Handling Strokes: If the target SVG uses strokes instead of or in addition to fills, append select-by-stroke:#OLD_HEX;set-attribute:stroke,#NEW_HEX to your action chain.
  • Case Sensitivity: Ensure hex color codes match the casing format inside the SVG source data (typically lowercase), as matching can fail if formats differ.
