Inkscape CLI: Export Vector Paths Without Rasters

This guide explains how to use the Inkscape command-line interface (CLI) to strip all raster elements from your files and export pure vector paths. Using Inkscape's modern action system, you can automate the selection and deletion of embedded or linked bitmap images before exporting your graphics to clean SVG or PDF formats.

The Modern Action Workflow

Modern versions of Inkscape (v1.2 and newer) provide a headless action pipeline through the --actions parameter. This feature allows you to query specific SVG elements, manipulate the document tree, and export the modified file in a single terminal command.

To find and eliminate all raster images (represented internally by <image> tags), use the following command structure:

inkscape input.svg --actions="select-by-element:image;delete;export-filename:output.svg;export-do"

Command Breakdown

  • input.svg: The source file containing mixed vector paths and raster elements.
  • --actions="...": Chains multiple internal Inkscape commands separated by semicolons:
    • select-by-element:image: Targets every raster graphic tag within the document.
    • delete: Drops all currently selected items from the document tree.
    • export-filename:output.svg: Designates the path and file name for the final export.
    • export-do: Executes the export pipeline.

Exporting to Vector PDF

If you need a vector-only PDF stripped of raster data, set the target file extension to .pdf and specify the PDF export parameters directly:

inkscape input.svg --actions="select-by-element:image;delete;export-filename:output.pdf;export-do"

To ensure strokes remain vector paths rather than being converted or rasterized during the PDF write process, append the --export-pdf-version flag:

inkscape input.svg --export-pdf-version=1.5 --actions="select-by-element:image;delete;export-filename:output.pdf;export-do"

Exporting to Plain SVG

Inkscape documents frequently contain proprietary metadata, editor tags, and sodipodi namespaces. To remove these along with the raster data, export as a clean, standardized SVG:

inkscape input.svg --export-plain-svg --actions="select-by-element:image;delete;export-filename:cleaned.svg;export-do"

Automating Batch Processing

To batch process an entire directory of mixed-content SVG files in a Bash environment, wrap the command in a loop:

for file in *.svg; do
    inkscape "$file" --export-plain-svg --actions="select-by-element:image;delete;export-filename:vector_only_${file};export-do"
done

Verification

To verify that all raster elements were purged from your output SVG, run a fast text search against the file:

grep -i "<image" output.svg

If the command returns no results, all raster elements were stripped successfully, leaving only clean vector shapes and paths.
