Adjust Trajectory Tension in Inkscape Interpolate Points

Adjusting the trajectory tension in Inkscape allows you to control how tightly or loosely a curved path bends between its defining nodes when using the Interpolate Points Live Path Effect (LPE). This guide provides a direct, step-by-step walkthrough for locating the Interpolate Points effect settings, modifying the trajectory tension value, and understanding how different numerical values affect the curvature of your vector paths.

Steps to Adjust Trajectory Tension

  1. Select the Path: Use the Select Tool (S) or Node Tool (N) to click on the path that has the Interpolate Points effect applied.
  2. Open the Path Effects Dialog: Go to the top menu and select Path > Path Effects (or press Ctrl + & on Windows/Linux, Cmd + & on macOS).
  3. Select the Interpolate Points Effect: In the Path Effects panel that appears on the right, locate and click on Interpolate Points in the list of applied effects.
  4. Choose a Compatible Method: Ensure the Interpolation method dropdown is set to a curve type that utilizes tension, such as Cubic spline or Centripetal Catmull-Rom.
  5. Adjust the Trajectory Tension Value:
    • Locate the Trajectory tension field in the effect options.
    • Type a specific numeric value directly into the box, or use the up and down arrow buttons to increase or decrease the tension incrementally.
    • Press Enter to confirm the adjustment.

How Trajectory Tension Affects the Path

  • Default Value (0.0): Produces standard, balanced curvature between the nodes based on the default Catmull-Rom algorithm.
  • Higher Positive Values (Approaching 1.0 or higher): Tightens the curve, pulling the path closer to straight line segments between nodes. At high values, the curve resembles a rigid polygon.
  • Lower or Negative Values: Loosens the path, causing the curve to swing outward away from the nodes, which creates wider, more exaggerated loops.
