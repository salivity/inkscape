Multi-Page SVG Navigation in Inkscape Inkex

This article provides a practical guide on handling multi-page SVG navigation and manipulation within Inkscape's Python extension system, inkex. Since Inkscape 1.2 introduced native multi-page support, the inkex API has provided specialized classes and methods to query, traverse, and manage these pages. Below, you will learn how multi-page architecture works under the hood, how to access and iterate through pages using inkex, and how to determine which graphical elements belong to a specific page.

Understanding the Multi-Page Structure in Inkscape

In Inkscape, multi-page documents do not group SVG drawing elements inside dedicated page container tags. Instead:

  1. Page Definitions: Pages are defined as <inkscape:page> elements inside the document's <sodipodi:namedview> element.
  2. Spatial Layout: Elements on the canvas remain in standard SVG groups or root layers. An element "belongs" to a page based on its geometric coordinates falling within that page's boundary box (x, y, width, height).

Accessing Document Pages with inkex

In modern inkex versions (Inkscape 1.2+), the NamedView object provides direct access to page definitions via the get_pages() method.

import inkex

class MultiPageNavigator(inkex.EffectExtension):
    def effect(self):
        # Access the sodipodi:namedview element
        namedview = self.svg.namedview
        
        # Retrieve all inkscape:page elements
        pages = namedview.get_pages()
        
        if not pages:
            inkex.utils.debug("This document contains only a single default canvas (no extra pages).")
            return

        for index, page in enumerate(pages):
            # Read page attributes
            label = page.get("inkscape:label", f"Page {index + 1}")
            x = float(page.get("x", 0))
            y = float(page.get("y", 0))
            width = float(page.get("width", 0))
            height = float(page.get("height", 0))
            
            inkex.utils.debug(f"{label}: bounds=({x}, {y}, {width}, {height})")

if __name__ == "__main__":
    MultiPageNavigator().run()

Associating Canvas Elements with Specific Pages

Because graphical elements (<path>, <rect>, <g>, etc.) are not children of <inkscape:page>, you must perform bounding box collision tests to identify which objects reside on which page.

import inkex

class PageElementMapper(inkex.EffectExtension):
    def effect(self):
        namedview = self.svg.namedview
        pages = namedview.get_pages()

        for index, page in enumerate(pages):
            # Create a bounding box for the page
            page_box = inkex.BoundingBox(
                (float(page.get("x")), float(page.get("x")) + float(page.get("width"))),
                (float(page.get("y")), float(page.get("y")) + float(page.get("height")))
            )

            # Find elements contained within or intersecting the page boundary
            page_elements = []
            for elem in self.svg.descendants():
                if isinstance(elem, inkex.ShapeElement):
                    bbox = elem.bounding_box()
                    if bbox and page_box.contains(bbox):
                        page_elements.append(elem)

            inkex.utils.debug(f"Page {index + 1} contains {len(page_elements)} shape elements.")

if __name__ == "__main__":
    PageElementMapper().run()

Programmatically Creating and Navigating to New Pages

To create or programmatically define new pages within an extension, instantiate an inkex.Page element and append it to self.svg.namedview:

import inkex
from inkex import Page

class AddPageExtension(inkex.EffectExtension):
    def effect(self):
        namedview = self.svg.namedview
        pages = namedview.get_pages()

        # Determine the position of the new page (e.g., placed to the right of existing pages)
        last_page = pages[-1] if pages else None
        offset_x = float(last_page.get("x", 0)) + float(last_page.get("width", 100)) + 20 if last_page else 0

        # Create a new page
        new_page = Page()
        new_page.set("x", str(offset_x))
        new_page.set("y", "0")
        new_page.set("width", "210mm")
        new_page.set("height", "297mm")
        new_page.set("inkscape:label", f"Page {len(pages) + 1}")

        # Append to namedview
        namedview.append(new_page)

Best Practices

  • Check for Empty Page Lists: Documents with only the default view may return an empty list when calling namedview.get_pages(). Always handle the fallback case where the document boundaries are defined by self.svg.viewbox rather than explicit page elements.
  • Unit Conversions: Page coordinates are stored in user units (SVG pixels). Ensure any comparison with custom geometry uses self.svg.to_dimension() or standard inkex.units parsing when converting between millimeters, inches, and pixels.
