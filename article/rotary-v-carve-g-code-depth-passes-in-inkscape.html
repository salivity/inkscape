Rotary V-Carve G-Code Depth Passes in Inkscape

Generating multi-pass G-code for rotary V-carve engraving in Inkscape involves translating 2D vector paths into conical-tool toolpaths using the built-in Gcodetools extension. This process requires unwrapping your cylindrical workpiece dimensions onto a flat canvas, defining a conical tool profile with specific depth steps, calculating multi-pass tool offsets based on the V-bit angle, and converting the planar coordinates into rotational commands for your machine.

Step 1: Calculate the Rotary Canvas Dimensions

Before designing, set up your Inkscape document properties to match your cylinder's unrolled surface area.

  1. Measure your cylinder's outer diameter (\(D\)) and length (\(L\)).
  2. Calculate the circumference using the formula: \(C = \pi \times D\).
  3. Open File > Document Properties.
  4. Set the canvas width to your cylinder's length (\(L\)) and the canvas height to the circumference (\(C\)) (or vice versa, depending on whether your rotary axis replaces the X or Y axis).

Ensure your artwork stays within these boundaries. The top and bottom (or left and right) edges represent the same seam on the physical cylinder.

Step 2: Prepare the Vector Artwork

V-carve engraving requires clean, standardized vector paths.

  1. Select your shapes or text.
  2. Navigate to Path > Object to Path to convert all elements into vectors.
  3. If using text or overlapping shapes, go to Path > Union to remove overlapping internal lines.
  4. Clean up any stray nodes with Path > Simplify if necessary to prevent toolpath stuttering.

Step 3: Insert Orientation Points

Orientation points establish the coordinate origin and depth scaling for the G-code output.

  1. Go to Extensions > Gcodetools > Orientation points.
  2. Set the Orientation type to in-out-reference point or standard 2-point mode.
  3. Set Surface (Z) to 0.0 (representing the cylinder surface).
  4. Set Depth (Z) to your total desired maximum cut depth (e.g., -2.0 mm).
  5. Click Apply and close the dialog. A set of green coordinate markers will appear at the bottom-left of your canvas.

Step 4: Configure the Conical (V-Carve) Tool Profile

To generate depth passes, you must define a tool profile and its maximum cutting step.

  1. Go to Extensions > Gcodetools > Tools library.
  2. Select cone as the tool type and click Apply.
  3. A green rectangular text box will appear on the canvas containing editable text fields.
  4. Select the Text Tool (F8) and modify the text values directly:
    • diameter: The maximum diameter of your V-bit.
    • cone angle: The included angle of your V-bit (e.g., 60 or 90).
    • depth step: The maximum depth per pass (e.g., 0.5 mm). The total depth set in your orientation points divided by this value determines the number of passes.
    • feed: XY linear cutting speed.
    • penetration feed: Z plunge speed.

Step 5: Generate the Engraving Toolpaths with Depth Passes

The Engraving function calculates the multi-pass tool offsets according to the conical shape of the bit.

  1. Select the artwork you wish to engrave.
  2. Go to Extensions > Gcodetools > Engraving.
  3. Under the Engraving tab:
    • Enable multi-pass cutting by ensuring your depth step in the tool settings is smaller than your target depth.
    • Set Maximum distance for clean paths to define fine-detail tolerance.
  4. Open the Preferences tab:
    • Specify the output file name and directory.
    • Set Z safe height (clearance above the cylinder for rapids).
  5. Click Apply. Inkscape will calculate the offsets and generate multiple depth-pass paths, displaying the cutting paths on the screen and exporting the raw .ngc or .gcode file.

Step 6: Adapt the G-code for Rotary Movement

Because Inkscape exports standard Cartesian coordinates (X, Y, Z), you must map one linear axis to your rotary axis (commonly the A-axis).

  • Hardware Mapping (Direct Substitution): If your rotary axis simply plugs into the machine's Y-axis motor driver, calibrate your controller's steps-per-millimeter so that one full rotation equals the circumference (\(C\)). In this setup, the exported G-code runs without text modifications.
  • Coordinate Substitution (G-code Editing): If your controller expects degrees for an A-axis:
    1. Open the exported G-code in a text editor.
    2. Use a rotary conversion script, post-processor, or find-and-replace routine to convert linear Y coordinates to degrees using the ratio: \(A = (Y / C) \times 360\).
    3. Replace all Y movement commands with A commands.
