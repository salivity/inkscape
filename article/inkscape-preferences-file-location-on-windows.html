Inkscape Preferences File Location on Windows

This guide explains the exact default location of the Inkscape user preferences file (preferences.xml) on Windows systems. You will learn the default file paths for standard and Microsoft Store installations, how to access the folder quickly using Windows shortcuts, and how to locate or reset your settings directly from within the Inkscape interface.

Default File Path

On Windows, Inkscape saves all custom user settings, interface customizations, and tool behaviors in a file named preferences.xml.

For standard installations (MSI or EXE installer), the default location is:

C:\Users\<Username>\AppData\Roaming\inkscape\preferences.xml

Quick Access via Windows Run

To open this directory immediately without manually navigating hidden system folders:

  1. Press Windows Key + R to open the Run dialog box.
  2. Type %APPDATA%\inkscape and press Enter.
  3. Locate the preferences.xml file inside the folder.

Microsoft Store (Appx/MSIX) Path

If you installed Inkscape from the Microsoft Store, Windows sandboxes the application data in a different folder:

C:\Users\<Username>\AppData\Local\Packages\Inkscape.Inkscape_*\LocalCache\Roaming\inkscape\preferences.xml

Locating the File Inside Inkscape

You can verify the exact path your specific installation uses directly within the software:

  1. Open Inkscape.
  2. Navigate to Edit > Preferences (or press Ctrl + Shift + P).
  3. In the left sidebar, click on System.
  4. Look for the User preferences entry under the "System Info" section.
  5. Click the Open button next to the path to launch the folder directly in Windows File Explorer.

Resetting Inkscape Preferences

If you need to reset Inkscape back to its default out-of-the-box state, close Inkscape and either delete the preferences.xml file or rename it to preferences.xml.bak. The next time Inkscape launches, it will automatically generate a new preferences.xml file with default settings. Alternatively, you can click the Reset Preferences button in Edit > Preferences > System and restart the application.
