How to Enable and Disable Font Ligatures in Inkscape

Font ligatures combine two or more adjacent characters into a single, unified glyph to improve typography aesthetics and readability, though certain design projects require them to be disabled. This guide explains how to toggle OpenType font ligatures on and off in Inkscape using built-in typography tools, as well as how to convert active ligatures into permanent vector paths.

Enabling and Disabling Ligatures in Inkscape

To control font ligatures, your selected font must support OpenType ligature features (such as standard ligatures, discretionary ligatures, or contextual alternates).

  1. Select the Text: Use the Text Tool (T) to highlight the specific characters you want to modify, or use the Select and Transform Objects Tool (S) to select the entire text box.
  2. Open the Text and Font Dialog: Go to the top menu and select Text > Text and Font..., or use the keyboard shortcut Shift + Ctrl + T.
  3. Navigate to the Features Tab: In the Text and Font dialog window, click on the Features tab located alongside the "Font" and "Text" tabs.
  4. Adjust Ligature Settings:
    • Scroll to the Ligatures section within the Features tab.
    • To enable ligatures, check the box for Common ligatures (or Discretionary ligatures / Contextual alternates if supported by the font).
    • To disable ligatures, uncheck these boxes.
  5. Apply the Changes: Click the Apply button at the bottom right of the panel to update your text on the canvas.

Converting Ligatures to Vector Paths

If you want to permanently turn active font ligatures into editable vector shapes (bypassing font rendering entirely):

  1. Select your text object with the Select Tool (S).
  2. Go to the top menu and click Path > Object to Path (or press Shift + Ctrl + C).
  3. Ungroup the resulting path by selecting Object > Ungroup (Shift + Ctrl + G) if you need to manipulate individual letterforms or the ligature glyph directly with the Node Tool (N).
