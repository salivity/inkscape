Batch Break Apart Paths Using Inkscape CLI

This article explains how to automate the "Path > Break Apart" operation headlessly across hundreds of SVG files using the Inkscape command-line interface (CLI). By leveraging Inkscape’s built-in actions and a simple shell or batch loop, you can process large volumes of vector files in bulk without launching the graphical user interface.

The Core CLI Command

In Inkscape 1.0 and later, commands are executed sequentially using the --actions parameter. The action to select objects is select-all:all, and the action to break apart combined paths into individual sub-paths is path-break-apart.

A single headless execution looks like this:

inkscape --batch-process --actions="select-all:all;path-break-apart;export-plain-svg;export-do" input.svg --export-filename="output.svg"
  • --batch-process: Prevents the GUI from opening and exits automatically when operations complete.
  • select-all:all: Selects all path elements across all layers.
  • path-break-apart: Executes the break apart operation on the selection.
  • export-plain-svg;export-do: Prepares and writes the resulting vector file.
  • --export-filename: Specifies the target output file.

Processing Multiple Files on Linux and macOS

To process hundreds of files in a directory, use a Bash shell loop.

Overwriting Existing Files

for file in *.svg; do
  inkscape --batch-process --actions="select-all:all;path-break-apart;export-overwrite;export-do" "$file"
done

Saving to a Separate Output Folder

mkdir -p output
for file in *.svg; do
  inkscape --batch-process --actions="select-all:all;path-break-apart;export-plain-svg;export-do" "$file" --export-filename="output/$file"
done

Speeding Up with GNU Parallel

When processing hundreds of files, running jobs in parallel across CPU cores significantly reduces processing time:

find . -name "*.svg" | parallel -j $(nproc) inkscape --batch-process --actions="select-all:all;path-break-apart;export-overwrite;export-do" {}

Processing Multiple Files on Windows (PowerShell)

In Windows PowerShell, navigate to the folder containing your SVG files and run:

Overwriting Existing Files

Get-ChildItem -Filter *.svg | ForEach-Object {
    inkscape --batch-process --actions="select-all:all;path-break-apart;export-overwrite;export-do" $_.FullName
}

Saving to a Separate Output Folder

New-Item -ItemType Directory -Force -Path .\output
Get-ChildItem -Filter *.svg | ForEach-Object {
    $outPath = Join-Path ".\output" $_.Name
    inkscape --batch-process --actions="select-all:all;path-break-apart;export-plain-svg;export-do" $_.FullName --export-filename=$outPath
}

Ensure inkscape is added to your system's PATH environment variable, or substitute inkscape with the absolute executable path (e.g., "C:\Program Files\Inkscape\bin\inkscape.exe").
