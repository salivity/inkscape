How to Fix 90 DPI SVG Shrinkage in Modern Inkscape

Older vector graphics created in Inkscape versions prior to 0.92 used an internal resolution standard of 90 DPI, whereas modern versions adhere to the 96 DPI standard specified by the CSS specifications. This discrepancy causes legacy vector graphics to shrink by approximately 6.25% when opened in current software. This guide details how to resolve this mismatch and restore your legacy SVG artwork to its correct physical dimensions using modern Inkscape tools and manual adjustments.

Why Legacy Files Shrink

When modern Inkscape reads a file created at 90 DPI, it interprets the raw pixel coordinates using the modern 96 DPI baseline. Because 90 divided by 96 equals 0.9375, the graphic renders at 93.75% of its intended size. To restore the file to its original real-world measurements, the artwork must be scaled up by a factor of 1.06667 (96 divided by 90), or 106.6667%.

Method 1: The Automated Legacy Import Dialog

Modern versions of Inkscape include a detection system for legacy files:

  1. Launch Inkscape and go to File > Open, then select your legacy SVG.
  2. If Inkscape detects the legacy 90 DPI metadata, a prompt titled Legacy Inkscape file or DPI Update will appear.
  3. Select the option labeled Scale the elements to keep their screen size or Change the viewBox to preserve the physical size, depending on your workflow:
    • Scale elements: Modifies the coordinate values of paths and shapes directly to scale the artwork up by 106.6667%.
    • Set viewBox: Adds a responsive coordinate system to preserve physical dimensions (inches, millimeters) without altering underlying coordinates.
  4. Click OK to apply the conversion.

Method 2: Manual Scaling via the Transform Panel

If Inkscape fails to auto-detect the legacy DPI or the file was saved by third-party software at 90 DPI, apply the transformation manually:

  1. Open the SVG in Inkscape.
  2. Press Ctrl + A (or Cmd + A on macOS) to select all objects across visible and unlocked layers.
  3. Open the Transform dialog by navigating to Object > Transform (Shift + Ctrl + M).
  4. Select the Scale tab.
  5. Set the unit dropdown to % (Percent).
  6. Enter 106.6667 in both the Width and Height fields.
  7. Ensure Apply to each object separately is unchecked.
  8. Click Apply.

Method 3: Adjusting Document Properties and ViewBox

For artwork defined with real-world units (such as millimeters or inches) that appears on a misplaced canvas:

  1. Navigate to File > Document Properties (Shift + Ctrl + D).
  2. Under the Display tab, confirm that the Display units match your desired real-world unit (e.g., mm or in).
  3. Examine the ViewBox settings:
    • If the viewBox width and height do not match your document's width and height in user units, reset the viewBox coordinates so the scale ratio reads 1.0.
  4. Click Resize page to content if the boundary of the canvas no longer matches your resized vector shapes.

Method 4: Modifying the SVG Code Directly

For batch processing or precise control, you can update the SVG source in a text editor:

  1. Open the .svg file in a code editor.
  2. Locate the root <svg> tag.
  3. If no viewBox attribute exists, calculate the viewBox values: multiply the current pixel width and height attributes by 0.9375 and add them as viewBox="0 0 [scaled_width] [scaled_height]".
  4. Alternatively, remove explicit pixel units from the width and height attributes and define real-world units directly alongside an explicit viewBox.
  5. Save the file and reopen it in modern Inkscape to verify the proportions.
