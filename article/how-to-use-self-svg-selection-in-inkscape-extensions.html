How to Use self.svg.selection in Inkscape Extensions

This guide demonstrates how to access, inspect, and manipulate selected SVG elements within the active document using the self.svg.selection API in modern Inkscape extensions (inkex). You will learn how to verify if elements are selected, iterate through the selection list, access element attributes, and filter selected elements by their SVG tag type.

Understanding self.svg.selection

When writing an extension inheriting from inkex.EffectExtension, the self.svg.selection object acts as an ordered mapping representing the elements currently selected by the user. Keys correspond to the XML id attributes of the elements, and values are the inkex.elements objects themselves.

Checking for Active Selections

To verify whether the user has selected any items before running processing logic, evaluate self.svg.selection as a boolean:

if not self.svg.selection:
    inkex.errormsg("Please select at least one element.")
    return

Accessing Selected Elements

1. Iterating Over Elements

You can iterate directly over the elements, their IDs, or key-value pairs:

# Iterate directly over element objects
for element in self.svg.selection:
    inkex.utils.debug(f"Element tag: {element.TAG}, ID: {element.get_id()}")

# Iterate over IDs and elements simultaneously
for elem_id, elem in self.svg.selection.items():
    inkex.utils.debug(f"ID: {elem_id} corresponds to {elem}")

2. Getting the First Selected Element

To quickly access a single element when only one selection is expected:

first_element = self.svg.selection.first()
if first_element is not None:
    # Perform operations on the element
    pass

3. Filtering by Element Type

The filter() method extracts only elements of a specific SVG type, such as paths, groups, or rectangles:

import inkex

# Select only path elements
paths = self.svg.selection.filter(inkex.PathElement)

# Select only group elements
groups = self.svg.selection.filter(inkex.Group)

for path in paths:
    # Safely modify path attributes
    path.style['stroke'] = '#ff0000'

Complete Example

Below is a complete implementation inside an inkex.EffectExtension:

import inkex

class SelectionExample(inkex.EffectExtension):
    def effect(self):
        if not self.svg.selection:
            inkex.errormsg("No elements were selected.")
            return

        for elem_id, elem in self.svg.selection.items():
            # Read an attribute
            current_fill = elem.style.get('fill', 'none')
            
            # Modify an attribute
            elem.style['stroke'] = '#0000ff'
            elem.style['stroke-width'] = '2px'

if __name__ == '__main__':
    SelectionExample().run()
