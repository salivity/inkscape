Lock Gradient Position Relative to Page in Inkscape

This guide explains how to prevent gradients from shifting when moving objects across the canvas in Inkscape. By default, Inkscape moves gradient fills and strokes together with the shape, but disabling a specific transform toggle on the main toolbar fixes the gradient's spatial coordinates relative to the page, allowing objects to move independently across a stationary gradient field.

The Setting: "Move gradients along with the objects"

The setting responsible for this behavior is the Move gradients (in fill or stroke) along with the objects toggle.

When this setting is enabled (the default state), gradient definition points move proportionally with the object. When this setting is disabled, gradient coordinates remain fixed to the page's absolute space, meaning the moving object simply reveals different sections of the static gradient as it shifts.

How to Disable the Setting

  1. Switch to the Select and transform objects tool by pressing S or F1.
  2. Look at the Tool Controls Bar running horizontally across the top of the canvas.
  3. Locate the four transform mode toggle buttons grouped on the far right side of the bar.
  4. Click the button displaying a gradient icon with a small arrow, labeled Move gradients (in fill or stroke) along with the objects, to deselect/turn it off.

Once toggled off, any subsequent movement of your shapes or paths will leave the gradient handles locked at their current canvas coordinates. You can toggle this setting back on at any time if you need the gradient to travel with the shape again.
