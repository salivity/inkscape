Create an Inkscape Input Extension for Vector Data

Creating an Inkscape input extension allows you to seamlessly open and import proprietary vector formats directly from the application's file dialogs. This guide explains how to construct an Inkscape extension using an XML-based .inx metadata file and a Python processing script leveraging the inkex library. You will learn how to read your proprietary file structure, convert custom geometric definitions into standard SVG nodes, and register the extension inside Inkscape.

1. Extension Architecture Overview

Inkscape extensions consist of two core components placed within the user's extensions directory:

  • The Definition File (.inx): An XML file that informs Inkscape about the file format name, the file extension, command-line arguments, and the executable script to run.
  • The Execution Script (.py): A script (typically Python) that reads the input stream, parses the proprietary vector commands, and converts them into an SVG DOM.

2. Define the Extension Metadata (.inx)

Create a file named custom_vector_input.inx. This file registers your custom file type in Inkscape's "Open" and "Import" dialog boxes.

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>Custom Vector Format Importer</name>
    <id>org.inkscape.input.custom_vector</id>
    
    <input>
        <extension>.cif</extension>
        <mimetype>application/x-custom-vector</mimetype>
        <filetypename>Custom Vector Format (*.cif)</filetypename>
        <filetypetooltip>Import custom proprietary vector files</filetypetooltip>
    </input>
    
    <script>
        <command location="inx" interpreter="python">custom_vector_input.py</command>
    </script>
</inkscape-extension>

3. Build the Parsing Script (custom_vector_input.py)

Inkscape provides the inkex Python module to simplify document manipulation. Inherit from inkex.InputExtension and override the load(stream) method. Your parser must read the raw binary or text stream, extract vector entities (points, lines, Bézier paths, fills, and strokes), and generate standard SVG elements.

import inkex
from inkex import SvgDocumentElement, Layer, PathElement
from inkex.paths import Path

class CustomVectorInput(inkex.InputExtension):
    def load(self, stream):
        # Initialize an empty SVG document container
        document = SvgDocumentElement()
        document.set('width', '800')
        document.set('height', '600')
        document.set('viewBox', '0 0 800 600')

        # Create a primary layer
        layer = Layer.new(name="Imported Layer")
        document.append(layer)

        # Parse the custom incoming data
        # (This example assumes a newline-delimited text format: "COMMAND X Y ...")
        for line in stream.read().decode('utf-8').splitlines():
            line = line.strip()
            if not line or line.startswith('#'):
                continue

            tokens = line.split()
            command = tokens[0].upper()

            if command == "LINE":
                # Expected: LINE x1 y1 x2 y2
                x1, y1, x2, y2 = map(float, tokens[1:5])
                path_data = f"M {x1},{y1} L {x2},{y2}"
                
                element = PathElement()
                element.set('d', path_data)
                element.style = {
                    'stroke': '#000000',
                    'stroke-width': '1px',
                    'fill': 'none'
                }
                layer.append(element)

            elif command == "POLY":
                # Expected: POLY x1 y1 x2 y2 x3 y3 ...
                points = [f"{tokens[i]},{tokens[i+1]}" for i in range(1, len(tokens), 2)]
                path_data = "M " + " L ".join(points) + " Z"
                
                element = PathElement()
                element.set('d', path_data)
                element.style = {
                    'stroke': '#333333',
                    'stroke-width': '1.5px',
                    'fill': '#cccccc'
                }
                layer.append(element)

        # Return the root XML tree
        return document

if __name__ == '__main__':
    CustomVectorInput().run()

4. Handling Complex Vector Entities

When translating custom vector data into SVG:

  • Bézier Curves: Convert your native cubic or quadratic curve coordinates into standard SVG path syntax using C x1 y1, x2 y2, x y (cubic) or Q x1 y1, x y (quadratic).
  • Coordinate Spaces: Proprietary CAD formats often place the origin (0, 0) at the bottom-left corner with the Y-axis pointing upward. Standard SVG places the origin at the top-left corner with the Y-axis pointing downward. Invert the Y-coordinates using y_svg = total_height - y_custom or apply a global SVG transform transform="scale(1, -1)".
  • Color Spaces: Convert internal colors (e.g., CMYK, native RGB integers, or index palettes) into standard 6-character hex strings (#RRGGBB).

5. Installation and Testing

Place both the .inx and .py files inside the user-level Inkscape extensions folder:

  • Linux: ~/.config/inkscape/extensions/
  • Windows: %APPDATA%\inkscape\extensions\
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/

Restart Inkscape. Go to File > Open, select your custom file format from the drop-down filter, and open your proprietary vector file to verify the rendering.
