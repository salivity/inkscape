Delete Objects with Eraser Tool in Inkscape

Inkscape features a versatile Eraser tool that includes a dedicated Delete mode designed to instantly remove entire vector objects rather than merely carving paths through them. This guide provides a straightforward walkthrough on how to activate the Eraser tool, switch to Delete mode, and quickly eliminate unwanted elements from your canvas with a simple click or drag.

Step 1: Select the Eraser Tool

Click on the Eraser tool icon in the left-hand vertical toolbox, or press the keyboard shortcut Shift + E to activate it immediately.

Step 2: Switch to Delete Mode

Once the Eraser tool is active, look at the Tool Controls Bar at the top of the Inkscape workspace. You will see three operation modes:

  1. Delete objects (red 'X' or object deletion icon)
  2. Cut out paths/shapes
  3. Clip from objects

Click on the first icon to enable Delete objects mode.

Step 3: Remove Objects from the Canvas

With Delete mode active:

  • Single Object: Click directly on any vector shape, path, or text element to delete it entirely.
  • Multiple Objects: Click and drag across the canvas. A red guideline will appear, and any object touched or crossed by this line will be deleted the moment you release the mouse button.

Key Considerations

  • Layer Locking: The Eraser tool will not delete objects that are on locked layers or individually locked.
  • Groups: If you cross any part of a grouped object, the entire group will be deleted. If you only want to delete a single component of a group, ungroup the elements first by pressing Ctrl + Shift + G.
  • Undo Action: If you accidentally delete the wrong item, press Ctrl + Z to immediately restore it.
