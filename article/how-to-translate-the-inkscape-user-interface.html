How to Translate the Inkscape User Interface

Translating the Inkscape user interface allows users worldwide to access the open-source vector graphics editor in their native languages. Inkscape uses the standard GNU gettext localization framework, relying on Portable Object (.po) files to map English interface strings to localized languages. This guide provides a straightforward overview of how to obtain translation files, edit strings using dedicated localization tools, test your changes locally within Inkscape, and submit your contributions to the project.

Required Tools and Accounts

Before you begin translating, you need the appropriate software and platform access:

  • PO File Editor: Download an editor such as Poedit, Gtranslator, or Lokalize. Poedit is widely recommended for its simplicity and built-in validation checks.
  • Inkscape GitLab Account: Create an account on the Inkscape GitLab instance (gitlab.com/inkscape/inkscape) to download updated templates and submit your work via Merge Requests.
  • Inkscape Installation: Install a recent version of Inkscape to preview your translated interface in real time.

Obtaining the Translation Template

Inkscape's interface text is generated from the source code into a Portable Object Template (.pot) file, which is then used to create or update language-specific .po files.

  1. Navigate to the Inkscape source repository on GitLab.
  2. Go to the po/ directory in the repository tree.
  3. Locate your language file named with your target locale code (for example, fr.po for French, es.po for Spanish, or de.po for German).
  4. If your language does not exist, download inkscape.pot to create a new .po file named with your target language code (e.g., pt_BR.po for Brazilian Portuguese).

Editing Translation Strings

  1. Open your language's .po file in Poedit or your chosen translation editor.
  2. Review the interface strings:
    • Source Text (msgid): The original English string from the software.
    • Translation (msgstr): Your localized translation of the text.
  3. Preserve Special Formatting and Placeholders:
    • Keep formatting variables (such as %s, %d, or {0}) exactly as they appear in the original string.
    • Preserve shortcut indicators (such as underscores _ used for mnemonic keyboard navigation, e.g., _File becoming _Fichier).
  4. Save your .po file. When you save in Poedit, it automatically generates a compiled .mo (Machine Object) file used by the application runtime.

Testing the Translation Locally

To verify how the translated text looks within the interface:

  1. Locate your local Inkscape installation directory.
  2. Navigate to the locale folder:
    • Linux: /usr/share/locale/<language_code>/LC_MESSAGES/
    • Windows: C:\Program Files\Inkscape\share\locale\<language_code>\LC_MESSAGES\
    • macOS: Inside the application bundle at Inkscape.app/Contents/Resources/share/locale/<language_code>/LC_MESSAGES/
  3. Replace the existing inkscape.mo file with the .mo file you generated from your updated translation.
  4. Launch Inkscape configured in your target language to inspect UI elements, menus, tooltips, and dialogs for text truncation or context errors.

Submitting Your Translation

Once your translations are complete and verified:

  1. Fork the official Inkscape repository on GitLab.
  2. Commit your updated .po file to a new branch in your fork under the po/ directory.
  3. Open a Merge Request (MR) against the master branch of the main Inkscape repository.
  4. Title the Merge Request clearly (e.g., Update [Language Name] translation) and submit it for review by the localization team coordinators.
