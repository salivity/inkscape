Using feBlend Color-Dodge and Color-Burn in Inkscape

This guide explains how to harness SVG blend modes—specifically Color-Dodge and Color-Burn—inside Inkscape’s Filter Editor. You will learn how to initialize custom filter graphs, add and route the feBlend primitive between source graphics or backgrounds, configure advanced blending equations, and troubleshoot SVG blending modes using the built-in XML tools.

1. Access the Filter Editor

Inkscape allows deep manipulation of SVG filter graphs through its dedicated editor interface:

  1. Open your document and select Filters > Filter Editor from the top menu.
  2. In the Filter Editor panel, click the New button at the bottom of the left-hand column to generate a blank filter.
  3. Double-click the newly generated filter name (e.g., filter1) to rename it to something descriptive, such as ColorDodgeEffect.

2. Add the feBlend Primitive

The feBlend node handles compositing two visual inputs using standard blend equations.

  1. Locate the Add Primitive drop-down menu at the bottom of the Filter Editor.
  2. Select Blend from the list.
  3. Click Add Primitive. A node labeled Blend will appear in the primitive list and in the node graph pane.

3. Route the Filter Graph Connections

feBlend requires two distinct image inputs: the base image and the blend layer. In Inkscape's node graph view, these are represented by connection lines running from input sources to the Blend node.

  1. Identify the input streams on the right side of the graph:
    • Source Graphic: The vector object to which the filter is applied.
    • Background Image: The rendered artwork lying beneath the target object.
    • Source Alpha / Background Alpha: Transparency channels.
  2. Click and drag the first connector triangle of the Blend node to your base layer source (such as Background Image).
  3. Click and drag the second connector triangle of the Blend node to the blend graphic (such as Source Graphic).

Note: For Background Image to render correctly in SVG, ensure the parent layer or root SVG supports background accumulation, or composite two distinct graphic streams inside the filter graph itself using primitives like Image or Flood.

4. Configure the Blend Mode

  1. Select the Blend primitive in the active filter list.
  2. Navigate to the Effect parameters section located beneath the graph.
  3. Open the Mode dropdown menu.
  4. Select Color-Dodge or Color-Burn:
    • Color-Dodge: Divides the background color by the inverted source graphic color, producing bright, vibrant highlights and glowing effects.
    • Color-Burn: Inverts the background color, divides it by the source graphic, and inverts the result, creating high-contrast, deeply saturated shadows.

5. Apply and Inspect via the XML Editor

  1. Select the vector path or shape on your canvas that you want to use as the blending element.
  2. In the Filter Editor, check the box next to your custom filter to apply it directly to the selection.
  3. If your version of Inkscape does not display advanced modes in the dropdown UI, open the XML Editor (Edit > XML Editor or Ctrl+Shift+X).
  4. Locate <svg:filter> in the XML tree, expand it, and select the child <svg:feBlend> element.
  5. In the attribute panel on the right, set the mode attribute directly to color-dodge or color-burn, then click Set.
