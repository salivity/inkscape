Convert Text to Single-Line Paths in Inkscape

This guide explains how to convert standard outline typography into single-line open vector paths in Inkscape for clean, efficient cutting on drag-knife plotters and CNC vinyl cutters. Standard digital fonts inherently consist of closed vector loops, causing cutting blades to trace both the inner and outer perimeters of every letter. By using built-in extensions, centerline tracing, and node editing, you can reduce text to pure single-stroke centerlines that eliminate double cuts and prevent material tearing.

Understanding the Drag-Knife Problem

Standard TrueType (TTF) and OpenType (OTF) fonts are filled vectors bounded by closed paths. When sent to a drag-knife cutter (such as a Cricut, Silhouette, or Roland plotter), the machine follows every path edge, resulting in two cut lines for each stroke of a letter. A drag-knife cutter requires an open, single-stroke path (often called an engraving, stick, or Hershey font) so the blade makes only one pass down the center of each letterform.

Method 1: Generate Native Single-Line Text (Hershey Text)

The most direct way to create single-line vector text in Inkscape is using the native Hershey Text utility.

  1. Open Inkscape and navigate to Extensions > Text > Hershey Text.
  2. In the dialog window, enter your required text into the Text field.
  3. Select an engraving font from the Font face dropdown (e.g., EMS Technical, EMS Simplex, or EMS One Stroke).
  4. Check the Live preview box to ensure the letterforms suit your project.
  5. Click Apply, then Close.

The generated letters are true open vector paths rather than standard editable text.

Method 2: Centerline Tracing for Existing Custom Typography

If you must convert an existing outline font, logo, or complex vector lettering into single-line paths, use Inkscape's centerline autotracing engine.

  1. Select your vector text and convert it to a path via Path > Object to Path.
  2. Ungroup the result by pressing Ctrl + Shift + G until all individual character paths are separated, then merge them into one object using Path > Combine.
  3. Select the combined path and open Path > Trace Bitmap (or press Shift + Alt + B).
  4. In the Trace Bitmap panel, switch to the Single scan tab.
  5. Choose Centerline tracing (autotrace) from the dropdown options.
  6. Adjust the Threshold and filter settings to achieve a clean representation in the preview window.
  7. Click Apply. Inkscape will overlay the newly generated open paths directly on top of the original filled vector.
  8. Delete or hide the original closed vector layer.

Method 3: Manual Skeletonization for Precision Work

Automated centerline tracing can create small loops or artifacts at corners. For high-precision jobs, manual editing produces the cleanest results:

  1. Select your text, convert it to paths (Path > Object to Path), and ungroup it (Ctrl + Shift + G).
  2. Set the Fill to None and apply a thin Stroke (e.g., 0.5 mm) in the Fill and Stroke panel (Ctrl + Shift + F).
  3. Select the Edit paths by nodes tool (F2).
  4. Identify the twin edges of each character stroke. Select the segments representing one side of the outline and press Delete, leaving only one path behind.
  5. Select end nodes where paths loop, click Break path at selected nodes in the top tool controls bar, and delete the joining segments to turn the shape into an open path.
  6. Select the remaining path segments and move the nodes to the center axis of the letterform.

Preparing and Exporting Paths for Drag-Knife Cutters

Once your paths are reduced to single lines, optimize them to avoid drag-knife blade catching:

  • Remove All Fills: Ensure every character has Fill: None and only a defined Stroke.
  • Join Disconnected Nodes: For continuous strokes, select overlapping nodes and click Join selected nodes.
  • Simplify Complex Paths: If the paths contain excessive nodes, select the paths and click Path > Simplify (Ctrl + L) to prevent the blade from stuttering.
  • Export: Save the file as a clean SVG via File > Save As > Plain SVG, or export to DXF (Desktop Cutting Plotter / AutoCAD DXF R14) depending on your cutter's software requirements.
