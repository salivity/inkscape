Inkscape Low-Poly Portraits With Delaunay Triangulation

This guide provides a step-by-step method for creating low-poly vector portrait illustrations in Inkscape using the Delaunay Triangulation extension. You will learn how to map facial features with coordinate points, automatically generate a geometric mesh, sample colors from a reference image, and refine the final artwork into a clean, modern vector illustration.

1. Set Up Your Canvas and Reference Image

  1. Open Inkscape and set up your document properties (Ctrl + Shift + D).
  2. Import your portrait reference image (File > Import). Choose a high-contrast, well-lit photo for the best results.
  3. Center the image on your canvas, rename this layer to "Reference," and lock it in the Layers and Objects panel (Ctrl + Shift + L).
  4. Create a new layer on top and name it "Points."

2. Plot Nodes Along Key Facial Features

  1. Select the Draw Freehand Lines or Draw Bezier Curves tool (B).
  2. Begin placing individual dots (single-node paths) across the subject’s face on the "Points" layer.
  3. Place nodes densely around detailed areas such as the eyes, nose, lips, and sharp shadow lines.
  4. Use a sparser distribution of nodes across flat areas with minimal tonal variation, such as the forehead, cheeks, and background.
  5. Ensure you place boundary nodes along the outer edges of the face, hair, and shoulders to maintain a defined silhouette.

3. Generate the Delaunay Triangulation

  1. Select all the plotted points using the Select and Transform Objects tool (S or Ctrl + A while on the "Points" layer).
  2. Combine all points into a single path by navigating to Path > Combine (Ctrl + K).
  3. Go to the menu and select Extensions > Generate from Path > Voronoi Diagram...
  4. In the dialog box, set the Diagram type to Delaunay Triangulation.
  5. Check Live preview to inspect the mesh. If the triangles align well with the facial geometry, click Apply and close the window.

4. Prepare the Mesh for Coloring

  1. Unlock the newly generated triangulation object and ungroup it (Ctrl + Shift + G) to separate individual triangles.
  2. Select all triangles and open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Set the Stroke paint to No paint (or keep a very thin stroke of 0.1 px in matching colors to prevent sub-pixel gaps).
  4. Create a new layer named "Mesh" and move the triangles there, positioned directly above the "Reference" layer.

5. Sample Colors and Fill Polygons

  1. Select a triangle in your mesh.
  2. Activate the Dropper tool (D).
  3. Click inside the area of the reference image directly beneath the selected triangle to sample the average local color.
  4. Press Tab or Alt + Click to cycle to the next adjacent triangle, and use the Dropper tool to sample its color.
  5. Repeat this process systematically across the entire portrait until all triangles are filled with their corresponding tones.

6. Refine and Polish

  1. Zoom in (+) and check for misaligned vertices or empty seams between triangles. Use the Edit paths by nodes tool (N) to snap adjacent nodes together.
  2. If any triangle looks too flat or covers a sharp edge, split the triangle manually and sample the contrasting colors to add depth.
  3. Hide or delete the "Reference" layer.
  4. Group the final artwork (Ctrl + G) and export your portrait as an SVG or high-resolution PNG (Ctrl + Shift + E).
