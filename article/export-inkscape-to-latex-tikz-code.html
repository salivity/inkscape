Export Inkscape to LaTeX TikZ Code

Exporting vector drawings from Inkscape directly into LaTeX TikZ code allows you to create crisp, scalable diagrams that match the native fonts and styling of your LaTeX documents. This guide outlines the exact steps to convert Inkscape drawings into TikZ code using the dedicated svg2tikz extension, as well as how to include the resulting code in your LaTeX projects.

Step 1: Install the svg2tikz Extension

Inkscape does not include a native TikZ exporter by default, so you need the community-standard svg2tikz (formerly inkscape2tikz) extension.

  1. Download the latest release of svg2tikz from its official repository.
  2. Locate your Inkscape user extensions directory:
    • Linux: ~/.config/inkscape/extensions/
    • Windows: %APPDATA%\inkscape\extensions\
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/
  3. Copy the extension files (specifically the .inx and .py files) into the extensions directory.
  4. Restart Inkscape to load the extension.

Step 2: Prepare Your Drawing

To ensure clean TikZ output, organize your Inkscape drawing:

  • Convert complex text or unusual fonts to paths (Path > Object to Path) if you want them rendered as pure shapes, or leave them as plain text objects so LaTeX can render them using the document font.
  • Remove unnecessary layers, hidden objects, and clipping paths to keep the generated code small and readable.

Step 3: Export to TikZ

Once your drawing is ready, export it:

  1. Click on Extensions > Export > Export to TikZ path... (or go to File > Save As... and select *TikZ code (*.tex, .tikz) from the file type dropdown).
  2. Configure your export settings:
    • Output format: Choose between generating a complete standalone LaTeX file or a standalone TikZ snippet.
    • Scale: Adjust the scale factor to fit your document's dimensions.
    • Precision: Set the number of decimal places for coordinate accuracy.
  3. Choose the output directory and click Apply or Save.

Step 4: Include the TikZ Code in LaTeX

To use the exported file in your document:

  1. Add the TikZ package to your LaTeX preamble: 
    \usepackage{tikz}
  2. Import the generated .tikz or .tex file directly into your document body: 
    \begin{figure}[htbp]
    \centering
    \input{my-drawing.tikz}
    \caption{Diagram created with Inkscape and TikZ.}
    \label{fig:diagram}
\end{figure}

Alternative: Built-in PDF/LaTeX Export

If your drawing contains complex gradients, filters, or effects that TikZ cannot easily render, use Inkscape's built-in PDF+LaTeX export:

  1. Go to File > Save As... and select Portable Document Format (*.pdf).
  2. In the options dialog, check the box labeled "Omit text in PDF and create LaTeX file".
  3. Include the generated .pdf_tex file in LaTeX using \input{drawing.pdf_tex} with the \usepackage{graphicx} and \usepackage{xcolor} packages loaded.
