How to Simulate Color Blindness in Inkscape

Designing accessible artwork requires checking how colors appear to individuals with color vision deficiencies. Inkscape allows creators to preview designs using color management tools and display profiles that accurately simulate conditions such as protanopia, deuteranopia, and tritanopia. This guide walks directly through setting up and toggling color blindness simulations using Inkscape’s Color Management preferences.

Step 1: Open Color Management Preferences

  1. Launch Inkscape and open the document you wish to evaluate.
  2. Open the preferences dialog by navigating to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left-hand sidebar, select Color management.

Step 2: Configure the Simulation Profile

  1. Locate the Proofing profile or Display target settings within the Color management panel.
  2. Select an ICC color profile specifically generated for color vision deficiency (such as profiles for protanopia or deuteranopia). Note: Ensure your operating system or Inkscape profile directory contains the relevant accessibility ICC profiles so Inkscape can detect them.
  3. Set the Rendering intent to Perceptual or Relative Colorimetric to ensure consistent color conversion.

Step 3: Enable On-Screen Soft-Proofing

  1. Within the Color management preferences, ensure the option to Simulate output on screen (soft-proofing) is checked.
  2. Close the Preferences window.

Step 4: Toggle the Simulation on the Canvas

  1. Return to your workspace.
  2. Look at the bottom-right corner of the status bar for the Color Management icon (represented by a small color swatch or screen icon).
  3. Click the icon to instantly switch between normal display mode and the simulated color vision deficiency view.
  4. Alternatively, toggle this view by going to View in the top menu and ensuring color proofing is activated.

Use this view to identify low-contrast areas, indistinguishable palette choices, and text readability issues before finalizing your design. Clicking the toggle again returns your canvas to standard RGB colors without altering any underlying document data.
