How to Use Number Nodes in Inkscape Diagrams

The Number Nodes extension in Inkscape is an essential tool for creating clear, professional technical assembly diagrams, balloon callouts, and step-by-step schematics. This guide provides a straightforward walkthrough on preparing your vector paths, configuring the Number Nodes extension settings, generating sequenced markers, and customizing the output to produce readable, production-ready technical illustrations.

1. Prepare Your Base Geometry

Before numbering, you must define the exact locations where numbers should appear on your technical drawing.

  1. Draw Anchor Paths: Use the Draw Bezier curves tool (B) or the Pen tool to place single-segment lines or multi-point paths where each node corresponds to a specific assembly step, component, or balloon marker.
  2. Convert Objects to Paths: If you use shapes (such as circles or rectangles) as marker positions, select them and navigate to Path > Object to Path (Shift + Ctrl + C).
  3. Verify Node Direction: The extension numbers nodes strictly in the order they were created. Select your path with the Node Tool (N) to verify node sequences. If the numbering appears in reverse order later, select the path and click Path > Reverse.

2. Launch the Number Nodes Extension

  1. Select the prepared path or group of paths you want to number.
  2. Go to the top menu and select Extensions > Visualize Path > Number Nodes....

3. Configure the Extension Parameters

The dialogue box provides several parameters to tailor the numbering for technical clarity:

  • Font size: Sets the point size of the generated numbers. For standard technical drawings (A4/Letter), a size between 8 px and 14 px is typically legible.
  • Dot size: Determines the radius of the marker dot placed at each node coordinate. Set this to 0 if you only want the text numbers without node dots.
  • Start numbering at: Defines the initial integer (usually 1 for the first step or part).
  • Step: Sets the increment value between consecutive nodes (typically 1).
  • Shift nodes label by: Adjusts the offset (X and Y coordinates) of the text relative to the node. Adding an offset prevents the text from overlapping lines or assembly components.

Check the Live Preview box at the bottom of the window to verify how the numbers align with your technical illustration in real-time.

4. Apply and Finalize the Output

  1. Click Apply and close the dialogue box.
  2. The generated numbers and dots will appear as a distinct group of vector text objects and paths directly above your selected geometry.
  3. Ungroup for Adjustments: If a specific number overlaps a detailed section of your technical drawing, select the group, press Ctrl + Shift + G to ungroup, and manually reposition individual numbers using the Select Tool (S).

5. Style and Format Assembly Callouts

To make your markers conform to standard technical drawing conventions (such as circular balloon markers):

  1. Create a standardized circle or boundary box on a separate layer.
  2. Align the generated numbers to the centers of these callout boundaries using the Align and Distribute panel (Shift + Ctrl + A).
  3. Apply leader lines with arrows linking each numbered callout directly to the target assembly components.
