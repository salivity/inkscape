Split a Closed Path in Inkscape Without Deleting Nodes

In Inkscape, converting a closed polygon into an open path without removing existing nodes can be accomplished quickly using the Node tool. Depending on your design goals, you can either sever the path directly at a vertex by splitting a single node into two overlapping endpoints, or remove an outline edge entirely by deleting the segment between two vertices. Both methods preserve the exact placement of your original nodes while transforming the closed shape into an open vector line.

Method 1: Break the Path at a Node

This method keeps the full visual perimeter intact by splitting a single vertex into two separate endpoints at the exact same coordinates.

  1. Convert to Path (if necessary): If the polygon was drawn with the Star/Polygon tool, select it with the Select tool (S) and go to Path > Object to Path (or press Shift + Ctrl + C).
  2. Select the Node Tool: Activate the Edit paths by nodes tool by pressing N or selecting it from the left toolbar.
  3. Select the Target Node: Click directly on the node where you want the split to occur.
  4. Break the Path: In the top Tool Controls bar, click the Break path at selected nodes icon.

The path is now open. The single node has been split into two independent nodes positioned directly on top of each other. You can test this by clicking and dragging one of the nodes away to reveal the opening.

Method 2: Delete a Segment Between Two Nodes

This method opens the path by removing a connecting line, leaving all original vertices completely untouched.

  1. Convert to Path: Ensure your polygon is a path via Path > Object to Path.
  2. Select the Node Tool: Press N to activate the node editing mode.
  3. Select the Segment: Click directly on the line segment connecting two nodes that you wish to remove. Alternatively, hold Shift and click the two nodes flanking the segment.
  4. Delete the Segment: In the top Tool Controls bar, click the Delete segment between two non-endpoint nodes icon.

Inkscape removes only the connecting stroke between the selected vertices, leaving both original nodes in place and resulting in an open path.
