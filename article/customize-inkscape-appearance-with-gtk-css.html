Customize Inkscape Appearance with GTK CSS

Inkscape utilizes the GTK toolkit for its graphical user interface, allowing users to modify its fonts, colors, padding, and layout using custom GTK CSS rules. This guide explains how to locate Inkscape's user profile directory, create an override style.css file, identify target UI selectors, and apply functional styling examples to personalize your workspace.

Step 1: Locate the Inkscape User Profile Directory

To apply custom CSS without altering system-wide application files, place your stylesheet directly within your personal Inkscape configuration folder.

You can find this path directly inside Inkscape by opening Edit > Preferences > System and checking the User config path. Typical default locations include:

  • Linux: ~/.config/inkscape/
  • Windows: %APPDATA%\inkscape\
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/

Step 2: Create the style.css File

Inside your user configuration folder, look for a subfolder named ui. If it does not exist, create it. Inside the ui folder, create a blank text file named style.css.

  • Full Linux/macOS path: ~/.config/inkscape/ui/style.css
  • Full Windows path: %APPDATA%\inkscape\ui\style.css

Inkscape automatically loads this file on startup and merges its rules with the active GTK theme.

Step 3: Inspect Interface Elements with GTK Inspector

To determine which class or element name controls a specific part of the interface, enable the GTK Inspector:

  1. Linux: Launch Inkscape from the terminal using the command:
    GTK_DEBUG=interactive inkscape
  2. Windows: In a command prompt, set the environment variable before running the executable:
    set GTK_DEBUG=interactive
    inkscape.exe

Use the "Objects" tab inside the Inspector to click on UI elements and read their corresponding CSS nodes, class names, and pseudo-classes.

Step 4: Write Custom CSS Rules

Open your ui/style.css file in any standard text editor. GTK CSS supports standard CSS syntax along with GTK-specific properties.

Adjust Global UI Font and Size

/* Change the primary interface font */
* {
    font-family: "Segoe UI", "Noto Sans", sans-serif;
    font-size: 11pt;
}

Compact the Toolbars and Buttons

/* Reduce padding around tool buttons for a tighter layout */
toolbar button {
    min-height: 24px;
    min-width: 24px;
    padding: 2px;
    margin: 1px;
}

Customize the Canvas Rulers

/* Change color and font for the measurement rulers */
#InkRuler {
    background-color: #2b2b2b;
    color: #aaaaaa;
    font-size: 8pt;
}

Highlight Active and Hovered Elements

/* Custom highlight color for active tools */
button:checked {
    background-color: #3584e4;
    color: #ffffff;
}

/* Subtle hover effect on buttons */
button:hover {
    background-color: rgba(255, 255, 255, 0.1);
}

Style Panels and Docks

/* Adjust panel container background and border */
notebook tab {
    padding: 4px 8px;
    background-color: #242424;
}

notebook tab:checked {
    border-bottom: 2px solid #3584e4;
    background-color: #303030;
}

Step 5: Apply and Debug Changes

Save your changes to ui/style.css and restart Inkscape. The application will render using your custom stylesheet rules. If a rule does not render as expected, ensure selector specificity is high enough to override default GTK styles by appending the !important rule or adding parent container selectors.
