Map Red and Green Channels in Inkscape feDisplacementMap

This guide explains how to map the horizontal (X) and vertical (Y) displacement axes to the red and green color channels using Inkscape's built-in Filter Editor and XML Editor. Configuring feDisplacementMap to use the red channel for horizontal shift and the green channel for vertical shift is a standard technique for applying 2D distortion maps, normal maps, or custom vector field distortions to vector objects and raster graphics.

Using the Filter Editor Interface

  1. Open the Filter Editor: Go to the top menu and select Filters > Filter Editor... to open the management panel.
  2. Select or Create a Filter: Choose the filter you are currently editing from the list, or click New to create an empty filter and assign it to your selected canvas object.
  3. Add the Displacement Primitive: In the "Add Effect" dropdown at the bottom of the primitive list, select Displacement Map and click Add Effect.
  4. Connect Input Streams: Ensure the Displacement Map primitive receives two inputs in the node graph:
    • Connect the primary input (in) to the graphic you wish to distort (e.g., Source Graphic).
    • Connect the secondary input (in2) to the graphic providing the color data for displacement (e.g., a gradient, a custom texture, or an imported image).
  5. Set Channel Selectors: Click on the Displacement Map primitive in the list to expose its parameters below.
    • Locate the X Channel setting and change its dropdown value to Red.
    • Locate the Y Channel setting and change its dropdown value to Green.
  6. Adjust Scale: Adjust the Scale slider to set the intensity of the displacement. Positive values shift pixels according to the brightness of the selected channels, where a value of 0.5 (neutral gray) results in no movement, values greater than 0.5 displace in one direction, and values less than 0.5 displace in the opposite direction.

Using the XML Editor for Direct Mapping

If you prefer direct code modification or need exact SVG attribute definitions:

  1. Open the XML Editor by pressing Ctrl + Shift + X (or Cmd + Shift + X on macOS).
  2. Expand the <svg:defs> tag and locate the relevant <svg:filter> element.
  3. Click on the child <svg:feDisplacementMap> element.
  4. In the attribute panel on the right:
    • Set the attribute xChannelSelector to R.
    • Set the attribute yChannelSelector to G.
  5. Click Set for each attribute to apply the changes directly to the document's SVG code.
