How to Create Radar Charts in Inkscape

Radar charts, commonly called spider diagrams, offer an effective visual method for comparing multiple quantitative variables across one or more data series. This tutorial provides a direct, step-by-step workflow for building fully editable, scalable vector radar charts from scratch using Inkscape. You will learn how to generate concentric polygon background webs, align radial axes, accurately plot and close data series polygons, and apply clear color-coded styling for multi-metric analysis.

Step 1: Set Up the Document and Snapping

  1. Open Inkscape and press Ctrl+Shift+D to access Document Properties. Set your display units to pixels (px) or millimeters (mm) according to your output needs.
  2. Enable the Snap Controls Bar on the right side of the canvas.
  3. Turn on Snap to paths, Snap to cusp nodes, and Snap to object centers to ensure precision when aligning grid lines and data points.

Step 2: Build the Concentric Polygon Grid

  1. Select the Stars and Polygons tool (F8 or *).
  2. On the top toolbar, switch the mode to Regular polygon.
  3. Set the Corners value to match your metric count (e.g., 5 for five metrics, 6 for six metrics). Ensure Spoke ratio is set to 1.000 and Rounded is set to 0.000.
  4. Hold Ctrl while clicking and dragging on the canvas to draw a symmetric polygon. This represents the outer boundary (100% scale).
  5. Open the Fill and Stroke panel (Ctrl+Shift+F). Set Fill to none, choose a light gray Stroke paint, and set the Stroke width to a thin line (e.g., 1px).
  6. With the polygon selected, press Ctrl+D to duplicate it.
  7. Open the Transform panel (Ctrl+Shift+M), switch to the Scale tab, check Scale proportionally, and scale the duplicate down to represent internal grid intervals (e.g., 80%, 60%, 40%, 20%). Repeat the duplication and scaling process for each interval.

Step 3: Draw the Radial Axes

  1. Select the Draw Bezier curves and straight lines tool (Shift+F6 or B).
  2. Click directly on the center node of the innermost polygon or intersection.
  3. Draw a straight line out to one of the vertices of the outermost polygon and press Enter.
  4. Repeat this process for each vertex so that an axis runs from the center to each metric corner.
  5. Select all axis lines, group them (Ctrl+G), and match their stroke color and width to the background polygon grid.

Step 4: Plot the Data Points

  1. Calculate the relative position of each metric along its respective axis line based on your raw values (e.g., a score of 70 on a 0–100 scale sits at 70% distance from the center).
  2. Use the Circle/Ellipse tool (F5) to create small markers (e.g., 6px by 6px) at each calculated metric distance along the axis lines.
  3. Select the Bezier tool again and click sequentially through each plotted point to draw a connected, closed loop representing your data set. Click the initial point to close the path.

Step 5: Style for Multi-Metric Comparison

  1. Select the closed data shape you created in Step 4.
  2. In the Fill and Stroke panel, apply a distinct primary color to the Stroke paint (e.g., deep blue) and increase the stroke width to make the series stand out (e.g., 2px or 3px).
  3. Set the Fill to the same color, but lower the Alpha channel or opacity (e.g., 20% to 30%) so underlying grid elements remain visible.
  4. For additional comparison datasets, duplicate the plotting process using contrasting colors (e.g., bright orange or green) with identical fill opacity settings.
  5. Group each dataset polygon with its corresponding point markers.

Step 6: Add Labels and Scales

  1. Select the Text tool (F8 or T).
  2. Click outside each outer vertex to label each axis with its metric name.
  3. In the Align and Distribute panel (Ctrl+Shift+A), align labels symmetrically relative to the chart’s center.
  4. Add numerical indicators (such as 0, 25, 50, 75, 100) along a single reference axis to provide a clear reading scale for the entire diagram.
