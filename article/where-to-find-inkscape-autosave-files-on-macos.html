Where to Find Inkscape Autosave Files on macOS

If Inkscape crashes or quits unexpectedly on macOS, unsaved progress can often be retrieved from cache locations and emergency save folders. This guide details the default temporary file paths where Inkscape stores recovery documents on macOS, how to access them via Finder or Terminal, and how to configure your autosave settings to prevent future data loss.

1. The User Home Directory (Emergency Saves)

When Inkscape suffers an unexpected crash on macOS, its built-in emergency save routine attempts to write the document state immediately before closing. By default, these emergency files are saved directly in your macOS user profile folder:

  • Path: /Users/<your-username>/ (or ~)
  • File Format: Files are typically named after the original document or labelled as inkscape-emergency-save.svg, often appended with a date or timestamp (e.g., New document 1.2024_05_12_14_30_00.0.svg).

How to access:

  1. Open Finder.
  2. Press Command + Shift + H to jump straight to your Home directory.
  3. Sort the folder by Date Modified to locate recently created .svg files.
  4. If the file is not visible, press Command + Shift + . (period) to toggle the visibility of hidden files.

2. The macOS Temporary Directory ($TMPDIR)

If the emergency save process cannot write to the home folder, macOS frequently redirects temporary application dumps to the system's private temporary directory.

How to access:

  1. Open the Terminal application (found in Applications > Utilities).
  2. Type the following command and press Enter: 
    open $TMPDIR
  3. A Finder window will open showing your system's temporary directory.
  4. Search this folder (and any subfolders named inkscape or alphanumeric temporary folders) for files ending in .svg.

3. Scheduled Autosave Directory

Scheduled autosaves (created at set intervals while the app is running normally) are distinct from crash emergency saves. If you have the autosave feature enabled, Inkscape stores these files in the directory configured in your preferences.

If no custom path was designated, Inkscape defaults to saving these backups in:

  • Default Path: ~/.cache/inkscape/ or /Users/<your-username>/Library/Application Support/org.inkscape.Inkscape/

How to access:

  1. Open Finder.
  2. Press Command + Shift + G to open the "Go to Folder" prompt.
  3. Enter ~/Library/Application Support/org.inkscape.Inkscape/ and press Enter.
  4. Check for folders named cache or backup files saved directly inside.

How to Verify or Change the Autosave Location

To ensure autosaves are actively working and to set a predictable recovery path:

  1. Open Inkscape.
  2. Navigate to Inkscape > Preferences in the top menu bar (or press Command + ,).
  3. In the left-hand sidebar, expand Input/Output and select Autosave.
  4. Ensure the Enable autosave box is checked.
  5. In the Autosave directory field, specify a dedicated folder (such as /Users/<your-username>/Documents/InkscapeBackups/) to make recovery straightforward following future unexpected quits.
