Create Brushed Metal in Inkscape Using Gradients

Creating a brushed metal texture in Inkscape relies on simulating the light reflections that bounce off micro-grooves in polished surfaces like aluminum or stainless steel. By applying a multi-stop linear gradient containing alternating bands of light, mid, and dark metallic tones, you can generate a convincing, vector-based brushed finish without raster textures. This guide explains how to construct your base shape, configure irregular gradient stops, and orient the shading to produce a clean metallic sheen.

Step 1: Create the Base Object

  1. Select the Rectangle tool (press R) or any shape tool to draw the object you want to shade.
  2. Open the Fill and Stroke panel by pressing Shift + Ctrl + F.
  3. Under the Fill tab, click the Linear Gradient icon. Inkscape will apply a default two-stop gradient transitioning from your base color to transparency.

Step 2: Access the Gradient Tool

  1. Switch to the Gradient tool by pressing G (or clicking its icon on the left toolbar).
  2. You will see a gradient line extending across your shape, anchored by a square handle (start stop) and a circle handle (end stop).
  3. Reposition the line so it stretches across the full width or along the intended direction of the brushed surface.

Step 3: Add Multiple Gradient Stops

A realistic brushed effect requires numerous narrow, non-uniform bands of light and shadow rather than a smooth, single transition.

  1. Hover over the gradient line with the Gradient tool active until your cursor displays an addition symbol.
  2. Double-click on the line to insert a new stop.
  3. Repeat this process to create between 8 and 16 intermediate stops along the line.
  4. Space the stops irregularly. Uniform spacing creates a synthetic, striped appearance, while uneven intervals mimic natural variations in metallic grain.

Step 4: Define the Metallic Color Palette

Select each stop individually by clicking on its handle, then assign a color using the palette or the Fill and Stroke panel:

  • Highlights: Set several narrow stops to near-white or very light gray (#EDEDED to #FFFFFF). These represent sharp reflections.
  • Midtones: Assign neutral steel grays (#B0B0B0 to #CCCCCC) to the majority of the stops.
  • Shadows: Place a few deeper gray stops (#666666 to #888888) immediately adjacent to your highlight stops to enhance contrast and simulate groove depth.
  • Ensure all stops have their alpha channel (opacity) set to 100%.

Step 5: Adjust Angle and Proportion

  1. Drag the start handle to one side of the object and the end handle to the opposite side.
  2. For standard horizontal or vertical brushed metal, keep the line perpendicular to the brushed direction. For example, to achieve a vertical brush pattern, run the gradient line horizontally.
  3. For a dynamic industrial finish, tilt the gradient handles at a 45-degree angle.
  4. Drag individual stop handles closer together to sharpen specific reflection bands or pull them apart to soften broader diffuse areas.

Step 6: Refine the Edge Lighting

To finish the metallic appearance, add a subtle bevel:

  1. In the Fill and Stroke panel, switch to the Stroke paint tab and select a Linear Gradient.
  2. Align the stroke gradient in the reverse direction of your fill gradient (light on the shadow side, dark on the highlight side).
  3. Set a thin stroke width (1 px to 2 px) under Stroke style to give the metal a crisp, cut-edge highlight.
