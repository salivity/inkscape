Rotate Icons in Inkscape Using XML animateTransform

This guide explains how to create continuous rotating SVG icon animations directly within Inkscape using its built-in XML Editor. By adding native SVG <animateTransform> elements to an icon group, you can produce lightweight, endlessly spinning vector graphics suitable for web loaders, status indicators, and UI elements without needing external coding tools or third-party animation software.

Step 1: Prepare Your Icon and Center Point

  1. Open your icon in Inkscape.
  2. Select the entire icon and press Ctrl+G to group all its paths into a single parent group.
  3. Select the grouped icon and look at the top toolbar to find its center coordinates:
    • Calculate the horizontal center (\(X_{center}\)): \(X + (\text{Width} / 2)\)
    • Calculate the vertical center (\(Y_{center}\)): \(Y + (\text{Height} / 2)\)
    • Note these two values, as they define the pivot point around which the icon will spin.

Step 2: Open the XML Editor

  1. Select the grouped icon on the canvas.
  2. Open the XML Editor by navigating to Edit > XML Editor or pressing Shift+Ctrl+X.
  3. In the XML tree on the left, verify that the active <svg:g> element representing your icon group is highlighted.

Step 3: Create the animateTransform Node

  1. With the parent <svg:g> selected, click the New element node button in the XML Editor toolbar (represented by an icon with an angled bracket and a small star/plus).
  2. A dialog prompt will ask for the node name. Enter:
    svg:animateTransform
  3. Click Create. The new element will appear nested directly inside your selected group.

Step 4: Configure the Animation Attributes

Select the newly created <svg:animateTransform> element. Using the Attribute name input field and Attribute value field on the right side of the XML Editor, add the following attributes one by one by entering the name, value, and clicking Set (or pressing Ctrl+Enter):

  • attributeName
    • Name: attributeName
    • Value: transform
  • type
    • Name: type
    • Value: rotate
  • from
    • Name: from
    • Value: 0 Xcenter Ycenter (replace with your calculated values, e.g., 0 50 50)
  • to
    • Name: to
    • Value: 360 Xcenter Ycenter (replace with the same center values, e.g., 360 50 50)
  • dur
    • Name: dur
    • Value: 2s (controls speed; change to a higher value to slow down, or lower to speed up)
  • repeatCount
    • Name: repeatCount
    • Value: indefinite

Step 5: Save and Preview

  1. Go to File > Save As...
  2. Choose Optimized SVG or Plain SVG to ensure compatibility with modern browsers and clean up redundant editor metadata.
  3. Open the saved .svg file in any modern web browser (such as Chrome, Firefox, or Edge) to view the smooth, continuous rotation.
