Add Node at Maximum Curvature of an Ellipse in Inkscape

This guide explains how to place a node precisely at the point of maximum curvature on an elliptical segment in Inkscape. On any ellipse, the maximum curvature occurs at the vertices along the semi-major axis, where the curve bends most sharply. You can locate and insert a node at this exact location using native parametric conversion, Inkscape’s geometric snapping tools, or guide-based alignment.

Method 1: Using Object to Path (For Native Ellipse Objects)

If the elliptical segment was created using Inkscape's Circles and Ellipses tool (F5 or E), Inkscape inherently tracks the major and minor axes mathematically.

  1. Select the ellipse or elliptical arc with the Select tool (S).
  2. Navigate to the top menu and select Path > Object to Path (or press Ctrl + Shift + C).
  3. Switch to the Node tool (N).
  4. Inkscape automatically generates four nodes at the exact extremities of the ellipse: two at the vertices of the semi-major axis (the points of maximum curvature) and two at the co-vertices of the semi-minor axis (the points of minimum curvature).

Method 2: Using Curve Extremum Snapping (For Arbitrary Path Segments)

If the elliptical arc has already been converted to an arbitrary Bézier path and its major axis is aligned horizontally or vertically, you can use Inkscape's quadrant/extremum snapping.

  1. Open the Snap controls bar (located at the top right of the workspace).
  2. Enable snapping globally by toggling Enable Snapping (%).
  3. Under the snapping options, enable:
    • Snap to paths
    • Snap to path extreme points (or "Snap to quadrant points of ellipses")
  4. Select the Node tool (N) and click on your path to display the segments.
  5. Hover your mouse along the sharpest bend of the elliptical curve until a snap indicator (such as an X or "Path extremum") appears.
  6. Double-click the segment directly on that snapped point. Inkscape will insert a new node precisely at the extremum without altering the path geometry.

Method 3: For Rotated Elliptical Paths

If the elliptical segment is rotated, the geometric extrema no longer align with the global X/Y axes, so standard extremum snapping will not detect the maximum curvature point.

  1. Find the angle of orientation:
    • Select the path and open the Transform panel (Ctrl + Shift + M).
    • If the rotation angle is known, rotate the object back to horizontal, apply Method 2, and then rotate it back.
  2. Alternative using Tangent Snapping:
    • Enable Snap perpendicular lines and Snap tangent lines in the Snap Controls.
    • Drag a guide line from the ruler (Ctrl + R) near the apex of the curve.
    • Rotate the guide (Shift + Click and Drag on the guide) until it snaps tangentially to the apex of the ellipse.
    • Switch to the Node tool (N), ensure Snap to guides is enabled, and double-click the intersection where the guide touches the curve.
