Adjust Proportional and Tabular Figures in Inkscape

This guide explains how to toggle between proportional and tabular figure styling for numerical data in Inkscape. Proportional figures have variable widths designed to blend naturally with text, whereas tabular figures share identical bounding widths to keep numerical columns aligned in charts and tables. Inkscape manages these styles natively through its OpenType font feature controls.

Prerequisites

To switch figure styles, you must use a font that contains OpenType numeric layout features. Common typefaces like Roboto, Inter, Fira Sans, and Garamond often include both proportional (pnum) and tabular (tnum) variants. If a font lacks these tables, the options in Inkscape will have no effect.

Method 1: Using the Text and Font Dialog

  1. Select the Text: Click the Text tool (T) from the left toolbar and highlight the numbers you want to adjust, or use the Selector tool (S) to select the entire text object.
  2. Open the Text and Font Panel: Navigate to Text > Text and Font... in the top menu bar, or press Shift + Ctrl + T.
  3. Access Font Features: In the panel that opens on the right, switch to the Features tab.
  4. Locate Numeric Options: Expand the Numeric or Numbers category within the feature list.
  5. Choose Figure Width:
    • Select Tabular (or check tnum) for monospaced numbers aligned for tables.
    • Select Proportional (or check pnum) for naturally spaced numbers suitable for regular text flow.
  6. Apply the Changes: Click the Apply button at the bottom of the panel to update your canvas.

Method 2: Using the XML Editor (CSS Property)

If you prefer direct code manipulation or are troubleshooting stubborn font styles, you can inject the CSS property directly:

  1. Select your text object.
  2. Open the XML Editor by pressing Ctrl + Shift + X (or go to Edit > XML Editor).
  3. Select the <svg:text> or child <svg:tspan> node corresponding to your text.
  4. Locate the style attribute in the right-hand panel.
  5. Append one of the following CSS rules to the style string (separated by a semicolon):
    • For tabular figures: font-variant-numeric: tabular-nums;
    • For proportional figures: font-variant-numeric: proportional-nums;
  6. Click Set to apply the styling.
