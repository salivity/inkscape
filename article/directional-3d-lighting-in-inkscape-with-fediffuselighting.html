Directional 3D Lighting in Inkscape with feDiffuseLighting

This guide explains how to use the feDiffuseLighting filter primitive in Inkscape to transform flat vector graphics into embossed, three-dimensional surfaces using directional light. By mapping an object's alpha transparency to an elevation height map and casting light with a directional source (feDistantLight), you can generate realistic matte shading, bevels, and surface relief. The following sections walk through setting up the Filter Editor, configuring light angles, adjusting surface height, and compositing the final result over your artwork.

1. Open the Filter Editor and Create a Filter

  1. Select the vector object you want to shade.
  2. Navigate to Filters > Filter Editor... in the main menu to open the Filter Editor panel.
  3. Click New at the bottom of the filter list to create an empty filter (e.g., filter1).
  4. Check the box next to your new filter to assign it to the selected object.

2. Add Required Primitives

To create smooth directional lighting, you need an elevation map, a diffuse lighting calculator, a light source, and a compositing step to blend the light with your artwork's original color.

  1. feGaussianBlur (Optional but Recommended):
    • In the Add Primitive dropdown, select Gaussian Blur and click Add Primitive.
    • Connect its input to SourceAlpha. This softens the edges of your shape to create a sloped ramp for the light to hit.
  2. feDiffuseLighting:
    • Select Diffuse Lighting from the dropdown and click Add Primitive.
    • Connect its input to the output of the feGaussianBlur (or directly to SourceAlpha for sharp, hard edges).
  3. feDistantLight:
    • In the Filter Editor, select the feDiffuseLighting primitive.
    • Expand the light source dropdown below the primitive settings and select Distant Light (this represents parallel, directional rays like sunlight).
  4. feComposite:
    • Add a Composite primitive to blend the illumination with your original shape.
    • Connect one input (Image) to SourceGraphic and the other input (Image 2) to the Diffuse Lighting output.

3. Configure the feDiffuseLighting Attributes

Select the Diffuse Lighting primitive in the list to reveal its parameters in the lower pane:

  • surfaceScale: Defines the apparent height of your 3D surface. A higher value creates a deeper, more pronounced bevel or bump, while a low value produces subtle relief. Typical values range between 2 and 10.
  • diffuseConstant: Controls the reflection coefficient (\(k_d\)). It determines how brightly the surface reflects diffuse light. A value of 1.0 is standard; values above 1.0 intensify the highlight brightness.
  • lighting-color: Sets the color of the light rays. For neutral shading, set this to pure white (#ffffff).

4. Set Directional Angles with feDistantLight

Select the nested Distant Light under your diffuse lighting primitive to adjust the direction of the light rays:

  • azimuth: The directional angle of the light source in the XY plane, measured in degrees from 0 to 360.
    • 0° directs light from the right.
    • 90° directs light from the bottom.
    • 180° directs light from the left.
    • 225° or 315° are standard conventions for top-left or top-right lighting.
  • elevation: The angle of the light above the surface plane, measured in degrees from 0 to 90.
    • 0° casts grazing, long shadows parallel to the surface.
    • 90° positions the light directly overhead, resulting in flat, uniform illumination.
    • 30° to 50° provides optimal contrast for directional relief.

5. Composite the Lighting with the Object Color

By default, feDiffuseLighting only outputs an opaque grayscale or tinted map of the light rays. To apply this light to your shape's original colors:

  1. Select the Composite primitive you added.
  2. Set the Operator dropdown to Arithmetic.
  3. Set the coefficients to:
    • K1: 1.0 (multiplies the light with the source graphic color).
    • K2: 0.0
    • K3: 0.0
    • K4: 0.0
  4. Alternatively, select In or Atop if you used a pre-colored light source and wish to mask the light to the boundaries of the original graphic.
