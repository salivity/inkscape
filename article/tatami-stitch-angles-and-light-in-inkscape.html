Tatami Stitch Angles and Light in Inkscape

Configuring tatami fill stitch angles in Inkscape using the Ink/Stitch extension allows you to manipulate how ambient light reflects off your embroidery, creating depth, dimension, and contrast without changing thread colors. Because embroidery thread is cylindrical and lustrous, stitches running in different directions catch and scatter light uniquely, causing identical thread tones to appear lighter or darker depending on the viewer's angle. By intentionally setting stitch angles in your design segments, you can simulate shadows, highlights, and 3D effects purely through structural design.

Understanding Thread Reflection and Stitch Angle

Embroidery threads, particularly polyester and rayon, possess a distinct sheen that reflects light perpendicular to the orientation of the fiber.

  • A horizontal stitch row (0°) reflects light upward and downward, appearing bright under overhead lighting.
  • A vertical stitch row (90°) reflects light side to side, appearing darker or matte when viewed from the same position.

A 90-degree difference between adjacent embroidery elements delivers the maximum optical contrast, while smaller 30- to 45-degree variations produce subtle, gradient-like shifts in sheen.

Adjusting Tatami Stitch Angles in Ink/Stitch

To set a uniform stitch angle for any closed vector shape:

  1. Select the vector object on the Inkscape canvas using the Select Tool (S).
  2. Open the parameter settings by navigating to Extensions > Ink/Stitch > Params.
  3. In the preview window that appears, ensure the fill method is set to Tatami.
  4. Locate the Angle of stitches (degrees) input field.
  5. Enter your desired angle between 0 and 360 degrees:
    • 0° produces horizontal stitching.
    • 90° produces vertical stitching.
    • 45° or 135° produces diagonal stitching.
  6. Observe the change in the interactive preview panel to ensure the alignment suits the shape's contours.
  7. Click Apply and Quit to save the angle configuration to the object's XML attributes.

Segmenting Shapes for Dynamic Contrast

To create light-and-shadow effects within a single-color graphic, split the artwork into distinct planar facets:

  1. Use Inkscape's Pen Tool (B) or the Division boolean operator (Path > Division) to split an object down its natural axis of symmetry or light-fall line.
  2. Select the "illuminated" side, enter Ink/Stitch > Params, and orient the stitches perpendicular to your expected light source (typically around 0° or 45°).
  3. Select the "shadowed" side and set the stitch angle perpendicular to the illuminated side (e.g., 90° or 135°).
  4. Keep the thread color, stitch density, and pull-compensation identical across both shapes.

When embroidered, the alternating angles will create a defined bevel or fold effect that shifts dynamically as the fabric moves.

Curved Light Control with Guiding Lines

For organic shapes such as leaves, drapery, or spheres, flat angles can look unnatural. You can create sweeping, curved light reflections by using directional guide paths:

  1. Draw your closed vector shape for the tatami fill.
  2. Draw an open path across or along the shape using the Pen Tool to indicate the flow of stitches.
  3. Select both the closed shape and the open path.
  4. Combine them into a single path by going to Path > Combine (Ctrl + K).
  5. Open Extensions > Ink/Stitch > Params. Ink/Stitch interprets the unclosed subpath as a directional guide, contouring the tatami stitches along the curve.

This technique causes the light highlight to curve naturally across the surface of the embroidery, replicating the way light bends around a rounded object.
