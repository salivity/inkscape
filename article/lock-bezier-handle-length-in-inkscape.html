Lock Bezier Handle Length in Inkscape

This guide explains how to lock the length of a Bezier node handle while adjusting its direction in Inkscape. When fine-tuning vector curves, maintaining the exact pull distance of a handle while altering its curvature angle is essential for precise vector illustration. Inkscape provides a built-in keyboard modifier that restricts handle movement strictly to rotation without affecting length.

The Shortcut: Hold the Alt Key

To rotate a Bezier handle without changing its length, use the Alt key while dragging.

Step-by-Step Instructions

  1. Activate the Node Tool: Select your path and switch to the Edit paths by nodes tool by pressing N or selecting the node icon from the left-hand toolbar.
  2. Display the Handles: Click on the specific node whose curve you wish to modify so its Bezier handles (the circular control points extending from the node) become visible.
  3. Grab the Handle: Click and hold the circular end of the Bezier handle you want to adjust.
  4. Hold Alt: Press and hold the Alt key on your keyboard while keeping your mouse button pressed down.
  5. Adjust the Angle: Move your cursor around the node. The handle will rotate freely in 360 degrees, but its distance from the node will remain completely locked.
  6. Release: Release the mouse button first to set the new angle, then release the Alt key.

Important Considerations

  • OS Conflicts on Linux: On some Linux desktop environments (such as GNOME or XFCE), the Alt key is reserved by default for dragging application windows. If holding Alt moves the entire Inkscape window rather than rotating the handle, change your window manager's "window action key" from Alt to the Super (Windows) key in your operating system's settings.
  • Node Types: This shortcut works on all node types with handles (Cusp, Smooth, and Symmetric). On smooth and symmetric nodes, holding Alt while dragging one handle will maintain the length of that specific handle while keeping both handles aligned in a straight line.
