Select Objects Underneath Other Objects in Inkscape

Selecting objects hidden beneath other shapes or layers in Inkscape is a common task in vector design that does not require moving elements out of the way. This guide covers the most efficient built-in methods—including keyboard shortcuts, the Layers and Objects panel, and alternate display modes—to quickly target and manipulate hidden objects while keeping your layout intact.

Method 1: The Alt + Click Shortcut (Z-Order Cycling)

The fastest way to select an object located directly beneath another is using the Alt modifier key with the Select tool (S or F1).

  1. Click on the topmost object to select it.
  2. Hold down the Alt key (or Option key on macOS) and click the same spot again. Inkscape will select the next object down in the Z-order stack.
  3. Continue to hold Alt and click until the specific hidden object you need is selected.
  4. To reverse the cycling order, hold Alt + Shift and click.

Note for Linux users: If the Alt key triggers window movement in your desktop environment, you can use Ctrl + Alt + Click or remap the window manager key in your OS settings.

Method 2: The Layers and Objects Panel

When working with complex illustrations with multiple overlapping elements, the Layers and Objects panel provides the most precise control.

  1. Open the panel by navigating to Layer > Layers and Objects... or pressing Ctrl + Shift + L (Cmd + Shift + L on macOS).
  2. Expand the layer containing your artwork.
  3. Hover over or click through the list of objects in the tree view to highlight and select the exact hidden item without touching the canvas.

Method 3: Cycling with the Tab Key

You can cycle through all objects on the current layer sequentially using the keyboard:

  1. Select any visible object near the hidden one.
  2. Press the Tab key to select the next object in the stacking order, or Shift + Tab to cycle backward.
  3. Stop when the bounding box outlines the hidden object you want to edit.

Method 4: Outline Display Mode

If an object is completely obscured by opaque fills:

  1. Go to View > Display Mode > Outline (or press Ctrl + 5 on the numeric keypad).
  2. Inkscape will render all paths as wireframes, removing all fills so you can directly click on the outline of the hidden object.
  3. Switch back by selecting View > Display Mode > Normal.
