How to Create GS1-128 Barcode Labels in Inkscape

This guide explains how to generate GS1-128 compliant barcode labels using the open-source vector graphics editor Inkscape. You will learn the structural requirements of the GS1-128 standard, how to configure Inkscape's built-in barcode generator or import compliant Code 128 vectors, how to dimension the barcode correctly for retail scanning, and how to format the Human-Readable Interpretation (HRI) text properly.

Understanding GS1-128 Requirements

GS1-128 (formerly UCC/EAN-128) is a specialized subset of the Code 128 symbology. It encodes data using Application Identifiers (AIs)—two- to four-digit prefixes enclosed in parentheses in human-readable text that identify the type of data that follows, such as batch numbers (10), expiration dates (17), or Global Trade Item Numbers (01).

To remain compliant with retail and logistics specifications:

  • Symbology: Code 128, starting with a Function 1 (FNC1) character.
  • Quiet Zones: Clear margins on the left and right sides of the barcode, each measuring at least 10 times the width of the narrowest bar (X-dimension).
  • X-dimension: Typically between 0.495 mm and 1.016 mm for outer case and distribution labels.
  • Bar Height: Standard specification requires a minimum bar height of 31.75 mm (1.25 inches) for logistics labels.

Step 1: Set Up the Inkscape Document

  1. Open Inkscape and navigate to File > Document Properties (Ctrl+Shift+D).
  2. Set the Display units to mm or in depending on your local standard.
  3. Under Page Size, enter the exact dimensions of your label (for example, standard 4 x 6 inch shipping labels or 100 x 150 mm labels).
  4. Set the Scale to 1.0 to ensure physical export dimensions match print requirements.

Step 2: Generate the Barcode Graphic

While Inkscape includes a native Code 128 tool, GS1-128 requires an invisible FNC1 character directly after the start character to signal GS1 compliance.

  1. Go to Extensions > Render > Barcode > Classic Barcode.
  2. Select Code 128 from the Barcode Type dropdown.
  3. In the Barcode Data field, enter your encoded payload without parentheses. For example, if your GS1 data is (01)00012345678905(10)BATCH123, enter 010001234567890510BATCH123.
  4. Set the bar height to the required GS1 minimum (e.g., 32 for 32 mm).
  5. Click Apply to generate the vector barcode onto your canvas.

Note on FNC1 support: Inkscape's native extension does not always embed the GS1-specific FNC1 flag. If your retail partner scans for strict FNC1 encoding, generate the base vector via a dedicated GS1 generator (such as Zint or BarcodeWriter) and import the resulting .svg directly into Inkscape via File > Import.

Step 3: Size and Align the Barcode

  1. Select the generated barcode group on the canvas.
  2. Open the Transform panel (Object > Transform or Ctrl+Shift+M).
  3. Ensure the aspect ratio is unlocked so you can scale width and height independently if needed.
  4. Scale the barcode width so the individual narrow bar (X-dimension) stays within the 0.495 mm to 1.016 mm range.
  5. Create a background rectangle behind the barcode with a pure white fill (#FFFFFF) that extends at least 10X the narrow bar width past both the left and right ends of the barcode to guarantee the required Quiet Zones.

Step 4: Add Human-Readable Interpretation (HRI)

GS1 specifications require clear, legible text positioned directly below the barcode bars.

  1. Select the Text tool (T) and click below the barcode.
  2. Use an approved OCR font such as OCR-B, or a standard clean sans-serif font like Arial or Helvetica.
  3. Format the data string showing the Application Identifiers inside parentheses:
    (01) 00012345678905 (10) BATCH123
    (The parentheses are printed in the HRI for readability but are never encoded into the barcode lines themselves).
  4. Center the text block beneath the barcode using the Align and Distribute panel (Object > Align and Distribute or Ctrl+Shift+A).

Step 5: Finalize and Export for Printing

  1. Select all barcode elements (the bars, the background quiet zone box, and the HRI text).
  2. Group them together by pressing Ctrl+G.
  3. Go to Path > Object to Path (Ctrl+Shift+C) if sending the file to a print shop that might not have your barcode font installed.
  4. Save the master file in native format via File > Save As > Inkscape SVG.
  5. Export for production via File > Save As, choosing Portable Document Format (*.pdf). In the PDF export dialog, set the output resolution to at least 300 DPI to avoid antialiasing blur on thermal and laser barcode printers.
