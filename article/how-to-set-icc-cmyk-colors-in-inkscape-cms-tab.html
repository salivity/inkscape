How to Set ICC CMYK Colors in Inkscape CMS Tab

This guide explains how to configure and apply ICC-based CMYK color values using the CMS (Color Management System) tab inside Inkscape's Fill and Stroke dialog. You will learn how to link an ICC print profile to your document, access the CMS tab, and define exact CMYK ink values for vector fills and strokes.

1. Install and Link an ICC Profile to the Document

Inkscape requires an active ICC profile linked to your document before the CMS tab can output calibrated CMYK values.

  1. Install your target CMYK profile (such as Coated FOGRA39 or U.S. Web Coated (SWOP) v2) to your operating system's standard color directory.
  2. Open Inkscape and navigate to File > Document Properties (or press Shift + Ctrl + D).
  3. Switch to the Color tab.
  4. Locate your installed CMYK profile in the Available profiles list, select it, and click Link (or the add icon) to attach the profile to the active document.
  5. Close the Document Properties dialog.

2. Open the Fill and Stroke Dialog

  1. Select the object you want to color using the Select tool (S).
  2. Open the color settings by going to Object > Fill and Stroke (or press Shift + Ctrl + F).
  3. Select either the Fill tab or the Stroke paint tab, depending on which element you want to edit.
  4. Ensure the color mode is set to Flat color (the solid square icon).

3. Configure Values in the CMS Tab

  1. Beneath the paint mode icons, find the color selector tabs (RGB, HSL, CMYK, Wheel, CMS). Click the CMS tab.
  2. In the CMS panel, open the profile drop-down menu and select the CMYK profile you linked in your Document Properties.
  3. Once selected, Inkscape displays channels corresponding to the profile: C (Cyan), M (Magenta), Y (Yellow), and K (Black), along with an A (Alpha) channel.
  4. Enter your target percentage values directly into the numerical fields or move the sliders to set the ink mix.
  5. Keep the Alpha slider at 100% to ensure solid, opaque ink distribution.

Important Technical Details

  • CMS Tab vs. Standard CMYK Tab: The default CMYK tab in Inkscape is a simple mathematical transform of sRGB and is not color-managed. The CMS tab directly references the ICC profile data, ensuring predictable ink separations for commercial print workflows.
  • Underlying SVG Code: Inkscape writes these values into the SVG markup as an icc-color() fallback string alongside an sRGB equivalent, preserving both on-screen display accuracy and target print data.
