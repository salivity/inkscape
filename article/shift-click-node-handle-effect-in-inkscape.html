Shift Click Node Handle Effect in Inkscape

In Inkscape, pressing the Shift key while clicking an existing node handle instantly deletes or retracts that handle back into the node. This action eliminates the Bézier curve control point on that side, turning the adjacent curve into a straight segment while keeping the opposite handle unaffected. It provides a fast, keyboard-driven method to transition smooth curves into sharp corners without manually altering the node type through the toolbar.

How Handle Retraction Works

When editing paths with the Node Tool (N), each curved segment is governed by handles that extend outward from the path's nodes.

  • Instant Deletion: Clicking directly on the circular end of a handle while holding Shift pulls the handle entirely into the base node, setting its length to zero.
  • Independent Modification: If the node is smooth or symmetric, Shift-clicking one handle automatically breaks the symmetry and converts the node into a cusp (corner) node. The opposite handle remains extended and retains its original angle and length.
  • Straightening Segments: Removing the handle causes the path segment connected to that side of the node to lose its curvature, snapping into a straight vector unless influenced by a handle on the neighboring node.

Restoring a Retracted Handle

If you retract a handle by mistake or need to reintroduce a curve later:

  1. Hold Shift.
  2. Click directly on the node itself and drag outward.
  3. A new handle will pull out from the node, allowing you to re-establish the Bézier curve. Alternatively, pressing Ctrl + Z immediately restores the deleted handle.
