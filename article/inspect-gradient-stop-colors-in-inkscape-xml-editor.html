Inspect Gradient Stop Colors in Inkscape XML Editor

This guide explains how to locate and inspect the RGB color profiles and exact values of individual gradient stops using Inkscape's built-in XML Editor. By accessing the underlying SVG source tree, you can view, verify, or manually edit the raw hexadecimal, RGB, or ICC color definitions associated with gradient stops without relying on the visual palette tools.

Step 1: Open the XML Editor

Select the object containing the gradient on your canvas. Open the XML Editor by navigating to Edit > XML Editor from the main menu, or by pressing the shortcut Ctrl + Shift + X (or Cmd + Shift + X on macOS). This opens a docked panel displaying the complete SVG document tree.

Step 2: Locate the Gradient Definition

SVG gradients are stored separately from the shapes that use them, typically inside the document's <svg:defs> section.

  1. In the XML Editor tree, expand the root <svg:svg> node.
  2. Locate and expand the <svg:defs> node.
  3. Look for gradient tags, either <svg:linearGradient> or <svg:radialGradient>.
  4. Note that Inkscape often uses two gradient entries: one that defines coordinates (linking to another gradient via xlink:href), and a parent gradient that holds the actual color stops. Select the gradient node that contains child elements.

Step 3: Select the Target Stop Element

Expand the parent <svg:linearGradient> or <svg:radialGradient> node to reveal its nested child nodes:

  • Each gradient stop is represented as an <svg:stop> element.
  • The stops appear in sequential order corresponding to their positions from start (offset 0) to end (offset 1).
  • Click on the specific <svg:stop> element you wish to inspect.

Step 4: Read the RGB and Color Profile Data

Once an <svg:stop> node is highlighted, look at the right-hand attribute pane within the XML Editor:

  • The style Attribute: Look for the attribute named style. Its value contains parameters such as stop-color and stop-opacity.
  • Standard RGB Format: The stop-color will display either as a hexadecimal code (e.g., #ff5733) or as a functional notation like rgb(255, 87, 51).
  • Color Profiles (ICC): If a specific color profile is applied to the stop, the stop-color attribute will define the fallback RGB value followed by the profile specification, typically formatted as icc-color(<profile-name>, <components>).
  • Alternative Presentation Attributes: In some SVG specifications or cleaned files, you may see stop-color listed as an independent XML attribute rather than inside the style string.
