How to Preserve Layer Visibility in Inkscape PDF

This guide explains how to ensure your layer visibility settings remain intact when exporting multi-layer documents to PDF in Inkscape. By properly configuring the Layers and Objects panel and selecting the correct PDF output settings, you can reliably include only your active design elements while completely omitting hidden drafting notes, reference images, or alternate layer versions.

1. Configure Layer Visibility Before Exporting

Inkscape determines what to render in a PDF based on the current canvas state and CSS visibility properties.

  1. Open the Layers and Objects panel by pressing Ctrl + Shift + L (Windows/Linux) or Cmd + Shift + L (macOS).
  2. Review the list of layers. Click the Eye icon next to each layer to set its state:
    • Open Eye: The layer is visible and will be rendered in the PDF.
    • Closed Eye / Slashed Eye: The layer is hidden (display:none) and will be excluded from the PDF.
  3. Check for sub-layers or nested objects. A visible object inside a hidden parent layer will not export, but a hidden object inside an otherwise visible layer might cause rendering artifacts if not hidden using the layer eye toggle.
  4. Ensure you have not substituted layer hiding with 0% opacity. An object with 0% opacity is still processed and may cause unwanted blank bounding boxes, large file sizes, or rasterization issues in the PDF.

2. Export the File to PDF

Once your layer visibility is established, export the document using Inkscape’s native PDF engine:

  1. Go to File > Save As... or press Ctrl + Shift + S (Cmd + Shift + S).
  2. In the file type dropdown menu, select Portable Document Format (*.pdf).
  3. Choose your destination folder, enter a file name, and click Save.

3. Set the PDF Output Options

After clicking Save, the Portable Document Format dialog will appear. Configure the following options to prevent unexpected rendering:

  • PDF version: Select PDF 1.5 or higher. This standard properly supports transparency and modern vector path rendering.
  • Text output options: Choose Embed fonts to keep text editable, or Convert text to paths if you want to ensure the visual layout does not shift on devices lacking your fonts.
  • Rasterize filter effects: Check this option only if your visible layers use blurs, drop shadows, or blend modes that pure vector PDF cannot represent.
  • Resolution for rasterization (dpi): Set this to 300 dpi for print, or 96–150 dpi for screen distribution.
  • Output page size: Choose Use document's page size to ensure the boundaries match your artwork bounds rather than expanding to hidden off-canvas elements.

Click OK to generate the PDF.

4. Alternative: Exporting via the Export Dialog (Inkscape 1.2+)

In newer versions of Inkscape, you can also use the integrated export panel:

  1. Open the panel via File > Export... (Ctrl + Shift + E / Cmd + Shift + E).
  2. Select the Document or Page tab depending on whether you want the full canvas or a specific page.
  3. Set the format dropdown to PDF.
  4. Click the Export button at the bottom. Inkscape will automatically respect your current layer visibility settings.

Troubleshooting Visibility Issues

  • Hidden layers still appearing: If an element still shows up in the PDF, it may be assigned to the Root canvas level instead of a dedicated layer. Move it into an explicit layer by right-clicking the object and choosing Move to Layer....
  • Clones and symbols: If a visible layer contains a clone (Alt + D) of an object located in a hidden layer, the visual representation will still export. To fix this, unlink the clone via Edit > Clone > Unlink Clone before hiding the original source layer.
