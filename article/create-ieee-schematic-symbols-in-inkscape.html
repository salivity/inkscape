Create IEEE Schematic Symbols in Inkscape

This guide explains how to design standardized schematic electrical component symbols in Inkscape following IEEE Std 315 (ANSI Y32.2) conventions. You will learn how to configure a precision coordinate grid, construct fundamental graphic elements using consistent stroke weights, position connection terminals at standardized intervals, and package the finished components into reusable SVG symbol libraries.

1. Configure the Document Grid and Units

IEEE schematic standards rely on a uniform modular grid so symbols align seamlessly with interconnecting wires.

  1. Open File > Document Properties (Ctrl+Shift+D).
  2. Set Display units to inches (in) or millimeters (mm). An imperial grid of 0.1 inches (2.54 mm) or a metric equivalent (2.5 mm) is standard for electronic schematics.
  3. Go to the Grids tab, select Rectangular grid, and click New.
  4. Set Spacing X and Spacing Y to 0.1 in (or 2.54 mm). Set Minor grid line frequency to 5 or 10 for sub-grid placement.
  5. Enable snapping: Ensure Snap to Grid is activated on the Snap toolbar (% key), which guarantees that connection terminals align precisely with the grid nodes.

2. Set Standard Stroke Weights and Fills

IEEE standards prescribe clear hierarchy in line thickness to distinguish component outlines from terminals and emphasis markers.

  1. Open the Fill and Stroke panel (Ctrl+Shift+F).
  2. Set standard line weights:
    • Component bodies and connection terminals: Use a medium stroke, typically 0.25 mm to 0.35 mm (around 1 pt).
    • Enclosures or shielding lines: Use a thinner stroke, roughly 0.18 mm (0.5 pt).
    • Heavy emphasis/buses: Use 0.5 mm to 0.7 mm.
  3. Set Fill to "No paint" for basic passive components (resistors, capacitors, inductors). Certain logic gates or diodes may require solid black fills for polarity or inversion bubbles, but standard bodies remain transparent or filled with white.
  4. Set Cap to "Square" or "Butt" and Join to "Miter" to ensure wire joints connect without overlapping artifacts.

3. Draw Core Component Geometries

Use geometric primitives and the Pen tool to construct components following standard IEEE forms.

  • Resistors (IEEE Std 315): A standard resistor consists of three complete zig-zag cycles (six peaks total). Use the Draw Bezier curves tool (B), hold Ctrl to lock angles, and snap each peak to an alternate sub-grid unit.
  • Capacitors: Draw two parallel lines perpendicular to the lead lines. For a non-polarized capacitor, both lines are straight. For an electrolytic/polarized capacitor, the negative plate is drawn as a curved arc using the Arc tool or a 3-point curved path.
  • Logic Gates: Draw the flat input edge aligned with grid lines. Use circular arcs to form the distinctive curved shapes of AND, OR, and XOR gates. Keep input and output pins symmetrically balanced along the primary grid.
  • Diodes: Draw an equilateral triangle pointing toward the cathode line. The cathode line should be identical in width to the triangle's base.

4. Position Connection Leads (Terminals)

Connection points must adhere to the schematic pitch to enable functional wiring.

  1. Extend terminal lines outward from the component body so the end of each lead lands precisely on a major grid line (e.g., 0.1 inch / 2.54 mm boundaries).
  2. Keep standard terminal lead lengths uniform across all symbols (typically 5.08 mm / 0.2 inches).
  3. Do not place connection points at arbitrary angles; leads must exit horizontally or vertically.

5. Add IEEE-Compliant Reference Labels

Reference designators (such as R1, C1, or U1) require consistent typography and placement.

  1. Select the Text tool (T) and choose a standard, legible sans-serif font such as Arial, Helvetica, or Liberation Sans.
  2. Set text size proportionally, typically between 8 pt and 10 pt.
  3. Position reference designators above or to the left of the symbol, and component values below or to the right, maintaining a clearance of at least 1.27 mm (0.05 in) from the body.

6. Group and Save as a Symbol Library

Convert individual drawings into reusable assets.

  1. Select all paths, strokes, and terminals belonging to a single component.
  2. Group them by pressing Ctrl+G.
  3. Open the Symbols panel (Object > Symbols or Ctrl+Shift+Y).
  4. Select your grouped component, click Add Symbol from current document in the Symbols panel, and assign a standardized title (e.g., IEEE_315_Resistor).
  5. Save the file in your Inkscape user configuration directory under the symbols folder as an .svg file. The library will now be accessible directly from the Symbols dropdown menu in future projects.
