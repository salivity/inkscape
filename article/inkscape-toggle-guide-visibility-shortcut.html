Inkscape Toggle Guide Visibility Shortcut

Managing visual aids efficiently speeds up vector design workflows. This guide covers the exact keyboard shortcut used to toggle guide line visibility on and off in Inkscape, how to locate the toggle option through the application menu, and a few essential tips for managing your canvas guides effectively.

The Keyboard Shortcut

In Inkscape, the default keyboard shortcut to toggle guide visibility on and off is Shift + | (the pipe symbol, typically typed using *Shift + * on standard QWERTY keyboards).

Pressing this combination instantly hides all active guide lines on your canvas without deleting them. Pressing the combination again restores their visibility.

Using the Application Menu

If you prefer using the mouse or want to confirm the shortcut for your specific keyboard layout, you can toggle guides via the main menu:

  1. Click on View in the top menu bar.
  2. Select Guides from the dropdown list.

A checkmark next to "Guides" indicates that they are currently visible. Clicking the option toggles the state.

Useful Tips for Working with Guides

  • Creating Guides: Click and drag from either the horizontal or vertical ruler into the canvas to place a new guide.
  • Locking Guides: To prevent accidentally moving guides while working, toggle the lock feature by clicking the small padlock icon in the corner where the rulers intersect, or go to File > Document Properties > Guides and select Lock all guides.
  • Deleting Guides: If you want to remove a guide permanently instead of hiding it, hover your cursor over the guide until it turns red, then press the Delete key, or drag the guide back into the ruler.
