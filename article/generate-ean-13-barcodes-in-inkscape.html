Generate EAN-13 Barcodes in Inkscape

Inkscape includes a built-in barcode rendering tool that allows you to create precise, scalable vector EAN-13 retail barcodes directly inside your document. This guide covers how to access the native barcode extension, enter your numeric sequence, configure layout settings, and ensure the human-readable text displays the full 13 digits—including the calculated check digit—for retail compliance.

1. Open the Barcode Generator

  1. Open your document in Inkscape.
  2. Navigate to the top menu and select Extensions.
  3. Hover over Render, then Barcode.
  4. Select Classic Barcode (or Barcode depending on your Inkscape version).

2. Configure EAN-13 Parameters

In the barcode generator window:

  1. Barcode Type: Select EAN-13 from the dropdown menu.
  2. Barcode Data: Enter the 12-digit base code of your product.
    • Note on Check Digits: EAN-13 consists of 12 data digits plus a 13th modulo-10 check digit. Inkscape automatically computes and appends the correct check digit even if you only supply the first 12 digits. If you enter all 13 digits, ensure the 13th digit is correct, or Inkscape will return an error or overwrite it with the valid check digit.

3. Ensure Human-Readable Text Is Visible

Standard retail barcodes require the numbers to appear beneath the bars for manual entry if the scanner fails:

  1. Locate the Text or Human-Readable Text option within the tool interface.
  2. Ensure the option to include text is enabled.
  3. In Inkscape's standard EAN-13 renderer, human-readable numbers are formatted automatically according to the GS1 specification:
    • 1 leading digit placed outside to the far left.
    • 6 digits beneath the left bar guard.
    • 6 digits (including the final check digit) beneath the right bar guard.

4. Adjust Dimensions and Sizing

Before rendering, configure the visual scale according to standard retail sizing requirements:

  • Bar Height: Set the bar height (the standard nominal height is 22.85 mm).
  • Bar Width / Module Width: Set the scale factor. The nominal X-dimension (width of the narrowest bar) for EAN-13 is 0.33 mm.
  • Quiet Zone: Ensure there is enough margin on both sides to allow barcode scanners to distinguish the start and end patterns.

5. Render and Position the Barcode

  1. Click Apply to generate the barcode vector object on the canvas.
  2. Click Close to exit the extension panel.
  3. The generated barcode is rendered as a grouped vector element. If you need to scale the barcode on your canvas, hold Ctrl to maintain aspect ratio, ensuring the bar widths do not distort relative to one another.
