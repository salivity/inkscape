How to Add Divider Slots in Inkscape Box Maker

This article explains how to design internal divider slots for laser-cut tabbed enclosure boxes using Inkscape and the Box Maker extension. While the standard Box Maker tool creates the outer notched panels of a box, adding internal dividers requires creating matching rectangular cutouts in the enclosure walls and designing interlocking partition pieces. Following this workflow allows you to accurately measure, align, and cut interlocking compartments for any custom enclosure.

Step 1: Generate the Outer Box

  1. Open Inkscape and navigate to Extensions > Render > Box Maker (or your preferred laser box extension).
  2. Enter your desired external dimensions: width, height, and depth.
  3. Set your exact Material Thickness and Kerf.
  4. Set the tab width to your preferred finger-joint size.
  5. Click Apply to generate the six sides of the enclosure on your canvas.
  6. Select the generated box parts, go to Object > Ungroup, and identify the interior walls (such as the front, back, left, right, and bottom panels) where the dividers will attach.

Step 2: Calculate Divider Dimensions

The interior partitions must fit the inside clearances of the enclosure, not the exterior measurements.

  • Inside Dimension: Calculate the internal space by subtracting twice the material thickness from the total outer dimension (e.g., \(\text{Inside Width} = \text{Outer Width} - [2 \times \text{Material Thickness}]\)).
  • Divider Height: The height of the divider should match the internal height of the box if the lid sits flat against it.

Step 3: Create the Slots on the Box Walls

  1. Select the Rectangle Tool (\(R\)).
  2. Draw a rectangle that will serve as the slot.
    • Set the width to your material thickness.
    • Set the height to the desired tab length (for example, 10 mm to 15 mm).
  3. Open the Align and Distribute panel (Shift + Ctrl + A).
  4. Place the slot rectangle over the box panel where you want the partition to sit.
  5. Use the alignment tools to center the slot horizontally or distribute multiple slots evenly across the face.
  6. Select both the wall panel and the slot rectangle.
  7. Go to Path > Difference (Ctrl + -) to cut the slot directly out of the panel. Repeat this for the opposite wall panel and the bottom plate if you want bottom-anchored dividers.

Step 4: Design the Divider Panels

  1. Draw a rectangle matching the calculated internal width and height of the box.
  2. If your dividers insert directly into the slots you created in Step 3, draw matching tabs on the edges of the divider with the same dimensions as the slots.
  3. Align the tabs to the outer edges of the divider plate using Align and Distribute.
  4. Select the divider body and the tabs, then merge them using Path > Union (Ctrl + +).

Step 5: Create Intersecting Cross-Dividers (Egg-Crate Joints)

If your box requires a grid of crossing dividers:

  1. Draw a vertical slot in the center of each divider panel where the perpendicular partition will cross.
  2. Set the slot width equal to the material thickness (adjusted slightly for kerf fit).
  3. Set the slot height to exactly half the total height of the divider panel.
  4. On one divider, cut the slot from the top edge downward (Path > Difference).
  5. On the intersecting divider, cut the slot from the bottom edge upward.
  6. These two half-lap slots will slide into each other to form a rigid internal grid.

Step 6: Final Preparation for Cutting

  1. Set the stroke width for all cut lines to your laser cutter’s required hairline thickness (commonly 0.001 inches or 0.02 mm).
  2. Set the stroke color to your machine's designated cutting color (typically pure red, #FF0000).
  3. Ensure all fills are removed.
  4. Save the file as an SVG or export it to DXF/PDF format for laser cutting.
