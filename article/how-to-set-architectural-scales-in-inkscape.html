How to Set Architectural Scales in Inkscape

Setting custom scale factors such as 1:50 or 1:100 in Inkscape allows you to create accurate architectural floor plans, elevations, and technical diagrams directly within a vector workspace. This guide outlines how to configure your document scale in Document Properties, calibrate the Measurement Tool for real-world dimensions, set up scaled snapping grids, and verify your drawing dimensions for accurate export and printing.

1. Configure the Document Scale

Inkscape defines scale as the relationship between user units (internal SVG coordinates) and display units (real-world printed units such as millimeters or inches).

  1. Open Inkscape and navigate to File > Document Properties (or press Ctrl + Shift + D).
  2. In the Page tab, set Display units to your preferred physical measurement, such as mm or cm.
  3. Locate the Scale section in the same tab:
    • For a 1:100 Scale (Metric): If your target display unit is millimeters (mm) and you want 1 mm on paper to equal 100 mm in reality, set Scale x to 0.01 (or 1.0 if drawing 1:1 to standard sheet sizes and scaling output). If drawing directly in real-world meters where 1 meter equals 10 mm on paper (1:100), adjust the scale factor so 1 user unit matches your working increment.
    • For a 1:50 Scale (Metric): Set Scale x to 0.02 (where 1 mm on the page represents 50 mm in real space).
  4. Close the Document Properties dialog to apply the scale globally to the canvas.

2. Calibrate the Measurement Tool

The Measurement Tool allows you to inspect distances on your canvas and display them in real-world architectural values.

  1. Select the Measurement Tool from the left toolbar (or press M).
  2. Look at the tool controls bar at the top of the window:
    • Set Units to m (meters) or mm (millimeters).
    • Adjust the Scale % field:
      • For 1:100, set the scale to 10000% (or enter 100 depending on your base document unit).
      • For 1:50, set the scale to 5000% (or 50).
  3. Click and drag across any object or line on your canvas to measure distances directly in full-scale architectural dimensions.

3. Set Up an Architectural Grid

Using an architectural grid ensures objects snap to exact structural increments (e.g., wall thicknesses, column grids, or module widths).

  1. Open File > Document Properties and switch to the Grids tab.
  2. Select Rectangular grid from the dropdown and click New.
  3. Set Grid units to mm or m.
  4. Define your spacing based on your scale:
    • 1:100 Scale: Set Spacing X and Spacing Y to 10 mm (representing 1 meter in real-world space).
    • 1:50 Scale: Set Spacing X and Spacing Y to 20 mm (representing 1 meter in real-world space).
  5. Set Major grid line every to 5 or 10 to visually group modular intervals.

4. Add Dimension Lines

To annotate dimensions directly on the drawing:

  1. Select the path or wall segment you want to label.
  2. Go to Extensions > Visualize Path > Dimensions.
  3. In the dialog, choose your desired dimension format, offset distance, and unit representation.
  4. Set the Scaling factor to match your drawing scale (50 for 1:50, 100 for 1:100) so the generated text displays the true real-world dimension.
  5. Click Apply.

5. Exporting at the Correct Ratio

When exporting your drawing to PDF for printing:

  1. Go to File > Save As... and select Portable Document Format (*.pdf).
  2. Ensure Page size matches your target paper size (e.g., A3, A2, A1).
  3. Print the resulting PDF at 100% scale (Actual Size / Do Not Scale) in your PDF viewer to maintain exact 1:50 or 1:100 proportions on paper.
