Export Inkscape to GIMP XCF with Layers

Exporting vector designs from Inkscape directly to GIMP's native XCF format while preserving your layer stack allows you to transition smoothly from vector illustration to raster editing. This guide covers how to organize your artwork, access Inkscape's built-in XCF export utility, and configure your export settings so that each vector layer is rasterized into an individual, editable layer inside GIMP.

Step 1: Organize Your Artwork into Layers

Inkscape only exports elements as separate GIMP layers if they are placed in distinct layers within Inkscape. Sub-groups or unassigned objects on a single layer will be flattened together during export.

  1. Open the Layers and Objects panel by navigating to Layer > Layers and Objects (or pressing Ctrl + Shift + L).
  2. Create dedicated layers for each component you want separated in GIMP (e.g., Background, Lineart, Shading).
  3. Move your vector paths, shapes, and groups into their respective layers.
  4. Rename each layer descriptively; these names will carry over directly into GIMP.

Step 2: Use the Save As Dialog

Inkscape includes an internal script capable of converting vector layers directly into a GIMP XCF file.

  1. Click File in the top menu and choose Save As... or Save a Copy... (Ctrl + Shift + S).
  2. In the file browser, click the Save as type dropdown menu.
  3. Scroll through the list and select GIMP XCF 32-bit (*.xcf).
  4. Choose your destination directory, enter your desired file name, and click Save.

Step 3: Configure the XCF Export Options

Once you click save, an export dialog box will appear with specific settings for the conversion process:

  • Save hidden layers: Toggle this option depending on whether you want hidden Inkscape layers included in the final GIMP file.
  • Save background: Check this to preserve the background defined in your Document Properties. If you need a transparent canvas, leave this unchecked.
  • Resolution (DPI): Set the DPI for rasterization. Vector shapes must be converted to pixels when entering GIMP. A value of 300 DPI is recommended for high-resolution print work, while 96 DPI or 72 DPI is standard for web and screen use.

Click OK to process the export. Inkscape will generate the .xcf file.

Step 4: Open and Verify in GIMP

  1. Launch GIMP and open the newly created .xcf file via File > Open.
  2. Check the Layers panel (Ctrl + L).
  3. Each Inkscape layer should now appear as an individual raster layer maintaining its original name, position, transparency, and blend order.

Alternative Method: Layered PSD Export

If the direct XCF option is absent in your specific build of Inkscape:

  1. Go to File > Export... and set the format to Photoshop PSD (*.psd).
  2. Ensure the export option is set to retain layers.
  3. Open the resulting .psd file in GIMP, then navigate to File > Save As... to save it natively as a layered .xcf.
