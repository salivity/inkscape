How to Apply Hex Color Codes in Inkscape

Applying an existing RGB hex color code directly to an object's fill in Inkscape ensures accurate color matching across your vector design projects. This guide covers how to open the Fill and Stroke panel, locate the direct color input field, and correctly paste or enter your hex code to update your artwork instantly.

Step 1: Select Your Object

Using the Select and Transform objects tool (shortcut S or F1), click on the vector shape, text, or path whose fill color you want to change.

Step 2: Open the Fill and Stroke Panel

Open the color management menu using one of the following methods:

  • Go to the top menu bar and select Object > Fill and Stroke...
  • Press the keyboard shortcut Ctrl + Shift + F on Windows and Linux, or Cmd + Shift + F on macOS.
  • Click the Fill and Stroke icon in the command bar on the right side of the window.

Step 3: Enable Solid Fill

Within the panel on the right:

  1. Click on the Fill tab.
  2. Ensure the fill mode is set to a solid color by clicking the Flat color icon (the solid square directly next to the "No paint" X icon).

Step 4: Enter the Hex Code in the RGBA Field

Look at the bottom of the Fill tab for the RGBA: text input box. Inkscape uses an 8-character hexadecimal value where the first six characters represent the red, green, and blue channels, and the final two characters represent the alpha (opacity) level.

  1. Highlight the existing code inside the RGBA: box.
  2. Paste or type your 6-digit hex code (without the # symbol).
  3. Append ff to the end of your 6-digit code if you want 100% opacity. For example, if your hex code is 3498DB, enter 3498DBff.
  4. Press Enter on your keyboard to apply the color.

The selected object will immediately update to match the exact RGB color specified by your code.
