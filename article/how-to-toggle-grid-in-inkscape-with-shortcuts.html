How to Toggle Grid in Inkscape with Shortcuts

Working with grids in Inkscape is essential for creating precise, aligned vector graphics. This guide explains the primary keyboard shortcut used to instantly show or hide the canvas grid, along with menu navigation options and quick setup steps if a grid is not appearing.

The Keyboard Shortcut

To toggle grid visibility on and off in Inkscape, press:

  • # (On standard US keyboards, press Shift + 3)

Pressing this shortcut will immediately display the default grid if it is hidden, or hide it if it is currently visible.

Menu Alternative

If you prefer using mouse navigation or want to confirm the shortcut for your specific keyboard layout:

  1. Click View in the top menu bar.
  2. Click Page Grid (or Grid depending on your Inkscape version) to toggle the display.

What to Do If No Grid Appears

If pressing the shortcut does not display a grid, your document may not have an active grid configured:

  1. Open document settings by pressing Ctrl + Shift + D (or go to File > Document Properties).
  2. Select the Grids tab.
  3. Choose your grid type (Rectangular or Axonometric) and click New.
  4. Close the window. You can now use # to toggle the newly created grid anytime.
