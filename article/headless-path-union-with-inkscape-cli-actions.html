Headless Path Union with Inkscape CLI Actions

This guide explains how to perform a headless vector path union operation using the Inkscape command-line interface (CLI). Modern versions of Inkscape (version 1.0 and later) support a robust action-based system that allows you to automate geometric operations, such as combining multiple paths, completely in the background without launching the graphical user interface.

Prerequisites

Ensure you have Inkscape 1.0 or newer installed. You can verify your version by running:

inkscape --version

The Basic Command Structure

Headless processing in Inkscape relies on two primary arguments:

  • --batch-process: Tells Inkscape to execute the actions and exit immediately without opening the GUI.
  • --actions: A semicolon-separated string of commands executed sequentially.

Unifying All Paths in an SVG

If your SVG file only contains the paths you want to merge, use select-all:paths followed by path-union:

inkscape input.svg --batch-process --actions="select-all:paths;path-union;export-filename:output.svg;export-do"

Unifying Specific Paths by ID

If your file contains other elements that should not be merged, select specific elements by their SVG id attributes using select-by-id:

inkscape input.svg --batch-process --actions="select-by-id:path1,path2;path-union;export-filename:output.svg;export-do"

Handling Basic Shapes (Rectangles, Circles)

The path-union action strictly operates on vector path elements (<path>). If your input file contains primitive shapes (such as <rect>, <circle>, or <polygon>), you must convert them to paths using object-to-path before executing the union:

inkscape input.svg --batch-process --actions="select-all;object-to-path;path-union;export-filename:output.svg;export-do"

Action Sequence Breakdown

  • select-all:paths or select-by-id:<id1>,<id2>: Defines the target elements for subsequent operations.
  • object-to-path: (Optional) Converts primitive SVG shapes into standard Bézier paths.
  • path-union: Merges selected overlapping or adjacent paths into a single combined path (equivalent to pressing Ctrl + + in the GUI).
  • export-filename:output.svg: Sets the output target destination.
  • export-do: Commits and writes the exported file to disk.
