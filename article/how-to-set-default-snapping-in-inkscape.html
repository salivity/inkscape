How to Set Default Snapping in Inkscape

In Inkscape, snapping parameters are tied directly to individual document settings rather than a standalone global toggle. To set global default snapping parameters for all new projects, you must configure your desired snapping options within an empty document and save it as your custom default template. This guide outlines the exact steps to customize your snapping behavior and make those settings permanent for future documents.

Step 1: Open a Blank Document

Launch Inkscape or create a fresh document by going to File > New (or pressing Ctrl + N on Windows/Linux, Cmd + N on macOS).

Step 2: Configure Your Desired Snapping Rules

  1. Locate the Snapping controls on the top right of the application window.
  2. Toggle the main Enable Snapping button on (% key).
  3. Click the arrow next to the snapping icon to open the snapping popover menu.
  4. Switch to Advanced Mode if you need fine-tuned control over specific snap targets.
  5. Enable or disable the individual snapping targets you want as your standard baseline, such as:
    • Bounding Boxes: Edges, corners, and midpoints.
    • Nodes: Cusp nodes, smooth nodes, and line midpoints.
    • Alignment: Snapping to other objects, guide lines, and page borders.

Step 3: Adjust Global Snapping Thresholds (Optional)

To modify general snap sensitivity:

  1. Go to Edit > Preferences (or press Shift + Ctrl + P / Shift + Cmd + P).
  2. In the left panel, navigate to Behavior > Snapping.
  3. Adjust the Snap distance (in screen pixels) or snapping weight preferences to fit your workflow.
  4. Close the Preferences window.

Step 4: Save as the Default Template

To ensure every new document opens with these exact parameters:

  1. Go to File > Save Template...
  2. In the dialog box, assign a name (e.g., My Default).
  3. Check the box labeled Set as default template.
  4. Click Save.

Step 5: Test the Configuration

Press Ctrl + N (or Cmd + N) to generate a new document. The new project will automatically load with your specified snapping targets and tolerances pre-configured.
