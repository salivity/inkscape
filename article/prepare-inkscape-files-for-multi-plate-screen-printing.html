Prepare Inkscape Files for Multi-Plate Screen Printing

Preparing vector artwork for multi-plate screen printing in Inkscape requires separating your design by ink color, applying trapping to prevent alignment gaps, adding registration marks for press setup, and converting all artwork to solid black for film positive output. Following this workflow ensures that each color layer cleanly exposes onto its corresponding screen mesh, resulting in precise color registration on the press.

Step 1: Organize Artwork by Color Layers

  1. Open your final vector artwork in Inkscape.
  2. Open the Layers and Objects panel (Ctrl + Shift + L).
  3. Create a new layer for every distinct ink color in your design (for example: Underbase White, Yellow, Red, Black).
  4. Select all vector paths corresponding to a specific color, right-click, and choose Move to Layer, then select the appropriate color layer.
  5. Ensure all text is converted to paths by selecting the text and choosing Path > Object to Path (Ctrl + Shift + C).

Step 2: Apply Trapping (Choke and Spread)

Screen printing presses experience slight paper or garment shifting. Trapping creates a tiny overlap between adjacent colors to prevent white gaps.

  1. Identify the lighter color adjacent to a darker color.
  2. Duplicate the lighter path (Ctrl + D).
  3. Apply a slight spread to the duplicate by selecting Path > Outset (Ctrl + )). For fine adjustments, set the outset step in Edit > Preferences > Behavior > Steps.
  4. Alternatively, apply a small stroke (e.g., 0.5 pt to 1 pt) in the same color to create an expansion beneath the darker overlapping layer.

Step 3: Add Universal Registration Marks

Registration marks allow the printer to align each screen precisely.

  1. Create a new top layer named Registration.
  2. Draw a small circle intersected by a crosshair outside the printable design area (top, bottom, left, and right margins).
  3. Group the registration mark components together.
  4. Ensure these marks remain identical and in the exact same coordinates on every single separation.

Step 4: Convert All Artwork to 100% Solid Black

Film positives block UV light during the screen exposure process. Regardless of the final ink color, every separated plate must be printed in pure, opaque black.

  1. Unlock and select all paths on a single color layer.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Set the Fill and Stroke colors to 100% Black (#000000 / CMYK: 0, 0, 0, 100).
  4. Ensure all transparencies and opacities are set to 100%. Repeat this step for every color layer and the registration marks.

Step 5: Export Individual Film Positives

  1. Make only the Registration layer and one specific color layer visible by toggling the eye icons in the Layers and Objects panel (hide all other color layers).
  2. Go to File > Save As... or File > Export....
  3. Choose PDF or high-resolution PNG (at least 300 to 600 DPI) as the output format.
  4. Save the file with a clear naming convention indicating the color and print order (e.g., Design_Plate_01_Underbase.pdf, Design_Plate_02_Yellow.pdf).
  5. Repeat this visibility toggle and export process for each individual layer.
