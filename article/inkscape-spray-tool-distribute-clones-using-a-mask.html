Inkscape Spray Tool: Distribute Clones Using a Mask

Inkscape’s Spray tool features a background-tracing function that allows you to distribute clones of an object according to the brightness, opacity, or color values of an underlying mask or image. This guide explains how to prepare your artwork, configure the Spray tool's tracing parameters, and scatter clones precisely over designated areas of a canvas.

1. Prepare the Mask and the Source Object

  1. Create or import the mask: Place the image or vector shape that will act as your distribution mask on the canvas. High-contrast shapes (such as black-and-white gradients or silhouettes) yield the most predictable results.
  2. Create the source object: Draw or select the object you want to clone and spray across the mask.
  3. Select the source object: Use the Select Tool (S) to select only the source object, leaving the mask unselected on the canvas.

2. Activate and Configure the Spray Tool

  1. Switch to the Spray Tool by pressing A or Shift + F3.
  2. On the top Tool Controls bar, set the spray mode to Spray clones of the initial selection (the icon showing multiple shapes connected to a parent).
  3. Adjust the core parameters:
    • Width: Sets the radius of the spray brush.
    • Amount: Controls the number of clones created per spray tick.
    • Rotation / Scale: Add variation to individual clones if desired.

3. Enable Background Tracing

  1. Look for the Trace the background toggle icon (a small dropper/eye over a grid) on the far right of the Spray Tool Controls bar and turn it on.
  2. Click the settings icon or dropdown next to the trace option to define how Inkscape reads the underlying mask:
    • Value/Luminance: Places clones primarily on brighter (or darker, if inverted) regions of the mask.
    • Opacity: Uses transparency levels to control where clones appear.
    • Color Channels (R, G, B): Restricts placement based on specific color channels.
  3. Configure whether the trace affects Presence (distribution density), Size, or Color of the sprayed clones. Ensure the option controlling clone distribution/presence is enabled.

4. Spray Across the Mask

  1. Hover your cursor over the mask area on the canvas.
  2. Click and drag to spray. Clones will automatically adhere to the rules set by your mask—appearing densely over target values and sparsely or not at all over excluded areas.
  3. Release the mouse button once the desired coverage is achieved.

Because the sprayed objects are linked clones, any modifications made to the original source object (such as fill color, stroke, or path edits) will automatically update across all distributed clones.
