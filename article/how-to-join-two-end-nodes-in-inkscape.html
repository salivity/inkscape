How to Join Two End Nodes in Inkscape

Closing an open path by joining its end nodes is an essential vector editing technique in Inkscape. This process allows you to turn open lines into closed shapes suitable for fills, Boolean operations, or clean exporting. You can easily connect two separate end nodes into a single continuous path using the Node tool and the Node tool control bar.

Method 1: Join Nodes with a New Segment

Use this method if you want to keep both nodes in their current positions and draw a new line segment between them.

  1. Select the Edit paths by nodes tool from the left toolbar, or press N on your keyboard.
  2. Click on the open path to reveal its nodes.
  3. Select the two end nodes you want to connect. You can do this by holding Shift and clicking each node, or by clicking and dragging a selection box around both.
  4. On the top toolbar (Node tool controls), click the Join selected endnodes with a new segment icon.

Inkscape will create a straight line segment connecting the two endpoints, successfully closing the path.

Method 2: Merge Two Nodes into One

Use this method if you want to pull the two end nodes together and fuse them into a single unified node at the midpoint.

  1. Select the Edit paths by nodes tool (N).
  2. Click the path to display the nodes.
  3. Select both end nodes using Shift + Click or by dragging a selection box over them.
  4. On the top toolbar, click the Join selected nodes icon, or press Shift + J.

The two endpoints will merge into a single node, closing the open gap.

Quick Tip for Overlapping End Nodes

If the two endpoints are already sitting on top of each other:

  1. Select the Node tool (N).
  2. Drag a selection box over the overlapping spot to select both nodes simultaneously.
  3. Press Shift + J to merge them instantly into a single closed corner.
