Convert Linear Gradient to Mesh Gradient in Inkscape

This guide explains how to transform a standard linear gradient into a complex, multi-node mesh gradient in Inkscape. By transitioning your fill type and leveraging Inkscape's dedicated Mesh Tool, you can take the baseline colors of an existing linear gradient and subdivide them into a customizable grid of rows, columns, and color-manipulating nodes for advanced vector shading.

Step 1: Select the Object with the Linear Gradient

  1. Choose the Select and transform objects tool (shortcut: S or F1).
  2. Click on the vector shape containing the linear gradient you want to convert.
  3. Open the Fill and Stroke panel by pressing Shift + Ctrl + F (or navigating to Object > Fill and Stroke).

Step 2: Switch the Fill to a Mesh Gradient

  1. In the Fill and Stroke panel, ensure the Fill tab is active.
  2. In the row of fill type icons (Flat color, Linear gradient, Radial gradient, etc.), locate and click the Mesh gradient icon.
  3. Inkscape will immediately convert your active linear gradient into a basic, single-patch mesh gradient while retaining your initial linear color stops along the boundary.

Step 3: Activate the Mesh Tool

  1. Select the Create and edit meshes tool from the left-hand toolbar (shortcut: X).
  2. With the object selected, the mesh grid, corner nodes, and control handles will become visible over your artwork.

Step 4: Add Nodes to Create a Multi-Node Mesh

A default converted mesh starts as a simple 1x1 patch (four corner nodes). To make it a multi-node mesh:

  • Add a row or column: Double-click directly on any existing grid line or bounding edge of the mesh where you want to insert a new division. Double-clicking a horizontal line inserts a vertical column of nodes; double-clicking a vertical line inserts a horizontal row of nodes.
  • Pre-set divisions: Alternatively, before creating a new mesh with the Mesh Tool, you can define the number of Rows and Columns directly in the top Tool Controls bar to establish a dense multi-node grid automatically.

Step 5: Adjust Nodes and Colors

  1. Click on any individual node inside the mesh grid to select it.
  2. Choose a new color from the color palette at the bottom of the screen to change the color radiating from that specific node.
  3. Click and drag nodes to reshape the flow of the gradient.
  4. Use the bezier handles attached to each mesh line to curve the gradient lines, giving your object three-dimensional curvature and organic transitions.
