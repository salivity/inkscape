How to Use Lattice Deform 2 in Inkscape

This guide explains how to apply and manipulate the Lattice Deform 2 Live Path Effect (LPE) in Inkscape. You will learn how to convert your vector elements, apply the deformation grid, adjust lattice settings, and drag control nodes to achieve complex, non-destructive vector warping and perspective distortions.

1. Prepare Your Vector Artwork

Lattice Deform 2 works on path elements. If you are working with text or basic geometric shapes (such as rectangles, circles, or stars), convert them into paths first:

  1. Select the object using the Select Tool (S).
  2. Navigate to the top menu and select Path > Object to Path (Shift + Ctrl + C).
  3. If you have multiple objects, combine them into a single path (Path > Combine) or group them (Object > Group).

2. Open the Path Effects Dialog

  1. Select your target object or group.
  2. Go to Path > Path Effects in the top menu to open the Path Effects panel on the right side of the workspace.

3. Add Lattice Deform 2

  1. In the Path Effects panel, click the Add Path Effect button (represented by a + icon).
  2. Use the search bar to locate Lattice Deform 2 and click to apply it to your selected object.

4. Configure the Lattice Grid

Once applied, the Path Effects panel will display configuration options for your lattice:

  • Horizontal / Vertical Grid Points: Set the number of rows and columns to control how many manipulation points appear on your grid. A higher number provides finer control over localized distortions, while a lower number creates broader, smoother bends.
  • Live Update: Ensure this is enabled to see real-time changes on your canvas as you move nodes.

5. Deform the Vector Object

  1. Switch to the Node Tool (N) from the left toolbar.
  2. An editable bounding grid will appear over your object, containing anchor points and control handles.
  3. Click and drag the node points along the grid perimeter or interior intersections to bend, stretch, perspective-warp, or squeeze the underlying vector graphic.
  4. Adjust the tangent handles attached to individual grid nodes to control the curvature of the distortion.

6. Finalize the Distortion (Optional)

Because Lattice Deform 2 is a non-destructive Live Path Effect, you can continue to modify the grid at any time. If you want to permanently bake the distorted shape into standard vector paths (for exporting or standard node editing):

  1. Select the distorted object.
  2. Go to Path > Object to Path.

The lattice grid will be removed, leaving behind the final deformed vector geometry.
