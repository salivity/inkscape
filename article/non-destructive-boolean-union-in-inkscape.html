Non-Destructive Boolean Union in Inkscape

This guide explains how to use Inkscape's Boolean Operations Live Path Effect (LPE) to combine shapes non-destructively. Unlike standard path operations that permanently merge vectors into a single path, the Boolean Operations LPE preserves the original shapes, allowing you to reposition, resize, or alter individual nodes at any time while viewing a real-time union result.

1. Prepare Your Shapes

  1. Create the two vector shapes you want to combine on the canvas.
  2. Ensure both shapes are paths. If you are using shape primitives (such as Rectangles, Circles, or Stars), select them and convert them by navigating to Path > Object to Path (or press Shift + Ctrl + C).

2. Copy the Secondary Path

The Boolean Operations LPE uses one path as the base object and links to another path as the operand.

  1. Select the shape that will act as the secondary object (the path you want to add to the base).
  2. Copy it to your clipboard by pressing Ctrl + C (or Cmd + C on macOS).

3. Apply the Boolean Operation LPE

  1. Select the primary (base) shape.
  2. Open the Path Effects panel by navigating to Path > Path Effects.
  3. Click the Add Path Effect button (the + icon).
  4. In the search box, type Boolean operation and select it from the list.

4. Configure the Effect to Union

  1. In the Path Effects dialog under Boolean operation, locate the Operation dropdown.
  2. Select Union from the list of operations.
  3. Under the Operand section, click the Paste path icon (clipboard symbol). Inkscape will apply the path copied in Step 2 to the base path, instantly generating a unified shape.
  4. You can now hide or delete the original secondary shape from the canvas, as the LPE maintains an independent copy of its path data.

5. Edit the Non-Destructive Union

Because the operation is dynamic, you can modify either component at any point:

  • Edit the Base Shape: Select the combined object and switch to the Node Tool (N). You will see the original nodes of the base shape and can manipulate them directly.
  • Edit the Operand Shape: In the Path Effects panel under the Boolean operation settings, click the Edit on-canvas button next to the Operand. Canvas handles will appear, allowing you to move, rotate, scale, or node-edit the secondary shape independently.

6. Make the Union Permanent (Optional)

If you finalize your design and no longer need non-destructive flexibility, select the combined object and go to Path > Object to Path. This bakes the Live Path Effect into a standard, single vector outline and removes the LPE controls.
