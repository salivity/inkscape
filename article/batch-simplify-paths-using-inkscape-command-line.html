Batch Simplify Paths Using Inkscape Command Line

This guide explains how to automate the path simplification process on hundreds of SVG files using Inkscape’s command-line interface (CLI). By leveraging Inkscape’s action commands combined with shell scripting in Linux, macOS, or Windows, you can batch process an entire directory of vector files without opening the graphical user interface.

Prerequisites

Ensure you are using Inkscape 1.0 or newer, as modern versions support the --actions parameter required for headless scripting. Verify that inkscape is added to your system's PATH variable so it can be called directly from your terminal or command prompt.

Always back up your files before running batch commands that overwrite original data.

The Core Inkscape Action Command

Inkscape executes operations sequentially using the --actions argument. To simplify paths in a single file, you select the elements, apply the simplify command, and save the result:

inkscape --actions="select-all:all;path-simplify;export-overwrite" input.svg
  • select-all:all: Selects all objects and paths across all layers.
  • path-simplify: Executes the same path reduction algorithm found under Path > Simplify in the GUI.
  • export-overwrite: Saves the modified vectors directly back to the source file.

If you prefer to keep the original files and export the simplified versions to a separate folder, replace export-overwrite with the export target:

inkscape --actions="select-all:all;path-simplify;export-filename:output/input_simplified.svg;export-do" input.svg

Batch Processing on Linux and macOS (Bash)

To process all .svg files inside a directory using Bash:

for file in *.svg; do
    echo "Processing $file..."
    inkscape --actions="select-all:all;path-simplify;export-overwrite" "$file"
done

For large datasets containing hundreds or thousands of files, you can speed up execution by using xargs to process files in parallel:

find . -maxdepth 1 -name "*.svg" -print0 | xargs -0 -P 4 -I {} inkscape --actions="select-all:all;path-simplify;export-overwrite" "{}"

(Note: Adjust -P 4 to match the number of available CPU cores.)

Batch Processing on Windows (PowerShell)

Open PowerShell in the folder containing your SVG files and execute the following loop:

Get-ChildItem -Filter *.svg | ForEach-Object {
    Write-Host "Processing $($_.Name)..."
    & inkscape --actions="select-all:all;path-simplify;export-overwrite" $_.FullName
}

If inkscape is not in your system environment variables, replace inkscape with the full executable path (e.g., & "C:\Program Files\Inkscape\bin\inkscape.exe").

Batch Processing on Windows (Command Prompt)

If using standard Windows Command Prompt (cmd.exe), run this single-line command:

for %f in (*.svg) do inkscape --actions="select-all:all;path-simplify;export-overwrite" "%f"

If writing this inside a .bat script file, double the percent signs (%%f):

@echo off
for %%f in (*.svg) do (
    echo Processing %%f...
    inkscape --actions="select-all:all;path-simplify;export-overwrite" "%%f"
)

Adjusting Simplification Strength

Inkscape's CLI uses the simplification threshold defined in your preferences file (preferences.xml). To apply a stronger simplification pass from the command line, chain multiple path-simplify actions together:

inkscape --actions="select-all:all;path-simplify;path-simplify;export-overwrite" input.svg
