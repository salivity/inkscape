How to Create Conical Gradients in Inkscape

While native SVG standards lack a dedicated conical gradient tag, Inkscape allows you to map a smooth angular sweep gradient around a central origin using a linear gradient combined with polar coordinate transformation. This article outlines the exact procedure for generating a 360-degree angular sweep, transforming it into a circular shape, and refining the gradient stops for clean vector output.

1. Create the Base Strip

  1. Select the Rectangle tool (R) and draw a horizontal rectangle. The width will define the circumference of the final circle, and the height will define the radius.
  2. Convert the rectangle into a path by navigating to Path > Object to Path (Shift + Ctrl + C).
  3. To ensure the shape bends smoothly without geometric distortion, add intermediate nodes: navigate to Extensions > Modify Path > Add Nodes..., set the maximum segment length or number of division nodes (e.g., 20–30 nodes), and click Apply.

2. Apply and Configure the Linear Gradient

  1. Select the Gradient tool (G) and choose the Linear gradient option from the top control bar.
  2. Drag horizontally across the rectangle from the left edge to the right edge.
  3. Define your color stops. The left edge represents 0 degrees (the start of the sweep), and the right edge represents 360 degrees (the end of the sweep).
  4. If you require a seamless transition around the circle, ensure the first and last color stops share the exact same color value.

3. Transform to Polar Coordinates

  1. With the gradient-filled rectangle selected, go to Extensions > Modify Path > Polar Coordinates....
  2. In the settings dialog:
    • Set the Circle percent to 100 to complete a full 360-degree sweep.
    • Check Fill with color if applicable.
    • Check or uncheck Map from top depending on whether you want the center at the top or bottom edge of your original strip.
  3. Click Apply. Inkscape will wrap the horizontal rectangular path into an annular ring, warping the linear color stops into an angular sweep around the center point.

4. Adjust the Sweep Center and Size

  • Create a full circle: If the generated shape has an open hole in the center (an annulus), decrease the inner offset or clip the shape with a circle.
  • Clip to specific dimensions: Draw a regular circle over the transformed shape using the Circle/Ellipse tool (E), position it directly over the sweep's focal point, select both the circle and the gradient shape, and go to Object > Clip > Set Clip.

Alternative: Mesh Gradients for Dynamic Conical Sweeps

For editable, non-destructive conical blends in modern versions of Inkscape:

  1. Select the Mesh tool (M) and set the mode to Normal or Conical in the tool controls bar.
  2. Click on a circle or square to generate a mesh patch.
  3. Drag the outer corner nodes into a circle around the center node.
  4. Select individual mesh corner handles along the perimeter and assign colors to each node sequentially around the central point to produce an angular gradient transition.
