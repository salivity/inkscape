Export to Android Vector Drawable in Inkscape

Exporting vector graphics directly from Inkscape into the Android Vector Drawable (XML) format eliminates the need for intermediate conversion steps in Android Studio. While Inkscape natively saves to standard SVG formats, you can enable direct XML export by adding a dedicated Vector Drawable extension to your Inkscape installation. This guide details how to install the required extension, optimize your vector paths for Android compatibility, and save your assets directly as XML drawables.

1. Install the Android Vector Drawable Extension

Because Inkscape does not include a native Android XML exporter by default, you must install an extension (such as the community-developed inkscape-vector-drawable or svg2vd extension).

  1. Download the extension files (.inx and .py files) from an open-source repository such as GitHub.
  2. Open Inkscape and navigate to Edit > Preferences > System.
  3. Locate the User extensions entry and click the folder icon to open your local extensions directory.
  4. Paste the downloaded .inx and .py files directly into this directory.
  5. Restart Inkscape to load the new export option.

2. Prepare Your Vector Graphic for Android

Android Vector Drawables support a subset of SVG features. To avoid rendering issues in Android applications, sanitize your artwork before exporting:

  • Convert Strokes to Paths: Select all stroked objects and choose Path > Stroke to Path.
  • Convert Text to Shapes: Select any text elements and choose Path > Object to Path.
  • Ungroup Elements: Deeply nested groups can cause transformation bugs. Select everything and repeatedly press Ctrl + Shift + G (or Cmd + Shift + G on macOS) until all elements are ungrouped.
  • Combine Paths: Combine shapes of the same color using Path > Union to minimize the number of distinct path tags in the resulting XML.
  • Remove Unsupported Features: Remove blurs, complex filter effects, and clipping masks, as standard Android Vector Drawables do not render them.
  • Resize Document to Selection: Go to File > Document Properties, expand Resize to content, and click Resize page to drawing or selection to ensure your viewport matches the asset bounds.

3. Export Directly to XML

Once the extension is installed and your paths are optimized:

  1. Click File > Save As (or File > Export depending on the specific extension version installed).
  2. In the "Save as type" dropdown menu, select Android Vector Drawable (*.xml).
  3. Choose your destination directory, name your file using standard Android resource conventions (lowercase letters, numbers, and underscores only), and click Save.

The output file can now be placed directly into an Android project's res/drawable/ directory without additional compilation.
