How Inkscape Calculates Bezier Arc Length

Inkscape determines the arc length of an arbitrary Bézier segment through its core computational geometry engine, lib2geom, using numerical integration via Gauss-Legendre quadrature combined with adaptive subdivision. Because the arc length of cubic and higher-degree Bézier curves cannot be computed using closed-form analytical equations, Inkscape calculates the derivative of the curve and numerically integrates its magnitude (velocity) across the parametric interval to achieve high precision and performance.

The Mathematical Problem

A parametric 2D Bézier curve is defined by coordinate functions \(x(t)\) and \(y(t)\) over the interval \(t \in [0, 1]\). The arc length \(L\) of this curve is given by the standard line integral:

\[L = \int_{0}^{1} \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} \, dt\]

For linear segments, this simplifies to Euclidean distance. For quadratic curves, an analytical solution involving logarithms and square roots exists. However, for cubic Bézier curves—the standard curve type used in Inkscape and SVG—the integrand contains the square root of a quartic polynomial, which produces an incomplete elliptic integral of the second kind. Because closed-form solutions are computationally impractical or nonexistent for arbitrary degrees, Inkscape must rely on approximation algorithms.

Numerical Integration: Gauss-Legendre Quadrature

Inkscape offloads 2D geometric tasks to lib2geom, a C++ library tailored for path manipulation. To compute path length, lib2geom evaluates the derivative of the Bézier curve, \(C'(t) = (x'(t), y'(t))\), which is itself a Bézier curve of degree \(n - 1\). The speed function \(\|C'(t)\| = \sqrt{x'(t)^2 + y'(t)^2}\) is then integrated.

The primary method employed is Gauss-Legendre quadrature. This numerical integration technique approximates the definite integral by evaluating the integrand at predetermined, optimally spaced points (Gauss nodes) and multiplying them by corresponding weights:

\[L \approx \sum_{i=1}^{n} w_i \left\| C'(t_i) \right\|\]

Gauss-Legendre quadrature is favored over uniform sampling rules (such as Simpson's rule or the Trapezoidal rule) because an \(n\)-point Gaussian quadrature yields an exact result for polynomials of degree \(2n - 1\) or less. Although the square root prevents the integrand from being a true polynomial, the smoothness of Bézier curves makes Gauss-Legendre quadrature converge rapidly with relatively few function evaluations.

Adaptive Subdivision and Error Control

When evaluating long segments, high-degree curves, or curves with sharp turns and inflection points, standard fixed-order quadrature can produce precision errors. In these scenarios, lib2geom applies adaptive subdivision:

  1. Flatness and Bounds Testing: The curve's control polygon provides upper and lower bounds. The chord length (the direct distance between endpoints) serves as the minimum possible length, while the sum of the control polygon edges serves as the maximum possible length.
  2. Recursive Splitting: If the curve exhibits high curvature or if the error tolerance between approximations exceeds a specified threshold, the algorithm splits the curve at its midpoint (\(t = 0.5\)) using de Casteljau's algorithm.
  3. Local Quadrature: The numerical quadrature is applied independently to each subsegment, and the partial lengths are summed.

This hybrid approach allows Inkscape to balance computational speed with sub-pixel visual accuracy, providing near-instantaneous length measurements during interactive path editing, stroking, and dashing operations.
