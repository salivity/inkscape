How to Paste in Place in Inkscape

Pasting an object at the exact coordinates of the original copy is an essential workflow technique in vector design. This guide explains how to use Inkscape's built-in "Paste in Place" feature using both menu commands and keyboard shortcuts, allowing you to replicate objects across different layers, pages, or documents without shifting their X and Y positions.

Keyboard Shortcut for Paste in Place

The fastest way to paste an object at the exact coordinates of the original is using a keyboard shortcut:

  • Windows and Linux: Ctrl + Alt + V
  • macOS: Cmd + Option + V

Step-by-Step Instructions:

  1. Select the object you want to copy using the Select tool (S or F1).
  2. Copy the object to your clipboard by pressing Ctrl + C (or Cmd + C on macOS).
  3. If desired, switch to a different layer, page, or open document.
  4. Press Ctrl + Alt + V (or Cmd + Option + V on macOS). The copied object will appear at the exact same coordinates as the original.

Using the Application Menu

If you prefer using the graphical interface:

  1. Select the object and copy it via Edit > Copy (or Ctrl + C / Cmd + C).
  2. Navigate to the target layer or document where you want the object placed.
  3. Open the top menu bar and click Edit.
  4. Select Paste in Place from the dropdown menu.

Duplicate vs. Paste in Place

Inkscape provides two similar tools that serve different purposes:

  • Duplicate (Ctrl + D / Cmd + D): Creates an exact copy directly on top of the original object on the same layer. It does not overwrite your clipboard.
  • Paste in Place (Ctrl + Alt + V / Cmd + Option + V): Takes the object currently stored in your clipboard and places it at its original coordinates on whichever layer, page, or document is currently active.
