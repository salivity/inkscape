Verify Photolithography Mask Clearances in Inkscape

Designing photolithography masks requires strict adherence to minimum feature size and line spacing rules to prevent bridging, light diffraction errors, and fabrication defects. This guide explains how to verify minimum line spacing clearances in Inkscape using document configuration, manual dimension inspection, and automated vector offset checks to identify violations before mask fabrication.

1. Configure Precise Units and Snapping

Before taking measurements, configure Inkscape to display real-world microfabrication units:

  1. Open File > Document Properties (Ctrl+Shift+D).
  2. Under the Display tab, set the Display units to micrometers (µm) or millimeters (mm), depending on your process limits.
  3. Enable snapping via the Snap controls bar on the right side of the canvas. Enable Snap to paths and Snap to path intersections to ensure measurement anchors lock directly onto geometry edges.

2. Manual Verification Using the Measurement Tool

For localized checks across critical regions, use the native Measurement Tool:

  1. Press M or select the Measurement Tool from the left toolbar.
  2. In the top tool controls bar, set the measurement unit to match your layout (µm or mm).
  3. Click and drag the measurement line from the outer edge of one feature to the nearest edge of the adjacent feature.
  4. Read the resulting distance dimension displayed on the canvas. If the distance is less than your photolithography foundry's minimum critical dimension (CD) for spacing, adjust the geometry.

3. Automated Clearance Checking via Stroke Expansion

Manual checks can easily miss subtle violations across complex layouts. Use a stroke expansion technique to globally detect clearance violations:

  1. Select all mask geometry and duplicate it using Ctrl+D.
  2. Group the duplicated geometry using Ctrl+G to keep it isolated from the original design.
  3. Open the Fill and Stroke panel (Ctrl+Shift+F).
  4. Set the Fill to None.
  5. Set the Stroke paint to a high-contrast color (such as red).
  6. Under Stroke style, set the width to precisely match your target minimum clearance value. Set the Join type to Round Join to prevent corner artifacts from skewing spacing.
  7. Inspect the layout: because the stroke expands equally outward by half the width from all edges, any locations where adjacent red strokes touch or overlap indicate a spacing clearance violation.

4. Isolating Violations with Boolean Operations

To definitively isolate and highlight every failure point:

  1. Select your stroked clearance group.
  2. Convert the strokes to filled vector paths via Path > Stroke to Path (Ctrl+Alt+C).
  3. Ungroup the paths via Object > Ungroup (Ctrl+Shift+G).
  4. Select two adjacent clearance paths and apply Path > Intersection (Ctrl+*).
  5. Any remaining closed paths on the canvas represent precise regions where clearance criteria are failed.
