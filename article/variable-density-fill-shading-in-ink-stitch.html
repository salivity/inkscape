Variable-Density Fill Shading in Ink/Stitch

Blending thread colors in Ink/Stitch is achieved through variable-density fill shading, a technique where the stitch spacing gradually increases or decreases across an embroidered area. By creating two overlapping shapes with identical stitch angles and setting opposing density gradients—one fading from dense to sparse, and the other from sparse to dense—the two thread colors physically interlace, resulting in a smooth, professional gradient transition.

Step 1: Prepare the Overlapping Shapes

Create the embroidery boundary in Inkscape where the color blend will occur.

  1. Draw the base shape and select the desired color for your starting thread.
  2. Duplicate the shape (Ctrl + D) in the exact same position and assign it your second thread color.
  3. Organize the layers so the base color stitches first and the overlapping blend color stitches second.

Step 2: Configure the Bottom Layer Gradient

Open the parameters for the bottom shape to establish the fading base layer.

  1. Select the bottom shape.
  2. Navigate to Extensions > Ink/Stitch > Params.
  3. Under the Auto-Fill tab, locate the stitch spacing controls.
  4. Set the initial Stitch Spacing to a standard fill density, typically between 0.4 mm and 0.45 mm.
  5. Enable gradient spacing by entering a larger value for the Ending Stitch Spacing, such as 1.5 mm to 2.5 mm. This spreads the rows apart toward the end of the shape.
  6. Set the Stitch Angle (for example, 0° for horizontal fills) and note this value.
  7. Click Apply and Quit.

Step 3: Configure the Top Layer Gradient

The top shape must reverse the spacing density so its stitches weave into the gaps left by the bottom shape.

  1. Select the top shape and navigate to Extensions > Ink/Stitch > Params.
  2. Set the initial Stitch Spacing to match the loose density of the bottom shape's finish (e.g., 2.0 mm).
  3. Set the Ending Stitch Spacing to standard density (e.g., 0.4 mm).
  4. Set the Stitch Angle to precisely match the bottom layer. Maintaining parallel stitch directions prevents thread buildup and allows the top fibers to drop smoothly between the bottom fibers.
  5. Invert the gradient direction or angle if your version of Ink/Stitch uses a directional vector, ensuring the loose end of the top shape sits directly on top of the loose end of the bottom shape.
  6. Click Apply and Quit.

Step 4: Manage Underlay Settings

Dense underlay can ruin a delicate gradient by pushing threads out of alignment or causing bulk.

  1. Re-open Params for both layers.
  2. Keep a light fill or running stitch underlay on the bottom layer to stabilize the fabric.
  3. Disable the underlay completely on the top layer to allow the loose stitches to lie flat against the bottom layer without unnecessary thread buildup.

Step 5: Simulate and Adjust

  1. Go to Extensions > Ink/Stitch > Visualize and Export > Simulator/Preview.
  2. Observe how the two thread layers interleave across the transition zone.
  3. If the transition looks too abrupt, increase the range between the start and end stitch spacing (e.g., widen the maximum spacing to 3.0 mm). If fabric shows through, reduce the maximum spacing to around 1.2 mm to keep the background completely covered.
