Link Text Flow Across Multiple Shapes in Inkscape

Flowing text across multiple linked shapes in Inkscape allows you to create multi-column layouts, custom text frames, and complex desktop publishing designs directly within a vector workspace. This guide explains the exact steps required to prepare your shapes, select them in the correct sequence, and use the Flow into Frame feature to make a single block of text automatically chain and flow from one container to the next.

Step 1: Create Your Text and Containers

  1. Use the Text tool (T) to type or paste your block of text onto the canvas as regular text.
  2. Use the shape tools (such as Rectangle, Circle, or the Pen tool) to draw the containers you want to hold your text. Place them in your desired layout across the canvas.

Step 2: Select the Elements in Sequence

The order in which you select your shapes determines the sequence of the text flow:

  1. Click on your text object using the Select and Transform objects tool (S).
  2. Hold down the Shift key.
  3. Click on each shape one by one in the exact order you want the text to flow through them (e.g., first column, second column, third column).

Step 3: Apply the Flow into Frame Command

  1. With the text and all target shapes selected, navigate to the top menu.
  2. Select Text > Flow into Frame (or press Alt + W).

The text will instantly enter the first shape and automatically spill over into the subsequent shapes when the previous container fills up.

Editing and Managing Chained Frames

  • Reshaping containers: You can modify the size or path of any container using the Edit paths by nodes tool (N) or the selection handles. The text will dynamically reflow in real time.
  • Adding more shapes: To add another shape to an existing flow, select the flowed text, hold Shift, select the new shape, and run Text > Flow into Frame again.
  • Unflowing text: To revert the flowed text back into standard text, select the text block and navigate to Text > Unflow (or press Alt + Shift + W).
