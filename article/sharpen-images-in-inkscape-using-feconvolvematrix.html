Sharpen Images in Inkscape Using feConvolveMatrix

Inkscape allows you to apply non-destructive image enhancements directly onto raster graphics using its built-in SVG Filter Editor. By adding the feConvolveMatrix filter primitive, you can calculate neighboring pixel weights using a mathematical matrix (kernel) to increase edge contrast and sharpen soft details without relying on external raster editing software.

Step 1: Open the Filter Editor

  1. Import or select the image you wish to sharpen on the canvas.
  2. Go to the top menu and select Filters > Filter Editor.
  3. In the Filter Editor panel, click the New button at the bottom left to create an empty custom filter. You can double-click the name to rename it (e.g., "Sharpen").

Step 2: Add the Convolve Matrix Primitive

  1. In the Add Effect drop-down menu at the bottom of the Filter Editor, locate and select Convolve Matrix.
  2. Click Add Effect.
  3. Ensure the connection line in the editor links the Source Graphic node directly to the input of the feConvolveMatrix effect.

Step 3: Configure the Sharpening Kernel

Select the feConvolveMatrix primitive in the list to reveal its parameters in the lower pane. Adjust the following properties to construct a standard 3x3 edge-enhancement kernel:

  • Order: Enter 3 3 to create a 3-by-3 grid.
  • Kernel Matrix: Enter the matrix values separated by spaces: 
    0 -1  0

-1 5 -1 0 -1 0

*(You can input this as a single line: `0 -1 0 -1 5 -1 0 -1 0`)*
* **Divisor**: Set to `1`. (The sum of the kernel values is `5 - 4 = 1`, which preserves the original image brightness).
* **Bias**: Set to `0`.
* **Target X / Target Y**: Set both to `1` (this targets the center pixel of a zero-indexed 3x3 grid).
* **Edge Mode**: Set to **Duplicate** (replicates boundary pixels) or **Wrap** depending on your image border preference.
* **Preserve Alpha**: Check this box to prevent the sharpening calculation from distorting transparent borders or alpha channels.

### Step 4: Apply the Filter to the Image
1. Ensure your target image is selected on the canvas.
2. Check the box next to your newly created filter in the Filter Editor list.
3. The image on the canvas will update immediately with enhanced edge contrast. 

To increase the sharpening intensity, raise the center value (e.g., center at `9` with `-1` for all surrounding eight values) or layer the effect by chaining additional primitives as needed.
