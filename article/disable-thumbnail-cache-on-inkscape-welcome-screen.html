Disable Thumbnail Cache on Inkscape Welcome Screen

Inkscape generates and stores visual previews of recently opened files to display them directly on the Welcome screen upon startup. While this feature helps users quickly identify previous projects, it can raise privacy concerns, consume disk storage, or cause performance lags on older hardware. This guide provides straightforward instructions to turn off thumbnail caching, adjust recent file visibility in preferences, and clear existing cached preview images from your operating system.

Disabling Document Thumbnails via Preferences

  1. Launch Inkscape.
  2. Open the Preferences window by navigating to Edit > Preferences from the top menu bar (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left-hand category pane, select Interface.
  4. Locate the Recent files or Welcome dialog section in the settings panel.
  5. Uncheck the option to Create thumbnails for recent files or toggle off thumbnail rendering to stop Inkscape from caching new document previews.
  6. To prevent recent files from displaying altogether, reduce the Maximum recent files counter to 0.

Preventing Thumbnails from Saving Inside Files

Inkscape can also embed thumbnail metadata directly into SVG files upon saving, which supplies the Welcome screen with preview graphics:

  1. In the Preferences dialog, expand Input/Output in the left sidebar.
  2. Click on SVG output.
  3. Locate the setting labeled Include thumbnail or Save document thumbnail.
  4. Uncheck the box to ensure Inkscape stops embedding image previews inside your saved vector files.

Clearing the Existing Thumbnail Cache

Disabling the feature stops future caching, but previously rendered thumbnails remain stored on your system. You can manually delete these files based on your operating system:

  • Windows: Press Win + R, type %LOCALAPPDATA%\inkscape\cache (or %APPDATA%\inkscape\cache), and press Enter. Delete the contents of the thumbnails or cache folder.
  • macOS: Open Finder, press Cmd + Shift + G, enter ~/Library/Caches/org.inkscape.Inkscape, and remove the cached thumbnail files.
  • Linux: Open a terminal or file manager, navigate to ~/.cache/inkscape/, and delete the thumbnail directory.

Once completed, restart Inkscape. The Welcome screen will no longer generate or display cached visual previews of your documents.
