Export Inkscape Vectors to Godot NavigationPolygon

Exporting vector line drawings from Inkscape into Godot as navigation polygons allows you to design complex 2D levels with precise pathfinding boundaries. While Godot can render SVG files natively as textures, it does not automatically convert raw SVG line paths into navigation geometry. This guide explains how to prepare your vector artwork in Inkscape, extract the coordinate data, and convert it into a functional NavigationPolygon inside Godot.

Step 1: Prepare Paths in Inkscape

Navigation geometry requires closed, non-intersecting shapes to define walkable or non-walkable areas.

  1. Draw Closed Shapes: Ensure all lines form closed shapes. If you drew open strokes, close them using the Edit paths by nodes tool (N) by joining the end nodes, or use Path > Stroke to Path to convert line thickness into a closed polygon.
  2. Convert Objects to Paths: Select all shapes and go to Path > Object to Path (Shift + Ctrl + C).
  3. Handle Holes and Obstacles: If your walkable map has internal obstacles (holes), select the outer boundary and the inner obstacles, then choose Path > Combine (Ctrl + K).
  4. Set Document Origin: Move the drawing close to the top-left corner of the canvas (0, 0), as Godot will treat this position as the node’s local origin.
  5. Save as Plain SVG: Go to File > Save As..., choose Plain SVG (*.svg) rather than Inkscape SVG to strip out unnecessary editor metadata.

Step 2: Convert SVG Geometry to Godot Polygon Data

To bridge the gap between SVG path data and Godot navigation, use one of the two standard workflows:

Method A: Using a GDScript Tool Script

You can parse the SVG path coordinates directly in Godot using a short @tool script that reads the SVG's d attribute and assigns the vertices to a NavigationPolygon.

  1. Open the .svg file in a text editor to locate the path points within the <path d="..." /> tag.
  2. Create a script attached to a NavigationRegion2D node in your Godot project:
@tool
extends NavigationRegion2D

# Array of Vector2 coordinates extracted from your path
@export var raw_points: PackedVector2Array = []
@export var generate: bool = false:
    set(value):
        if value:
            build_navpoly()

func build_navpoly() -> void:
    if raw_points.is_empty():
        return
        
    var nav_poly = NavigationPolygon.new()
    nav_poly.add_outline(raw_points)
    nav_poly.make_polygons_from_outlines()
    navigation_polygon = nav_poly
  1. Paste the normalized vertex points into the inspector array and toggle the Generate checkbox to generate the polygon mesh instantly.

Method B: Using CollisionPolygon2D as an Intermediary

If you prefer visual placement without writing custom XML parsers:

  1. Import the SVG into Godot as a texture.
  2. Add a Sprite2D node with your SVG texture to the scene.
  3. Select the Sprite2D node, navigate to the top editor toolbar, and click Sprite2D > Create CollisionPolygon2D Sibling.
  4. Adjust the simplification threshold to match your desired vertex count and click Build.
  5. Add a NavigationRegion2D to the scene.
  6. Create a new NavigationPolygon in the inspector.
  7. Select the generated CollisionPolygon2D, copy its polygon array from the Inspector, and paste it into an outline array within your NavigationPolygon.

Step 3: Bake and Verify the Navigation Mesh

  1. Select your NavigationRegion2D.
  2. Ensure the NavigationPolygon is assigned and visible in the 2D viewport.
  3. Click the Bake NavigationPolygon button in the top toolbar to triangulate the navmesh.
  4. Enable Debug > Visible Navigation from the Godot editor's main menu while running your project to confirm the agents can traverse the imported shape.
