Maintain Mitered Corners with Inkscape Offset LPE

This guide explains how to prevent sharp corners from beveling or rounding when using the Offset Live Path Effect (LPE) in Inkscape at large offset distances. By default, extreme offsets often truncate sharp angles due to miter limit thresholds. Adjusting the join type and scaling the miter limit directly within the Path Effects panel allows you to preserve crisp, pointed mitered edges regardless of how far the path is expanded.

Apply the Offset Path Effect

  1. Select the vector path you want to expand.
  2. Open the Path Effects dialog by navigating to Path > Path Effects.
  3. Click the Add Path Effect button (the + icon) and select Offset from the list.

Set the Join Type to Miter

In the Path Effects panel under the Offset settings:

  1. Locate the Join parameter.
  2. Change the dropdown menu to Miter.

This specifies that intersecting edges should extend until they meet at a sharp point rather than rounding off or flattening.

Increase the Miter Limit

At extreme offset distances, the distance between the inner corner and the outer tip increases significantly. Inkscape automatically bevels corners when this distance exceeds the Miter limit value to prevent excessively long spikes.

  1. Locate the Miter limit field within the Offset LPE parameters.
  2. The default value is typically set to 4.00. Increase this value significantly (for example, to 20.00, 50.00, or higher) depending on the sharpness of your angles and the magnitude of your offset.
  3. Observe the canvas as you increase the number. Once the miter limit is high enough to accommodate the acute angle multiplied by the offset distance, the corner will snap from a flat bevel back to a sharp point.

Troubleshooting Acute Angles

For extremely sharp, acute angles (under 15 degrees), the miter point can project extremely far outward. If the corner still appears cut off at high offset distances:

  • Enter an arbitrarily high miter limit, such as 100.00.
  • Ensure that the original path does not contain duplicate or overlapping coincident nodes at the corner, as redundant nodes can confuse the path calculation and force a round or beveled cap.
