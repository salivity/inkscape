How to Report Bugs and Request Features in Inkscape

Inkscape relies on community feedback to improve stability and introduce new capabilities through its GitLab repository. This guide outlines the exact process for submitting actionable bug reports and well-structured feature requests directly to the Inkscape development team, from preparing your report to collaborating with developers.

1. Prepare Before Submitting

Before opening a new ticket, take the following preparatory steps:

  • Search Existing Issues: Check the Inkscape GitLab issue tracker to verify that your bug or feature request has not already been submitted. If a matching issue exists, give it a "thumbs up" reaction or add relevant new details in a comment.
  • Test on the Latest Version: Verify whether the bug occurs in the latest stable release or development build of Inkscape.
  • Isolate the Problem: Determine the exact steps required to reproduce the bug consistently. Keep the example as simple as possible.
  • Gather System Information: Open Inkscape and go to Help > About Inkscape, then copy the full version string and your operating system details.

2. Set Up a GitLab Account

  1. Go to GitLab and sign in, or create a free account if you do not have one.
  2. Navigate to the official Inkscape project repository on GitLab.

3. Submit a Bug Report

  1. Go to the Issues section of the Inkscape project and click New issue.
  2. Select the Bug issue template from the template dropdown menu.
  3. Fill out the template fields completely:
    • Title: Write a concise, descriptive summary of the problem.
    • Description: Detail the exact step-by-step instructions to reproduce the issue.
    • Observed Behavior: Explain what actually happened (e.g., crash, visual artifact, tool failure).
    • Expected Behavior: Explain what should have happened.
    • Inkscape Version and OS: Paste the diagnostic information collected from the Help menu.
    • Attachments: Attach sample .svg files, crash logs, or screenshots/screen recordings that demonstrate the problem.
  4. Click Create issue.

4. Submit a Feature Request

  1. In the Issues section, click New issue.
  2. Select the Feature Request or Enhancement template if available, or start with a general template.
  3. Clearly structure your proposal:
    • Summary: Provide a brief summary of the proposed feature.
    • Use Case: Explain the problem you are trying to solve and why this feature would benefit Inkscape users.
    • Proposed Solution: Describe how the feature should look and function within the user interface. Include mockups or workflow diagrams if available.
    • Alternatives Considered: Mention any workarounds or alternative software implementations you have evaluated.
  4. Click Create issue.

5. Follow Up on Your Submission

Once submitted, the Inkscape triage team or developers may ask for clarification, additional log files, or testing of a patch. Enable notifications for your issue so you can respond promptly to inquiries and assist in the resolution process.
