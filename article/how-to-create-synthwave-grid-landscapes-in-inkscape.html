How to Create Synthwave Grid Landscapes in Inkscape

This guide provides a straightforward tutorial on designing an iconic 1980s-inspired synthwave landscape using Inkscape's vector toolset. You will learn how to build the dark atmospheric backdrop, design a classic horizontal-sliced neon sun, transform flat 2D lines into a 3D perspective grid floor, and apply glowing neon effects to capture the retro-futuristic aesthetic.

Step 1: Set Up the Canvas and Background

  1. Open Inkscape and access File > Document Properties to set your page size to standard 1920x1080 pixels (or your preferred aspect ratio).
  2. Select the Rectangle Tool (R) and draw a rectangle that covers the entire canvas.
  3. Open the Fill and Stroke panel (Shift + Ctrl + F).
  4. Set the fill to a Linear Gradient. Edit the gradient so the top color is a very dark navy or black (#050110) and the bottom color near the center is a deep violet or magenta (#2b0845).
  5. Lock this layer in the Layers and Objects panel to prevent accidental movement.

Step 2: Create the Glowing Retro Sun

  1. Select the Circle/Ellipse Tool (E), hold Ctrl, and draw a circle in the upper half of the canvas.
  2. Apply a vertical Linear Gradient to the circle, transitioning from bright yellow (#ffe600) at the top to vibrant hot pink or magenta (#ff007f) at the bottom.
  3. To add the classic horizontal blinds effect, select the Rectangle Tool and draw thin, horizontal bars across the lower half of the sun, making each subsequent lower bar slightly thicker than the one above it.
  4. Select all the horizontal bars, go to Path > Union (Ctrl + +), then select both the sun and the united bars and choose Path > Difference (Ctrl + -) to cut the stripes out of the sun.

Step 3: Construct the 2D Grid

  1. Select the Pen (Bezier) Tool (B). Hold Ctrl to draw a perfectly straight vertical line.
  2. Duplicate the line (Ctrl + D) and move it horizontally. Repeat this process or use the Create Tiled Clones tool (Edit > Clone > Create Tiled Clones) to create 15–20 evenly spaced vertical lines.
  3. Draw an equal number of horizontal lines intersecting the vertical lines to form a square grid mesh.
  4. Select all the grid lines and navigate to Path > Combine (Ctrl + K).
  5. Change the stroke color to bright cyan (#00f0ff) and set the stroke width to roughly 2 px.

Step 4: Apply Perspective to the Grid

  1. Select your combined grid and navigate to Path > Path Effects.
  2. Click the + button to add an effect and choose Perspective / Envelope.
  3. Set the mode to Perspective.
  4. Switch to the Node Tool (N) to display the four outer control handles of the bounding box.
  5. Drag the two bottom corner nodes outward to the lower canvas edges to widen the foreground, and drag the two top corner nodes inward toward the horizon line to narrow the background.
  6. Position the top of the perspective grid so it aligns horizontally with the center of the sun.

Step 5: Add Neon Glow and Horizon Blending

  1. Duplicate the perspective grid (Ctrl + D).
  2. On the duplicated grid, increase the stroke width slightly, change the stroke color to a deep magenta or bright violet, and increase the Blur slider in the Fill and Stroke panel to around 5–10% to create a neon bloom.
  3. Lower the blurred layer directly behind the crisp cyan grid using Object > Lower (Page Down).
  4. Draw a small rectangle across the horizon line where the grid meets the sky. Give it a Linear Gradient that fades from a bright neon color (#ff00aa) at the horizon to completely transparent upward and downward, softening the transition between the grid and the background.

Step 6: Add Mountain Silhouettes (Optional Horizon Detail)

  1. Use the Bezier Tool (B) to draw a jagged, polygonal mountain range across the horizon line.
  2. Fill the mountain shape with a very dark purple or black, and set a thin, bright magenta stroke along the top edges to emphasize the neon wireframe theme.
  3. Position this mountain layer between the sun and the grid to complete the depth of the synthwave scene.
