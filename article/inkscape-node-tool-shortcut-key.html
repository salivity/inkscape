Inkscape Node Tool Shortcut Key

Mastering keyboard shortcuts in Inkscape dramatically accelerates your vector illustration workflow, especially when manipulating complex vector paths. This guide explains the primary keyboard shortcut required to instantly activate the Node editing tool from any active tool, along with practical tips for seamless switching between object selection and path editing.

The primary shortcut key to switch to the Node tool ("Edit paths by nodes") in Inkscape is N. Alternatively, you can press the function key F2.

Pressing either N or F2 immediately activates the Node tool regardless of which tool you are currently using, such as the Select tool, Pen tool, or Rectangle tool. Once active, the cursor changes to an arrow with a small node icon, allowing you to select, add, delete, and adjust individual path nodes and Bézier handles.

Additional Quick-Switch Methods

Aside from the standard single-key shortcut, Inkscape offers intuitive mouse interactions to access the Node tool:

  • Double-Clicking Paths: When using the Select tool (S or F1), double-clicking directly on any path or vector shape automatically switches the active tool to the Node tool and selects the clicked path for immediate editing.
  • Toggling with the Spacebar: While using the Node tool, pressing the Spacebar temporarily switches back to the Select tool, allowing you to move or transform objects quickly before returning to node manipulation.

Returning to the Select Tool

To exit the Node tool and return to standard object transformation mode, press S or F1 to re-engage the Select and Transform Objects tool.
