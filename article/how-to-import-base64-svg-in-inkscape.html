How to Import Base64 SVG in Inkscape

This guide explains how to import and work with Scalable Vector Graphics (SVG) containing embedded base64 raster data in Inkscape. While Inkscape handles embedded base64 images natively through standard import workflows, understanding how Inkscape parses this data—and how to inspect, extract, or convert it—ensures that your embedded graphics display properly without rendering errors or performance bottlenecks.

Standard Import Method

Inkscape natively supports SVG files containing embedded base64 raster images wrapped in standard <image> tags.

  1. Launch Inkscape.
  2. Go to File > Open (or press Ctrl + O on Windows/Linux, Cmd + O on macOS).
  3. Navigate to the SVG file containing the base64 data and select Open.
  4. Alternatively, to add the SVG into an existing document, navigate to File > Import (Ctrl + I / Cmd + I). When prompted, select Include SVG image as an editable object in the current file.

If the base64 string is correctly formatted within the SVG syntax, Inkscape automatically decodes and displays the raster image on the canvas.

Importing Raw SVG Code with Base64

If you have raw SVG code rather than an .svg file:

  1. Open a plain text editor (such as Notepad, TextEdit, or VS Code).
  2. Paste the SVG code containing the <image xlink:href="data:image/png;base64,..." /> tag.
  3. Save the file with an .svg extension (ensure the file type is set to "All Files" to prevent it from saving as .svg.txt).
  4. Open the saved file in Inkscape using File > Open.

Alternatively, you can open the built-in XML editor in an active Inkscape document by pressing Ctrl + Shift + X. Create a new <svg:image> node and paste your base64 URI directly into the xlink:href or href attribute.

Verifying Embedded Base64 Data

To confirm that the raster image is properly embedded as base64 data rather than linked externally:

  1. Select the image on the canvas.
  2. Open the XML Editor (Edit > XML Editor or Ctrl + Shift + X).
  3. Locate the highlighted <svg:image> element in the XML tree.
  4. Check the attributes panel on the right. An embedded image will show an xlink:href or href attribute starting with data:image/[format];base64, followed by the encoded string.

Managing Embedded Raster Data

Once the file is open, Inkscape provides tools to manipulate the embedded raster content:

  • Extracting the Raster Image: To convert the base64 image into an external file, select the image and navigate to Extensions > Images > Extract Image. Choose a directory and format. Inkscape will save the file locally and replace the base64 string with a standard file link.
  • Vectorizing the Image: If you need the base64 raster data converted to scalable vector paths, select the image and go to Path > Trace Bitmap (Shift + Alt + B). Adjust your detection thresholds and click Apply to generate vector paths directly over the embedded raster graphic.

Troubleshooting Common Import Issues

  • Black Box or Missing Image: If the image does not render, ensure the SVG root tag contains the required namespace: xmlns:xlink="http://www.w3.org/1999/xlink".
  • Corrupt Data Strings: Ensure the base64 prefix matches the image encoding (for example, data:image/png;base64, for PNGs or data:image/jpeg;base64, for JPEGs) and that no line breaks or whitespace interrupt the base64 character string.
  • Slow Canvas Performance: Extremely large base64 strings can cause high memory usage. Extracting the image or lowering the resolution of the raster data before encoding helps maintain smooth performance.
