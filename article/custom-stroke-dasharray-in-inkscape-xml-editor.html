Custom Stroke Dasharray in Inkscape XML Editor

Inkscape provides basic dash presets in the Fill and Stroke dialog, but creating intricate, syncopated stroke rhythms requires accessing the underlying SVG code. By utilizing Inkscape's built-in XML Editor, you can manually inject custom values into the stroke-dasharray attribute. This article explains how the SVG dash array syntax functions, provides practical numerical patterns for complex rhythms, and details the exact steps to apply raw values directly to any vector path.

Understanding SVG stroke-dasharray Syntax

The stroke-dasharray property controls the pattern of dashes and gaps used to stroke paths. Its value is a list of comma- or space-separated numbers that alternate between the length of a dash and the length of a gap:

stroke-dasharray: [dash_1] [gap_1] [dash_2] [gap_2] ...

  • Even number of values: The sequence repeats indefinitely in the specified order (e.g., 10, 5, 2, 5 creates a long dash, a gap, a short dash, and a gap).
  • Odd number of values: If an odd number of entries is provided, the browser or renderer automatically duplicates the sequence to achieve an even count (e.g., 5, 3, 2 becomes 5, 3, 2, 5, 3, 2).
  • Units: Values inherit the stroke width unit or pixels by default.

Step-by-Step: Adding Raw Values in the XML Editor

  1. Select the Object: Use the Select tool (S) to click the path you want to modify. Ensure the path has a stroke applied.
  2. Open the XML Editor: Navigate to Edit > XML Editor from the main menu, or press Ctrl + Shift + X (macOS: Cmd + Shift + X).
  3. Locate the Node: The XML Editor tree will automatically highlight the XML node representing your selected object (typically a <svg:path> or <svg:rect>).
  4. Locate the Style Attribute: In the right-hand panel of the XML Editor, locate the style attribute under the attribute list. Click on it to display its value in the bottom text box.
  5. Modify or Insert stroke-dasharray:
    • Look for an existing stroke-dasharray declaration inside the style string (e.g., stroke-dasharray:none; or stroke-dasharray:4, 4;).
    • Replace it with your custom rhythm: 
      stroke-dasharray:16, 4, 4, 4, 1, 4;
    • If no stroke-dasharray property exists in the style string, add it to the end, ensuring it is separated from the preceding property by a semicolon: 
      ;stroke-dasharray:20, 6, 2, 6;
  6. Apply the Changes: Press Ctrl + Enter or click the Set button beside the attribute input box. The canvas immediately updates to reflect the new rhythm.

Formula Examples for Stroke Rhythms

  • Morse Code Rhythm (Dash-Dot-Dot): stroke-dasharray: 12, 4, 3, 4, 3, 4;
  • Syncopated Triple-Pulse: stroke-dasharray: 18, 4, 8, 4, 2, 8;
  • Graduated Wave Pattern: stroke-dasharray: 2, 3, 4, 3, 8, 3, 16, 3;

Fine-Tuning Line Caps and Offsets

  • Round Caps Interaction: When using stroke-linecap: round;, the ends of each dash are extended by half the stroke width. To create true dots, set the dash length to 0 or 0.01 and compensate for the rounded radius by increasing the gap length (e.g., 0.01, 8).
  • Adjusting Starting Position: To change where the pattern begins along the path, locate or add the stroke-dashoffset property in the same style string (e.g., stroke-dashoffset: 10;).
