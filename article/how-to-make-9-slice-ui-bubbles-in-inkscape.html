How to Make 9-Slice UI Bubbles in Inkscape

Designing scalable dialog box user interface (UI) speech bubbles requires a 9-slice approach to prevent rounded corners and decorative tails from distorting when resized to fit dynamic text. This tutorial provides a step-by-step workflow for creating a vector speech bubble in Inkscape, establishing precise slicing boundaries, and cutting the graphic into nine modular components—four corners, four edges, and a center—ready for implementation in game engines, UI frameworks, or CSS.

Step 1: Set Up the Canvas and Snapping

  1. Open Inkscape and navigate to File > Document Properties.
  2. Under the Display tab, set the display units to Pixels (px).
  3. Enable pixel snapping by toggling the Snap to Grid or Snap to Pixel Grid controls on the right toolbar to ensure clean, pixel-perfect exports without anti-aliasing blur along the cut lines.

Step 2: Create the Speech Bubble Graphic

  1. Select the Rectangle Tool (R) and draw a box that defines your default dialog size (e.g., 96×96 px).
  2. Use the circular corner-radius handles on the rectangle to set your desired rounded corners.
  3. Select the Pen Tool (B) to draw a triangular polygon for the dialog tail, ensuring it overlaps the bottom or side border of your rounded rectangle.
  4. Select both the rectangle and the triangle, then go to Path > Union (Ctrl + +) to merge them into a single continuous shape.
  5. Apply your desired fill color, border stroke, or internal gradients using the Fill and Stroke panel (Shift + Ctrl + F).

Step 3: Map the 9-Slice Guide Boundaries

A 9-slice grid divides the graphic into nine regions:

  • Four fixed corners: Contain the rounded corners (and tail, if fixed to a corner).
  • Four scalable edges: Top, bottom, left, and right segments that stretch or tile along one axis.
  • One expandable center: Fills the remaining interior space.
  1. Drag two vertical guides from the left ruler: place one immediately after the left rounded corners and the second immediately before the right rounded corners.
  2. Drag two horizontal guides from the top ruler: place one immediately below the top rounded corners and the second immediately above the bottom rounded corners.
  3. Ensure the dialog pointer tail is positioned either completely inside the bottom-edge slice (if centered/scalable) or completely within a designated corner block to prevent slicing the tail in half.

Step 4: Slice the Graphic into Nine Parts

  1. Draw four straight, thin divider lines using the Pen Tool (B) across the guide boundaries—two horizontal lines spanning the full width and two vertical lines spanning the full height.
  2. Select your speech bubble shape and duplicate it multiple times if you wish to preserve the original asset on a hidden layer.
  3. Group the four divider lines together, select both the lines and the speech bubble, and navigate to Path > Division (Ctrl + /). Inkscape will cut the vector shape into nine separate path objects along the line paths.
  4. Verify the separation by clicking each piece individually: you should now have Top-Left, Top-Center, Top-Right, Mid-Left, Center, Mid-Right, Bottom-Left, Bottom-Center, and Bottom-Right.

Step 5: Exporting for UI Frameworks

Depending on your target framework, you can export the assets in two standard formats:

  • Individual Tiles (Game Engines / CSS sprites): Select each of the nine pieces individually, open the Export Panel (Shift + Ctrl + E), choose Selection, and export each tile as a standalone SVG or PNG (e.g., bubble_top_left.png, bubble_top.png, etc.).
  • Single-Image 9-Patch (Android / CSS border-image / Godot): Leave the bubble intact as a single image export. Measure the pixel offsets of your guides from the top, right, bottom, and left edges. Use these pixel measurements as the slice parameters in your game engine (e.g., Godot NinePatchRect margin properties) or CSS:
.dialog-bubble {
  border-image-source: url('bubble.svg');
  border-image-slice: 24 24 32 24 fill; /* Top, Right, Bottom, Left offsets in px */
  border-image-repeat: stretch;
}
