Replace Inline Styles with CSS Classes in Inkscape

Inkscape defaults to embedding presentation attributes directly into SVG elements as inline style tags, which can bloat file sizes and complicate web styling. Converting these inline attributes to external CSS classes allows you to manage graphics dynamically with standard stylesheets. This guide explains how to assign CSS classes to your vectors, remove the default inline style attributes, and link an external CSS stylesheet directly within Inkscape.

1. Assign CSS Classes to Elements

Before removing inline styles, assign CSS classes to the elements you want to style.

  1. Open your document in Inkscape.
  2. Open the Selectors and CSS dialog by navigating to Object > Selectors and CSS... (or press Ctrl + Shift + Q).
  3. Select the object or group on your canvas.
  4. In the Selectors and CSS dialog, locate the Class section at the bottom.
  5. Click the + button or enter your desired class name into the field (for example, icon-primary) and press Enter.

2. Remove Inline Style Attributes

Inkscape stores inline styles in the style attribute of each XML node. You must delete these attributes so they do not override your external rules.

  1. Open the XML Editor by going to Edit > XML Editor... (or press Ctrl + Shift + X).
  2. Select the object on the canvas; the corresponding node will automatically be highlighted in the XML tree.
  3. In the right-hand panel of the XML Editor, locate the attribute named style.
  4. Select the style attribute and click the Delete attribute icon (the red 'X' or minus icon) at the top of the attribute list.
  5. Repeat this process for any other elements that need external styling.

3. Link an External CSS Stylesheet

To instruct the SVG to fetch styles from an external .css file, insert an XML stylesheet processing instruction.

  1. In the XML Editor (Ctrl + Shift + X), click on the very top root element (usually <svg:svg>).
  2. Deselect all nodes, or ensure you are ready to create a processing instruction node.
  3. Inkscape's internal interface handles processing instructions best through direct header placement. In the XML Editor, select the root <svg:svg> node.
  4. Click the New element node button.
  5. Set the node name to style to add a local style container, or manually add an XML processing instruction:
    • To add a standard web-linked stylesheet, create a <link> tag under the SVG namespace:
      • Create element: xhtml:link (or link).
      • Set attribute: rel="stylesheet".
      • Set attribute: type="text/css".
      • Set attribute: href="styles.css".
    • Alternatively, if serving standalone SVGs, open the .svg file in a text editor and insert this line right after the <?xml ... ?> declaration: 
      <?xml-stylesheet type="text/css" href="styles.css" ?>

4. Create the External CSS File

In your project directory, create the external file (for example, styles.css) referenced by your SVG and define the rules matching your assigned classes:

.icon-primary {
  fill: #007acc;
  stroke: #003366;
  stroke-width: 2px;
}

5. Save the SVG

Go to File > Save As... and choose Optimized SVG (*.svg) from the file type dropdown. In the export settings dialog, ensure Remove style attributes and Convert CSS attributes to XML attributes remain unchecked or configured according to your workflow so your manual modifications are preserved.
