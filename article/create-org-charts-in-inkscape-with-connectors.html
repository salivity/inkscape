Create Org Charts in Inkscape with Connectors

Creating an organizational tree chart in Inkscape is streamlined using the Diagram Connectors tool. This guide explains how to prepare your hierarchy shapes, link them with dynamic connectors, style the lines, and manage the chart layout so that connections adapt automatically when elements are moved.

Step 1: Create the Chart Nodes

  1. Select the Rectangle tool (R) and draw a box to represent a position or person.
  2. Select the Text tool (T), click inside or over the box, and type the title or name.
  3. Group the text and the box together by selecting both and pressing Ctrl + G.
  4. Duplicate the group (Ctrl + D) as many times as needed to create the roles for your hierarchy, then arrange them roughly into your tree structure (top-level manager at the top, subordinates below).

Step 2: Activate the Connectors Tool

  1. Click the Create diagram connectors icon in the left toolbox, or press O on your keyboard.
  2. Notice the control handles (small red or gray dots) that appear in the center or edges of your grouped shapes when the tool is active.

Step 3: Link the Elements

  1. Hover the cursor over the parent (top) shape until the center connector handle appears.
  2. Click and drag the connector line from the parent shape to a child (subordinate) shape.
  3. Release the mouse when the cursor is over the target shape's connector handle. The line will snap and attach to the target.
  4. Repeat this process for all reporting relationships in your tree chart.

Step 4: Adjust Connector Types and Routing

With the Connectors tool active, look at the Tool Controls bar at the top of the screen to adjust behavior:

  • Orthogonal Routing: Click the Orthogonal connectors button to force lines into clean, right-angled paths, which are ideal for traditional tree structures.
  • Polyline Connectors: Use this option if you prefer direct, diagonal lines between nodes.
  • Avoid Shapes: Select the connectors and toggle the Make connectors avoid selected objects option to prevent lines from running directly behind or through other boxes.
  • Curvature: Adjust the curvature setting in the top bar to add rounded corners to right-angle turns.

Step 5: Format the Lines

  1. Switch to the Select tool (S) and click a connector line.
  2. Open the Fill and Stroke panel (Ctrl + Shift + F).
  3. Under the Stroke paint tab, choose the line color.
  4. Under the Stroke style tab, adjust the line width, dash style, and end markers (such as arrowheads, if directional reporting is required).

Step 6: Align and Arrange

  1. Select the nodes in a specific tier using the Select tool.
  2. Open the Align and Distribute panel (Ctrl + Shift + A) to align tiers horizontally and distribute spacing evenly.
  3. Because the connectors are dynamically linked, moving any box automatically updates the attached lines without breaking the connections.
