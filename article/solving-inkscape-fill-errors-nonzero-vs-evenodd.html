Solving Inkscape Fill Errors: Nonzero vs EvenOdd

Self-intersecting paths and complex combined vectors in Inkscape often create unexpected rendering glitches, such as unwanted holes or improperly filled shapes. These visual errors occur because rendering engines rely on specific mathematical algorithms to determine which enclosed regions belong to the inside or outside of a path. By adjusting the path's fill rule between Nonzero (Winding) and EvenOdd, or by reversing path directions, you can instantly resolve these rendering artifacts without redrawing your vector artwork.

Understanding Nonzero vs. EvenOdd Fill Rules

Inkscape supports two primary SVG fill rules that define how overlapping and intersecting paths are colored:

  • Nonzero (Winding Rule): This default rule determines whether a point is inside the shape by drawing a ray outward and tracking the direction (clockwise vs. counterclockwise) of every intersecting path segment. If overlapping sub-paths travel in the same direction, they stay filled. If an inner loop runs in the opposite direction of the outer boundary, it creates a transparent cutout (hole). Unintended self-intersections often fail to create cutouts under this rule if the path directions match.
  • EvenOdd Rule: This rule ignores path direction entirely. It counts the total number of path boundaries crossed from any given point to infinity. If the number of crossings is odd, the area is filled; if the count is even, the area remains empty. This makes EvenOdd ideal for automatically alternating between solid and transparent regions in self-intersecting or nested paths.

How to Change Fill Rules in Inkscape

  1. Select the problematic path using the Select Tool (S or F1).
  2. Open the Fill and Stroke dialog by pressing Ctrl + Shift + F (or Cmd + Shift + F on macOS) or navigating to Object > Fill and Stroke.
  3. In the Fill tab (or Stroke paint tab if using filled strokes), locate the Fill rule toggle buttons at the bottom-right corner of the panel.
  4. Switch from Nonzero (represented by a solid polygon icon) to EvenOdd (represented by a polygon with a hole in the center), or vice versa.
  5. Inspect the canvas to verify that the self-intersecting loops and overlapping sections now render correctly.

Fixing Fill Errors Without Changing the Rule

If your target format requires the Nonzero rule (often required for certain font formats, cutting plotters, or specific SVG standards), you can fix rendering errors manually:

  • Reverse Sub-Path Direction: If a hole in a compound path is filled instead of transparent under the Nonzero rule, switch to the Node Tool (N), select a node on the inner loop, and select Path > Reverse (Shift + R). This flips the winding direction and restores the cutout.
  • Flatten Self-Intersections: To permanently remove overlapping geometry, select the path and navigate to Path > Union (Ctrl + +) or use the Shape Builder Tool (X) to merge overlapping segments into a clean, single-boundary shape.
