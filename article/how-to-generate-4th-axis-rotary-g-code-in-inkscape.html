How to Generate 4th-Axis Rotary G-Code in Inkscape

This guide outlines the process of generating rotary chuck 4th-axis coordinates for cylinder engraving using Inkscape. It covers calculating the unwrapped surface dimensions of your cylinder, sizing your artwork, generating vector toolpaths using Inkscape's built-in G-code tools, and converting linear planar movements into rotational degrees for a true 4th-axis (A-axis) controller.

1. Calculate Cylinder Circumference

Engraving on a cylinder requires "unwrapping" the curved surface into a flat plane. You must calculate the exact circumference of the workpiece to define the rotational boundary.

  • Measure the diameter (\(D\)) of the cylinder using calipers.
  • Calculate the circumference (\(C\)):
    \[C = \pi \times D \approx 3.14159 \times D\]

For example, a cylinder with a 50 mm diameter has a circumference of \(50 \times 3.14159 = 157.08\text{ mm}\).

2. Set Up the Inkscape Document

Configure the workspace so that the linear axis represents the length of the cylinder and the rotational axis matches the circumference.

  1. Open File > Document Properties (Shift + Ctrl + D).
  2. Set the display units to millimeters (mm).
  3. Set the canvas dimensions:
    • Width (X-axis): Set to the engravable length of your cylinder.
    • Height (Y-axis): Set to the calculated circumference.
  4. Close the Document Properties dialog.

3. Prepare and Position the Artwork

  1. Import or create your design.
  2. Select all artwork and convert it to paths via Path > Object to Path (Shift + Ctrl + C).
  3. Resize the design to fit within the document bounds, ensuring that any pattern meant to wrap seamlessly around the cylinder aligns precisely with the top (\(Y = \text{Circumference}\)) and bottom (\(Y = 0\)) edges of the canvas.

4. Generate Standard Toolpaths with Gcodetools

Inkscape includes a native extension called Gcodetools to generate CNC motion commands.

  1. Go to Extensions > Gcodetools > Orientation points.
    • Select 2-points mode.
    • Set the surface Z depth (usually 0.0) and the engraving depth (e.g., -0.2 mm for cutting or laser focus depth).
    • Click Apply.
  2. Go to Extensions > Gcodetools > Tools library.
    • Choose the tool type (e.g., cylinder or engraving) and click Apply.
    • Adjust the generated green text box on the canvas to configure feed rates and plunge speeds.
  3. Select your design paths and go to Extensions > Gcodetools > Path to Gcode.
    • In the Preferences tab, enter a file name and output directory.
    • In the Path to Gcode tab, click Apply to generate the .ngc or .gcode file.

5. Convert Planar Coordinates to 4th-Axis (A-Axis) Coordinates

Standard Inkscape output produces linear \(X\), \(Y\), and \(Z\) coordinates. Depending on your CNC or laser controller configuration, use one of two methods to translate the Y-axis into rotation:

Method A: Hardware-Level Y-to-Rotary Substitution (No Code Modification)

If your rotary chuck plugs directly into the machine’s Y-axis driver port:

  1. Divide your driver's steps-per-revolution by the cylinder circumference: \[\text{Steps per mm} = \frac{\text{Microsteps per Revolution}}{\text{Circumference}}\]
  2. Update the machine's Y-axis step value in the firmware (e.g., GRBL $101).
  3. Run the standard Inkscape G-code file directly; linear Y-movements will turn the rotary chuck by the exact linear surface distance.

Method B: Software Conversion to A-Axis Degrees (True 4-Axis)

If your controller expects a dedicated rotary axis command (\(A\)) measured in degrees (\(0^\circ\) to \(360^\circ\)):

  1. Open the generated G-code file in a text editor or spreadsheet.
  2. Convert all linear \(Y\) coordinates to degrees (\(A\)) using the formula: \[A = \left(\frac{Y}{\text{Circumference}}\right) \times 360\]
  3. Replace the Y[value] commands with A[calculated_angle] using a find-and-replace script or a post-processor utility.
  4. Ensure the file header initiates the A-axis mode on your machine controller before execution.
