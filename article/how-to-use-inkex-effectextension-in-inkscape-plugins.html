How to Use inkex.EffectExtension in Inkscape Plugins

This guide explains how to build an Inkscape Python plugin by inheriting from the inkex.EffectExtension class. You will learn the fundamental architecture of an effect plugin, how to handle user arguments, how to override the primary execution method to manipulate the SVG document tree, and how to register the script for execution within Inkscape.

Basic Plugin Architecture

To create an effect extension, you must import the inkex module, define a custom class that subclasses inkex.EffectExtension, override the required lifecycle methods, and execute the class instance using the run() method.

Here is a minimal functional template:

import inkex

class MyExtension(inkex.EffectExtension):
    def add_arguments(self, pars):
        """Define command-line arguments passed from the .inx file."""
        pars.add_argument(
            "--my_option",
            type=str,
            default="default_value",
            help="An example string option",
        )

    def effect(self):
        """Main execution logic for modifying the SVG document."""
        # Access argument values
        option_value = self.options.my_option

        # Access and modify the SVG document
        for elem in self.svg.selection:
            elem.set("fill", "red")

if __name__ == "__main__":
    MyExtension().run()

1. Handling Parameters with add_arguments()

The add_arguments() method configures the argument parser. Inkscape calls this method automatically before executing the main script logic.

  • The pars parameter is an instance of Python’s standard argparse.ArgumentParser.
  • Use pars.add_argument() to register options corresponding to the <param> tags defined in your companion .inx XML descriptor file.
  • Once parsed, these options are accessible inside the class via self.options.<argument_name>.

2. Manipulating the Document in effect()

The effect() method contains the core logic of your extension. It is executed once arguments are successfully parsed and the document is loaded into memory.

When subclassing EffectExtension, several attributes are exposed on self:

  • self.svg: The root SvgDocumentElement representing the entire document tree. You can query elements using methods like self.svg.xpath() or traverse elements with self.svg.descendants().
  • self.svg.selection: A collection of elements currently selected by the user in the Inkscape workspace. If no items are selected, it defaults to empty unless fallback behavior is implemented.
  • self.msg(): A utility method for sending informational messages or errors back to the user interface via an Inkscape dialog box.

3. Execution

At the bottom of the script, instantiate your custom class and invoke run():

if __name__ == "__main__":
    MyExtension().run()

The run() method handles reading the SVG from standard input, parsing command-line parameters, executing effect(), and outputting the modified SVG back to standard output for Inkscape to render.
