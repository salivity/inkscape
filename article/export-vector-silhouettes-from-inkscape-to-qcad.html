Export Vector Silhouettes from Inkscape to QCAD

Exporting vector silhouettes from Inkscape into QCAD allows architects and draftsmen to incorporate custom entourage—such as people, vegetation, and vehicles—into technical drawings. This guide outlines the complete process of cleaning vector artwork in Inkscape, converting paths to a CAD-friendly format, exporting as DXF, and properly scaling and organizing the silhouette inside QCAD for 2D architectural detailing.

1. Prepare the Vector in Inkscape

Before exporting, you must convert the silhouette into clean, continuous geometry that CAD software can interpret without visual distortion or missing geometry.

  • Simplify and Merge Paths: If your silhouette consists of multiple overlapping shapes, select all components and navigate to Path > Union. This eliminates overlapping boundary lines.
  • Convert Objects to Paths: Ensure all elements are pure vector paths by selecting everything and clicking Path > Object to Path.
  • Handle Fills and Strokes: CAD software works strictly with lines, not filled vector paths. Select your silhouette, set the Fill to "None" in the Fill and Stroke panel, and assign a solid color to the Stroke. This prevents double-line exports and ensures a single outline is generated.
  • Set Document Units: Go to File > Document Properties and set the display units to the unit you use in your architectural drawings (e.g., millimeters or meters).

2. Export to AutoCAD DXF

QCAD natively uses DXF and DWG formats. Inkscape can export directly to DXF using built-in filters.

  1. Click File > Save As...
  2. In the file format dropdown, select AutoCAD DXF R14 (*.dxf) or Desktop Cutting Plotter (AutoCAD DXF R14) (*.dxf).
  3. Choose a destination folder and click Save.
  4. In the export settings dialog:
    • Set the Base unit to match your target drawing standard (typically mm or m).
    • Check ROBO-Master or LWPOLYLINE if available to ensure paths export as connected continuous polylines rather than fragmented line segments.
    • Click OK to complete the export.

3. Import and Standardize in QCAD

Once exported, import the file into QCAD to ensure proper scaling, layer assignment, and block creation.

  • Open the File: Launch QCAD, go to File > Open, and select the saved DXF file.
  • Check the Scale: Silhouettes exported from illustration software often require scale adjustments. Use the measurement tool (Info > Distance Point to Point) to measure a known dimension (such as the height of an average person, typically 1750 mm). If the scale is incorrect, select the geometry, run the Modify > Scale command, and adjust it using a reference factor.
  • Assign to a Dedicated Layer: Create a specific layer (e.g., A-FLOR-ENTR or Det-Silhouettes) with your preferred lineweight and color settings, then move the silhouette entities onto this layer via the Property Editor.
  • Convert into a Block: To reuse the silhouette repeatedly across different sections and elevations without cluttering drawing geometry, select the silhouette and go to Block > Create Block from Selection. Specify an insertion point (typically the bottom-center or the ground line of the silhouette) and name the block.

Your silhouette is now stored as a clean, reusable 2D vector asset ready for insertion into any QCAD detailing sheet.
