Export G-Code for Laser Diodes in Inkscape

Exporting vector contours to G-code for diode laser cutters in Inkscape involves converting standard shapes into clean vector paths, setting up machine coordinates, and utilizing G-code generator extensions. This guide outlines the exact steps to convert native vector artwork into G-code (typically .gcode or .nc files) compatible with GRBL-based diode lasers using Inkscape's built-in Gcodetools extension.

Step 1: Set Document Properties and Coordinates

Diode laser cutters typically use the bottom-left corner as the origin point (0, 0) in GRBL workspace coordinates.

  1. Open File > Document Properties (Ctrl + Shift + D).
  2. Set the Display units to mm.
  3. Under the Page tab, set the custom size to match your laser's usable working bed (e.g., 400 mm x 400 mm).
  4. Ensure the origin marker is configured to the bottom-left corner to match standard GRBL machine coordinates.

Step 2: Convert Vectors to Continuous Paths

G-code generators cannot interpret native shapes (rectangles, circles), text, or grouped objects without converting them to vector paths first.

  1. Ungroup all elements by selecting everything (Ctrl + A) and pressing Ctrl + Shift + G repeatedly until all groups are dissolved.
  2. Convert all objects to paths by navigating to Path > Object to Path (Ctrl + Shift + C).
  3. If using dynamic offsets or strokes that define cutting outlines, select the objects and go to Path > Stroke to Path.
  4. Combine overlapping cut paths if necessary using Path > Union or Path > Combine to prevent the laser from tracing the same line multiple times.

Step 3: Add Orientation Points

Inkscape needs reference markers to translate screen coordinates into machine travel dimensions.

  1. Go to Extensions > Gcodetools > Orientation points...
  2. Select 2-points mode.
  3. Set the Z surface to 0.0, Z depth to 0.0 (diode lasers typically do not control physical Z-axis movement during cutting), and Units to mm.
  4. Click Apply. Inkscape will place coordinate markings at the bottom-left corner of the canvas.

Step 4: Configure the Tool Library for Laser Parameters

Diode lasers use the spindle speed parameter (S) to regulate laser power (e.g., S0 for off, S1000 for 100% power on typical GRBL setups) and feed rate (F) to control cutting speed.

  1. Go to Extensions > Gcodetools > Tools library...
  2. Choose Cylinder from the tool type list and click Apply.
  3. A green rectangular box containing text will appear on the canvas. Select the Text Tool (F8) to edit the parameters inside this box:
    • feed: Set to your desired cutting speed in mm/min (e.g., 300 to 1000 depending on material).
    • penetration feed: Set equal to your feed rate.
    • spindle rpm: Set to your maximum laser power value (e.g., 1000 for full diode output in GRBL).
    • depth step: Set equal to your material thickness or target single-pass depth.

Step 5: Generate and Export the G-Code

Once the paths and parameters are configured, generate the machine code.

  1. Select the paths you wish to cut.
  2. Navigate to Extensions > Gcodetools > Path to Gcode...
  3. Switch to the Preferences tab:
    • Enter the destination directory path in the Directory field.
    • Enter a target name in the File field (e.g., cut_contour.gcode or cut_contour.nc).
    • Set Z safe height to 0.0 to avoid unnecessary pause cycles.
  4. Switch back to the Path to Gcode tab and click Apply.

Inkscape will calculate the vectors and write the file directly to your specified folder. Load the generated .gcode or .nc file into a laser control sender (such as LaserGRBL or LightBurn) to preview the toolpath and initiate the cut.
