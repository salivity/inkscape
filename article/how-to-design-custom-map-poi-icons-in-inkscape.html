How to Design Custom Map POI Icons in Inkscape

Designing custom points of interest (POI) map icons in Inkscape involves establishing a pixel-perfect canvas, constructing a legible base container or pin, crafting simplified symbolic glyphs using Boolean path operations, and exporting the final artwork as an optimized SVG. By adhering to consistent grid metrics, uniform stroke weights, and minimal geometric detail, you can create scalable map symbology that remains sharp and recognizable across various zoom levels in GIS platforms like QGIS, ArcGIS, or web map engines.

1. Document Setup and Grid Alignment

Map icons must render cleanly at small display sizes, typically between 16×16 and 32×32 pixels.

  1. Open Inkscape and access File > Document Properties (Shift+Ctrl+D).
  2. Set the display units to pixels (px) and define the canvas width and height to your target size (e.g., 24×24 px or 32×32 px).
  3. Navigate to the Grids tab, choose Rectangular grid, and click New.
  4. Set the grid spacing to 1 px and enable snapping to grids via the Snapping toolbar. This prevents fractional pixel placement, which causes blurry rendering on digital maps.

2. Create the Base Container

Most POI icons sit inside a uniform container, such as a circle, rounded square, or traditional map pin.

  1. Circle/Square Badge: Select the Circle tool (E) or Rectangle tool (R). Hold Ctrl while dragging to create a constrained proportional shape (e.g., a 20×20 px circle on a 24×24 px canvas).
  2. Classic Map Pin:
    • Draw a circle for the upper bulb.
    • Use the Pen/Bézier tool (B) to draw an inverted triangle below the circle.
    • Select both shapes, open Path, and select Union (Ctrl++).
    • Use the Node Tool (N) to smooth the transition nodes between the circle and the point.
  3. Center the base container on your canvas using the Align and Distribute panel (Shift+Ctrl+A), setting "Relative to" to Page.

3. Build the Foreground Glyph

The interior glyph represents the specific location type (e.g., hospital, park, restaurant). Keep shapes extremely simple so they are recognizable from a distance.

  1. Assemble the silhouette using primary shapes (rectangles, ellipses, and polygons). For example, a fork and knife can be constructed by combining simple rectangles and rounded paths.
  2. Use Boolean path operations to combine or hollow out shapes:
    • Path > Union to merge adjacent shapes into a single outline.
    • Path > Difference to cut a shape out of the background.
    • Path > Exclusion to create transparent cutouts.
  3. Avoid fine lines, complex textures, or small details that disappear at standard map viewing distances.

4. Apply Visual Hierarchy and Styling

Ensure your icon has high contrast against various base map backgrounds.

  1. Open the Fill and Stroke panel (Shift+Ctrl+F).
  2. Apply a solid color fill to the base container. Use standardized color coding where appropriate (e.g., blue for services, green for recreation, red for medical).
  3. Set the foreground glyph to a contrasting color (typically white) or use Path > Difference to punch the glyph out of the container completely, creating a transparent negative space.
  4. If the icon will be overlaid directly on satellite imagery, add an outline: assign a contrasting 1 px or 2 px stroke around the outer edge.

5. Final Path Optimization and SVG Export

Map software relies on clean, lightweight vector data to maintain performance.

  1. Select all paths with strokes and choose Path > Stroke to Path (Ctrl+Alt+C) to prevent line weights from scaling inconsistently.
  2. Select all active elements of the icon and execute Path > Union to combine them into as few composite paths as possible.
  3. Delete any hidden layers, reference sketches, or unused objects.
  4. Go to File > Save As... and select Plain SVG (*.svg) instead of Inkscape SVG. This strips out Inkscape-specific metadata, resulting in smaller file sizes compatible with web mapping libraries and desktop GIS applications.
