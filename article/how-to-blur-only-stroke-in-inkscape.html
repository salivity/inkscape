How to Blur Only Stroke in Inkscape

Applying a blur effect exclusively to an object's stroke while keeping its fill sharp cannot be done with Inkscape's default Blur slider, which affects the entire object. To achieve an isolated stroke blur, you must either use the Filter Editor control to composite the fill over a blurred stroke, or separate the fill and stroke into distinct objects using the Duplicate command. This guide explains how both methods work so you can choose the best approach for your project.

The Default Blur Limitation

In the Fill and Stroke panel (Shift + Ctrl + F), the Blur slider located at the bottom applies a uniform SVG Gaussian blur to the entire selected object. Inkscape treats the fill and stroke of a single path as a combined graphic element by default, meaning any basic blur applied there softens the interior fill as well as the outer outline.

Method 1: The Filter Editor Control

The only dedicated Inkscape control that enables selective filtering on a single object is the Filter Editor.

  1. Select your object.
  2. Go to the menu bar and choose Filters > Filter Editor.
  3. Click New in the Filter Editor panel to generate a custom filter, and check the box next to it to assign it to your selected object.
  4. In the Effect list dropdown, choose Gaussian Blur, then click Add Effect.
  5. In the Effect list dropdown again, select Composite, and click Add Effect.
  6. Set up the routing nodes inside the editor:
    • Connect the input of the Gaussian Blur to Source Graphic. Adjust the blur radius using the slider below.
    • For the Composite node, connect one input to Source Graphic (your original crisp object) and the other input to the output of the Gaussian Blur.
    • Set the Composite operator to Over in the primitive attributes.

This control stack renders the sharp fill directly on top of the blurred path, effectively producing a blurred stroke effect on a single vector element.

Method 2: The Duplicate Method (Fastest Workflow)

If you prefer to avoid manually routing SVG nodes in the Filter Editor, the standard production method is isolating the stroke into its own object:

  1. Select the object and press Ctrl + D to duplicate it directly in place.
  2. Select the bottom object, open the Fill and Stroke panel, set its Fill to none (X), and leave the Stroke paint intact.
  3. Adjust the Blur slider at the bottom of the Fill and Stroke panel to soften this bottom stroke.
  4. Select the top object, turn its Stroke paint to none (X), and leave the Fill fully intact and sharp.
  5. Select both objects and press Ctrl + G to group them together for easy editing.
