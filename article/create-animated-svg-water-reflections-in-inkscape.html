Create Animated SVG Water Reflections in Inkscape

This guide explains how to generate a realistic, animated water reflection using Inkscape’s SVG filter tools and native SVG animation. You will learn how to duplicate and invert an object, build a custom displacement filter using turbulence and displacement primitives, and embed standard SVG animation tags into the code to bring the water ripples to life without requiring external JavaScript or video files.

1. Prepare the Reflection Base

  1. Open your artwork in Inkscape and select the object or group you want to reflect.
  2. Duplicate the selection by pressing Ctrl + D.
  3. Flip the duplicate vertically using the Flip selected objects vertically button (or press V).
  4. Move the inverted copy directly below the original object.
  5. With the inverted copy selected, adjust its opacity to around 70–80% in the Fill and Stroke panel.
  6. Optional: Apply a vertical linear gradient fade to the duplicate so it gradually disappears toward the bottom, mimicking light falloff on water surfaces.

2. Build the Ripple Filter with the Filter Editor

Inkscape creates water effects by combining a noise generator (feTurbulence) with a pixel-shifting filter (feDisplacementMap).

  1. Navigate to Filters > Filter Editor to open the panel.
  2. Click New to create a fresh filter and rename it to something recognizable, such as WaterRipple.
  3. In the Add primitive dropdown menu, select Turbulence and click Add primitive.
  4. With feTurbulence selected in the list, set the following parameters in the bottom panel:
    • Type: Fractal Noise
    • Base Frequency: Set X to 0.01 and Y to 0.08 (ripples are typically stretched horizontally).
    • Num Octaves: 2 (higher values increase detail at the cost of rendering performance).
  5. In the dropdown, select Displacement Map and click Add primitive.
  6. Set the connections in the editor list:
    • Connect the top input of feDisplacementMap to Source Graphic.
    • Connect the bottom input of feDisplacementMap to the Turbulence node.
  7. Select the feDisplacementMap node and set the Scale slider between 15 and 30, depending on how aggressive you want the wave distortion to be. Set X Channel to Red and Y Channel to Green.
  8. Check the box next to your new filter (WaterRipple) while the inverted reflection graphic is selected on the canvas to apply it.

3. Animate the Displacement Filter

Inkscape does not have an internal timeline for playback, but it allows you to inject SMIL animation directly into the SVG’s XML structure.

  1. Open the XML Editor by going to Edit > XML Editor (or press Ctrl + Shift + X).
  2. Locate the <svg:filter> element in the XML tree that corresponds to your WaterRipple filter.
  3. Expand it to reveal the <svg:feTurbulence> child element and select it.
  4. Click the New element node button at the top of the XML Editor panel.
  5. Enter animate as the element name and click Create.
  6. Select the newly created <animate> node and add the following attributes using the attribute input fields on the right:
    • attributeName: baseFrequency
    • dur: 5s (controls the speed of the wave motion)
    • from: 0.01 0.08
    • to: 0.01 0.04
    • repeatCount: indefinite
    • direction: Add an attribute named alternate (set via type or create an auto-reversing loop by setting values: values="0.01 0.08; 0.01 0.03; 0.01 0.08").

Alternatively, you can animate the seed attribute to create a boiling water effect:

  • attributeName: seed
  • from: 1
  • to: 50
  • dur: 3s
  • repeatCount: indefinite

4. Save and Test

  1. Save the file as an Optimized SVG or standard Inkscape SVG (File > Save As).
  2. Because Inkscape does not render SMIL animations on the live canvas, open the saved SVG file directly in any modern web browser (such as Chrome, Firefox, or Edge).
  3. Observe the wave displacement. If the motion is too abrupt or the waves are too intense, reopen Inkscape, lower the Scale in the feDisplacementMap node, or adjust the baseFrequency values in the XML animation node until the desired fluidity is reached.
