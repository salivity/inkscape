Inkscape: Adjust Blur Quality for PDF Export

When exporting vector designs containing Gaussian blurs to PDF, Inkscape automatically rasterizes the blur effect because the PDF format does not natively support SVG filter primitives. By default, this rasterization can result in pixelated, low-quality blurs. You can dramatically improve the rendering quality of Gaussian blurs by adjusting the rasterization resolution (DPI) during the export process or directly within your document preferences.

Adjust Blur Quality During PDF Export

The most direct way to change blur quality for an exported PDF is through the export settings dialog:

  1. Navigate to File > Save As... or File > Save a Copy... from the top menu.
  2. Select Portable Document Format (*.pdf) from the format dropdown list, choose your save location, and click Save.
  3. A dialog box titled Portable Document Format will appear.
  4. Locate the field labeled Resolution for rasterization (dpi).
  5. Increase this value to your desired quality:
    • 96 DPI: Standard screen quality (fast, small file size, but often blurry/pixelated on high-res displays).
    • 150–300 DPI: Standard print quality and crisp digital viewing. 300 DPI is the recommended baseline for sharp, smooth blurs.
    • 600 DPI: High-resolution professional print quality (results in larger file sizes).
  6. Click OK to export the PDF.

Adjust Blur Quality via Document Properties

You can also define the default filter effect rasterization resolution globally for the document:

  1. Open File > Document Properties (or press Ctrl + Shift + D on Windows/Linux, Cmd + Shift + D on macOS).
  2. Go to the General or Rendering section (depending on your Inkscape version).
  3. Set the Filter effects resolution (often labeled as Filter effects resolution (DPI)) to a higher value such as 300.
  4. This ensures that any new exports or preview renderings maintain consistent high-resolution smoothing across all filtered objects.

Considerations

  • File Size: Higher DPI values exponentially increase the file size because the blurred areas are converted into high-resolution bitmap images embedded inside the PDF.
  • Vector Integrity: Increasing the DPI only affects elements with filters (like Gaussian Blur, drop shadows, or glow effects). Pure vector elements like paths, text, and flat fills will remain fully scalable vector graphics regardless of this setting.
