Add CSS Hover Effects to SVG in Inkscape XML Editor

Creating interactive SVG hover states allows you to add dynamic visual feedback—such as color changes, opacity shifts, and transitions—directly into a vector file without requiring external CSS files or JavaScript. By utilizing the built-in XML Editor in Inkscape, you can assign CSS classes to vector shapes and embed a dedicated <style> element containing standard :hover pseudo-class rules. This guide demonstrates how to configure your SVG elements, inject the necessary CSS styling within Inkscape, and test the interactive results.

Step 1: Open the XML Editor

  1. Open your SVG artwork in Inkscape.
  2. Open the XML Editor by navigating to Edit > XML Editor or by pressing Shift + Ctrl + X.
  3. The XML tree on the left displays the structural hierarchy of your SVG document, including root tags, layers, and visual shapes.

Step 2: Assign a Class to the Target Shape

Using CSS classes rather than object IDs makes your code easier to manage and reuse across multiple elements.

  1. On the canvas, select the object you want to animate on hover. The corresponding node (such as <svg:path> or <svg:rect>) will automatically highlight in the XML Editor.
  2. In the right-hand panel of the XML Editor, locate the attribute input fields at the bottom.
  3. In the Attribute name field, type class.
  4. In the Attribute value field, type your class name (for example, interactive-shape).
  5. Click Set (or press Ctrl + Enter) to add the attribute to the element.

Step 3: Embed a <style> Element

To declare CSS rules, you must add an internal <style> element inside the <defs> or root <svg:svg> node.

  1. In the XML tree, select the <svg:svg> node at the very top, or the <svg:defs> node if one already exists.
  2. Click the New element node icon on the XML Editor toolbar.
  3. In the dialog, enter style and click Create.
  4. With the newly created <svg:style> element selected, select the text node child or create a new text node by clicking the New text node icon.
  5. In the content panel, specify the CSS rules along with the type attribute for the style element:
    • Set the attribute type to text/css on the <svg:style> element.

Step 4: Write the CSS Hover Rules

Input your CSS rules inside the text node of your <style> element. Include default styling, transitions, and the :hover selector.

.interactive-shape {
  fill: #007acc;
  transition: fill 0.3s ease, opacity 0.3s ease;
  cursor: pointer;
}

.interactive-shape:hover {
  fill: #ff5722;
  opacity: 0.8;
}

Ensure any conflicting inline styles on the object itself—such as a hardcoded style="fill:..." attribute—are removed from the element's node in the XML Editor so the CSS class rules take precedence, or use the !important rule in your CSS declarations.

Step 5: Save and Test

  1. Save the file in standard format via File > Save As... and select Optimized SVG or Plain SVG.
  2. Because the native Inkscape editing canvas does not continuously execute real-time CSS pseudo-class states like :hover, open the saved .svg file directly inside any modern web browser (such as Chrome, Firefox, or Safari) to preview and test the interactive hover behavior.
