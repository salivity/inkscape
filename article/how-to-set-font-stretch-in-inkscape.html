How to Set Font Stretch in Inkscape

Adjusting font stretch—such as making text condensed, narrow, or expanded—is essential for fitting text into specific layouts and achieving precise typographic designs. In Inkscape, font stretch can be set using font family variants, variable font axes, direct CSS attribute editing in the XML Editor, or manual object scaling. This guide covers how to access and apply these font-stretch properties efficiently within your vector projects.

Method 1: Use Font Styles and Variants

The standard way to apply condensed or expanded styles without distorting glyph proportions is by selecting a font family that includes dedicated width variants.

  1. Select the Text Tool (T) and click on your text.
  2. Open the Text and Font panel by pressing Shift + Ctrl + T (or navigate to Text > Text and Font).
  3. In the Font tab, browse through the Style list for the selected typeface.
  4. Look for built-in width styles such as Condensed, Semi-Condensed, Expanded, or Narrow.
  5. Select the desired style and click Apply.

Method 2: Adjust the Width Axis on Variable Fonts

If you are using an OpenType variable font (such as Roboto Flex, Inter, or Montserrat), you can freely control font stretch along a continuous slider.

  1. Select your text using the Text Tool.
  2. Open the Text and Font panel (Shift + Ctrl + T).
  3. Click on the Variations tab (visible when a variable font is selected).
  4. Locate the Width (wdth) slider.
  5. Drag the slider to the left for condensed text or to the right for expanded text.
  6. Click Apply to save the changes.

Method 3: Apply the font-stretch Property via the XML Editor

Inkscape allows direct SVG styling, enabling you to add the standard CSS font-stretch property directly to any text element.

  1. Select the text object with the Select Tool (S).
  2. Open the XML Editor by pressing Shift + Ctrl + X (or via Edit > XML Editor).
  3. Ensure the active <svg:text> or <svg:tspan> node is highlighted in the tree.
  4. In the attributes list on the right, look for the style attribute.
  5. At the bottom of the attributes panel, find the Name and Value fields.
  6. Type font-stretch into the attribute name field.
  7. In the value field, enter one of the standard SVG stretch values:
    • ultra-condensed
    • extra-condensed
    • condensed
    • semi-condensed
    • normal
    • semi-expanded
    • expanded
    • extra-expanded
    • ultra-expanded
  8. Click Set (or press Enter).

Note: This method relies on your operating system and installed fonts having matching faces that map to these SVG stretch keywords.

Method 4: Manual Horizontal Scaling

If your chosen font does not include width variations and you simply need an immediate visual stretch:

  1. Select the text using the Select Tool (S).
  2. In the top toolbar, ensure the aspect ratio lock icon is unlocked.
  3. Adjust the W (Width) percentage or absolute value to stretch or condense the text horizontally.
  4. Alternatively, click and drag the horizontal bounding box handles directly on the canvas while holding Shift to stretch outward from the center.
