Export Inkscape Palette as an ACO Swatch File

This guide explains how to extract and export your Inkscape document colors into an Adobe Color Swatch (.aco) file. While Inkscape natively uses the GIMP Palette (.gpl) format for color management, you can easily gather your document swatches and convert them into an ACO file suitable for Adobe Photoshop and other graphic design software using built-in palette tools and conversion workflows.

Step 1: Create a Document Palette in Inkscape

  1. Open your project in Inkscape.
  2. Open the Swatches panel by navigating to View > Swatches (or pressing Shift + Ctrl + W).
  3. Select the objects containing the colors you want to include in your palette.
  4. Open the Fill and Stroke panel (Shift + Ctrl + F), click the Swatch button (the small icon resembling a color palette) on the Fill tab, or click the menu in the Swatches dialog and select Auto to automatically generate swatches based on the colors used in your document.

Step 2: Save the Palette to the Native GPL Format

Inkscape stores user palettes internally as .gpl files, which serve as the base for the .aco export.

  1. In the Swatches panel, click the menu/gear icon in the upper-right corner.
  2. Select Export or locate your active document palette in the Inkscape user configuration directory:
    • Windows: %APPDATA%\inkscape\palettes
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes
    • Linux: ~/.config/inkscape/palettes
  3. Save or copy your designated palette file to a convenient location on your computer.

Step 3: Convert the GPL Palette to an ACO Swatch File

Because Inkscape does not have a native binary compiler for Photoshop .aco files built into its default installation, you must use one of the following methods to convert your exported palette:

Method A: Using an Inkscape ACO Export Extension

  1. Download a third-party ACO exporter extension for Inkscape (such as an Inkscape ASE/ACO exporter script).
  2. Place the .inx and .py files into your Inkscape extensions directory.
  3. Restart Inkscape.
  4. Go to Extensions > Export > Export to ACO/ASE, select your document swatches, and choose the output destination to save directly as an .aco file.

Method B: Converting via GIMP or Palette Converters

  1. Open your saved .gpl file using GIMP or an online palette conversion tool (such as Palette-Converter or Lospec).
  2. If using GIMP:
    • Open the Palettes dialog (Windows > Dockable Dialogs > Palettes).
    • Right-click your imported palette and select Export as... > Adobe Color Swatch (.aco).
  3. Save the resulting .aco file to your computer.

Your color palette is now fully compatible with Adobe Photoshop and other software supporting the ACO format. To load it, open Photoshop, access the Swatches panel, click the menu icon, select Import Swatches, and choose your generated .aco file.
