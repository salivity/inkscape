How to Create Animated SVGs in Inkscape with SMIL

This guide explains how to create lightweight, native SVG animations directly inside Inkscape by injecting SMIL (Synchronized Multimedia Integration Language) elements using the built-in XML Editor. By adding animation tags directly to the vector markup, you can produce self-contained, animated vector graphics that run natively in modern web browsers without requiring external CSS stylesheets or JavaScript libraries.

Step 1: Open the XML Editor in Inkscape

  1. Open your vector project in Inkscape.
  2. Select the object you wish to animate on the canvas.
  3. Open the XML Editor by navigating to Edit > XML Editor or by pressing Ctrl + Shift + X (Cmd + Shift + X on macOS).
  4. The XML tree will highlight the specific node corresponding to your selected visual element (such as a <path>, <rect>, <circle>, or <g>).

Step 2: Add a SMIL Animation Element

To animate an element with SMIL, you must add an animation tag as a child node under the target element's node.

  1. Ensure the target element is selected in the XML tree.
  2. In the top toolbar of the XML Editor panel, click the New element node icon.
  3. In the dialog box that appears, enter the name of the SMIL animation tag you want to use:
    • svg:animate: Used for basic attributes like opacity, fill, stroke, coordinates, or dimensions.
    • svg:animateTransform: Used for transformation properties such as rotate, scale, translate, or skew.
    • svg:animateMotion: Used for moving an object along a predefined path.
  4. Click Create to nest the animation element inside the selected object.

Step 3: Define Animation Attributes

Once the child node is created, select it in the XML tree to define its behavior using attributes in the right-hand panel of the XML Editor.

Example 1: Animating Opacity with svg:animate

To create a pulsing fade effect:

  1. Select the newly created <svg:animate> node.
  2. In the Attribute name input field, enter attributeName and set the Value to opacity, then click Set.
  3. Add from with a value of 1.
  4. Add to with a value of 0.2.
  5. Add dur (duration) with a value of 2s.
  6. Add repeatCount with a value of indefinite.

Example 2: Rotating an Object with svg:animateTransform

To make an object continuously rotate around its center point:

  1. Select the newly created <svg:animateTransform> node.
  2. Add attributeName with a value of transform.
  3. Add type with a value of rotate.
  4. Add from with a value of 0 cx cy (replace cx and cy with the center coordinates of your object).
  5. Add to with a value of 360 cx cy.
  6. Add dur with a value of 4s.
  7. Add repeatCount with a value of indefinite.

Step 4: Key SMIL Attributes Reference

  • attributeName: The exact SVG or CSS property to animate (e.g., fill, d, cx, width).
  • from / to: The starting and ending states of the property.
  • values: A semicolon-separated list of values (e.g., 0; 1; 0) for multi-step animations, overriding from and to.
  • dur: The duration of one animation cycle (e.g., 500ms, 3s).
  • repeatCount: How many times the animation plays (e.g., 1, 5, or indefinite).
  • begin: When the animation starts (e.g., 0s, click, or mouseover).

Step 5: Save and Preview

Inkscape's canvas does not render live SMIL playback. To view and test your animation:

  1. Go to File > Save As...
  2. Choose Optimized SVG or Plain SVG to remove proprietary Inkscape metadata, or keep standard Inkscape SVG if you plan to edit shapes further.
  3. Open the saved .svg file in any modern web browser to view the running animation.
