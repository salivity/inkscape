Split a Path into Subpaths in Inkscape

Splitting a compound vector path into individual subpaths in Inkscape allows you to edit or animate components separately. While standard separation commands often fill in holes and alter fill rules, Inkscape provides native tools to cleanly separate disconnected geometry while preserving the exact original visual appearance of your artwork.

Method 1: Using the "Split Path" Feature (Inkscape 1.2 and Newer)

The most direct way to divide disconnected subpaths without ruining overlapping cutouts or holes is the Split Path command. Unlike older methods, this tool retains the fill rules of compound shapes.

  1. Select the object using the Select Tool (S).
  2. Navigate to the top menu and select Path > Split Path.
  3. Inkscape will automatically separate every physically disconnected cluster into its own independent object while keeping interior cutouts intact.

Method 2: Using "Break Apart" with Fill Rule Adjustments

If you are using an older version of Inkscape or dealing with strictly non-overlapping subpaths, the standard Break Apart function can be used.

  1. Select your path with the Select Tool (S).
  2. Go to Path > Break Apart (or press Shift + Ctrl + K).
  3. If your path contained holes (such as the center of an "O" or "A"), the holes will turn into solid black shapes because they are now separate objects.
  4. To restore the original appearance:
    • Select the outer shape and the inner cutout shape together.
    • Go to Path > Difference (Ctrl + -) to punch the hole back out, or Path > Combine (Ctrl + K) to restore the compound path for just that specific letter or shape.

Method 3: Manually Splitting a Continuous Path

If the subpaths are still connected by lines or nodes and you want to separate them into open subpaths:

  1. Switch to the Node Tool (N).
  2. Click on the path to reveal the nodes.
  3. Select the specific node (or nodes) where you want the split to occur.
  4. Click the Break path at selected nodes button in the top tool controls bar.
  5. Go to Path > Break Apart (Shift + Ctrl + K) to convert the newly separated segments into distinct path objects.
