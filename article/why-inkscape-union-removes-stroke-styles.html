Why Inkscape Union Removes Stroke Styles

When you use the Union command on multiple intersecting strokes in Inkscape, your customized stroke styles—such as line widths, dash patterns, and colors—often vanish or distort. This occurs because Inkscape’s Boolean operations are mathematically designed to calculate overlapping closed areas (fills) rather than rendered line outlines, and SVG standards restrict any single path to a single stroke style. Understanding how Inkscape processes path data makes it easy to prevent this issue using the correct workflow.

The Math Behind the Union Command

Inkscape’s Boolean operations (Path > Union, Difference, Intersection) calculate the geometric area enclosed by vector paths. Pure strokes are mathematically zero-width lines with styling applied dynamically on top by the rendering engine. When you execute a Union operation on standard strokes:

  1. Inkscape looks for filled regions: If the paths are open or have no fill, the software treats the mathematical centerlines as the boundary or attempts to automatically close them, effectively ignoring the visual stroke thickness.
  2. Stroke styling is stripped or merged: A single SVG <path> element can only hold one set of presentation attributes (one stroke width, one stroke color, and one fill). Combining multiple separate objects into a single path forces them to inherit the style of the bottommost object in the z-order.

The Correct Workflow: Stroke to Path

To combine intersecting strokes while preserving their visual width and intersections, you must convert the rendered strokes into actual vector shapes before applying the Union command:

  1. Select all the intersecting strokes you wish to merge.
  2. Navigate to Path > Stroke to Path (shortcut: Ctrl + Alt + C on Windows/Linux, Cmd + Option + C on macOS). This converts the thickness of the line into a closed polygon with an outline and an internal fill.
  3. With the newly created shapes still selected, go to Path > Union (shortcut: Ctrl + + or Cmd + +).

This merges the overlapping geometries into a single, seamless vector shape without losing the intended visual thickness.

Alternative: Path Combine vs. Path Union

If your goal is to keep the lines editable as strokes rather than expanding them into filled shapes, do not use Union. Instead, select your strokes and go to Path > Combine (Ctrl + K). This creates a compound path containing multiple sub-paths. Note that while this keeps the lines editable as strokes, all intersecting segments in the combined path will still share the exact same stroke width, color, and dash settings. To maintain completely distinct stroke styles across different lines, they must remain separate objects.
