Blend Textures in Inkscape Using feComposite Arithmetic

This article provides a direct guide on using the SVG feComposite filter primitive with the Arithmetic operator inside Inkscape to seamlessly blend vector textures onto shapes. By leveraging mathematical coefficients to combine input graphics, this technique allows you to create custom overlays, distress effects, and complex shading without rasterizing your artwork or relying solely on standard layer blend modes.

Understanding the Arithmetic Operator in feComposite

The feComposite primitive combines two input images (in and in2) on a per-pixel basis. When set to the Arithmetic operator, it calculates the output color using the following formula:

result = k1 * in1 * in2 + k2 * in1 + k3 * in2 + k4

  • in1 (Input 1): Typically your vector texture overlay.
  • in2 (Input 2): Typically the base shape or object being textured.
  • k1: Multiplies the two inputs together (similar to Multiply blend mode).
  • k2: Controls the visibility and intensity of in1 alone.
  • k3: Controls the visibility and intensity of in2 alone.
  • k4: An offset value added to all pixels (often kept at 0 to avoid washing out blacks).

Step-by-Step Guide to Blending Textures

1. Prepare Your Artwork

  1. Create or import your base object (e.g., a colored shape or character illustration).
  2. Place your vector texture (e.g., grain, hatching, or grunge paths) directly on top of the base object.
  3. Group the base object and the texture together by selecting both and pressing Ctrl + G.

2. Open the Filter Editor

  1. Go to the menu and select Filters > Filter Editor.
  2. Click the New button in the Filter Editor panel to create a new custom filter.
  3. Rename the filter to something descriptive, such as "Vector Texture Blend".

3. Add and Route the feComposite Primitive

  1. In the drop-down menu at the bottom of the Filter Editor, select Composite and click Add Primitive.
  2. In the graphical routing area of the Filter Editor, you will see the Composite node with two connection triangles on its left side:
    • Connect the top triangle (in) to Source Graphic (which represents the top element/texture).
    • Connect the bottom triangle (in2) to Background Image or use a secondary primitive (such as Source Graphic routed through a graphic split) depending on whether the objects are grouped or stacked.
    • If working with a single group, an easier routing approach is to add an Image primitive or duplicate inputs using an Offset or Tile primitive to assign specific vector elements to each input. Alternatively, apply the filter directly to the top texture layer and set in2 to Background Image (ensure "Enable Background Image" is supported or enabled in Document Properties).

4. Configure the Arithmetic Settings

  1. Select the Composite primitive in the list to reveal its properties at the bottom of the panel.
  2. Change the Operator dropdown from Over to Arithmetic.
  3. Adjust the k values based on your desired visual outcome:
    • Subtle Dark Texture (Multiply-like): Set k1 = 1, k2 = 0, k3 = 0, k4 = 0.
    • Highlight/Bleach Texture (Add-like): Set k1 = 0, k2 = 0.5, k3 = 1, k4 = 0.
    • Soft Overlay Blend: Set k1 = 0.5, k2 = 0.5, k3 = 0.5, k4 = 0.
    • Thresholded Distress: Increase k1 above 1.0 and use negative values for k4 (e.g., k4 = -0.1) to cut through the base shape sharply.

5. Apply the Filter

  1. Select the target object or group on the canvas.
  2. Check the box next to your new filter in the Filter Editor list to apply it.
  3. Continue tweaking the numeric values in the Effect Parameters tab until the vector texture integrates smoothly with the base design.
