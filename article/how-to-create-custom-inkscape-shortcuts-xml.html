How to Create Custom Inkscape Shortcuts XML

Creating a custom keyboard shortcut configuration file (.xml) in Inkscape allows you to personalize your design workflow, map unassigned commands, and back up or transfer your layout between machines. This guide outlines how to locate the Inkscape keys directory, write the XML syntax for keybindings, discover command action IDs, and activate your custom configuration file.

Step 1: Locate the User Keys Directory

Inkscape reads custom shortcut files from a dedicated keys directory in your user configuration profile. To find the exact path on your machine:

  1. Open Inkscape.
  2. Go to Edit > Preferences (or press Ctrl + Shift + P).
  3. Select System in the left-hand menu.
  4. Locate the path listed next to User keys.

The default locations are typically:

  • Windows: %APPDATA%\inkscape\keys\
  • Linux: ~/.config/inkscape/keys/
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/keys/

If the keys folder does not exist inside your user directory, create it manually.

Step 2: Create the XML Configuration File

Inside the keys folder, create a new text file and save it with a .xml extension (for example, custom_shortcuts.xml or default.xml). If you name the file default.xml, Inkscape will apply it automatically upon launch.

Open the file in a text or code editor and structure it with the following baseline template:

<?xml version="1.0" encoding="UTF-8"?>
<keys name="Custom Shortcuts">
  <!-- Define shortcut bindings here -->
</keys>

Step 3: Add Shortcut Bindings

Each shortcut is defined using a <bind> element within the <keys> container. The element uses three primary attributes:

  • action: The internal Inkscape command identifier.
  • key: The specific key on the keyboard (e.g., a, F1, Delete).
  • modifiers: Optional modifier keys, separated by commas if multiple are used (e.g., ctrl, shift, alt).

Example XML configuration:

<?xml version="1.0" encoding="UTF-8"?>
<keys name="Custom Shortcuts">
  <!-- Bind Object Align & Distribute dialog to Ctrl + Shift + A -->
  <bind key="a" modifiers="ctrl,shift" action="DialogAlignDistribute" />

  <!-- Bind Export Dialog to 'e' without modifiers -->
  <bind key="e" action="DialogExport" />

  <!-- Unbind an existing shortcut by leaving the key empty or assigning to no action -->
  <bind key="q" modifiers="ctrl" action="" />
</keys>

Step 4: Find Inkscape Action IDs

To assign an action, you must use Inkscape's exact internal action name. You can find these IDs directly inside Inkscape:

  1. Go to Edit > Preferences > Interface > Keyboard Shortcuts.
  2. Search for the tool or command you want to rebind.
  3. The table displays the command label alongside its technical Action ID.

Alternatively, you can view the complete list of available actions via the terminal by running:

inkscape --action-list

Step 5: Activate and Test the Shortcut File

  1. Save the .xml file in your keys directory.
  2. Restart Inkscape.
  3. If the file is named default.xml, it will load automatically. If you named it something else (e.g., custom_shortcuts.xml), go to Edit > Preferences > Interface > Keyboard Shortcuts, find the keyboard configuration drop-down at the top, and select your custom profile name as defined in the name="" attribute of your XML file.
