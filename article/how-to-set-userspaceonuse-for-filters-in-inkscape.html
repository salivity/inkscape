How to Set userSpaceOnUse for Filters in Inkscape

By default, Inkscape applies SVG filter effects using the objectBoundingBox coordinate system, which calculates dimensions and positions relative to the individual object. Changing this setting to userSpaceOnUse binds the filter coordinates directly to the document's absolute coordinate system, ensuring consistent effect scaling and positioning regardless of the target object's size. This guide demonstrates how to configure filter effects to use userSpaceOnUse in Inkscape using both the XML Editor and the Filter Editor.

Why Switch to userSpaceOnUse?

The default objectBoundingBox mode scales coordinates based on the width and height of the selected object. While useful for simple drop shadows or bevels, it can cause distortions when applied to objects of different aspect ratios. The userSpaceOnUse mode fixes the filter effects to global canvas units (pixels, millimeters, etc.), which is essential for seamless tiling textures, global lighting, and uniform blur sizes across multiple elements.

Method 1: Using the XML Editor (Recommended)

The most direct and reliable method to set coordinate units is through Inkscape's built-in XML Editor.

  1. Select the Filtered Object: Click on the object that has the filter applied.
  2. Open the XML Editor: Go to Edit > XML Editor or press Ctrl + Shift + X (Cmd + Shift + X on macOS).
  3. Locate the Filter Definition:
    • In the XML tree, expand the <svg:defs> node.
    • Look for the <svg:filter> element associated with your object. (You can confirm the filter ID by checking the style attribute on your selected object, which will contain filter:url(#filterXXXX)).
  4. Modify or Add the filterUnits Attribute:
    • Click on the target <svg:filter> node in the tree.
    • In the right-hand panel, check if filterUnits already exists in the attribute list.
    • If it exists, click it, change its value in the lower text field to userSpaceOnUse, and click Set.
    • If it does not exist, type filterUnits in the attribute name field, enter userSpaceOnUse in the value field, and click Set.
  5. Modify or Add primitiveUnits (Optional):
    • If you also want individual filter primitives (such as blur radiuses or offset distances) to use canvas coordinates rather than object percentages, add or update the primitiveUnits attribute on the same <svg:filter> node.
    • Enter primitiveUnits as the attribute name and set its value to userSpaceOnUse.

Method 2: Adjusting Coordinates via the Filter Editor

You can adjust filter boundaries and coordinate behaviors through the Filter Editor interface.

  1. Open the Filter Editor: Navigate to Filters > Filter Editor... from the top menu.
  2. Select the Active Filter: In the list of filters, select the filter applied to your object.
  3. Access Filter General Settings:
    • Click on the Filter General Settings tab located at the bottom of the Filter Editor dock.
  4. Adjust Region Units:
    • Locate the bounding box parameters: X, Y, Width, and Height.
    • Switch the coordinate drop-down fields or units from percentage values (relative to the object) to absolute unit measurements (such as px, mm, or pt).
    • When absolute units are assigned to the filter region, Inkscape automatically adapts the underlying SVG code to calculate coordinates against the user space rather than scaling proportionally with the object's bounding box.
