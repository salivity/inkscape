How to Reverse a Linear Gradient in Inkscape

Reversing the color flow of an existing linear gradient in Inkscape allows you to invert the transition of colors across an object without having to rebuild the gradient from scratch. This article covers the quickest methods to flip a gradient's direction, including using the built-in toolbar shortcut, swapping the gradient nodes directly on the canvas, and managing gradient stops.

Method 1: Use the Reverse Gradient Button (Fastest)

The most direct way to flip the colors of an existing gradient is using the dedicated control button:

  1. Select the object containing the linear gradient using the Selection Tool (S).
  2. Switch to the Gradient Tool by pressing G (or clicking the Gradient icon in the left-hand toolbox).
  3. Look at the Tool Controls Bar at the top of the screen.
  4. Locate and click the Reverse the direction of the gradient button (represented by an icon with two opposing horizontal arrows).

The color flow will immediately flip across the object while keeping the coordinates of the gradient line intact.

Method 2: Manually Swap the Gradient Handles

If you want to reverse the flow while simultaneously adjusting the angle or placement, you can move the on-canvas handles:

  1. Select the object and press G to activate the Gradient Tool.
  2. Notice the gradient line across your object, marked by a square node (the starting stop) and a circular node (the ending stop).
  3. Click and drag the square node to the position of the circular node.
  4. Drag the circular node to the original position of the square node.

Method 3: Swap Colors Using the Fill and Stroke Panel

If you prefer working numerically or through palette panels:

  1. Open the Fill and Stroke panel by pressing Shift + Ctrl + F.
  2. Ensure your object is selected and navigate to the Fill or Stroke paint tab (depending on where the gradient is applied).
  3. Click on the gradient preview bar to access the gradient stops.
  4. Select the first stop and note its color value, then select the final stop and swap their respective hex codes or color values.
