How to Migrate Inkscape Settings to a New OS

Migrating your complete Inkscape configuration to a fresh operating system installation allows you to preserve custom shortcuts, interface layouts, palettes, templates, and third-party extensions. By locating your source user configuration directory, copying the core data, and placing it into the corresponding folder on your new OS, you can seamlessly restore your preferred working environment without manual reconfiguration.

1. Locate the Inkscape Configuration Folder on the Old System

The easiest way to find your configuration folder is directly through Inkscape:

  1. Open Inkscape on your current system.
  2. Navigate to Edit > Preferences (or press Ctrl + Shift + P / Cmd + Shift + P).
  3. Select System from the left navigation panel.
  4. Look for the User configuration path.
  5. Click the Open button next to the path to open the directory in your file manager.

If you cannot open Inkscape, navigate manually to the default paths:

  • Windows: %APPDATA%\inkscape\ (typically C:\Users\<YourUsername>\AppData\Roaming\inkscape\)
  • Linux: ~/.config/inkscape/ (or ~/.var/app/org.inkscape.Inkscape/config/inkscape/ for Flatpak)
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/

2. Back Up Your Configuration Files

Copy the entire inkscape folder to an external drive, cloud storage, or local network share. The folder contains key components that define your workflow:

  • preferences.xml: Contains core application settings, interface arrangements, tool defaults, and recent history.
  • keys/: Stores custom keyboard shortcut layouts (default.xml or custom shortcut files).
  • extensions/: Holds custom Python scripts and extension definition files (.inx).
  • palettes/: Stores user-imported color palettes (.gpl).
  • templates/: Holds custom document presets and startup files (default.svg).
  • symbols/ and paint/: Stores custom vector symbols, patterns, and hatches.
  • ui/: Contains custom stylesheets (user.css) and custom toolbar configurations.

3. Install Inkscape on the New Operating System

Download and install the same version (or newer) of Inkscape on your new OS installation. Launch the application once and close it completely; this initial launch creates the required directory tree on the new system.

4. Restore the Configuration on the New System

  1. Locate the new Inkscape configuration path on your target system using the paths listed in Step 1.
  2. Ensure Inkscape is completely closed.
  3. Paste the contents of your backup folder into the target inkscape folder, overwriting existing files when prompted.

Note: If you are migrating across different operating systems (e.g., Windows to Linux), certain external extensions that rely on OS-specific system libraries or hardcoded file paths may require you to reinstall Python dependencies via your new operating system's package manager or terminal.

5. Relaunch and Verify

Open Inkscape on your new operating system. Check that your custom templates appear in the startup dialog, keyboard shortcuts respond as expected, and your palettes and extensions are visible in their respective menus.
