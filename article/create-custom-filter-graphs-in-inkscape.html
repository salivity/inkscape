Create Custom Filter Graphs in Inkscape

Inkscape’s Filter Effects dialog enables the creation of sophisticated vector rasterization and styling effects by chaining basic operations called filter primitives. This guide provides a step-by-step walkthrough on how to open the Filter Effects interface, add primitives, connect inputs and outputs to build a visual graph, and fine-tune parameters to produce custom SVG filter effects.

1. Open the Filter Effects Dialog

To access the filter graph workspace:

  • Navigate to the top menu and select Filters > Filter Editor... (labeled as Filter Effects in some versions).
  • A dockable panel will appear containing three main areas: the Filters list, the Effect list / Graph view, and the Filter Primitive settings panel.

2. Create and Assign a New Filter

  • In the left panel under the Filters list, click the New button to create an empty filter (e.g., filter1).
  • Rename the filter by double-clicking its name if desired.
  • Select the vector object on your canvas that you want to style.
  • Check the box next to your new filter's name to assign the filter to the selected object. The object will initially look unchanged because no primitives are in the graph.

3. Add Filter Primitives

Filter primitives are the building blocks (nodes) of your filter graph, such as Gaussian Blur, Offset, Composite, or Color Matrix.

  • In the dropdown menu labeled Add primitive:, select the desired effect block (for example, Gaussian Blur).
  • Click the Add button. The primitive will appear in the central graph area.
  • Repeat this step to add subsequent primitives required for your effect, such as an Offset or Merge node.

4. Connect Nodes in the Filter Graph

The visual graph uses connection lines (pipes) to pass visual data from standard inputs or previous primitive outputs into downstream primitives:

  • Standard Inputs: The graph includes standard input sources such as Source Graphic (the original colored vector), Source Alpha (the original shape's silhouette/transparency), and Background Image.
  • Routing Connections: Each primitive listed in the graph has connection points representing its inputs. Click and drag a connection line from an input point of a primitive to the output of a preceding primitive or a standard source.
  • Multi-Input Nodes: Nodes like Merge, Composite, or Blend accept multiple input connections. Drag lines to link distinct branches of your graph into these multi-input nodes to combine effects.

5. Adjust Primitive Parameters

  • Select any primitive in the central list to reveal its specific controls in the lower panel.
  • Adjust node-specific properties, such as the standard deviation for Gaussian Blur, horizontal and vertical distances for Offset, or mathematical operations (Over, In, Out, Atop) for Composite.
  • The canvas updates in real time to reflect parameter adjustments.

6. Manage and Reuse the Filter Graph

  • Unconnected primitives or unused branches can be removed by selecting the primitive and clicking Remove.
  • Use the Duplicate button to clone an entire filter setup if you want to create variations without rebuilding the graph from scratch.
  • Once created, the custom filter remains stored within the document and can be applied to any other vector object by selecting the object and checking the filter’s name in the dialog.
