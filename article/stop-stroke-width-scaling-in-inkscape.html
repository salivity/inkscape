Stop Stroke Width Scaling in Inkscape

When resizing vector objects in Inkscape, the program is configured by default to scale the stroke width proportionally with the object. This article provides straightforward methods to disable this behavior so your outline thicknesses remain constant no matter how much you enlarge or shrink your artwork.

Method 1: The Tool Controls Bar (Quickest Method)

The fastest way to toggle stroke scaling on or off is directly from the workspace interface.

  1. Click the Select and Transform objects tool (the black arrow icon) in the left toolbar, or press S (or F1).
  2. Look at the Tool Controls Bar running horizontally across the top of the canvas.
  3. Locate the four transformation toggle buttons on the right side of the control bar.
  4. Click the icon that looks like a box with corner lines, labeled "When scaling objects, scale the stroke width by the same proportion".
  5. Ensure the button is deselected (not highlighted).

Once turned off, any object resized using the selection handles will retain its exact stroke width.

Method 2: Inkscape Preferences (Permanent Setting)

If you want to ensure the setting persists across all sessions and tools, configure it in the global preferences.

  1. Open the Preferences window by going to Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  2. In the left sidebar, expand the Behavior category and select Transforms.
  3. Locate the Store transformation and scaling options.
  4. Uncheck the box labeled Scale stroke width.
  5. Close the Preferences dialog.

How to Verify It Works

  1. Draw a rectangle or circle and assign it a stroke width of 5 px using the Fill and Stroke panel (Ctrl + Shift + F).
  2. Drag the corner handles to scale the shape to twice its size.
  3. Check the Stroke style tab in the Fill and Stroke panel. The stroke width will remain exactly 5 px instead of doubling to 10 px.
