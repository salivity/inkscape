Convert Illustrator ASE to Inkscape Palette via CLI

This guide demonstrates how to convert Adobe Swatch Exchange (.ase) files into Inkscape-compatible palette (.gpl) files using the command line. Because Adobe Illustrator saves palettes in a proprietary binary format and Inkscape reads plain-text GIMP Palette files, a command-line interface (CLI) conversion tool is the fastest method to batch process and integrate Adobe swatches directly into your open-source design workflow.

1. Install the CLI Converter

The most efficient way to convert .ase files to .gpl via the terminal is using the Python-based ase-to-gpl utility.

Ensure you have Python and pip installed, then run:

pip install ase-to-gpl

Alternatively, if you use Node.js, you can use the ase2gpl npm package:

npm install -g ase2gpl

2. Run the Conversion Command

Once installed, execute the conversion command by pointing the tool to your input .ase file and defining the output .gpl file name.

Using the Python utility:

ase-to-gpl input_palette.ase output_palette.gpl

Using the Node.js utility:

ase2gpl input_palette.ase -o output_palette.gpl

To batch-convert multiple .ase files in a directory on Linux or macOS:

for file in *.ase; do
    ase-to-gpl "$file" "${file%.ase}.gpl"
done

3. Move the Palette to Inkscape

Inkscape requires .gpl files to be placed in its user palettes directory to make them visible in the application interface. Move your generated file to the appropriate path for your operating system:

  • Linux: 
    mv output_palette.gpl ~/.config/inkscape/palettes/
  • macOS: 
    mv output_palette.gpl ~/Library/Application\ Support/org.inkscape.Inkscape/config/inkscape/palettes/
  • Windows (Command Prompt): 
    move output_palette.gpl "%APPDATA%\inkscape\palettes\"

4. Access the Palette in Inkscape

Restart Inkscape if it is currently running. Open the palette bar at the bottom of the window, click the small arrow in the bottom-right corner to open the palette list, and select your newly converted palette from the menu.
