Inkscape Mesh Gradient Tool: Multi-Color Shading Guide

Inkscape's Mesh Gradient tool allows vector artists to create photorealistic, multi-directional color transitions and organic shading on any vector object. By dividing an object into a flexible grid of interconnected patches, each defined by independently colorable corner nodes and adjustable Bézier handles, you can control the flow and blend of complex colors far beyond standard linear or radial gradients.

1. Activating and Applying the Mesh Tool

  1. Select the vector path or shape you wish to shade.
  2. Choose the Mesh Tool from the left-hand toolbar (or press F7 / click the grid-like gradient icon).
  3. On the top Tool Controls bar, configure the initial grid settings:
    • Choose whether the mesh applies to the Fill or Stroke.
    • Set the initial number of Rows and Columns (start simple, such as 2x2 or 3x3, as you can add more later).
  4. Click and drag over your selected object, or double-click the object to generate the default mesh grid over its surface.

2. Understanding the Mesh Components

A mesh gradient consists of three key components:

  • Corner Nodes (Diamonds): Located at the intersections of the grid lines. These control the actual color values applied to the gradient.
  • Edge Handles (Circles/Bézier Handles): Attached to the lines connecting corner nodes. Moving these handles curves the gradient flow and changes how color stretches across the surface.
  • Patches: The four-sided areas bounded by four corner nodes and four edge lines.

3. Assigning Colors to Nodes

To build multi-color shading:

  1. Click on any corner node (diamond) to select it.
  2. Select a color using the Color Palette at the bottom of the screen, the Fill and Stroke panel (Shift + Ctrl + F), or the Eyedropper Tool (D) to sample from a reference image.
  3. To apply the same color to multiple points, hold Shift and click each node, or click and drag a selection box around multiple nodes, then pick your desired color.

4. Shaping and Refining the Gradient Flow

  • Bending Color Lines: Click and drag the circular Bézier handles along the grid lines to curve the gradient. This allows highlights and shadows to wrap naturally around curved objects.
  • Moving Nodes: Click and drag any corner node to reposition where a specific color concentration sits on the object.
  • Adding More Detail: To insert an extra row or column for finer shading, double-click on any outer or inner grid line where you need more color stops.
  • Deleting Mesh Lines: Select a node on the line you want to remove and press Delete or Backspace to simplify the mesh.
