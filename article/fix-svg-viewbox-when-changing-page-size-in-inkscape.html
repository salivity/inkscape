Fix SVG ViewBox When Changing Page Size in Inkscape

Modifying canvas dimensions in Inkscape often introduces coordinate mismatches between the root SVG dimensions and the internal viewBox attribute, causing artwork to shift, scale unexpectedly, or crop. This article explains how Inkscape manages the relationship between physical page dimensions and the viewBox, detailing the direct adjustments in Document Properties, the XML Editor, and the interactive Page tool required to recalculate and normalize coordinate mapping accurately.

The Relationship Between Page Size and viewBox

An SVG element contains two sets of sizing values: the viewport attributes (width and height) and the viewBox attribute (min-x, min-y, width, height).

  • width and height define the display size or physical footprint of the SVG file in CSS units (such as pixels, millimeters, or inches).
  • viewBox defines the internal coordinate system and aspect ratio mapped inside that viewport.

When you alter the page size in Inkscape, the software automatically attempts to reconcile the new canvas boundary with the existing coordinate system. If the aspect ratio changes, or if the document scale is decoupled from the display units, the viewBox can retain old coordinate boundaries, leading to misplaced graphics or scaling artifacts when rendered in web browsers.

Method 1: Adjusting Scale in Document Properties

The most common cause of viewBox distortion after resizing is a mismatched document scale factor. Inkscape manages internal viewBox recalculations via the Document Properties panel.

  1. Press Shift + Ctrl + D (or go to File > Document Properties).
  2. Under the Page tab, set your new dimensions using the Custom size fields.
  3. Switch to the internal scaling controls (labeled Scale in Inkscape 1.0 and newer, found under the Page display settings).
  4. Verify the Scale x and Scale y values. For standard 1:1 pixel rendering, set the display units to pixels (px) and ensure the scale factor is set to 1.00000.
  5. When the scale is set to 1.0, Inkscape automatically updates the viewBox width and height values to match your canvas width and height exactly.

If you resize a page by clicking Resize page to content, Inkscape will recalculate the min-x and min-y coordinates of the viewBox to match the bounding box of your selected objects, setting the new origin point automatically.

Method 2: Manual Recalculation via the XML Editor

If an imported SVG has existing transforms or a locked coordinate system that Inkscape fails to update automatically, you can edit the attributes directly within the application.

  1. Press Shift + Ctrl + X to open the built-in XML Editor.
  2. Select the top-level node: <svg:svg id="svg...">.
  3. Locate the viewBox attribute in the right-hand panel. It consists of four space- or comma-separated numbers: min-x min-y width height.
  4. Locate the width and height attributes of the SVG root.
  5. If you want a standard origin without offsets, set the first two values to 0 0.
  6. Update the third and fourth values to match your new document width and height (expressed in user units/pixels). For example, if your new page size is 1920×1080 px, change the viewBox to: 
    0 0 1920 1080
  7. Click Set (or press Ctrl + Enter) to apply the changes.
  8. Inspect your visual canvas. If the graphics appear displaced, select all elements (Ctrl + A) and move them into the new viewport coordinates manually, or use the Align and Distribute panel (Shift + Ctrl + A) to center them within the page.

Method 3: Using the Interactive Page Tool

Inkscape 1.2 and later versions include a dedicated Page Tool that allows multiple pages and dynamic resizing directly on the canvas without breaking coordinate systems.

  1. Press R or select the Create and edit pages tool from the left toolbar.
  2. Click on the page boundary you want to edit.
  3. Drag the boundary handles to resize the canvas interactively, or enter precise measurements into the top tool control bar.
  4. Using this tool forces Inkscape to update the underlying SVG viewBox coordinates dynamically while maintaining the origin and keeping layers aligned with their absolute coordinate positions.

Preventing Coordinate Drift on Export

To ensure the recalculated viewBox remains intact without Inkscape injecting proprietary wrapper code:

  • Save your work using File > Save As... and select Optimized SVG (*.svg) or Plain SVG (*.svg).
  • In the Optimized SVG export dialog, ensure that options altering the coordinate precision or removing the viewBox are unchecked, preserving your exact recalculations for deployment in web development and production pipelines.
