How to Cut Objects Using Inkscape Eraser Tool

This guide provides a straightforward overview of using the Eraser tool in Cut mode within Inkscape. You will learn how to configure the tool settings, draw cut lines across vector paths, and separate the sliced components into individual, editable vector objects.

1. Prepare Your Vector Objects

The Eraser tool's Cut mode works directly on vector paths.

  • If you are working with primitive shapes (rectangles, circles, stars) or text, convert them to paths first by selecting them and going to Path > Object to Path (or press Shift + Ctrl + C).
  • If you only want to slice specific objects on your canvas, select them using the Select Tool (S). If nothing is selected, the tool will cut through all unlocked objects in its path.

2. Activate the Eraser Tool

Select the Eraser Tool from the vertical toolbox on the left side of the screen, or press the shortcut Shift + E.

3. Switch to Cut Mode

Look at the Tool Controls Bar at the top of the workspace. You will see three operation modes for the Eraser:

  1. Delete objects (red 'X' icon)
  2. Cut out from paths and shapes (scissors icon)
  3. Clip from objects (eraser over a square icon)

Click the middle icon: Cut out from paths and shapes mode.

4. Adjust Tool Properties

Before slicing, fine-tune the cut behavior using the settings in the top bar:

  • Width: Controls the thickness of the cut line. Set this to a lower value (e.g., 1 to 5) for a thin, precise slice, or a higher value to remove a wider strip of the shape.
  • Cap: Choose the shape of the stroke ends (round, square, or butt) if you are erasing wide sections.
  • Break apart cut paths: Toggle this icon on if you want Inkscape to automatically separate the resulting pieces into independent objects.

5. Draw the Cut Line

  • Click and drag your cursor across the vector shape where you want the cut to occur. A red guideline will appear, showing the path of your cut.
  • Release the mouse button. Inkscape will calculate the intersection and slice through the shape along the drawn path.

6. Separate the Cut Pieces

If the sliced parts still move together as a single compound path:

  1. Select the sliced object using the Select Tool (S).
  2. Navigate to Path > Break Apart (or press Shift + Ctrl + K).
  3. Click outside the canvas to deselect, then click on the individual sections to move, recolor, or edit them independently.
