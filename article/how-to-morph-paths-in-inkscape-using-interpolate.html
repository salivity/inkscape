How to Morph Paths in Inkscape Using Interpolate

Morphing between two vector shapes in Inkscape is done using the built-in Interpolate extension, which automatically generates intermediate shapes between a starting path and an ending path. This guide explains how to properly prepare your vector objects, configure the interpolation parameters, and execute the morphing effect to create smooth transitions, gradients, or frame-by-frame vector animations.

Step 1: Prepare the Source Objects

  1. Open your document in Inkscape and draw the two shapes you want to morph between: a starting shape and an ending shape.
  2. Select both objects using the Select Tool (S).
  3. Convert both shapes into vector paths by navigating to Path > Object to Path (or press Shift + Ctrl + C).
  4. If your shapes consist of multiple sub-paths, ungroup them or select Path > Combine (Ctrl + K) to ensure each shape acts as a single path object.

Step 2: Optimize Node Counts (Recommended)

While Inkscape can interpolate paths with differing node counts, matching the number of nodes produces the cleanest morph:

  1. Switch to the Node Tool (N).
  2. Inspect the node count of both paths on the status bar at the bottom.
  3. Add nodes to the simpler path by double-clicking on segments until both shapes have a similar number and distribution of nodes.
  4. Ensure both paths travel in the same direction. If a shape twists during interpolation, select one path and go to Path > Reverse.

Step 3: Open the Interpolate Tool

  1. Select both paths simultaneously by holding Shift and clicking on each.
  2. Navigate to Extensions > Generate from Path > Interpolate... in the top menu.

Step 4: Configure the Interpolation Settings

In the Interpolate dialog box, adjust the following parameters:

  • Exponent: Set this to 0.0 for evenly spaced intermediate steps. Values higher or lower than 0 create an accelerating or decelerating distribution.
  • Interpolation Steps: Enter the number of intermediate shapes you want to create between the start and end paths.
  • Interpolation Method: Choose 1 for standard linear node interpolation, or 2 for smoother curve transitions.
  • Duplicate Endpaths: Check this box if you want copies of the original starting and ending paths included inside the generated group.
  • Interpolate Style: Check this option to blend colors, stroke widths, and opacity gradually between the two shapes.

Step 5: Preview and Apply

  1. Check the Live Preview box at the bottom of the dialog to see the result on your canvas in real time.
  2. Adjust the steps or method if the shape distortion needs refinement.
  3. Click Apply to generate the vector morph steps, then click Close.

The output will be created as a new group containing all generated intermediate paths placed between your original shapes. You can ungroup them (Ctrl + Shift + G) to edit, recolor, or reposition individual frames.
