Subscript and Superscript Formatting in Inkscape

Adjusting text to subscript or superscript in Inkscape is a straightforward process used frequently for mathematical equations, chemical formulas, and footnote markers. This guide explains how to quickly apply subscript and superscript styling to selected characters using built-in toolbar buttons, keyboard shortcuts, and manual baseline adjustments.

Method 1: Using the Text Tool Controls Bar

  1. Select the Text tool from the left toolbar or press T (or F8).
  2. Click inside your text object and highlight the specific characters you want to modify.
  3. Look at the Tool Controls Bar at the top of the screen.
  4. Click the Toggle Subscript icon (\(x_2\)) to lower the text, or click the Toggle Superscript icon (\(x^2\)) to raise the text.
  5. Click the icon again if you need to revert the characters to normal text.

Method 2: Using Baseline Shift Keyboard Shortcuts

If you prefer using keyboard shortcuts or need custom placement beyond the default settings:

  1. Select the Text tool and highlight the characters to be adjusted.
  2. Hold Alt and press the Up Arrow key to shift the selected characters upward (superscript).
  3. Hold Alt and press the Down Arrow key to shift the selected characters downward (subscript).
  4. Each keypress moves the character by a set amount, allowing you to fine-tune the vertical offset.
  5. Highlight the text and adjust the Font Size dropdown in the top toolbar to proportionally scale down the characters as needed.

Method 3: Manual Precise Adjustments

  1. Highlight the target characters with the Text tool.
  2. Locate the Shift baseline field in the top Tool Controls bar (represented by vertical offset arrows).
  3. Enter a positive numerical value to move the text up into a superscript position, or enter a negative numerical value to move it down into a subscript position.
  4. Adjust the Font size in the same toolbar to match your required typographic proportions.
