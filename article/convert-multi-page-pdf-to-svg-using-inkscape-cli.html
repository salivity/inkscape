Convert Multi-Page PDF to SVG Using Inkscape CLI

Converting a multi-page PDF into separate SVG files using the Inkscape command-line interface (CLI) is an efficient way to automate vector graphics extraction. While Inkscape does not provide a single built-in flag to automatically split and export every page simultaneously, you can achieve this by passing the --pdf-page option inside a simple shell loop. This guide covers how to identify the total page count and batch-export each page to its own SVG file across Linux, macOS, and Windows.

The Basic Command Structure

Modern versions of Inkscape (v1.0 and later) use the following command structure to extract a specific page from a PDF and output it as an SVG:

inkscape input.pdf --pdf-page=1 --export-filename="page_1.svg"
  • --pdf-page=1: Specifies the 1-based index of the page you want to import.
  • --export-filename="page_1.svg": Defines the output file name. The .svg extension instructs Inkscape to format the output as an SVG.

Method 1: Automating with Bash (Linux / macOS / WSL)

To automate the conversion across all pages, use a shell script that determines the total page count using pdfinfo (from poppler-utils) and iterates through each page.

#!/usr/bin/env bash

PDF="document.pdf"

# Extract total page count
PAGES=$(pdfinfo "$PDF" | awk '/^Pages:/ {print $2}')

# Loop through each page and export to SVG
for (( i=1; i<=PAGES; i++ )); do
    echo "Exporting page $i of $PAGES..."
    inkscape "$PDF" --pdf-page="$i" --export-filename="page_${i}.svg"
done

If pdfinfo is not installed, you can use qpdf:

PAGES=$(qpdf --show-npages "$PDF")

Method 2: Automating with PowerShell (Windows)

On Windows, you can automate this using PowerShell without third-party page-counting tools by looping until Inkscape encounters an invalid page, or by using a predefined range.

If you know the page count (e.g., 10 pages):

$pdf = "document.pdf"
$totalPages = 10

for ($i = 1; $i -le $totalPages; $i++) {
    Write-Host "Exporting page $i..."
    & inkscape $pdf --pdf-page=$i --export-filename="page_$i.svg"
}

Useful Optional Flags

You can append additional flags to the export command to modify the SVG output:

  • --export-text-to-path: Converts all fonts and text elements into pure vector paths, ensuring the SVG renders consistently across systems where the source fonts are not installed.
  • --export-plain-svg: Removes Inkscape-specific metadata from the output file, generating a standard, lightweight SVG.

Example with flags:

inkscape input.pdf --pdf-page=1 --export-plain-svg --export-text-to-path --export-filename="page_1.svg"
