Create an Inkscape Voronoi Extension in Python

This guide explains how to build a custom Inkscape extension using Python and the inkex library to generate randomized Voronoi tessellations directly on your canvas. By coupling an XML definition file (.inx) for the user interface with an underlying Python script (.py) leveraging scipy.spatial, you will learn how to define custom input parameters, calculate Voronoi regions from pseudo-random points, and render the resulting geometry as native SVG paths.

Extension File Architecture

An Inkscape extension requires two primary files placed inside the user extensions directory:

  • Linux: ~/.config/inkscape/extensions/
  • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/
  • Windows: %APPDATA%\inkscape\extensions\

These files consist of an XML configuration file (.inx) describing the user interface and menu placement, and a Python script (.py) implementing the generation logic.

1. Create the Extension Definition (random_voronoi.inx)

Save the following XML content as random_voronoi.inx in your Inkscape extensions directory. This file registers the extension under the Extensions > Generate menu and provides controls for point count, width, and height.

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespace/inkscape/extension">
    <name>Random Voronoi Tessellation</name>
    <id>org.inkscape.generate.random_voronoi</id>
    <param name="num_points" type="int" min="3" max="1000" gui-text="Number of Points:">50</param>
    <param name="width" type="float" min="10.0" max="5000.0" gui-text="Width (px):">500.0</param>
    <param name="height" type="float" min="10.0" max="5000.0" gui-text="Height (px):">500.0</param>
    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Generate"/>
        </effects-menu>
    </effect>
    <script>
        <command location="inx" interpreter="python">random_voronoi.py</command>
    </script>
</inkscape-extension>

2. Create the Python Script (random_voronoi.py)

Inkscape packages its own Python environment, which includes inkex, numpy, and scipy. Create random_voronoi.py in the same directory. This script reads the parameters, creates random coordinates, calculates the Voronoi network using scipy.spatial.Voronoi, and appends the path segments into a group element on the active layer.

#!/usr/bin/env python3
import random
import numpy as np
from scipy.spatial import Voronoi
import inkex
from inkex import Group, PathElement

class RandomVoronoiExtension(inkex.EffectExtension):
    def add_arguments(self, pars):
        pars.add_argument("--num_points", type=int, default=50, help="Number of random seed points")
        pars.add_argument("--width", type=float, default=500.0, help="Width of generation bounding box")
        pars.add_argument("--height", type=float, default=500.0, help="Height of generation bounding box")

    def effect(self):
        width = self.options.width
        height = self.options.height
        num_points = self.options.num_points

        # Generate uniform random points
        points = np.array([
            [random.uniform(0, width), random.uniform(0, height)]
            for _ in range(num_points)
        ])

        # Compute Voronoi diagram
        vor = Voronoi(points)

        # Create a group to store the segments
        container = Group()
        container.set("inkscape:label", "Voronoi Tessellation")
        self.svg.get_current_layer().append(container)

        path_data = []

        # Iterate through finite ridge vertices
        for simplex in vor.ridge_vertices:
            simplex = np.asarray(simplex)
            if np.all(simplex >= 0):
                p1 = vor.vertices[simplex[0]]
                p2 = vor.vertices[simplex[1]]

                # Optional bounding check to keep paths within defined area
                if (0 <= p1[0] <= width and 0 <= p1[1] <= height and
                    0 <= p2[0] <= width and 0 <= p2[1] <= height):
                    path_data.append(f"M {p1[0]},{p1[1]} L {p2[0]},{p2[1]}")

        # Render paths to SVG
        if path_data:
            elem = PathElement()
            elem.set("d", " ".join(path_data))
            elem.set("style", "stroke:#000000;stroke-width:1;fill:none;")
            container.append(elem)

if __name__ == "__main__":
    RandomVoronoiExtension().run()

3. Running the Extension in Inkscape

  1. Restart Inkscape to allow the application to discover the new .inx metadata.
  2. Open a document and navigate to Extensions > Generate > Random Voronoi Tessellation.
  3. Set your desired point density, width, and height in the dialog box.
  4. Click Apply. Inkscape will execute the Python script, calculate the Delaunay dual to form the Voronoi ridge vertices, and draw the tessellation on your active layer as an SVG path group.
