How to Enable Discretionary Ligatures in Inkscape

Inkscape offers advanced typographic controls through its dedicated Text dialog, allowing designers to unlock specialized OpenType features embedded in modern typefaces. This guide provides a direct, step-by-step walkthrough on how to navigate the OpenType feature settings to enable discretionary ligatures, transforming standard character pairs into decorative glyphs for your vector artwork.

Step 1: Select Your Text

  1. Open your project in Inkscape.
  2. Select the Text Tool from the left toolbar (or press T).
  3. Click and drag across the text you wish to modify, or click on the text object with the Select Tool (S) to select the entire block.
  4. Ensure the font you are using actually supports OpenType discretionary ligatures (often abbreviated as dlig), as fonts without these embedded tables will not show any visual change.

Step 2: Open the Text and Font Dialog

  1. Navigate to the top menu bar and click on Text.
  2. Select Text and Font... from the dropdown menu, or press the keyboard shortcut Shift + Ctrl + T.
  3. The Text and Font dock will open on the right side of the screen.

Step 3: Access the OpenType Features Tab

  1. Inside the Text and Font panel, locate the tabs near the top: Font, Text, and Features.
  2. Click on the Features tab. This panel exposes all available OpenType tables provided by the active font family.

Step 4: Toggle Discretionary Ligatures

  1. Scroll through the categories in the Features tab to locate the Ligatures section.
  2. Find the checkbox labeled Discretionary Ligatures (feature code dlig).
  3. Check the box to activate the feature.

Step 5: Apply the Changes

  1. Click the Apply button at the bottom-right corner of the Text and Font panel.
  2. Inkscape will re-render the selected text, replacing applicable character combinations (such as "st", "ct", or specific flourished pairings) with the font's designed discretionary ligatures.
