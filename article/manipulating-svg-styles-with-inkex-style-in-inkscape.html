Manipulating SVG Styles with inkex.Style in Inkscape

Manipulating SVG styling programmatically is a core task when developing Inkscape extensions using Python. This guide demonstrates how to inspect, add, update, and remove element styles directly using the inkex.Style class, which behaves like a standard Python dictionary representing inline SVG CSS properties.

Accessing and Inspecting Element Styles

In modern Inkscape extensions (inkex 1.0 and newer), SVG elements represent their inline style attribute through the style property. This property returns an inkex.Style object, which implements Python's collections.abc.MutableMapping interface.

To read a style property, use standard dictionary access or the .get() method to handle missing keys gracefully:

# Access an element from the document
element = self.svg.selected.first()

# Retrieve a style property
fill_color = element.style.get('fill', 'none')
stroke_width = element.style.get('stroke-width', '1px')

Modifying and Adding Style Properties

Because inkex.Style acts as a dictionary, modifying or adding CSS rules requires only assigning a value to the target key. Values should typically be strings conforming to standard SVG/CSS specifications.

# Update existing styles or add new ones
element.style['fill'] = '#ff5733'
element.style['stroke'] = '#000000'
element.style['stroke-width'] = '2.5px'
element.style['fill-opacity'] = '0.8'

Changes made to element.style update the internal dictionary immediately and are serialized back to the element's style attribute upon document export.

Removing Style Properties

To eliminate a specific style declaration so that an element inherits styling from a parent group or default stylesheet, use the standard del statement or the .pop() method:

# Remove a style property using del
if 'stroke' in element.style:
    del element.style['stroke']

# Safely remove a property using pop
element.style.pop('stroke-dasharray', None)

To clear all inline styles from an element entirely:

element.style.clear()

Creating and Assigning a New inkex.Style

You can instantiate inkex.Style independently and assign it to an element. The constructor accepts a raw CSS string, a dictionary, or keyword arguments:

from inkex import Style

# From a CSS string
element.style = Style("fill:#00ff00;stroke:#333333;stroke-width:1px")

# From a dictionary
element.style = Style({'fill': 'blue', 'opacity': '0.5'})

# Updating multiple styles at once
element.style.update({
    'fill-rule': 'evenodd',
    'stroke-linecap': 'round'
})

Complete Extension Example

Below is a minimal EffectExtension implementation showing how to iterate over selected elements and apply direct style changes:

import inkex
from inkex import EffectExtension

class DirectStyleModifier(EffectExtension):
    def effect(self):
        # Iterate over all selected elements
        for elem in self.svg.selection:
            # Check if the element has styling capabilities
            if hasattr(elem, 'style'):
                # Read current stroke
                current_stroke = elem.style.get('stroke', 'none')

                # Apply new styling
                elem.style['fill'] = '#4a90e2'
                elem.style['stroke-width'] = '3px'

                # Conditional logic based on existing style
                if current_stroke == 'none':
                    elem.style['stroke'] = '#1b365d'

if __name__ == '__main__':
    DirectStyleModifier().run()
