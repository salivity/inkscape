Export Inkscape to Figma Without Losing Layer Names

Transferring vector assets between Inkscape and Figma often results in generic layer names like "path123" or "Group." This article explains why layer names disappear during SVG transfers between both applications and provides clear, step-by-step methods to preserve your exact layer hierarchy and naming conventions in both directions.

Why Layer Names Disappear

The primary reason layer naming fails between Figma and Inkscape is how each tool handles SVG metadata:

  • Inkscape stores the visible layer name inside a custom XML attribute called inkscape:label, while using the standard id attribute for internal references.
  • Figma ignores inkscape:label and strictly uses the standard SVG id attribute to name imported layers and frames.

To maintain naming integrity, the SVG id attributes must directly match your desired layer labels.

Exporting from Inkscape to Figma

To make Figma recognize your layer names, you must align the element IDs with your layer labels before exporting.

  1. Set the Object ID in Inkscape:
    • Select your layer or object.
    • Open the Object Properties panel (Shift + Ctrl + O).
    • Copy the text from the Label field into the ID field.
    • Click Set.
  2. Alternative for Complex Files (XML Editor):
    • Open the XML Editor (Shift + Ctrl + X).
    • Select the <svg:g> (group) or path tag corresponding to your layer.
    • Edit the id attribute to match your desired layer name.
  3. Save the File:
    • Go to File > Save As.
    • Choose Plain SVG or Optimized SVG.
    • If using Optimized SVG, open the export settings dialog, navigate to the SVG Output tab, and ensure that Remove unused IDs and Shorten IDs are unchecked.
  4. Import to Figma:
    • Drag and drop the exported SVG directly into your Figma canvas. Figma will parse the id attributes and apply them as layer names.

Exporting from Figma to Inkscape

When moving designs from Figma to Inkscape, Figma must be configured to write layer names into the SVG code.

  1. Select Your Frame or Group:
    • Select the root frame or components you want to export in Figma.
  2. Configure SVG Export Settings:
    • In the right-hand sidebar, scroll down to the Export section.
    • Set the format dropdown to SVG.
    • Click the Advanced settings icon (the three horizontal dots ...).
    • Check the box for Include "id" attribute. This forces Figma to write the layer name to the XML id tag.
    • Uncheck Outline text if you want to keep editable text elements.
  3. Export and Open in Inkscape:
    • Click Export [Layer Name].
    • Open the file in Inkscape (File > Open).
    • Open the Layers and Objects panel (Ctrl + Shift + L). The objects will reflect the names assigned in Figma.
