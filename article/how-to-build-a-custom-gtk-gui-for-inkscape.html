How to Build a Custom GTK GUI for Inkscape

This guide explains how to build and integrate a custom GTK-based graphical user interface (GUI) into an Inkscape extension using Python and PyGObject. While Inkscape natively generates basic dialogs from .inx XML files, creating a custom GTK interface allows developers to design complex, interactive controls, dynamic forms, and custom workflows. Below are the steps, configuration files, and Python code required to implement a functional GTK3 GUI for your custom extension.

1. Prerequisites and Requirements

To run GTK within an Inkscape extension, your environment must have:

  • Inkscape 1.0+
  • Python 3 with the inkex extension library.
  • PyGObject (gi repository) configured with GTK 3 support (gir1.2-gtk-3.0 on Linux, or the bundled Python environment on Windows and macOS).

2. Define the Extension Metadata (.inx file)

Inkscape requires an .inx file to register the extension in its menus. When using a custom GTK window, you do not define UI controls inside the .inx file; you only define the menu hook and the entry point script.

Create a file named gtk_custom_extension.inx:

<?xml version="1.0" encoding="UTF-8"?>
<inkscape-extension xmlns="http://www.inkscape.org/namespaces/inkscape/extension">
    <name>Custom GTK Interface</name>
    <id>org.example.custom_gtk_extension</id>
    <effect>
        <object-type>all</object-type>
        <effects-menu>
            <submenu name="Custom Tools"/>
        </effects-menu>
    </effect>
    <script>
        <command location="inx" interpreter="python">gtk_custom_extension.py</command>
    </script>
</inkscape-extension>

3. Build the GTK Window and Extension Script

Create gtk_custom_extension.py. This script subclasses inkex.EffectExtension, initializes PyGObject, builds the GTK window, and modifies the SVG document based on user input.

#!/usr/bin/env python3
import sys
import gi

gi.require_version("Gtk", "3.0")
from gi.repository import Gtk
import inkex
from inkex import Circle


class CustomGTKWindow(Gtk.Window):
    def __init__(self, extension_instance):
        super().__init__(title="Custom Extension Controls")
        self.extension = extension_instance
        self.set_default_size(300, 150)
        self.set_position(Gtk.WindowPosition.CENTER)
        self.set_border_width(12)

        # Layout container
        vbox = Gtk.Box(orientation=Gtk.Orientation.VERTICAL, spacing=8)
        self.add(vbox)

        # Label
        self.label = Gtk.Label(label="Set Radius for New Circle:")
        vbox.pack_start(self.label, False, False, 0)

        # Input field (SpinButton)
        adjustment = Gtk.Adjustment(value=20, lower=1, upper=500, step_increment=1)
        self.spin_button = Gtk.SpinButton(adjustment=adjustment, numeric=True)
        vbox.pack_start(self.spin_button, False, False, 0)

        # Button Layout
        hbox = Gtk.Box(orientation=Gtk.Orientation.HORIZONTAL, spacing=6)
        vbox.pack_start(hbox, True, True, 0)

        # Apply Button
        btn_apply = Gtk.Button(label="Apply")
        btn_apply.connect("clicked", self.on_apply_clicked)
        hbox.pack_start(btn_apply, True, True, 0)

        # Close Button
        btn_close = Gtk.Button(label="Close")
        btn_close.connect("clicked", self.on_close_clicked)
        hbox.pack_start(btn_close, True, True, 0)

        self.connect("destroy", Gtk.main_quit)

    def on_apply_clicked(self, widget):
        radius = self.spin_button.get_value()
        self.extension.add_circle(radius)

    def on_close_clicked(self, widget):
        self.destroy()
        Gtk.main_quit()


class CustomGTKExtension(inkex.EffectExtension):
    def effect(self):
        # Open GTK interface
        app_window = CustomGTKWindow(self)
        app_window.show_all()
        Gtk.main()

    def add_circle(self, radius):
        # Access the current SVG root
        svg = self.document.getroot()

        # Create a circle element
        circle = Circle()
        circle.set("cx", "100")
        circle.set("cy", "100")
        circle.set("r", str(radius))
        circle.set("style", "fill:#3498db;stroke:#2980b9;stroke-width:2")

        # Append to SVG
        svg.add(circle)


if __name__ == "__main__":
    CustomGTKExtension().run()

4. How the Execution Flow Works

  1. Invocation: When selected under Extensions > Custom Tools > Custom GTK Interface, Inkscape executes the Python script and passes the SVG data via standard input.
  2. UI Execution: The effect() method initializes the GTK application loop using Gtk.main(), pausing further script execution while displaying the standalone window.
  3. SVG Manipulation: Clicking Apply calls add_circle(), modifying the in-memory XML tree representation provided by inkex.
  4. Exit and Document Save: Once the window is closed, Gtk.main_quit() stops the loop. The inkex base class writes the modified SVG tree to standard output, updating the active Inkscape canvas.

5. Installation and Testing

  1. Locate your Inkscape User Extensions directory:
    • Linux: ~/.config/inkscape/extensions/
    • Windows: %APPDATA%\inkscape\extensions\
    • macOS: ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/extensions/
  2. Place both gtk_custom_extension.inx and gtk_custom_extension.py into the extensions directory.
  3. Make the Python file executable (Linux/macOS): 
    chmod +x gtk_custom_extension.py
  4. Restart Inkscape to load the extension.
