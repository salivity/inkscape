Calculate Pitch Circles for Inkscape Gear LPEs

This guide explains how to calculate pitch circle diameters and radii when designing gear profiles using Live Path Effects (LPE) and parametric tools in Inkscape. By understanding the direct mathematical relationship between tooth count, module, and circular pitch, you can accurately configure gear dimensions to ensure proper tooth engagement, center-to-center spacing, and seamless mechanical meshing within your vector layouts.

Essential Gear Geometry Variables

To calculate the pitch circle accurately, you must define the following standard gear parameters:

  • \(N\) (or \(z\)): Number of Teeth — The total count of teeth distributed evenly around the gear.
  • \(m\): Module — The unit of size that indicates how big or small the gear teeth are (commonly in millimeters).
  • \(p\): Circular Pitch — The distance measured along the pitch circle from the face of one tooth to the corresponding face of the adjacent tooth.
  • \(D\): Pitch Diameter — The diameter of the imaginary pitch circle where two gears make contact and roll together without slipping.
  • \(R\): Pitch Radius — The radius of the pitch circle (\(D / 2\)).

Primary Calculation Formulas

Inkscape’s parametric inputs rely on standard involute gear geometry. Depending on whether your tool prompts for the module or the circular pitch, use the corresponding formula:

  1. Using Module (\(m\)): \[\text{Pitch Diameter } (D) = N \times m\] \[\text{Pitch Radius } (R) = \frac{N \times m}{2}\]

  2. Using Circular Pitch (\(p\)): Because circular pitch represents circumference divided by tooth count (\(p = \frac{\pi \times D}{N}\)), the pitch diameter is calculated as: \[\text{Pitch Diameter } (D) = \frac{N \times p}{\pi}\] \[\text{Pitch Radius } (R) = \frac{N \times p}{2\pi}\]

Calculating Pitch Circles in Inkscape

When applying gear profiles in Inkscape via Live Path Effects or vector rendering extensions, tooth spacing is often defined using your document's current display units (such as millimeters or pixels).

  1. Match Document Units to the Formula: Ensure your project units are set consistently (e.g., millimeters). If you enter a circular pitch of \(5\text{ mm}\) for a gear with \(24\) teeth, the pitch diameter must be derived using the same unit.
  2. Calculate the Radius for Snapping and Layout:
    • For \(N = 24\) and \(p = 5\text{ mm}\): \[D = \frac{24 \times 5}{\pi} \approx \frac{120}{3.14159} \approx 38.197\text{ mm}\] \[R \approx 19.098\text{ mm}\]
  3. Draw Reference Circles: Create a circle with the exact computed diameter (\(38.197\text{ mm}\)) centered on your gear path. Turn this circle into a guide or set it to an auxiliary layer to verify that the generated tooth flanks intersect this boundary at the proper depth (the pitch line).

Calculating Center Distances for Meshing Pairs

To correctly position two meshing gears generated with the same module or circular pitch, calculate the center-to-center distance (\(C\)) using their respective pitch radii (\(R_1\) and \(R_2\)):

\[C = R_1 + R_2 = \frac{D_1 + D_2}{2}\]

Using the module: \[C = \frac{m \times (N_1 + N_2)}{2}\]

Using circular pitch: \[C = \frac{p \times (N_1 + N_2)}{2\pi}\]

Set Inkscape’s rotation centers and align the two gears along this calculated distance \(C\) to guarantee proper mechanical clearance and engagement without tooth overlap.
