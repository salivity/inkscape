Create Blurred Vector Clouds and Smoke in Inkscape

This guide demonstrates how to create realistic, scalable vector clouds and atmospheric smoke in Inkscape by leveraging compound paths and Gaussian blur. You will learn how to construct basic volume shapes, merge them into unified compound paths, build layered density, and apply non-destructive blur and opacity adjustments for a natural atmospheric effect.

1. Build the Base Shapes

Select the Circles and Ellipses tool (E) and draw several overlapping circles of varying sizes to form the silhouette of a cloud, or draw elongated, staggered ellipses along an upward trajectory for rising smoke. Ensure the shapes overlap significantly to establish a solid, continuous volume.

2. Merge into a Compound Silhouette

  1. Select all the overlapping shapes using the Select and Transform Objects tool (S).
  2. Navigate to Path > Union (or press Ctrl + +) to fuse the individual shapes into a single vector path.
  3. For discontinuous smoke trails containing isolated puffs that you want to manipulate as one object, select the shapes and go to Path > Combine (or press Ctrl + K) to create a single compound path.

3. Build Internal Density and Tonal Variation

Atmospheric elements require varying density, with solid cores and soft, fading edges:

  1. Duplicate the base compound path by pressing Ctrl + D.
  2. Scale down the duplicate path slightly and reposition it toward the center of the cloud or the thickest section of the smoke plume.
  3. Repeat this process once more to create a third, even smaller core layer.
  4. Assign colors to each layer based on lighting: use pure white or light grey for cloud highlights, darker tones for cloud undersides, and semi-translucent greys or tints for smoke.

4. Apply Blur and Adjust Opacity

  1. Open the Fill and Stroke panel by pressing Shift + Ctrl + F.
  2. Select the largest, outermost compound path and adjust the Blur slider between 10% and 25%, depending on the scale of your canvas. Set its Opacity slider between 30% and 60% to create a soft, dissipated outer edge.
  3. Select the middle path and apply a moderate blur (around 5% to 12%) with higher opacity (60% to 80%).
  4. Select the innermost core path and apply a subtle blur (around 2% to 5%) with near-full opacity to represent the thickest concentration of vapor or particulate.

5. Add Directional Lighting with Gradients

To give the element dimension rather than a flat appearance:

  1. Select any of your blurred compound paths and switch to the Gradient tool (G).
  2. Apply a Linear or Radial Gradient across the shape.
  3. Set the stop facing the light source to an opaque, bright color, and set the opposing stop to a lower opacity or a ambient shadow tone.

6. Group and Position

Select all the corresponding blurred compound paths and press Ctrl + G to group them. You can now duplicate, flip, scale, and rotate this group across your scene to build complex sky environments and atmospheric depth without losing vector scalability.
