How to Change Default Units in Inkscape

This guide explains how to change the measurement units in Inkscape to millimeters (mm) or inches (in). You will learn how to update the units for your active project and how to save a custom default template so every new document automatically opens with your preferred unit of measurement.

Step 1: Change Units for the Current Document

To update the measurement units for the file you are currently working on:

  1. Open Inkscape and navigate to the top menu.
  2. Go to File > Document Properties (or press Ctrl + Shift + D on Windows/Linux, Cmd + Shift + D on macOS).
  3. In the Document Properties window, select the General tab.
  4. Locate the Display units dropdown menu and select either mm (millimeters) or in (inches).
  5. Below the display settings, under the Custom size or Page section, change the Units dropdown to match your chosen measurement.
  6. Close the Document Properties window. The rulers and bounding box dimensions will now reflect your chosen units.

Step 2: Set Units as the Default for All New Documents

Inkscape uses templates to define default settings. To make millimeters or inches permanent for all future projects, save your configured document as the default template:

  1. Create a blank document and set the Display units to mm or in using the steps above.
  2. Adjust the page size (e.g., A4 for mm or Letter for inches) and orientation if desired.
  3. Go to File > Save Template....
  4. In the dialog box that appears:
    • Enter a Name (e.g., Default Millimeters or Default Inches).
    • Check the box for Set as default template.
  5. Click Save.

Step 3: Changing Units on Specific Tool Controls

While the display units control the canvas rulers and dimensions, you can also change the unit on the fly for specific tools:

  • When using the Select and transform objects tool (S or F1), locate the unit dropdown on the top control bar (next to the W and H fields) to toggle between mm, in, px, or other units instantly.
