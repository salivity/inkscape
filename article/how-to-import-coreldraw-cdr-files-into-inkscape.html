How to Import CorelDRAW CDR Files into Inkscape

This guide explains how to open and import CorelDRAW (.cdr) vector drawing files directly into Inkscape. While CorelDRAW uses a proprietary format, Inkscape includes native support for many CDR file versions through built-in conversion libraries. Below, you will find step-by-step instructions for direct importing, alternative conversion methods for unsupported versions, and tips for handling formatting discrepancies.

Method 1: Direct Import in Inkscape

Modern versions of Inkscape come pre-configured with libcdr, a library that allows the software to read and parse CorelDRAW files directly.

  1. Launch Inkscape on your computer.
  2. Go to the top menu and select File > Open (or File > Import if you want to add the design to an existing document).
  3. In the file browser window, click the file type drop-down menu and select Corel DRAW files (*.cdr), or leave it set to All Files.
  4. Navigate to your .cdr file, select it, and click Open.
  5. If prompted with an import dialog, adjust the page settings or color profiles as needed, then click OK.

Note: Inkscape generally supports CDR files from CorelDRAW versions 7 through X8. Files created in newer versions may fail to open or display missing elements.

Method 2: Convert via LibreOffice Draw

If Inkscape fails to open a newer or complex .cdr file directly, LibreOffice Draw can often parse it using an updated rendering engine.

  1. Open LibreOffice Draw.
  2. Go to File > Open and select your .cdr file.
  3. Once the file loads, go to File > Export.
  4. Choose SVG (Scalable Vector Graphics) as the export format and save the file.
  5. Open the newly created .svg file directly in Inkscape.

Method 3: Export from CorelDRAW (If Accessible)

If you have access to CorelDRAW, exporting to an open vector format produces the cleanest results in Inkscape:

  1. Open the file in CorelDRAW.
  2. Go to File > Export.
  3. Select SVG (Scalable Vector Graphics) or PDF (Portable Document Format).
  4. Open the exported SVG or PDF inside Inkscape.

Common Issues and Tips

  • Missing Fonts: If the source machine had custom fonts installed, the text in Inkscape may default to a generic system font. Convert text to paths/curves in CorelDRAW prior to exporting to preserve exact typography.
  • Proprietary Effects: Complex effects specific to CorelDRAW—such as special drop shadows, contour fills, and mesh gradients—may either be rasterized or lost during conversion.
  • Layer Groups: Imported CDR files often place all elements into grouped layers. To edit individual components in Inkscape, select the imported graphic and press Ctrl + Shift + G (or Cmd + Shift + G on macOS) to ungroup the objects.
