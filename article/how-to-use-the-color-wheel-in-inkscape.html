How to Use the Color Wheel in Inkscape

Inkscape offers several methods for choosing colors, with the Wheel color selector being one of the most intuitive options for visual color harmony. This guide explains how to access the Color Wheel in the Fill and Stroke dialog, navigate the outer hue ring and inner saturation-lightness triangle, and adjust object opacity for precise vector styling.

1. Open the Fill and Stroke Dialog

  1. Select the object you want to recolor using the Select and Transform objects tool (S or F1).
  2. Open the Fill and Stroke panel by pressing Ctrl + Shift + F (Windows/Linux) or Cmd + Shift + F (macOS), or by going to Object > Fill and Stroke in the top menu.
  3. Select either the Fill tab (to color the inside of the shape) or the Stroke paint tab (to color the outline).
  4. Click the Wheel tab icon located below the fill type buttons, alongside other color models like RGB, HSL, and CMYK.

2. Select the Hue

  • The outer circle represents the hue (the base color).
  • Click and drag the small circular handle along the outer ring to select your desired color from the 360-degree spectrum.

3. Adjust Saturation and Value (Lightness)

  • The inner triangle changes dynamically based on the hue selected on the outer ring.
  • The apex of the triangle represents the pure, fully saturated hue.
  • The bottom-left corner represents pure white.
  • The bottom-right corner represents pure black.
  • Click and drag the node inside the triangle to blend the hue with white, black, or gray to achieve the exact shade, tint, or tone required.

4. Adjust Opacity and View Hex Values

  • Alpha Slider (A): Located directly beneath the color wheel, this slider adjusts the transparency of the active fill or stroke from 0 (invisible) to 100 (fully solid).
  • RGBA Field: The text box at the bottom displays the current color's hex code. You can copy this code for use in other projects or paste an existing hex value to position the wheel selector automatically.
