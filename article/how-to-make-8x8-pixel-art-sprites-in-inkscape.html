How to Make 8x8 Pixel Art Sprites in Inkscape

This guide explains how to configure Inkscape to create crisp, vector-based 2D pixel art aligned perfectly to an 8x8 retro video game grid. You will learn how to prepare a pixel-precise canvas, set up strict grid snapping, draw using modular vector blocks, and export the artwork cleanly without unwanted blur or anti-aliasing artifacts.

1. Document and Canvas Setup

  1. Open Inkscape and create a new document.
  2. Open Document Properties by pressing Shift + Ctrl + D.
  3. Under the Display tab, set the Display units to px.
  4. In the Custom size section, set the canvas Units to px.
  5. Set both the Width and Height to 8 px for a single sprite, or a multiple of 8 (such as 64 px or 128 px) if you plan to build a spritesheet.
  6. Uncheck Show page border shadow to improve visual clarity at low resolutions.

2. Configure the 8x8 Snap Grid

  1. In the Document Properties window, switch to the Grids tab.
  2. Select Rectangular grid from the dropdown and click New.
  3. Set Grid units to px.
  4. Set Spacing X to 1.00000 and Spacing Y to 1.00000 so every individual pixel has its own grid cell.
  5. Set Major grid line every to 8 to clearly mark the boundaries of your 8x8 sprite tiles.
  6. Ensure the grid color is easily visible against your background canvas.

3. Enable Grid Snapping

  1. Toggle the global Snapping switch on in the upper right corner of the window (or press %).
  2. Expand the snapping menu and ensure Snap to Grids is active.
  3. Enable Snap bounding boxes and set it to snap to corners and edges.
  4. Disable snapping to object midpoints or smooth nodes to avoid accidental sub-pixel misalignment.

4. Drawing Vector Pixels

  1. Select the Rectangle Tool (R).
  2. Click and drag across a grid intersection to create a 1x1 pixel square. Snapping ensures the square locks exactly to the 1-pixel grid.
  3. Open the Fill and Stroke panel (Shift + Ctrl + F).
  4. Set a solid Fill color and ensure Stroke is set to No paint; stroke borders introduce sub-pixel outlines that break the pixel-art aesthetic.
  5. To populate your sprite, duplicate existing pixels using Ctrl + D and drag them into adjacent grid cells, or use the Spacebar while dragging to stamp duplicates along your path.
  6. Use restricted retro color palettes (such as 4 to 16 colors) to maintain an authentic retro game appearance.

5. Exporting Pixel-Perfect Sprites

  1. Open the Export dialog by pressing Shift + Ctrl + E.
  2. Set the export area to Page or Selection, depending on whether you are exporting an individual 8x8 sprite or an entire sheet.
  3. Because native 8x8 pixel images are too small for modern displays, scale the export using integer multiples (e.g., 800% to produce a 64x64 image, or 1600% for 128x128). This preserves hard, sharp edges.
  4. In the advanced export settings, ensure that anti-aliasing or image resampling does not blur the output, maintaining the crisp, blocky retro look.
  5. Select your target directory and click Export.
