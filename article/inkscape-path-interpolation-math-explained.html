Inkscape Path Interpolation Math Explained

Inkscape blends vector shapes using its Interpolate extension, which algorithmically generates intermediate shapes between two open or closed paths. This process relies on matching the structural definitions of both paths and applying parametric linear interpolation to every corresponding on-curve node and off-curve Bézier control handle. By treating intermediate coordinates as functions of a continuous time or step parameter, Inkscape smoothly transitions geometric properties from a source path to a target path.

Structural Alignment and Node Pairing

Before mathematical coordinate calculation begins, Inkscape pairs the components of the two input paths. For predictable results, both paths must contain the exact same number of nodes and subpath segments, oriented in the same direction.

Each path is internally represented as a sequence of cubic Bézier segments. A cubic Bézier curve segment is defined by four 2D coordinate vectors:

  • \(P_0\): Starting anchor point
  • \(P_1\): First control handle
  • \(P_2\): Second control handle
  • \(P_3\): Ending anchor point

If a segment is a straight line, Inkscape standardizes it into a degenerate cubic Bézier curve where the control handles are collinear with or coincident to the endpoints. Inkscape pairs each point \(k\) from the source path \(A\) with the equivalent point \(k\) in the destination path \(B\), forming coordinate pairs \((A_k, B_k)\).

Linear Interpolation of Coordinates

Once corresponding coordinates are mapped, Inkscape calculates intermediate steps using standard linear interpolation (\(LERP\)). For a given intermediate state governed by a normalized progression factor \(t \in [0, 1]\), each coordinate vector \(V(t) = (x(t), y(t))\) is calculated as:

\[V(t) = (1 - t) \cdot A_k + t \cdot B_k\]

Decomposed into Cartesian axes, the equations for the intermediate \(X\) and \(Y\) positions are:

\[x(t) = x_{A} + t \cdot (x_{B} - x_{A})\] \[y(t) = y_{A} + t \cdot (y_{B} - y_{A})\]

This calculation is applied uniformly to both anchor nodes and off-curve control points. Because the control handles are interpolated directly rather than recalculating curvature trajectories, the intermediate curves maintain affine consistency across all steps.

Step Distribution and Parametric Progression

When generating a specified number of interpolation steps (\(N\)), Inkscape derives the interpolation factor \(t\) for each individual step \(i\) (where \(i \in \{1, 2, \dots, N\}\)):

\[t_i = \frac{i}{N + 1}\]

Under linear distribution (the default exponent setting of 0), steps are distributed evenly along the transform vector between the source and target.

When an exponent value (\(e\)) is supplied to produce easing or non-linear spacing:

  • If \(e > 0\), the progression factor is transformed exponentially: \(t'_i = t_i^{(e + 1)}\) (or via a normalized power curve depending on implementation), clustering intermediate steps toward the start path.
  • If \(e < 0\), the inverse power mapping clusters intermediate paths toward the end path.

The modified factor \(t'\) is then substituted into the linear interpolation formula for each node coordinate.
