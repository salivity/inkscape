How to Change Canvas Background Color in Inkscape

Changing the canvas background color in Inkscape helps improve contrast, reduce eye strain, and accurately preview designs intended for colored backgrounds. This guide outlines the simple steps to modify the background color for your current document, adjust transparency settings, and save your preferred color as the permanent default template for all future projects.

Change the Background Color for the Current Document

  1. Open your project in Inkscape.
  2. Open the Document Properties window by pressing Ctrl + Shift + D (Windows/Linux) or Cmd + Shift + D (macOS), or by navigating to File > Document Properties in the top menu.
  3. In the Document Properties panel, select the Page tab.
  4. Locate the Background section and click on the Background color bar.
  5. A color palette dialog will appear. Choose your desired color using the color wheel, RGB/HSL sliders, or by entering a Hex color code.
  6. Check the Alpha (A) slider at the bottom of the color picker. By default, Inkscape sets the background alpha to 0 (fully transparent). Move the slider to 255 (or 100%) to ensure the background is completely opaque.
  7. Close the Document Properties panel. Your canvas will instantly update with the chosen color.

Toggle the Checkerboard Background

If you work with transparent assets and prefer a visual grid instead of a solid color:

  1. Open File > Document Properties (Ctrl + Shift + D / Cmd + Shift + D).
  2. Under the Page tab, check the box labeled Checkerboard background.
  3. Uncheck it at any time to return to a flat canvas color.

Set a Custom Background as the Permanent Default

If you want Inkscape to always open with your custom background color:

  1. Start a new, empty document.
  2. Follow the steps above to set your desired background color and alpha level.
  3. Ensure the canvas is completely blank with no leftover objects or guides.
  4. Go to File > Save Template... in the top menu.
  5. In the dialog box, enter a Name for the template (for example, "Custom Default").
  6. Check the box that says Set as default template.
  7. Click Save.

Whenever you launch Inkscape or open a new document, the canvas will automatically display your custom background color.
