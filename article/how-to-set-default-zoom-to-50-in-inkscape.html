How to Set Default Zoom to 50% in Inkscape

Inkscape does not include a standalone preference setting specifically for zoom levels, but you can easily set the default zoom to 50% for all new documents by modifying your default template. By setting your desired canvas view in an empty document and saving it as the default startup template, Inkscape will automatically open every subsequent new project at that exact 50% magnification.

Step 1: Open a Blank Document

Launch Inkscape or open a new document by pressing Ctrl + N (Windows/Linux) or Cmd + N (macOS).

Step 2: Adjust the Zoom Level to 50%

  1. Locate the Zoom indicator field in the bottom-right corner of the Inkscape window.
  2. Click inside the percentage box, type 50%, and press Enter.
  3. Use your mouse scroll wheel or the middle mouse button to pan the canvas so the page is positioned exactly where you want it centered on your screen.

Step 3: Save as the Default Template

  1. Go to the top menu and select File > Save Template...
  2. In the dialogue box that appears:
    • Enter a Name (such as Custom Default or Default 50% Zoom).
    • Check the box labeled Set as default template.
  3. Click the Save button.

Step 4: Verify the Changes

Close Inkscape and reopen it, or press Ctrl + N / Cmd + N to generate a new document. The new document will now automatically open centered at a 50% zoom level.
