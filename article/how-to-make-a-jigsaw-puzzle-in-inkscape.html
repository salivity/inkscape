How to Make a Jigsaw Puzzle in Inkscape

This guide demonstrates how to design interlocking puzzle pieces using the native Jigsaw extension in Inkscape. You will learn how to access the tool, configure key parameters like tab size and piece count, generate the vector pattern, and combine the resulting cut lines with an underlying image for printing or laser cutting.

Accessing the Jigsaw Generator

Inkscape comes with a built-in extension to automatically generate puzzle piece paths:

  1. Open Inkscape and set up your document to the desired puzzle dimensions via File > Document Properties.
  2. Navigate to Extensions > Render > Jigsaw... in the top menu.
  3. A dialog box will appear containing the settings needed to generate your puzzle pattern.

Configuring the Puzzle Settings

The Jigsaw dialog allows you to customize the geometry and arrangement of the pieces. Adjust the following controls to achieve your desired layout:

  • Number of columns and rows: Enter how many pieces wide and tall you want the puzzle to be.
  • Piece width and height: Specify the dimensions for individual pieces. Ensure the total width (columns × piece width) and total height (rows × piece height) match your target puzzle size.
  • Tab size: Controls the percentage size of the interlocking tabs relative to the pieces. A value between 15% and 25% provides a traditional appearance.
  • Edge radius: Adjusts the roundness of the tabs. Higher values create smoother, more rounded loops, while lower values produce sharper corners.
  • Jiggle: Sets the amount of randomness applied to the alignment and shape of the cut lines. Keeping this value slightly above zero creates traditional, organically shaped puzzle pieces rather than a rigid, symmetrical grid.

Check the Live Preview box to view real-time changes directly on your canvas. When satisfied with the layout, click Apply and close the window.

Customizing the Puzzle Cut Lines

Once generated, the puzzle exists as a single vector path made up of interconnected lines.

  • For Laser Cutting: Select the puzzle, open the Fill and Stroke panel (Ctrl+Shift+F), set the fill to none, and set the stroke width to your laser cutter's hairline specification (typically 0.001 inches or 0.05 mm).
  • For Vector Styling: You can change stroke colors, line thickness, or apply drop shadows for digital presentation purposes.

Combining the Puzzle with an Image

To make a standard picture puzzle, apply your vector puzzle lines to an image:

  1. Import your artwork using File > Import and scale it to fit the boundaries of the puzzle grid.
  2. Place the image directly underneath the puzzle vector using Object > Lower to Bottom (End key).
  3. If you only need cut lines, align the puzzle directly over the image and export your file as a PDF or SVG for your cutting machine.
  4. If you need individual interlocking pieces filled with the image for digital mockups, ungroup the puzzle (if broken into distinct closed paths) or use the vector path to slice the bitmap via clipping masks (Object > Clip > Set Clip).
