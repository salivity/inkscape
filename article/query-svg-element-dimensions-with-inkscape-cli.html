Query SVG Element Dimensions with Inkscape CLI

This guide explains how to extract the exact width and height of a specific SVG element using the Inkscape command-line interface. By targeting element IDs with Inkscape's built-in query arguments, developers and designers can inspect bounding box dimensions directly from the terminal or automate dimension extraction within automated build scripts and pipelines without launching the graphical user interface.

Prerequisites

To query a specific element, you need to know its id attribute. Open the SVG in a text editor or inspect it inside Inkscape to find the target element's ID (for example, rect1024 or layer1).

Querying Width and Height Separately

Inkscape provides dedicated query flags to output the width and height of an element in user units (typically pixels).

To query the width of a specific element, use the --query-id flag alongside --query-width:

inkscape --query-id="element_id" --query-width filename.svg

To query the height of a specific element, use --query-height:

inkscape --query-id="element_id" --query-height filename.svg

You can also use the shorthand equivalents for these options:

# Query Width
inkscape -I element_id -W filename.svg

# Query Height
inkscape -I element_id -H filename.svg

Querying Both Dimensions Simultaneously

If you need both width and height at the same time, using --query-all is faster because it parses the SVG document once. Combined with --query-id, it outputs a comma-separated list containing the element's ID, X position, Y position, width, and height:

inkscape --query-id="element_id" --query-all filename.svg

Output format:

element_id,x,y,width,height

To isolate the width and height directly in a Unix/Linux shell, pipe the result to cut:

# Extract Width (4th field)
inkscape --query-id="element_id" --query-all filename.svg | cut -d',' -f4

# Extract Height (5th field)
inkscape --query-id="element_id" --query-all filename.svg | cut -d',' -f5

Querying the Whole Document

If you omit the --query-id (or -I) parameter entirely, Inkscape defaults to querying the bounding box of the entire SVG canvas:

# Get total document width
inkscape -W filename.svg

# Get total document height
inkscape -H filename.svg
