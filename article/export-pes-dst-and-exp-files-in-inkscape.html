Export PES, DST, and EXP Files in Inkscape

Exporting embroidery formats like PES, DST, and EXP directly from Inkscape requires the use of the free, open-source extension known as Ink/Stitch. By converting vector paths into stitch data within Inkscape, you can save your designs into formats compatible with major embroidery machine brands, including Brother, Tajima, and Melco. This guide covers the complete, step-by-step process of preparing your vector graphic and saving it in your desired machine format.

Step 1: Install the Ink/Stitch Extension

Inkscape does not natively support embroidery machine formats out of the box.

  1. Download the Ink/Stitch extension corresponding to your operating system.
  2. Unpack the downloaded archive into your Inkscape extensions directory (found via Edit > Preferences > System > User extensions).
  3. Restart Inkscape. You will now see an Ink/Stitch menu item under the Extensions menu.

Step 2: Prepare Your Vector Paths

Before exporting, your artwork must be converted into paths that Ink/Stitch can process into stitches:

  1. Select all elements in your design.
  2. Navigate to Path > Object to Path to ensure no raw shapes or text objects remain.
  3. If using text, ensure fonts are converted to paths or created using the Extensions > Ink/Stitch > Lettering tool.
  4. Set appropriate fill and stroke colors, as Ink/Stitch uses fills for tatami/fill stitches and strokes for satin or running stitches.

Step 3: Generate and Validate Stitches

Validate your design to ensure there are no intersecting paths or unclosed loops that cause machine errors:

  1. Go to Extensions > Ink/Stitch > Troubleshoot > Troubleshoot Objects. Fix any highlighted errors.
  2. Select your objects and go to Extensions > Ink/Stitch > Params to preview stitch density, underlay, and stitch types.
  3. Click Apply and Quit once you are satisfied with the stitch parameters.

Step 4: Export to PES, DST, or EXP

Once your design is digitized and validated, export it into your required machine file format using either of the following methods:

Method A: Standard "Save As"

  1. Click File > Save As... (or File > Save a Copy...).
  2. Open the file format dropdown menu at the bottom of the dialogue box.
  3. Scroll through the available formats and select your required format:
    • Brother Embroidery Format (.pes)
    • Tajima Embroidery Format (.dst)
    • Melco Embroidery Format (.exp)
  4. Choose your destination folder, enter a file name, and click Save.

Method B: Ink/Stitch Batch/Interactive Output

  1. Navigate to Extensions > Ink/Stitch > Output > Save Embroidery File.
  2. Select your target format from the list.
  3. Choose the export location and click Apply to generate the file.

Your exported PES, DST, or EXP file is now ready to be loaded onto a USB drive or transferred directly to your embroidery machine.
