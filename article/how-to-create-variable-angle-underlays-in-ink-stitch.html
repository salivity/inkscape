How to Create Variable Angle Underlays in Ink/Stitch

This guide explains how to generate fill stitches with variable angle underlays using the Ink/Stitch embroidery extension for Inkscape. While Ink/Stitch provides automated underlay options in the basic fill parameters, these use uniform angles across the shape. Creating an underlay that dynamically shifts along with a curved or contour-following fill requires using custom guided fills on duplicate layers. Below are the precise steps to set up guide paths, configure custom underlays, and adjust parameter settings for clean embroidery output.

1. Create the Top Fill Shape and Direction Guides

  1. Draw your base shape as a closed path using the Bezier Tool (B).
  2. Draw two or more open stroke paths across the shape to serve as stitch direction guides. These lines define the variable flow of the fill stitches across your shape.
  3. Select both the shape and the guide lines, then group them together (Ctrl + G) or combine them into a single object depending on your workflow.

2. Duplicate the Shape for the Custom Underlay

Because default automated underlays cannot independently follow custom variable angles, you must create a dedicated underlay object:

  1. Select the entire group (the shape and its guide lines).
  2. Duplicate the selection (Ctrl + D).
  3. Open the Layers and Objects panel (Ctrl + Shift + L).
  4. Rename the lower group to "Underlay" and the upper group to "Top Fill". Ensure the Underlay group sits below the Top Fill group so it stitches first.

3. Adjust the Underlay Angle Guides

For structural stability, underlay stitches should cross the top stitches at an angle (ideally between 45 and 90 degrees):

  1. In the "Underlay" group, select the guide lines.
  2. Rotate or redraw these lines using the Node Tool (N) so that they run perpendicular or diagonal to the curves of the top fill guides while still maintaining a variable curve.

4. Configure Underlay Stitch Parameters

  1. Select the path in the "Underlay" group.
  2. Go to Extensions > Ink/Stitch > Params.
  3. Set the stitch properties to function as an underlay:
    • Method: Fill Stitch (Guided Fill).
    • Row Spacing (Density): Increase this value to between 1.2 mm and 2.5 mm (a low-density grid prevents excessive bulk).
    • Stitch Length: Set between 2.5 mm and 3.5 mm.
    • Underlay: Ensure all built-in underlay checkboxes are unchecked inside this dialog to avoid redundant stitches.
  4. Click Apply and Quit.

5. Configure the Top Fill Stitch Parameters

  1. Select the path in the "Top Fill" group.
  2. Go to Extensions > Ink/Stitch > Params.
  3. Set your standard top stitch parameters:
    • Row Spacing (Density): Set to your desired final density (typically 0.4 mm to 0.45 mm).
    • Underlay: Uncheck the default underlay options (Tatami, Row, Center Walk) since the custom variable underlay is already generated beneath it.
  4. Click Apply and Quit.

6. Verify and Simulate the Stitch Path

  1. Select both the Underlay and Top Fill groups.
  2. Navigate to Extensions > Ink/Stitch > Visualize and Export > Simulator/Realistic Preview.
  3. Ensure the underlay sews first along your modified contour angles, followed by the dense top fill running along its respective variable guide paths.
