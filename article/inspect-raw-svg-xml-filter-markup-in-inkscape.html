Inspect Raw SVG XML Filter Markup in Inkscape

Inkscape allows designers to build complex visual effects using custom SVG filters, but understanding, exporting, or fine-tuning them often requires examining the underlying code. This guide provides a direct, step-by-step walkthrough on how to inspect the raw SVG XML markup of any custom filter using Inkscape’s built-in tools as well as standard text editors.

Method 1: Using Inkscape's Built-in XML Editor

The fastest and most direct way to inspect and edit the raw markup of a filter without leaving Inkscape is through the native XML Editor.

  1. Open the XML Editor

    • Go to the top menu and select Edit > XML Editor...
    • Alternatively, press the keyboard shortcut: Ctrl + Shift + X (Windows/Linux) or Cmd + Shift + X (macOS).
    • A panel will dock on the side of your workspace displaying the document tree.

  2. Locate the <svg:defs> Section

    • In the XML Editor tree view on the left, expand the root <svg:svg> element.
    • Look for the <svg:defs> tag. All reusable resources, including gradients, markers, and custom filters, are stored inside this section.

  3. Find Your Filter Element

    • Expand the <svg:defs> node.
    • Scroll until you find the <svg:filter> elements.
    • If you named your filter via the Filter Editor (Filters > Filter Editor...), the id or inkscape:label attribute will match your custom filter's name.

  4. Inspect the Filter Primitives

    • Click the arrow next to your <svg:filter> element to expand its child nodes.
    • Each child represents an individual filter primitive, such as <svg:feGaussianBlur>, <svg:feColorMatrix>, or <svg:feBlend>.
    • Selecting any primitive displays its attributes (like in, stdDeviation, result, and type) in the attribute list on the right-hand side of the XML panel, where values can be reviewed or edited.

Method 2: Inspecting via an External Code Editor

If you need to copy, batch edit, or read large blocks of SVG filter code in a formatted environment, opening the file directly in a text editor is the most effective approach.

  1. Save Your File

    • Go to File > Save As...
    • Choose either Inkscape SVG (preserves Inkscape-specific metadata) or Plain SVG (strips editor-specific tags, leaving clean, standard SVG code).

  2. Open in a Code Editor

    • Open the saved .svg file in any text or code editor (such as VS Code, Sublime Text, or Notepad++).

  3. Locate the Filter Block

    • Use the search function (Ctrl + F or Cmd + F) to search for <filter.
    • The complete filter definition will appear between the opening <filter id="..."> and closing </filter> tags inside the <defs> container, containing all raw SVG filter primitives ready for copying or external use.
