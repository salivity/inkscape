How to Export Inkscape SVG to Apple ICNS Icons

Inkscape does not support direct export to Apple's native ICNS format, but you can create multi-resolution ICNS files by exporting your vector design as a high-resolution PNG and converting it using native macOS tools or cross-platform utilities. This guide outlines the standard workflow for preparing your vector artwork in Inkscape, generating the required icon resolutions, and packaging them into a single, production-ready .icns file.

Step 1: Prepare the Artwork in Inkscape

  1. Open your vector graphic in Inkscape.
  2. Open Document Properties (Shift + Ctrl + D or Shift + Cmd + D).
  3. Set the canvas to a square aspect ratio. A size of 1024 x 1024 px is recommended as the master size for macOS icons.
  4. Align your icon within the canvas, leaving standard padding around the edges to match macOS design guidelines.

Step 2: Export the Master PNG

  1. Go to File > Export... (Shift + Ctrl + E or Shift + Cmd + E).
  2. Select the Page tab to export the entire 1024 x 1024 canvas.
  3. Set the export format to PNG.
  4. Set the width and height to 1024 x 1024 pixels.
  5. Export the file as icon_512x512@2x.png.

Step 3: Generate the ICNS File

Method A: Using macOS Terminal (Recommended)

macOS includes a native command-line utility called iconutil that compiles an .iconset folder into an .icns file.

  1. Create an iconset folder: Open Terminal and create a folder ending with .iconset:

    mkdir MyIcon.iconset

  2. Generate the required resolutions: Place your exported 1024x1024 PNG in your working directory. Run the following sips commands to create all required Apple standard sizes inside the .iconset folder:

    sips -z 16 16     icon_512x512@2x.png --out MyIcon.iconset/icon_16x16.png
sips -z 32 32     icon_512x512@2x.png --out MyIcon.iconset/icon_16x16@2x.png
sips -z 32 32     icon_512x512@2x.png --out MyIcon.iconset/icon_32x32.png
sips -z 64 64     icon_512x512@2x.png --out MyIcon.iconset/icon_32x32@2x.png
sips -z 128 128   icon_512x512@2x.png --out MyIcon.iconset/icon_128x128.png
sips -z 256 256   icon_512x512@2x.png --out MyIcon.iconset/icon_128x128@2x.png
sips -z 256 256   icon_512x512@2x.png --out MyIcon.iconset/icon_256x256.png
sips -z 512 512   icon_512x512@2x.png --out MyIcon.iconset/icon_256x256@2x.png
sips -z 512 512   icon_512x512@2x.png --out MyIcon.iconset/icon_512x512.png
cp icon_512x512@2x.png MyIcon.iconset/icon_512x512@2x.png

  3. Convert the iconset to ICNS: Run iconutil to package the folder into a multi-resolution icon file:

    iconutil -c icns MyIcon.iconset

    This generates MyIcon.icns in the current directory.

Method B: Using Linux (libicns)

If you are working on Linux, use the png2icns tool provided by the icnsutils package.

  1. Install the package: 
    sudo apt install icnsutils
  2. Export the individual sizes from Inkscape: 16x16, 32x32, 128x128, 256x256, and 512x512.
  3. Combine them into an ICNS file: 
    png2icns icon.icns icon_16.png icon_32.png icon_128.png icon_256.png icon_512.png
