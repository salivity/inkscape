Lock Perspective Axes in Inkscape 3D Box Tool

This article explains how to lock and constrain the X, Y, and Z perspective axes when using the 3D Box tool in Inkscape. By adjusting vanishing point settings in the Tool Controls bar and utilizing keyboard modifiers, you can switch between perspective projections and parallel (axonometric or isometric) views, preventing specific axes from converging to a point.

Using the Tool Controls Bar to Lock Axes

The primary method for locking any perspective axis to a fixed, parallel orientation is via the 3D Box Tool Controls bar at the top of the canvas:

  1. Select the 3D Box tool from the toolbox on the left, or press Shift + F4 (or X).
  2. Click on an existing 3D box or draw a new one to display its bounding controls and the Tool Controls bar.
  3. Locate the three perspective toggle buttons in the top toolbar: Angle X, Angle Y, and Angle Z (indicated by icons representing parallel lines for each axis).
  4. Click the toggle button for the axis you wish to lock:
    • Toggle X (|| X): Sets the X vanishing point (\(VP_X\)) to infinity, locking the X-edges into parallel lines.
    • Toggle Y (|| Y): Sets the Y vanishing point (\(VP_Y\)) to infinity, locking the vertical/Y-edges into parallel lines.
    • Toggle Z (|| Z): Sets the Z vanishing point (\(VP_Z\)) to infinity, locking depth/Z-edges into parallel lines.
  5. Enter a specific degree value in the corresponding Angle input field next to the active toggle to fix the exact orientation of the parallel lines.

Constraining Axes with Modifier Keys

When manipulating a 3D box directly on the canvas using its handles, you can use keyboard modifiers to constrain movement along the perspective axes:

  • Shift + Drag: Dragging a vanishing point while holding Shift moves all vanishing points simultaneously, maintaining their relative perspective relationships.
  • Ctrl + Drag: When dragging a box handle (corner), holding Ctrl constrains the movement along the handle's corresponding perspective axis, preventing accidental distortion across other dimensions.
