Generate Dimension Annotations in Inkscape with Python

This article explains how to programmatically generate technical dimension annotations—including extension lines, dimension lines, arrowheads, and measurement labels—using Inkscape's native Python scripting API (inkex). By leveraging the inkex library, you can automate CAD-style dimensioning directly on SVG paths, ensuring consistent engineering drawings and eliminating manual drafting errors.

Understanding the Components of a Technical Dimension

A standard linear dimension annotation consists of four basic SVG elements:

  1. Extension Lines: Two parallel lines projecting outward from the feature's start and end points.
  2. Dimension Line: A line perpendicular to the extension lines showing the measured span.
  3. Markers (Arrowheads): SVG markers attached to the start and end of the dimension line.
  4. Dimension Text: A text element centered along the dimension line displaying the numeric measurement and units.

Setting Up the Script with inkex

Inkscape 1.0 and newer versions utilize the updated inkex API. You can write this either as an installable Inkscape extension or as a standalone script that manipulates an existing SVG file.

Required Imports

import math
import inkex
from inkex import PathElement, TextElement, Tspan

Complete Python Script Implementation

The following script defines an Inkscape extension that takes two coordinates, calculates the Euclidean distance, and appends a fully formatted dimension group to the active SVG layer.

import math
import inkex
from inkex import Group, PathElement, TextElement, Tspan

class AddDimensionAnnotation(inkex.EffectExtension):
    def add_arguments(self, pars):
        pars.add_argument("--x1", type=float, default=100.0, help="Start X coordinate")
        pars.add_argument("--y1", type=float, default=100.0, help="Start Y coordinate")
        pars.add_argument("--x2", type=float, default=300.0, help="End X coordinate")
        pars.add_argument("--y2", type=float, default=100.0, help="End Y coordinate")
        pars.add_argument("--offset", type=float, default=20.0, help="Offset distance from object")

    def effect(self):
        layer = self.svg.get_current_layer()

        x1, y1 = self.options.x1, self.options.y1
        x2, y2 = self.options.x2, self.options.y2
        offset = self.options.offset

        # Calculate angle and distance
        dx = x2 - x1
        dy = y2 - y1
        distance = math.hypot(dx, dy)
        angle = math.atan2(dy, dx)

        # Perpendicular unit vector for the offset direction
        perp_angle = angle + math.pi / 2
        ox = offset * math.cos(perp_angle)
        oy = offset * math.sin(perp_angle)

        # Dimension line coordinates (shifted by offset)
        dim_x1, dim_y1 = x1 + ox, y1 + oy
        dim_x2, dim_y2 = x2 + ox, y2 + oy

        # Create parent group for the dimension
        dim_group = Group()
        dim_group.set("id", self.svg.get_unique_id("dimension_"))

        # 1. Extension Lines
        ext_style = "stroke:#000000;stroke-width:0.5;stroke-dasharray:none;"
        ext1 = PathElement()
        ext1.set("d", f"M {x1},{y1} L {dim_x1 + (ox * 0.2)},{dim_y1 + (oy * 0.2)}")
        ext1.set("style", ext_style)

        ext2 = PathElement()
        ext2.set("d", f"M {x2},{y2} L {dim_x2 + (ox * 0.2)},{dim_y2 + (oy * 0.2)}")
        ext2.set("style", ext_style)

        # 2. Dimension Line
        dim_line = PathElement()
        dim_line.set("d", f"M {dim_x1},{dim_y1} L {dim_x2},{dim_y2}")
        dim_line.set("style", "stroke:#000000;stroke-width:0.75;marker-start:url(#Arrow1Mstart);marker-end:url(#Arrow1Mend);")

        # 3. Text Label
        mid_x = (dim_x1 + dim_x2) / 2
        mid_y = (dim_y1 + dim_y2) / 2

        text = TextElement()
        text.set("x", str(mid_x))
        text.set("y", str(mid_y - 2))  # Slight gap above the line
        text.set("style", "font-size:10px;text-anchor:middle;font-family:sans-serif;fill:#000000;")
        
        # Format distance to two decimal places
        tspan = Tspan()
        tspan.text = f"{distance:.2f} mm"
        text.append(tspan)

        # Assemble elements into group
        dim_group.append(ext1)
        dim_group.append(ext2)
        dim_group.append(dim_line)
        dim_group.append(text)

        layer.append(dim_group)

if __name__ == "__main__":
    AddDimensionAnnotation().run()

Key Script Calculations

  • Angle Calculation (math.atan2): Determines the orientation of the measured line relative to the X-axis.
  • Perpendicular Offsets: Computes perp_angle = angle + math.pi / 2 to ensure the dimension line is placed parallel to the target geometry at a designated distance (offset).
  • Extension Line Overshoot: Extension lines are drawn slightly beyond the dimension line (ox * 0.2) to conform to standard drafting practices.
  • Arrowhead Markers: Standard Inkscape markers like Arrow1Mstart and Arrow1Mend must exist in the document's <defs> section. If generating a file from scratch, ensure these marker definitions are appended to the root SVG <defs> node.

Running the Code Standalone

To run the logic outside the Inkscape GUI on an existing SVG file:

import inkex

# Load an existing SVG file
doc = inkex.load_svg("input.svg")

# Apply annotation logic directly on the doc.getroot() element
# ... [Insert calculation and element creation from above] ...

# Save output
with open("output.svg", "wb") as f:
    f.write(doc.tostring())

This approach allows you to batch-process technical drawings, measure existing bounding boxes or path segments dynamically, and inject dimension annotations automatically.
