Create Vector Compass Rose in Inkscape

This guide demonstrates how to design an intricate, symmetrical vector compass rose using Inkscape. By creating a single faceted compass point and leveraging Inkscape's rotational symmetry tools—specifically the Rotate Copies Path Effect and the Transform panel—you can quickly generate primary, secondary, and tertiary directional points aligned around a shared center.

1. Set Up Guides and Snapping

  1. Open a new document in Inkscape.
  2. Drag a horizontal and a vertical guide from the rulers onto the canvas so they intersect in the middle.
  3. Enable Snapping on the top toolbar. Ensure Snap to Guides and Snap to Nodes/Cusps are turned on.

2. Draw the Base Compass Point

A classic compass rose uses shaded facets to create a three-dimensional look.

  1. Select the Draw Bezier curves and straight lines tool (B).
  2. Click at the guide intersection (the center base), click vertically upward along the vertical guide to create the tip, click outward to the left to define the half-width, and click back at the center to close the triangle.
  3. Select the Fill and Stroke panel (Ctrl+Shift+F), give this left triangle a dark fill color (e.g., #2B2B2B), and remove the stroke.
  4. Select the triangle, press Ctrl+D to duplicate it, then click the Flip horizontally icon (H) on the top toolbar.
  5. Move the flipped shape to the right side of the vertical guide so both triangles share the central vertical seam.
  6. Change the fill color of the right triangle to a lighter shade (e.g., #D4D4D4).
  7. Select both triangles and press Ctrl+G to group them into a single compass point.

3. Set the Rotation Center

  1. Click the grouped point twice to reveal its rotation handle (the crosshair + at the center).
  2. Drag this crosshair down to the guide intersection. Snapping will ensure it locks precisely onto the center point.

4. Apply Rotational Symmetry

You can generate the remaining cardinal points (North, East, South, West) using either the Rotate Copies path effect or the Transform tool.

Method A: Using the Rotate Copies Path Effect (Live Symmetry)

  1. Ungroup your point (Ctrl+Shift+G), select both facets, and combine them into a single path using Path > Object to Path, then group them again (Ctrl+G).
  2. Go to Path > Path Effects... to open the Path Effects panel.
  3. Click the + (Add Path Effect) button and select Rotate Copies.
  4. In the effect settings:
    • Set Number of copies to 4.
    • Set Starting angle to 0.
    • Set Rotation angle to 90.
  5. Inkscape will automatically project four symmetrical points around the center. Any changes made to the master point will automatically update the other three.

Method B: Using the Transform Tool (Standard Duplication)

  1. Select the grouped point.
  2. Open the Transform panel (Ctrl+Shift+M) and navigate to the Rotate tab.
  3. Set the Angle to 90.0 degrees.
  4. Press Ctrl+D to duplicate the shape, then click Apply in the Transform panel.
  5. Repeat the duplication and rotation two more times to complete the four cardinal points.

5. Add Secondary and Tertiary Points

  1. Select the main cardinal points and duplicate them (Ctrl+D).
  2. Open the Transform panel, set the rotation angle to 45.0 degrees, and click Apply.
  3. Scale this new set down proportionally by holding Ctrl+Shift and dragging an outer bounding box handle inward.
  4. Adjust the fill colors to slightly darker or muted tones to create visual hierarchy between cardinal and ordinal directions.
  5. For a 16-point compass, duplicate the secondary set, rotate by 22.5 degrees, scale down further, and adjust colors accordingly.

6. Add Circular Accents

  1. Select the Create circles, ellipses, and arcs tool (E).
  2. Hold Ctrl+Shift, click on the guide intersection, and drag outward to create a perfectly centered circle.
  3. Set the circle to have a stroke, no fill, and position it behind or between the points using the Page Down key.
  4. Duplicate the circle and resize it to create concentric rings framing the star.
