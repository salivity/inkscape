Create Inkscape Presentations with JessyInk

This guide explains how to turn scalable vector graphics into interactive, browser-based slide decks using the JessyInk extension in Inkscape. You will learn how to initialize the extension, organize layers into slides, apply element animations and transitions, and export the finished presentation as an interactive SVG file that runs in any modern web browser without third-party presentation software.

What is JessyInk?

JessyInk is a built-in Inkscape extension that embeds JavaScript into your SVG files. This code turns standard vector illustrations and layer structures into interactive slides. Because the resulting file is a standard SVG, the presentation scales infinitely to any display resolution and can be viewed using any standard web browser.

Step 1: Initialize the Document

Before building slides, you must inject the JessyInk script into your SVG document.

  1. Open a new or existing document in Inkscape.
  2. Navigate to Extensions > JessyInk > Install/update... in the top menu.
  3. In the pop-up window, click Apply, then click Close.

The core scripts are now embedded in your document, enabling keyboard navigation and presentation features.

Step 2: Structure Slides Using Layers

JessyInk treats top-level layers as individual slides.

  1. Open the Layers panel (Layer > Layers and Objects... or Ctrl+Shift+L).
  2. Create a separate top-level layer for each slide you want to display.
  3. Place your text, graphics, and backgrounds on their respective slide layers.
  4. Rename each layer with a clear title or order number (e.g., 01_Intro, 02_Features).

Step 3: Configure Layer Roles

To ensure JessyInk recognizes your layers as sequential slides:

  1. Select a layer in the Layers panel.
  2. Go to Extensions > JessyInk > Layer properties....
  3. Set the layer mode to Slide.
  4. (Optional) Enter a slide title to display during index navigation.
  5. Click Apply.
  6. Repeat this process for every slide layer in the project.

Step 4: Add Object Transitions and Sub-Slides

You can reveal objects sequentially on a single slide to create bullet-point animations or progressive disclosures.

  1. Select the specific object or group on a slide that you want to animate.
  2. Navigate to Extensions > JessyInk > Effects....
  3. Choose the effect type:
    • Appear: Reveals the object on a step forward.
    • Disappear: Hides the object on a step forward.
    • Pop: Briefly highlights the object.
  4. Assign an order number (e.g., 1 for the first click, 2 for the second click).
  5. Click Apply.

Repeat this process for each sequential element on the slide.

Step 5: Set Up a Master Slide (Optional)

If your presentation uses persistent elements such as a company logo, page footer, or consistent background pattern:

  1. Create a dedicated layer containing these shared elements.
  2. Select the layer.
  3. Open Extensions > JessyInk > Layer properties....
  4. Set the mode to Master Slide and click Apply.

This layer will remain visible across all regular slides during the presentation.

Step 6: Export and Present

Because JessyInk relies on native browser rendering, you do not need to convert the file into a PDF or PowerPoint format.

  1. Save the file normally inside Inkscape as an Inkscape SVG (File > Save).
  2. Locate the saved .svg file on your computer and open it with any modern web browser (such as Chrome, Firefox, Safari, or Edge).
  3. Switch your browser to full-screen mode (typically F11 on Windows/Linux or Cmd+Ctrl+F on macOS).

Presentation Controls

Once opened in a browser, control your presentation using the following keyboard shortcuts:

  • Next Slide / Step: Right Arrow, Page Down, or Spacebar
  • Previous Slide / Step: Left Arrow or Page Up
  • First Slide: Home
  • Last Slide: End
  • Slide Index / Overview: i (allows you to visually browse and jump to any slide)
  • Drawing Mode: d (lets you annotate directly on the slide using your cursor)
