Trace Pixel Art to Vector Grids in Inkscape

Converting pixel art into clean, perfectly aligned vector graphics in Inkscape allows you to scale sprites infinitely without losing crisp edges or introducing unwanted blur. This guide covers how to import your raster sprite, configure the Trace Bitmap tool to capture hard pixel edges, snap paths to a precise grid, and optimize the final vector paths for clean shapes.

Step 1: Import and Configure Image Rendering

  1. Open Inkscape and go to File > Import to load your pixel art image (PNG or GIF format works best).
  2. Select the imported image and open the Object Properties panel (Shift + Ctrl + O).
  3. Set the Image Rendering dropdown to Blocky (optimizeSpeed / nearest neighbor). This prevents Inkscape from applying anti-aliasing interpolation to the source image preview.

Step 2: Configure the Trace Bitmap Tool

  1. Select your pixel art on the canvas.
  2. Open the trace dialog via Path > Trace Bitmap (or press Shift + Alt + B).
  3. Select the Multicolor tab and choose Colors from the detection dropdown.
  4. Set the number of Scans to match the exact number of colors used in your sprite (including background if applicable).
  5. Uncheck Smooth to prevent Inkscape from blurring color boundaries.
  6. Uncheck Stack scans to keep color layers from overlapping abnormally, or keep it checked if you prefer a continuous base layer.
  7. Switch to the Details / Advanced sub-tab:
    • Set Speckles (suppression threshold) to 0.
    • Set Smooth corners to 0 (forces 90-degree square corners).
    • Set Optimize to 0 (keeps straight edges along the pixel boundary).
  8. Click Apply.

Step 3: Align to a Pixel-Perfect Grid

  1. Hide or delete the original raster image to view the generated vector group.
  2. Open View > Page Grid (or press #) to enable the document grid.
  3. Open File > Document Properties (Shift + Ctrl + D), navigate to the Grids tab, and set the Grid units to px with spacing values set to 1.0 (or the pixel scale of your sprite).
  4. Enable snapping on the top-right toolbar: toggle on Snap to Grids and Snap to Nodes.
  5. Select your vector object, ungroup it using Object > Ungroup (Shift + Ctrl + G), and use the Node Tool (N) to verify that all nodes snap squarely to the grid intersection points.

Step 4: Clean and Merge Vector Paths

  1. Select all shapes sharing the same color.
  2. Go to Path > Union (Ctrl + +) to combine separate pixel squares of the same color into a single compound path.
  3. Repeat this process for each color layer to minimize total node count while preserving exact sharp-edged pixel boundaries.
