SVG Sprite Sheets with Distinct ViewBoxes in Inkscape

This guide explains how to generate inline SVG sprite sheets in Inkscape using <symbol> definitions with independent viewBox attributes. You will learn how to design your icons, convert them into reusable symbols within the editor, verify their individual coordinate boundaries, and export clean, production-ready SVG code for modern web development.

1. Design and Group Your Artwork

  1. Open Inkscape and create or import the vector icons you want to include in your sprite sheet.
  2. Ensure each distinct graphic is self-contained. Select all paths comprising an individual icon and press Ctrl + G (or Cmd + G on macOS) to group them.
  3. Open the Align and Distribute panel (Shift + Ctrl + A) and normalize your icon positions or dimensions if needed (for example, standardizing them inside 24x24 or 32x32 pixel squares), though distinct shapes and aspect ratios are fully supported.

2. Convert Groups into Symbols

  1. Open the Symbols dialog by navigating to Object > Symbols (or press Shift + Ctrl + Y).
  2. Select your grouped graphic on the canvas.
  3. In the Symbols panel, click the Add Symbol from current document icon (the plus sign at the bottom).
  4. Repeat this process for every icon you wish to include in the sprite sheet.

When Inkscape creates a symbol, it moves the vector content into a <symbol> element inside the <defs> section of the SVG file.

3. Configure Unique IDs and ViewBoxes in the XML Editor

Inkscape allows deep inspection and manual attribute configuration via its built-in XML Editor.

  1. Open the XML Editor via Edit > XML Editor (or press Shift + Ctrl + X).
  2. Expand the root <svg:svg> element, then locate and expand the <svg:defs> element.
  3. Select each <svg:symbol> element to review its attributes in the right-hand pane:
    • Set the id Attribute: Click the id field and rename it to a semantic label (e.g., id="icon-arrow", id="icon-check"). This identifier is what web browsers will reference via <use href="#id">.
    • Verify the viewBox Attribute: Inkscape automatically generates a viewBox attribute for symbols derived from objects. Confirm that the viewBox reflects the local dimensions of that specific artwork (e.g., viewBox="0 0 24 24" or viewBox="0 0 48 32").
    • Normalize Offsets: If your icon has unexpected offsets, ensure any wrapping <g> tags inside the <symbol> do not have unwanted transform="matrix(...)" or transform="translate(...)" properties throwing off your coordinate zero-point. If needed, manually adjust the viewBox min-x, min-y, width, and height values directly in this panel.

4. Export the Sprite Sheet

  1. Go to File > Save As...
  2. Choose Optimized SVG (*.svg) from the file format dropdown.
  3. In the export settings dialog:
    • Enable Remove unused defs (ensure your symbols remain referenced or uncheck this if your symbols are not currently placed on the visible canvas).
    • Enable Convert styles to XML attributes for easier CSS manipulation.
    • Strip editor metadata to keep the file size minimal.
  4. Save the file.

5. Using the Sprite Sheet Inline in HTML

Open the saved SVG file in a code editor. You will see an SVG wrapper containing your defined symbols:

<svg xmlns="http://www.w3.org/2000/svg" style="display: none;">
  <symbol id="icon-chevron" viewBox="0 0 16 16">
    <path d="M4 6l4 4 4-4" fill="none" stroke="currentColor" stroke-width="2"/>
  </symbol>

  <symbol id="icon-badge" viewBox="0 0 32 20">
    <rect width="32" height="20" rx="4" fill="currentColor"/>
  </symbol>
</svg>

Paste this block directly after the opening <body> tag of your HTML document. You can now instantiate any symbol anywhere on the page with automatic scaling according to its distinct viewBox:

<svg width="16" height="16" aria-hidden="true">
  <use href="#icon-chevron"></use>
</svg>

<svg width="32" height="20" aria-hidden="true">
  <use href="#icon-badge"></use>
</svg>
