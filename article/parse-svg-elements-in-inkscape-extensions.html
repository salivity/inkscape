Parse SVG Elements in Inkscape Extensions

Building custom Inkscape extensions requires querying and manipulating the SVG document structure programmatically. This guide explains how to access, search, and extract data from SVG elements using Python and the official inkex extension module in modern versions of Inkscape (1.0 and newer).

Setting Up the Base Extension

Inkscape extensions inherit from classes provided by the inkex library, most commonly inkex.EffectExtension. The SVG document is parsed into an XML tree structure based on lxml, which is exposed via the self.svg attribute inside your extension class.

import inkex

class SvgParserExtension(inkex.EffectExtension):
    def effect(self):
        # self.svg is the root SVG element
        root = self.svg

Accessing Elements

1. Parsing Selected Elements

To parse only the elements currently selected by the user in the Inkscape canvas, iterate over self.svg.selection:

for elem in self.svg.selection:
    inkex.utils.debug(f"Selected element ID: {elem.get_id()}, Tag: {elem.TAG}")

2. Searching by Tag Type

You can search through the entire document tree for specific element types using class filters on self.svg.descendants():

# Find all path elements
paths = self.svg.descendants().filter(inkex.PathElement)

# Find all rectangle elements
rects = self.svg.descendants().filter(inkex.Rectangle)

for path in paths:
    inkex.utils.debug(path.get_id())

3. Querying with XPath

For complex structural queries, use XPath directly on the document:

# Find all groups containing paths
groups_with_paths = self.svg.xpath('//svg:g[svg:path]')

# Find elements by a specific attribute value
custom_elements = self.svg.xpath('//*[@data-custom="true"]')

Extracting Element Data

Once an element reference is obtained, its geometry, styles, and attributes can be read.

Attributes and Metadata

Read standard and custom XML attributes using standard dictionary access or helper methods:

elem_id = elem.get('id')
custom_attr = elem.get('inkscape:label', 'Default')

Styles

Inkscape provides structured parsing for the inline style attribute via elem.style:

fill_color = elem.style.get('fill', '#000000')
stroke_width = elem.style.get('stroke-width', '1px')

# Modify styles directly
elem.style['fill'] = '#ff0000'

Path Geometry and Transformations

For path elements, geometric commands and transformations can be parsed into objects rather than raw strings:

# Parse path data commands (d attribute)
if isinstance(elem, inkex.PathElement):
    path_data = elem.path.to_arrays()
    for command, args in path_data:
        # e.g., 'M', [x, y] or 'C', [x1, y1, x2, y2, x, y]
        inkex.utils.debug(f"Command: {command}, Args: {args}")

# Parse transform matrix
transform = elem.transform

Complete Example

Below is a complete script demonstrating how to iterate over all paths in a drawing and print their IDs along with their stroke colors:

import inkex

class PathInspector(inkex.EffectExtension):
    def effect(self):
        paths = self.svg.descendants().filter(inkex.PathElement)
        
        for path in paths:
            path_id = path.get_id()
            stroke = path.style.get('stroke', 'none')
            inkex.utils.debug(f"Path ID: {path_id} | Stroke: {stroke}")

if __name__ == '__main__':
    PathInspector().run()
