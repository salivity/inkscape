How to Adjust Inkscape Node Size on High-Res Screens

Working on high-resolution (HiDPI or 4K) displays often makes path nodes and control handles in Inkscape appear tiny and difficult to click. This guide explains the exact setting responsible for the display size of node indicators, providing step-by-step instructions to make them larger and easier to see on modern monitors.

The Setting: Handle Size

The display size of node indicators and their control points is controlled by the Handle size setting (labeled as Node size in some older versions) located within Inkscape's Preferences menu under the Interface section.

Increasing this setting scales up the square, diamond, and round indicators displayed when using the Node Tool (N), without altering the actual vector geometry of your artwork.

How to Change the Node Indicator Size

Follow these steps to adjust the size of node indicators:

  1. Open Inkscape.
  2. Go to the menu bar and select Edit > Preferences (or press Ctrl + Shift + P on Windows/Linux, Cmd + Shift + P on macOS).
  3. In the left-hand sidebar of the Preferences window, click on Interface.
  4. Locate the Handle size slider.
  5. Move the slider to the right to increase the visual size of path nodes and bezier handles, or enter a higher numerical value directly.
  6. Close the Preferences dialog. The changes apply immediately on your canvas.

Adjusting Overall UI Scaling for High-DPI Displays

If the entire Inkscape interface (including toolbars, icons, and menus) is too small alongside your nodes, you can adjust the overall application scaling:

  1. Open Edit > Preferences > Interface > Theming.
  2. Locate the UI theme scale or Window scale option.
  3. Adjust the percentage or scale factor until the interface comfortably fits your screen resolution.
