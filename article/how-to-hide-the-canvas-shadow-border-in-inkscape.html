How to Hide the Canvas Shadow Border in Inkscape

This guide explains how to quickly hide the default canvas shadow border in Inkscape. By adjusting a single setting inside the Document Properties menu, you can remove the drop-shadow effect surrounding your workspace for a flatter, distraction-free design area.

To hide the canvas shadow, you need to disable the Show border shadow setting within the document settings.

Follow these steps to turn it off:

  1. Open your project in Inkscape.
  2. Open the Document Properties dialog by navigating to File > Document Properties in the top menu, or by pressing the keyboard shortcut Ctrl + Shift + D (Windows/Linux) or Cmd + Shift + D (macOS).
  3. In the Document Properties panel that opens on the right, ensure you are on the Page tab.
  4. Scroll down to the Border section.
  5. Locate the setting labeled Show border shadow (or Border shadow depending on your Inkscape version) and uncheck the box.

The shadow around your page boundary will disappear immediately. You can close the Document Properties panel, as Inkscape saves these changes in real time. If you also want to remove the bounding outline entirely, you can uncheck the Show page border option located in the same section.
