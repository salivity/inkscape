Inspect CMYK Values in Inkscape XML Editor

This guide explains how to inspect exact CMYK color channel values directly from the SVG source code using Inkscape's built-in XML Editor. While Inkscape works natively in an RGB display space, it allows color profiling and print-specific CMYK definitions that are stored directly within element attributes. Accessing the XML Editor provides a reliable way to verify the exact Cyan, Magenta, Yellow, and Key (Black) values embedded into your vector objects.

Step 1: Open the XML Editor

Launch Inkscape, open your document, and open the XML Editor using one of the following methods:

  • Go to the top menu and select Edit > XML Editor.
  • Press the keyboard shortcut Ctrl + Shift + X (Windows/Linux) or Cmd + Shift + X (macOS).

A panel will appear, displaying the hierarchical tree structure of the SVG document on the left and the attributes of the selected node on the right.

Step 2: Select the Target Object

With the XML Editor open, select the object on your canvas using the Select Tool (S). The XML tree will automatically expand and highlight the specific XML element node (such as <svg:path>, <svg:rect>, or <svg:circle>) that corresponds to your selection.

Step 3: Locate the Color Attribute

In the right-hand panel of the XML Editor, locate the attribute responsible for the object's color:

  • style: Most objects store their visual properties here. Click on the style row to view its contents in the bottom text field.
  • fill or stroke: If the document does not bundle styles into a single declaration, fill and stroke values may appear as individual attributes.

Step 4: Read the CMYK Channel Values

Within the attribute value, look for either the fill: or stroke: declaration. If the color was set using a CMYK profile or color managed workflow, the definition will feature an RGB fallback alongside the explicit CMYK definition:

  • ICC Color Syntax: fill:#rrggbb icc-color(<profile-name>, C, M, Y, K)
  • Device-CMYK Syntax: fill:device-cmyk(C, M, Y, K)

The four numerical values represent Cyan, Magenta, Yellow, and Key (Black) in order:

  • The channels are typically expressed as decimal numbers ranging from 0 to 1 (for example, 0.2, 0.5, 0, 0.1 corresponds to 20% Cyan, 50% Magenta, 0% Yellow, and 10% Black).
  • Some profiles may define these values directly as percentages (e.g., 20%, 50%, 0%, 10%).

If only a standard hexadecimal code (like #ff00aa) or rgb() value appears without an icc-color or device-cmyk tag, the object only contains RGB data and has not been explicitly assigned CMYK channel values.
