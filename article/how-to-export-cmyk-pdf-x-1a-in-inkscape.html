How to Export CMYK PDF/X-1a in Inkscape

This guide explains how to generate print-ready CMYK PDF/X-1a files from Inkscape for commercial printing. Because Inkscape natively uses an RGB SVG engine and the Cairo graphics library, it cannot directly output a certified ISO-standard PDF/X-1a file on its own. To achieve true PDF/X-1a compliance, you must configure CMYK color profiles inside Inkscape, export the artwork correctly, and convert the output using Ghostscript or Scribus.

1. Install CMYK Color Profiles

Inkscape requires an external ICC profile to calculate CMYK values accurately.

  1. Download standard prepress profiles, such as ISO Coated v2 (ECI) or U.S. Web Coated (SWOP) v2.
  2. Install the profile into your operating system's default color directory (/usr/share/color/icc on Linux, C:\Windows\System32\spool\drivers\color on Windows, or /Library/ColorSync/Profiles on macOS).
  3. Restart Inkscape.

2. Configure Inkscape Color Management

Set up your working space to preview and map CMYK colors accurately.

  1. Open your document in Inkscape.
  2. Go to File > Document Properties (Ctrl+Shift+D or Cmd+Shift+D).
  3. Navigate to the Color tab.
  4. Click Available Profiles, select your installed CMYK profile (e.g., ISO Coated v2), and click Add.
  5. Go to Edit > Preferences > Color management to ensure your display and proofing profiles are enabled to simulate CMYK color gamuts directly on your screen.

3. Design and Assign CMYK Swatches

To avoid automatic, inconsistent RGB-to-CMYK conversions during output:

  1. Open the Fill and Stroke panel (Ctrl+Shift+F).
  2. Instead of standard RGB or HSL tabs, switch to the CMS tab.
  3. Select your installed CMYK profile from the dropdown menu.
  4. Input your intended CMYK percentages directly.

4. Prepare and Export Base PDF from Inkscape

Prepare the vector artwork to avoid font-rendering and transparency errors common with PDF/X-1a specifications (which disallow live transparency).

  1. Flatten transparencies or convert transparent overlays into high-resolution rasters if necessary.
  2. Select all text and choose Path > Object to Path to ensure fonts are fully outlined.
  3. Go to File > Save As.
  4. Select Portable Document Format (*.pdf) from the file type dropdown.
  5. In the PDF export dialogue:
    • Set PDF version to PDF 1.4.
    • Enable Convert texts to paths.
    • Check Export area is page.
    • Set Resolution for rasterization (dpi) to 300 or higher.
  6. Click OK to save the base PDF.

5. Convert to Certified PDF/X-1a

Because Inkscape's internal Cairo exporter does not write the required PDF/X-1a output intent dictionary, use one of the two standard prepress conversion methods below:

Method A: Using Ghostscript (Fastest Vector Conversion)

Ghostscript can compile the Inkscape PDF into a strictly compliant PDF/X-1a file via the command line:

gs -dPDFX -dBATCH -dNOPAUSE -dNOOUTERSAVE \
   -sProcessColorModel=DeviceCMYK \
   -sDEVICE=pdfwrite \
   -dPDFACompatibilityPolicy=1 \
   -sColorConversionStrategy=CMYK \
   -sOutputFile=output_pdfx1a.pdf \
   PDFX_def.ps input_inkscape.pdf

(Ensure PDFX_def.ps points to your CMYK ICC profile to correctly populate the OutputIntent identifier).

Method B: Using Scribus (GUI Workflow)

  1. Open the free desktop publishing software Scribus.
  2. Go to File > Open or File > Import > Vector File and load your base PDF/SVG from Inkscape.
  3. Go to File > Export > Save as PDF.
  4. In the export window, set Output Profile to PDF/X-1a.
  5. Under the Color tab, verify the target is set to Printer and select your CMYK ICC profile.
  6. Click Save to produce the final, certified commercial print file.
